# ラウンジUI原本

画像生成による透過PNG。採用した生成プロンプトは [docs/prompts/ui_lounge_prompts.md](../../../docs/prompts/ui_lounge_prompts.md) に記録。

| 原本 | 用途 |
|---|---|
| panel.png | 会話枠・HUD・情報パネル・モーダルの9スライス |
| button.png | 選択肢・共通ボタン・名前欄・タイトル項目の9スライス |
| map-pin.png | 白〜銀の縁と墨色の面の地図看板。差し色は役割別の低彩度色で合成 |
| heart.png | 好感度と絆。空は無彩色、途中は下からクリップして表示 |
| gauge.png | 上段が空の外枠、下段が塗り。割合と残量の色はゲーム側で制御 |
| reward.png | 能力アップ通知。無彩色の面と枠を、上がった項目の色で合成 |

元PNGは保存したまま、採用した6原本から実行時用の7枚を再作成する:

```bash
python3 remake/tools/build_ui_skin.py
```

出力先は `remake/img/ui/lounge/*.webp`。透明余白の切り出し範囲と出力幅はビルダーで指定する。再生成で寸法や物体の範囲が変わったら、古い切り出し設定を使わず `source_size` と `crop` も更新する。

色や数値は `remake/css/ui-art.css` と既存DOMの役割。技術=黄、センス=水色、根性=赤橙、魅力=紫、洞察=青緑、体力回復=黄緑、好感度=ピンク、絆=琥珀。洞察と回復は色が被らないよう分ける。体力は最大値に対する残量が50%超で緑、25%超〜50%で黄、25%以下で赤。
