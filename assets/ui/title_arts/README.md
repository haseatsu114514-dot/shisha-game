## 追加・再生成

採用した縦2:3の原画を `title_art_<キャラID>_<2桁番号>_<場面>.png` で置く。候補・修正待ち・不採用原画をこのフォルダへコピーしない。

```bash
python3 remake/tools/build_manifest.py --title-only
```

`remake/data/manifest.json` の `titleArts` と `webp`、`remake/img/ui/title_arts/` だけを更新。他の立ち絵のアンカーや採用画像は再計測しない。全体の目録再生成でもタイトルアートを維持する。

表示は `remake/js/scenes/title.js` と `title-art.js`。元の右側配置・煙へのフェード・メニューを保ち、画像のデコード後に登場アニメーションを開始する。タイトルの抽選は進行・ギャラリー解放・セーブを変更しない。
