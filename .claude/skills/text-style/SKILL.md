# テキスト規範（句読点・改行・改ページ）

2026-07-07 オーナー指定（G1/G2）で制定。**この規範が句読点・改行の正本**。
迷ったらここに従い、規範自体を変えるときはこのファイルを更新する。

## 句読点のルール

1. **台詞（speaker あり）の末尾に「。」を付けない**。
   - ✅ `わかりました` ／ ❌ `わかりました。`
   - 閉じ括弧の直前も同じ: ✅ `（そうか）` ❌ `（そうか。）`
   - `！` `？` `……` で終わるのは可。`……。` は `……` にする。
   - ナレーション（speaker 空）は散文なので「。」で終えて良い。
2. **冒頭の間投詞のあとは「、」**。
   - ✅ `え、俺が、大会にですか？` ／ ❌ `え。俺が、大会にですか？`
3. **「。……」＋短い続き（相槌・照れ笑い等）は「、……」**。
   - ✅ `頑張れますよね、……えへへ` ／ ❌ `頑張れますよね。……えへへ`
   - 続きが独立した文なら「。……」のままで良い:
     `一度やってみるといい。……覚えておいて、損はありません` は変えない。
4. **1台詞に「。」は2個まで**を目安に。3個以上になったら台詞行を分ける
   （ノベルゲームのテンポ。lint が WARN を出す）。

## 改行・改ページのルール

- 手動改行 `\n` は入れない（autoWrap が全角24字・禁則・**文末（。！？）優先**で折る）。
- **語の途中では折らない**（2026-10-09 TX01・オーナー「言葉の途中で改行するぐらいなら早めに改行」）。
  句読点で折れない行は、手前の文節の頭（BudouX 日本語モデル `remake/js/vn/budoux_ja.js`）で早めに折る。
  漢字同士の間・同じ字の連続（えへへ）・辞書の一語（ありがたい）では折らない。「♡」「──」の後も区切りで、行頭に来た空白は表示しない。
  文末優先で改ページが1枚増える時だけ、一番後ろの区切りで折って1ページに収める。
- 早めに折る分、40字台でも3行（2ページ）になりうる。新しい台詞は台詞エディタか `node remake/test/text_wrap.mjs` で確かめる。
- 一文を2つの吹き出しにまたがせない。心の声は各行を（）で閉じる（`lint_dialogue.py` が閉じていない括弧をWARN）。
  どうしても演出で折りたい時だけ、1行が全角24字以内になる位置に置く。
- 1台詞は**全角48字（2行）以内**。超えると自動改ページで文が割れる（lint WARN）。
- 短い断片だけの「孤立ページ」（例: `ありがたい）` 1行）はエンジン側で自動回避される
  （engine.js typeText の寄せ替え）。それでも変な割れ方をしたら台詞を分けるのが正道。

## ツール（書いたら必ず通す）

```bash
# 1) 自動整形（上のルール1〜3を機械的に適用。--dry-run で差分確認から）
python3 tools/tidy_dialogue_text.py --dry-run
python3 tools/tidy_dialogue_text.py

# 2) リンタ（規範違反は WARN、旧名等は ERROR）
python3 tools/lint_dialogue.py

# 3) 手動で微調整したいとき（ブラウザの台詞エディタ。検索→編集→保存＋本編と同じ改行プレビュー）
python3 tools/text_editor_server.py   # → http://127.0.0.1:8321/
#   ・保存すると data/dialogue/*.json に直接書き戻る
#   ・プレビューは remake/js/vn/text.js の autoWrap 実物を配信＝本編とズレない
#   ・画面の「台詞の検査」「⬆️コミット&プッシュ」で 4) まで完結できる（main/masterでは拒否）
#   ・使い方の詳細は docs/tools/text_editor_manual.md（アプリ内「❓ヘルプ」からも読める）

# 4) 反映
# remake/ はJSONを直接読む。保存後、ブラウザを再読み込みする
```

## 注意（壊しやすい場所）

- 報酬キュー行（`……【技術】と【センス】が上がった。`）は**規定フレーズを一字一句変えない**
  （docs/gameplay_agent_reference.md「報酬を地の文に埋めない」参照）。tidy はナレーション末尾の「。」を触らないので安全。
- `remake/js/` 内のインライン台詞（インライン文字列）にも同じ規範を適用する。
  tidy は JSON しか見ないので、工程モジュールなどに台詞を書くときは手で従うこと。
- `remake/js/vn/text.js` を変更すると、台詞エディタも同じ実物を配信する。組版を複製しない。
