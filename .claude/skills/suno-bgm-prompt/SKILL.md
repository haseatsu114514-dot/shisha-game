# Suno AI用 BGMプロンプトの作成と組み込み

成果物は**オーナーがSunoにそのまま貼れるプロンプト**＋**曲のキー名（ファイル名）**。
ゲーム側の再生仕様（ループ・音量・埋め込み制約）を踏まえて依頼文を作る。

## Step 0 — まず「曲待ち」の把握

BGMは `assets/audio/bgm/<key>.mp3`。**0バイトのファイルは曲待ちプレースホルダ**:

```bash
find assets/audio/bgm -size 0   # 未制作の曲一覧（キー名は既に決まっている）
rg -n 'playBgm\("' remake/js   # どの場面でどのキーが鳴るか
```

新規の依頼が既存プレースホルダに該当するなら、そのキー名を使う（勝手に新キーを増やさない）。
完全新規の場面用なら `bgm_<場面>.mp3` で命名し、鳴らす場所（`SFX.bgm("キー")` の挿入点）まで決める。

## Step 1 — 場面の機能を言語化してからプロンプトを書く

曲は「かっこいい曲」ではなく**場面の機能**で発注する。書く前に3点を確定:

1. **どこで鳴るか・何から切り替わるか**（例: 控室の緊張→開幕コールでEDMへ。前後の曲との温度差が演出）
2. **プレイヤーに何をさせている時間か**（読ませる/選ばせる/操作させる。操作中は主張しすぎない）
3. **何分聞き続けるか**（日常曲は長時間ループ＝飽きない控えめさ。ジングル的な曲は短くドラマチックに）

## Step 2 — Sunoプロンプトの型

コピペ可能な1ブロックで、以下を含めて出す:

- **Instrumental指定**（歌なし。ボーカルが入ると台詞と喧嘩する）
- **スタイル/ジャンル・楽器編成・テンポ(BPM目安)・ムード**を英語で具体的に。
  世界観の基調: 薄暗いシーシャラウンジ／チル・スモーキー・琥珀色のネオン。
  レトロゲーム調UIに合うが、チップチューンに寄せる必要はない（既存曲は生楽器系）
- **ループ前提の構造**: イントロは短く（2〜4小節）、終端が頭に自然に戻る。
  派手なアウトロ・完全終止・長いフェードアウトは付けない
- **禁止事項**: no vocals, no sudden loud hits（会話画面で驚かせない）
- 目安尺: 1.5〜3分。場面の長さとループの継ぎ目を意識する（旧版の75秒埋め込み制限は廃止）

迷ったら2案出す（本命＋テイスト違い）。Sunoは当たり外れがあるので選択肢が親切。

## Step 3 — mp3を受け取った後の組み込み（こちら側の仕事）

1. `assets/audio/bgm/<key>.mp3` に配置（キー名=ファイル名。プレースホルダなら上書き）。
2. 画像・音声の目録に載るよう `python3 remake/tools/build_manifest.py` を実行。現行版はURLから音声を読み、単一HTMLへ埋め込まない。
3. 新しい場面なら `playBgm("キー")` を使うか、会話の `metadata.bgm` にキーを指定する（`remake/js/core/audio.js`・`vn/engine.js`）。
4. ブラウザで切替タイミング・ループ継ぎ目・音量を耳で確認。音量は `remake/js/core/state.js` の設定と `remake/js/core/audio.js` に従う。
   初回再生はユーザー操作までブロックされる仕様（自動再生制限）。
