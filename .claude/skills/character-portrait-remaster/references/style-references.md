# 過去の制作画像を毎回参照する

対象キャラの元絵と、これまで制作した画像を毎回実際に見る。画質と質感は文章だけでは引き継がない。

## 画像一覧と比較

- [全画像の一覧](style-references.json)：採用済みは初期15枚、つむぎの生成元2ファイルとゲーム用6枚、サメちゃんの5表情と追加生成元v3、凛v7・追加4生成元・ゲーム用5枚の12グループ42画像。通常修正案v11の生成元と確認用配置を加え、現在13グループ44画像。
- [比較ビューアー](style-gallery.html)：全画像の縮小一覧、1倍／2倍の原寸表示、白／暗い背景の切り替え。
- 初期の採用済み基準コミット：`cd76b8cf640bca11bf3b6afe2420484823247505`。

ビューアーはリポジトリのルートで `python3 -m http.server 8765 --bind 127.0.0.1` を起動し、
`http://127.0.0.1:8765/.claude/skills/character-portrait-remaster/references/style-gallery.html` を開く。
ファイルを直接開くとJSONを読み込めないブラウザがある。

画像一覧の `path` はこのディレクトリからの相対パス。全画像を目視したうえで、各セットの代表画像の顔・髪・服・縁を原寸で確認する。
ビューアーが使えない場合も、画像表示ツールでPNGを開き、必要な部分はブラウザ等の拡大表示で確認する。
透過の縁は白と暗い背景の両方で見る。ビューアーの2倍表示は補間なしで、保存元の画素は変えない。

## 何を合わせるか

| 見る箇所 | 揃える点 |
|---|---|
| 顔・目 | 小さな線やハイライトの鮮明さ、陰影の細かさ、顔の描き込みの密度 |
| 髪 | 細かなドットの粒度、ハイライトの段階、束と輪郭のシャープさ |
| 服・小物 | 布と金属の塗り分け、細部の密度、丁寧な陰影による高級感 |
| 輪郭・透過 | 線の太さ、ぼやけの有無、細い髪の残り方、色付きの縁や背景残り |
| 全身 | 顔と服で質感が揃っているか、表情ごとの品質と頭身が揃っているか |

意図された細かな高解像度ドット絵調を保つ。縮小でドットが見えなくなっても、滑らかな塗りへ寄せない。
2倍表示で見るドットの大きさと、1倍表示での完成度を両方確認する。
つむぎの基本5差分と病み可愛いv2、サメちゃんの基本4差分v2は2026-10-03に採用確認済み。
サメちゃんの追加5枚目v3と凛の新デザインv7は、2026-10-04のオーナー「全て完了したらマージ」で採用・組み込みを指示済み。
サメちゃんは可愛い青い瞳と小さな汗・吐息で息切れする熱弁。凛は胸元の紙なし・少し青みのある暗い髪・短めのロング・女性らしい体格を保ち、少し年上の半目とクールな微笑みを基本にする。
凛の5表情は通常／笑顔／真剣／驚き／悲しみ。笑顔1枚だけ目を閉じて頬に手を添える可愛いギャップを加えた。
[凛の5表情比較](rin-five-review.html)、[刷新前との比較](rin-redesign-review.html)、[サメちゃん5表情比較](kafuka-five-review.html)で本人と初期基準を確認する。
初期の採用済み15枚は変更していない。旧案は生成履歴に保存し、採用済み画風の一覧へ加えない。

2026-10-04の追加指摘で、凛v7系の髪・質感を修正中。本人のデザイン参照として使い、均一な強い光沢と細い毛線は引き継がない。最新指示は、みんと・つむぎに画風を揃え、v9の太すぎる毛束を写真程度の自然な束感に戻すこと。[通常v11](rin-style-v11.png)と[生成記録](rin-style-v11-generation.json)、[みんと／つむぎとの原寸比較](rin-style-v11-comparison-native.png)を保存。現在13グループ44画像（採用済み12・修正案1）。v8〜v10は履歴で、採用済み基準へ加えない。新しい描き方は通常1枚で比較している段階。

## 生成に必ず実画像を添付する

1. 対象キャラの元画像をデザインの参照にする。
2. 過去の採用済みPNGを最低1枚、通常は2枚、画風の参照として添付する。
   みんと営業姿＋あげはが標準。私服や落ち着いた衣装ではみんと私服も使う。今回の凛は最新指示でみんと営業姿＋つむぎを主要参照にする。
3. 最大5枚の環境なら、対象キャラに2〜3枚、画風に1〜2枚を割り当てる。
   対象の表情一覧を比較シートにまとめても、画風の参照は鮮明な元のPNGを含める。
4. 次のように役割を明記し、選んだファイルパスも生成プロンプトとともに保存する。

```text
The target character references define this character's identity, face, hair,
clothes, accessories and expressions. The attached previously approved Minto
and Ageha artwork defines the shared rendering quality and texture: refined,
high-resolution fine pixel-art grain, crisp delicate outlines, carefully stepped
shading, detailed hair and fabric, and a premium finish. Match those actual
images closely in rendering style. Preserve the target character's own design.
```

生成後は全身を同じ人物表示サイズで並べて比較し、顔・髪・服は双方の原寸で確認する。
粗いドット、ぼやけ、滑らかすぎる塗り、表情間で違う粒度や切り抜き残りを見つけたら直す。
確認用の比較画像を作る際も、画質の判断には元のPNGを使う。

## 新チャットでの取得と今後の更新

最新mainを取得し、一覧にある画像ファイルをローカルへ用意する。パスだけ読んで生成を始めない。
初期基準のSHA-256が一覧と異なる場合は、その変更履歴を確認する。
意図しない再圧縮や加工があれば、保存した初期基準コミットから元のPNGを取得して比較する。
後から採用された改善版を使う場合も、初期基準への固定参照を消さず履歴を残す。

新しく制作したセットを一覧へ追加する。採用前は `pending`、採用後は `approved` とし、
画像パス・表情名・参照役割・SHA-256・採用元コミットまたはPRを記録する。
ビューアーは一覧から表示するため、一覧の更新で次回も全制作セットを参照できる。
不採用になった案は採用済み基準へ加えない。直前の1人だけを参照して画風を徐々に変えない。
