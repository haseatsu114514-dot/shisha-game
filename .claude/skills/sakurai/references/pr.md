# 広報（ゲーム画面を見せる・製品像・体験版・発信）

桜井政博のゲーム作るには、の字幕から作った要点。番号は動画の通し番号（古い順）。

## 080 広報はかけ算【広報】
- 開発と広報は両輪で掛け算。知られなければ存在しないのと同じなので、作る側も積極的に知らせる方法を考える。
- 年間に数万本出る時代（Steam で2021年は推定1万本超）。埋もれないための努力が要る。
- 参戦ムービーなど「ゲーム内でも、単体の宣伝でも使える」素材を前提に作ると広報に効く。
- 告知のしつこい連投は読み手が嫌になる。公式の告知文や運営情報にも開発側が目を通して提案する。

## 101 製品像は正しく伝える【広報】
- タイトル・パッケージ・スクショ・予告で見せる製品像は、実際の中身と合致させる。バナナを買ってリンゴの味がするのはNG。ずれは興味を持つ客に届かず、間違えて買った人を失望させる。
- ゲーム内の意外性は良いが、売り場のイメージを偽らない。製品のアートは客が手に取る重要なきっかけ。
- タイトルは日本語なら4文字に略した形（スマブラ等）まで考えて決める。
- スーパーデラックスのシンプルなパッケージは「桐箱」というコンセプトで本質を表した例。直接的でなくても本質を伝える表現はある。

## 121 体験版【広報】
- 体験版は知ってもらうのに非常に有効だが、制作は小さいソフト1本分に近い労力がかかる。
- 理由：発売前配布なら漏洩対策（ログやファイルからネタバレを丁寧に抜く）、本編と別の2バージョン管理（更新・デバッグも別）、製品版並みのデバッグ、調整不足による悪評リスク。
- 完成後に要素を削る形で作ると楽だが効果は落ちる。調整済みの体験版を出すなら、発売後しばらくしてからになる。オンライン配信が日常になり有効性は高い。

## 141 ウェブサイト【広報】
- 公式サイトは、まとまった情報を正しく発信する場として重要。SNSの短い発信と併用し、作品に向いた構成にする。
- 要素が多いゲームは、一覧・遊び方・ステージ・サウンド・ムービーなど階層を整理して見せる。
- 初代スマブラは、見た目で「浅い」と偏見を持たれた。遊び方や駆け引きを資料にまとめ、発売前から発信して理解を求める努力をした。
- 理解されにくい作品ほど、遊び方・面白さを伝える手引きを自分で用意する。

## 161 参戦ムービー【広報】
- ゲーム中に挟むムービーは発売前にネットで拡散されてしまう。ならば進行に関係なく誰が見ても面白い独立した映像にする、と方針転換した（37本制作）。
- 制作の流れ: ディレクターがカット単位のプロット（見せ方・仕草・音楽タイミング）を書く、制作会社と詰める、絵コンテ、アニマティクス（粗編集で構図と尺を確定）、CG制作、音響。ゲームパートはリプレイ機能とデバッグカメラで撮影。
- 監修は全段階で入れる。よく出す指摘: もっと堂々と見せる、レイアウト変更、他キャラとの絡みを増やす、シリアスとコミカルのバランス、音楽に合わせる。

## 184 ゲーム画面を見せてくれ!【広報】
- ゲームが動く映像（プロモ動画）は購入判断に必須。無いと「論外」で買われない。
- 動画の冒頭にロゴ・OP・キャラ紹介・世界観を長く流さない。早い段階で実際のゲーム画面を見せる。ストアのトップ動画にゲーム画面が一切無いのも避ける。
- 特に新規IP・インディーは即ゲーム画面。ティザー的見せ方が許されるのは著名シリーズ・著名作者のみ。
- 映像演出は映画に及ばないので、製品の訴求点をパッと見せる。プレゼンはスピード。
- 例外：ゲームシステムを活かし、処理に偽りのないテックデモなら演出込みでも可。

## 205 人の目の前でゲームすること【広報】
- 目の前で実演するのは最も効果の高いプレゼンになり得る。実演では、必殺技や切り札を全部出す、圧勝にしすぎない、通常技も多めに見せる、など「見せ場を網羅する」ことを意識する。
- 実演するにはゲーム内容への理解が必要で、プレゼンを考えること自体が自分の考えの整理になる。
- 人前で見せる前提で頭の中で披露プレイを想像し、客の反応を考えてみると、課題が見えてくる。

## 224 ターゲティングとマーケティング【広報】
- ターゲット設定やマーケティングのデータは既存の物から作ったもので、新しい道は示さない。追いかけると平凡になり、レッドオーシャンに入る（例：ドラクエ風RPGが乱立した）。
- ユーザーの境界は曖昧（年齢や性別で線引きできない）。初代カービーは「初心者向け」であり、子供向けとは考えなかった。
- 新しい企画では話半分に扱い、人と違うことをする。ただし商売上必要な場面では使う。

## 243 スマブラ拳【広報】
- 良いゲームも知られなければ無いのと同じ。開発と広報は両輪で掛け算。奥深さが伝わりにくい作品は、遊び方・駆け引きを公式サイトで手引きとして出す。
- 開発中の写真や情報を速報として出し続け、コメントにも返答した。毎日1つ更新する運用（平日毎日、多言語対応）で、毎日の変化を楽しみに見に来る習慣を作ると効果が高い。
- ディレクターは最も詳しいので自分で発信するのも手だが、多忙になる。任せるなら監修の時間は覚悟する。
