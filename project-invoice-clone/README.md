# 動画編集 案件管理 クローン

X の参照動画にあった「案件管理 & 請求書自動作成」アプリのローカル版です。

## 使い方

`index.html` をブラウザで開くだけで動きます。

- ステージ別の案件ボード
- 管理月ごとの案件表示
- 月次の売上・経費・粗利サマリー
- 新規案件の追加と編集
- ドラッグ&ドロップでステータス変更
- クライアント管理
- 発行元プロフィールの複数保存と選択
- 保存品目の追加・編集・削除
- 経費の追加・編集・削除
- 発行元と振込先の設定
- 納品済み案件から請求書を自動生成
- 値引率と源泉徴収の選択
- ブラウザの印刷機能で PDF 保存

データはブラウザの localStorage に保存されます。

GitHub Pages では `/project-invoice-clone/` で公開する構成です。
