# Rila Riders Rescue（リニューアル版）

スマホ対応の高難易度2Dスタイリッシュアクション（ブラウザゲーム）。
主人公りらが、彼氏をさらった悪の組織のアジトに殴り込む。

このフォルダは旧 `game` リポジトリの全面リニューアル版です。
**ゲームロジック（手触り・技・難易度）はそのまま**に、見た目とUXを作り直しています。

## リニューアル内容

- **没入型レイアウト**: ゲーム画面が常に最大サイズで中央に表示される。ページ上の説明文・コマンド表・音量バーの常時表示を全て撤去
- **ポーズメニュー新設**: `Esc` / `P` または画面右上の ❚❚ ボタン。再開・操作ガイド・設定・タイトルへ戻る（誤操作防止の2段階確認つき）
- **操作ガイドのオーバーレイ化**: 基本操作＋4スタイルの技表をタブ形式でいつでも参照可能（表示中は自動ポーズ）
- **設定パネル**: 音量・画質モード（RETRO / CINEMATIC）・フルスクリーンをポーズメニューに集約
- **フルスクリーン対応**: 右上 ⛶ ボタン
- **タブ切替時の自動ポーズ**: 戦闘中にタブを離れると自動でポーズ
- **モバイル操作の全面再設計**: 縦持ちは画面下の操作パッド、横持ちは画面端への半透明オーバーレイ。ATKを主役にした配置で誤タップを軽減
- **SKIPボタンはカットシーン中のみ表示**
- **ファイル構成の整理**: `js/game.js`（エンジン）と `js/shell.js`（UI シェル）を分離

## ファイル構成

```
index.html        … 最小限のDOM＋オーバーレイ
css/style.css     … シェルのデザイン一式
js/game.js        … ゲームエンジン本体（旧 game.v0.6.1.js ＋ ポーズ/シェルAPI追加）
js/shell.js       … ポーズ・ガイド・設定・フルスクリーンなどのUI制御
assets/           … BGM・効果音・ボイス
```

エンジンとシェルは `window.RRR` API（pause / resume / getState / returnToTitle /
toggleVisualMode / get・setMasterVolume）だけで連携しており、
ゲームロジック側の変更は「ポーズゲート」と「攻撃ボタンの色をdata属性化」のみ。

## 実行

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 操作（PC）

| キー | 操作 |
| --- | --- |
| A / D, ← / → | 移動 |
| W / Space / ↑ | ジャンプ（2段可） |
| S / ↓ | しゃがみ・下入力 |
| J / F | 攻撃 |
| K | 射撃 |
| L | ダッシュ回避 / ガード |
| V（方向＋V） | スタイルチェンジ（直接選択） |
| U | バースト |
| Esc / P | ポーズ |
| G | 画質モード切替 |
| M | ミュート |

スタイル別の技は、ゲーム内右上の「？」→ COMBAT GUIDE を参照。
