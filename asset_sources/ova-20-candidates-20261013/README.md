# 90年代OVA画風：初稿20案＋強調版4案

KITE（1998）とBASTARD!!の旧OVA（1992）を参考に、正規キャラと店舗素材を用いて制作した比較候補。正式なゲーム素材には採用していない。

## 最新の強調版（21〜24）

初稿の現代的な細い線、細かい陰影、光沢を減らし、当時の顔・線・セル影・髪の帯状反射と背景美術を強く反映した。

## 参照と制作記録

- 人物は `assets/sprites/characters/` の正規立ち絵と `data/characters.json`、`brand/character_profiles.md` を参照。
- 場面は画風比較用の仮構図。顔・髪・衣装・年齢感を維持し、外部作品のキャラや衣装への置換はしない。
- [KITEの場面資料](https://www.screencapsmovie.com/2023/08/kite.html)、[BASTARD!!の場面資料](https://fantasyanime.com/anime/bastard-shots)、[BASTARD!!の制作セル写真](https://www.ebay.com/itm/126429087910)。
- [参照一覧](references.html) は掲載元の画像URLを表示する。外部作品の原画像をリポジトリへ同梱していない。
- プロンプト・入力参照・生成寸法・SHA-256・QAメモは [generation.json](generation.json)。
- [候補選択ギャラリー](index.html) はローカルで開いて番号の選択・拡大表示ができる。
- PNGは生成した原本をそのまま保管。再圧縮・切り抜き・拡大はしていない。

## QAと適用範囲

24原画を表示して正規キャラとの本人性・衣装・場所・構図を目視比較。画像を全件復号し、寸法・モード・SHA-256を記録。背景・キャラ・スチルの正式採用、設備構造の最終QA、画像レイヤー分離、ゲーム組込みは今回の範囲外。

初稿には現代的な描き込みが残るため比較用に保持。01の周辺の半透明光は立ち絵採用時に整理が必要。08・13の背景に残る展示器具は実物写真による追加QAが必要。21〜24をより強い90年代感の選定候補として追加した。
