3案とも 1084×1451 px の透過 PNG。並び比較は [`compare.html`](compare.html) を開く。背景には既存の `remake/img/ui/character_intros/graphic/bg_hajime.webp` を同じ設定で表示する。この HTML は候補の比較資料で、ゲーム画面への登録ではない。

## 生成時の参照画像と固定指示

- **見た目・服装・顔立ち・画風の正本**: `assets/sprites/characters/hajime/chr_hajime_normal.png`
- **表情と視線の基準**: `assets/sprites/characters/hajime/chr_hajime_serious.png`
- **現行カットイン＝比較対象のみ**: `remake/img/ui/character_intros/graphic/hajime.webp`。顔・画風の正本としては使わない。
- **背景の正本**: `remake/img/ui/character_intros/graphic/bg_hajime.webp`

共通の画風固定指示は、正規立ち絵のアニメ塗り、輪郭線、控えめな陰影、顔と目の形、年齢感、黒いキャップの三本線、黒いフード付きジャケット・Tシャツ・カーゴパンツ・靴、細い銀色の長方形ペンダントを厳密に維持すること。美化、装飾追加、別人化、現行グラフィック風への描き替えは禁止。3案とも真剣で静かな視線と閉じた口、同じ全身の距離感、透過背景を指定した。

個別の生成指示は次のとおり。

- **A**: 立ち絵とほぼ同じ体の向き・重心・肩・両手ポケット。視線と表情だけを変更。
- **B**: 立ち絵の体の向きと距離を維持。片手を胸元のジッパー付近へ上げ、頭を数度傾け、肩と重心をわずかに変更。もう片方の手はポケット。
- **C**: 同じ向きと距離を維持。片手をポケット、もう片方を帽子のつばへ。頭・肩と前方への重心移動を B より少し強める。大きな身振りや体のひねりは禁止。

画像生成は Codex 内蔵 imagegen で各案を個別に実行。比較ページは既存背景と透過 PNG を HTML/CSS で重ねている。

## 一次検品

- 3案の帽子、髪型、顔、黒い服装、ペンダント、カーゴポケット、靴を正規立ち絵と目視比較した。明らかな装飾追加や別人化は見当たらない。
- 3案は同じ画素数・透過背景で、共通の現行背景上に置いた。表情は静かな真剣さで揃えた。
- シーシャ台・HMD・ボウル・ホースは描いていない。植物、看板文字、ロゴの追加もない。
- 候補のため、最終採否と実画面での見え方は司令塔の比較プレビュー検品に委ねる。
