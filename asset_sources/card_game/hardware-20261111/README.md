## 検品

- 風防: 空の取り外したカバー1つ。開口、通気穴、側面の輪形ハンドルが成立。ボウル・HMD・炭・台を混ぜていません。
- アイスホース: 冷却ジェルの硬いハンドル→柔らかいホース→台側の接続金具を両方向に追跡。分岐・第三の端・途切れなし。初回が短かったので修正し、最終版の管は概ねハンドル4本分の長さが見えます。首掛け・人物・煙はなし。
- ディフューザー: 3cm級のシリコン製の部品という設定。上の差し込み口と側面の小さな通気穴が区別できます。水中のダウンステム先端に使う小部品で、台・瓶・HMD等は描いていません。
- 3枚とも同じ夜紫背景、左上のラベンダー光、薄い暖色の縁、ペインター調。文字・数字・実在ロゴ・枠なし。comparison.jpgに採用済みtimerと210px/100pxの比較を保存。器具の輪郭は識別できます。細部の見え方や明るさの最終採否はオーナー判断です。

画像デコード・正方形・不透明・SHA、LFSアップロードを検証します。API保存のためローカルcheckout/root/hooks検査は対象外。原画・512候補・記録だけを追加し、ゲーム用素材・JS・CSS・採用済みカード・build結果は変更していません。ゲームへの組み込みと実ゲームの検査は採用後の工程です。
