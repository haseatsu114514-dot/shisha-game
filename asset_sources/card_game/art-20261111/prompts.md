- **絵に文字・数字・枠を描かない。** カードの枠・名前・数字はコードが描く。

## CHECK（1枚ごと。外れたら同じ文で作り直す。3回でだめなら、どこがだめかを README に書く）

- 卓: 画像いっぱいに天板だけ／物・影・線・文字なし／模様が弱く、上に白い文字と札を置いて読める／四隅が中央より暗い。
- 裏面: 縦長の札が画像いっぱい／二重の細線が一周している／中央に紋が1つ／上下を逆にしても同じに見える／文字・数字・マークなし。
- カードの絵（24枚）: 題材が1つで中央・約70%／背景は夜紫の無地／100pxに縮めても何の絵か分かる／人物・手・顔なし／
  シーシャ台・ボウル・HMD・炭の塊・ホースなし／文字・数字・ロゴなし。
- 24枚を並べて、明るさ・大きさ・光の向きがそろっている。1枚だけ浮くものは作り直す。

## gen.py に入れていない絵（別の手順が要る）

- **機材が写る器具 3枚**（`card/windguard` 風防・`card/ice_hose` アイスホース・`card/diffuser` ディフューザー）:
  `docs/shisha_reference.md`「4. 画像生成の必須手順」に従う。参考写真（非公開リポジトリ `siryou` の
  `shisha-hardware-reference/web-refs/images/`）を見て、4.2 の文をそのまま貼り、STYLE-ART の後ろに置く。4.1 と 4.4 で検品する。
- **箱絵の無い葉 4種**（`cool_mint`・`jasmine`・`chocolate`・`coffee`。`ice_grape` はグレープの箱を借りている）:
  本編のショップと同じ箱絵にする。作り方は `asset_sources/new-flavor-cartons-nf04/PROMPTS.md`（メーカーごとの採用済みの箱を参照に渡す）。
  カードのデータ上のメーカーは、クールミント＝アルファーヘブン、ジャスミン＝アフサール、チョコレート・コーヒー＝ドバジ。
- 炭・コンロ・ボウル・HMD・人物・審査員は、本編の正規の絵を使う（新しく描かない）。
