# TRPGの20面ダイス（立体の絵）— Codex用の依頼文

オーナー要望（2026-11-10・TMX06）「サイコロもリアルにしたい」。今の判定のダイスはCSSで描いた平らな20面なので、立体の絵に替える。
出目の数字はコードが上の面に描く（絵には数字を入れない）。投げる・跳ねる・止まる動きも今のコードのまま使う。

- 置き場所: 原画はこのフォルダの `raw/`、採用した原寸は `assets/ui/trpg/`、ゲーム用は `remake/img/ui/trpg/`（WebP）
- 画風の基準: 既存の卓の小物 `assets/ui/trpg/spare-polyhedral-kit-v1.png`（添付して「同じ質感」と伝える）
- 受け取ったら: 透過・数字が無いこと・上の面が正面を向いた三角であること・6コマが同じダイスに見えることを確認してから組み込む

## 依頼文（このままCodexへ）

```text
TRPGミニゲームの判定画面で使う「20面ダイス」の絵を2枚作ってください。
添付の spare-polyhedral-kit-v1.png は、同じ卓に置いてある小物です。これと同じ画風・質感（上品でリアル寄りのアニメゲームの小物、やわらかな絵筆の質感、くっきりした輪郭）でそろえてください。

共通の決まり:
- 被写体は20面ダイス（正二十面体）1個だけ。工場で作られたRPG用ダイスの正確な形（20枚の正三角形の面、角は少しだけ丸い）。宝石や石ころのような不規則な形にしない
- 素材は象牙色（アイボリー）の樹脂。ほんのり温かい乳白色で、面ごとに明るさが違い、稜線に細い光が走る。角と稜線にごく薄い真鍮色の縁取り
- 光は左上からの暖かいランプの光。深緑のフェルトの上に置く想定なので、影側の面にごく薄い緑の照り返し
- 背景は完全な透過（アルファ）。机・フェルト・木枠・背景の色は描かない
- 絶対に描かないもの: 数字、文字、記号、点（ピップ）、ロゴ、枠、UI、手、人物、ほかのダイス、光の輪、集中線、モーションブラー、watermark
  （数字はゲームのプログラムが後から面の上に描きます。面はすべて無地にしてください）

--- 1/2: d20-rest.png（止まっているダイス） ---
サイズ: 1024x1024、透過PNG
- ダイスは画像の中央。左右上下に12%以上の余白
- カメラは真上に近いやや手前から（水平から約70度上）。いちばん上の面が、頂点を上にした正三角形にほぼ正面から見え、画像の中央に来る
- その上の面は、画像の幅の約38%の大きさ。ここに後から数字を描くので、ハイライトや傷を入れず、なめらかで明るい無地にする
- 上の面のまわりに、傾いた面が9〜10枚見える（正二十面体を真上近くから見た形）
- 接地の影は入れない（影はプログラムが描きます）

--- 2/2: d20-tumble.png（転がっている途中の6コマ） ---
サイズ: 1536x1024、透過PNG。3列x2行の6マス（1マス 512x512）に、同じダイスを1個ずつ
- 6マスとも 1/2 と同じダイス・同じ大きさ・同じ光。向きだけが違う
- 向き: ①頂点が手前を向く ②稜線が正面に来る ③大きく左に傾く ④大きく右に傾く ⑤頂点が真上を向く ⑥奥へ倒れかけ
- どのマスも、ダイスはマスの中央。マスの端から12%以上の余白。マスの境界線や枠は描かない
- モーションブラー・残像・影は入れない（くっきりした静止画を6つ）
```

## 組み込み（こちら側の作業）

1. 原画を `raw/` に保存し、`assets/ui/trpg/d20-rest.png`・`d20-tumble.png` へ（新規画像は Git LFS）
2. `remake/img/ui/trpg/` へ WebP（rest は 512px、tumble は 768x512）
3. `remake/css/trpg-stage.css` の `.trpg-roll-stage .trpg-die` を絵に替える（宙では tumble の6コマを順に、着地で rest。数字は今の DOM のまま上の面に重ねる）
4. `node remake/test/browser/trpg_tabletop.mjs` と、スマホ横持ちの判定画面の目視
