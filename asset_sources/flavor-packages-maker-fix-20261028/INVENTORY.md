## 棚卸しの補足

- `remake/img/shop/packages/` の18点（issue586 で採用された旧世代の植物画缶）は現行コードから参照されておらず、メーカー表記もない（植物画と装飾枠のみ）。棚卸しの「画像あり」には数えていない
- `remake/img/shop/flavors.webp`（植物画シート18窓）はショップ一覧で生成アートの読み込みに失敗した際の代替表示専用で、パッケージ自体は描かれていない（果物イラストのみ・表記なし）
- 制作画面の `flavorPackageArt` は生成アートの4マップのみを使い、未登録フレーバーは「フレーバー」の文字表示にフォールバックする。画像なし37件＋今回新規生成した3件はこの状態
- キャラクター系シート（sheet-nine / sheet-three / blast mint / dragonfruit-black-tea）はメーカー横断で同一の中立デザイン（黒箱＋筆波＋実写）になっており、メーカー別の意匠が確立しているのは heaven10（アルファーヘブン）、remaining8（アフサール／ドバジ）、limited 勢だけである
