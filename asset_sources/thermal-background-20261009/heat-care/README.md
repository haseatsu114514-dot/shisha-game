## 現在の仕様（要点）

- 背景: 序盤は色のない灰色→ぬるいうちに暖かい色→適温は虹（心地よい程度の虹色の炎・陽炎）→超えると黄色→赤の炎と黒煙でだんだん火事に。温度に沿って連続的に移る。
- ボウル: 普段は煙を出さない。過熱から自然な灰白色の煙を少し。焦げたら黒煙。
- 温度計: 黒い部分なし。灰色→暖色の目盛りの上を少し暗くし、適温は一色の緑、その真ん中に細い金の最適温（虹は背景だけ）。超えると管の中で炎。上端の「焦げる」（94%から）と熱管理の下端の「冷え切り」（6%まで）は細い縞で、入ると点滅。今の温度は管の外の光る矢印でも示す。吸い出しの針は太く上下に金の印。
- 調整（大会のR3・熱管理）: 炭を焼く個数（焼かない／1〜3個）→替えた分だけ少し温度が上がる→吸い出しと同じ針（キープで維持）。炭は燃え進んで温度が動き続ける。最低1回吸って「整え終える」。
- フレーバーの体力: 体調の顔の横の一枚の葉が、斑点→欠け→穴→枯れて崩れる（4段階＋尽きる）。吸い出しは4回目、調整は3回目から傷み、文字は出さずダメージ音と揺れだけ。吸い出しから調整へ引き継ぐ。
- 疲れ: 吸いすぎ・過熱（76%以上）の煙を吸うと、はじめの体力が削れて「疲れ」が付く（針が速く、成功帯が狭い。体力が境界を割れば体調の顔も変わる）。レッスンでは起きない。
- その一台がダメになる: 温度計の一番上（焦げ・画面全体の大爆発）、調整で冷え切り、フレーバーの体力切れ。大会ではその場でGAME OVER→「再挑戦しますか？」→大会の頭から。レッスンはスミさんが詰め直してやり直し、前日リハーサルは専用の短い場面。
