## 現在の仕様（要点）

- 背景: 序盤は色のない灰色→ぬるいうちに暖かい色→適温は虹（心地よい程度の虹色の炎・陽炎）→超えると黄色→赤の炎と黒煙でだんだん火事に。温度に沿って連続的に移る。
- ボウル: 普段は煙を出さない。過熱から自然な灰白色の煙を少し。焦げたら黒煙。
- 温度計: 一本の切れ目のないグラデーション（灰→暖色→適温のミント→橙→赤）。今の温度より上は少し暗い。文字の目盛りは置かず、適温の両端に白い刻み、真ん中に虹の最適温（適温／最適温／適温のサンド）、上端の焦げる帯（94%から）に炎、熱管理の下端の冷え切り帯（6%まで）に雪の結晶。今の温度は管の外の光る矢印、吸うと横に ▲／＝／▼ が浮かぶ。
- 吸い方: 温度計の横の半円ダイヤル。輪は左の上げ吸い（暖色）→キープ→右の下げ吸い（寒色）のグラデーションで、各帯に「▲ 上げ吸い／キープ／▼ 下げ吸い」。光る芯が実際の成功帯。内側に今の温度の一語（最適温は虹色の文字）と吸った回数の点。EXCELLENT 等の判定は出さない。
- 調整（大会のR3・熱管理）: 立ち上げから吸われて消耗した炭を交換する。「炭を交換しますか？」（交換しない／1〜3個、▲が多いほど戻る）→ 交換する個数だけ炭焼き → 焼け具合で戻る熱と持ちが変わる → 交換した分だけ温度が戻る → ダイヤル（キープで維持）。炭は燃え進んで温度が下がり続ける（↓）。最低1回吸って「整え終える」。最初の炭焼きの結果は上書きしない。
- フレーバーの体力: 体調の顔の横の一枚の葉。緑→黄緑→黄土→茶→黒と色が抜け、斑点→欠け→穴→反って崩れる。吸い出しは4回目、調整は3回目から傷み、文字は出さずダメージ音と揺れだけ。
- 疲れ: 吸いすぎ・過熱（76%以上）の煙を吸うと、はじめの体力が削れて疲れる（針が速く、成功帯が狭い）。札は出さず、作業中のはじめが真剣→普通（汗）→沈んだ顔（汗と荒い息）に変わる。レッスンでは起きない。
- SCORE: 作業台の右上。工程の結果が出るたび（炭焼きは炭ごと）に数字が回って＋点が浮かぶ。穴あけ・炭焼き・完成品（配合・蒸らし・吸い出し・熱管理で分ける）・FLAVOR TRIAL を各25%で配分。結果表にも載る。
- その一台がダメになる: 温度計の一番上（焦げ・画面全体の大爆発）、調整で冷え切り、フレーバーの体力切れ。大会ではその場でGAME OVER→「再挑戦しますか？」→大会の頭から。レッスンはスミさんが詰め直してやり直し、前日リハーサルは専用の短い場面。
- GAME OVER画面: 画像は使わずに描く（`remake/js/chapters/gameover.js`）。色の抜けた場面、斜めの帯の大きな GAME OVER、影絵のシーシャ台と理由ごとの煙（焦げた=黒煙と火の粉、冷え切った=細い煙が途切れて止まる、フレーバー=枯れ葉のかけら、順位=静かな煙）、理由の印と「再挑戦しますか？」。
