## 現在の仕様（要点）

- 背景: 冷たい薄青→淡い色づき→適温は虹（心地よい程度の虹色の炎・陽炎）→超えると黄色→赤の炎と黒煙でだんだん火事に。温度に沿って連続的に移る。
- ボウル: 普段は煙を出さない。過熱から自然な灰白色の煙を少し。焦げたら黒煙。
- 温度計: 黒い部分なし。色の目盛りの上を少し暗くし、適温は虹、超えると管の中で炎、上端は「焦げる」の縞（入ると点滅）。熱管理では下端に「冷え切り」の縞。
- 調整（大会のR3・熱管理）: 炭を焼く個数（焼かない／1〜3個）→替えた分だけ少し温度が上がる→吸い出しと同じ針（キープで維持）。炭は燃え進んで温度が動き続ける。最低1回吸って「整え終える」。
- フレーバーの体力（葉4枚）: 吸い出しは4回目、調整は3回目から1枚ずつ減り、ダメージの演出が出る。吸い出しから調整へ引き継ぐ。
- その一台がダメになる: 温度計の一番上（焦げ・画面全体の大爆発）、調整で冷え切り、フレーバーの体力切れ。大会ではその場でGAME OVER→「再挑戦しますか？」→大会の頭から。レッスンはスミさんが詰め直してやり直し、前日リハーサルは専用の短い場面。
- GAME OVER画面: オーナー制作の絵ができたら `assets/backgrounds/bg_game_over.png` に置き `python3 remake/tools/build_manifest.py` を実行すれば、自動で背景に敷く。
