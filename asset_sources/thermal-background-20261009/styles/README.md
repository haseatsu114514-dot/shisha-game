# 温度による背景変化 — 3案の比較（2026-10-09）

TH07〜TH09（適温は気持ちいい陽炎と煙、超えると炎／緑の炎はやめる／炭の角が赤と白にじわじわ熱が入るモチーフ）を受けて、
3案を同じ仕組みで作り、実際の熱管理の画面で並べたもの。画像生成は使わず、すべてコード（`remake/js/craft/thermal.js`）で描いている。

## 全案で共通

- まだぬるい: 薄い色から始まる。
- 適温: 炎は出さない。作業風景（はじめと台）が熱い空気越しのように少しゆらぎ、背景もゆらめく。台の上は白くやわらかい煙。
- 熱が強い→過熱→超高温→灼熱: 適温を超えてから炎が立ち、橙→赤→青→紫と燃え盛る。紫は「焦げる寸前」の警告。
- 温度計の一番上: 爆発して焦げた背景になり「シーシャが焦げてしまった」。大会はGAME OVER。
- ボウル・台そのものは燃やさない（爆発後だけ焦げて黒煙）。

## 3案

| 案 | URL | 低温〜適温の見せ方 |
|---|---|---|
| 炭火（既定・おすすめ） | `?thermal=ember` | 参照動画の斜めの四角を、シーシャの角炭に置き換えた。低温は灰色の炭、温まると縁がばらばらに赤く熾り、適温では角から白く熱が回る。暗い炭火の色に陽炎と白い煙 |
| 虹 | `?thermal=rainbow` | ゲーム的なごほうび感。適温で四角が虹色に巡り、オーロラの帯と瞬きが出る |
| 炎の強さ | `?thermal=steady` | 色は暖色のまま、炎の「様子」で温度を見せる。適温は高さのそろった穏やかな炎、超えると高さがばらばらになり燃え盛る |

ゲームでは、URLの末尾に `?thermal=rainbow` などを付けると案を切り替えられる（付けなければ炭火）。開発用にはブラウザのコンソールで `__remake.dev.thermalStyle("rainbow")` でも切り替わる。
