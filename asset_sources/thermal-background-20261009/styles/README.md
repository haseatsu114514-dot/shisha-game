# 温度による背景変化 — 3案の比較（2026-10-09）

TH07〜TH12 を受けて、低温〜適温の見せ方が違う3案を同じ仕組みで作り、実際の熱管理の画面で撮った。
画像生成は使わず、すべてコード（`remake/js/craft/thermal.js`）で描いている。

## 全案で共通

- まだぬるい: 薄い色から始まる。
- 適温: 炎は出さない。作業風景（はじめと台）が熱い空気越しのように少しゆらぎ、背景もゆらめく。台の上は白くやわらかい煙（TH09）。
- 熱が強い: 黄色い炎が画面の下から立ち始める。
- 過熱: 赤い炎が画面の上の方まで燃え盛る。
- 灼熱・焦げる寸前: 赤と黄色の炎が画面の上を越えるほど高く、速く燃える。青・紫の炎は使わない（TH12）。
- 炎はどれも画面の下から立ち上がる。途中に浮いた炎のかけらは出さない（TH11）。
- 温度計の一番上: ボウルの位置から爆発し、焦げた背景と黒煙になって「シーシャが焦げてしまった」。大会はGAME OVER（TH06）。
- ボウル・台そのものは燃やさない。爆発の後だけ焦げて黒煙が昇る（TH04）。

## 3案

| 案 | URL | 低温〜適温の見せ方 |
|---|---|---|
| 炭火（既定・おすすめ） | `?thermal=ember` | 参照動画の斜めの四角を、シーシャの角炭に置き換えた。低温は灰色の炭、温まると縁がばらばらに赤く熾り、適温では角から白く熱が回る（TH08）。暗い炭火の色に陽炎と白い煙 |
| 虹 | `?thermal=rainbow` | ゲーム的なごほうび感。適温で四角が虹色に巡り、オーロラの帯と瞬きが出る |
| 炎の強さ | `?thermal=steady` | 色は暖色のまま、炎の様子で温度を見せる。適温は高さのそろった穏やかな炎、超えると高さがばらばらになり燃え盛る |

ゲームでは、URLの末尾に `?thermal=rainbow` などを付けると案を切り替えられる（付けなければ炭火）。開発用にはブラウザのコンソールで `__remake.dev.thermalStyle("rainbow")` でも切り替わる。
