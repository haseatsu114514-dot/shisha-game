# 温度による背景変化 — 確認画像（2026-10-09）

TH01・TH02 のブラウザ確認で撮影した一覧。ゲームの素材ではなく、見た目の記録。
背景・炎・煙はすべてコード（`remake/js/craft/thermal.js` のCanvas＋SVG）で描き、画像生成は使っていない。

| ファイル | 内容 |
|---|---|
| `bands-practice.jpg` | 練習のベンチで6段階を並べたもの。まだぬるい（薄い霧）→熱が入っていく（薄い緑）→適温（緑）→熱が強い（橙）→過熱（赤・炎）→灼熱（紫・マゼンタの炎・黒煙） |
| `steam-tournament.jpg` | 大会（SMOKE CROWN CUP）の蒸らし弾幕の上で、まだぬるい／適温／過熱／灼熱を並べたもの。雑念弾・心拍線・温度計・コメント欄が読めることの確認用 |

撮影条件: 1280×720、Playwright（Chromium）。段階ごとの色を並べるため、`setBenchTemperature()` で背景だけを指定温度にしている。
そのため `steam-tournament.jpg` の温度計は実際の（低い）温度のまま。実プレイでは温度計と背景は同じ値で動く（`remake/test/thermal_background.mjs` で一致を確認）。

色の割り当ては2026-10-09のオーナー指定「適温は緑、やばいと赤や紫のやばそうな色、低い時は薄い感じから」に従う。
参照動画の斜めの四角模様・下から立つ炎・黒煙の構成は維持し、色だけを差し替えた。灼熱の炎は、緑＝適温と混同しないよう黄緑からマゼンタへ変更。
