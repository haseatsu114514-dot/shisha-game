全案に「水煙前線 -EN:CODE-」「CHAPTER n」「章名」を入れ、正式な英語副題も現行設定から使用。文字は生成せず、透過PNGの別レイヤーとして組版した。画像内にキャラ名、所属、役割ラベル、メニューは入れない。

文字と位置も章ごとに調整。2章はゴシックの大きな段差とピンクのずれ、斜体の副題。3章は細い明朝の縦書きと広い余白。4章は太めの明朝と墨色。5章は銀色の太い文字とDIN Condensedの機械的な字形。ゲームタイトルは2・3・5章では左下、4章では上部へ置いた。

## 開き方

`index.html` を開くと5章から表示される。章の切り替え、4章一覧、文字の表示切り替え、PNGダウンロードが可能。左右矢印キーでも章を切り替えられる。

`lighting-ch2/index.html` は2章の光4案。A=目元、B=顔半分、C=髪と肩の輪郭、D=はじめ。個別表示・一覧・文字なし切り替えが可能。全4案を実際に開いて確認した。Aは比較の初期表示で、採用決定ではない。

- `images/ch2-title.png` 〜 `images/ch5-title.png`: 1280×720のタイトル画像
- `comparison.png`: 枠外に説明を添えた2×2比較
- `lighting-ch2/`: 光4案のPNG、比較PNG、切り替えHTML、4案で同じ文字レイヤー。直前の明るいタイトル案も `previous/` に保存
- `plates/`: 文字なし1280×720の画像
- `layers/`: 透過文字レイヤー
- `originals/`: 画像生成の原寸出力。初稿・影の案・緑の色案など、修正前の生成原寸も別名で保存
- `prompts/`: 各生成の実際のプロンプト
- `refs/`: 採用済みキャラ画像3枚と制作確認用参照シート
- `generation.json`: 参照元のパス、コミットSHA、Git blob、SHA256、使用画像、生成ID、過去案
- `review/`: 画像確認・ブラウザ確認・再合成確認の記録

## 参照元と生成方法

正本は `origin/main` の `21e920a10a81ed85f561171bc85e77d88e9b554d`。ゲームが使用する `assets/sprites/characters/{hajime,ageha,sumi}/chr_{id}_normal.png` を開いて確認し、実際の画像を内蔵 `image_gen` に渡した。参照コピーは元画像とSHA256が一致する。顔の別案や古い `visual_concepts` は正本にしていない。

ゲームタイトル・章題・英語副題は同コミットの `brand/story_and_structure.md`。ロケーションは物語を踏まえたイメージで、既存の採用背景を再現したものではない。画像生成は内蔵ツールのみ。人物画像の手修正・左右反転・引き伸ばしは行っていない。生成原寸から1280×720へ中央基準で比率を保ってフィットしている。

5章の提供画像は絵柄・光・金属・歯車・寄りの構図の参考として実際に3枚渡した。既存の画面や機械の顔をそのまま転用する指示はしていない。提供画像自体はリポジトリに複製せず、ファイル名とSHA256を `generation.json` に記録した。

## 未解決・採用前に決めること

- **5章**: SHISHA-9000の採用済み肖像は現行ツリーに見当たらない。今回の顔はユーザーの方向性を確かめる仮デザインであり、採用済みキャラを忠実に再現したとは扱わない。最終的な機械の外見は別途決定する。
- **2章**: アゲハ中心の構図試作。竜二・零を追加するかは未確定。肖像の大きさは心理的な圧力を表す画面上の比喩。
- **3章**: 店名や特定の採用店舗内装は示していない。最終画面で場所を特定する場合は、その店の採用背景に合わせる。
- **4章**: 手の構図は受け継ぐ所作のイメージ。具体的なシーシャ作業の動作や機材の説明ではない。
- これらは静止画の画風・文字組版の試作。アニメーション、本編への登録、公開サイトへの反映は今回の範囲外。

## 文字組版を再現する場合

macOSのヒラギノ角ゴシックW8、ヒラギノ明朝ProN（W3/W6）、Times New Roman、Arial Narrow Bold/Italic、DIN Condensed BoldとPillowを使う。フォントファイルは同梱していない。

```sh
python3 build_titles.py
python3 build_lighting.py
python3 build_comparison.py
```

参照画像・生成原寸のハッシュを維持した状態で実行する。文字のみを描画し、原寸画像に触れずにタイトルPNGを再合成する。
