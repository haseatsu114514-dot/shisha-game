## 保存構成

- `images/`: 1280×720の代表画面
- `plates/`: 文字なし画像
- `layers/`: 文字のRGBA画像
- `originals/`, `prompts/`: 初期・照明変更などの生成原寸とプロンプト
- `type-polish/`: 最新の生成文字、新しい3・4章の原寸、変更前の画面、参照と配置のmanifest
- `refs/`: 本編使用中のはじめ・アゲハ・スミさんの参照コピーと参照シート
- `generation.json`, `review/`: 参照元、コミットSHA、Git blob、SHA256、確認結果

旧案は原寸または変更前のPNGとして保存。第1章の選定D・A〜F・文字組版案、採用済み人物素材は上書きしていない。

## 参照と生成

初期参照は `21e920a10a81ed85f561171bc85e77d88e9b554d`、今回の更新参照は `80b0ceca309b54d47518a7664936c2e760f36953`。現在の実装が使う人物画像を開き、内蔵image_genに実際の画像を渡している。文字品質の参考に第1章Dの完成画像を渡した。詳しい参照元・SHA256・プロンプトは `generation.json` と `type-polish/manifest.json`。

ゲームタイトル・章題・英語副題は現行の `brand/story_and_structure.md` を確認。2・5章は絵を再生成せず、文字を別レイヤーで合成。3・4章の絵はユーザーの最新の構図指示で生成し直した。文字の透明な部分で元の絵が画素一致することを確認する。

5章の提供参考画像自体はリポジトリに複製せず、ファイル名とハッシュを記録。今回の機械の顔は、採用済みSHISHA-9000画像を確認できていないため引き続き仮デザイン。4章の師のイメージは画面上の比喩であり、死亡や新しい物語設定の採用ではない。

python3 build_lighting.py
