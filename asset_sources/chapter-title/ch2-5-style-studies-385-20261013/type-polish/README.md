# 生成章題・最新画面

ユーザーが章題の画像生成を許可したため、1章の仕上がりを実際の画像参照にして、章題を透過画像として制作。小さいゲームタイトル・CHAPTER・正式英語副題は別途組版し、読みやすさを保つ。背景と文字は別レイヤー。

| 章 | 今回の画面・文字 |
| --- | --- |
| 2 | ユーザー選定の照明C。生成した「才能の壁」は縦・横の2案。 |
| 3 | 王冠だけを大きく見せる新しい背景。「虚ろな王冠」は生成した濃い青灰色の縦文字。 |
| 4 | はじめを主体に、スミさんを守護霊のように淡く浮かぶ師のイメージへ。夕焼けとターコイズの現代のドバイで、和風の墨・紙・筆文字は使わない。「継承の煙」は生成した現代的な横文字。 |
| 5 | 元の機械の画像に、クローム明朝・白金の筆文字の2案。「機械仕掛けの神」の文字を生成。 |

2章Cの採用は照明・絵の選定。新しい文字の採用はレビュー用の候補。初期表示は5章の白金案、全章比較では2章横文字・5章白金案を表示する。本編への登録・mainへのマージはしない。

## 章ごとの色

1章は白と余白、2章は選定Cのピンクと深い影、3章は銀灰と古びた金、4章は夕焼けとターコイズ、5章は紫とクローム。3・4章の明度と色温度を変え、暗い色が続かない並びにした。2・5章の絵と1章Dは変更していない。

3・4章の色は内蔵image_genで参照付き編集。明るい背景に合わせて、章題も同じ文字素材を画像参照として青灰・深い青緑へ生成編集した。生成原寸・プロンプト・編集前・実際に渡した参照の保存コピーとSHA256は `palette-v2/`。

## 成果物

- `index.html`: 個別切り替え、6案一覧、変更前の画面比較
- `lineup.html`, `lineup.png`: 1章Dを含む、文字入りの現在の5章一覧
- `comparison-2-5.png`: 2・5章の文字4案
- `comparison-all.png`: 2〜5章の最新画面
- `images/`: 1280×720の完成PNG、各章の初期表示
- `layers/`: 生成文字と小文字をまとめたRGBAレイヤー
- `plates/`: 文字なし画面
- `sources/`: 2章C・5章の使用画像をそのまま保存
- `originals/`: 内蔵image_genの原寸、生成文字の元のアルファを保持
- `prompts/`: 各画像生成に渡したプロンプト
- `previous/`: 修正前の画面・文字レイヤー
- `manifest.json`: 出力ID、SHA256、使用元のSHA256、透過情報、配置、初期表示、参照コミット

参照正本は `origin/main` の `80b0ceca309b54d47518a7664936c2e760f36953`。予約status run `38294088521` で同一workerのIssue #385を確認。1章の文字品質参照は `../../ch1-white-walk-385-20261013/selected-D/D-title.png`。2章Cは `../lighting-ch2/plates/C-art.png`、5章は `../plates/ch5-art.png`。SHA256はmanifestに記録。4章の人物は本編使用中の `assets/sprites/characters/{hajime,sumi}/chr_{id}_normal.png` を実際に開き、生成ツールに渡した。

字の余白をクロップし、比率を保って縮小して配置。文字の形や色は手で描き変えていない。2・5章の人物・背景を生成し直していない。生成文字の透明部分では元の絵の画素が一致する。

旧和風案として生成した `ch4-01-ink-craft.png` はユーザーの最新方針に合わないため使用せず、原寸記録としてのみ残す。5章の機械の顔は引き続き仮デザイン。4章のスミさんは継承を表す画面上の比喩であり、死亡や新しい物語設定の採用ではない。
