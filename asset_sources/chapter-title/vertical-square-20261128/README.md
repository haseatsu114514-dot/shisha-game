# 縦画面のタイトルコール用の、文字の無い正方形の章タイトルの絵（VPN28・2026-11-28）

オーナー「今の横長画像をベースに縦画面用のを再生成してみて　タイトルや章情報は上下でやるから画像メインのに」。
縦画面のタイトルコール（VPN27＝上にゲームタイトルのロゴ・真ん中に絵・下に章の情報の3段）の真ん中に置く絵を、各章の横長の章タイトル（`remake/img/ui/chapters/chN-title.webp`・1280×720）を元に作り直した。

- 生成: OpenAI images edit（`/v1/images/edits`）、モデル `gpt-image-2.6-sunburst`、1024×1024、quality high。参照は各章の横長の章タイトルの絵1枚だけ。台本は `gen.py`、送ったプロンプトと結果は `prompts.json`。
- 形を正方形にした理由: 上のロゴ（約100px）と下の章の情報（約160px）を残したまま、縦の画面（390×844）で絵をいちばん大きく出せる形。低い画面でも高さの半分まで縮めて収まる。
- プロンプトの共通の決まり: 文字・題字・数字・ロゴを一切入れない（章名は画面の文字で出す）／同じ人物・画風・色・光・場所／人物を足さない／顔を端で切らない／はじめ（黒い帽子と黒いパーカー）はネックレスなし／シーシャの機材は描かない（漂う煙だけ）。
