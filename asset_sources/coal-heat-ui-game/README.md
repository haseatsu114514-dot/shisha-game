# 採用モックを使った炭焼きゲーム

Issue #503 / worker `codex-coal-mockups-20261013-b0d54e25`。
承認モックはPR #506、mainの`60d44b43525f81657ea22b1e6afd9de19d02ddb0`。
原画・参考資料は`../coal-heat-ui-proposals/`に保存済み。

新たに画像生成でコンロ、炭壺、フラット炭とキューブ炭の未着火/着火差分、はじめの作業風景を作った。
採用画像は`assets/ui/making/heat_*.png`と`hajime_heat_scene.png`。
正確な入力、生成元、8項目の構造計画、寸法、採用/却下の理由は`generation.json`。
却下された薄いフラット炭も`iterations/thin-flat/`へ保存した。高さ調整前は`iterations/thick-flat/`、下げすぎた候補は`iterations/too-low-flat/`へ保存した。

オーナー指定の`exec-59b978f3`をフラット炭の基準にし、「やや高さありすぎ」に合わせて側面を少し低く再生成した。
広い上面・向き・灰の質感を保つ。幅86pxで約80px高から約69px高へ、薄すぎた初版約60pxより厚みを残す。
キューブは新たに高さを増し、真っ直ぐな四角い面と角で形を区別した。
未着火差分もそれぞれの着火画像を直接参照し、輪郭・向き・位置を保つ。
生成画像の画素は独立しているため完全一致ではないが、bbox差はフラット各辺3px、キューブ各辺2px以内。
新しい実行画像は標準`build_manifest.py --making-only`でWebP化し、透明余白のbboxをmanifestへ反映する。

コンロは後部の電源コード、中央と外縁を避けた中間コイル上の接地点、間隔のある三角配置。
炭の方向は全個同じ。炭の番号・下の焼成説明・三つの収納枠を削除した。
回収先は長い持ち手のある単一炭壺を上から見る角丸小窓。
同じ炭素材と入力時点の焼け具合を縮小して引き継ぐ。キューブへの置換はしない。
参考は前版の`hybrid-reference.md`にある実物写真・25mm炭/130mm炭壺。
ゲーム内の炭は操作のため拡大し、炭壺は別視点で縮小。厳密な温度分布/実物寸法の計測ではない。

実装先は`remake/js/craft/heat_view.js`、既存`heat.js`の時刻・能力補正・評価・得点を維持する。
試遊入口は`remake/craft-preview.html?step=heat`、キューブは`&charcoal=cube`。
保存済みゲームを読み書きしない試遊で、本編も同じゲーム部品を使う。

読み込みは現在の工程と観客のみを待ち、次の工程を背景で準備する。
即時のキャッシュ読込は幕を出さず、必要な画像の待機/表示画像decodeが済んでから入力とゲーム時計を開始する。

PC/タッチ・交換1〜4炭、読み込み遅延・キャッシュ、既存工程の検証記録はPRと`docs/qa/coal-heat-ui/`。
