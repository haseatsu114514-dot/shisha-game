# 目視QAと修正記録

全6枚を生成結果と正式立ち絵・背景で比較した。これはオーナー確認用の品質判定で、正式採用の承認ではない。生成AIの同一性や寸法の完全保証ではない。

共通: 繊細な線、段階的な陰影、控えめな発色、描いた背景を確認。人物はレンズへ正面を向ける紹介絵にせず、場面の芝居から構図を作った。6枚に字幕・ロゴ・UI・時刻・発売日の焼き込みはない。

店舗: 01〜03の初版は識別できる窓・棚・扉などに未確認の配置があったため最終セットから除外。正式背景を追加入力し、背景を低コントラストの材質/色面へ絞った。04は公式の緑ソファ・橙クッション・木テーブル周辺。別角度の全体間取りを検証したとの主張はしない。

05の会場通路と06の控え室は、物語に基づく舞台美術の試作であり正式店舗背景の描き直しではない。
