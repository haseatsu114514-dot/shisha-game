# 予告編試作：動画版 / テロップ送り版

同じセル画版6カット・同じ台詞で2つの見せ方を作った。オーナー確認用。本編へは未接続、mainへのマージ禁止。

- [比較プレイヤー](index.html): 動画再生と、自分のペースで送るゲーム風の台詞表示
- [MP4](teaser-37s.mp4): 1280×720、24fps、37秒、H.264、無音。微小な寄り/移動/切替を付けた静止画予告編
- [編集台本](timeline.js): 各カットの長さ、台詞、原作データの参照ID、カメラ移動量
- render.jsは動画書き出しとテロップ版の共通レンダラー。既存remake/のコードへ依存/接続しない

## 編集意図

「勝つほど、遠くなる。」→スミの沈黙→なるとのすれ違い→みんとの笑顔の気遣い→つむぎの水→去るアゲハ→独りのはじめ→作品名。
前半の会話、中盤の表情/手元、後半の背中/俯瞰を繋ぎ、人物の距離を変える。
みんとは一人の横顔の寄り、つむぎは手元を含む二人の行動カットとして似た構図の連続を避けた。

台詞はdata/dialogue/ch2_main.jsonとch2_isolation.jsonの抜粋。イントロの短いコピーと締めの問いは予告編用の仮コピー。本編の台詞・設定は書き換えない。
文字は動画/プレイヤーで重ね、素材PNGへ焼き込まない。発売日や架空の情報は表示しない。
人物の動きは動画生成AIで生成していない。今回は見せ方/読みの間を選ぶため、静止画の小さなカメラ移動と切替まで。声・音楽は未追加。

## テロップ送り

1. 「ゲーム風」を選ぶ
2. 台詞が少しずつ出る。表示中にクリック/Space/Enterすると全文を表示
3. 全文表示後の同じ操作で次のカットへ。戻る/最初からにも対応

PCとスマートフォンでブラウザ表示可能。フォルダごとの保存でローカルHTMLからも動作する。
