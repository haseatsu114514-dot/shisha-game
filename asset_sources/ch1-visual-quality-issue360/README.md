## 自宅の採用仕様

- 新規再描画4枚: 晴れ昼／夜、曇天昼／夜。元の本棚、ベッド、窓、キッチン、机の位置と部屋の広さを保持。人物・シーシャ器具は追加しない。
- 組み込み画像生成で出力。生成原寸は1672×941で、ネイティブFull HDではない。再描画後にLanczosで1920×1080へ軽く正規化した。原寸PNGと全指示を `generated/` と `home-prompts.json` に保存。
- 使用PNGは `assets/backgrounds/`、配信WebPは `remake/img/backgrounds/`。昼夜WebPの合計は272,208 bytes（旧281,142 bytesより3.2%減）。曇天は選択された1枚だけを読み、全差分を追加プリロードしない。
- 曇りと雨は同じ曇天画を共有し、雨の日だけ既存の雨アニメーションを窓外へ重ねる。絵には雨粒を描き込まない。天気抽選、セーブ形式、会話、報酬は変更しない。
- 曇天が未制作の場所は元の画像を使う。大会やタイトルの選択は維持する。
- 下部25%は落ち着いた描画。PCは1920×1080、スマホ横は844×390、縦は390×844で既存回転案内を確認。
- 旧自宅PNG/WebPは `previous/` に保持。復旧時は晴れ昼夜を戻し、曇天2枚のmanifest登録と天気選択を同時に戻す。

生成した絵を原寸で検品し、重複家具・文字・人物・部屋の破綻を確認。天候別のゲーム画面で窓、雨の範囲、文字の読みやすさを確認した。`review/` は表示検査の証跡。

## となりの採用仕様

オーナー指示でトルコランプ約14灯の大小・丸形／扁平形・模様・配色・吊り高さを散らし、通常の暖白色スポット照明4灯を併用。夜も家具と人物の背後が読める明るさ。台は準備／展示状態でホース、ハンドル、ボウル、HMD、炭、煙なし。既存の店の植栽は維持し、参照写真の吊り植物は追加しない。

晴れ昼夜・曇天昼夜4枚、原寸1672×941→1920×1080、WebP q62。晴れ昼夜は旧322,586→新323,134 bytes（+548 bytes）。自宅と合わせた4枚の合計は旧603,728→新595,342 bytes（1.4%減）。曇天は選択画像だけ読み込む。全指示は `tonari-prompts.json`、構成・不採用経緯は `tonari-plan.md`。参照したオーナー写真は参考用途のみで再配布しない。

今後の全店への植物反復を避ける規則、となりの照明、未使用の台のホース省略を `docs/asset_ai_guidance.md` に記録。今回は自宅・となりまで。残りは別の機会にCodex限定で継続する。

## 再現・検証

```sh
python3 remake/tools/build_manifest.py --backgrounds-only bg_home_day.png bg_home_night.png bg_home_overcast_day.png bg_home_overcast_night.png
BASE_URL=http://127.0.0.1:8360/remake/ node remake/test/ch1_visual_quality.mjs
```

背景限定ビルドは指定背景とWebP目録だけ更新し、他チャットの立ち絵アンカー・タイトル・音声を保つ。
自宅・となりの晴れ／曇り／雨×昼夜×PC／スマホ24項目、未制作背景のフォールバック、縦回転案内の計26項目が成功。VN画像待機・スキップ4項目、第1章の敗北→再挑戦→優勝、データロードとJSONも成功。背景限定ビルドが立ち絵・タイトル・音声など他のmanifestフィールドを保つことを確認した。

最初のPR CIは未変更の `steam_slash.mjs:62` で色判定に失敗（ダメージ中のピンクと通常の水色）。同じテストはローカルのPC／スマホで成功。弾幕・テスト条件は変更せず、最終PRのCI成功を確認してからマージする。

## シーシャを含む次の素材

`docs/asset_ai_guidance.md` と `asset_sources/shisha-hardware-reference/` の構造・HMD・ホース・実物寸法・喫煙規則に従う。写真一覧や構造図を生成へ渡さず、選んだモデルの実物写真を添付する。顔は採用立ち絵、画風は採用タイトル絵を基準にする。
提供済みの台はHMD必須。直炭・混成HMD・巨大炭・ホースの誤接続／分岐・機材から出る煙は不採用。制作途中の裸ポストと提供済み状態を区別し、構成と検品結果を画像ごとに記録する。
