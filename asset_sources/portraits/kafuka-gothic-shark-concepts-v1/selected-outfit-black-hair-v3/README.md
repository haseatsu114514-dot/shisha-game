# 最新：選んだ服装＋黒髪・通常／腹話術

PRT60／61／62。オーナーが添付した3案目の服装を基準に、黒×淡い青・アイボリーの配色とフード・ポケット・スカート・靴を保ち、髪を黒＋少量の青メッシュへ変更した。髪の銀白部分は残していない。

添付の服装は保存済み `skater/source.png` と同じ絵であり、白背景を焼き込まない元のRGBAを実参照に使った。通常の修正はその服の色・構成を基準にし、先行する黒髪試案は髪色だけの参照とした。腹話術は完成済みの顔を隠すポーズを基準に、服と髪を最新通常へ揃えた。

本人の可愛い青い瞳・ギザ歯・顔立ち、成人の体格、王冠のコロちゃんは保持。腹話術ではコロちゃんを両手で顔の前へ持ち上げ、本人の目・鼻・口を全部隠す。ぬいぐるみの口が開いて喋っているように見える。

2回の生成元は1024×1536 RGBAで無加工保存。確認用は896×1200 RGBA・共通倍率0.607095046854083、足元下端1174px・横差0.061px未満。生成元と確認用の四辺にalpha>=16なし。描き足し・顔の合成・アルファ閾値処理はない。各フォルダの `generation.json` と `prompt.txt` に実参照の役割・パスとSHA-256、バイト一致・配置を保存。[検証](validation.json)。

人物の黒髪と服装の方向は指定済み。今回の仕上がりは確認用で、ゲームの立ち絵・アイコン・WebP・manifest・台詞・設定は変更していない。[確認用PR #206](https://github.com/haseatsu114514-dot/shisha-game/pull/206)。
