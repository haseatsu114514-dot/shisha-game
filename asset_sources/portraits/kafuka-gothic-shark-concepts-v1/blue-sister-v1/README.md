# サメちゃん：青ベースのストリートシスター

**この版は履歴。最新の黒髪指定と添付の服装選択を反映した [通常／腹話術v3](../selected-outfit-black-hair-v3/README.md) を参照。**

PRT59／60。オーナーは3案目を選び「青ベースのシスターがいい」と指定し、サメのぬいぐるみで顔を隠して喋る腹話術の立ち絵を追加依頼した。

フード・ジャケット・スカートの主色を青へ変更。アイボリーのコイフ風の額縁、大きなポケット・靴紐、サメのヒレと尾、シスターの小さな十字架を残した。本人の顔・髪・体格は選択した案を基準にした。

腹話術は青版通常を実参照にし、コロちゃんを両手で顔の前へ持ち上げた。本人の目・鼻・口は隠し、王冠・青いサメの顔・白い口元・開いたギザ歯の口が喋る役になる。服・脚・全身の表示倍率を共通にした。

2回の生成元は無加工保存。各フォルダの `prompt.txt`・`generation.json` に実参照の役割、パス・SHA-256、生成元とのバイト一致、配置を記録。両方とも1024×1536 RGBA、確認用は共通倍率0.607095046854083・896×1200 RGBA。足元下端1174px、横差0.647px未満。生成元と確認用の四辺にalpha>=16なし。アルファ閾値処理・顔の合成・描き足しは行っていない。[検証記録](validation.json)。

服の方向はオーナーが選択済み。青版の仕上がりと追加ポーズは確認用で、ゲームの5表情・アイコン・設定・台詞・WebP・manifestは変更していない。
