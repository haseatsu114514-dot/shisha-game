## 確認結果と限界

元画像でも画面右の上まぶたが太く、虹彩上部が隠れる。50%付近の表示では細部が詰まって見える。`sad` や `ura_smug` は表情として半目、`wink` は画面右を閉じる意図なので、全表情の目を機械的に開く対象ではない。10表情は `original-all-expressions.png` で確認。

v1は顎の自然な連続性と本人らしさを保つ候補になったが、右目への改善が弱かった。v2では上まぶた中央をわずかに上げ、虹彩とまつ毛の分離を追加指定した。別AIの独立確認でも「v1より縦の開きが少し増えた」「前回の局所合成による肌の歪みは見えない」と評価。ただし元との差は控えめで、縮小時には目立ちにくい。

黒×ミントの衣装・髪型・角と羽・緑の瞳・チョーカー・穏やかな表情は保持。再生成なので元画素と同一ではなく、描線が少し滑らか、髪が少し暖色、頬と顎がわずかにすっきりしている。左目・口・衣装・手にも再描画差がある。「同じ顔で完全解消」とは断定しない。

前回の細い顎マスク合成は使用していない。原画全体を `tools/fit_portrait.py` で均一縮小し、896×1200の比較用キャンバスへ配置しただけ。v1原画の人物高1430px、v2は1436pxから、既存の938pxへ縮小。足元・身長・spriteScaleを変えていない。

## 保存・検証

生成原画、実プロンプト、実参照のパスとSHA-256はこのフォルダと `generation.json` に保存。本人参照は元のみんと通常と顔crop、既存あげは通常は質感用。v2はv1と元みんと通常を参照。

候補PNGと可逆WebPはRGBA一致。`check-browser.cjs` は候補画像をブラウザのrouteだけで差し替え、実ゲームをPC 1280×720／スマホ844×390で比較する。元絵と候補それぞれで通常表情・読込・表示寸法・JSエラーなしを確認。結果は `browser-check.json`。本番ディスク上の素材は復元済みのまま。

次はこの顔・テイストを比較基準にする。少し滑らかになった描き味と右目の改善量を重視し、他表情への一括展開はしない。GitHub接続は既存のForbiddenが未解消で、保存はローカル作業branchのみ。
