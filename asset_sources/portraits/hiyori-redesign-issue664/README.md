# 朝霧ひより・立ち絵再制作候補（#664）

正式立ち絵11表情を最新の人物設定に合わせて再生成し、投擲の瞬間 `axe_throw` と通常衣装の可愛い爆発顔 `office_mukii` を追加した。計13枚の候補。ゲームの正式素材と台本はまだ差し替えていない。

## デザインの基準

- 正本は `data/characters.json` と `brand/character_profiles.md`。ひよりは25歳の有能な総務社員。仕事の疲れは本物で、「儚い女」は本人が意識して演じている。
- 通常衣装は赤みのあるピンクブラウンの高いポニーテール、茶色の瞳、アイボリーのレースブラウス、黒スラックスと黒バッグ。大学時代はミディアムヘアと店員服。
- `office_mukii` は通常衣装のまま、伏し目の演技が崩れ、頬を赤らめて小さく拳を握る「ムキーッ」の顔。
- 斧投げ衣装は普段と明確に違う、くすんだ青のジップジャージ上下、細いピンクのライン、白スニーカー。斧投げ後の笑いと叫びはコミカルなストレス発散。投擲の瞬間は小さな踏み込みと前に伸びる右腕、手から離れる斧を描く。
- 凛、アゲハ、みんとの正式立ち絵を線、塗り、人物サイズの比較に使用した。

## ファイル

- `raw/<face>-source.png`: image_genの原画13枚。ジャージ版の斧4枚は旧版を置き換えた。旧版は前のコミット履歴に残る。
- `generation.json`: 実際の生成指示、参照順、SHA-256、候補状態とゲーム用の縮尺目標。
- `qa/hiyori-13-contact.jpg`: 全13枚の表情一覧。
- `qa/hiyori-cast-scale-v2.jpg`: 主要キャラの現行表示サイズと、1000px高にそろえた新候補の比較。
- `qa/hiyori-vs-game-v2.jpg`: 現行のひよりとジャージ案の比較。

## 縮尺とQA

現行の896×1200立ち絵では、不透明部分の高さはひより1152px、凛1000px、アゲハ973px、みんと938px。ひよりが目立って大きいことを確認した。新候補のゲーム用書き出しは、足元をy=1173に合わせ、人物の高さを**1000px**目標とする。投擲案は斧も含めて枠内に収める。原画の解像度は保持する。

原寸と灰色背景への透過合成で全13枚を確認。斧の形、手足、衣装の連続性、全身が収まることを確認した。画像生成プレビューの暗い色は透明領域に残るRGBで、実表示には現れない。

次はオーナーの顔・表情・衣装・縮尺確認。正式採用時に既存11キーの896×1200透過PNG／WebPと顔アイコンを作り、追加2表情の使用箇所を決めて実画面で検証する。
