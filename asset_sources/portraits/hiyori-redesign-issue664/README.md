# 朝霧ひより・立ち絵再制作候補（#664）

現在の正式立ち絵11表情をすべて新しく生成し、斧を投げる直前の `axe_throw` を1枚追加した。**候補保存段階で、ゲームの採用素材はまだ差し替えていない。**

## デザインの基準

- 正本は `data/characters.json` と `brand/character_profiles.md`。25歳の健康で有能な総務社員。仕事の疲れは本物で、儚げなお姉さんは本人が意識して演じている。
- 現在は赤みのあるピンクブラウンの高いポニーテール、茶色の瞳、白〜アイボリーのレースブラウスと黒スラックス、黒バッグ。大学時代のみミディアムヘアと黒Tシャツ・グレーのエプロン。
- 斧投げは黒キャップ、白Tシャツ、黒カーゴパンツ、白スニーカー。投擲時と直後の叫びでは伏し目の演技が崩れ、目・眉・口・体の動きに素の熱量が出る。
- オーナーの追加指示により、凛・アゲハ・みんと等の正式立ち絵と、線の太さ、顔の描き込み、細かな陰影、人物の画面内サイズを比較した。各表情の同一人物性を保つ。

## ファイル

- `raw/<face>-source.png`: image_genから受け取った原画12枚。元のバイト列のまま保存。
- `generation.json`: 採用候補の実指示・参照順・SHA-256・採用状態。
- `qa/hiyori-12-contact.jpg`: 全12枚を同じ見た目の高さで並べた一覧。
- `qa/hiyori-vs-game.jpg`: 凛・アゲハ・みんとと、現行ひより／新候補を同じゲーム表示枠で比較した画像。

## 目視QAと残件

全12枚を原寸と透過背景で確認。通常衣装の7表情は顔・レース・バッグを統一。学生時代はミディアムヘアと店員服を維持。斧投げは通常・笑い・叫びの差を確認し、追加の投擲姿勢では斧の刃と柄が接続され、片手で柄を握り、全身と斧が画面内に収まることを確認した。透過PNGを灰色へ合成して、背景色や光が表示されないことを確認した。画像生成プレビューで見える暗い色は透明部分に残るRGBで、実表示の背景ではない。

初期の通常衣装候補3枚は絵柄・縮尺の比較で外し、通常衣装v4を選択。初回の学生時代候補は髪が長めだったため、肩までのミディアムヘアで作り直した。初期候補は原画に含めず、この理由を記録する。

次はオーナーによる顔・画風・ギャップの確認。合格後に既存11キーの896×1200透過PNG／可逆WebPと顔アイコンへ登録し、新しい`axe_throw`は台本上の使用箇所を別途確認する。PC/タッチの実画面、読込、セーブを検証する。候補のままなら本編の仕様・演出・保存は変わらない。
