- 全再生成ではなく、**現行絵を土台にした局所編集**（頬・顎の暗線を弱める／ほぼ消す）。同一性・画風の維持を優先。

  - **A案（weaken）**: 暗線を弱める
  - **B案（remove）**: 暗線をほぼ消す
- 候補本体はいずれも現行と同じ 896×1200・RGBA PNG。
