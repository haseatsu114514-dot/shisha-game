# 鉄仮面さん E案の採用原画

- `approved-E.png`: オーナーが選定した第2ラウンド E案の複製。原本は `work/codex-a-tekkamen-design2-1110/presentation/E_immaculate_part_and_brows.png`。
- `smile-source.png`: E案を参照し、口元と目をわずかに緩めた生成原画。
- `graphic-source.png`: E案とはじめの既存グラフィック人物を参照した登場カットイン原画。七三分け・太眉・白い顔を保ち、ネクタイを直しながら上体をひねる。
- `graphic-bg-source.png`: はじめの既存グラフィック背景を参照した背景原画。左側を暗くして人物を見せ、右側に弧と直線を置く。

採用立ち絵は両表情の透過外縁に残る赤い画素を、近傍の不透明な内側の色で置き換え、896×1200へ配置した。微笑は高さ1120px・上端50pxで通常と揃えた。登場人物は1024×1024の透過WebP、背景は1672×941のWebPへ変換した。現行と新画風の立ち絵には同じ清書結果を使用する。
