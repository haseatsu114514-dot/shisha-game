# 腹話術の差分指定と表示比較（Issue #323）

腹話術の全7台詞（分岐・未接続台本を含む）が通常・笑顔・真剣・驚きの差分を指定していたため、採用済みの `ventriloquism` に統一した。本人の顔を王冠のコロちゃんで隠す原画を再利用し、画像・絵柄・衣装・透過は変更していない。最初の地の文も顔の前に持ち上げる描写へ合わせた。

同じ初対面の台詞を本番VNで表示した比較。beforeは修正前mainの台本、afterは修正後の台本を使用。

| 画面 | 修正前 | 修正後 |
|---|---|---|
| PC 1280×720 | [before](before-desktop.png) | [after](after-desktop.png) |
| スマホ横持ち 844×390 | [before](before-mobile.png) | [after](after-mobile.png) |

`remake/test/kafuka_portrait.mjs` は全7台詞の差分・名前欄・画像読込・台詞枠・本人の通常差分への復帰・セーブ不変を両画面で検証する。

黒い点やドット状の欠けは対象キャラ・表情・場面が未特定で、現時点では再現できていない。立ち絵85枚のPNG/WebPを比較し、表示されるRGBとアルファの差はゼロ。VNの立ち絵は `image-rendering: auto` で、話者はフィルターなし。通常差分15人の完全不透明部分に孤立した低アルファ画素は検出されなかった。これらの検査は全ての原画品質を保証するものではないため、未再現の画像を推測で補修せずIssueを開いたまま残す。
