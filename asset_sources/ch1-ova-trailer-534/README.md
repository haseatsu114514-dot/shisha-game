# 第1章「煙がつなぐ街」— 90年代OVA風予告

Issue #534。オーナーの「第1章の内容を見せる90年代OVA風の予告を作る」への制作物。

紬は前回採用された可愛いOVA風の顔・塗りを参照し、正規立ち絵の髪・衣装を維持する。夜の街、スミとの準備、なるの誘い、紬の絵、ライバルの影、大会入口の6枚を新しく生成する。元画像にはタイトル・字幕を焼き込まず、予告の編集で加える。勝敗・みんとの私生活・後の章の秘密は明かさない。

本編への配置を選べる独立した予告プレビュー。既存Cの章末→第2章予告や、別PRの第1章冒頭カットを変更しない。

- `images/`: 生成された原寸PNG。
- `generation/`: 各カットの指示・参照役割・構成メモ・検品記録。
- `index.html`: 音付き録画と原画6枚の一覧。
- `trailer/`: 字幕とオリジナル音楽を重ねる40秒の予告。原画のWebPは切り抜かず16:9へ収める。
- `trailer/chapter-one-ova.mp4`: 実際のブラウザ再生の音付き録画。開始・終了画面を含む約43秒、H.264/AAC、1280×720・30fps。
- `qa/`: PC・スマホ・横画面・動きを抑える設定の表示と操作、音楽時計、実再生順序、録画の音量と無音区間の確認記録。

シーシャ台を描く準備カットは、メーカーの実写を取得して目視し生成に添付する。写真そのものは転載・同梱せず、URLと寸法を記録する。新しい画風はオーナーの指定による。

## 見る・録画する

リポジトリのルートでプレビュー用HTTPサーバーを起動し、次のURLを開く。

```bash
python3 remake/tools/serve_preview.py --port 8123
```

- 一覧: `http://127.0.0.1:8123/asset_sources/ch1-ova-trailer-534/`
- プレイヤー: `http://127.0.0.1:8123/asset_sources/ch1-ova-trailer-534/trailer/`
- 映像だけの表示: プレイヤーに `?cinema=1` を付ける。

再生はクリックで開始する。停止・音の切替・移動・見直しに対応し、非表示タブでは停止する。動きを抑える設定では寄り・引きを止める。ブラウザのセーブ・報酬・既読は読み書きしない。音楽の時計で映像を進めて字幕と音楽を合わせ、音声が利用できない環境では映像の時計で再生する。

`qa/record.mjs` は本体の録画ツールから、この独立プレイヤー向けに分けたもの。Playwright・Chromium・ffmpegを用意し、HTTPサーバー起動後に次で再録画できる。CDPの実際の描画タイムスタンプと、同じブラウザのWeb Audio出力を録音する。原画から別の動画を合成したものではない。

```bash
CHROME_EXECUTABLE_PATH=/usr/bin/chromium \
OUTPUT_VIDEO=/tmp/chapter-one-ova.mp4 \
CAPTURE_DIR=/tmp/ch1-ova-capture \
node asset_sources/ch1-ova-trailer-534/qa/record.mjs
```

## 確認

- 6枚の顔・髪・衣装・手・元画像の文字なしを目視確認。スミの準備台はベース→ステム→広い灰皿→小さな金属ポストで連続し、ボウル・HMD・炭・ホースをまだ付けていない。みんとの初稿の不要な植物は生成ツールで修正し、初稿も保存した。
- PC 1280×720、スマホ390×844、横844×390、動きを抑える設定で表示と操作を確認。音なし・一時停止・移動・終端・再生し直しが成功し、localStorageは変化しない。
- 実録画は6画像・全10カットを順に再生。字幕や画面のはみ出し・コンソールエラーなし。音楽を捕捉し、最終の無音を測定。画面と音楽の終端はともに40秒。
- `node --check` と `git diff --check` 成功。変更はこの素材フォルダだけなので、既存のRemake CIの対象パスには入らない。本編の全編回帰テストは実施していない。
