# art不足の装備の照合・HMD3点の原画候補（#2741）

Issueの「data.artなし18件」を現行データで照合し、単純な欠落判定を避けました。現在のdata.artなしは20件で、既存の商品絵・ボウル絵、自室台、廃止品が混ざっています。20件のID別判定はart-field-audit.json。今回新規に作ったのは、店の商品カードが文字で代用されている3種です。

- tanukish_lid: 上が開いた穴あき筒と黒い取手、内側の短い管。
- winkwink_hagal: 同じモデルで高さを保って口径を広げた大径版。
- amaburst_hms: 薄い底皿＋低いドーム蓋、上に3つの開口、上下の独立した橙の取手。筒型と混ぜていません。

採用済みロートスの商品絵を画風・金属の塗り・光の参照に使用し、日本の店/通販の実写でモデルの構造と装着時の縮尺を確認。写真はsiryouから取得して実際に開き、生成ツールへ渡しました。**写真bytesはゲームのrepoへ入れていません。** 参照パスとSHA、生成前8行、§4.2を全文入れたプロンプトは同梱。

原画は無加工の生成出力、candidates/は512角の比例縮小のみ。comparison.jpgで既存ロートスと原寸の金属・形を比較。3点とも全体入り、穴と取手の構造、文字・ロゴ・炭・ボウル・台・ホースなし、デコード・寸法・RGBA・四隅透過・SHAを確認。薄いalpha画素が残るため、採用前に境界確認が必要です。採用済み・production-readyとは扱いません。
