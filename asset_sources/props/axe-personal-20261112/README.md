## 表示仕様・検品残件

- 同一キャンバスを同じCSS寸法でcontain表示し、個別tight cropで中心位置をずらさない。準備/比較表示の候補サイズは160×240 CSS px（高密度画面にも原本解像度は足りる）。実際の前景寸法はスマホ試遊後に決定。
- 飛行は既存3D meshを使い、この側面画像の画面内回転で代用しない。飛行時の柄/グリップ配色連動は未実装。
- alpha0領域は各約123万pxあり、実際に透明。透明画素のRGB残存色を、不透明な背景や広い影と取り違えない。
- alpha1〜8の微小残渣が各約1.3〜1.5万px。明暗両背景での輪郭確認・清掃と配信用縮小書出しは未了。
- 上約80px、下約53pxの余白。生成時の内部目標10%には未達だが、10%はユーザーの必須指定ではない。原画同士の位置は揃っており、これだけで画像生成失敗とは扱わない。
- 写実的な木目・光沢が残るため、本編画風/実スマホの小表示で最終確認する。
- 各1回の影除去/余白調整編集も試したが、外形位置が不統一になったため修正版は不採用。配布は初回3枚のみ。既知拒否のcut-mark生成はしていない。
