# つむぎ：タイトルアート候補生成レポート

## 生成条件

- 使用ツール：組み込み `image_gen`。参照画像を入力した新規場面生成。
- 参照：`sprite_normal.webp`（容姿の基準）、`titleart_ref.webp`（顔・髪・衣装意匠の補助）。既存の構図は指定していない。
- プロンプト：`prompts.md` の共通スタイルおよび番号1〜5の各場面全文を使用。各番号は同番号の `cand_N.png` に対応。
- 追加指定：参照と同じ顎丈の暗褐色〜黒のボブ、まっすぐな前髪、暖色の髪のハイライト、色白の肌、赤茶〜琥珀色の瞳、繊細な顔立ち、小さな黒い耳飾りを維持。衣装は場面指定に沿い、参照のくすんだ紫と小花刺繍の特徴を反映。参照のタブレット・シーシャ・座り姿・背景・ピクセル調の転用を避けるよう指定。
- 全候補に縦2:3、人物1人、文字・ロゴ・透かしなし、健全な服装、正しい顔・手指を指定。
- 自己評価：5＝高い再現度、1＝低い再現度。目視評価であり、完全一致を保証するものではない。
