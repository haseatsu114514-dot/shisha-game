# みんと タイトルアート生成レポート

生成日: 2026-10-28

## 共通

- 使用ツール: built-in image_gen（CLI・外部APIスクリプトは使用していない）。
- 生成方法: 参照画像付き新規生成。既存画像の構図を編集・流用せず、各場面を新しく生成した。
- 参照: `sprite_normal.webp` を容姿の基準、`titleart_ref.webp` を顔・髪・瞳・衣装細部の補助として、すべての生成に両方を入力。
- プロンプト: `prompts.md` の各番号の英語プロンプト全文を使用し、下記の補足を前置した。元のプロンプトと参照画像は変更していない。
- 全候補: 1024×1536 px、縦横比2:3、PNG。生成時から指定サイズのため、リサイズ・切り抜き・形式変換なし。
- 評価基準: 5＝非常によく一致、4＝概ね一致し軽微な差あり、3＝一部に差あり、2＝大きな差あり、1＝不一致。評価は生成後の目視による。

各候補の本文は `prompts.md` 内の対応する番号の ```text ブロック全文。その前に次の補足を付けた（用語の use case は illustration-story）。
