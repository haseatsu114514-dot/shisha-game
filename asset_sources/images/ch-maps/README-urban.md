# マップ候補「都会バリエーション」（第2〜5章・各4枚）

オーナー指示（2026-10-29）による追加候補です。現行のマップ候補は植物・緑が多すぎるため、第2章以降について **緑を減らした都会的なバリエーション** を作りました。

- これは**候補プールの拡充**です。オーナー選定済みのマップ（第3章=候補1／第4章=候補10／第5章=候補7、組み込み済み）は置き換えません。今後の選別プール（過去の決定済みアートも含める方針）に加わります。
- 制作: Codex A 画像生成（2026-10-29）。原寸 PNG 1672×941／組込形式版 WebP 1280×720（quality 85）。
- 画風: 第1・2章マップ基準の斜め見下ろしの街イラスト。ピン・ラベル・読める文字は焼き込んでいません。
- 都会方向の定義: ビル・道路と交差点・コンクリートの街区・駅と高架鉄道・アーケード商店街・ネオンや看板の色味が主体。緑は街路樹・小さな広場程度のアクセントのみ。
- 検品: 16枚すべて目視確認済み。建物の崩壊・融解などの構造破綻なし。
