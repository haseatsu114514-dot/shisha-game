# 第1章：大須・栄の昼夜マップ清書案

**2026-10-08採用**: オーナー「新立ち絵や背景は一旦採用」により、`game-ready` の昼夜PNGを本編背景へ反映。スポット座標は維持。[採用・旧版保存の記録](../../adoptions/ch1-art-20261008/README.md)。以下は制作時点の記録。

既存のマップを構図の参照として、ゲームらしい見下ろしの街を保ちながら建物・道路・屋根の境界を描き直しました。大須観音・招き猫・MIRAI TOWER・オアシス21を含み、ランドマークを見分けやすくしています。現実の地図の正確な距離ではなく、既存ゲームの大須・栄をまとめた構成を継承しています。

昼は現在の昼マップを参照。夜は新しい昼の原画を最優先にし、元の夜マップは時間帯と光の参照にしました。原画は各1672×941 RGBで無加工保存。全フレームを1280×720へ縮小し、切り抜き・描き足し・シャープ処理はしていません。可逆WebPはPNGと全RGB画素が一致します。

既存のスポット座標を[pin-layout.json](pin-layout.json)へ保存。実際の画面で、昼夜とも新旧マップの全ピン座標が一致し、行き先選択パネルが画面内に収まることを確認。背景内にUIピンや文字を焼き込んでいません。街並みは生成で描き直しているため、元画像と建物の全画素が同一という意味ではありません。

ゲームの背景ファイル・ピン配置・manifestは変更していません。候補の確認用素材です。各generation.jsonにプロンプト・実参照・ハッシュを記録しています。
