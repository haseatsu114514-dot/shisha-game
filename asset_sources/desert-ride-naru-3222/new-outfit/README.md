# なる・新衣装のサンドボード原画候補（#3306）

2026-11-11、Codex 内蔵 image_gen で1回1ポーズずつ制作。採用前の原画候補です。

新版立ち絵を服装・人物、採用済み同ポーズの旧衣装原画を構図、主人公の同ポーズを画風の参照に使用しました。通常滑走の新衣装版を後続5枚の衣装固定にも使用しました。依頼文全文、参照パス・SHA-256、修正プロンプトと回数は `generation.json`、寸法・透過境界・SHA-256は `inspection.json`。最終候補6枚はこのフォルダ直下、生成履歴8枚は `history/` です。すべて生成出力の無加工コピーです。

## 検品と残件

- 6ポーズとも銀灰の髪・日焼け肌、焦げ茶とクリームのジャケット、白い袖線、茶のリブ編み、灰色のカーゴとクリームのフラップ、茶とクリームの靴、クリームの板。旧衣装の黒いカーゴ・白い靴・腰のチェーンはありません。
- 通常・左右旋回・空中で膝を曲げる・着地の深いしゃがみ・転倒を同ポーズの見本と目視比較。転倒は両足と板が離れています。人物と板の全体が入り、背景・砂・煙・文字・機材はありません。
- 全点 RGBA PNG、四隅 alpha=0。不透明な灰色背景に重ねた原寸表示で、輪郭の目立つ色にじみ・不自然なテカリ・小物の破綻は見当たりません。背面のため顔の表情は比較対象外です。
- **検品未通過: ごく薄い孤立 alpha 画素が残っています。** 余白を大きく取り直した版でも、alpha>0 の厳密な境界では全点が四辺5%以上の完全透過を満たしません。主要な人物・板は十分内側にありますが、薄いゴミがないという要件を満たしたとは扱いません。色付きの透過RGBは合成時に表示されませんが、非0 alpha のゴミとは別に扱っています。
- **採用前に透過境界の処理または再生成が必要です。** 本納品では無加工保存の指定を守り、alphaの閾値処理・切り抜き・縮小をしていません。原画の画面内サイズは余白修正で小さくなっています。ポーズと板の遠近は目視比較で、ピクセル単位の一致やゲーム内での位置合わせは未検証です。

## 後工程

採用と透過境界の解決後、Issue #3306 の手順で旧版を classic-outfit/ へ退避し、新版原画を正規位置へ置き、既存 build.py で縮小・板の中心合わせ・WebP生成を行ってください。このPRは原画候補のみで、ゲーム用WebP・desert-ride-art.js・テスト・採用済み画像は変更していません。

API経路で既存mainのtreeへ追加しています。ローカルcheckout/root/hooks検査は対象外。画像デコード・寸法・alpha・ハッシュと、差分が新規原画フォルダだけであることを検証します。ゲーム実装の変更がないためゲームのテストは対象外です。
