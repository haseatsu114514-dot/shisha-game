# 冒頭のカット割り（#531）

既存の暖かいtonariと本文表示を保ち、出来事が画面にも現れるようにする。新しい常連の手元1枚と、採用済みの作業素材・店内を組み合わせる。

| 台本のきっかけ | カット | 使用素材 |
| --- | --- | --- |
| 夕方のtonari | 店内の引き | 現行の時間帯別店内＋既存の台配置 |
| 吊りランプと薄い煙 | 照明に少し寄る | 同じ店内＋既存の薄く重ねた煙 |
| 炭をつかむ | はじめの手とトング | `hajime_craft_heat`＋`coal_just`＋`bench_base` |
| ボウルを支え、葉をほぐす | スプーンとボウル | `hajime_craft_pack`＋`bench_base` |
| いつもの常連 | スーツの袖と手元 | 新規 `bg_tonari_customer_hands` |
| ホースの持ち手を置く | 同じ手元へ寄る | 上記原画の再フレーミング |
| 席を立ち、ひと言 | 店内へ戻り、画面端を影が抜ける | 同じ店内。扉は画面外のまま |
| ドアの音、残り香 | 空いた席へ寄る | 同じ店内＋既存ドアベルSE |
| スミの最初の発話 | 通常の店内へ戻す | 以降は従来の立ち絵・会話 |

カットの指定は正本台本の `shot`。本文の正規表現や行番号には依存しない。約0.3〜0.65秒の切り替えを台詞と同時に始め、固定の鑑賞待ちは挟まない。SKIP・動きを減らす設定では移動とフェードを止め、絵は切り替える。本文枠・フォント・文字サイズ・自動改行は変更しない。

## 素材と検品

- [実際の生成指示・参照元](generation.md)
- [生成原画](../../assets/backgrounds/bg_tonari_customer_hands.png)／[表示用WebP](../../remake/img/backgrounds/bg_tonari_customer_hands.webp)。原画は加工せず保存。既存の `build_manifest.py --backgrounds-only bg_tonari_customer_hands.png` で表示用画像と目録を生成。
- 常連は顔を見せない成人モブ。はじめの顔・衣装を流用していない。暖かな左窓の光、木の卓、緑のソファを現行店内に合わせた。
- 吸い口→硬いハンドル→しなるホース→画面端まで一本で追跡。ハンドルの先端と根元を分け、淡青の短いチップは1個。枝分かれ・空中で途切れた端・ホースからの煙はない。本体は構図外のため描かない。
- 炭はトングの両顎の間に重ね、手で直接触れない。ボウルとスプーンは採用済み原画のまま。本文もこの動作に合わせる。
- 固定背景の天井にファンを追加しない。同じ不一致のあった `ch1_sumi`・`ch1_bonds`・バイト本文も、照明の中でほどける煙へ整えた。
