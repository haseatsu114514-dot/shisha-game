# 冒頭・常連の手元カット

- 人物: 顔を映さない成人の常連サラリーマン（salaryman）。正規立ち絵がないモブ。はじめに流用しない。
- 場面: 一服を終え、卓上にホースの硬いハンドルを置く。
- 台の型: 画面外。新しい台の形を描かない。
- HMD: 画面外。
- 炭: 画面外。
- ホース: 画面外の台 → 下辺に続く黒い柔らかいホース1本 → 卓上の黒い硬質ハンドル。端が途切れるのは画面端のみ。
- 吸い口: ハンドル先端の短い淡い青色の使い捨てチップ1個。
- 構図: 胸より下、片手と卓上に寄る。木の卓、暗緑色のソファ、左窓から夕方の光。手・ハンドルは上側の中央、下3割は後付け本文枠に隠れてもよい余白。
