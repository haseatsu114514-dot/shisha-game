# 場面のモーショングラフィックス v3：もう1パターンずつ・天気（2026-10-10・CI109〜CI116）

オーナー「こういうモーショングラフィックスを本気でもう１パターンずつ作ってみて」「占いのはキャラの顔出てくるのは違和感　タロットとかを出すのはいいけど」「チェキはお絵描きしてないのが出てきて、かわいて色がついてきて、その後マーカーでお絵描きアニメーションが入って完成とかがいい」「贈り物のハガルはもう少し見た目がちゃんと生成されてるハガルがいい」「サメちゃんのはシンプルに牙ががぶりみたいなトランジションがいいかも　逆に開くのとか」「スケッチはいい感じ　ペンだけダサい」「DAY4とかのやつは雨と太陽と曇りとか天気わかるようにしてもいいかも　３パターン」。

各場面に a／b の2パターン、配色は紫1色（mono・紫）と場面ごとの色（free・色）。動画は前半が実際の速さ、後半が同じ場面の0.5倍速。音は入っていない。960px幅に縮めて保存。オーナー確認後（CI117〜CI119）、緑が基調だった配色（バイト・占い b・贈り物 a・チェキ b など）を緑以外に替え、扉 b を抽象的な形だけに、サメちゃん b の顔を外して撮り直した。扉 a・バイト a は前回（[v2](../scene-motions-v2-20261010/README.md)）と同じ動き。

就寝を挟まない朝のDAYカードにも、小見出しの後ろに天気（晴れ・くもり・雨）のアイコンと文字を出す。くもりは見た目だけで、背景・会話・給料・制作は変わらない（`daily/weather.js` の `weatherOf()`）。

## 試し方

URL に `?movar=b`（別パターン）や `?mopal=free`（場面ごとの色）を付ける。ブラウザのコンソールでは `__remake.dev.motionVariant("b")`・`__remake.dev.motionPalette("free")` で切り替え、`__remake.dev.motion("cheki")`（`tarot`・`gift`・`shift`・`shark`・`sketch`・`dawn-sun`・`dawn-cloud`・`dawn-rain`・`dawn-sick`）で本来の背景・会話つきで再生する。扉は `?move=door`。今のセーブを上書きするので、試すときはセーブしてから。

## 実装

- 場面ごとのファイル: `remake/js/motions/<場面>.js`（`a` と `b` を書き出す）と `remake/css/motions/<場面>.css`。窓口は `core/scene-motions.js`、扉は `core/transition-moves.js` から使うときに読み込む（一つの場面の不具合がほかを止めない）
- 夜明けの天気: `motions/dawn-weather.js`。朝のDAYカードは `ui.dayCard(..., { weather })`
- 新しく画面に出る文字: タロットの「運命の輪　正位置」「星　正位置」、バイト b の「tonari ・ THANK YOU FOR TODAY」「おつかれさま」、サメちゃん a の「がぶっ！」
