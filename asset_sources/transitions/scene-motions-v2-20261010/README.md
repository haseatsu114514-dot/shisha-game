# 場面のモーショングラフィックス v2：紫1色と場面ごとの色（2026-10-10・CI108）

オーナー「紫×1色みたいなシンプルかつテーマカラーあるようなやつと関係ないバージョンで作ってみて欲しい　それぞれ」「オープンクローズは時計は出さなくていい　裏表がくるっと回るモーショングラフィックスがいい」「チェキは落書きされてるのが現像されるのちょっとおかしい」「扉はなんか洋風なのでシンプルなのに」「もっとモーショングラフィックス感欲しい　おしゃれなアフターエフェクツで作ったやつみたいな」。

同じ7つの動きを2つの配色で録画した。各動画は前半が実際の速さ、後半が同じ場面の0.5倍速。音は入っていない。

| フォルダ | 配色 |
|---|---|
| [mono/](mono/) | 紫1色。濃淡だけで描く（既定） |
| [free/](free/) | 場面ごとの色（扉＝紺とサーモン、贈り物＝贈り主の色、バイト＝緑と赤、サメちゃん＝水色 など） |

| 動画 | 変更点 |
|---|---|
| 0_door_mg | アーチの洋風の扉をやめ、長方形の扉1枚に。床の線と枠が線で描かれ、扉が下から立ち上がって開き、放射線と輪とともに戸口が画面いっぱいに広がる |
| 1_cheki | 現像されるのは落書きのない写真だけ。白い余白の落書きは、写真が出来てからペン先が走って描かれる |
| 2_tarot | 3枚の札と円の目盛り。真ん中の札がくるっと裏返る（※次の版で顔を出さない絵柄に変更） |
| 3_gift | 放射の光、線のはじけ、紙吹雪 |
| 4_shift_close | 時計を撤去。吊り札が落ちて揺れ、OPEN→CLOSED に裏表がくるっと回る |
| 5_shark | 波の3層と斜めの光、サメの横切り |
| 6_sketch | 方眼紙の線画、鉛筆、円で色の店へ |

## 切り替え

`?mopal=free`（または `__remake.dev.motionPalette("free")`）で場面ごとの色、`?mopal=mono` で紫1色。動きの試し方は `__remake.dev.motion("cheki")` など（前の版の [README](../scene-motions-20261010/README.md) 参照）。扉は `?move=door`。

部品は `remake/js/core/mg-kit.js`（緩急・放射線・輪・紙吹雪・きらめき・1文字ずつ出る文字・配色）。
