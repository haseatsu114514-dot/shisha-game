# 場面ごとのトランジション提案（2026-10-09）

オーナー「このゲームにモーショングラフィックスのトランジションを所々つけていきたい　まずはこういうシーンでこういうのはどうかって提案が欲しい」への提案。CI51〜57で比べた見た目（紫と淡いラベンダー、少量のピンク、大きな面と曲線）を引き継ぎ、**場面の意味ごとに型を使い分ける**。今回は提案と動くモックまでで、本編のトランジションは変更していない。

[動くモック](index.html)は、リポジトリのルートで `python3 remake/tools/serve_preview.py --port 8123` を起動し、`http://127.0.0.1:8123/asset_sources/transitions/scene-plan-20261009/` を開く。背景は `remake/img/backgrounds/` を直接読む。「ゆっくり ×3」で形を確認できる。同じ内容をオーナー用の非公開ページにも置いた（https://claude.ai/artifact/DJUhcJLXqPE1366P6i4suV ）。

## いまの遷移

- 背景が変わるたびに `remake/js/core/transitions.js` の幕が出る。斜め・煙・円の3種を順番に使い、中央に金の「水煙前線」。場面の意味とは関係なく決まる
- ほかに `core/ui.js` の煙ワイプ（タイトル・会場入り・再挑戦）、暗転（就寝・約束）、DAYカード、ROUNDの横帯、章タイトル

## 7つの型

| 型 | 動き | 意味 |
|---|---|---|
| 一筆 | S字の紫の帯が右下から左上へ抜ける（v5上段） | 標準の背景切り替え |
| 波 | 丸い波が横へ流れる（v5中段） | 時間が過ぎる |
| 開口 | 葉の形の窓が閉じて開く（v5下段） | 人に会う・一点に寄る |
| 交差 | 2本のリボンが逆の斜めから交わる（v4下段） | 大会・勝負 |
| 泡 | ボトルの泡が満ちて弾ける | 夢・回想 |
| 走査 | 横線のノイズとずれ | 正体不明・データ |
| 輪 | 煙の輪が中心から抜ける | 達成・勝利 |

## 作るときの約束

- 型は `core/transitions.js` にまとめ、場面の側から型を指定する（master_spec #20 の `transition: "smoke_wipe"` 方式）。指定がなければ一筆
- 長さの上限は、よく見る場面0.5秒前後、日の区切り1.5〜2秒、物語の要所2.5秒
- 覆っているあいだはクリックとEnterを受け付けない。SKIP中は短くする。動きを減らす設定ではフェードだけ
- 能力アップの通知は幕の前に流し切る（F12の再発防止）
- 画像を使わずSVG・CSSの図形で描く

## おすすめの進め方

1. マップ → 場所（開口）
2. 就寝 → 翌朝（波＋めくり）
3. 会場入り・ROUND（交差）

master_spec #20 の「まず主要遷移3箇所だけ作って効果を確認 → 全体展開」と同じ順。気に入った型を他の場面へ広げる。
