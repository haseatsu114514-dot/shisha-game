# 抽象的な煙のポップなトランジション

追加指定で[紫系の3パターン](../concepts-v4-purple-smoke-20261008/README.md)を制作。最新の色指定は紫系。この水色・コーラル案は比較履歴として保持する。

最新指定「煙をモチーフにしたポップなトランジションとかも作りたい　リアルな煙というよりはアートな感じで抽象」。[生成モックアップ](source.png)は2行×3コマで、上段左→右、下段左→右の6段階。

水色・コーラル・クリームの大きな渦に、紫の輪郭と網点を組み合わせた抽象的な煙。煙の物理的な質感ではなく、丸い形・色面・渦の連なりで「膨らむ・流れる・ほどける」を表す。P4/P5風の大胆なグラフィック方向と、黒／金に固定しない指定を保持。

1. 店内に煙の形が入り始める。
2. 渦が大きく膨らむ。
3. 形が重なり、場面をほぼ覆う。
4. 下段左で完全に覆い、背景を替えられる状態になる。
5. 色面がほどけ、夜の街が見えてくる。
6. 端へ抜けて、次の場面へ落ち着く。

[生成指示](prompt.txt)と[実参照・SHA-256・保存記録](generation.json)。1672×941の生成原画はバイト一致で保存し、元の生成ファイルも保持。参照画像は店内と夜の街という切替前後の場面用。配色を制約する参照にはしていない。文字・人物・UI・ロゴは含めない。

静止した比較モックアップで、実際のアニメーションや本番レイヤーではない。採用する場合は、16:9で扱う独立した渦・面・マスクと動きへ展開する。今回は本編トランジションを変更しない。
