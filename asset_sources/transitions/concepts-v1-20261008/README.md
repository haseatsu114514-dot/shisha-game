# 画面トランジション：生成モックアップ3案

オーナー「トランジションの作り直しはモックアップとして画像生成でイメージ見せて欲しい」。[原画](source.png)は3案×4コマ。各行を左から右へ読むと、店内を覆う→完全に隠す→次の夜マップを出す流れ。動きの方向を確認する静止モックアップで、実際のアニメーションではない。

| 行 | 案 | 意図 |
|---|---|---|
| 上 | 煙の流れ | 柔らかい白い煙が左下から覆い、右上へ抜ける。穏やかな場面変更向け |
| 中 | 黒と金の斜め帯 | 墨色の面と真鍮の縁が走る。速く力強い場面変更向け |
| 下 | 炭の光と煙の輪 | 炭色の光が煙を囲み、中央を覆ってから外へ開く。印象を強く残す場面変更向け |

普段の空気感には上段を推奨。下段は生成結果の発光がかなり強く、採用する場合は琥珀色の弱い光へ抑える余地がある。

実参照は現行の `assets/backgrounds/bg_eden_shop.png` と採用夜マップ。人物やUIは描かず、黒・濃紫・琥珀・煙のゲームカラーへ合わせた。[生成指示](prompt.txt)と[実参照・SHA-256・保存記録](generation.json)。1672×941の生成原画をバイト一致で保存、元の生成ファイルも保持。

3×4の比較ボードであり、各コマの比率は本番16:9と異なる。採用後は1280×720用の独立した煙・帯・マスクと、実際の動き・暗転時間へ展開する。比較ボードをそのままゲーム画面に被せない。今回は実装・採用を行わず、既存のトランジションコードと表示は維持。
