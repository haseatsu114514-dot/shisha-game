# マップ→場所の移動トランジション：6パターン（2026-10-10）

オーナー「タップしたとこから円が広がるやつもいいんだけどなんかシンプルすぎるから歩いて向かうシルエットみたいなトランジションもかっこいいかも　それとか扉を開けるとか　これは何パターンか頼む」（CI103）。

実際のゲームで DAY3 昼に大須マップの tonari を押し、ヘッドレスのChromiumで録画した。各動画は前半が実際の速さ、後半が同じ場面の0.5倍速。音は入っていない。

| 動画 | 型 | 動き | 長さ（ゲーム内の実測） |
|---|---|---|---|
| [1_pin.mp4](1_pin.mp4) | pin（現行） | 押したピンから円が広がり、中央の葉の形の窓が開く | 約0.9秒 |
| [2_steps.mp4](2_steps.mp4) | steps 足あと | 画面の手前から押したピンまで足あとが続き、ピンから円が広がって開く | 約1.5秒 |
| [3_walk.mp4](3_walk.mp4) | walk 歩く | キャップをかぶった人影が夜の街を歩く。遠くのビルと街灯が流れ、左上に行き先。歩く背中の向こうに場所が開く | 約1.8秒 |
| [4_door.mp4](4_door.mp4) | door 扉 | 両開きの扉が閉まり、行き先の札。扉の隙間から光がこぼれ、ドアベルの音で開いて店の中へ一歩入る | 約1.8秒 |
| [5_noren.mp4](5_noren.mp4) | noren 暖簾 | 地図の看板と同じ一文字（tonari は「店」）を染めた暖簾が下り、手でよけるように左右へ割れる | 約1.7秒 |
| [6_walk_to_door.mp4](6_walk_to_door.mp4) | walkdoor 歩いて扉へ | 人影が扉まで歩き、ドアベルとともに開いた光の中へ入る。光が画面に広がって場所が出る | 約2.8秒 |

長さには、行き先の絵の読み込み待ちを含む。マップの移動は1章で約20〜26回あるため、長い型ほど繰り返しで重く感じやすい。

## 試し方

- 既定は今までどおり pin。本編では選んだ型だけが変わる
- URLの末尾に `?move=walk` のように付ける（`pin`・`steps`・`walk`・`door`・`noren`・`walkdoor`）
- またはブラウザのコンソールで `__remake.dev.moveStyle("door")`。端末に保存され、次の移動から変わる

## 実装

- `remake/js/core/transition-moves.js`: 6つの型。画像を使わずSVGとCSSの図形で描く。人影は手足の角度を毎フレーム計算して歩かせる
- `remake/js/core/transition-kit.js`: 共通部品（色・SVG・葉の窓・人影・入力の抑止）
- マップで行き先を決めると、押したピンの位置・行き先の名前・エリア・看板の一文字を次の背景切り替えへ渡す（`daily/map.js` の `cueMove`）
- 動きを減らす設定とSKIP中は、従来の短い幕になる

## 確認

- 6つの型をゲーム内で再生し、ブラウザエラー0
- 夜に家へ帰る→夜明けの幕→翌朝（DAYカードの重複なし）、大会当日→元の煙ワイプ→ROUND 1 の元の横帯を確認。`remake/test/illness.mjs` PASS

## 場所の種類での使い分け（案）

店（tonari・PEPPERMINT・EDEN・KEMURIKUSA・カフェ・C.STATION）は扉、屋外（観音堂・路上占い）は歩く、のように分けられる。扉は店ごとに見た目を変えられる（tonari は木の扉とドアベル、PEPPERMINT はピンクの扉にハートの小窓、EDEN は林檎の意匠など）。

## ほかに挿入できそうな場面（CI105・アイデア）

| 場面 | 動き |
|---|---|
| みんとのチェキ（PEPPERMINT） | ファインダーの四隅の枠が寄り、シャッターの羽根が閉じてフラッシュ。画面の下からフィルムが出てきて、白っぽいフィルムがじわっと現像されて写真が浮かぶ。追加チェキ3枚（ハート・頬・手振り）にも使える。落書きは絵に描き込まれているため、文字が書かれていく動きまで付けるなら落書きなしの版が要る |
| 雨の日の移動 | 傘が開いて画面を覆い、閉じると到着。雨の日だけの移動の型 |
| つむぎのスケッチ（DAY12夜） | 鉛筆の線が走って場面が線画で描かれ、色が乗って次の場面になる |
| 凛の試作品テスト（Dr.fookah 2階） | 「SAMPLE」のラベルとバーコードが押され、検査票が差し込まれて会話へ |
| 路上占い（タロット） | カードがくるっと裏返ると結果 |
| 締めくくりの贈り物（専用ハガル） | リボンがほどけて箱が開き、光の中からハガル |
| Dr.fookah（問屋街のショップ） | 卸のシャッターが上がって店内へ |
| バイトの時間経過（tonari） | 入口の札が OPEN から CLOSED へ裏返り、時計が早回りする |
| サメちゃんとの夜道の出会い | 水面とサメのヒレが画面の下を横切り、泡がはじけて場面へ |
