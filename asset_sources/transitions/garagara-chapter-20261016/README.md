## ガラガラくじ（CI128・`remake/js/motions/garagara.js`）

商店街の福引きの回転抽選器（六角の胴）に寄せて作り直した。朱と黒の漆塗りに真鍮の金具。胴は回るたびに厚みと光の当たり方が変わる。木の握りのハンドル、土台、布張りの樋、漆の受け皿。暗い店先にスポットライト。

ハンドルを一度引いてためてから約1.6回転（中の玉がガラガラ鳴り、止まり際はゆっくり）→ 穴を少し下へ向けて玉がカチッと出る → 樋を転がって受け皿に落ち、だんだん低く弾んで止まる（画面がゆっくり寄る）→ S賞は金の光の筋・輪・金箔、A賞は少し金箔、B・C賞は控えめな光 → 暗くなるのと重なって賞のカード。約4.4秒。玉の色は S金・A赤・B青・C白。
