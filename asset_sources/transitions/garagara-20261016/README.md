# シーシャくじのガラガラ（2026-10-16・CI124）

オーナー「モーショングラフィックスでガラガラくじの演出作って欲しい」。Dr.fookah のシーシャくじ（`daily/kuji.js`）を引いたとき、これまでの「棚の箱が揺れる」演出の代わりに、福引きの回転抽選器（ガラガラ）を回す。

台と八角の胴が弾んで出る → ハンドルをぐっと引いてから1回転半（回るあいだ玉の音と台の揺れ）→ 受け口から玉が転がり出て、受け皿で2回弾んで止まる → 玉が光る（S賞は大きな輪・放射線・紙吹雪）→ 賞のカード。約4秒。

玉の色が賞を表す: S賞＝金、A賞＝赤、B賞＝青、C賞＝白。胴と台は場面ごとの色（木と赤）／紫1色（`?mopal`）。動画は前半が実際の速さ、後半が0.5倍速。

試し方: `__remake.dev.motion("garagara-S")`（`-A`・`-B`・`-C`）。景品は渡さず演出だけ見る。実装は `remake/js/motions/garagara.js`。SKIP中とテストの高速送りでは回さずにカードだけ出す。
