# 紫系の抽象煙トランジション：3パターン

最新指定「何パターンかアイデア欲しい」「色はやはり紫系とかポップな感じとかゲームに合わせて欲しい」。[生成モックアップ](source.png)は3行×4コマ。各行を左から右へ読むと、店内を覆う→完全に覆う→夜の街を出す流れ。

紫・ラベンダー・アイボリーを軸に、少量のピンクでポップさを足す。3案の配色を揃え、形と動きの違いを比較できる構成。リアルな煙ではなく、印刷感のある大きな曲線・色面・網点として表現する。

| 行 | 案 | 動きのアイデア | 合いそうな用途 |
|---|---|---|---|
| 上 | 巻き込む渦 | 大きな煙の渦が回り込み、画面を覆ってからほどける | 場所を移る、印象的な場面へ入る |
| 中 | もくもく流れ | 丸い煙の塊がつながって流れ、ふくらみながら場面を覆う | 普段の切り替え、穏やかな日常 |
| 下 | 交差する煙リボン | 2本の長い煙が反対の斜め方向から交差し、重なってから抜ける | 大会、勢いを出すイベント |

普段は中段、強い演出は下段を推奨する使い分け案。用途・タイミング・音はまだ実装していない。各行の3枚目に完全遮蔽の瞬間があり、背景を替えられる。

[生成指示](prompt.txt)と[実参照・SHA-256・保存記録](generation.json)。1672×941の原画をバイト一致で保存。生成元も保持。実参照は店内と夜マップの切替前後の場面用で、色を制約する参照ではない。文字・人物・UI・ロゴは含めない。

静止した比較ボードであり、各コマは本番16:9の素材ではない。採用後は渦・面・マスクを独立したレイヤーと動きに展開する。今回は本編トランジションを変更しない。
