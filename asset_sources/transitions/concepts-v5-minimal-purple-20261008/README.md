# 紫系のシンプルで抽象的なトランジション：3案

最新指定「トランジションはもっとシンプルで抽象的なのでもおしゃれでいいかも」。[生成モックアップ](source.png)は3行×4コマ。各行を左から右に読むと、店内を覆う→完全に隠す→次の街を出す流れ。

紫と淡いラベンダーを中心に、少数の大きな面・曲線・余白へ絞った。前案の網点、太い輪郭、細かな煙の形を外し、構図と動きで見せる方向。

| 行 | 案 | 動きのイメージ |
|---|---|---|
| 上 | 一筆の煙 | 一つのS字の面が斜めへ伸びて画面を覆い、細く抜ける |
| 中 | 丸い波 | 大きな丸みを持つ面が横へ流れ、場面を覆って通り過ぎる |
| 下 | 余白が開く | 一つの曲がった開口が閉じて隠し、次の場面へ開く |

煙のモチーフと軽さを残すなら上段を推奨。実際のテンポ・音・形の補間は今後の検討。各行の3枚目に背景を完全に隠す瞬間がある。

[生成指示](prompt.txt)と[実参照・SHA-256・保存記録](generation.json)。1672×941の原画をバイト一致で保存。色面のわずかな濃淡も生成原画のままで、厳密な2色だけのruntime画像ではない。元の生成ファイルも保持。人物・文字・UI・ロゴを入れず、店内と夜マップを切替前後の参照として使用。
