# トランジションv2：大胆なグラフィックの3案

最新指定「煙や金とか黒にこだわらなくていい」「ペルソナ4や5みたいなセンスの良いトランジションを考えて欲しい」。大きな図形、強い色対比、斜めの構図、網点・印刷の質感、勢いのある画面切替を軸に生成。[原画](source.png)の各行を左→右に読む静止モックアップ。

| 行 | 案 | 動きのイメージ |
|---|---|---|
| 上 | 黄ポップ | 大きな円と丸い窓が横へ滑り、黄・橙・白の面で覆ってから開く。明るく弾むP4寄りの方向 |
| 中 | 赤シャープ | 赤・白・黒の鋭い紙片と斜めの面が走り、一気に覆って裂けるように開く。力強いP5寄りの方向 |
| 下 | 青×ピンクの街のリズム | 大きな帯・斜めの切り口・網点が横へ走って重なり、次の街へ弾ける。ゲーム独自の配色を作る方向 |

独自の印象には下段を推奨。動かす際は短く勢いよく入り、完全に覆う瞬間に背景を替え、面がまとめて抜ける構成を想定する。テンポや音は今回の静止画像では確認できない。

参照画像は店内と夜マップの「前の場面／次の場面」用。トランジションの色を制約する参照ではない。[生成指示](prompt.txt)と[実参照・SHA-256・保存記録](generation.json)。1672×941の生成原画をバイト一致で保存。元の生成ファイルも保持。人物・文字・日付UI・実在ゲームのロゴは描いていない。

3案×4コマの比較ボードであり、本番の16:9素材ではない。採用後は独立した面・マスク・網点と実際のタイミングへ展開する。今回の指示はモックアップ提示までで、トランジションのruntimeは変更しない。[以前のv1](../concepts-v1-20261008/README.md)は比較履歴。煙・黒・金への固定は最新指定で撤回。
