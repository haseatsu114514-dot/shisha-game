# 制作UIの質感（GP41）

2026-10-08、オーナー「温度のゲージとかリフレッシュボタンとかシーシャ作り全般で今UIがショボい奴は生成を使って豪華に」の依頼。4枚とも内蔵 `image_gen.imagegen` で生成したPNG原画。`prompts.json` に全指示、`generation.json` に実参照・寸法・ハッシュを保存する。共通スタイルは `docs/prompts/asset_gen_prompts.md` を使用し、既存ラウンジの黒・金・煙の装飾を実参照した。

| 素材 | 現行remake/での用途 |
|---|---|
| ui_temperature_frame.png | 蒸らし・吸い出し共通。中央の透明な空洞に実温度／適温／最適温／停止予測を描く |
| ui_craft_button.png | 全制作モードの実ボタン・タイマーの停止再開ボタン。文字はDOM |
| ui_refresh_button.png | リフレッシュの専用面。残り回数・使用可否は既存操作ロジック |
| ui_craft_panel.png | 作業風景・見守る人物・選択カード・弾幕・吸い方のゲージ・評価カードの金属枠 |

`assets/ui/making/` に無加工のPNGを置き、通常のmanifest／WebP生成で取り込む。PNGの透明な余白は既存makingBoxと表示時の背景サイズで吸収する。温度計は蒸らし幅54px・高さ300px、吸い出し幅76px・高さ440px。中央の上下10%を除く空洞内に実際の温度を表示し、枠や装飾は入力を遮らない。色・帯・針・予測値・使用回数の画像への焼き込みはしない。制作画面への切り替え時に4素材のデコードも待つ。

白い100均風のキッチンタイマー本体は以前の採用素材を維持。生成UIの接続と画像／manifest生成は実施済み。ユーザー指定で追加のプレイ検証・回帰テストは実行していない。
