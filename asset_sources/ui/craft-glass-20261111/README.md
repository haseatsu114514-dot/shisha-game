## 受け取った後の手順（実装側）

1. 透過の画像は alpha≥8 の外接範囲で切り出し、完全透明画素の RGB を黒にする。重ねて使う組（`tile`・`tile-on`・`tile-off`、`key`・`key-amber`、`dial-bezel`・`dial-glass`）は、光彩のいちばん広い1枚の外接範囲を共通の切り出し枠にする。
2. 採用画像を `assets/ui/craft-glass/<名前>.png`、実行時の WebP を `remake/img/ui/craft-glass/<名前>.webp` に置く（`remake/tools/build_ui_skin.py` に表を足す）。新規画像は Git LFS。
3. 当てる場所（`asset_sources/ui/craft-stage-20261110/stage_src.css` → `build_stage_css.py`）:

| 部品 | 置き換えるもの | 当て方 |
|---|---|---|
| `tile` / `tile-on` / `tile-off` | 選ぶ札の CSS の面（詰め方・通気・機材の `.opt`、配合の `.flavor-row`）。選んでいる札・選べない札 | 九分割（`border-image`）。縁の幅は 0 のまま `border-image-width` で絵の縁の太さを決め、箱の大きさ・押せる範囲は変えない |
| `panel` | 舞台の上の CSS の面（配合の左の列、穴あけの説明、炭壺の帯、吸い出しの下の札、ライバルの小窓） | 九分割 |
| `frame` | 詰め方・配合の大きな作業面の縁（中の絵は今のまま） | 九分割。中は透明 |
| `strip` | 説明の帯（香りの一言・配合の合計・ひとことの案内） | 左右の端を残して横に伸ばす |
| `plaque` | 柱の札（`spine-plate`）・吸い出しの見出し・針の現在位置 | 両端の丸を残して横に伸ばす（`spine-plate` と同じ割合） |
| `key` / `key-amber` | 灰色の平たいボタン（二番手）／金のボタンの絵（主） | 九分割 |
| `bead` / `rail-now` | 上のレールの工程の丸と今の工程の札（`rail-now` と同じ割合。左の丸に番号） | 工程の丸は背景、今の札は今の `rail-now` と同じ切り方 |
| `badge` | 右上の「？」の丸、大会のライバルの顔の縁 | 丸の背景 |
| `spine-housing` | 熱の柱の外枠（今の `spine-housing` と同じ形・寸法） | 今と同じ切り方（上86・下97 を残して縦に伸ばす。窓は透明） |
| `dial-bezel` / `dial-glass` | ダイヤルの台座（今の `dial-bezel` と同じ幾何。帯の溝 r118〜212 に窓）と、その上に重ねるガラスの照り | 台座は今と同じ位置。照りは針より下・色の帯より上 |
| `voice-plate` | 左下の一言の板（今の `voice-plate` と同じ形） | 今と同じ切り方。顔は左の丸い座 |
| `stage-leather` | 吸い出し・蒸らしの舞台の奥（今は熱の背景の模様） | 舞台いっぱいに敷く。左と上を暗く溶かす |

4. 画面で確かめる: PC（1280×720）とスマホの横持ち（844×390）で、全工程（機材・配合・詰め方・穴あけ・炭焼き・蒸らし・吸い出し・調整）と大会・チュートリアル。白い字が読めること、九分割の継ぎ目が見えないこと、押せる範囲が変わらないこと。関連のブラウザ検査（`craft_layout_*`・`craft_materials`・`phone_density`・`craft_progress` ほか）を通す。
5. シーシャ作りの次は、新版の日常の画面（会話・地図・MENU・小窓。LK19 で夜紫の部品を当てた所）にも同じ方向を広げるかをオーナーに確かめる。
