## 4案

| 案 | 見た目 | 良いところ | 気になるところ |
|---|---|---|---|
| A 熾火 | いまの構図のまま、色を炭火へ。火の粉が上がり、足元の火が人物を下から照らす。時計は燃え尽きていく炭の輪。時間切れで火が消えて灰色になる | シーシャの炭と結びつく。いまの画面からの変化が小さく、採用しやすい | 構図は同じなので、題字とボタンが人物の頭と胸に重なる点は変わらない |
| B 斜め割り | 対戦カードの構図。人物は左の斜めの面、右に巨大な残り秒数（1秒ごとに叩きつける）と残り時間のゲージ、縦に積んだ2択。台詞は名札つきの帯 | 人物に何も重ならない。残り秒数・2択・台詞の役割がひと目で分かる。色はいまの紫と金 | 人物が左へ寄り、右半分はUIになる。大きい衣装は斜めの線で切れる |
| C 漫画の大ゴマ | 紙の白と黒。人物は集中線の大ゴマ、台詞は吹き出し、残り秒数は黒いギザギザ、2択は2つのコマ（選ぶと黒く反転）。時間切れは黒いページ | いちばん個性が出る。スミさんの掛け合いや恋人の一言が漫画の1ページとして読める | ゲームのほかの画面（暗いネオン）と調子が違う。負けた直後に白い画面へ切り替わる |
| D 閉店前のネオン | 店の壁のネオン看板「CONTINUE? ／ コンティニューする？」。残り時間は管の長さと数字で減り、残り5秒で瞬く。時間切れで消灯して赤い「GAME OVER」だけが灯る。諦めると一文字ずつ消える | シーシャバーの夜の空気に合う。時間切れと「諦める」の見せ方が静かで後味がよい | 題字が筆文字から英字のネオンに替わる。勢いは4案でいちばん控えめ |

推し: **B**（人物・残り秒数・2択・台詞が重ならず、スマホ横持ちでも読みやすい）。A の炭火の色と火の粉を B に足す組み合わせもできる。

## この先

- A を使わないと決まったら、`continue-ember.css` と `continue-looks.js` の ember の飾り・切り替えの選択肢を消す。前の版の neon を消すときも同じ（neon の検査 `continue_neon.mjs` などは `layout: "neon"` を指定している）。
- 絵を足すなら: A は炭と火の粉、C は紙の質感と効果線。どちらも今は図形で描いているので、Codex へ依頼すれば質感を上げられる。
