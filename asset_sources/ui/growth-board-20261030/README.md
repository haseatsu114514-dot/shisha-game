## 1. 見た目の芯: 「火を灯す」

- 火種＝**小さな炭火の粒**。盤のノードを解放する＝**火を灯す**。言葉（SPEC 1.10）と絵を一続きにする。
- 色は今のUIの墨×金をそのまま使う。新しい色は火種の琥珀だけ足す。

| 用途 | 色 |
|---|---|
| 万能の火種・未使用の印・今夜 Lv UP の光 | 琥珀 `#ffb43c`（芯 `#fff1b8`、外 `#e86a12`） |
| 系統限定の火種・能力ノード | 能力色（`--stat-*`）: 技 `#f2c34c`／感 `#6cc6e8`／根 `#ef7a5e`／魅 `#b49aef`／察 `#65c9bb` |
| 経験値ゲージ | 精算済み＝濃い金 `#c08a2a→#f4d27a`、今日の分＝薄い金 |
| 鍵・まだ取れない | 灰 + 透明度 |

色だけに頼らず、漢字バッジ（技・感・根・魅・察）を必ず添える（master_spec #19）。

## 2. 画面ごとの方針

### 2.1 HUD（実装済み・#1702）
- 情報カードの体力の下に「Lv.N［ゲージ］あとN」。満タンで琥珀に脈打ち「今夜 Lv UP」。次が節目なら、ゲージの右端に火種2粒の印。
- 未使用の火種は五角形ボタンの右上に琥珀の炎形の丸＋個数。**画像が届いたら CSS の丸を火種アイコン（32px）に差し替える**。

### 2.2 寝る前のレベルアップ（実装済み・#1702）
- フル演出（初回・節目・2つ以上）: ゲージが満ちて弾ける → 火種の粒が五角形へ飛ぶ → 「Lv.1 → Lv.3／火種 ＋2」。
- ふだんは画面上部の短い帯（約1.8秒）。
- **次の改善（画像不要）**: 「今日学んだこと」を文字だけでなく、既存の顔アイコン（`remake/img/ui/face_icons/`）と行き先の記号を最大3つ並べる。誰から学んだかが一目で分かり、REPORT G2（成長と物語を一画面で結ぶ）が強くなる。
- 火種の粒は、届いたら火種アイコン画像に差し替える（今は CSS の炎形）。

- **背景**: 暗い煙の盤面の画像（下の画像3）。輪・扇・線はコードで描く（画像に焼くと座標がずれるため）。
- **中央**: 「はじまりの一服」の紋（画像4）。
- **能力ノード**: 丸い炭の受け皿。未解放は冷えた灰色の炭、解放済みは能力色で灯る。コード（CSS/SVG）で描き、漢字バッジを重ねる。
- **スキルノード**: 六角形の真鍮の札（枠はコード）の中にスキルアイコン（画像2）。輪の鍵がかかっていても**名前とアイコンは見せる**（REPORT P8: 「あれが欲しい」を作る）。第4輪の決め手4つは1.3倍に大きく描く。
- **ノードの状態**（SPEC 6.2 の5つ＋第二弾で2つ）:

| 状態 | 見た目 |
|---|---|
| 解放済み | 能力色で塗り、弱い発光 |
| 今取れる | 能力色の縁が明滅（呼吸する速さ） |
| 火種が足りない | 縁だけ・必要数を火種の粒で表示 |
| 段の順待ち | 薄い灰 |
| 輪の鍵 | 錠＋「第N章」 |
| 修行がまだ（ADDENDUM-0035） | 錠の代わりに相手の顔アイコンの小札「スミさんの修行で開く」 |
| その色の火種がない（ADDENDUM-0042） | 縁にキャラの色の点線 |

- **✦（質が変わる段）**: 根性5段・洞察3段／5段・魅力2段のノードに小さな✦。右欄にも「✦3段で配合の相性ヒント」（REPORT P1・R3）。
- **灯す瞬間**: ノードに火種の粒が吸い込まれ、能力色で灯る → 右欄のピップが1つ増え、五角形（レーダー）が少し広がる（ADDENDUM-0044）。
- **スマホ横 844×390**: 盤を左、右欄は折りたたみ（能力名だけ）。チュートリアルの案内文は**上**に出す（下の操作帯と重ねない。REPORT P9）。ノードは44px以上。
