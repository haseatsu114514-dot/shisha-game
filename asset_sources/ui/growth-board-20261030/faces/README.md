# 心得の盤の授業の札の顔（SBD81）

2026-10-31 オーナー「キャラアイコンの拡大率がバラバラで整えたい」。顔アイコン（`remake/img/ui/face_icons`）は人ごとに顔の大きさと高さが違い、札の中でそろわなかった。

- `make_faces.py` が立ち絵（`chr_<人>_normal`）から、目の高さと顔の大きさをそろえて 160×160 に切り出す → `remake/img/ui/growth_board/faces/<人>.webp`（20人、Git LFS。2026-11-02 に王煙楼・博士を追加）と `faces/new/<人>.webp`。
- ~~`EYES` は立ち絵の上での [目の真ん中 x, 目の高さ y, 頬から頬の幅]。目で測った値。~~ 2026-11-06 に廃止。顔アイコンと同じ `data/portrait_metrics.json` の記録（目・あご・頭頂・頬）から切り出す。目で測った表は描き直し前の立ち絵のままの人（みんと・レヰ・組長・スティーブ・ヴォルク・ダ・シルヴァ）がいて、旧デザインの顔が残っていた。顔の大きさは √(頭の高さ×頬の幅)×0.87（以前の表の平均。SBD87・SBD88 の寄り具合を保つ）。右のパネルの立ち絵も同じ記録（manifest の `faceFrames`）で置く。人を足すときは `make_faces.py` の `WHO` と `growth-board-screen.js` の `BOARD_FACES` に足す。
- 設定で新バージョンの立ち絵を選んでいる時は、新バージョンの立ち絵とその絵で測った記録から作った `faces/new/<人>.webp` を出す（右のパネルも新バージョンの立ち絵）。新バージョンの絵が無い人（凛想）は現行のまま。
- 顔アイコンの無かった綾取・スティーブ・シェイク・ダ・シルヴァも、これで札に顔が出る。
- 確認用の一覧は `contact_sheet.png`（赤い線が目の高さ）。
