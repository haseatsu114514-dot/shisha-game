# 心得の盤の授業の札の顔（SBD81）

2026-10-31 オーナー「キャラアイコンの拡大率がバラバラで整えたい」。顔アイコン（`remake/img/ui/face_icons`）は人ごとに顔の大きさと高さが違い、札の中でそろわなかった。

- `make_faces.py` が立ち絵（`chr_<人>_normal`）から、目の高さと顔の幅をそろえて 160×160 に切り出す → `remake/img/ui/growth_board/faces/<人>.webp`（18人・約190KB、Git LFS）。
- `EYES` は立ち絵の上での [目の真ん中 x, 目の高さ y, 頬から頬の幅]。目で測った値。`growth-board-screen.js` の `PORTRAIT_EYES` も同じ値で、右のパネルの立ち絵を置くのに使う。人を足す・立ち絵が変わったら両方を直す。
- 顔アイコンの無かった久世・スティーブ・シェイク・ダ・シルヴァも、これで札に顔が出る。
- 確認用の一覧は `contact_sheet.png`（赤い線が目の高さ）。
