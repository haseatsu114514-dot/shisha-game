スタイル: 薄暗いシーシャラウンジの空気。`assets/backgrounds/bg_eden_shop.png` 程度の2Dドット絵〜ピクセルペインター調で、輪郭・影・質感に細かいドット感を残す。リアル写真調や滑らかすぎる3D調は避ける。シーシャ台の先端は小さい凸型の金属ポストにし、凹んだカップ型・ボウル一体型・大きな先端パーツにしない。手・腕は細身で中性的、明るいピーチ系の同一肌色に統一する。

視点: 作りパートは一人称（プレイヤーの手元を上から見下ろす角度）。
出力: PNG・透過指定のものは背景完全透過。@2x（実寸の2倍）で。指定なき限り 1280×720 基準。
NG: 文字/ロゴ/UI/数字の焼き込み（数値はゲーム側UIで出すので画像に入れない）、watermark。

Common rules for all 4 images:
Use case: production game UI asset for a growth system called "Kokoroe no Ban" (a skill board). The theme is "lighting a fire": the currency is a small glowing charcoal ember called "hidane" (fire seed). Match the existing UI material: black-purple enamel, warm brass/gold edges, amber glow, faint smoke haze, crisp pixel-painter microtexture. Ability colors used across the game: technique #f2c34c (gold-yellow), sense #6cc6e8 (sky blue), guts #ef7a5e (coral red), charm #b49aef (lavender), insight #65c9bb (teal). DO NOT include any rendered words, letters, kanji, numbers, labels, gauges, progress bars, node circles, connecting lines, frames for buttons, or UI chrome; the game draws all of those. No hands, no people, no shisha hookah, no hose. No watermark. Clean edge alpha with no detached flecks on transparent images. Straight-on front view.

A single horizontal sprite sheet, exactly 1536 x 256 pixels, transparent background, divided into 6 equal square cells of 256 x 256 (invisible grid, no drawn borders). Each cell contains ONE centered "hidane" ember icon, occupying about 70% of the cell, with at least 24 px empty transparent margin on every side so the sheet can be sliced mechanically. The ember is a small rounded chunk of glowing charcoal: a dark grey-black porous coal body with a bright molten core showing through cracks, and a soft teardrop-shaped flame halo rising from the top. Same silhouette, size, angle and lighting in all 6 cells; only the glow color changes:
cell 1 (universal): warm amber core #fff1b8 -> #ffb43c -> #e86a12 outer glow;
cell 2: core and halo tinted gold-yellow #f2c34c;
cell 3: sky blue #6cc6e8;
cell 4: coral red #ef7a5e;
cell 5: lavender #b49aef;
cell 6: teal #65c9bb.
The shape must stay readable when shrunk to 16 x 16 px: bold simple silhouette, strong contrast between dark coal and bright core, no thin details. No sparks flying outside the cell, no smoke trails, no text or kanji on the ember.
