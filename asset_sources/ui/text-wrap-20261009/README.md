# 会話欄の改行（2026-10-09 TX01）

`before_after.png` は、同じ台詞を本編の会話欄（PC 1280×720）で表示した比較。上が変更前、下が変更後。

- 「…音だけが鳴っ｜ている。」→「…音だけが｜鳴っている。」
- 「…見たことないんで｜すよね〜♪」→「…見た｜ことないんですよね〜♪」

句読点で折れない行は、語の途中で折らずに手前の文節の頭で早めに折る（`remake/js/vn/text.js`）。
第1章の会話・LIME以外の吹き出しで、語の途中の改行は127か所→0、2ページ以上に分かれる台詞は308→30、
文の途中で改ページする台詞は157→0（バイトの結果文は48→0）。検証は `node remake/test/text_wrap.mjs`。
