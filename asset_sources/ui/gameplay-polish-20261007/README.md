# 制作画面の配置・静止モックアップ

GP12・GP15〜17の表示確認。左側の独立したシーシャ台パネルを廃止し、はじめと作業台を一つの広い場面へ収める。

- `craft-heat-desktop.png`: 1280×720。炭の中央配置と広い作業風景
- `craft-steam-mobile.png`: 844×390。大会の操作パッド・リフレッシュ・実況欄が重ならない
- `craft-steam-portrait.png`: 591×1280。縦画面でもステージ全体が収まる

静止モックアップは現行版のはじめの立ち絵・tonariの背景・既存の制作素材をHTML/CSSで配置したもの。人物画像の再生成や差し替えは行っていない。動画・煙のタイマーは制作窓に読み込まない。
`remake/js/craft/worker.js` が場面を組み、`.bench-worker-stage` を将来の工程別動画の接続先として残す。親の `data-step` と自然な工程キャプションが操作に追従する。
