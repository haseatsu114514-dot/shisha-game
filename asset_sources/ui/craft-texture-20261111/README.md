### 依頼文どおりでない点（Codex の報告のまま）

- **寸法**: 4枚とも 1672×941（約16:9）。依頼の 1536×864（または 1536×1024 を上下で切る）と違う。
- **灰色の場所**: わずかな明るさのむらがあり、参照の完全な単色ではない。部品の境界や寸法も画素単位では一致しない（装飾・太さが変わっている）。
- **プロンプトの確認**: `pack-A`・`pack-B`・`pull-A` の3枚は、先に作業した担当が生成したものを回収した。実際に渡したプロンプトの記録は残っておらず、依頼文と同じだったことは確認できていない。`pull-B` は、参照 `refs/pull-masked.png` と依頼文の COMMON＋方向B の段落をそのまま渡して新しく1回生成した。
- **作り直し**: 3回までの作り直しはしていない（不足の1枚だけを作る依頼だったため）。
- 詰め方の左上の小皿・左の布・右上の筒、参照の右上にある画像の欠落の印は、参照（今の作業マットの絵）に元からある。新しく描かれた機材ではない。
- 日本語の文字は見本なので崩れがあってよい。文字は実装で使わない。

これは方向を選ぶための候補で、厳密な CHECK の全面合格や本番の素材ではない。**どの方向にするかはオーナーが決める**（どちらでもない・混ぜる、も可）。決まったら部品ごとの依頼文を作る（[prompts.md](prompts.md) の「受け取った後」）。
