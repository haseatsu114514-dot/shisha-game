# シーシャくじ原画の後処理（Issue #3228）

正本: `../prompts.md`。入力: PR #3251 の `raw/` 23枚。原画の画色・描線は保持し、透明マスク、寸法、配置を補正した。色調補正・描き直しはしていない。

## 処理方法

- 透過画像は alpha≥96 の最大連結成分を本体とし、その周囲2pxを残して外側の影・残画素を除去。リサイズ後の alpha 1–11 を0にした。
- 玉5枚は同じ 1024×1024 キャンバス、中心 (512,512)、直径約718px の共通円形 alpha に合わせた。原画の塗りとハイライトは各画像から維持。
- 札5枚は無地の右側から縦帯を除いて本体比率2.38:1にし、幅92%で中央に配置。基準札 S の alpha 形状を他4枚に適用した。無地部分の継ぎ目は一覧画像で確認。
- 土台は板面の中間帯を除いて約7:1へ。前後の外縁と金具を保持。
- 黒地2枚は不透明 RGB のまま 1024×1024 へ縮小し、外周82pxを #000000 にした。
- カウンターは y<563（55.0%）を alpha 0、y≥563を不透明に統一。

- 出力23枚、透過21枚・黒地2枚。すべて正本の指定寸法。
- 玉5枚の alpha 配列はピクセル単位で一致。札5枚の alpha 配列も一致。
- 札の alpha≥96 本体外接矩形: 1413×594px、比率2.379:1。土台: 1382×198px、比率6.98:1。
- 残る評価: 元絵の塗りの配置は微差があるため、玉・札の色柄までピクセル単位で同一ではない。今回は絵の再描画を避け、輪郭と位置だけを揃えた。
