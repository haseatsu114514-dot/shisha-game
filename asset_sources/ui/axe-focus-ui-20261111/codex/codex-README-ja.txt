斧投げUI素材 #3207 / AXR14・選別用候補（本編未組込）

6種類の原出力、指定キャンバスに縦横比を保って収めたPNG、比較プレビュー、SHAとQAを同梱。生成は組込み画像生成機能。参照は公開ゲーム素材 target_board_watl_c.png と menu-walnut-panel.webp。私的写真・シーシャ機材なし。生成前に1,657,777BコピーとSHA一致を確認。

原画は無文字・無数字・目盛りなし、針だけ右向き三角。木/鋼/真鍮/エナメルを画風参照に合わせた。中央は平らで文字を置ける。選択札は明るい青＋真鍮/白縁。キャンバス版6枚は指定px、外周alpha=0。全採用条件が通った最終素材ではない。

未合格/未確認: 生成は指定対象物の比率を厳密に守らず、キャンバス版の針は448x45（指定約448x96）、ボタンは1184x273〜274（指定約1184x384）、札800x359〜360（指定約800x432）、ゲージ221x1984（指定約256x1984）。原画を引き伸ばして形を歪めることはせず縦横比を維持したため、この差が残る。9分割帯・4辺の対称性・色違いの完全ピクセル一致は未合格。生成の輪郭に微細なalpha縁ノイズが残る可能性あり。正寸最終版として自動採用しない。

細長さを是正したゲージの追加案、比率を是正したオレンジ案、中央alpha欠落が発生して不採用の緑追加案は rejected/ に保存。緑穴あき案を使わない。
