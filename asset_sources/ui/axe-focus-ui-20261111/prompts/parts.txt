Game UI prop for an axe-throwing mini game set in a Japanese night lounge with amber lamps, burgundy upholstery and black steel lanes. High quality illustrated anime adventure game prop with painterly realistic materials: chalkboard slate, walnut wood, blackened steel, brushed brass, safety-orange enamel paint. Same look as the existing target board `assets/ui/axe_throw/target_board_watl_c.png` and the menu panel `assets/ui/axe_throw/menu-walnut-panel.webp` (attach both as style references; copy their material and lighting, not their shape).
Perfectly front-facing orthographic view, no perspective, no tilt. Soft even light from the upper left. One object only, centered, with a small transparent margin. True transparent background (RGBA PNG), no floor, no wall, no external cast shadow, no glow outside the object.
STRICTLY NO text, NO letters, NO numbers, NO icons, NO arrows printed on the surface, NO logo, NO watermark, NO gauge marks, NO scale ticks, NO colored bands. The game code draws every label, band, needle position and number on top.
The middle area must stay flat, calm and evenly lit (no knots, no scratches, no strong grain, no highlights) so that white or dark text stays readable on it. Wear, screws and rivets only on the outer rim.
