# 再生成する前の6種類・編集用PSD

**[PSD6種類・フォント・完成見本をまとめてダウンロード](dialogue-ui-before-regeneration-psd.zip?raw=true)**

対象は、直近の没にした再生成6案より**一つ前の実装デザイン**です。11 煙／紫の煙／16 ペーパーラウンジ／25 琥珀ラウンジ／28 重なる薄紙／従来ゴージャスを、別々のPSDにしています。

各PSDはゲームと同じ1280×720px、sRGB、72ppi。背景・キャラ・本文ウインドウ・名前欄・操作欄・▼を分け、枠は透過画像、文字7枚は編集できるテキストレイヤーとして保持しています。枠と文字をグループでまとめて移動できます。背景と立ち絵は参考レイヤーです。

文字の打ち替え用に、使用したZen Kaku Gothic New／Zen Old MinchoのTTFとライセンスも同梱。最初にフォントをインストールしてください。文字の影は元の表示をキャッシュとして保持するため、打ち替え後は必要に応じて調整してください。

元のUI版は `502c9f9c`。新たに没にした原画は含めていません。修正後はPSDのまま返せば、ゲーム側の寸法や余白へ反映するために確認できます。

PSDの再読込、文字レイヤー7枚の保持、別のPSD読込ライブラリによるレイヤーの再合成を検証しています。書き出し時の座標と確認結果はZIP内のJSONを参照してください。
