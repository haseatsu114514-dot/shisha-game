## 指定するとき

「**O16を元に、名前欄だけ直す**」「**V02-11の煙を使い、文字の余白だけ調整**」のように指定できます。複数の版を組み合わせたい場合も、名前・本文・操作のどの部分かを番号で分けられます。

選ばれたIDの原画・表示版を固定して、指定部分だけ編集します。原案を選んだのに現行実装の似た枠へ置き換えたり、他路線まで再生成したりしません。追加版は新しいIDで残し、元画像を上書きしません。選定前のためゲームの採用状態は変えていません。

**配布済みPSDは[V12](versions/V12.md)です。** [PSD6種をダウンロード](https://github.com/haseatsu114514-dot/shisha-game/raw/31827d9e26e7ddbd4dcd2b0693f36a62a908a0db/asset_sources/ui/vn-smoke-11/psd-export/dialogue-ui-before-regeneration-psd.zip)。それ以前の版を選んだ場合は、このPSDをその版と同一とは扱いません。
