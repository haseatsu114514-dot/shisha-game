# 会話枠に合わせたUI一式

2026-10-24の本人指定：16のメイン採用を11「実験・煙だけの輪郭」へ変更。11の紫版も作り、16・25・28・従来ゴージャスを残す。会話枠に合わせた共通UI一式を各テーマで制作し、UI選択でゲーム全体を切り替える。

現在の比較実装は本編タイトルCONFIGの「UIデザイン」で6種類を選択。初期は約2種類、残りはシーシャくじで解放する方針で、解放制は未実装。設定は端末のconfigのみ、ゲームの進行・判定は変更しない。下は本編CSSを使ったブラウザ描画で、画像生成だけのラフとは区別する。

メニュー・パネル・ボタン・地図の案内／ピン・通知・ハート・体力ゲージの共通装飾を切り替える。店内背景・人物・スマホ本体・ミニゲームの機材や物語演出を塗り替える機能ではない。体力の緑/黄/赤・能力5色は意味を保つ。

最新指示「文字と枠／操作と▼が重なる」「SKIPなどは全部右上」「窓をもっと横へ」を反映。通常表示は窓幅1216px・高さ208px、本文は左100px／右84pxの余白を確保し、操作バーは枠の12px上・右寄せ、▼は右下に独立。本文・本心は同じ高さの窓に収め、選択肢は操作バーから16px上に離す。2画面表示の操作バーも背景側の右上へ統一。名前なしの地の文・心の声では名前欄を隠す。

## 確認

- 実Chromium：1280×768／844×438、6テーマのパネルが実際に異なる色・形へ変わること、本文2行・本心の字面と名前／操作／▼の非重複、44px操作領域、地の文・選択肢を確認。
- CONFIGで全テーマを選べ、再起動後の選択が維持され、不明な旧テーマ値は既定11へ。ゲームの保存文字列は不変。
- プレビューのテーマ選択・UI一式表示はlocalStorage/sessionStorageとも変更しない。
- 従来枠の通常送り・AUTO/SKIP・LOG・用語・地の文・本心は `conversation_ui.mjs` PC/横持ちPASS。

本人「微妙だったからまだ作らなくていい」により追加制作・本編採用は保留。以前の試作はプレビューの「光の試作」で任意ON/OFF。元の窓と本文を静止させたまま、外周の短い光だけ18秒周期で流す。操作や文字に重なる光、全画面の点滅は入れない。動き軽減設定では停止。設定は保存せず本編にも自動採用しない。
