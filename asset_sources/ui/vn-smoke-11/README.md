現在の比較実装は本編タイトルCONFIGの「UIデザイン」で6種類を選択。初期は約2種類、残りはシーシャくじで解放する方針で、解放制は未実装。設定は端末のconfigのみ、ゲームの進行・判定は変更しない。下は本編CSSを使ったブラウザ描画で、画像生成だけのラフとは区別する。

メニュー・パネル・ボタン・地図の案内／ピン・通知・ハート・体力ゲージの共通装飾を切り替える。店内背景・人物・スマホ本体・ミニゲームの機材や物語演出を塗り替える機能ではない。体力の緑/黄/赤・能力5色は意味を保つ。

最新の見直しは、名前札と操作枠が上辺から少し出る構成。通常表示は1216×176px・画面下16px（煙の2種類は幅1240px・左右112px）、本文上44px／通常左右96px、本文28px・行高44px、名前22px、操作17px。本文窓を低くし、人物と背景が見える面積を確保しました。原画の透明な余白まで調べ、札と見える縁の距離を調整。本文2行・本心・地の文・AUTO状態で操作位置を変えません。11系の操作をさらに32px左へ、ほかの操作は8px上へ。28の本文は4px上へ動かし、▼は枠ごとに内寄せして揺れを2pxへ抑えています。

## 確認

- 実Chromium：1280×768／844×438、6テーマのパネルが実際に異なる色・形へ変わること、本文2行・本心の字面と名前／操作／▼の非重複、44px操作領域、地の文・選択肢を確認。

- プレビューのテーマ選択・UI一式表示はlocalStorage/sessionStorageとも変更しない。
- 従来枠の通常送り・AUTO/SKIP・LOG・用語・地の文・本心は `conversation_ui.mjs` PC/横持ちPASS。
