# 会話枠に合わせたUI一式

2026-10-24の本人指定：16のメイン採用を11「実験・煙だけの輪郭」へ変更。11の紫版も作り、16・25・28・従来ゴージャスを残す。会話枠に合わせた共通UI一式を各テーマで制作し、UI選択でゲーム全体を切り替える。

本編タイトルCONFIGの「UIデザイン」で6種類を選択。設定は端末のconfigのみ、ゲームの進行・判定は変更しない。下は本編CSSを使ったブラウザ描画で、画像生成だけのラフとは区別する。

メニュー・パネル・ボタン・地図の案内／ピン・通知・ハート・体力ゲージの共通装飾を切り替える。店内背景・人物・スマホ本体・ミニゲームの機材や物語演出を塗り替える機能ではない。体力の緑/黄/赤・能力5色は意味を保つ。

本人から原案との差の指摘を受け、11・紫版・28の操作バーを原案の右下へ修正。本心を併記するときは窓の高さを拡げ、文字と操作を重ねない。DS表示は操作領域を維持。名前なしの地の文・心の声では名前欄を隠し、本文位置を保つ。

[プレビューを開く](../../../remake/conversation-preview.html)をローカルHTTPまたは公開版で開き、「UI一式」とUI選択で比較。プレビューはセーブ・設定を保存しない。

生成ラフはUIの色提案で、人物・背景が微細に再描画される可能性がある。本編は文字を画像に焼き込まない。最初の簡略SVGは本人指摘により11・紫版・16・28の背景素材から外し、原案画像を実参照して生成した質感付き素材へ置換した。原画・生成指示・機械的な余白調整の記録は `faithful/`。

## 確認

- 実Chromium：1280×768／844×438、6テーマのパネルが実際に異なる色・形へ変わること、会話枠・本文・44px操作領域の寸法維持、地の文・選択肢を確認。
- CONFIGで全テーマを選べ、再起動後の選択が維持され、不明な旧テーマ値は既定11へ。ゲームの保存文字列は不変。
- プレビューのテーマ選択・UI一式表示はlocalStorage/sessionStorageとも変更しない。
- 従来枠の通常送り・AUTO/SKIP・LOG・用語・地の文・本心は `conversation_ui.mjs` PC/横持ちPASS。

## 光が動く11の試作

プレビューの「光の試作」でON/OFF。元の窓と本文を静止させたまま、外周の短い光だけ18秒周期で流す。操作や文字に重なる光、全画面の点滅は入れない。動き軽減設定では停止。設定は保存せず本編にも自動採用しない。

[15秒の試作動画](faithful/light-prototype.mp4)。SVGの細い発光パスをCSSのstroke-dashoffsetで動かすため動画をゲーム内再生せず、追加の大きな描画ライブラリも不要。煙の揺らぎや会話開始時の一度だけの発光は次の比較アイデアで、この動画では実装していない。

### 16の尖った輪郭の再照合

本人「16はモックにあったのを忠実に再現、尖ってる感じ」。本文面の元画像上の参考頂点を `(95,650), (1564,673), (1639,870), (1572,895), (125,895), (47,805)` として正規化し、外形をCSSの六角形で固定。生成素材のalphaを輪郭の決定に使わず、紙の質感として内側へ載せる。名前札の傾きと左の斜線、本文の太字、右下の尖った角に合わせて次送り位置も調整。座標は目視照合の参考点であり、元画像との画素完全一致を主張しない。
