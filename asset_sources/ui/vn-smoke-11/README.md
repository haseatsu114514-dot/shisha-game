# 会話枠に合わせたUI一式

**[最新版：構図・文字サイズ・名前と操作の変更前後](polish/README.md)**

2026-10-24の本人指定：16のメイン採用を11「実験・煙だけの輪郭」へ変更。11の紫版も作り、16・25・28・従来ゴージャスを残す。会話枠に合わせた共通UI一式を各テーマで制作し、UI選択でゲーム全体を切り替える。

現在の比較実装は本編タイトルCONFIGの「UIデザイン」で6種類を選択。初期は約2種類、残りはシーシャくじで解放する方針で、解放制は未実装。設定は端末のconfigのみ、ゲームの進行・判定は変更しない。下は本編CSSを使ったブラウザ描画で、画像生成だけのラフとは区別する。

メニュー・パネル・ボタン・地図の案内／ピン・通知・ハート・体力ゲージの共通装飾を切り替える。店内背景・人物・スマホ本体・ミニゲームの機材や物語演出を塗り替える機能ではない。体力の緑/黄/赤・能力5色は意味を保つ。

最新の仕上げ指示を反映し、通常表示は窓幅1216px・高さ224px、本文左100px／右92px／上64px。本文30px、名前24px（青い窓26px）、操作16pxの階層へ整理。操作を各素材の見える上辺の見出し段に接続し、名前と中心線を合わせる。本文2行・本心・▼・操作の非重複を確認。2画面の操作は引き続き背景側右上。名前なしの文章は名前欄を隠す。
