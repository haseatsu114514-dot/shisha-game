## 内容が変わっても操作を動かさない

![通常・2行・地の文・本心](states.png)

見出し段は窓内の上22px・44px高。名前と右上の操作を同じ段へ置き、操作は352px・4等分で固定します。名前がない場合も段の高さを予約し、本文の開始位置を動かしません。

前回の16は、地の文で操作幅・セル比率を変更し、別の原画へ切り替えていました。その指定を削除し、同じ原画と固定した列を使います。AUTO/SKIPの印も絶対配置へ変え、ラベル文字を横へ押さないようにしました。

実ブラウザで、ボタンの枠だけでなく**ラベル文字の座標・幅**も比較。通常会話、2行、地の文、主人公の心の声、本心、選択肢、AUTOのON/OFF、青い窓のキャラ切替で動かないことを確認しています。16の5状態の枠・操作セルの実座標は `positions.json`。

## 読む余白

通常表示の窓は1216×248px。本文は上92px・左右104px、30px・行高48pxで2行。名前24px、操作16px。見出しと本文は淡い罫線と空白で分け、下にも空間を残します。本心は22px・行高33px、本文から12px離します。▼は右下へ独立。細いボタン枠や文字が本文の縁に触れない位置へ合わせています。

11／紫版も煙の縁が操作文字に重ならないように描画位置を調整。青い窓は同じ見出し段に装飾を収め、従来の金枠は空の名前札を持たない一枚の枠を使用します。2画面の16も同じ穏やかな素材・配色へ更新しています。

## 生成素材と確認

原画 `paper-source.png`、指示 `paper-prompt.txt`、ハッシュと矩形切り出し座標は `generation.json`。原画のalphaや絵を描き換えず、余白を機械的に切り出してWebPへ可逆変換。文字領域はCSSの下地で背景を透かさず、外側の柔らかな影・紙の端は保ちます。人物・背景・台詞の正本は変更していません。以前のP5風原画は `../polish/` に候補として保存し、現行表示には使いません。保存済み設定のID `cut-paper` は互換性のため維持します。

全6テーマ・青い窓4キャラを1280×768／844×438で検査。本文2行・本心・名前／操作／▼の非重複、同じ見出し座標と文字座標、保存不変を確認。AUTO／SKIP・LOG・用語・地の文・心の声のPC／横持ち操作、2画面PC／スマホの実選択も成功。
