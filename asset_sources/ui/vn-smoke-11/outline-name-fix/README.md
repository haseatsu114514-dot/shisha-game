名前札と操作を本文の上辺へ重ね、本文窓を176px高・画面下16pxへ。本文28px・行高44px、本心22px・行高31px。名前と操作の枠は独立し、本文・本心の行数で操作位置は変わりません。操作は11が名前より8px上、16が16px上で、本文との間隔を広げています。11の▼は内側へ移し、揺れ幅を2pxにしています。16の文字領域は模様を抑えています。
