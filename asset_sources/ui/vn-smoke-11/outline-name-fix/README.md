# 16・11と共通レイアウトの最新版

**[構図と文字のバランス・変更前後](../polish/README.md)**

名前・本文・操作の大きさを整理し、操作は右上の見出し段へ接続。通常表示の窓幅1216px・高さ224px、本文上64px・左100px／右92px。本文30px／名前24px（青い窓26px）／操作16px。本文2行・本心・▼と操作を分離し、名前札と操作の高さを各原画の上辺に合わせています。

16はP5を参考に画像生成から再制作。黒い吹き出し・太い白縁・紫の下紙・網点、名前札と操作欄が一体の原画です。地の文には名前札と人物向けの尾を外した別原画を使用。11と紫版は名前を本文左端に合わせ、本文より控えめな大きさへ。新しい動きは追加しません。
