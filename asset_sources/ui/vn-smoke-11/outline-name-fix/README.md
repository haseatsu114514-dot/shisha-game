# 16・11と共通レイアウトの最新版

2026-10-24 追加指示「文字と枠が重なる」「右下のSKIPなどと▼が重なる」「操作は全部右上」「窓を横へ」「16はP5の紫版のように、形を凝りたい」を反映。

通常表示は窓幅1120→1216px、高さ208px。本文を左100px／右84px・上36pxの安全領域に置き、2行の字面・本心と名前／操作／▼を分離。操作バーは窓の12px上に右寄せ、次送りは窓の右下。選択肢は操作バーの上に16pxを空ける。2画面表示でも操作バーを背景側の右上へ移動し、本文・▼と分離する。

16は黒と紫の非対称な面、太い影、折り返し、網点、細い切り込みと傾いた名前札を `remake/img/ui/vn-lounge/cut-paper-rebel.svg` とCSSで実装。中央は読みやすい墨色の面を残す。P5のロゴ・素材は使用せず、追加指示に基づく独自のUI。旧 `cut-paper-traced.svg` は以前の形の記録として残し、現行表示には使用しない。

11と紫版は名前の背後だけを暗くし、左寄せ・横罫・光点を維持。新しい動きは追加しない。長い名前の縮小判定も名前札内側の余白を差し引くよう修正。
