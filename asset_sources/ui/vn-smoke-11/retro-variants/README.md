# 静止画の会話ウインドウ・レトロ案4種

オーナー「90年代とか平成のエロゲ風」「ユニークなのも」「全部動くUIな必要はない」。年代の意匠を使った創作の比較案で、特定作品・OSの画面をそのまま模写したものではない。

同じひよりの会話・背景を実参照して、窓の形・色・文字組み・操作の見せ方を変えた。4案とも**静止画**。文字とボタンを含むデザインモックで、UI選択への追加や本編の採用はまだ行っていない。生成により人物・背景に微細な再描画があり、窓以外が画素単位で完全固定された比較ではない。

## 追加指示（2026-10-24）

動くUIの追加制作は保留し、静止画の原案を優先。初期UIは2種類程度、残りは後々シーシャくじで解放する方針（初期の組み合わせ・景品配分は未定、解放制は未実装）。

各UIの本文は**2行まで**収まる設計にする。現状の原案は1行の見本であり、2行版は未制作。名前欄・操作ボタン・次送りとの重なりを避け、各案の縁・レース・立体枠を残して本文の余白を確保する。

### 書体の方向（追加要望・未確定）

UIごとに書体も変えて比較する。R1は日本語ドット体、R2は当時風の角ゴシック、R3は柔らかい明朝、R4は等幅ゴシックが候補。実際の日本語フォントで2行分の字幅と行間を検証する。上の生成原画の文字は実フォントを組版したものではなく、正式な書体の導入・採用は未実施。

## 選定後に守ること

- モックをそのまま背景に貼って二重の文字・ボタンを作らず、窓・名前札・ボタンの素材と実際の文字/入力を分離する。
- 特にPC-98風は角の段差と罫線、平成青は銀縁と光沢、桜色は不透明な紙と細いレース、デスクトップは立体的なハイライト/影の方向を守る。単純な四角へ省略しない。
- 当時らしさのために本文を読みにくくしたり、セーブ/ログ/タッチ領域を失わせたりしない。
- デスクトップ案の閉じる・最小化風の絵はモック上の意匠。ゲームの終了や進行を勝手に割り当てない。
- この4案にはアニメーションを付けない。11の外周光試作と独立して選べる前提。
