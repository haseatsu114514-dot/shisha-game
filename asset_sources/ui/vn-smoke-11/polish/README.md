## 参照と設計判断

参照先は [P5R公式](https://persona.atlus.com/p5r/)、[P5Rの公開会話画面](https://www.engadget.com/2020-03-31-persona-5-royal-new-game-plus-review.html)、[ATRI公式](https://atri-mdm.com/)・[公式Steamページ](https://store.steampowered.com/app/1230140/ATRI_My_Dear_Moments/)、[Summer Pockets RB公式ギャラリー](https://key.visualarts.gr.jp/summer_rb/gallery.html)・[公式Steamページ](https://store.steampowered.com/app/3418570/Summer_Pockets_REFLECTION_BLUE/)。参照画像を本ゲームの配信素材にコピーせず、以下は本ゲーム向けの組版判断として実装しています。

- **窓の一体感**：操作を窓の見出し段に接続し、名前と操作の中心線を合わせる。素材ごとの見える上辺に合わせ、単に全テーマを同じ絶対Y座標へ並べない。
- **読む順序**：本文30px／名前24px（青い窓26px）／操作16px。名前を本文と同じ強さで競わせない。本文行高45px、本心22px・行高33px。数値は1280×720の本ゲームの論理解像度に対する値です。
- **読みやすい面**：窓幅1216px、高さ224px、本文の上64px・左100px・右92pxを確保。操作の44px領域と本文2行、本心、▼の字面を分離。
- **素材の個性**：青い窓は名前と操作を枠内へ。11は名前を本文左端に揃え、操作を墨色のまとまった見出しへ。紙・琥珀の名前札は文字数に応じて幅を調整。従来の金枠は金の操作枠を維持。

## 16を画像生成から再制作

P5の会話UIを参考に、黒い吹き出し・太い白の不規則な縁・紫の下紙・網点・斜めの名前札を一体の画像として生成しました。右上の操作欄も同じ原画内に接続されており、別の棒を浮かせて置く構成をやめています。

地の文／心の声には、名前札と人物へ向かう尾を取り除いた別原画を生成。空白の名前札を残さず、操作欄と本文の形を保ちます。原画・プロンプト・切り出し座標・ハッシュは `generation.json`。名前・本文・操作文字はHTMLであり画像への焼き込みではありません。画像の原画には文字やロゴを入れていません。

## 検証

実Chromiumで全6テーマと青い窓4キャラを1280×768／844×438で検査。実際の本文2行・本心・名前／操作／▼の非重複、字面の収まり、名前と操作の見出し配置、文字サイズの階層、選択肢、44px操作領域、保存不変を確認。従来枠の通常送り・AUTO／SKIP・LOG・用語・地の文・心の声はPC／横持ちで成功。2画面PC／スマホの表示切替・実選択も成功。共通の可読域検査や失敗判定は変更していません。
