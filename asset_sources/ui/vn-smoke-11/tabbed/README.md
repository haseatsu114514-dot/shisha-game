## 前回の違和感と今回の判断

前回は見出しを本文の中に入れたため、248pxの窓に加えて煙や紙が上へ張り出し、キャラの腰と店内を広く隠していました。罫線で横一列を区切る構成も、会話を読む窓より設定パネルに近い印象でした。名前の所在と操作のクリック範囲を探す必要がありました。

| テーマ | 実画面で目立った点 | 今回の構成 |
| --- | --- | --- |
| 11 煙 | 上下に膨らむ煙と見出し段で、窓が大きく見える。名前の背景が曖昧 | 低い煙の本文面と、淡い縁の墨色の札。原画の上辺がたわむ位置まで札を下げて接続 |
| 11 紫 | 明るい輪郭の面積が大きく、人物より手前で強く目立つ | 窓を低くし、紫の札と本文の間隔を整理。煙の原画と光の細部は保つ |
| 16 紙 | 紙の厚みと本文内の見出しが重なり、重いカードに見える | 柔らかな紙の本文面に、墨紫の小さな札。本文は明朝、上下の空間を縮めて人物を見せる |
| 25 琥珀 | 原画の上側に透明な余白があり、座標だけ揃えると札が浮く | 原画の実際の金の縁へ札を合わせる。琥珀色の縁・茶色の面・明朝を揃える |
| 28 薄紙 | 本文内の小さいラベルが紙の個性に馴染まず、全体が厚い | 外側の生成りの紙と同色の札に濃い文字。本文は炭色の不透明な面で読みやすく保つ |
| 従来の金枠 | 装飾の多い本文枠に対し、名前と操作が内側に埋もれる | 同じ原画の金の装飾で札を作り、本文の上辺へ重ねる。本文は明朝で統一 |

今回の基準は、人物を見せる面積、2行を追いやすい余白、誰の台詞かが分かる名前札、見つけやすい操作枠、会話状態で動かない操作位置、昼夜での可読性です。画面全体と原寸の両方で確認しています。

## 配置と文字

1280×720の論理画面で、本文窓は標準幅1216px・高さ176px、画面下16px。煙の2種類は幅1240px・左右112pxの余白、ほかは左右96px。上44pxを取ります。下側の空間を詰めながら本文2行の領域は維持しています。本文28px・行高44pxで2行、本心22px・行高31pxです。

名前札と操作枠は高さ50px。通常は本文上端より36px上へ出し、名前札は下14pxを重ね、操作枠は8px上げて下6pxを重ねます。11／紫版は原画の低くたわむ上辺に合わせて16px下げます。名前札の幅は実際の文字幅に合わせ、最小168px・最大272px。短い名前と英字名で無駄に広がらず、長い名前は字面を測って収めます。

名前22px、操作17px。操作は356px・4等分、各操作は44px高。本文・本心・地の文・主人公の心の声・選択肢でも同じ位置で、AUTO／SKIPの印も文字を押しません。▼は右下へ離します。素材ごとに上辺の位置を調整し、内容によっては変更しません。25と従来の金枠は操作を32px右、名前を32px左へ寄せています。

11／紫版・28の本文はZen Kaku Gothic New、16・25・金枠はZen Old Mincho Regular。既存の同梱書体を使い、ライセンスは `remake/fonts/OFL-ZenKakuGothicNew.txt` と `OFL-ZenOldMincho.txt`。会話を組む前に本文と名前の書体・選択中の枠を読み込み、初回だけ代替フォントで改行したり枠が遅れて出たりすることを防ぎます。

## 実際に切り替えて確認

[会話プレビュー](../../../../remake/conversation-preview.html)では、6テーマ、2行本文・本心・地の文・選択肢、キャラ、Eden／となり・昼／街・夜を切り替えられます。書体を変えたときは選んだ場面を再表示します。プレビューはセーブや設定を書き込みません。青い平成ADV窓も同じ上辺の構成に合わせた比較用です。

16の紙は本文と本心の領域に不透明な墨紫の面を重ね、植物模様が文字に重ならないようにしています。紙の縁と外側の装飾は残します。

## 検証

全6テーマを1280×768／844×438で検査。文字の収まり、名前・本文・操作・▼の非重複に加え、**札のすぐ下に原画が実際に描かれているかを画像のalphaで検査**しています。CSSの箱だけが近く、透明な余白で浮く状態を見落とさないためです。

通常・2行・地の文・心の声・本心・選択肢・AUTOの切替で、操作セルとラベルの実座標を比較。フォント配信を保留する検査では、読み込み前に本文を表示せず、読み込み後に選択した書体で組むことを確認。昼夜背景の切替と保存不変も確認しています。

PC／横持ちのAUTO・SKIP・LOG・用語、ひよりの本心・長文・進行・保存、通知と12ページの会話、2画面PC／タッチの実選択に成功。先読み済み会話が枠を再取得しない検査と、占いのヒントの赤がテーマに消されない検査も成功。温度演出の既存検査は再実行で成功し、その実装・判定は変更していません。

原画の差し替えや簡略化は行わず、既存のPNG／WebP／SVGの素材と文字・札の構成を使います。前回のPNGは `before/` に保持し、同じ背景・人物・台詞で比較しています。
