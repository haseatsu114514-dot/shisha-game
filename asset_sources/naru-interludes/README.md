# なるの章間カットとスチル

2章の対峙後、店をしばらく休業して行き先を告げず修行へ出たなるを、読者だけに見せる。3章でははじめの全国大会準備と並行して、なるも別ルートを勝ち上がる。

| 原画 | 配信元PNG | 接続先 |
| --- | --- | --- |
| `after-hours-source.png` | `assets/cgs/cg_naru_after_hours.png` | `ch2_naru_window` の両分岐後。海沿いの借りた作業場で練習を記録 |
| `next-entry-source.png` | `assets/cgs/cg_naru_next_entry.png` | `ch3_naru_work` / `ch3_tournament_eve`。別会場の予選控室 |
| `last-chance-source.png` | `assets/cgs/cg_naru_last_chance.png` | `ch3_national_result`。同日の夕方に第二代表決定 |

生成は `image_gen.imagegen`。指示と参照は `generation.json`。正規なる立ち絵を本人性の基準とする。修行と予選の画像は、自分の店の緑壁・営業風景から、旅先の借りた作業場・地方ホールの控え通路へ修正した。顔、髪、目、衣装、手、鞄、ノート、横長構図を原画で目視確認。喫煙・シーシャ機材を写さない場面に限定。外部の製品画像・ロゴ・ストック素材は不使用。

PNGを原画からそのままコピーし、`build_manifest.py --cgs-only` で本編用WebPと目録を生成。既存の `show_cg` / `hide_cg` と閲覧済みギャラリーを使う。追加カットは能力・好感度・主人公の勝敗を変更しない。地域大会は第3章DAY7、代表決定大会ははじめの全国大会と同日の夕方。はじめには翌日の連絡まで結果を明かさず、なるが東京の客席にいた描写もしない。第4章冒頭は第二代表としての再登場のみ。第4章本編の接続は既存どおり未実装。5章には追加しない。

旧原画と旧指示はこのブランチの先行コミット `8639d0ef4` に保存済み。画像IDは閲覧記録の互換性のため維持する。
