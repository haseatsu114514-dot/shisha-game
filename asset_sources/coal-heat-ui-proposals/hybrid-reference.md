## 修正方針

1. **炭の質感**：形の揃った圧縮角炭、細かい粒、浅い自然なひび・灰の膜へ変更。焼け頃は大きな黒い面を消し、白〜灰色の表面と赤い熾きを共存させる。生の炭の黒さは開始時の説明に限る。
2. **ゲーム用の合図**：Bの角括弧・番号・「今」を取り込む。物理的な白熱の穴・溶岩の噴出でジャストを表現しない。短い光は判定に同期するゲーム上の合図で、実物の炭が一瞬だけ光る現象だとは扱わない。
3. **回収先**：仕切り付きトレーを一つの炭壺へ置換。取った炭は同じ壺の中に入る。壺の横に「炭壺 0/3 → 1/3」のような回収数を置く。3つの収納枠・番号付きポケットを作らない。
4. **結果**：各炭の評価と早い／遅い誤差は小さなテキストの記録へ分ける。収納区画で評価を表現せず、まだ焼いている炭に重ねない。
5. **構成**：Aの寄り画・暗い赤のコイル・既存のはじめの作業風景を使い、Bの見やすい当たり領域を加える。炭壺とトングが操作する炭を覆わない。

## 炭の状態の描き分け

| ゲームの段階 | 描画の基準 |
|---|---|
| 開始時 | マットな黒い圧縮炭。赤熱・灰はまだほとんどない。 |
| 加熱途中 | 下側から赤熱と薄い灰が広がる。黒い部分はまだ火が回っていない箇所として描く。 |
| 焼け頃／ジャスト | 見える各面に薄い明るい灰と赤い熾き。大きな未着火の黒い面は残さない。「今」のUIが取る瞬間を示す。 |

## 目視確認する項目

- 焼け頃の炭が、白〜灰色の薄い灰と赤い熾きの両方を持つ。
- 焼け頃に大きな冷たい黒い面、溶岩の割れ目、爆ぜる火の粉、白い火口を描かない。
- 細かな灰の粒と圧縮された面があり、巨大な自然岩ではない。
- 炭壺が一つの深い金属容器で、取っ手と台座がつながる。仕切り・三つの収納枠はない。
- 取る前3個＋壺0個、回収後2個＋壺1個で、炭の個数が対応する。
- はじめの顔・帽子・服、工程HUD、静かなコイルを維持する。
- 原画は構図案。本編操作・採点・時計・炭壺のアニメーションは未接続。
