# 大会の競技規則・紙面

`rule-paper-source.png` は内蔵 `image_gen.imagegen` で制作した原画。紙の繊維、細い真鍮色の罫線、隅の煙の模様だけを描き、文字・数字・ロゴは入れていない。ゲーム用の同一画像を `assets/ui/tournament-rules/rule-paper.png` に保存した。

条文は `remake/js/scenes/rule-sheet.js` のHTMLで表示し、課題フレーバーと持ち込み・支給の区別は現行の `remake/js/craft/steps.js` の規則を参照する。画像中の模様は架空の装飾であり、実在の団体・製品の印章を使わない。

生成指示: 「日本のビジュアルノベル用、大会規則の縦長の象牙色の紙。細い左右対称の墨色と真鍮色の縁取り、隅に薄い幾何学的な煙模様、中央はHTML文字を重ねるため広い無地。文字、数字、ロゴ、人物、器具、背景の部屋は描かない」。
