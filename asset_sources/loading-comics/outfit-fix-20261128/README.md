登録中の69話（138コマ）を、新バージョンの立ち絵（`remake/img/sprites/character_variants/new/`）と1コマずつ見比べた。旧い設定のまま描かれていた人と、直したコマ:

ピアス・ネックレスがある人（凛想の銀のフープと小さなタグ、ひよりの金の耳飾り、あげはのチョーカーとハート、みんとの緑のハートのチョーカー、つむぎの小さなピアス）は、立ち絵と合っていた。

**修正の跡**: `restored-39-2`（『少しだけ』）の左上は、2026-11-12 に紙面の切れ端を消した跡（ぼやけ）が目立っていたので描き直した。`restored-33`（『対策本部』）は2コマ目の「本人」の札の矢印が上下両方に生えていたので、ましろを指す1本にした。どちらの話も元の紙面が小さかった（1コマ幅 454〜570px）ので、2コマとも同じ解像度で描き直してそろえた。`restored-21`（『苦手なもの』）の左上の跡は、ゲームの大きさでは目立たないので触っていない。

## 作り方

`fix.py`。OpenAI の画像生成API（`images/edits`、モデル `gpt-image-2.6-sunburst`、1536×1024、品質 high）に、今のコマと直す人の立ち絵を渡し、「書いた変更だけをして、吹き出しの日本語・構図・背景・ほかの人物はそのまま」と指示した（指示の全文は `prompts/<コマ>.txt`）。範囲指定（マスク）は使っていない（スチルの時に、範囲の外まで描き直されたため）。各コマ1回で、20コマとも採用した。

- 原画: `originals/<コマ>.webp`（1536×1024・生成のPNGを変換しただけ）
- ゲームの絵: `remake/img/loading/<コマ>.webp` を 1440×960 に縮めて差し替え（`tools/loading_comic_cut.py check` で20コマとも OK・3:2・400 KiB 以下）
- 直す前の絵は git の履歴に残っている（この PR の一つ前のコミット）

検品: 20コマとも、直す前と並べて、吹き出しの文字が一字も変わっていないこと・直した人の顔と表情・ほかの人と背景が変わっていないことを見た。`node remake/test/loading_comics_spec.mjs` は PASS。説明文（alt）は `restored-15-1` の「帽子を目深にかぶった」を「茶色の帽子とスーツの」に直した。
