# 全キャラ参戦 — 2コマ漫画の台本（34話・2026-11-02）

オーナー「今キャラが限られてるから全キャラ参戦させたい」「会ったキャラの漫画が開放される感じでロードで出る」。採用25話に漫画のない17人に、1人2案ずつ台本を用意した。Codex で描いてから選別ページで選び、採用した話を登録する。

- 規則: [../README.md](../README.md) §2（①導入→②オチ・2人まで・台詞3つ・各12字以内・先に話す方の吹き出しを左か上）、§10（`cast` と解放）。
- 中身は番外編のギャグ。本編の能力・設定・大会結果は変えない。正体や裏の顔（博士の裏ボス、ヴォルクの偵察、シェイクの旅装の素性など）は、会った後でも明かさない範囲にとどめた。シェイクの『旅の人』は正体を知った後の笑いなので `minChapter: 4`、SHISHA-9000 は `minChapter: 5`。
- シーシャ台・ハガル・HMD・炭・ホース・喫煙・煙は描かない（器具の描写ぶれを避ける。過去の候補と同じ）。
- 台本の構造化データは [scripts.json](scripts.json)、Codex に貼るプロンプトは [prompts.md](prompts.md)（1話1ブロック）。

## 登録するときの注意

- **サラリーマン**: ゲームの「会った」記録（`state.met`）に入らない（名乗らない常連で、登場カットインもない）。第1章の冒頭 `ch1_opening` に必ず出るので、登録するときに `core/title-art-unlock.js` の `EXTRA_MET_SIGNALS` に `salaryman: (s) => !!s.flags?._ch1_opening` を足す（冒頭を読んだ記録＝実際に会った既存記録）。足さないとこの2話は出ない。
- **てつこ**（mukai の猫）: 「会った」記録がないので `cast` には入れず、ヨルの『裏口の主』に出演させた（`cast` はヨル）。
- ほかの16人は、登場カットインか既存の `markMet` で会った記録が付く（王煙楼・シェイク・太陽・SHISHA-9000・パッキー・マキ・ヨルはカットイン、ほかは大会や章の紹介）。
