# LDC24 #021「タイマーの数」— 候補原画・同executor保存試験

未制作候補を1回生成し、同じ既存ゲームexecutorの正式ローカル出力を、無加工で候補専用branchに保存する技術実証です。採用・本編登録・配信用画像の生成・Ready化・mergeは対象外です。

次の50話に数える1話であり、この1話だけの採否は求めません。既制作45話を再生成していません。

- `original.png`: image_genが出力した原画。再エンコードなし。
- `prompt.txt`: 実際に渡したプロンプト全文。
- `provenance.json`: 正本台本・参照SHA・生成来歴。参照画像の実体は同梱しません。
- `QA.md`: 合格点・制作上の不適合・未実施。
- `cut-dry-run.txt`: 既存切出しツールの書込みなし診断結果。派生画像や登録データは作成していません。

**漫画制作QAは未合格です。** 枠下端が下敷きより37px低く、右コマの下縁でタイマー等の一部が切れます。原画を採用素材として使わず、QA記録付きの比較候補として扱ってください。
