# QA — 技術経路の検証と漫画の採用判定を分ける

## 実施済み

- 必須参照4点のSHA-256、実寸、完全デコードを確認し、すべて目視後に添付。下敷き1536×1024、はじめ/スティーブnormal 896×1200 RGBA、店背景1280×720 RGB。
- 生成ツールが示した同executorのPNGを読み取り確認。1536×1024 RGB、1,813,689 bytes。コピー前後のSHA一致。原画の再エンコードなし。
- 目視: 両コマではじめが左・Steveが右。黒いキャップ/パーカー、髭・眼鏡・柄シャツ/エプロンは参照と整合。左の手のひらにタイマー3個、右は数十個の視覚オチ。
- 目視: 台詞は「タイマー、何個？」「ヘイ、三つだけ。」「三つじゃない！」と読め、左上→右下の吹き出し順。画像だけからUnicodeコードポイントの同一性を証明したわけではありません。
- 目視: 題名・話数・署名・透かし・可読英語や余計な擬音は未検出。炭・シーシャ器具・ホース・煙は未検出。
- 既存 loading_comic_cut.py sheet --dry-run はexit 0。検出領域は左715×511・右714×511、比率1.399/1.397。3:2化には左右各3.3/3.4%の紙帯が必要との診断。実際の補正/切出しは未実施。

## 不適合・留保（未採用）

- 枠の暗色横線: 下敷きは上269–271/下752–754、出力は上269–271/下789–791。下端が37px低く、枠720×480を固定する指示に不一致。キャンバス寸法の一致と、コマ枠の一致を混同しない。
- 右コマ下縁で胴・タイマーの一部が切れる。全重要物の4%安全域や、完全な全身表示は合格としない。
- 枠外の紙色にも質感/色むらがあり、完全な単色固定の確認は合格としない。
- 185話scripts.jsonはminChapter=1、同READMEの一覧は第3章。留保として記録し、解放条件を変更していない。

## 設定監査の留保

一時global configへの公式初期化直後は、元global設定のmetadata不変を確認。後段のcommit前監査ではmtimeのみの変化を検出した（size/inode/device/modeは同じ）。書き手/原因は未確認で、試験全期間のmetadata不変とは扱わない。元globalへの書込みコマンドや値の表示/コピーは行わず、一時configからread-only includeを保持した。
