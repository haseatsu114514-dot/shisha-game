## 解放と採用前の確認

新規6話は `minChapter: 4`、`cast: ["saif"]` または `["rashid"]`。ヌールも登録時は第4章以降かつ面識確認を必要とする。名乗る場面の `_met_saif/_met_rashid` はVNエンジンのset_flag処理で面識記録へ反映され、既存hasMetCharacterで判定できる。今回、実装やフラグは追加しない。
