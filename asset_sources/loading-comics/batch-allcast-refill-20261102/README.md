## 前回の選別から分かったこと（台本の狙い）

前回の34話は、採用4話・保留2話・没28話だった。採用の4話はどれも、②の絵が①から大きく変わり、絵だけでオチが分かる。

- 『休憩もフェスタ』: 騒ぎが大爆発する
- 『会長の名刺』: 威厳のある人と、庶民的な物とのギャップ
- 『旅の人』: 隠していた正体が見える
- 『ライチの皮』: 達人の技で、むいた量が山になる

没には、言葉や設定の知識が要るオチと、変化の小さい静かなオチが多かった（Claude の推測。オーナーの理由ではない）。今回の台本はどれも、②のオチの物や変化をコマの中央に大きく置いた。1キャラの5案は、全部ちがう型にした。
