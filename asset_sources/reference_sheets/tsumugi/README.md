# つむぎ｜画像生成向けリファレンスシート

このディレクトリの4つの横長PNGは、現在ゲームで採用されている**正規の画像をそのまま**レイアウトしたものです。人物の顔・髪・衣装・体格・塗りを新しい解釈で描き直していません。

- `01-5-directions.png`：**全身5方向**。正面／真横／背面／斜め前／斜め後ろ。実在する歩行スプライト72pxのAコマを共通倍率で拡大。**高精細な新規三面図ではありません**。
- `02-expressions.png`：**全身の表情6枠＋顔拡大**。通常／微笑み／喜び（参考）／真剣／驚き／困り顔。正規の通常・笑顔・会釈・真剣・驚き・悲しみを使用。「喜び」は専用素材がないため、会釈の笑顔を代用。困り顔には採用済みの悲しみを使用。
- `03-face-hair-parts.png`：**顔の正面・真横・斜め45度、目・眉・鼻・口の拡大**。正面は現行高精細PNG、残り2方向は既存歩行素材からの拡大で、解像度の違いを明記。
- `04-outfit-palette.png`：**衣装・持ち物・髪の拡大とパレット**。正規立ち絵の切り出しのみ。パレットは画像内のピクセルから外見設定の目標色に近い実在色を選ぶ近似スポイトで、厳密な指定色とは限らない。

## 絶対に維持する外見

元の正規立ち絵の **短く丸みのある暖色ダークブラウンのボブ**（双つ結び・ポニーテール禁止）、柔らかく分かれた前髪、頬を囲む横髪、赤みのある茶色の瞳、穏やかな大人の顔。小ぶりの耳のピアス。パーカーは **深い紫のオーバーサイズのジップアップ**、フード・淡い紐・袖と胸の花や葉の細かな刺繍を維持。黒い短いプリーツスカート、チャコールのひざ下靴下、黒い厚底寄りの紐靴。絵を描く暗色タブレットの端の小さなヒビ／傷と、細い白いスタイラス。無根拠な髪飾りやヘッドホンは足さない。

画風は高精細な微細ドット質感のビジュアルノベル立ち絵。元画像の顔立ち・頭身・肩幅・胴脚バランスを基準にし、美化や一般的な美少女顔への置換をしない。

## 補完デザインとして扱う範囲

現在の原画セットだけでは **高精細な真横・背面・斜め前後の全身立ち絵、真横と45度の高精細顔、後ろ身頃の刺繍の細部、独立した「喜び」の表情** は確定できません。方向シートはゲームの歩行用素材に見える形だけを証拠にします。これらを新規生成する時は **「補完デザイン」** と明記し、正規立ち絵との差分をレビューしてください。元画像から確定できない身長・装飾・素材は設定として書き足さないでください。

```sh
python3 tools/render_tsumugi_reference.py
```
