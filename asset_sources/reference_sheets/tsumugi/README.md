# つむぎ｜画像生成用リファレンス（正規立ち絵のみ）

**歩行用の小さなドット絵は一切含めない。** 正規ゲーム立ち絵PNGの顔・体型・髪・衣装・画風を変えずに整理した横長PNG 3枚です。

- `01-expressions.png`：公式立ち絵6枠の**全身と表情・拡大顔**。通常／微笑み／喜び（参考）／真剣／驚き／困り顔。喜びは独立した立ち絵がないため既存の会釈と穏やかな笑顔で代用し、困り顔は既存の悲しみを参考表示。
- `02-face-hair-parts.png`：**正規立ち絵3表情の顔拡大（すべて正面）**、目／眉／鼻／口。横・45度を低解像度の歩行絵で代用しない。
- `03-outfit-palette.png`：**衣装・持ち物・髪の拡大とカラーパレット**。正規立ち絵の切り出しのみ。パレットは元画像に実在するピクセルを用いた近似色の参考表示（公式HEX値の確定ではない）。

## 絶対に維持する外見

正規立ち絵の**短く丸い暖色ダークブラウンのボブ**（双つ結び・ポニーテール禁止）、柔らかく分かれた前髪、頬を囲む横髪、赤みのある茶色の瞳、穏やかな大人の顔。小さな耳のピアス。深い紫のオーバーサイズのジップアップパーカー、淡い紐、袖と胸の細かな花・葉の刺繍。黒い短いプリーツスカート、チャコールのひざ下靴下、黒い厚底寄りの紐靴。暗い色の絵描き用タブレットの小さな傷と白いスタイラス。髪飾り・ヘッドホンは新設しない。

**画風：** 元の高精細で繊細なピクセル調のビジュアルノベル立ち絵。新しい描き起こしで目・輪郭・頭身・衣装を美化・変更しない。

## 未制作（補完デザイン）

高精細の**全身5方向（真横・背面・斜め前後）、顔の真横と45度、後ろ身頃の刺繍の細部、独立した喜び表情**は、現在の立ち絵から確定できません。今後これらを生成する場合は「補完デザイン」と明記し、正規画像を直接参照したうえで、人物が一致するか個別に確認してください。

歩行ドット絵や旧テキスト設定の「黒髪・ヘッドホン」は新規生成の参照として使わず、現行の正規立ち絵を優先します。

## ファイル・再生成

```sh
python3 tools/render_tsumugi_reference.py
```

- **第一参照**：`assets/sprites/characters/tsumugi/chr_tsumugi_normal.png`
- **表情参照**：`assets/sprites/characters/tsumugi/chr_tsumugi_{smile,serious,surprise,sad,bow}.png`
- **外見ルール**：`.claude/skills/character-portrait-remaster/references/tsumugi-v1-prompt.txt`
- **出典・参考パレット・未確定事項**：`manifest.json`

この3シートは全てゲームの正規立ち絵PNGから作成。ドット歩行スプライトの画像は参照にも配置にも含めていません。
