## 生成条件と検品

生成は Codex 組み込み画像生成のみ。前回候補・実在背景・既存CG・はじめと博士の正規立ち絵を役割付きで渡した。まず投票場面を再生成し、HMDとボウルトップをより低く小さくする一度の修正を加えた。完成・提供済みのシーシャ台として、細いステンレスステム、透明ガラスベース、小さい黒色ボウル、低いロータス型金属HMD、HMD内の小さい角炭2個、側面ポートから1本のホースを指定した。画像に文字・UI・ロゴは入れない指示とした。

- 原寸目視：清潔な白衣、投票の挙手、主人公たち数人・審査役・客、夕方の SMOKE LAB、控えめな植物を確認。
- 機材拡大目視：ボウルと低い金属HMDは別部品として読める。炭2個はHMD上部の浅い金属受けの内側に収まり、直炭や炎は見当たらない。ボウル→受け皿→ステム→ガラスベースが縦に連続し、ホースは側面ポートから硬いハンドルまで1本で追える。水はベース下部に限定される。
- 縮尺：上部のボウル＋HMD＋炭は台全体の約2割、人物の顔の半分以下。HMDの幅は受け皿の半分以下。台は人物の近くの卓上にあり、過度な接写ではない。
- ファイル形式・解像度・SHA-256 を確認。採用可否は司令塔の実ファイル検品とオーナー判断待ち。
