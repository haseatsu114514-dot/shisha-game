名前はNoto Sans JPの極太を前傾・凝縮し、帯と同じ角度で配置。本名の括弧は呼び名のすぐ後ろへ小さく添え、同じ行で読む形にした。二つ名の上には英語もラベルも置かず、下段の一言は正本のまま残している。白い斜め帯、黒い名前、色と図形の背景を共通化した。以前の人物PNGは拡縮と位置調整だけで重ね、描き直し・色フィルターは使わない。

追加指示により、全14枠を並べて配色を見直した。パッキーは橙、あげははピンク。はじめをクリーム、スミさんを銅色、前園を深い青緑にし、黄・橙の重複も減らした。つむぎはラベンダー、凛は藍色。星・きらめき図形は全て廃止し、衣装・小物・好きな味・作品から本人の象徴をベクターで描いた。大きな象徴と同じ小柄を背景全体へ展開している。はじめ・つむぎ・スミさんは前案より36px左へ移動した。

背景品質の追加指示があったアダム・つむぎ・あげは・みんと・サメちゃん・なるは、薄い線画を廃して幾何学版を作り直した。太い同心円、斜線、格子、チェック、波の反復を大きく構成し、本人の象徴は塗りのある専用SVGで載せている。この6人の幾何学背景も比較用に残す。アダムは左の緑の青りんご、右の赤りんごに揃えた。りんごはオーナー指定の視覚的象徴であり、ダブルアップルの味の設定を変えない。

比較提示後、オーナー「イラストでかつキャラの後ろが暗いのいい感じ」「このイラスト方向性でいきたい」により、主案をイラストへ切り替え、残りの8枠も専用背景を制作して全14枠を揃えた。人物の背面は、それぞれの色相を保った高彩度の専用暗色。濁った色に見えるとの指示を受け、背景全体の一律減光を外し、右上の原画の色をそのまま見せている。二つ名は白字と暗い下地。一言は38pxへ拡大し、長文は意味の切れ目で最大二行。台詞下の暗い面にはイラストを薄く透かし、人物だけがくっきり見える配置にした。全14枠ともイラストが初期表示で、幾何学へ切り替えて比較できる。原画と生成指示は [backgrounds/generation.json](backgrounds/generation.json) に記録。左右逆だったアダムの初期原画も未使用履歴として残している。

## 範囲と正本

現行第一章の立ち絵がある人物に、主人公の前回案と私服の「お姉さん」を含む14表示枠。お姉さんとみんとは同じ人物の別表示であり、新キャラを追加していない。名前を明かさないモブ・未制作の零の顔見せは新規人物画像を作らず、今回は紹介素材の対象にしない。

あげははDAY4の顔見せに登場するが、名乗る前は正体を伏せる。ここでは名乗り後の紹介候補として一枚保存し、DAY4の場面へ接続しない。本名を伏せるお姉さん・みんと・サメちゃんは小さな本名を表示しない。呼び名と本名が同じ人物には重複した括弧を付けない。

二つ名と一言は `data/characters.json` の `intro_cutin`、サメちゃんは `data/dialogue/kafuka.json` の `profile.intro_cutin`。はじめだけ前回のモックアップに保存した提示案を継承。全員の文言・表情・原画パス・SHA-256・背景柄は [characters.json](characters.json) に記録している。

はじめ・アダム・なる・博士・サメちゃんは前回v2の本人PNGを参照する。前園とパッキーは最新の再制作確認PNGを参照し、PR #225で本編にも採用済み。ほかは採用済みのゲームPNGを参照。原画はバイト一致・人物フィルターなし。今回の画像生成による博士の初期スタディは [未使用履歴](unused-generated/dr_kemuri/README.md) に保存し、最終版には使わない。

全14枚は1280×720。編集元は `index.html`・`style.css`・`preview.js`・`motifs.js`・`characters.json`。キャラ切替・もう一度・一時停止／再開・連続再生を備える。背景と帯→人物→二つ名と名前・本名→一言の順に約1.3秒で揃う。動きを減らす環境では静止表示。単体HTMLは外部リクエストなしで動く。

ゲーム本体・正本台詞・manifestは今回変更していない。素材を作る依頼として確認用PRへ保存する。

## 再生成

リポジトリのルートから、Pillowでメタデータを読み、ChromiumでUIを描画する。人物PNGの画素編集は行わない。

```bash
python3 asset_sources/character-intros/ch1-v3/build-data.py
node asset_sources/character-intros/ch1-v3/render-preview.cjs --video
```

Playwright・Chromium・FFmpegが必要。フォントの追加文字は [fonts/README.md](fonts/README.md) を参照。動画以外なら `--video` を省略。
