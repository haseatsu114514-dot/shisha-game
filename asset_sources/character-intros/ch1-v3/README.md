## 範囲と正本

現行第一章の立ち絵がある人物に、主人公の前回案と私服の「お姉さん」、アゲハ初遭遇版と第2章版を含む15表示枠。お姉さんとみんとは同じ人物の別表示であり、新キャラを追加していない。名前を明かさないモブ・未制作の零の顔見せは新規人物画像を作らず、今回は紹介素材の対象にしない。

アゲハ初遭遇はDAY4の買い出し帰りに落とした荷物を拾ってもらう場面用。名前は「？？？」、バイブスは開示しない。初回はsmile表情、第2章の紹介は最初の目を開いたnormal表情の独立した出力で、キャラ選択ボタンも分けた。現在の紹介は全員で呼び名だけを表示する。

全15枚は1280×720。編集元は `index.html`・`style.css`・`preview.js`・`motifs.js`・`characters.json`。キャラ切替・もう一度・一時停止／再開・連続再生を備える。背景と帯→人物→二つ名と呼び名→一言の順に約1.3秒で揃う。動きを減らす環境では静止表示。単体HTMLは外部リクエストなしで動く。

今回の追加指定でアゲハの紹介文・表情の正本と、ゲーム本体の括弧付き本名の表示も更新した。イラスト背景・新しい組版・アゲハ初遭遇演出のゲーム接続とmanifest更新は含まない。停止後の今回の修正をPR226へ保存し、マージは停止したまま。

## 再生成

リポジトリのルートから、Pillowでメタデータを読み、ChromiumでUIを描画する。人物PNGの画素編集は行わない。

```bash
python3 asset_sources/character-intros/ch1-v3/build-data.py
node asset_sources/character-intros/ch1-v3/render-preview.cjs --video
```

Playwright・Chromium・FFmpegが必要。フォントの追加文字は [fonts/README.md](fonts/README.md) を参照。動画以外なら `--video` を省略。
