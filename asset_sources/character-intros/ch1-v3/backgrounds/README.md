# イラスト背景の比較試作

採用候補の幾何学背景は `../motifs.js` のオリジナルSVG。ここには比較用に画像生成した背景原画を保存する。人物・名前帯・文言は原画に含めず、登場画面のHTMLで重ねている。

6人とも `source.png` が現行の比較原画。アダムは左が緑の青りんご、右が赤りんご。`adam/unused-order-study.png` は左右逆だった初期案で、表示へ接続していない。つむぎ・あげはの原画にも星やきらめきは使わない。

背景が人物より目立つという指示により、画面の合成では人物背面を暗い色面で整理し、画像濃度を80%に抑えた。二つ名は暗色の下地に白字、セリフは暗い下端へ置く。原画そのものは生成出力のバイトを維持する。

生成指示・実参照・未使用原画は `generation.json`、現行原画のSHA-256は `../characters.json`。人物PNGは従来の制作済み画像を参照し、画像生成やフィルターで変更しない。
