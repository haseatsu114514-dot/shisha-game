# イラスト背景の比較試作

主案のイラスト背景の原画を保存する。全14表示枠へ専用原画を制作。人物・名前帯・文言は原画に含めず、登場画面のHTMLで重ねている。比較用に残した幾何学背景は `../motifs.js` のオリジナルSVG。

各フォルダの `source.png` が現行の原画。アダムは左が緑の青りんご、右が赤りんご。`adam/unused-order-study.png` は左右逆だった初期案で、表示へ接続していない。あげは・凛を含め、星やきらめきは使わない。

背景が人物より目立つという指示により、画面の合成では人物背面を各色相を保った彩度のある暗色で整理した。全体の減光は濁りの原因になるため外して、右上の原画は鮮やかな色を維持する。二つ名は暗色の下地に白字。38pxのセリフは一～二行で、イラストが薄く透ける暗い下端へ置く。原画そのものは生成出力のバイトを維持する。

生成指示・実参照・未使用原画は `generation.json`、現行原画のSHA-256は `../characters.json`。人物PNGは従来の制作済み画像を参照し、画像生成やフィルターで変更しない。
