# キャラ別の登場カットイン v2（モックアップ）

オーナー「キャラごとに色を変えたりとか模様を入れたりとか個性を出していきたい」「アニメーションさせたい」「今はモックアップ段階」。旧v1の立ち絵と読みやすい名前の構成を引き継ぎ、5人に配色・模様・入る動きを加えた。

- [操作できる単体HTML](mockup.html)：ダウンロードして開く。フォント・立ち絵・コードを全て内包し、外部アセット不要。キャラ切替／もう一度／一時停止・再開／5人連続再生。
- [動きの動画](animation-preview.mp4)：5人を順に再生、音声なし。
- [5人の静止比較](comparison.png)
- [登場の順序](animation-sequence.png)
- [スマホ幅](mobile-preview.png)

| キャラ | 配色・模様 | 入る動き |
|---|---|---|
| はじめ | 琥珀色・クリーム＋煙の曲線・円 | やわらかく横から入る |
| アダム | 赤・緑の左右分割＋二重円 | 帯と立ち絵が短い時間で鋭く入る |
| なる | 黄・橙＋太い斜線・スピード線 | 模様が横に流れてから名前が出る |
| チャコール博士 | シアン・濃い青緑＋六角格子・折れ線グラフ | 背景が現れ、立ち絵・名前・一言が順に出る |
| サメちゃん | 海の青・水色＋波・牙・小さな十字 | 採用の青インナー立ち絵が少し弾んで入る |

背景・帯→立ち絵→二つ名・名前→本名→一言。約1.5秒で揃って表示を保つ。連続再生時は約3.9秒で次のキャラへ。動きを減らす設定ではアニメーションを省く。

## 立ち絵と文言

はじめ・アダム・なる・博士は[PR #206](https://github.com/haseatsu114514-dot/shisha-game/pull/206) のv1で使った再制作PNGをバイト一致でコピー。サメちゃんは今回ユーザー採用の黒髪＋濃い青インナー通常をバイト一致でコピー。全5枚にCSSフィルターなし。人物の再生成や描き直しなし。`characters.json` に元画像のハッシュと構図を保存。

大きい呼び名＋必要な場合だけ小さい本名、ふりがななし。サメちゃんは別名表示の設定に従い本名を出さない。二つ名・一言は現在の `intro_cutin` を優先。はじめだけ未登録のため、v1と同じ短い提示案。文章・キャラ設定・ゲーム台詞は変更していない。

## 再生成・検証

リポジトリのルートをHTTP配信し、このフォルダを開く。URL `?character=adam` でキャラ指定、`?video=1` で操作部を隠す。`node render-preview.cjs --video` で単体HTML、各静止画、スマホ確認、動画と検証記録を再作成。Playwright・Chromium・FFmpegが必要。

[検証記録](render-validation.json)：全5人の文字領域・PNG読み込み・フィルターなし、開始／途中／完了のアニメーション、切替／再実行／一時停止・再開／連続再生、390px幅の操作、動きを減らす設定、ブラウザエラー0。単体HTMLは管理環境でfile://表示が禁止されているためHTTPで開き、文書以外の外部リクエストを拒否して動作を確認した。

実際の会話エンジン・ゲームの初登場処理・manifestは変更していない。モックアップの確認後に実装へ移すための素材とコード。
