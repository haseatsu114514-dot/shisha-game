## 生成の参照と指示

Codex 組み込み画像生成を、各案1回ずつ使用。いずれの案でも参照画像に次の役割を明記した。

- 参照1：現行グラフィックカットイン（構図・顔立ち・絵柄・服装の正本）`remake/img/ui/character_intros/graphic/hajime.webp`

共通の画風固定指示：「現行グラフィック版の絵柄に厳密に一致させる。はじめの顔立ち、髪、黒い帽子と白い三本の湯気印、黒いフード付き服、白い紐、細長い首飾り、白い縁取りを厳密に維持。別人化・美化・装飾追加・衣装変更・色変更・質感変更は禁止。艶やグラデーションを増やさず、現行の平面的で鋭い黒白の陰影と線を維持。追加の文字や小物なし」。背景は完全透過と指定した。

- A 指示：参照1とほぼ同じ距離感、画面内位置、頭・肩・手のポーズ。
- B 指示：同じ距離感と配置を保ち、頭・視線・肩をわずかに動かし、画面右の手の指先を頬から顎の手前へ移す。
