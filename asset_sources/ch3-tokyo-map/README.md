# 第3章・東京の広域地図

高円寺・中野の高架と細い店の路地に、上野の動物園・池・公園を混ぜた架空の地区。
第1章の浅草、第2章の渋谷の街形を反復せず、シーシャ店を訪ねる東京編の地図として制作した。

## 採用画像と生成の記録

- `day-source.png` / `night-source.png` が採用原画。どちらも1672×941、不透明。`assets/backgrounds/bg_tokyo_map_day.png` / `_night.png` と同一bytes。
- `initial-not-adopted.png` は高円寺・中野寄りの最初の近景。`ueno-near-not-adopted.png` は動物園・池を足したが、まだ近く緑が多かった版。採用へ戻さない。
- 実際の生成指示を `prompt-initial.txt`、`prompt-ueno-wide.txt`、`prompt-overhead.txt`、`prompt-night.txt` に保持。最初は既存の `bg_osu_map_day.webp` を描画密度の参照だけに使用し、街形とランドマークは作り直した。
- 上野を混ぜる、動物園、全国会員のジム、より上から広く見る、緑を増やしすぎない、という追加指示を順に反映。
- 夜版は昼原画を直接参照し、地形・建物・動物園・池・ジム・カメラを保持して光を変更。暗い青の環境光と店の灯りを残し、動物園は閉園後の静かな描写とした。
- 配信はWebP昼約799KB／夜約651KB。第1・2章の背景は変更しない。

```sh
python3 remake/tools/build_manifest.py --backgrounds-only bg_tokyo_map_day.png bg_tokyo_map_night.png
```

## 街の見分け方とUI

左側を建物と舗装中心の街区にし、緑は右の動物園・公園へ集中。高架駅、給水塔、小劇場を転用したライブハウス、動物園の門と鳥舎、池と橋が目印。
mukaiは青灰の3階建てと外階段、Smoke & Gloryは赤煉瓦、鉄の煙は黒い工房、煙幕はえんじの庇、チョイザップは黄色とガラス張りの店舗で区別する。

名前・番号・現在の印は絵に焼き込まず、`ch3-map-model.js` の同じ百分率座標を昼夜へ重ねる。
現在の場面と既読の店だけを表示し、未訪問のライバル店や人物を先取りしない。公共ランドマークとジムは常時表示する。
実在の東京駅は地区の小さな高架駅と混同せず、地図外からの到着方向を「東京駅から」とする。
なるの別会場の場面を東京の店へ置かない。

行程カードの「東京の地図」は閲覧のみ。自由時間では、会員が利用できる枠に限って地図のジムから実際のトレーニングへ進む。
動物園と池は今回の景観ランドマークであり、入園・チケット購入・専用デートはまだ接続していない。

## 会員資格と自由時間

- 第1・2章の `_gym_member` を共有。東京で入会料・利用料を取り直さない。地元のみんと・なる等の遭遇台本は呼ばず、東京の無人店舗用の短い昼夜描写を使う。
- 未消化の既存自由時間だけを使い、一日一回。新規のジム枠は主筋の時刻と重なる枠を除き、恋人の約束を優先。既存の予約済みの枠は互換のため保持する。
- 正常読了後に基準体力−8（既存の根性補正）、施設の基本魅力2P（既存の章上限・振替あり）、実利用日のfit記録を一度だけ確定。本筋stageは進めない。
- 中断・取消・別セーブ・再読込では無消費／無成長。同じ枠・同じ日の繰り返しは付与しない。
- 「この時間は休む」は一枠を消化し、既存の自宅休養相当の体力＋55（最大体力まで）。能力・金銭は増やさない。
- 東京全体の病気・翌朝処理の新規実装は含まない。既存のfit形式を保持する。

## 検品と検証

- 原画の高い俯瞰、都市と緑の比率、昼夜での位置一致、動物園の囲い・池と道、4店とジムの識別を目視確認。
- 昼夜×PC1280×720／横持ち844×390で、画像デコード・16:9・画面内収容・全8ピンの非重複を確認。横持ちは地図を約552px幅まで広げた。
- 通常の地図開閉、Esc・Tab・元ボタンのフォーカス復帰、保存不変、画像失敗時の閉じる操作を確認。
- 本番LOAD経由で地図からジム利用→主筋復帰、既存会員の金額不変、実消耗・成長、利用日のfit、一度きりの枠消化、LOAD、中断、休養をPC・横持ちで確認。
- 旧・新ルート、主筋との時刻重複、予約優先、未訪問の店名非表示はunitでも検査。既存の東京訪問4ケースも成功。
- 背景待ち中に旧カードが残る競合を修正し、地図を閉じるだけのときはカードを再作成せずフォーカスを保持。

検証入口は `node remake/test/browser/ch3_map_activities.mjs`、`node remake/test/ch3_map.mjs`、`node --experimental-vm-modules remake/test/ch3_activities.mjs`。追加したbrowserケースは既存CIレジストリへ登録している。
