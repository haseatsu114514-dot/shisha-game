## ソファの焦げ跡

店内全景から、炭1個分（約2.5cm）の局所的な焦げ跡への接写へ。手と布を寸法の手掛かりにし、鎮火後として炎・赤熱を描かない。画像内で焦げが手幅より小さく、台詞が重なる下部より上にあることを目視確認。初稿の布目は正史の「革」と一致しなかったため、革の質感へ修正し、焦げ跡をさらに小さくした。原画の採用前比較として保存。

![焦げ跡の接写・革へ修正](sofa-leather-charcoal-closeup.png)

[布張りの初稿](sofa-charcoal-closeup.png)は履歴として保持。
