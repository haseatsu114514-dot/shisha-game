# 第3章・mukai 店内背景

東京の tonari 姉妹店「mukai」の店内。第3章前半の到着・ましろとの交流に使用する。`assets/backgrounds/bg_mukai_shop.png` がゲーム用画像。

- 店の個性: 3階の細長い空間、青灰色の壁、オリーブ色の長椅子、珈琲カウンター、夕方の東京の窓景。ムカイさんの珈琲好きと、作れない日にも座れる居場所を示す。tonari の木壁・モザイクランプを踏襲しない。
- `first-draft.png`: 新規生成した構図原画。写真に寄った質感だったため、そのまま採用しなかった。
- `source.png`: 原画を参照し、同じ構図をアニメ背景の絵画調へ描き直した採用原画。1672×941。
- `assets/backgrounds/bg_mukai_shop.png`: 原画を 1280×720 へ縮小・中央合わせし、メタデータを除いたゲーム用 PNG。描き足しはしていない。

生成は `image_gen.imagegen` を使用。全文指示は [prompt.txt](prompt.txt)、ハッシュは [generation.json](generation.json)。既存素材を画像参照として入力していない。人物・看板文字・ロゴは含めない。シーシャ台・ボウル・ホース・炭・煙を描かず、機材構造が曖昧な装飾を避けた。出力を原寸と配布寸法で目視し、椅子・卓・階段の配置、窓景、室内の明るさ、人物立ち絵を置ける中央の余白を確認した。
