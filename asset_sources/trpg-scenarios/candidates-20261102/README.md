## 加工

1. 原画 1672×941 を左上基準で 1671×940 に最小クロップ（16:9。右と下を1pxずつ）→ LANCZOS で 1280×720 → `assets/backgrounds/trpg_<id>_room.png`。
2. `python3 remake/tools/build_manifest.py --backgrounds-only trpg_<id>_room.png …` で `remake/img/backgrounds/trpg_<id>_room.webp` を作成。目録 `remake/data/manifest.json` は今回の11行の追加だけに整理した。
3. 絵は直さず、各JSONの `spots[].x/y` を対象物の位置へ合わせた（検証器の範囲 x6〜94・y15〜88 内）。画面中央上の調査見出し（約 x27〜73%・y15〜30%）の文字と輪が重ならないことを、ブラウザで文字の矩形を測って確認した。
4. `presentation.backdrop`（画像待ちの色）を `presentation.image` に置き換えた（01・02と同じ形）。

採用画像の原画SHA・派生SHA・座標は `../generation.json`。不採用案も比較用に残す。
