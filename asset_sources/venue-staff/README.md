# 遊び場の店主

2026-10-13のオーナー指示に基づく新規キャラクター。設定の正本は `data/characters.json` の `maki` / `sai`。斧崎マキは夜の斧投げBarの豪快な女性店主。六角サイはボドゲカフェの店長で、糸目の自然な笑顔が逆に少し怖い、親切で落ち着いた男性。サイを意図的に威圧する悪役にはしない。

各フォルダの `normal-prompt.txt` が実際の生成指示、`normal-source.png` が生成PNGを変更せず保存した原画。`image_gen.imagegen` の新規生成・透明背景を使用。既存人物の絵は流用していない。今の登場では通常表情1枚を使う。表情差分や恋愛ルートの追加は含まない。

全身、顔、両手、服装、両足を目視確認。サイは目を開いた悪役顔や笑いを誇張した顔にせず、閉じた糸目と柔らかな口元を保つ。マキは短い赤茶の髪と銅色の一房、作業シャツ、革エプロン、厚い作業靴で区別する。シーシャ・ホース・武器を持つ場面ではない。

配布画像は縦横比を保って896×1200内へ縮小し、透明な同サイズのキャンバス中央へ配置。人物の描き足し・切り抜き・顔や体型の修正はしていない。元PNG・配布PNG/WebP・実際のプロンプトのSHA256とalphaの計測は [metadata.json](metadata.json)。

`python3 remake/tools/build_manifest.py --portraits-only maki sai` で追加した2人だけの目録とWebPを作る。斧投げの来店メニューとボドゲカフェの本棚・昼の試遊・夜の振り返りで表示する。PC／横持ちタッチ相当の実画面と操作記録は [QA](../../docs/qa/venue-hours/README.md)。
