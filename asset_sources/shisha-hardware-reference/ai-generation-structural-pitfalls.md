## 1. 構造図を頭の中で組み立てる

典型的な流れは「炭 → （直接のアルミ または HMD・チムニー） → フレーバーを詰めた**ハガル** → 上部の接続金具 → **ステム** → **水入りベース**」。受け皿はハガルのすぐ下（上部ステムまわり）、ホースはベース上部の接続口に向かう。実機の構造は機種で違うので、すべてを1型に固定しない。

**ありがちな誤り**：
- ボウルとトレーを融合／トレー自体にフレーバーを詰める
- ボウルの代わりに丸いボトルや金属皿を積む
- HMDを台の最上部に浮かせる／蓋がボウルと離れている
- ホースをボウル、炭受け、トレー、水入り瓶の底から生やす
- アルミがハガルの口を覆わず、全く別の袋状物体だけになる
- 完成したシーシャ台なのに炭・ハガルの存在が不自然（ただし意図的に見切れる構図はOK）

## 2. ハガル（フレーバーボウル）の「外形」と「内部」は別物

外観（色・高さ・素材・口径・装飾）と、内面の煙の通り道（吸気穴の位置）は**別の設計軸**。商品名が読めない写真から内部型式を断定しない。

- **伝統型／エジプシャン系**：底側に複数の穴があるタイプ。上から見たときは器の底に複数の吸気穴。
- **ファンネル／phunnel**：中央に盛り上がった柱があり、柱の最上部に**1つの吸気口**。フレーバーは周囲のドーナツ状部分に詰める。
- **ボルテックス／vortex**：中央に柱があるが、吸気口は**柱の側面に複数**。ファンネルと混同しない。
- **その他**：複数室、材質差、特殊な底形状等もあり得る。すべてのボウルを3分類で網羅したと誤認しない。外側が華やかな陶器でも内側の穴を勝手に増やさない。

**外部照合**： [Hookah-Shishaのボウル型式解説](https://help.hookah-shisha.com/portal/en/kb/articles/what-is-the-difference-between-traditional-vortex-and-phunnel-hookah-bowls)、[Hookah Vaultの解説](https://www.hookahvault.com/pages/hookah-bowls)。両者とも「伝統型の底穴／ファンネル柱頂部の1穴／ボルテックス柱側面の複数穴」を区別している。

## 3. アルミ・穴あけ・炭・HMD／チムニー

- **アルミ直置き**：ボウル口に張ったホイルの面に小穴があり、その上に炭を置く。しわができるのは主に縁や巻き込み箇所で、中央面はある程度張られている。
- **アルミ+HMDなどの組み合わせ**：器具とボウルの間にアルミが見える事例もある。**HMDは必ずアルミ必須でも、必ずアルミ禁止でもない**。種類と装着方法に合わせる。
- **金属HMD**：炭を載せる／収める熱管理用の金属部品。蓋付きの円盤、深い皿、通気スリット付きなど多様。炭が乗る床面や空気の流れが物理的に成立する。
- **煙突／チムニー型**：背の高い穴あき円筒・網。ハガルの上に載るものなので、下部ステムの装飾や水容器ではない。長い本体と区別する。
- **炭**：四角いココナッツ炭等。赤い発光面と白っぽい灰が同居し得る。サイズを巨大な赤い岩や炎にしない。炭の数は写真で多様。現ゲームの初期状態は基本三角配置3個を尊重する。
- **取り外した蓋・金属パーツ**：トレー上や脇へ仮置きされている写真を、一体型の「余分なボウル」だと読まない。

※一般的なHMDの形や役割の照合には[KaloudによるHMD説明](https://kaloud.com/blogs/blog/what-is-a-hookah-heat-management-device)を用いた。特定のメーカー仕様を本作の絶対ルールにしない。

## 4. 撮影・生成でよく起こる破綻

| 破綻 | 事前チェック |
|---|---|
| シーシャ台が多重に重なり、パーツが混ざる | 各台ごとに「ベース→ステム→トレー→ボウル→熱管理」の軸を1本ずつ追う |
| ホースが宙に浮く、接続口に入っていない | 台側の接続ポートと人物の手／吸い口までを曲線で追跡 |
| 煙がHMD・本体から常時噴出する | 喫煙中の主な煙は人物の口元などから出て広がる。炭の炎や湯気に置き換えない |
| 炭を5倍に大きくする、巨大炎にする | 指やトング、ハガルの径と比率を比較し、灰と赤熱を描き分ける |
| 全台を銀色、同じ金属・同じ瓶にする | 木・色ガラス・装飾陶器・金属・透明ガラス・角型モダンなど幅を残す |
| すべて正面・中央の通販商品写真 | 手元近接、一人称制作、ソファ越し、足元からの煽り、横向き、窓際複数台など構図を選ぶ |
| 新たな部品を画面に勝手に増やす | 作業工程／注文／店の設定に必要な構造だけ。全写真から「全部乗せ」しない |
| アルミ穴とハガルの通気穴を同一視 | アルミ上の小穴と、ボウル内部の排気穴は別の位置にある |
| 箱・ガラスベースの水をステム全体に流す | ベース内の水面は通常ベース下部。ステム全体が水槽に変化しない |
| 写真の人物をゲームキャラとして転用 | 実在人物の顔・衣装・店名・商品意匠・ロゴはコピーしない |

## 5. ゲーム制作フローを優先する

- 現行『水煙前線 -EN:CODE-』の制作パートで**ハガルが未装着**なら、上端は小さい凸型の金属ポストでOK（全てのシーンにボウルを出す必要はない）。
- **詰める→アルミ／穴あけ→炭焼き・配置→蒸らし→吸い出し**の各場面を混ぜず、そのシーンで実際に組まれている部品だけを描く。現在の採用済み操作・演出が優先。
- 写真にHMDや別方式が写っていても、**既存の穴あけテンプレ・基本の3炭・熱管理システムを無断で変更しない**。将来の機材・交流解放は別仕様として扱う。
- CGや背景はこの構造ガイドに従いつつ、ゲームの採用済みピクセルペインター調や世界観と整合させる。新しい絵に何を映すかはそのシーンの指定が優先。

最も不足しているのは「**ハガルの内側の真上写真（伝統型・ファンネル・ボルテックス）**」「**ホイル張り直前／穴あけ直後の同一ボウル**」「**HMDの蓋を外した内部と炭の置き方**」「**バラしたパーツと組み立て前後**」。既存写真で十分な項目は追加収集を必須にしない。

## 7. 追加3構造図・外部参照で注意する点（2026-10-09）

- [提供された構造図3点の部品名称と空気の流れ](anatomy-diagrams-20261009.md)と[ハガル内部・炭配置の出典付き解説](bowl-interiors-foil-coal-placement-20261009.md)を参照。
- ステム側面の**ホース接続口**と**パージ弁**を同じ機能として描かない。**ベース内のダウンステム**と**先端のディフューザー**も別。ディフューザーは機種によって有無がある。
- **ハガル内部の孔／アルミの針穴／HMDの通気スリット／チムニーの穴**は、それぞれ**異なる場所・異なる部品の穴**。一つの部品に全部を統合しない。
- 炭の配置は2個対向・3個外周三角・4個分散など実例がある。既存ゲームの3炭・外周24または外12中12穴テンプレは写真や外部攻略記事で置き換えない。
- ファンネルのアルミ中央部の穴あけには流儀差がある。外部資料が割れる部分は「実機・レシピに依存」とする。必須の唯一パターンにしない。

## 8. ホースとマウスピースの追加誤描写チェック（2026-10-09）

- [提供写真6点、ホースのパーツとチップの使い分け、外部出典](hose-and-mouthpieces-20261009.md)を確認。
- **側面ポート→ホース根元→たわむチューブ→硬いハンドル→（任意の着脱式チップ）→口元**の1本の接続を追跡。別のパージ弁からホースを生やさない。
- 使い捨て衛生チップと首掛け式マイマウスピースは**代替例**。チップをホースの持ち手サイズに巨大化させたり、首掛けストラップを煙の通るホースとして描かない。
- 煙の主な吐き出し口は**人物の口**。顔と長いハンドルの距離、手の握り方、首にかけたチップとホースのつながりを確認。
