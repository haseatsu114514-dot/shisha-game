# AI画像検品：首掛けマイマウスピースとホース接続の失敗例（2026-10-09）

実際に生成された「吸っている絵」「炭を動かしている絵」の2つの問題から、**生成前の部品指定と生成後の目視QAの両方**を強化する。シーシャ写真は造形理解用で、人物の顔・ブランドロゴの完コピは不要。ヒロインは**指定キャラのリポジトリ内の正規立ち絵・プロフィールを最優先**し、「ゲームのヒロイン」というだけで汎用の別人にしない。

## 指摘された2つのNGと修正条件

### NG-A：首にチェーンだけ、またはただのアクセサリーが描かれ、マイマウスピースとして成立していない

- **携帯中**：細いチェーン／ストラップ → リング・留め具 → **実体のある短い着脱式マイマウスピース本体**、の接続がある。器具の先端に穴や装着部があり、ハンドル先端に差す／被せる等の構造が成立する。
- ペンダントが単なる棒の飾り・チャームになっていないか確認する。必要なら小さな拡大インセット、胸元に寄った構図で「どこから吸うか／どちら側をハンドルに接続するか」を見せる。
- **使用中**：マイマウスピースを使用すると設定した場合は、首から外して**ホースハンドルの口側先端に実際に装着**する。首飾りのまま口へ浮遊接続しない。
- **例外**：本人が予備のマイマウスピースを首に下げたまま、別の使い捨てチップをハンドルに装着して吸う描写は可能。その場合「ネックレス型を使用中」とは説明しない。
- 使い捨てチップの装着は機材・場面に依存。ハンドル単体で吸う構図もあり、**すべてのシーンに必ず着脱チップを追加するルールではない**。
- マウスピースは色・素材・装飾を自由に変えてよいが、ホースハンドル本体やチェーンとは**別パーツ**でなければならない。
- **NG**：首のチェーンだけ、ただのアクセ棒、チェーンの先端がホースに化ける、首から外さずにハンドル先端で同じマイチップを二重化、実際の吸い口部が消失。
- **OK**：携帯時のチェーン＋短い中空のマイチップ、または使用時のハンドル先端に装着されたマイチップ。

### NG-B：ハンドルがホースから離れ、本体ポート側ともつながっていない

- 画面で見せる基本経路は **「台本体のホースポート → ホース根元の接続金具 → 柔軟なホース → 手で持つ硬いハンドル → 口側先端（必要ならチップ） → 人物」**。
- 画像生成後に、**ホース1本を台から手元まで目で追跡**する。ポートから出たホースが途中で消える、二手に分岐する、背景に吸い込まれる、別のホースとすり替わる、ハンドルの根元が宙に浮く、ベースの底／炭皿／ハガルから出る、は原則NG。
- **手でハンドルを握る部分を含め、視認できる接続点はすべて連続**している。ホースは重力に沿ってしなり、手前の台や腕の前後関係が破綻しない。
- **画角・遮蔽の例外**：カメラ外へ続くホース、手・家具で一時的に隠れるホースは許容。ただし両端で方向・太さ・色・接続相手が一致し、**未接続に見えない**こと。見切れた部分まで無理に全部描き足さない。
- **ハンドルを単品で持っている小物紹介カット**は別。吸っている・作業している完成シーシャの実使用シーンと区別する。
- **NG**：ホースが二本あるように見える、台のポートが空、曲がったホースとハンドルが接続していない、ホースが途中で途切れる、マウスピースに直接ホースが接続され持ち手が消える。
- **OK**：本体の正しい側面ポートに繋がった柔軟なホースが、硬いハンドルの根元まで続いている。

## 画像生成の前に固定する設定

### 保存したNG実例：一本のホースがY字に分岐

[みんとの喫煙カット初版と具体的なNG箇所](ng-examples/README.md#ng-hose-01みんとの喫煙カットでホースがy字に分岐する)を必ず確認する。接続口とハンドルが描かれていても、その間の管が三方向へ枝分かれする画像は不採用。手元→ポートの逆向きにも追跡し、交差を合流として描いていないか、第三の端がないか、足元や画面外への延長が経路と矛盾しないかを見る。交差は前後の遮蔽で表し、管の輪郭を結合しない。

1. **登場人物**：名前を明示し、`brand/character_profiles.md` など正規資料の服・顔・髪型・画風を優先する。「ヒロイン」とだけ書かない。
2. **場面**：携帯／ハンドル装着／喫煙／炭交換／ボウル準備など、**いま何をしているか**を一つ決める。
3. **台の構造**：ホースポートを一つ決める。パージバルブを混同しない。デザインや色は自由、物理的な経路は自由に切断できない。
4. **マウスピースの状態**：`なし` / `使い捨てチップ` / `首から下げたマイチップ（携帯中）` / `ハンドル装着中のマイチップ` のどれかを意識する。例外は意図が説明できるときのみ。
5. **カメラ**：本体と持ち手が両方入る場合はホース接続を確認しやすい位置に。アップの場合は見える経路のみ矛盾なく描く。

## 生成後の必須合格チェック（1つでもNGなら修正・再生成）

- [ ] キャラの顔・髪・服・画風は指定した**既存ヒロイン**の正規資料に一致しているか。
- [ ] 首掛けマイチップを描いた場合、**チェーン＋リング／接続部＋立体的な吸い口本体**が存在するか。
- [ ] マイチップ使用中なら首からハンドル先端へ移っていて、**二重化・謎の空中接続**がないか。
- [ ] ホースが描かれる実使用シーンでは、**本体のホースポートからハンドルまで1本の連続経路**が視認できるか、または自然な遮蔽・画角として説明できるか。
- [ ] ポート・パージ・ホース根元・ハンドル根元・口側先端の接続が物理的に自然か。
- [ ] 経路を両方向に追っても一本であり、Y字分岐・三つ目の端・前後関係のない交差・足元への不自然な延長がないか。
- [ ] 使い捨てチップとマイチップの大きさや装着方法は適切か。必要のない二重装着がないか。
- [ ] 煙は人物の口元とタイミングが合っているか。ホース根元やチェーンから煙が出ないか。

**運用**：既存の生成画像にこの種の欠陥が見つかったら「採用せず、欠陥を明示して再生成」する。文章で「直したことにする」だけでは合格にしない。画像の参照だけでゼロエラーを保証できるわけではないので、必ず出力を検品する。

## プロンプトに貼る短縮文

> 指定されたゲームの既存ヒロイン本人を正規立ち絵に合わせて描く。シーシャは本体側面のホースポートから柔軟なホースが自然につながり、その先が手に持つ硬いハンドルへ実際に接続する。見える経路を途切れさせたり、空中で終わらせたりしない。首掛け式マイマウスピースを描くなら、チェーンだけではなく、装着口・吸い口を備えた独立した小さな本体を明確に描く。使用時はハンドルの先端に装着し、携帯時は首から下げる。使い捨てチップとの併用は場面に応じて意図的に選ぶ。出力後に部品接続と人物設定を目視チェックし、不整合があれば修正・再生成する。
