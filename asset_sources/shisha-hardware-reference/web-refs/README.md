# 日本のシーシャ店・機材の参考写真（Web の写真・手元に取って見る）

日本のシーシャバーと、日本の店で使われている機材の写真 **116枚** の一覧（2026-11-02）。オーナー方針「シーシャの画像は日本のシーシャバーを参照、海外はあまり参照しない」「無料ライセンスでなくても、参考にするだけなら集める」に基づく。

**写真そのものはリポジトリに入れていない。** 各サイトの著作物で、このリポジトリは公開なので、入れると配布になる。一覧 [`refs.json`](refs.json) に「どのページのどの写真か」を記録し、使う人がスクリプトで手元に取ってくる。

```bash
python3 tools/fetch_shisha_web_refs.py            # 全部取る（取得済みは飛ばす）。約11MB
python3 tools/fetch_shisha_web_refs.py --only hmd # 部位で絞る
python3 tools/fetch_shisha_web_refs.py --list     # 一覧と見るポイントを表示
```

保存先は `web-refs/images/`（`.gitignore` 済み）。**commit しない。** ゲーム素材として使わない・配らない。生成ツールに渡すときは「形・構造・縮尺の参考にし、写真の写し、ロゴ・刻印・文字・人物の顔は描かない」と書き添える。

## 集め方の記録

- 2026-11-02 に Claude が、上のページから写真を集めて目視で選んだ（候補552枚 → 116枚）。各サイトの robots.txt に従い、アクセスを拒否されたページ（RETRIP・秋葉原の紹介記事）と消えていたページは飛ばした。
- 広告・ロゴ・バナー・Tシャツ・料理・無関係の写真は外した。商品写真に写るブランド名やサイトの透かしは描かない。
- 名古屋の EGG SHISHA は閉店のお知らせを出している（2026-11 時点）。写真は記事が残っている間だけ取れる。
- リンクが切れたら、ページを開いて同じ部位の写真に差し替え、`refs.json` を直す。

## 非公開の保管先

オーナー案「資料を別の非公開リポジトリに置き、ゲームは公開のまま」を採るなら、取得した `images/` をその非公開リポジトリに入れ、PC ではこのフォルダに置く（`images/` は `.gitignore` 済みなので、ゲームのリポジトリには入らない）。
