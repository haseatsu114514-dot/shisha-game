# ヒロイン日常・タイトルCGの画像生成ルール（2026-10-09）

オーナーの画像生成チャットで指摘された「直炭」「別人・大人びた顔」「ハガルとHMDの縮尺」「機材の混成」「背景の反復」を今後の制作へ引き継ぐ正本。ヒロインの日常・タイトル用CGを新規生成・修正するときに読む。既存の実物資料は構造理解に使い、画風と世界観はゲームを優先する。

## 1. 参照画像の役割を分ける

- **本人・顔・年齢感・衣装**：`assets/sprites/characters/<id>/chr_<id>_normal.png` と採用済みの表情差分を実際に開く。設定の数値と人格は `data/characters.json`、説明は `brand/character_profiles.md` を参照する。古い文章と採用済み画像で外見が食い違う場合、画像に存在する髪型・衣装・アクセサリーを優先し、古い形容を混ぜない。
- **質感・描画密度**：`assets/ui/title_arts/title_art_keyvisual_01.png` を実際に開き、細かなピクセルの粒度、段階的な陰影、布・金属・ガラス・煙の描き分けを合わせる。タイトル絵は顔や機材構成の正本にしない。元絵の直炭や濃い顔の陰影を新しいCGへ持ち込まない。
- **機材の構造と比率**：このディレクトリの実物資料、さらに選んだ具体的モデルの資料を参照する。写真の人物・店内・広告・商品ロゴをCGへコピーしない。
- 参照画像を生成ツールへ添付し、どの画像が「本人」「質感」「HMDモデル」の基準かをプロンプトに明記する。画像を開かずパスだけ読んで「確認済み」としない。

## 2. 顔と年齢感を立ち絵に合わせる

- 正式立ち絵の目の形・目の間隔・眉・小さな鼻と口・頬・顎・輪郭・髪・頭身を保つ。衣装色だけ似た汎用の別人に置き換えない。
- 成人という設定を理由に、目を細くする、頬を削る、顎を長くする、鼻筋を強める、濃い化粧を足すなどの変更をしない。設定年齢と、正規立ち絵が持つその人の顔の若さを両方保つ。
- タイトル絵の高級感は背景・材質・光・細かな粒度で合わせる。顔の強い陰影や厚い目元で大人びさせない。凛の落ち着いた顔など、本人の年齢感と固有の特徴も一律に幼くしない。
- みんとの営業姿は採用済み画像の**黒い長髪、角と蝙蝠のアクセサリー、緑と黒の衣装**を確認する。古い「ミント色のツインテール」という文章を本人の外見として混ぜない。私服は採用済み `chr_minto_ura_normal.png` を別途参照する。

## 3. HMDは画像ごとに具体的な一モデルを決める

- **2026-10-11 UTC追加のオーナー方針：炭は通常2〜3個、稀に4個。** 選んだHMDの容量・蓋の状態・炭サイズで成立する個数を優先し、小さな器具に無理に3〜4個を詰めない。準備・洗浄中はまだ載っていない炭を足さない。[タッパー保管の実物4写真と制作条件](flavor-storage-tubs-issue396/README.md)も参照し、常用フレーバーの保管は透明／半透明の角丸矩形容器を優先する。ブランドやラベルの文字は模写しない。既存の正式タイトル18枚は維持し、未採用候補から小さく修正する。

- **喫煙中・吸い出し中・提供済みなど完成状態のシーシャCGではHMDを必須とし、アルミへ炭を直接置く直炭描写をしない。** 炭は選んだHMDの金属床・受け皿・網など、実際に炭を収める部分へ接触させる。
- 生成前に `HMDモデル / ボウルの型と寸法 / 蓋の有無と状態 / アルミの有無 / 炭の大きさと数` を一つの構成として記録する。名前だけ指定せず、そのモデルの写真も見る。
- 一つのHMDへ別モデルのドーム・煙突・網・スリット・複数の取手を寄せ集めない。外形、蓋、本体、取手、通気口、炭の置き場所を選んだモデルの構造へ揃える。
- アレンジは**色、表面の仕上げ、小さな装飾**程度とし、部品の数・接続・炭床・蓋の方式・比率を変えない。ロゴ・メーカー文字・広告は描かない。
- 画像間ではモデルを変えてよい。同じシリーズ全体を一種類へ固定する必要はなく、「一枚の中で成立する一モデル」と「候補全体のバリエーション」を両立させる。
- 詰める・洗う・組み立てる途中には、その工程でまだ載っていないHMDや炭を無理に追加しない。ボウル未装着の台の先端は従来どおり小さな凸型金属ポストとする。

## 4. ハガル・HMD・炭の縮尺を確認する

[装着写真／手持ち写真の出典と確認点](installed-and-handheld-scale-20261009.md)を参照する。近接商品写真、手と並ぶ写真、台全体の写真をそれぞれの用途で使う。

- **2026-10-09追加指摘：単体の商品写真と寸法指定だけで縮尺確認を済ませない。** 新規生成前に、選んだHMDがボウルへ実際に装着され、受け皿・ステム・ベースまで写る実写を調べて開く。手持ちのハガル／HMDは、実物を持つ手・掌・指が写る実写も別に参照する。オーナーから今後提供される参考画像も、この用途別の実写参照へ追加する。
- **装着時の相対比率**は、HMDとハガル口径の適合だけでなく、受け皿径・ステム全高・ベース幅との関係を確認する。小さすぎる受け皿や短すぎるステムによって、HMD／ハガルだけが巨大に見える絵を避ける。顔との比率だけで合格にしない。
- **縮小で短くしすぎる逆のNG**：[凛・つむぎの原画NG例](ng-examples/README.md)を確認する。ハガルの口径・上の器の深さ・細い脚の長さ・全高を別々に照合する。大きすぎた絵を修正するとき、脚まで潰して短い台座にしない。適合する具体的な脚付きボウルの実写と比率を先に決める。
- **手持ちの相対比率**は、開口部・器全体の高さ・細い脚を分けて、掌の幅と指の届く距離で確認する。ハガルを両手で抱える食器や大きなカップにしない。冷たいHMDを机に置く場合も、その機材だけを手前で強調拡大せず、同じ奥行きの手・ボウルと寸法が合うようにする。
- 実写は出典とモデルを記録し、広告の生成画像・AI画像を実物の寸法根拠にしない。実写でモデルが特定できないときは断定せず、外部の仕様と組み合わせて照合する。
- 一般的な描写の出発点として、ハガル口径約7〜8cm、低いHMD径約7〜8cm、角炭の一辺約25〜27mmを比較する。ただし実際には**選んだモデルと適合ボウルの寸法**を優先し、これを全機材へ強制しない。
- 手で扱うボウルは片手の掌と比べて自然なサイズにする。HMDやハガルを顔・頭と同じ直径の巨大な器にしない。パフェグラスや飲み物のカップと混同しない。
- 炭はHMD径に対して小さな角炭として描く。数個が内部へ収まる寸法を保ち、巨大な赤い岩や炎を置かない。灰色の表面と小さな赤熱部を描き分ける。
- HMDはボウルの口へ安定して載る別部品。ボウル、アッシュトレー、ステムへ溶かしたり、浮かせたり、二重のボウルにしない。
- 台の全高は床置き・卓上・低重心型で変わる。家具への設置位置と人物の座高を指定し、ベースが卓上へ置かれているのに床置き台のように伸びる等の破綻を避ける。
- 遠近の大小は許容するが、同じ台のハガル・HMD・炭・手が同一の奥行きにある場合は互いの比率を保つ。

## 5. 台・背景・行動のバリエーション

- シリーズでは伝統的な金属台、木製ステム、角型の現代的な台、透明ガラスの低い台などを使い分ける。材質・色・設置位置・HMDモデル・カメラ距離を毎回同じにしない。
- 背景は昼の窓際、店の作業カウンター、倉庫や機材ショールーム、夜の席、本人の日常の外出先など、設定に合う場所と時間帯を選ぶ。同じ暗い棚・バー照明・植物を全カットへ反復しない。
- **背景植物は必須ではない。** つむぎの植物好きなど、そのキャラや場所に意味がある場合に使う。全ヒロインの画像へ大量の観葉植物を飾る必要はない。
- **同日追加指摘「まだ観葉植物率が高い」：室内の新規候補は観葉植物・鉢・吊り蔦を原則入れない。** 既存タイトル絵に植物があっても、それを質感と一緒に背景の必須要素として移さない。人物や場所に意味のある屋外の植栽等に限り、少数のカットへ絞る。生成後は候補全体でも植物の登場頻度を数えて確認する。
- 吸う、ボウルを詰める、炭を扱う、道具を洗う、絵を描く、買い物や休憩など、本人の性格と生活から行動を選ぶ。シーシャと無関係のカットへ台を無理に追加しない。
- 顔が見える構図を確保し、候補一式では場所・行動・光・構図の違いを一覧で比べられるようにする。

## 6. 生成後の必須目視QA

生成後に原寸で本人・手元・機材を確認し、次を制作記録へ残す。参照資料を読んだだけで合格にしない。

- [ ] 正規立ち絵と同一人物で、顔・髪・衣装・アクセサリー・年齢感が合っている。
- [ ] タイトル絵に合う細かな粒度・描画密度・材質感を保ち、粗いドットや滑らかすぎる塗りへ変わっていない。
- [ ] 完成・喫煙状態の台は指定した一モデルのHMDを備え、直炭になっていない。
- [ ] HMD・蓋・取手・通気口は同じモデルの組で、他モデルの構造が混ざっていない。
- [ ] ハガル口径、HMD、炭、指・手、人物と家具の縮尺が互いに自然である。
- [ ] ベース→ステム→アッシュトレー→ハガル→HMDの積層が成立し、炭が実際の受け面へ接している。
- [ ] 本体の正しいホースポート→柔軟なホース→硬いハンドルの経路を目で追える。パージへの誤接続、浮遊、分離、途中消失がない。自然な遮蔽・見切れは可。
- [ ] ホースを手元からポートへ逆向きにも追跡し、Y字分岐・第三の端・前後関係のない交差がない。[みんとの初版NG実例](ng-examples/README.md)と同じ構図の失敗を繰り返していない。
- [ ] 分岐がなくても、人物の足や前景を囲む不自然な大回り、右へ見切れた管がベース下から別に戻ったような矛盾がない。重力・家具との接触・遮蔽の前後が自然。[つむぎの修正版NG例](ng-examples/README.md)も比較する。
- [ ] 首掛けマイチップを描いた場合はチェーンに加えて独立した吸い口本体があり、使用時はハンドル先端へ装着されている。携帯状態と混ぜて二重化していない。
- [ ] 煙は口元と行動のタイミングに合い、HMD・ホース根元・チェーンから常時噴き出していない。
- [ ] 背景・光・台・行動に候補間の違いがあり、植物だけを機械的に増やしていない。
- [ ] 文字、ロゴ、広告、透かし、UIが焼き込まれていない。

**一つでもNGなら欠陥箇所を明記して修正・再生成する。** 未確認の画像へ「確認済み」と記録しない。本人違い、直炭、混成HMD、縮尺破綻、未接続ホースを採用候補のまま扱わない。
