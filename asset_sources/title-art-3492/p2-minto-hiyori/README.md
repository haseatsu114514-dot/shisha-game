## 生成と原画

Codex 内蔵画像生成。全案で縦2:3・1680×2520・不透明を指定。人物は先細りの線、輪郭より細い内側の線、2〜3段の硬いセル影、髪の面で分けた反射、マットな肌と布を共通にし、環境光の柔らかさは背景に使った。UI・文字・ロゴ・透かし・左フェードの焼き込みは目視で見当たらない。

- **みんと A／B**　現行の黒とミント色の営業衣装、黒ストレートロング、角、蝙蝠の髪飾り、緑の瞳、ハートのチョーカーと胸元のリボンを指定。A は夕刻のウインク、B は夜のラウンジで両目を開いた微笑み。いずれも口から左へ煙を吐いた直後に片手で硬いハンドルを持ち、もう片方を卓に置く。両案を1回ずつ再生成し、低い閉蓋のロータス型 HMD、ハガルの細い脚、単一ホースと、タイトルでの両手の位置を指定し直した。
- **ひより A／B**　赤みのある茶髪の高いポニーテール、流した前髪、頬に沿う巻き毛、琥珀色の瞳、金色の耳飾りを指定。私服は現行のチャコールのパーカーと生成りのカーゴパンツ。A は明るい河川敷で目を閉じて笑い、片手で反対の手首を支えながら歩き出す。初稿の手が上端に寄ったため、頭上の空を取り直した。B は夕方に両手を頭の後ろへ添え、目を開いて水辺を見る。みんと A／B とひより A は各2回、ひより B は1回生成した。

生成元と提出原画のバイト列が一致し、双方で PNG の構造検査と全画素のデコードを通過。全点 8-bit RGB（カラータイプ2）、不透明。ICC プロファイルや `sRGB` チャンクを持たないため、表示比較は Chromium の既定解釈。標準の1120×1680に幅96・高さ144 px不足し、出力実寸のまま保存した。

みんと両案は、銀色の低いロータス型 HMD、黒いハガルの脚と接合部、受け皿、縦ステム、ガラスベースの順を確認。ハガルと HMD は台全高の約2割、HMD の幅は受け皿幅の約4割、頭頂〜顎に対するハガルと HMD の高さは約3割。炭は閉蓋の内側にある設定で、炭そのものの個数は画面から判別できない。側面ポートから薄緑のホース1本を金属継手、低い U 字、硬い黒のハンドルまで両方向に追い、分岐・途切れ・浮きが見当たらない。指とハンドル、添え手と卓の接触を確認。煙筋は口元から左へ流れる。ひよりの両案はシーシャ機材なし。 [機材の基準](../../../docs/shisha_reference.md#4-画像生成の必須手順機材の形と構造) · [画像の検品項目](../../../docs/asset_ai_guidance.md#シーシャcgの出力後必須qa2つの実例ミス)

## タイトルでの確認

`9410f81a8c` の `remake/` をセーブなしの Chromium で起動し、実行中の `.title-art` の背景画像を候補に切り替えた。1280×720 および1920×1080の各 DPR 1／2、844×390の DPR 3 で4案を確認。静止後の `cover / center 20%`、左マスク 0–26%、不透明度0.97は現行の CSS に従う。1280×720 の画像枠は x780、幅500 px。844×390 の画像枠は x497.8、幅270.8 CSS px。メニュー右端から画像枠までそれぞれ約431、233 CSS pxの間隔があり、全案で顔と手元はメニューと重ならない。

PC と横持ちでは登場アニメーションの途中（開始から650 msの時点）も確認した。高 DPI の検品対象は画面内の位置と見切れ。1920×1080 DPR 2 と 844×390 DPR 3 の比較には CSS ピクセルで取得したキャプチャを用いた。

- **みんと**　両表示で顔、吸い口を握る手、卓の添え手が見える。左マスクは主に煙の先と台の左側に掛かる。ゲーム背景にも台があるため、みんとの台と並ぶ状態を比較シートで確認できる。
- **ひより**　両表示で顔・両腕・手首が見える。左マスクは主に空、河川敷、花に掛かる。A の足元は下端付近、B のポニーテールは右端付近。
- **560×720**　原画を560×840に縮小し、上24・下96 pxを切った。PC 比較の下段に、左マスクを掛ける前の4案を追加した。みんと A の添え手の指先にわずかな見切れが残ったため、追加生成はここで止めた。
