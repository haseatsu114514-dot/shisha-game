## 参照と生成

本人性は新版立ち絵 `remake/img/sprites/character_variants/new/{tsumugi,mashiro}/chr_<id>_normal.webp` と正式な笑顔差分、構図・所作は配信中の `title_art_tsumugi_04_painting_studio.webp` と `title_art_mashiro_05_rooftop_dusk_yawn.webp`、塗りは P1 の [S1](../p1/ageha04_s1.png) を参照した。人物の輪郭を明確にし、影を2〜3段にまとめ、背景は場面ごとの光で塗り分けた。シーシャ機材のない日常場面として生成した。顔比較の中央と右は候補から420×420を等倍で切り出した。左の正規立ち絵を拡縮した。

Codex 内蔵画像生成で各1回。出力指定は縦2:3・1680×2520の原画。実出力は4点とも不透明PNGの1024×1536で、配信標準の1120×1680に届かなかった。無加工で保存した。

## タイトルでの確認

main `4333f0c7` を実行した Chromium のタイトルで背景画像だけを候補に切り替えた。1280×720・1920×1080のDPR1/2と、844×390のDPR3で各4案を表示。定位置の顔と手元、メニューとの距離、現行の左マスクを確認した。比較シートにはPCと横持ちの静止後の画像を縮小して載せた。ゲームへの組み込みでは登場中の見切れ、圧縮後の画質、読み込み時間、抽選と既存セーブの挙動を確認する。
