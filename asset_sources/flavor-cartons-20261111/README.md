# フレーバー箱絵 原画台帳（Issue #3287）

Codex 内蔵画像生成で E1 から順に生成した原画。生成結果を無加工で保存。参照画像は各回の入力に添付した。

## 検品

全9種: 箱1つ、全体が画像内、背景透過、文字・数字・実在ロゴなし。メーカーの既存箱と形・画風・紋章を照合。E2 と E3 は通常版との見分けも確認した。
