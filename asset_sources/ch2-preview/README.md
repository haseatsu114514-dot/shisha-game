# 第2章・90年代風次回予告の原画

Issue #384 の第1章ラスト強化に使う、独立した 4:3 のアニメ予告スチル。

## 制作と原画

- 2026-10-12 UTC に OpenAI の `image_gen.imagegen` で、この変更のために新規生成。
- 本人性は正規立ち絵・表情差分を実際に開いて確認し、生成時に添付した。キャラ設定は `brand/character_profiles.md`、画像指示は `docs/asset_ai_guidance.md` と `asset_sources/shisha-hardware-reference/heroine-title-cg-rules-20261009.md` を確認した（後者は sparse checkout のため Git の正本を `git show` で読んだ）。
- 画風の変更はオーナーの「90年代風の次回予告」「魅せ方は任せます」に従う。通常立ち絵とタイトル絵は変更していない。
- 全PNGが生成サービスから取得した未加工原画。実装素材は `assets/cgs/ch2_preview/` の同名WebP。
- 外部の配布素材・製品写真・既存アニメ作品のカットは使用していない。文字、ロゴ、UIは描き込まず、ゲーム側で字幕を重ねる。
- シーシャ本体・ホース・マウスピースは全画面の外。人物の首掛けマイチップも写らない構図。機材構造を生成で創作しない。
- 生成指示の全文・参照画像は `prompts-front.json`（01〜03）と `README-dark.md`（04〜06）に記録。

## 形式変換

WebP化だけを行い、再描画・顔の加工・画像のピクセル化はしていない。

```sh
ffmpeg -y -hide_banner -loglevel error -i asset_sources/ch2-preview/01_hajime.png -c:v libwebp -quality 90 -compression_level 6 assets/cgs/ch2_preview/01_hajime.webp
```

02〜06も同じ設定。PNG原画を保存し、圧縮で細い線が失われた場合に再変換できる。
