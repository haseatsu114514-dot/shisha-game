# #3810 イベント絵・店内背景

[候補の比較](comparison.jpg)。既存絵を構図と配色の参照にして、Codexの画像生成で各対象を2案ずつ作った。ポエムとカットインの原画はこのフォルダ、店内・初登場スチルの採用原画は `assets/backgrounds/` に保存。実物の参考写真は非公開の資料リポジトリに置き、同梱していない。

| 対象 | 採用 | 選定理由 |
| --- | --- | --- |
| 第1章ポエム | `poem-b` | 刻んだ葉の質感、透明のベースの水面、畑と海辺のモチーフが横長の枠内で読める |
| 鉄仮面さんの手元 | `customer-clean` | 黒いハイネックの現行衣装、透明の短い使い捨てチップ、持ち手と一本のホースが見える。台が写った初案を修正 |
| 鉄仮面さんの登場カットイン | `cutin-plain` | 白い顔に目・鼻・眉を描かない。他キャラと並べた時の見せ方に合わせた。眉あり案は `volk-with-brows.png` |
| ケムリクサ | `kemuri-b` | オリーブ色の席と木のカウンターを維持。台のガラスベースと卓の接地が読める |
| tonari | `tonari-a` / `tonari-b` / `night-b` / `night-a` | 晴れ昼・曇り昼・晴れ夜・曇り夜。左の窓、モザイクランプ、奥の席と右の棚を維持 |

生成時は作品内の現行絵を参照し、機材の形だけ `siryou` の `stand-russian-05`、`stand-lounge-japan-01`、`hose-silicone-handle-01`、ホースとマウスピースの資料を参照。店内に人物・保存容器・コーヒーマシン・文字は入れない。未使用の台はガラスベース、細いステム、受け皿、小さな上向きのポストで、ボウル・HMD・炭・ホースは外した状態。手元のカットは台を画面外に置き、着脱式の短いプラスチックチップを硬い持ち手の先端に差し、反対側の柔らかいホースを画面の右外に出す。
