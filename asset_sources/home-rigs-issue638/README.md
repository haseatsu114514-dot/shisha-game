## #640 の本編配置

オーナーの確定仕様に従い、`home_rig_set` 所持で机上、`home_rig_pro` 所持で床、両方所持で両方を表示する。装備・使用台選択とは分け、所持していなければ元の背景を維持する。

v3原画を無変更で `assets/ui/scene_props/shisha_home_tabletop.png`／`shisha_home_pro.png` へコピー。`files.json` の原画SHA256と一致する。背景画像の生成や修正はせず、既存 `remake/js/core/scene-art.js` のSVG合成を使う。透明な余白を表示時のviewBoxで除き、1280×720の背景座標で卓上台は接地点(563,552)・高さ126px、大会台は(914,563)・高さ236px。夜は既存の明度補正、底面には接地影を用いる。ホース・ハガル・炭・煙は追加しない。

晴れ／曇天の昼夜と無印の家背景、本編の家・帰宅・一服・朝・マッププレビュー・家の練習窓で同じ合成と所持判定を使う。原画の半透明の縁は実背景上で確認し、デザインの再生成やアルファの加工は行っていない。

登録は `python3 remake/tools/build_manifest.py --scene-props-only shisha_home_tabletop.png shisha_home_pro.png`。指定2点だけ目録と配信WebPへ追加し、他の背景や画像を再ビルドしない。[比較画像と検証記録](../../docs/qa/home-rig-backgrounds/README.md)を参照。
