## 原画と編集履歴

生成は `image_gen.imagegen`。原画は変更せずコピーし、配布だけImageMagickで全体を1280×720へ縮小したlossless WebP。写真の貼り込み・実在バンドのジャケット・実ロゴ・店名文字・器具を描く指示は使わない。りゅうじの肖像画は背景装飾として匿名の架空人物を指定した。

- りゅうじは会話の画像参照 `num_last_images_to_include: 5` を使用。ユーザー添付の木壁事務所と、その後に検品表示した旧4室を含む。添付を主参考として明示し、旧畳室の保持を禁止した。添付原本のローカルファイルは取得できていないため、同梱済みの参考写真だとは記載しない。新しい生成原画・実際の全文指示・参照方式を保存する。
- REI・ヴォルク・MELTY PUFFの最初の改修は、目視した [旧原画](archive/v1/README.md) のコピーを `referenced_image_paths` へ添付した。画角を維持しながら家具・飾り・収納を編集した。
- MELTY PUFFの最初の改修候補では左下の雑誌に文字状の見出しが生成されたため、表紙だけを画像編集で清掃。 [修正前の原画と実際の指示](archive/revision-candidates/ageha-magazine-text/README.md) を保存し、最終編集ではその候補原画を添付した。クマ・デコ小物・家具を保ち、表紙見出しをハートと星へ替える指示。採用 `prompt.txt` は最終編集の実際の全文であり、最初の改修指示は候補側に残す。
- 旧4室の生成原画・実際の全文指示・当時の配布画像・寸法とハッシュは [archive/v1](archive/v1/README.md) に保存。過去の畳や容器指定を書き換えて新しい生成履歴にしない。

[metadata.json](metadata.json) に入力方式、参照、実寸、SHA256、配布変換を記録。[人物と内装の自動検査](../ch2-characters/validate.py) と [ゲーム上のQA](../../docs/qa/ch2-preview/README.md) を併用する。背景が読めなければ見学台本へ進まず、再読込か地図へ戻る操作を残す。

## 目視と制作範囲

4室を並べて素材・色・照明・家具・動線の違いを確認する。白・ピンクのクマの布地と座面への接地、CDケースとギター、ソファ・机・運搬ケースの接地、閉じた収納、人物と会話枠が重なる中央と下部の余白を検品する。見学会話も新しい飾りと家具へ合わせ、畳・靴を脱ぐ案や見える容器棚の説明を残さない。画像検査の数値だけで「タッパーなし」や構造を判定しない。

夜用の室内差分は未制作。同じ準備中の絵を使い、街の昼夜切替は街の表示比較として扱う。ヴォルクは県大会の出場者ではなく技術展示の先行登場。はじめ・あげは・神崎・REIが第14日に対戦する。店の内装で神崎の素性を匂わせるが、名乗り・紹介で組長と早期に確定しない。

後続は実物機材資料を使った営業中差分、必要な昼夜差分、DAY2以降の日常と関係の接続。入口見学と本編DAY1だけで店舗全体・県大会・第2章完成としない。
