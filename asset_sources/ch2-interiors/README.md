店名・写真・宣伝文字・ロゴは画像へ焼き込まず、名称はゲームの文字で表示する。4室を並べて材料・色・照明・家具・動線が異なることを目視確認した。床と卓、座布団、プリクラ機、運搬ケースの接地、玄関の段差、人物と会話枠のための中央と下部余白を確認。容器は小さい角丸矩形の密閉タッパーで列と向きを揃え、背景の遠近に応じた縮尺。葉・蓋・ラベル位置を目視した。保管ラベルの小さく読めない筆跡だけはオーナー方針の例外。機材・炭・使用中のホースは描かない指示を優先し、店内会話でも「奥で準備中／実演前」と扱う。

生成は `image_gen.imagegen`。あげは・神崎は目視した旧背景の編集による再制作で、旧背景と [オーナー提供の容器原本](../shisha-hardware-reference/flavor-storage-tubs-issue396/photos/01-sealed-blue-rim.jpg) を添付した。旧背景の器具・写真・大きな文字・物販棚を取り除くよう指定。容器写真は構造参照だけで、ブランド・文字・撮影画像を配布背景にコピーしない。REI・ヴォルクは新規生成のため画像添付なし。資料を読み、同じ容器形状を文章で指示した。旧背景を本編全体で置換せず、試遊専用の別名背景として配布する。

生成原画は無変更保存。 [metadata.json](metadata.json) に入力参照、実寸、SHA256、配布変換を記録。配布は原画全体を1280×720へ縮小したlossless WebP。 [人物と内装の自動検査](../ch2-characters/validate.py) と [ゲーム上のQA](../../docs/qa/ch2-preview/README.md) を併用する。背景が読めなければ見学台本へ進まず、再読込か地図へ戻る操作を残す。店内からは選んだ昼夜の地図へ戻る。

夜用の室内差分は未制作のため、試遊では同じ準備中の絵を使う。神崎と展示室の外光を夜景として扱うものではなく、街の昼夜スイッチは街の表示比較だけ。常設店の所在地（特に東京資料があるREI・ヴォルク）は本編接続時に整理する。ヴォルクは県大会の出場者ではなく展示の先行登場。あげは・神崎・REIがはじめと第14日に対戦する。

後続は機材の実物写真を使った営業中背景、必要な店内差分、日常の行動と関係の接続。今回の入口見学だけで店舗全体・県大会・第2章完成としない。
