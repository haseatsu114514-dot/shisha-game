## 加工（C のみ）

- 原画 1672×941 RGB（生成器が指定の 1280×720 を守らなかった）。16:9 よりわずかに縦長なので、上下を 0.25px ずつ（計0.5px相当）だけ中央で切り、Pillow の LANCZOS で 1280×720 に縮小した（`Image.resize((1280, 720), LANCZOS, box=(0, 0.25, 1672, 940.75))`）。色・明るさ・構図の変更はしない。
- 出力は既存背景と同じ 1280×720 RGB PNG（アルファ無し）。WebP 派生は `python3 remake/tools/build_manifest.py --backgrounds-only bg_mukai_attic.png` で作成。
- 昼夜は描き分けない。夜は既存の夜の色調補正（`tint="night"`）を掛ける。
