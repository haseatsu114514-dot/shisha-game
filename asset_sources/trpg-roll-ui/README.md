## 採用・検品

6点を卓の小物、既存ロゴ2枚、変更前の劇場の画面を参照して描き起こした。生成画像を切り出し、帯の縁とアルファをそろえ、盾の面を額縁の内周に合わせた。ゲーム用は WebP 品質88で書き出した。

- [x] 寸法・アルファを検査し、原画6枚に文字・数字が描かれていないことを目視で確認。
- [x] 帯は原画の左右端を完全に透過させ、中央に向かって不透明になる。劇場の幅に合わせて描画した時も縁の形と端のフェードを確認。
- [x] 盾の額縁単体で内側が透過することと、面を重ねた際に隙間の画素がないことを検査。
- [x] 劇場で白・金の文字と補正の札の濃い文字を重ね、PC 1280×720 と横持ちスマホ 844×390（Chromium エミュレーション）で余白と読みやすさを目視で確認。
