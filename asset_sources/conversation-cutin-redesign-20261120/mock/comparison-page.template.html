会話カットイン 再設計案

はじめの顔のカットインを、絵・枠・出し方・置き場の4点から作り直す案です。下の画面は本編の会話画面（新版の見た目）で、いまの版と再設計案を同じ場面で切り替えられます。再設計案の絵は仮のもの（今の立ち絵の原画を寄せて切り抜いただけ）で、方向が決まったら Codex で専用の絵に差し替えます。

背景と直前の流れは撮影用に短くしています（本編では各場面の背景になります）。再設計案の動きはこのページでの再現で、音は入っていません。

安っぽく見える理由

  1. 絵が立ち絵の流用

    全身の立ち絵（896×1200）から顔のあたりを切り抜いて縮めています。顔は元の絵で幅150pxほどしかなく、スマホの高精細な画面では線が甘くなります。体も胸の途中で切れるので、「小さい立ち絵が箱に入っている」ように見えます。2026-11-07 に決めた「残す案が決まったら専用の絵を2〜3枚作る」が、まだ済んでいません。

  2. 枠が新版の画面と別の絵柄

    枠は紫のベタ塗りに斜線と薄茶の細い線です。新版の「夜紫の半透明の面と金の細い罫線」に合わず、影も光もないので、画面に紙を貼ったように見えます。

  3. 置き場所がぶつかる

    相手の台詞の行では、枠の真下に相手の名前が来て、相手の顔の枠に見えます。新版はウインドウの上の縁が無いので、枠の下端が宙に浮きます。相手が2人いる大会の場面では、目元の帯が左の人物の顔に重なります。

  4. 出たまま動かない

    台詞と同時に出て、次の行へ進むまで止まったまま残ります。止まった絵をじっくり見られるので、粗が目立ちます。音も、画面側の反応もありません。

  5. 最初に見る2回が、台詞の内容と合っていない

    序盤のアピール用に足した2か所です。冒頭の「なんか、負けられないなあ」は軽い口調なのに、決意の目元帯が出ます。つむぎの「……猫です」は、はじめの顔の話ではないのに、驚いた顔が出ます。

変えること

デザイン

  • カットイン専用の胸から上の絵を Codex で描く。立ち絵と同じ人・同じ画風のまま、顔を大きく、手や首の小さな仕草を入れる。
  • 枠は金の細い線と淡いラベンダーの光。中は同じ部屋の背景をぼかしたもの。帽子が枠の上へ少しはみ出す。
  • 宙に浮く箱をやめ、画面の左端から出る帯にする。形は「寄りの帯」と「目元の帯」の2つだけ。感情の違いは絵・色・動きで出す。

出るタイミング

  • 相手の行（その顔）：相手の顔と同じ高さに、台詞が出切ってから差し込む。約1秒で自分から消える。
  • はじめ自身の行：名前のすぐ上。帯が先に開いてから台詞が出て、次の行へ進むまで残る。
  • 決意：画面を横切る目元の帯を0.9秒だけ。
  • 既存の効果音から短い音を付ける。SKIP・LOG・動きを減らす設定での扱いは今のまま。

頻度

  • 出すのは3種類の場面だけ：相手がはじめの顔に触れた行／大会の決意と敗北／絆の締めくくり。
  • 目安は1章あたり「その顔」2〜3回、大会で1回、締めくくりは相手ごとに1回。1会話1回は今のまま。
  • 内容に合わない2か所を外し、台本に元からある「その顔」の台詞へ置き直す。

置き場の見直し

いまの20か所と、足す候補です。台詞は書き換えません。

種類台詞判定理由・変更

Codex で描く絵

最初は4枚で、いまの型をすべて置き換えられます。1回の生成で1枚、1024×1024、胸から上、背景は単色（透過はこちらで抜きます）。参照には同じ表情の今の立ち絵と、画風の基準2枚を渡します。貼り付け用の依頼文はリポジトリに保存しました。

動揺

目を見開き、片手が帽子のつばへ上がりかける。「その顔（軽い）」に使う。

沈み

視線を落とし、つばの影が目元にかかる。肩が少し落ちる。「その顔（重い）」と敗北に使う。

受け取る

目を細めた小さな笑み。会釈の手前まで頭を下げる。絆の締めくくりに使う。

決意

つばを指でつまんで下げ、あごを引いて前を見据える。目元の帯に使うので顔を大きく描く。

あとで足すなら「照れ」（頬の赤み、首の後ろへ手）。「顔、赤いよ」と言われる行が3つあります。

別案：枠なし

枠を使わず、画面の左手前にはじめが立つ形です。貼り付けた感じは消えますが、カットインというより「主人公の立ち絵が出た」見え方になります。本編ではじめの立ち絵はほぼ出ないので、画面の約束事が変わります。相手が2人いる場面では左の人物と重なるため使えません。おすすめは枠ありの案です。

決めてほしいこと

  1. 枠ありか、枠なしか。おすすめは枠あり（上の画面の再設計案）です。
  2. 決意を、画面を横切る帯にしてよいか。0.9秒のあいだ相手の顔が隠れます。代わりに、相手が2人いても同じ形で出せます。
  3. 冒頭の1回を外してよいか。序盤のアピールは、アダム初回の「ふっ……その顔」へ移す案です。
  4. 絵は最初の4枚でよいか。照れの絵も先に欲しければ5枚にします。
