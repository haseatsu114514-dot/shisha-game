# けむりのとなり — 短編漫画20本

『水煙前線 -EN:CODE-』の人物を使った番外編。4コマ1本＋2コマ19本。各2コマは右→左、ページ内は上→下に読む。

りゅうじは最新採用の53歳・白系大柄チェックスーツ・色付き眼鏡・口ひげ・紫のネクタイで統一。参照正本は `brand/character_profiles.md`、`data/characters.json` と各人物の正規立ち絵。`comics.json` にネーム、作画指示、検品記録を保存。

見本の漫画は短い掛け合いとテンポのみ参考にし、人物・絵柄・既存ネタは流用しない。丸い輪郭とガッシュ／色鉛筆の質感による描き下ろし。ゲーム本編への画像登録・正規立ち絵の変更は含まない。
