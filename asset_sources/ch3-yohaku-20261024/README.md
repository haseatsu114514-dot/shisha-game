# 第3章「余白」店内背景

東京の久世朔の店で使う、夕方の店内背景。客がお茶だけでも座れる余地と、久世の観察ノートを画面右に置いた。既存の装飾的な店舗と並べても、左の広い白壁・奥の透ける仕切り・低い長椅子で見分けられる構成にした。
