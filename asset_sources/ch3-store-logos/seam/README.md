- 登録: `remake/js/core/store-logos.js` の `ch3_club`。横長の文字ロゴなので frame を文字の周り（[20, 191, 728, 130]）に詰め、地図の詳細欄（180×104 以内）で横幅いっぱいに出す。初めて入るまでは地点が `club_unknown` なのでロゴは出ない（店名がばれない）。
