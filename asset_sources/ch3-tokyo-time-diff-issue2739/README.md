# Issue #2739 向井の東京店・昼背景候補

## 選定と用途

`data/background_catalog.json` の `bg_mukai_shop.png` は `place: mukai_shop`、`time: ""` の単一画像で、実際のゲーム背景 `remake/img/backgrounds/bg_mukai_shop.webp` は青い夕景の窓外と点灯した室内を描く。昼の訪問用に差分を1枚作成した。`bg_mukai_shop_day_original.png` が原画、`bg_mukai_shop_day_preview.webp` が確認用圧縮画像。どちらも1920×1080。

`candidate.json` は正式登録時の検討用台帳素材である。`data/background_catalog.json` と `remake/img/backgrounds/` は変更していない。採用とゲームへの組込は別途判断する。

## 参照と生成指示

- 既存背景・構図参照・画風参照: `remake/img/backgrounds/bg_mukai_shop.webp`。現物を入力画像として Codex 組込み imagegen の `lighting-weather` 編集に使用。
- 画風固定: 入力画像のゲーム背景そのものの絵柄、筆致、線の少ない写実寄りの手描きアニメ背景、質感、遠近感、色の扱いを厳密に維持する。別スタイルへ描き直さない。
- 構図固定: 同一カメラ位置と画角。左の長い緑色ソファとクッション、複数の丸卓と椅子、中央奥の大きな窓と手すり、奥右の階段、右のエスプレッソマシン・積まれた白いカップ・長いカウンター、壁灯と床タイルを元画像と同じ位置・形・数で維持。窓外の建物配置も維持する。
- 時刻変更: 窓外を明るい昼にし、柔らかな自然光を店内に入れる。屋外光と室内の光・影のみ変更する。
- 禁止: 人物、シーシャ機材、植物、新しい家具、看板、文字、ロゴ、透かしを追加しない。

組込み imagegen の出力は1672×941だったため、納品規格に合わせて Lanczos 補間で1920×1080へ拡大し、PNG と品質92の WebP で保存した。

## 目視検品

- 既存背景と同じ主要な家具配置、窓、階段、カウンターの構図を確認。
- 昼の窓外と店内の自然光を確認。背景植物の追加なし。
- シーシャ機材なし。HMD・ボウルトップの形状検品は対象外。
- 採用判断時には、元画像から一部の椅子やカップの細部が変化している点も比較すること。
