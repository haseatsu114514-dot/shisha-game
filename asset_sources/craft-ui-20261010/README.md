# 制作UIのモックアップ反映（TH47〜55）

オーナー提示の16:9モックアップを参照し、採用済みの人物・店舗・機材素材を使って実ゲームの制作画面を更新。
背景画像は追加せず、既存の温度アニメーションを使用する。枠・ボタン・ダイヤル・針はCSS/SVGで描画。

| 実画面 | 内容 |
|---|---|
| [01-pull-desktop.png](01-pull-desktop.png) | 1280×720。左の作業風景と温度計、右の半円ゲージ、金縁の吸うボタン。最適温帯の中央に白線。 |
| [02-up-drawing.png](02-up-drawing.png) | 右の上げ吸いを止めた一口の途中。針は固定、左の水泡が動き、温度が徐々に上がる。 |
| [03-down-drawing.png](03-down-drawing.png) | 左の下げ吸いを止めた長い一口の途中。温度が徐々に下がり、吸い終わるまで両ボタンを無効化。 |
| [04-pull-mobile.png](04-pull-mobile.png) | 844×390の横向きスマホ。16:9の作業台を画面内に収める。 |

上げ吸いは1.4秒、キープは1.9秒、下げ吸いは3.2秒。両端は強いぼこぼこ音と水泡、キープは少し控えめ。
現在の人物の動きは採用済み立ち絵の呼吸動作。今後の吸引動画は `.bench-worker[data-draw]`（`up` / `keep` / `down`）に接続する。
温度の計算・針の再開・音の終了は同じ一口の完了に合わせる。

## 検証

`remake/test/pull_draw.mjs` で通常入力・連打・キー長押し・提供の制限、温度の補間、音の開始と停止、画面離脱、熱管理、動きを減らす設定、スマホの操作領域を確認。上げ約1.71秒／下げ約3.47秒で完了（ヘッドレス描画環境での測定。設定値は1.4秒／3.2秒）。

`remake/test/thermal_background.mjs` で既存の温度演出・炭交換・葉の消耗・体力・焦げ／冷え切り判定の引継ぎを確認。両テストはPASS、ページ例外0。
