## 採用（Claude 選定。オーナーが別案を選んだら `build.py` の `ADOPT` を書き換えて再実行）

| 用途 | 採用 | 理由 | ほかの案 |
|---|---|---|---|
| ゲームの遠景（空・砂丘） | **B** | 中景の砂丘の稜線がはっきりしていて、走っている時も奥行きが読める | A（静か）・C（霞が強い） |
| 会話の背景 `bg_dubai_dunes_day` | **C** | 車がいちばん小さく、立ち絵の入る中央手前がいちばん空いている | A・B は車が大きく左端で切れる |
| 砂煙 | **C** | 横に広く低い形が、板の後ろに流れる砂煙に合う | A（丸い）・B（縦に立つ） |
| 大岩・小岩 | **A・A** | 陰が濃く、明るい砂の上で遠くからも形が読める。大小とも同じ描き方 | B（滑らか）・C（層状） |
| 旗竿 | **A** | 旗がいちばん大きく、細く縮めても旗だと読める | B・C |
| ゴールの幕 | **A** | 布の色が砂と夕日の色になじむ | B（白い）・C（横長） |
| はじめの背面（滑走） | **B** | 頭が真後ろで、耳・頬が見えない（「顔を見せない背面」の条件にいちばん合う）。両足の留め具も見える | A・C は耳と首の端が少し見える |

## 加工（`build.py`）

- 描き足し・色の変更はしない。行ったのは次の4つだけ:
  1. **低い alpha の微粒子の除去**: alpha 8 未満を透明にし、最大の塊の1%未満の小さな塊（縁からはみ出した点）を消した（消した画素数は `adoption.json` の `stray_alpha_cleared`）。
  2. **切り抜きと縮小**: 透明な余白を切り、乗算済みアルファで縮めた（縁に暗い色がにじまない）。背面 768px 高・大岩 512px 幅・小岩 384px 幅・旗竿 512px 高・ゴール 1024px 幅・砂煙 256px 幅。
  3. **遠景の空と陸の分離**: 1800px 幅に縮め、空（地平線の8px下まで）と陸（稜線の12px上から下端、空の青と雲を透明にした）の2枚にした。ゲームは空→太陽→陸の順に重ねるので、夕日が砂丘の稜線の後ろへ沈む。空はゆっくり、陸は速く横へ流れる（カーブのパララックス）。
  4. **会話の背景**: 1672×941 を 1280×720 に縮め、はみ出す分だけ中央で切った（縦横比はほぼ16:9）。
- 基準点: 背面は板（明るい橙）の重心を足元にした（`anchor` x 0.6125・y 0.833）。旗竿は竿の足（x 0.0591）。数値は `adoption.json` と `remake/js/minigames/desert-ride-art.js` の `DESERT_ART` が一致し、`remake/test/desert_ride.mjs` が照合する。

## ゲームでの使い方と、まだ無いもの

- 左右・ジャンプ・着地の構え・転倒の姿勢は、背面の1枚を板の重心を軸に傾け・縮めて表している（差分の画像はまだ無い）。
- 起伏・コースの路面・太陽・夕方の色は Canvas で描く。絵が読み込めない間・失敗した時は、以前の図形で描く（遊びは止まらない）。
- Codex への次の依頼（`docs/spec/desert_ride.md` §4）: 背面の差分5枚（今回の **B を基準** にして lean_left・lean_right・jump・brace・fall）、遠景と会話背景の夕方版（今回の **遠景B・会話C** を基準に同じ構図で）、ヌールの立ち絵（normal を先に3案→選定→smile・surprise）。
