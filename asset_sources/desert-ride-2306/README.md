## 第4弾（2026-11-02・PR #2333 のコメント・DSR08）

採用した遠景B・会話C・背面Bを基準に Codex が描いた続き。ZIP（SHA-256 `a2e51cde303a597de9d5bdd4d122b9b66d457c84047f7f25f1e9c6b9062678bf`）はコメントの値と一致し、同梱の目録の全項目も一致した。原画は `raw/phase4/`（Codex の README・HANDOFF・PROMPTS・検品記録は `codex-*`・`PROMPTS.json`）。Codex 側で縮めた候補（`candidates/`）は使わず、同じ `build.py` で原画から作った。

| 用途 | 採用 | 確かめたこと |
|---|---|---|
| 遠景の夕方 | ✅ `backdrop_dusk` | 昼Bと1画素以内でそろう（稜線のずれを相関で測定）。昼で作った陸の透明度をそのまま使う。太陽は描かれていない（ゲームが描く） |
| 会話の背景の夕方 | ✅ `bg_dubai_dunes_dusk` | 会話Cと同じ構図・同じ切り方。右に夕日 |
| 背面の差分5枚 | ✅ lean_left・lean_right・jump・brace・fall | 服・髪・板が背面Bと同じ。原画はどれも 1024×1536 なので、背面Bを 768px 高にした倍率（0.561）をそのまま掛け、頭の大きさがそろうことを並べて確認。左右は画面の左右（Codex の記録どおり、最初の「左」の依頼が右に出た分を右として残し、左は別に描き直したもの。反転はしていない） |
| ヌールの normal | ✅ **A**（2026-11-02 オーナー選定） | 3案は別々のデザイン（A は簡素、B はリュック・耳飾り・腕時計、C はネックレス・腕時計が指定外）。B・C は採用しない。画風は細かいドット絵寄りではなくアニメ塗り寄り。`build.py` の `noor_portrait` が 896×1200 に縮小・配置（人物の高さ 0.975・足元の余白 14px・重心を中央・透過は原画のまま）。顔の位置は `data/portrait_metrics.json`、顔アイコンは `tools/make_face_icons.py noor`。頭身 7.96 で標準より頭が少し小さい（WARN） |

- 基準点: 姿勢ごとに板（明るい橙）の重心を測った（`adoption.json` の各 `anchor`）。転倒は板が体から離れるので、体と板の不透明な画素の横の中心と、下端の少し上にした。
- 転倒の原画は、離れた板の留め具がはっきりしない（Codex の留保）。走っている最中は 0.8 秒ほどしか出ないので、そのまま使う。

## 第5弾（2026-11-02・ヌールの表情差分・DSR10）

採用した normal A を基準に Codex が顔だけ描き変えた smile・surprise（各1案）。ZIP（`noor-dsr10-2366-review-NOT-ADOPTED.zip`、SHA-256 `a8b9665bceed50b4fa714f6f33403bebb17cb4f3df8b6f5fc0bba126695a6e3c`）の同梱目録は全部一致し、同梱の基準画像は採用した A の原画と同じ（SHA-256 `2e72bc62…3b53`）。原画は `raw/phase5/`（Codex の README・PROMPTS・目録は `codex-*`・`PROMPTS.json`。画風見本のみんと・あげはは採用済みの絵なので複製しない）。

- 服・髪・サングラス・スカーフ・ブーツ・腰に手のポーズが A と同じで、新しい小物は無い。笑顔は目を閉じて口を開けて笑う、驚きは目を開いて口を小さく開ける。
- 布やブーツの輪郭は数画素ずれる（顔だけを描き変えた生成のため）。normal と同じ切り抜き・倍率・位置をそのまま掛けたので、表情を切り替えても体と足元は動かない（`tools/portrait_metrics.py faces noor` で 0件）。
- 登場カットインはグラフィック絵柄で依頼中（DSR11・`docs/spec/desert_ride.md` §4）。

## 加工（`build.py`）

- 描き足し・色の変更はしない。行ったのは次の4つだけ:
  1. **低い alpha の微粒子の除去**: alpha 8 未満を透明にし、最大の塊の1%未満の小さな塊（縁からはみ出した点）を消した（消した画素数は `adoption.json` の `stray_alpha_cleared`）。
  2. **切り抜きと縮小**: 透明な余白を切り、乗算済みアルファで縮めた（縁に暗い色がにじまない）。背面 768px 高・大岩 512px 幅・小岩 384px 幅・旗竿 512px 高・ゴール 1024px 幅・砂煙 256px 幅。
  3. **遠景の空と陸の分離**: 1800px 幅に縮め、空（地平線の8px下まで）と陸（稜線の12px上から下端、空の青と雲を透明にした）の2枚にした。ゲームは空→太陽→陸の順に重ねるので、夕日が砂丘の稜線の後ろへ沈む。空はゆっくり、陸は速く横へ流れる（カーブのパララックス）。
  4. **会話の背景**: 1672×941 を 1280×720 に縮め、はみ出す分だけ中央で切った（縦横比はほぼ16:9）。
- 基準点: 背面は板（明るい橙）の重心を足元にした（`anchor` x 0.6125・y 0.833）。旗竿は竿の足（x 0.0591）。数値は `adoption.json` と `remake/js/minigames/desert-ride-art.js` の `DESERT_ART` が一致し、`remake/test/desert_ride.mjs` が照合する。

## ゲームでの使い方と、まだ無いもの

- 左右・ジャンプ・着地の構え・転倒は第4弾の差分の絵で表す（`riderPose`）。差分が読み込めない間は、背面の1枚を傾け・縮めて表す。
- 絵が読み込めない間・失敗した時は、以前の図形で描く（遊びは止まらない）。
- 起伏・路面・太陽は Canvas。夕方は同じ構図の夕方の遠景を重ね、砂・岩・人物にも薄く暖色をかける。
- まだ無いもの: ヌールの登場カットインのグラフィック絵柄（人物絵・背景。DSR11）。届くまでは立ち絵を使う簡易版。
