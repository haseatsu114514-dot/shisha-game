# 蒸らしのアタック・リチャージ（2026-10-11）

PR #282マージ後のSF58〜64。オーナー提供の `owner-slash-reference.png` は三日月状の光の参考のみ。ゲームの画像・音を流用せず、アタックのアイコンと光はSVGで実装した。

- ハートは通常水色、被弾後はピンク赤。実判定と中心・直径が一致する白い塗り丸を表示し、装飾の輪は外した。
- アタックは前方80px／80度、再使用まで1.8秒。四方向キー＋Z、ボタン、スマホのスティック＋ボタンに対応。入力なしは上側の前方。長い言葉の端が範囲に触れた場合も消し、後方・遠方は残す。
- リフレッシュは一台一回制を撤回し、使用後8秒で一回分を再充填。根性による既存の範囲・一段階のメンタル回復を保持。各ボタンは充填の輪と残り秒数を表示する。
- 操作欄はリフレッシュ／アタック／精密／スティック、間隔12px。銀色のノブを10px上げ、実際の中立入力もその中心へ合わせた。

80px・80度の扇形へ縮小した（既存スクリーンショットは縮小前の試写記録）。アタックに回復・無敵・出現停止・追加得点はなく、リフレッシュより短い範囲と待ち時間で使い分ける。バランスの初期値であり、長期の難易度を保証するものではない。
