# 斧投げの効果音（2026-11-11・作り直し）

オーナー「斧投げは最新のになってる？なんか効果音しょぼかったり」への対応。

それまでの斧投げの音は、その場で鳴らす短い合成音（雑音と単音の重ね・`core/audio.js` の旧 `playAxeSe`）だけで、刺さる音に重さが無く、
回って飛ぶ音・外れて跳ね返る音・床に落ちる音・ゲージを止める手応え・節目の音の区別も無かった（宣言・最後の1投・持ち替え・目標達成がすべて同じ「ピロン」）。

刺さる音の芯には、既存の録音 `assets/audio/se/minigame/axe_thunk_01〜03.wav`（Freesound「R15-11-Axe Thuds」craigsmith・**CC0**。出典は [../minigame-se/](../minigame-se/README.md)）を使い、
低い衝撃・板の鳴り・木の割れる粒を重ねた。ほかは `build.py`（numpy だけ）で合成した。乱数の種を固定しているので、何度作っても同じ音になる。

```bash
python3 asset_sources/music/axe-throw-sfx/build.py
```

| ファイル（`assets/audio/se/axe_throw/`） | 場面 | 作り |
|---|---|---|
| `throw.wav`（0.62秒） | 斧を放す（自分・相手） | 腕を振る「フッ」のあと、回る刃が空気を切る「ブン・ブン・ブン・ブンッ」。間隔が少し詰まり、近づくほど大きく高く（760→1550Hz）、同じ所に低い「ブン」（95〜150Hz） |
| `hit_1〜3.wav`（0.7秒） | 刃が板に刺さる | 録音の「ドスッ」＋低い衝撃「ドンッ」（約90→46Hz）＋板の鳴り「ゴォン」（158・386・702・1180Hz）＋木の割れる粒「パキッ」 |
| `killshot.wav`（1.4秒） | 宣言した青に刺さる（キルショット） | `hit_1` ＋刃が震えて鳴る「キィーン」（1870Hz を2本少しずらしてうならせ、5160・3420・8120Hz を重ねる） |
| `bounce.wav`（0.35秒） | 柄から当たる・回りすぎで、板に当たって跳ね返る | 中が空洞の板を叩く「コンッ」（212・535・1310Hz）＋刃の小さな金属音 |
| `drop.wav`（0.9秒） | 落ちた斧が床で鳴る | 「ガシャン」（刃の金属 640・1495・2710・3990Hz と柄の木）＋小さく2回跳ねる＋転がる粒 |
| `stop.wav`（0.12秒） | 横・縦のゲージを止める | 歯止めの「ガチッ」（硬いクリック2つと小さな低い手応え） |
| `call.wav`（0.45秒） | キルショットを宣言する | 刃を構える「チャキッ」（擦れ＋カチッ）と、澄んだ金属の鳴り（2093Hz） |
| `cue_drum.wav`（0.9秒） | 最後の1投・持ち替え・延長戦の札 | 低い太鼓「ドン・ドンッ」（2打目が強い） |
| `cue_clear.wav`（1.0秒） | 目標達成（CHALLENGE CLEAR） | 明るい「シャーン」と、上がる鈴の4音（ド・ミ・ソ・ド） |

- 形式は既存の録音SEと同じ（モノラル 44.1kHz 16bit・計約0.7MB）。部品の終わりはなめらかに消し、途中で切れて「プツッ」と鳴らないようにした（スペクトログラムで確認）。
- 台帳 `game_files.json`（SHA-256）は `build.py` が書き出し、`remake/test/minigame_se.mjs` が照合する。

## ゲームでの鳴らし方（`remake/js/core/audio.js` の `AXE_SE`・`playAxeSe`）

- 斧投げで最初に操作した時に `preloadAxeSe` で全部を先に読む。読み込み前・取得失敗の間は、今までの合成音で鳴る（音が欠けない）。
- 歓声・勝ち負けは、既存の録音（`minigame/axe_cheer.wav`・`axe_win.wav`・`axe_lose.wav`。CC0）をそのまま使う。勝ちはファンファーレと歓声を一緒に鳴らす。元の録音が小さいので音量は 1 より上げる（歓声 1.8・ファンファーレ 1.6）。
- 0点で刺さった時は刺さる音を少し小さく（0.75倍）して失敗音を重ねる（喜ばせない）。失敗音（`miss`）は今までの合成音のまま。
- 音量は、それぞれの一番大きい0.15秒の大きさを測って、刺さる音が約 -16dB、投げる音が約 -21dB、ゲージを止める音が約 -30dB に来るようにした（`AXE_SE` の `gain`）。
