# サンドボードのブーストの効果音（2026-11-11・自作）

オーナー「ビリビリなる効果音とか欲しい、ブースト溜まると」「後ブースト時も効果音欲しい、早そうな」への対応。

外部の音源は使わず、`build.py`（numpy だけ）で合成した。乱数の種を固定しているので、何度作っても同じ音になる。権利はこのプロジェクトのもので、`.bgm` に梱包せず `.wav` のまま `assets/` に置く。

```bash
python3 asset_sources/music/desert-ride-boost-sfx/build.py
```

| ファイル | 場面 | 作り |
|---|---|---|
| `assets/audio/se/desert_ride/zap_sparse.wav` | 溜まり始めの放電（2秒ループ） | まばらな「ジジッ」（うなる矩形波＋雑音を細かく点滅させた弧）4本と、「パチッ」という火花 毎秒10個 |
| `assets/audio/se/desert_ride/zap_dense.wav` | 満タンに近い放電（2秒ループ） | 弧16本・火花 毎秒40個の、絶え間ない「ビリビリ」 |
| `assets/audio/se/desert_ride/boost_rush.wav` | ブースト発進（1.4秒） | 「ドンッ」（135→45Hz に下がる低音）＋「パシッ」（点火の雑音）＋「キュイーン」（500→2600Hz に上がる回転音）＋「シュゴーッ」（帯域が 350→3200Hz に上がってから抜ける風） |
| `assets/audio/se/desert_ride/boost_loop.wav` | ブースト中の風切り（2秒ループ） | 16Hz で細かく震える風圧、2Hz のうねり、低いうなり、細いジェットの鳴り（1750Hz） |

- 形式は既存の録音SEと同じ（モノラル 44.1kHz 16bit）。ピークは -9〜-14 dBFS。
- ループは「2周つないでフィルターに通し、後ろの1周を使う」ので、つなぎ目で音が途切れない。周期のある揺れ（16Hz・2Hz・6Hz）は2秒でそろえてある。
- 台帳 `game_files.json`（SHA-256）は `build.py` が書き出し、`remake/test/desert_ride_sfx.mjs` が照合する。

## ゲームでの鳴らし方（`remake/js/core/audio.js` の `DESERT_SE`・`desertLoopLevels`）

- **放電**: ゲージが 1 割を超えると `zap_sparse` が小さく鳴り、溜まるほど大きくなる。半分を超えると `zap_dense` が混ざり始め、満タンでは `zap_dense` が主になる（音量 最大 0.25）。溜まるほど再生の速さも少し上がり、鋭く聞こえる。ブーストを使うと止まる。
- **発進**: ブーストと立て直し（リカバリー）の瞬間に `boost_rush`。それまでの短い「シュッ」（`boost_whoosh.bgm`・Joseph Sardin「Whoosh #8」）は使わなくなった（ファイルは残す）。
- **ブースト中**: `boost_loop` を 0.2 の音量で鳴らし、ブーストの残りが 0.5 秒を切ると小さくなって消える。

音量は、既存の滑走音・風の音（平均 -40〜-31 dBFS を 0.14〜0.34 で鳴らす）より少し上に来るよう、ファイルの平均の大きさを測って決めた。
