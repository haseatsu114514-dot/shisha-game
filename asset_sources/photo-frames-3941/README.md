## 先行60枚の点検（2026-11-27）

オーナー「プリクラやチェキがまだそもそもの画像少ないので補充して欲しい　今か仮のは作ったけどクオリティ低いのも混ざってるから　収集要素として多めに用意したい」。
先行60枚を、正規の立ち絵（`remake/img/sprites/character_variants/new/`）と顔を並べて見比べた。目視は比較カタログ（PDF）と、P01〜P07・C01〜C07 は原画で行った（P08〜P30・C08〜C30 は縮小した大きさでの目視。手指の細部は原画で再確認が要る）。

### 判定の目安

- ✅ そのまま候補に残せる
- ⚠ 使えるが弱い（理由を書いた）。追加候補の同じ題材と見比べて選ぶ
- ❌ 作り直し（正本との食い違い・質の不足）
