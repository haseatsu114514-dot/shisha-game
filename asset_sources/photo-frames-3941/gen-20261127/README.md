# チェキ・プリクラの追加候補（2026-11-27）

オーナー「プリクラやチェキがまだそもそもの画像少ないので補充して欲しい　今か仮のは作ったけどクオリティ低いのも混ざってるから　収集要素として多めに用意したい」（要望台帳 PFC01〜）。
先行60枚（[../README.md](../README.md) の点検）の弱み、つまりチェキに手書きの一言が無い・プリクラに落書きの文字が無い・はじめ一人が多い・正本と違う人物（P07 ひより・P24 ヨル）を埋める方向で作った。
**どれもまだ本編には入っていない。** 選定ページ（Artifact「プリクラ・チェキ候補」 https://claude.ai/artifact/5so3tbBpBNFngkNb76VoK5 ・オーナーだけが開ける）で「使う」を付けた番号から組み込む。

## 作り方

- `gen.py` と `jobs.json`。OpenAI の画像の編集（`/v1/images/edits`、モデル `gpt-image-2.6-sunburst`、品質 high、1024×1536）。鍵は環境変数から読み、値は記録していない。
- 参照に渡した絵（すべて採用済み）:
  - チェキ: 1枚目＝本編の初来店チェキ（`remake/img/cgs/cg_minto_first_cheki.webp`）から作った白紙の台紙の型（台紙と写真の窓の位置はそのまま）、2枚目＝初来店チェキそのもの（写真の質と手書きの筆致の見本）、3枚目＝みんとの正規の立ち絵、2ショットは4枚目にはじめの正規の立ち絵。
  - プリクラ: 1枚目＝本編の半分こ用シール（`cg_ch2_ageha_purikura_strip.webp`。2コマの形と落書きの見本）、2枚目＝はじめの正規の立ち絵、3枚目以降＝相手の正規の立ち絵（`remake/img/sprites/character_variants/new/`）。
- 画風は [立ち絵の規格](../../../docs/portrait_standard.md) 3節の英文をそのまま足した。はじめはネックレス・鎖・ペンダントを描かないよう明記した（P01 の反省）。ひよりは高いポニーテール、ヨルは41歳の女性と明記した。
- 文字: 手書きの言葉は、各キャラの正本の呼び方・口調に合わせた（みんと・ましろ・ひより・ヨル・凛想＝「はじめくん」、あげは＝「ハジメっち」、組長＝「あんちゃん」、サメちゃん＝「お主」）。出力の文字は全部目で読んで確かめた（読めない字・違う字は無かった）。
- 大きさ: チェキは出てきた台紙を見つけて本編の位置（台紙 x45〜948・y72〜1530、写真の窓 x105〜888・y128〜1231）へ合わせ直し、台紙の外を本編と同じ透過にした 993×1584（本編の演出 `motions/cheki.js` がこの位置で写真を切り抜く）。プリクラは真ん中を縦長に切って 640×1080。
- API の出力そのもの（`raw/`）は保存していない（`python3 gen.py --refit ID` で合わせ直しだけやり直せるのは、同じ作業場所に残っている間だけ）。

## 検品（目視・原寸）

- 人物: 正規の立ち絵と顔・髪型・服を見比べ、全員同じ人に見えることを確かめた。鳴の上着は今の正規の立ち絵（茶とクリーム）どおり。はじめにネックレスは無い。
- 手: 指の本数・ハートやピースの形に崩れは無い。
- 作り直したもの: C40（1回目は、はじめが自然に笑っていて「かたいよ〜？」の言葉と合わなかった → 汗をかいた固い顔で作り直した）。
