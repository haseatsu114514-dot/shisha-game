# ひよりのランダムタイトル5場面（#486、旧 #342 B）

採用済み夕暮れ／窓際v2／雨上がりの3枚を維持し、書店とラーメン店の新2枚を生成して実参照を5枚にした。ユーザーの5パターン制作・ゲーム実表示・生成素材の利用依頼と既存マージ許可に基づく追加で、他チャットの未承認候補の一括採用や既存21枚の置換ではない。新2枚の個別選定が既に行われたとは記録しない。

本人は25歳、健康的な157cmの体格、ピンクブラウンの高いポニーテール、茶目、柔らかな同じ顔。現在の白〜アイボリー立ち襟フレンチスリーブのレース、黒スラックス、細い時計と耳飾りを正式normalと採用済みCGに合わせた。正式normal／質感のkeyvisual／採用済み夕暮れCGを実際に開いて生成ツールへ添付し、参照の役割を実指示に分けた。原画と実指示、参照hashはgeneration.jsonとraw/、prompts/に保存。

- 書店：明るい昼光・クリーム壁とくすんだ金属棚・本を両手で支える別ポーズ。顔・手・本の支え、髪、レース、時計、バッグを出力後に目視した。病弱や悲惨な過去を示す描写、室内植物、偽文字、機材なし。
- ラーメン店：赤とクリームのタイル、昼光、カウンターに置いた普通の大きさの丼。右手の箸から麺が丼へつながり、左手はレンゲ、時計は左手首。顔・手・箸の持ち方・麺・レンゲと丼の縮尺を目視した。湯気は食べ物から。公開の小さな笑みで、斧投げの大声／核心を先出ししない。文字、ブランド、室内植物、シーシャ・HMDなし。

原画は両方1024×1536の不透明な縦2:3。PNGは原画の同一バイトコピー。WebPは既存のencode関数で新2枚だけ変換し、旧画像は再生成しない。baseline.jsonは旧画像のバイトhashと正規ひより全表情を保存し、素材ID改名でも同じ画像が残ることを検証できる。元のメタデータはbase_shaのGitHub正本から参照する。

register.pyはtitleArtsに新2登録とwebpの新2パスだけを追加し、立ち絵のアンカー・縮尺・他のmanifest項目・共有generated timestampを維持する。登録時の検証とサイズ・hashはregistration.json。generation.jsonのregistered=falseは生成時点の履歴で、現在の登録はregistration.jsonを参照する。

検証はvalidate.py、remake/test/browser/hiyori_title_five.mjs、既存title_arts.mjs、保存6ケース、LIME VM。5枚内の均等な各bucketとキャラ間均等、同キャラ連続回避、PC／タッチ横持ち、縦持ちガイド→横持ち復帰、実友人／旧保存／複数恋人・LIME不変を確認する。全5枚は実際のpicker・prepareTitleArt・showTitleを通して表示し、表示用の偽画像へ置き換えない。

本編タイトルは従来の横向きガイドを維持する。縦持ちでガイドに覆われた状態を「CGが見えた」と扱わず、回転後に確認する。正式斧投げ・仕事相談・恋愛/友情・ハガルは後続の別Issue。CI・最新main・公開反映の結果はIssue/PRへ記録する。
