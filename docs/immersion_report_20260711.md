# 1章「テキストを自動スキップしたくなる」対策レポート（2026-07-11）

オーナー報告: 「1章は全体的にテキストを自動スキップしたくなるシーンが多い。
物語に没頭してちゃんと読んでもらうための工夫を考えてほしい。他にもゲーム体験として
直した方がいい所を挙げてほしい」→ 本レポートは**提案フェーズ**（実装はオーナーの採用指示後）。

---

## 1. 診断 — なぜスキップしたくなるか（ch1 実データ）

ch1 の dialogue 全ファイルを機械計測した結果:

| 指標 | 実測値 |
|---|---|
| イベント数 / 台詞行数 / 総文字数 | 97本 / 1,755行 / 約48,400字 |
| 選択肢・分岐の総数 | **18箇所（100行に1回）** |
| 15行以上あるのに選択肢ゼロのイベント | **46本 / 97本** |
| 40行超の長尺イベント | 4本（tournament_after 75行 / opening 53行 / day5_sumi_story 48行 / minto_first 47行） |
| 最長ノンストップ区間 | opening 41行連続・minto_first 47行連続クリック |

### 原因の整理（重要度順）

1. **受け身の時間が長すぎる（選択肢の枯渇）** — プレイヤーの動詞が「次へ」しかない
   時間が9割以上。ヒロイン訪問1〜5回目・スミさん夜話・大会前後、ほぼ全部が
   「見てるだけ」。手が暇になると手はSKIPボタンを探す。
2. **読まなくても損しない** — 報酬はシーン末尾に必ず出る（type:apply／テキストキュー）
   ので、読んでも読まなくても結果が同じ。効率で考える人には「スキップが正解」になっている。
3. **シーン頭の空気描写が長い** — 例: day5_sumi_story は誰も喋らない地の文が5行続いて
   から「はじめ。ちょっと残れ」。1回目は雰囲気でも、2回目以降の訪問イベントで
   毎回舞台説明から入ると「知ってる」で流される。
4. **山場が無音のまま** — BGM 5曲（bgm_map／bgm_tournament_wait／bgm_tournament_edm／
   bgm_result_emotional／bgm_rival_shop）が**0バイトのプレースホルダのまま**。
   マップ画面と大会クライマックスと優勝リザルトに音楽がない。
5. **くり返しイベントが同型** — 訪問イベントは「来店→会話→一服→報酬」で毎回同じ器。
   さらに固定夜イベントが14日中9日、**その日の行動が終わった後に自動で**始まる
   （プレイヤーが「早く次の行動を選びたい」モードの時に読み物が来る）。
6. **クリック単価が高い** — 吹き出し1回=全角48字まで。約48,000字÷48字≒
   本編だけで**1,000回以上のクリック**。1クリックで得られる情報が少ないと作業感が出る。

※ UI装備（AUTO・SKIP・LOG・文字速度4段階・J7自動演出）は既に揃っている。
足りないのは機能ではなく「**読みたくなる構造**」。

---

## 2. 提案 — 没頭して読んでもらう工夫（採用しやすい順にピックアップ）

### ★S: 構造で読ませる（効果大）

**S1. あいづち・内心選択肢を長シーンに挿す（10〜15行に1回目安）**
- 2択・どちらでも本筋は同じ所へ合流。ただし直後の1〜2行だけ相手の返しが変わる。
- はじめの性格アーク（1シーン1テル・内心モノローグ）の器としても使える:
  片方を「素直な反応」、片方を「ちょっと得意げな内心」にすればキャラ表現と操作が両立。
- エンジン改修不要（既存の choice + branches だけで書ける）。
- まずは選択肢ゼロ46本のうち1,000字超の上位から:
  `ch1_minto_first`(47行) `ch1_day5_sumi_story`(48行) `ch1_naru_first`(35行)
  `ch1_minto_fifth`(38行) `ch1_tsumugi_fifth`(42行)。

**S2. 「読んだ情報が武器になる」ループ（知識報酬）**
- 会話に出た常連の好み・審査員の流儀・シーシャ知識を、その場で
  「……常連ノートに書き加えた」「用語集に追加された」のトーストで**登録演出**する
  （常連ノート・用語集は既存UI。登録の瞬間を見せるだけで「今の行は拾う価値があった」になる）。
- 登録された知識が後で実利になる: バイトで高橋さんの好みを当てる選択肢が出る、
  南雲の「最後まで温存する流儀」を読んでいた人は審査バーの動きが腑に落ちる、等。
- 「スキップすると後で選択肢の意味が分からない」＝読ませる仕掛けの王道。

**S3. 選択のコールバック（世界が覚えている）**
- 優勝インタビューの回答をなるが拾う仕掛けは実装済み（B2）。この型を増やす。
- 例: ヒロイン訪問1回目の選択を3回目で本人が言及する
  （「前に○○って言ってたでしょ」）。1箇所2〜3行の追記で済み、感情効率が高い。

### ★A: テキスト規範（書き方で読ませる）

**A1. シーン頭3行フック規則**
- 冒頭3行以内に「今日は何が起きる話か」を立てる。空気描写は bg／sfx／fx に委譲し、
  ドラマが立ち上がってから差し込む。
- 例: day5_sumi_story は「はじめ。ちょっと残れ」を1〜2行目へ前倒し、
  閉店後の静けさ描写は瓶が出たあとに回す。
- 訪問2回目以降は舞台説明を原則書かない（読者はもう店を知っている）。

**A2. 地の文の連続は2〜3行まで／40行超イベントは分割**
- 長尺4本が対象。特に `ch1_tournament_after`（75行）はch1の感情的クライマックスなので、
  表彰→帰り道→夜のLIME（採点表）のような場面転換で2〜3ブロックに割り、
  間に選択肢か背景転換を挟む。
- あわせて総量も見直す。「スキップされる」の答えの半分は「テキストが多すぎる」。
  選択肢ゼロ46本の地の文を2〜3割刈るパス（story-review案件）を推奨。

**A3. くり返しイベントは「差分ファースト」**
- 訪問2回目以降は「前回と違うこと」から始める（見ない客がいる・店の様子が変・
  ヒロインの状態が違う）。GG2の三拍子体裁は維持したまま頭の1行だけ変える。

### ★B: 演出の抑揚（読み心地）

**B1. BGM発注が最優先**（曲はオーナーのSuno発注待ち・プロンプトは
`docs/bgm_suno_prompts.md` に納品済み）
- マップ・大会待機・大会本番・優勝リザルトが無音系のまま。没入の投資対効果は
  今これが一番高い。テキストを1行も変えずに体感が変わる。

**B2. 話者別テキストブリップ（タイプ音）**
- 文字送りに合わせて話者ごとに音程の違う小さな「ポポポ」を鳴らす
  （Undertale／どうぶつの森方式）。ボイスなし作品で「キャラが喋ってる感」を出す定番。
  WebAudio合成SEの仕組みは既存。地の文は無音・音量控えめで乱発感を防ぐ。

**B3. 重要行の「間」**
- `[imp]` タグ行の表示前に0.3〜0.5秒の自動の溜めを置く（クリック待ちではない）。
  J7の振動・白フラッシュと同系の自動演出として engine 側に一括で入れられる。

**B4. AUTOを読書モードとして磨く**
- 現状AUTOの送り間隔は行の長さに関係なく固定（1400ms等）。
  「基本値＋文字数×係数」の可変にすると、AUTO派がストレスなく「観る」体験になる。
  スキップしたい人をAUTOに誘導できれば読了率は上がる。

### ★C: スキップとの共存（禁止ではなく設計）

**C1. 未読SKIPにワンクッション**
- 現状SKIPは未読も60ms/行で飛ぶ。敗北→再挑戦の救済として必要なので廃止はしないが、
  未読区間でSKIPを押した時だけ「未読のシーンです。飛ばしますか？」を1回挟む
  （既読管理は dialogue_id 単位で十分・行単位は不要）。
- 体験版で誤タップ→ストーリー消失→離脱、を防ぐ保険でもある。

## 3. その他のゲーム体験の改善候補（第2問）

1. **初見の敗北率が未検証（台帳A7・据え置き中）** — 大会は2位以下=GAME OVERの一発勝負。
   初見が普通に読んで普通に遊んで勝てるかを playtest-feedback（初見なりきり通し）で検証する。
   体験版の離脱ポイント第1候補。テキスト改善と同じ優先度で推奨。
2. **日常パートの「今日やるべきこと」の薄さ** — 大会レギュレーション（ミント2g）と
   審査の仕組みが、14日間の行動計画にあまり接続されていない。目的が薄いと日常パートが
   作業になり、テキストスキップの遠因になる。スミさんの宿題形式で小刻みなミニ目標
   （「今週は吸い出しジャストを3回決めてみろ」等＋達成報酬）を出す案。
3. **「新しい話がある」の見える化（抑制つき）** — 固定夜イベントの「!」予感バッジは
   実装済み。訪問イベント側も「好感度が次の段階に届く時だけ」ピンに小さな印を出す
   （全部に付けると攻略ゲー化するので条件は絞る）。
4. **大会ステージ背景がプレースホルダ（台帳A2残）** — クライマックスの画面。
   Codex発注のみで直る。
5. **体験版まわりの保留4件（A3終わり方／A4感想導線／A6セーブ互換／A8縦持ち）** —
   オーナー判断待ちのまま。テキスト改善と同時期に決めたい。

## 4. おすすめの進め方（採用時の順序案）

1. **即効・テキスト外**: BGM発注（B1）＋大会背景発注（A2残）＝素材待ちを先に走らせる
2. **第1弾実装**: S1（あいづち選択肢を長尺9本へ）＋A1/A2（頭3行フック・長尺分割。
   まず `ch1_tournament_after` と `ch1_day5_sumi_story`）
3. **第2弾実装**: S2（知識登録トースト＋実利1〜2箇所）＋B2（話者ブリップ）＋B3（間）
4. **検証**: playtest-feedback で初見通し（A7も同時に消化）
5. C1（未読SKIP確認）とB4（AUTO可変速）は第2弾に同乗可

どれを採用するか（全部盛り／S+Aだけ／まず1〜2個試す）の指示で着手する。
