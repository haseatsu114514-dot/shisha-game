# A7: 初見敗北率の検証レポート（2026-07-16）

台帳A7（2026-07-11起票）「初見が普通に読んで普通に遊んで勝てるか」の計測結果。
計測スクリプトは `web/test/firstplay.mjs`（調査用・恒常テストではない。合否を持たないため
web-build-test スキルの一覧には数えない）。

## 初見プレイヤーのモデル化

- **選択はチュートリアルで教わったとおり**: トライアングル配置・蒸らし8分・ノーマル詰め・
  課題ミント2g＋ダブルアップル10g・テーマはフルーティ
- **タイミング系ミニゲームは下手**: ジャスト待ちをしない（炭は赤くなったら取る）、
  反応が遅れる、穴あけの打点が少ない、適温を待ちきれず提供する
- **FLAVOR TRIAL は適当**: 実績の裏打ちを気にせずランダムにぶつける
- **蒸らし弾幕**: リアルタイムのため被弾0〜3をランダム付与（直接演技せず）
- 準備の成果は控えめ（リハーサル rough〜good・練習ボーナス0〜4）

## 結果 — 9走 / 9勝（敗北率 0%）

| プロファイル | 優勝 | craft スコア（南雲バー=80が実質の勝敗線） |
|---|---|---|
| 寄り道少なめ（全ステ15） | 3/3 | 87 / 83 / 103 |
| 平均的（全ステ28） | 3/3 | 109 / 103 / 103 |
| やり込み気味（全ステ42） | 3/3 | 97 / **80** / 109 |

- 勝敗は事実上 **craft ≥ 80（南雲の一括投入）** で決まる（basis: `finishTournament()`。
  craft未達だと持ち点が動かず敗北、達すると必ず逆転＝乱数の影響はほぼ無い）。
- 1走だけ **ちょうど80** があった＝ミニゲームが全体的に崩れると境界線に触る。
  床はバーのすぐ上にある。

## 読み取り

1. **チュートリアルの教えに従う限り、初見はまず負けない**。選択（配置・蒸らし・詰め・
   課題遵守・テーマ相性）だけで craft の大半が積み上がり、ミニゲームの下手さは
   ±15点程度の揺れに収まる。体験版の離脱懸念だった「初見お手上げ」は**確認されなかった**。
2. **負け筋は「教えに逆らう選択」**に集中している（敗北テスト=screenshots.mjs も
   高火力テーマ×耐熱不足・炭4個・蒸らし3分・かため、と選択を外して負けている）。
   「稽古で教わったことを守れば勝てる／外すと負ける」はスミさんの物語と噛み合った設計。
3. **調整の提案は不要と判断**（バランス変更はしていない）。むしろ「全部教わったとおりに
   やって、ミニゲームも全部きれいに決まる」と craft 100超で圧勝になるが、
   ch1は「南雲の1票だけで勝つ＝実力ではない」が正史なので、点差の演出とは矛盾しない。

## 留保（モデルの限界）

- 蒸らし弾幕の被弾は仮定値（0〜3）。実機の初見被弾がこれより多い場合、
  craft は最大−12点ずれる＝境界（80）を割る初見が一定数出る可能性は残る。
- 「選択も外す初見」（蒸らし0分を試す・炭4個で焦がす等）は測っていない。
  そこは意図された負け筋なので、敗北→再挑戦の導線（実装済み）が受け皿。
