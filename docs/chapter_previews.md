# 第1章の章末と次回予告

Issue #384。第1章で勝利とライバルの「もう一口」を受け取ったあと、はじめが採点表を気にし始める短い余韻から、第二章「才能の壁（ジェラシー・ヘイズ）」の断片へつなぐ。

## 演出と正本

`data/chapter_previews/ch2.json` がカット順・字幕・時間の正本。全11カット47.8秒。オーナーの「みんとが出る既存90年代風サンプルをベースに」に従い、Issue #415のセル画版v2の6場面・台詞・読みの間を採用した。スミの沈黙、なるとのすれ違い、みんとの気遣い、つむぎの水、アゲハの背中、ひとりの控え室をつなぎ、「誰のために、煙を作る。」で締める。

通常ゲームから4:3のTV枠へ切り替え、その中に16:9の元絵全体を収める。絵の下にサンプルと同じDotGothic16の字幕を置き、小さな寄り・止め絵、控えめな走査線と独自合成BGMでTVアニメの予告のリズムを作る。音声ナレーションは付けず、サンプルの読みの間を確保する。既存6場面の断片までを扱い、大会の順位・採点の説明、未知の送信者の正体、アゲハが去る理由は追加しない。

実装素材は `assets/cgs/ch2_preview/` に6枚、1664×936のWebPで合計約0.84MiB。`asset_sources/trailer-90s-anime-concept/images/` のPNGを形式変換したもので、元絵の再描画・リサイズ・クロップはしない。採用元と実装素材のハッシュ・変換条件は `asset_sources/ch2-preview/adoption.json`。生成指示と目視QAは既存サンプル側にある。DotGothic16は約2MiBで、サンプルと同じSIL OFLフォント。素材と書体は章末/再視聴時に読み、タイトル起動時には追加通信しない。

曲は `remake/js/chapters/preview-score.js` のオリジナルWebAudioスコア。既存のBGM音量/消音を尊重し、予告内の音ボタンは一時的な消音のみ。SEの音量を0にしても曲中の打楽器は音楽として残る。外部曲・音声は追加しない。

## 進行と保存

- `ch1.js` の大会後の会話・休養で見送った夜イベントを終えてから、`phase=cleared` を保存し `showClear()` へ進む。
- クリア画面の上へ `playChapterPreview()` を重ねる。完走/明示的スキップのみ `_ch1_preview_seen` を保存する。古いクリアセーブにも初回の予告を出す。
- 再視聴と単体APIは報酬・章・日付・好感度・LIME・本編の既読・手動保存枠を変更しない。中断・画面の撤去は予告を既読にしない。
- 予告終了後は通常16:9のクリア画面へ戻る。成長のレーダーを維持し、「次回予告をもう一度」「タイトルへ」を表示。未実装の第2章へ遷移するボタンは出さない。

一時停止・音・スキップはロード中も表示する。画像の読み込み/デコードに失敗した場合は再読込かスキップを選べる。準備前にタイムラインは進めない。タブが隠れた間は映像と曲を止め、ユーザーの一時停止はタブ復帰後にも保持する。Enterの連打ではスキップしない。Escでスキップ、Spaceで一時停止/再開、Tabで操作へ移動。動きを減らす設定ではパン・ズームを省く。

## 確認

`python3 remake/tools/serve_preview.py --port 8123` を起動し、`http://127.0.0.1:8123/remake/chapter-preview.html` の再生ボタンを押す。本編の保存は変更しない。本編の到達から確認する場合は新規第1章の大会優勝、またはクリア済みセーブから再開する。

`node remake/test/browser/ch1_preview.mjs` の9ケースで、自然完走の全11カット、既存サンプルの6枚/16:9構図の保持/ドット書体、初回と再視聴、旧セーブ、16:9復帰、PC/タッチ横画面、動き軽減、字幕と操作の収まり、非表示の停止、読み込み失敗と遅延、中断の後片付け、単体ページの保存不変を検証する。CIは `.github/workflows/ch1-preview.yml`。

実ブラウザの音付き録画とQAは `docs/qa/ch1-preview/`。録画は単体ページで本編と同じ台本・画像・演出・音楽を再生したもの。ゲーム本編の通し検証は `node remake/test/playthrough.mjs`。
