## 目的・確定仕様

- 参考の「CONTINUE?」演出のように**音声なしでも鮮烈な20秒**を作る。既存ゲーム公式立ち絵、表情差分、文字の飛び込み、SE、BGMで魅せる。ボイス付与は余裕ができてからでよい。
- ゲームオーバーの地点でまだ諦めてほしくない登場人物が、画面の向こうのプレイヤーへ語りかける。通常はスミさんの「俺たちの戦い」、プレミアは交際中のヒロイン。
- 既存の恋人プレミア確率は**20%**、同一恋人の連続登場なし。`state.lovers` のみから判定。第1章のみんとは大会のライバルなので除外。サメちゃん（かふか）はヒロイン候補だが現時点では恋愛ルート未接続、交際成立していない通常プレイでの抽選は不可。強制プレビューは可。
- 選択肢「大会に戻る／諦める」の**どちらを押しても、キャラに固有の一言とワンショット演出**を見せてから従来の遷移。
- 演出の20秒はセリフの長さであり、**本当の選択期限ではない**。0秒で選択は消えず、放置してもゲームが勝手に諦めない。「諦める」は本当に諦められる（確認ループ／罠にはしない）。
- デスクトップ・スマホ横持ちに対応。画面酔い軽減設定では揺れ・点滅を消す。ミュートでもセリフと操作は成立する。

## 1. 押下後のリアクション台詞：通常スミさん3種類

| 出演台本（ID） | 「大会に戻る」を押した瞬間 | 「諦める」を押した瞬間 |
| --- | --- | --- |
| `together`（共同責任） | 「……そうこなくっちゃな！ ほら、トング持て。俺も最後まで付き合うぞ！」 | 「……わかった。今日はここまでだ。悔しさは捨てんなよ。……お疲れ。」 |
| `disaster`（世界の終わり） | 「よおおし！ カルダモン絶滅回避！ 行くぞ、俺たちの続きだ！」 | 「……おう。新聞の一面は白紙にしとく。……よく頑張ったな。」 |
| `meeting`（反対多数） | 「可決ッ！！ 全会一致ッ！！ では直ちに、大会へ復帰だ！！」 | 「……反対一票、撤回。今日は閉会だ。お疲れ、はじめ。」 |

演出: 戻る＝`surprise → smile`（対応顔がある範囲で）。会議パターンは大きく架空の「可決」スタンプ。諦める＝一瞬だけ固まる→落ち着いた表情で送り出す。スミさんが選択を責めずに締めくくること。

## 3. 20秒の演出タイムライン（参考案）

| 秒 | 画面 | SE |
| --- | --- | --- |
| 0.0〜0.4 | 暗転から突然割り込み。いったん画面中央に白い `CONTINUE?` を叩きつける | `se_continue_interrupt`: 短い低音衝撃 |
| 0.4〜1.0 | 立ち絵が画面端から迫る。正規の顔差分を使用 | `se_continue_title`: 鋭い金属音 |
| 1〜5 | 文字送りを急加速。重要ワードだけ大きい／一回振動 | 台詞キュー頭だけ `se_continue_beat` |
| 5〜10 | 表情差分が切り替わり、軽い上下運動。背景の圧が増す | 小さい鼓動・時折ノイズ |
| 10〜15 | 最も大袈裟な台詞でわずかにズーム | 音楽は続ける。SEは一発だけ |
| 残り5〜1秒 | 大きい残り秒数が「5→4→3→2→1」。字の周囲に危機感 | 1秒に1回 `se_continue_count_tick`。音程を少しずつ上げる |
| 0秒 | カウント音停止。選択肢をさらに明るくする（※自動終了はしない） | `se_continue_zero`: 低く一度だけ |
| 選択した瞬間 | 通常台詞をキャンセル→そのキャラ・そのボタン固有の一言へ切替 | `se_continue_accept` または `se_continue_retire` |
| 一言後 | 再挑戦: 明るいフラッシュ→大会冒頭／諦める: 静かな暗転→タイトル | BGMを短くフェードアウト |

**カウントは表示演出のみ**。20秒経ったら背景で音楽だけ続けて、好きなだけ選べる。カウント音は毎文字鳴らさない。音無しでも「次に進む／諦める」がわかる。

## 4. SE・音量・BGMの詳細

- `se_continue_interrupt`: 低い衝撃＋吸い込む空気のノイズ、0.2〜0.35秒。
- `se_continue_title`: 金属的「ガンッ」、0.12秒。大きいが耳障りでない。
- `se_continue_beat`: キュー／強調文字頭に柔らかい低音、0.06〜0.12秒。
- `se_continue_count_tick`: 残り5・4・3・2・1秒時に1音ずつ。目安620→700→780→870→990Hz、各0.07秒。長さ・音色は試聴調整。SE過多にならないよう5秒間のみ。
- `se_continue_zero`: 鼓動1回。「タイムアップ／強制終了」と誤認させない低い音。
- `se_continue_accept`: 1秒以下の短い上昇成功音。
- `se_continue_retire`: 小さい下行2音。敗北を嘲笑・責めない。
- `se_continue_pencil`（つむぎ）、`se_continue_shark_plush`（サメちゃん）、`se_continue_scan`（凛）は候補。オリジナルWebAudio SEとして合成するのが簡単。必要ないキャラは無理に専用音を足さない。
- BGM: 既存採用 **BGMer「EMGコール」**。通常1.08倍速。発音する瞬間だけBGMを70〜85%へ短くduckし戻す。選択後の一言中はもう少し音を絞り、読みやすさ最優先。音楽が取得できなくても既存WebAudioの緊迫曲で演出成立。Web版なのでオーディオ解禁とボリューム設定を尊重。
- 音を増やすより**無音の0.15秒・画面一瞬停止**がインパクトを作る。つむぎの最終笑顔やスミさんの急な真顔で積極的に活用。

## 5. 元ネタ寄りの画面レイアウト指示

- 黒ベース、**中央上に巨大 `CONTINUE?`**、左右どちらかに人物の正規立ち絵を大胆に拡大、反対側に大きなセリフ。下に2択の文字主体。
- 現行UIの小さな装飾ラベル、細かすぎる説明文、残念理由のバッジ等は抑えて、立ち絵と台詞を主役にする。
- 強調文字は1キューに**最大1〜2箇所**に限定。赤／白のコントラスト、コントロールが消えない範囲でカメラ揺れ。
- プレミアは同じ基本レイアウト、本人に合う差し色だけ変化。つむぎ最終キューは笑顔なのに少し怖い、サメちゃんは王冠ぬいぐるみが手元で跳ねる。
- 音声なしのため、**字幕は自然に読める速度**にする。20秒固定が長文に厳しいときは、台詞量を調整するか次のセリフボタンを活かす。瞬間全文表示／早送りで読むことも可能。
- `prefers-reduced-motion` 対応、光過敏への配慮（フル画面点滅の連発は不可）、背景と白文字のコントラスト確保。

## 6. 実装するときのコード設計メモ

**次回やること。今回は行わない。**

1. `data`（台本）と `render`（字幕アニメ／立ち絵）と `controller`（決定／分岐）の責務を分離。既存 `SUMI_CONTINUE_SCRIPTS` と `PREMIUM_CONTINUE_SCRIPTS` に `reactions: { retry: { text, face, effect }, quit: { text, face, effect } }` を追加する設計を推奨。
2. `onRetry/onTitle` は押下後直ちに呼ばず、まず台詞イベントを1度だけ表示。約2.0〜2.8秒表示／ユーザーの追加タップで短縮可能。**多重クリックしてもゲーム遷移は一度だけ**。`cleanupContinue` でアニメ・SE・タイマー・BGMを止める。
3. 現状は `buildGameOver` が押下後 `cleanup(); onRetry?.()` または `cleanup(); onTitle?.()` のため、このクリックハンドラを段階演出に差し替える。異なる分岐を多重発火させない。
4. SEは `remake/js/core/audio.js` の共通AudioContextと既存設定を利用する。端末の音声自動再生制限・ミュート・音切れに配慮。SEだけのために新しいAudioContextを乱立させない。
5. BGMのテンポと字幕のキュー `at` の同期は開始時を共通基準にする。ブラウザがバックグラウンドに行ったらタイマーを音に追従／復帰時に再同期。途中で「次のセリフ」を押したときは、重複SEやカウントの多重発火を防ぐ。
6. プレビュー `remake/continue-preview.html` に **各キャラ × 戻る／諦めるの2分岐**を再生する操作と、SE ON/OFFチェックを追加する。ゲーム本編はそのまま遷移する。
7. 回帰テスト `remake/test/continue_premium.mjs` と、実プレイ `remake/test/burnt_gameover.mjs` 等を更新。キャラ9台本（スミさん3＋恋人6）×2ボタン、途中押し・終了後押し・連打・ミュート・動き軽減・スマホ・復帰を検証。恋人率20%と連続なし・第1章みんと除外は維持。
8. 実装前に最新の `origin/main` を確認して新規ブランチからPR。ドキュメントを参照して既存UIを置換する。正規立ち絵を使用し、外部から生成した別人画像で置き換えない。
