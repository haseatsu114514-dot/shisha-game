# 朝霧ひより・本編の登場と接続仕様

オーナー指定の「他店で偶然相席→スミさんへの報告と伝言→各店での交流→好感度3でLIMEからtonariへ」を現行の `remake/` に接続した。
キャラの基本情報・外見・服装は [`data/characters.json`](../data/characters.json) の `hiyori`、台本と条件は [`data/dialogue/hiyori.json`](../data/dialogue/hiyori.json) が正本。

## 本編での進め方

1. 自由行動で他店に行き、一服する。KEMURIKUSA、EDEN、PEPPERMINT、C.STATIONのどこからでも初対面になる。特定の日・店へ固定しない。通常の買い物やDr.fookahのショールームでは発生しない。
2. 次にスミさんと実際に会う。tonariでのバイト、客としての来店、スミさんとの会話、スミさんがいるtonariの固定夜イベントで報告が進む。明るかった学生時代の回想と「気が向いたら一服しに来い」という伝言を受け取る。
3. 初対面後は他店での一服ごとに約20%で偶然再会し、伝言を渡す。その後の再会で仕事疲れの会話へ。さらに別の店でも一日一度までの相席会話を重ねる。背景はその訪問先を使う。
4. 好感度3以上で、スミさんから「ひよりが客として来てる」とLIMEが届く。仕事の呼び出しではなく、彼女が自分で寄った私的な来店。返事で向かうと、ひよりには予告せずはじめが顔を出す。
5. 変わらぬ師匠の優しさにひよりが涙する。感動場面の終盤で初めて、師匠への尊敬とはじめへの応援を表の言葉にする。次のtonariで三人の会話が続く。

「星3」の依頼は、既存の好感度表示に合わせて **♥3**（既存の33点の段階）へ接続。能力の★3とは別。
追加の相席だけで行動枠・料金・体力を二重に消費しない。再会のLIMEは昼の行動1回、参加費なし。断る・未読期限切れ・他の約束との競合で永久に失われず、日を改めて届く。スミさんの仕事のLIMEより物語の報告を優先し、同じ朝の連投は避ける。

## 台本とフラグ

| 段階 | 正式台本 | 読了フラグ | 条件 |
|---|---|---|---|
| 他店で相席 | `hiyori_meeting` | `_hiyori_meeting_done` | 第1〜2章のシーシャ店で有効な訪問 |
| スミさんへ報告 | `hiyori_sumi_message` | `_hiyori_sumi_message_done` | 出会い読了・面識、次の実対面 |
| 伝言を渡す | `hiyori_shop_message` | `_hiyori_message_delivered` | 報告読了、他店で再会 |
| 仕事の疲れ | `hiyori_cracks` | `_hiyori_cracks_done` | 伝言読了・♥1以上、他店で再会 |
| 各店で交流 | `hiyori_shop_repeat_0`〜`3` | `_hiyori_repeat_count` | 報告後の既読段階を終え、一日一度 |
| tonariで鉢合わせ | `hiyori_tonari_return` | `_hiyori_tonari_return_done` | 報告・伝言・仕事疲れ読了、♥3以上、スミさんのLIMEに返信 |
| 三人の物語へ | `hiyori_tonari_followup` | `_hiyori_tonari_followup_done` | 再会読了、次にtonariで会う |

`route.enabled` はtrue。未制作イベントは `missing_script` により発火しない。読了フラグは最後まで読んだ後だけ記録し、同時呼び出し・再読による二重報酬を防ぐ。
#1434 決定Bの先行2件: 遠隔連絡 `hiyori_tokyo_contact`（既読 `_ch3_read_hiyori_tokyo_contact`）は第3章の寄り道カードで、仕事の相談読了・面識・連絡先があり、ひよりが東京に来ていない時だけ。恋人成立後の `hiyori_feelings_spoken`（`_hiyori_feelings_spoken`）は第1〜3章、恋人・絆Lv2で、LIMEのデートの帰りに一度だけ。告白 `confession_hiyori_accept` とは別の場面。遠隔応援（第4章）と第5章の友人／恋人の場面は、各章を作る時に再評価する。
初対面の店は `_hiyori_meeting_shop`、一日一度の制限は章と日を含む `_hiyori_encounter_day` で保存。

好感度は再会 `_hiyori_tonari_return_done` の読了まで♥3（33点）で条件待ちする。
停止中も通常の倍率・占い・85%ペース・端数を一度だけ計算し、実獲得分を `_hiyori_affinity_waiting_pts` に保存する。再会読了後、既存報酬より先に次のハートまで最大15点を一度だけ救済する。獲得記録は残し、再読やロードでは再加算しない。旧セーブの既存ポイント・恋人の絆は減らさない。

再会後は4日に一度の候補日に、ひよりから営業中の既知の店への夜のLIMEが届く。未読・他の人との誘い・予約・固定夜イベント・大会日は抑制する。返信では予定だけを作り、実際の訪問で3000円・行動1回・体力・既存の交流報酬を一度だけ処理する。台本は既存 `hiyori_shop_repeat_0`〜`3` を使い、長編イベントや恋愛台詞は追加しない。
初対面は従来どおり確定。以降の偶然の相席は既存のセーブの `seed` と章・日・行動枠・店舗から抽選する。同じ訪問のロードでは結果が変わらず、固定5回周期や訪問カウンタの追加はない。店主・施設の会話テーブル、スミさんへの報告、LIMEからのtonari再会はこの抽選で変更しない。
名乗りで `_met_hiyori`、連絡先交換で `_lime_contact_hiyori` を立てる。既存の `flags`・`contacts`・`affinity` に保存するためスキーマ変更なし。旧セーブの好感度から出来事を推測して埋めない。

## 画像と本心

現在はオーナーが選択したレースブラウス案。ポニーテール、白〜アイボリーのフレンチスリーブ、黒のパンツ、名札なし。通常・物憂げ・控えめな微笑み・驚き・感動の涙の5表情と、ミディアムヘアで元気な学生時代の1表情を使用する。
原画と生成指示は [`asset_sources/portraits/hiyori-office-v1/`](../asset_sources/portraits/hiyori-office-v1/README.md)。896×1200の透過PNG、RGBAが一致する可逆WebP、160pxの顔アイコン、manifestを揃えた。背景や別人で素材待ちを埋めない。

正式名は朝霧ひより（あさぎり ひより）。他店で名乗った直後に一度だけ登場カットインを表示し、呼び名「ひより」と「儚げな元スタッフ」、本人の短い台詞を出す。背景は乳白色・淡い桃色・薄い藤色の線香花火。現在の立ち絵をそのまま重ね、柔らかいフェードと小さな火玉の光で儚さを出す。動きを減らす設定では停止し、既読は `_intro_hiyori` で保存する。
原画・指示・実画面の記録は [`asset_sources/character-intros/hiyori-senkou-v1/`](../asset_sources/character-intros/hiyori-senkou-v1/README.md)。PC・横持ちスマホ・動きを減らす設定の3項目を `remake/test/hiyori_intro.mjs` で実行する。

学生時代を知ったはじめがすぐ演技の全容を見抜く展開にはしない。`_hiyori_real_self_known` は今回の回想・再会で立てない。
回想後の一部台詞だけに `inner` を付け、発話の後に淡いピンク・括弧付きで出す。プレイヤーにだけ見え、はじめは聞いた台詞と見た行動へ返す。仕事の疲れは本物で、儚い演技も本人の好きなあり方。

`remake/hiyori-preview.html` の5本は過去の表示確認サンプルで、本編の正式台本とは別。セーブや設定を読み書きしない。未制作の斧投げ背景を他店で代用しない。

## 斧投げ用の素材（#477）

専用夜背景 `bg_axe_lounge_night` と、キャップ/Tシャツの `axe_normal`・`axe_laugh`・`axe_shout`、現在のレース衣装の `serious`・`love_blush` を追加した。旧6表情と顔アイコンのバイナリ、全表情の共通足元・縮尺は維持する。原画・生成指示・SHA・再登録手順・表示QAは [素材記録](../asset_sources/hiyori-axe-issue477/README.md)。

この素材登録だけでは `_hiyori_real_self_known` や仕事・恋愛・友情の読了を立てない。登録時点では正式斧投げ台本とミニゲームは未接続だった。操作は #480、タイトル5枚は #486、正式台本は #492で接続。casual/lounge/date等の他衣装と残り表情は未制作として素材記録に残す。

## 斧投げの操作（#480）

独立した練習ページ remake/axe-throw.html と、前後の会話の間で呼べる結果APIを追加した。
生成素材を実参照し、横・縦・力の3ゲージ、3投／10投練習、キルショット宣言、落下、ひより／サメちゃんの前後の反応、再挑戦を実装。相手の投擲と勝敗を含む対戦は後続の追加要素。
操作単体で素顔発覚・好感度・友人/恋人・LIMEを変更しない。
正式な素顔発覚台本とイベント解禁は旧 #343 の別作業。
詳細は [斧投げの操作とAPI](axe_throw.md)。

## tonariでの仕事の入口（後続追加）

三人の初回の会話（`tonari_followup`）を実際に読み終えた後、**次にtonariでスミさんと対面したとき**、ひよりが客として手帳を鞄へしまう追加回 `hiyori_tonari_afterwork` を一度だけ再生する。総務の具体的な働きぶりと、仕事から意識を切り替えたい気持ちを描く。第1〜2章・♥3以上が条件で、読了後に `_hiyori_tonari_afterwork_done` を保存し、好感度を5点だけ付与する。

この会話は後半の `work_talk` に**代替しない**。斧投げでの素顔の発覚はまだ起きないので `_hiyori_real_self_known` や `_hiyori_work_talk_done`、恋愛・友情の最終条件に影響させない。斧投げ用背景・後半立ち絵がない間も既存のtonari背景と既存表情で完結する独立エピソードだけを接続する。

## 正式な斧投げ（#492 / 旧 #343）

再会・三人の会話・退勤後の入口まで実際に読んだ♥3以上、第1〜2章の夜だけ、tonariのサブメニューに「ひよりと斧投げへ」が出る。参加3000円・体力10・行動1回を表示し、不足時と当日同枠のLIME予約時は選べない。翌日の予約・受信箱は変更しない。

`hiyori_axe_reveal` → 本番の3投ミニゲーム → `hiyori_axe_reveal_close`を順に待つ。正式な前後台本は専用背景とaxe_normal/axe_laugh/axe_shoutを使う。夢中で一度だけ声が大きくなるが、健康・有能さ・本当の仕事疲れ・儚い演技を楽しむ本人のあり方は維持する。innerは引き続きプレイヤーだけに見える。

後段の読了後に `_hiyori_real_self_known`・既存好感度10・物語1回・料金・体力・夜の行動・私的な夜の記録を一緒に保存する。calendarはこの行動を二重に進めない。点数や成功率で報酬を変えず、練習ページでは物語を変更しない。中止・未読・ロードによる所有stateの変更では未払い/未読で、再挑戦できる。既読の旧セーブを再課金せず、好感度・恋人・実友人から未読を補完しない。

後段の仕事相談/恋愛友情/告白/専用ハガル・AI対戦・海外は別Issue。第2章のAPI条件があっても、今の新規ゲームが第2章へ進める証明にはしない。

検証: `remake/test/browser/hiyori_axe_story.mjs` は本番前後台本/3投/読了保存/取消/ロード/旧関係/LIMEと本番calendar入口、`hiyori_axe_natural.mjs` は新規ゲームから出会い・報告・伝言・♥3のLIME・再会・三人・退勤後を自然に経て斧投げまでPC/タッチで通す。後者は乱数seedだけ固定し、日・好感度・読了を注入しない。既存 `hiyori.mjs` の共通関係APIケースは専用fixtureイベントであり、実斧投げの読了証拠とは区別する。

## 深い仕事相談と関係の問い（#496 / 旧 #344）

正式斧投げを読んだ後、次の夜のtonari対面で `hiyori_work_talk` を読む。総務として整理・対応できる人であること、本当の疲れ、笑えることと余裕があることの違いを描き、退勤後の入口の手帳会話を重複させない。採用済みのserious/normal/smileを使い、別衣装は代用で作らない。

仕事相談の後に `hiyori_bond_question` を読み、実回答を既存の `{char,value,day}` へ保存する。友人のvalue:0を無回答扱いにせず、反応の読了後だけ `_hiyori_bond_question_done` を立てる。途中保存からは同じ答えの反応へ戻り、再選択・好感度の再付与をしない。所有stateが変わったら仕事/質問のVNを中断し、前の場面から新セーブへ報酬を加えない。

MAX時の正式台本 `hiyori_bond_finale` と `confession_hiyori`/accept/rejectを追加した。二度の実回答と正式な締めくくりの読了を確認してから恋愛へ進む。途中で友人を選んだ場合は友人の結論へ進み、既存の友人/恋人は再読で分類し直さない。最終質問の保存済み0/1も同じ反応へ戻す。

**専用ハガル #497 / 旧 #345 はDraftで接続・検証中。** `route.finale.gift` に `suyaki_hiyori` を登録し、採用済みB「素顔でひと休み」を単体素材化した。容量20g、非売品・売却不可。オーナー承認に基づき、ピーチ3g以上で既存の香り+4・総合ボーナス+1を使う。正式な素顔・仕事・実回答・反応読了を経た後だけ締めくくりへ進む。過去の読了や回答を好感度・所有機材から補完しない。機材未登録を明示する共通APIのfixtureと、専用機材を使う本番設定の検証を区別する。**保存/LIMEの新規テスト3件の失敗と中断待ちが残り、自然到達・表示・既存回帰・最終CIは未完。マージ・公開可の状態ではない。** [停止時の保存・失敗・再開手順](../asset_sources/hiyori-hagal-issue497/README.md)。

検証は `remake/test/browser/hiyori_work_relationship.mjs`。自然New Gameの仕事到達は `GOAL_HIYORI_WORK=1 node remake/test/browser/hiyori_axe_natural.mjs` で、seedだけ固定して実斧投げ→仕事相談→最初の友人回答まで通す。後続素材未登録のため本番ではfinales/恋人を増やさない。
