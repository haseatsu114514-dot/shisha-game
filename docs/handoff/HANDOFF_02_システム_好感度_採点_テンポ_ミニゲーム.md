## 1. ゲーム全体のループ構造

各章は「**日常パート(育成・交流)→ 大会パート(ミニゲーム+採点)→ インターバル/次章**」の流れ。

### 1日の流れ
1日は4つの時間帯に分割: **朝(morning) → 昼(noon) → 夜(night) → 深夜(midnight)**。
- **行動回数(actions_remaining) = 1日2回**。マップ上の行動(バイト・練習・ライバル訪問・交流イベント)で1回消費。
- 朝に **LINE(LIME)** 受信チェック(`morning_phone`)。
- 深夜→翌朝で日数が進み、行動回数が2に回復。
- 夜の締め(`night_end`)で当日サマリー表示。特定日に **夢シーン**(`dreams.json`)が挿入される。

### 章の長さ(テンポ)
- 各章 **7日間** プレイ → **8日目が大会当日**(`tournament_day = 8`)。
- 第5章のみ **30日**・大会なし(SHISHA-9000戦は別枠)。

## 3. ステータス & 育成 ✅(`PlayerData`)

### ステータス(5種類のみ)
**技術 / センス / 根性 / 魅力 / 洞察**
- 初期値は全て **10**(均等スタート)。上限 **100**。第4章末までに頑張れば全て100(★5)到達可能。
- ❌ 廃止/誤記: `技術力` `洞察力` `メンタル` `度胸` `味覚` `集中力`、および「洞察が主人公の強み(初期偏り)」は旧設定。
- 内部的には英語キー `technique/sense/guts/charm/insight`(`taste`は`sense`の旧エイリアス)。

### 表示ルール(重要)
- **数値は絶対に見せない**(内部0〜100は非公開)。メニューは **★1〜5**(`ceil(値/20)`)で表示。
- 上昇通知は抽象表現のみ: 1〜2pt=「少し上がった」 / 3〜4pt=「上がった」 / 5pt以上=「大きく上がった」。

### 所持金
- 初期 **30,000円**。マップ移動・機材購入・店訪問で消費(§7のコスト参照)。

### 報酬ルール(`CLAUDE.md`)
- **全イベント・行動に必ず何らかの報酬**(ステータスUP or アイテム付与)。
- 育成で攻略難易度が激変しない(「そこそこ有利」程度)。**育て方で詰む事態は作らない**設計。

## 4. 機材システム ✅(`PlayerData` + `data/equipment.json`)

4スロット: **ボウル(bowl) / ヒートマネジメント(hms) / 炭(charcoal) / パイプ(pipe)**。

- **初期装備**: シリコンボウル / ロートスハガル(lotos_hagal) / フラット炭 / 安価パイプ。
- **練習ボーナス**: 装備ごとに練習タグ(packing/aroma/presentation/rush)で上がるステータスが変わる(`BOWL_PRACTICE_BONUS` 等)。ボウル×HMSの **コンボ名+追加ボーナス**あり(例: `素焼き:winkwinkハガル`=「育成特化セット」)。
- **相性制約**: 素焼きボウル(suyaki) × タヌキッシュリッド(tanukish_lid) は **組み合わせ不可**。
- **炭の戦略**: フラット炭=安定火力(有効範囲広い) / キューブ炭=高火力チキンレース(`roll_heat_chicken_race`、成功率は技術+根性依存、成功で大リターン/失敗でセンス減)。
- **キャラ印ボウル**: `suyaki_naru`(バニラ特化)/`suyaki_adam`(ダブルアップル特化)/`suyaki_minto`(ミント特化)── 対応フレーバー使用時に大会スコア加点(`get_equipment_flavor_bonus`)。
- 旧ID→現行IDの **レガシーマップ**完備(`standard→silicone_bowl` 等)。リビルド時は現行IDで統一。

## 5. フレーバー & レシピ 🎮(`flavors.json` / `recipes.json` / `ng_mixes.json`)

### 基本フレーバー(Ch1想定6種・ラインナップは検討中)
ミント / ダブルアップル / ブルーベリー / バニラ / パイナップル / ココナッツ(主に「アルファーヘブン」ブランド)。`docs/planned_flavors_list.md` に約55種の全リストあり。

### カテゴリ特性(6カテゴリ)
`cooling / spice / fruit / sweet / floral / special(tea)`。各フレーバーに **3つの特性値**:
- `heat_tolerance`(熱耐性) … 温度管理の許容幅に影響
- `smoke_weight`(煙の重さ) … 吸い出しゲージ速度に影響
- `steam_bias`(蒸らし傾向) … 蒸らし最適レンジに影響
ミックス時はグラム加重平均で全体特性を算出。

### 味スコアの3層構造(確定方針)
実際のシーシャは「大体何混ぜても美味い」。これに合わせ **カテゴリ単位の自動相性判定は廃止**:
1. **デフォルト** = 普通に美味い(補正なし)。フレーバー特性は「味の良し悪し」ではなく「作り方の変化」に効く。
2. **レシピ成立** = とても良い(ボーナス)。§下の発見型レシピで管理。
3. **NGミックス** = 本当にひどい(ペナルティ)。`ng_mixes.json` に少数だけ手動定義。

### 発見型レシピシステム
- 日常パートのキャラ交流で **レシピを習得**(`PlayerData.learned_recipes`)→ 大会で該当配合(比率に`ratio_tolerance`の幅あり)を作ると加点+専用プレゼン手札追加。
- **レシピ未習得だと成立しない**(偶然成立はさせない。近い配合だと「誰かに聞いてみたら…」と伏線)。
- レシピ習得=キャラ深掘り。紐付け例:
  - ピニャコラーダ ← スミさん(好感度3) / 地獄のメンソール ← なる(好感度2) / ミッドナイトチャイ ← つむぎ / トロピカルサンセット ← アダム。Ch2以降は宵野葉子・神崎竜二・ましろ・ナンディ・シェイク等が各章のレシピを提供。
- データ: `data/recipes.json`(教わる/隠し) + `data/secret_recipes.json`。

## 6. 好感度システム ✅(`AffinityManager`)

### レベル(出会い・交流の好感度)
- `level` 0〜5。`spend_time_with()` で +1。
- **章ごとのキャップ**(`CHAPTER_AFFINITY_CAP`): **Ch1=3 / Ch2=4 / Ch3=5 / Ch4=5**。各章で上限まで。
- 表示は ★/☆ 5個(`get_star_text`)。
- 管理対象: sumi, naru, adam, minto, tsumugi, ageha(+常連は別途「裏好感度」、§7参照)。

### 恋愛(romance)& 愛情度(affection)
- **恋愛対象(ROMANCE_CANDIDATES)= みんと / つむぎ / アゲハ / ましろ**（✅決定: 4ヒロイン全員を攻略可能にする）。
  - ⚠️ 現行コードの `ROMANCE_CANDIDATES` は `[minto, tsumugi, ageha]` で **ましろ未登録**。実装で `mashiro` を追加し、`DEFAULT_AFFINITIES` と章キャップにも登録する（§14）。
  - **タイミング注意**: ましろはCh3で初登場。「Ch3までに全ヒロイン恋愛着地」のルール下では、ましろの好感度はCh3の短期間で上限まで上げられる設計（出会いが早い＝Ch3開始時から接触可）にするか、ましろだけCh4着地を許容するかを実装時に決める。Ch4登場表(下記)はすでにましろを friend/girlfriend 両対応にしてある。
- 好感度MAX(Lv5)到達 → 告白イベント(`confession.json`)で「付き合う/友達のまま」選択 → `romance` フラグ。
- 恋人後のデートで **愛情度(affection, 0〜5)** が別途上がる(`add_affection`、`interaction.gd`のデートシーン)。
- **修羅場**: `get_romance_count() >= 2`(2人以上と交際)で `is_two_timing()` = 修羅場イベント発生。

### 恋愛ルートの着地タイミング(`CLAUDE.md`)
- **Ch3までに**全ヒロインの恋愛を着地(付き合う/友達)。**Ch4(ドバイ)に新規の攻略ヒロインは追加しない**。
- Ch4は既存ヒロインが「応援」で登場し感情回収。

| つむぎ | 来ない | 来る |

## 7. キャラとの出会い・交流フロー ✅(`map.gd` / `interaction.gd`)

### マップとロケーション(章別)
マップから行き先を選んで行動。章ごとに出現スポットが変わる(`_build_spot_list` 系)。主なスポット: 自宅/tonari(無料・時間消費なし系もあり)、ライバル店(なる=ケムリクサ / アダム=Eden / みんと=ぺぱーみんと)、商店街、観音、チョイザップ(ジム=会員制)、C.STATION、Ch3=mukai、Ch4=dubai_shisha 等。

### コスト & 制限
- 店訪問コスト例: Dr.Hookah(ショップ)3,500円 / ライバル店 3,000円(+行動1) / チョイザップ入会 4,000円 / C.STATION 2,000円。
- **同じ店は1日1回まで**(`_visited_today`)。ショップ移動は時間を消費しない。
- ライバルが「不在」の日がある(出勤管理)。不在時は行動消費を `undo_action()` で返却。

### 初回訪問の処理(`interaction.gd`)
- 初訪問で `met` フラグ + **ライバル情報(intel)獲得**(例: なる初訪問で「お菓子系」、アダムで「double_apple_only」)。
- **章ゲート**: なるはCh1で好感度3(3回訪問)に達すると「出勤していない」/Ch2-3は「修行の旅」で不在/Ch4で帰還。みんと・アダムはCh2以降に「大会後初訪問」専用ダイアログへ分岐。アゲハはCh3以降に大会後分岐。
- 恋人状態のキャラを訪問すると **デートシーン**(愛情度+1)へ。

### お忍び来店 & 常連の裏好感度(設定書準拠)
- **お忍び来店**: 好感度が一定以上のライバル/キャラがtonariに「ただの客」として来店する交流体験(パラメータ上昇なし、フレーバーテキスト主体)。
- **常連の裏好感度**: かこ/りら等は表示好感度なし。隠し「裏好感度(最大3)」を持ち、3回遭遇MAXで第5章や世界大会にギャラリー(応援)として駆けつける。サラリーマンは日常ランダム接客には出ずストーリー専用。

## 10. 採点ロジック ⚠️**現行実装・見直し中**

> 採点は再設計中のため、以下は「現行コードの仕組み」の記録。数式・配点は変更前提。好感度・出会い・ミニゲームのI/Oは維持されるので、採点だけ差し替え可能な構造になっている。

### スコアの二軸
大会スコアは **専門点(technical)** と **一般/観客点(audience)** の2軸で積算。
- 開始時ベース値(Ch1 `ch1_tournament.gd`):
  - `technical = 技術×0.9 + センス×0.7 + 根性×0.5`
  - `audience = 魅力×0.9 + 洞察×0.25`
  - イージーモードで +補正。
- 以降、各工程(セッティング/パッキング/盛り方/アルミ/炭/蒸らし/弾幕/吸い出し/調整/プレゼン)で `delta_spec` `delta_aud` を加算。

### 審査員の嗜好(`JUDGE_FOCUS_PREFERENCES`)
各審査員が4軸(**味 taste / 煙 smoke / 吸いやすさ ease / 個性 unique**)のうち2つを重視。例: 南雲=味+煙、チャコール博士=味+個性、前園=煙+個性。プレゼンで審査員の好みに刺さる手札/軸を出すと加点。

### 進行
3ラウンド制(各ラウンド後に調整メニュー)→ 最終プレゼン → 最終発表。中間速報・暫定順位を都度表示。**4人一斉対決で1位のみ次章進出**(§Part1の大会ルール)。

### リザルトランク(`shisha_rank.gd`)
スコア/章別最大値の比率で **SSS≥0.95 / SS≥0.85 / S≥0.75 / A≥0.60 / B≥0.45 / C** を表示(勝敗問わず大会後に必ず出る)。
章別想定最大: Ch1=90 / Ch2=100 / Ch3=110 / Ch4=120。
- **第5章(SHISHA-9000)解禁条件**: Ch4で **Sランク以上**(`is_ch5_unlock_rank`)。

## 11. ミニゲーム 🎮**最新設計(2026-03-08 計画書)**

> 以下は `docs/minigame_implementation_plan.md` の最新意図。現行の大会コードは一部が旧版(作り直し対象)なので、リビルドは計画書準拠で。

### 大会フロー(全16ステップ・`TOTAL_STEPS`は15→16へ)
1.セッティング(機材) 2.フレーバー選択 3.パッキング配合(スライダー) **4.盛り方選択★ 5.アルミ穴あけ(作り直し)★ 6.炭焼き判定(拡張)★** 7.炭の配置(3/4個) 8.蒸らしタイマー 9.思考の暴走弾幕 10.吸い出し **11-12.調整フェーズ(改修)★** 13.ラウンド結果 **14.プレゼン(大幅改修)★** 15.最終発表。

### 各ミニゲームの要点
- **盛り方選択(新規)**: ふわふわ/ふつう/しっかり の3択。蒸らし最適値・吸い出し速度・heat_state・プレゼン味/煙スコアに波及。
- **アルミ穴あけ(作り直し)**: 旧リズムゲーム(破綻)を廃止 → **アルミ上面に穴が光る→タップ**式。精度(PERFECT/GOOD/NEAR/MISS)でspec加算。HMSで穴数が変動。
- **炭焼き判定(拡張)**: バックグラウンドで炭が焼ける演出+「もう少し待つ/ちょうどいい/裏返す」。5段階の焼き加減(段階3=ベスト)。焼きムラペナルティあり。
- **思考の暴走弾幕**: 東方風シューティング(主人公の迷いを弾幕で表現)。**現状維持**(変更しない)。
- **吸い出しゲージ**: ゲージ系。早い吸い出しでボーナス(2回=最速ボーナス)。**現状維持**。
- **調整フェーズ(改修)**: 「最低2回」撤廃。**炭の世話アクション5種**(灰を落とす/炭を回す/炭交換/HMSフタ調整/終える)。**数値表示を全廃**し煙の様子テキスト+審査員リアクションで状態を伝える。
- **プレゼン(大幅改修)**: 旧「軸を選ぶだけ」を廃止 → **手札プレゼン方式**。大会中の各工程選択が「手札」になり、審査員の質問3ターンに手札を出す。質問軸との相性・一貫性ボーナス・矛盾ペナルティ。レシピ使用で専用手札(個性に強い)。
- **水量調整**: 大会では見送り(機材選択時の選択で表現)。将来は練習モードで体験。

### 章別スケーリング(抜粋)
