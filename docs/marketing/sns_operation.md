# SNS運用ルール（X）

> まのさば（魔法少女ノ魔女裁判）公式Xの運用を手本に、本作の集客・コミュニティ運用の型をまとめた実務メモ。
> 出典リサーチ：[#2471](https://github.com/haseatsu114514-dot/shisha-game/issues/2471)（まのさばX運用分析）／[#2475](https://github.com/haseatsu114514-dot/shisha-game/issues/2475)（AI製漫画・イラストのSNS運用）／[#2470](https://github.com/haseatsu114514-dot/shisha-game/issues/2470)（AIっぽさを出さない画像生成・開示）／[#2516](https://github.com/haseatsu114514-dot/shisha-game/issues/2516)（オーナー決定）。数値はリサーチ当時（2026-11-03）の各調査者の実測/推測で、ここでは再検証していない。
> 画像を作るときの品質チェックは [AIっぽさを抑える制作メモ](../prompts/ai_naturalness_guide.md) と [素材制作の詳細ルール](../asset_ai_guidance.md) に従う。

## 0. 大前提（オーナー決定・2026-11-04）

- **使うSNSは X のみ。** pixiv・Bluesky は当面使わない（#2516）。余力でInstagram/Threadsに同じものを流すかは、Xの運用が固まってから別途判断する。
- **AI開示文は、ゲーム内にも投稿にも置かない。** ストアの申請フォームなどで求められた場合だけ「画像とコードの一部にAI使用」と記載する。AIを使うのはコードと画像のみ。**ツール名は書かない**（#2516）。
  - ※ #2475 は「bio・固定ポスト・各投稿の3か所に開示を書く」と提案していたが、**2026-11-04のオーナー決定がこれを上書きする**。投稿に開示文は付けない（この節を正とする）。
- **喫煙の注意書きはゲーム内に置かない**（#2516）。SNSでも法的な断り書きを創作して足さない。代わりに「喫煙をすすめる描き方をしない」を運用側の下限として守る（§6）。

## 1. アカウントの姿勢

- 名乗りは**ゲーム開発元の公式アカウント**。「絵師」「イラストレーター」「描きました」は名乗らない（#2475）。売りは絵の上手さではなく、物語・キャラ・夜の店のユーモア・シーシャそのもの。
- 文章の書き手は伏せる（店の声／キャラの声で話す）。まのさばも「書いているのは私かもしれないしキャラかもしれません」と伏せている（#2471）。
- 口調は**夜の店の、少しだけ大人のユーモア**。まのさば式の露悪・死・処刑トーン（「生まれてしまった日」等）はそのまま真似ない。作品と乖離する（#2471 §6）。
- キャラの口調ルールを守る：はじめは「俺」、ましろは「僕」、神崎ははじめを「あんちゃん」と呼ぶ。台詞を載せる画像・投稿でもこれを崩さない。

## 2. 週次投稿カレンダー

自分で書く投稿は**週3〜4本**に固定する（まのさばの直近は約0.6件/日。最初の1か月は増やさず、反応と炎上しにくさを見る＝#2475）。時刻はまのさばで反応が多かった枠に寄せる（昼12時台・夜19時台＝#2471）。

| 曜日・時刻(JST) | 定番枠 | 中身 |
|---|---|---|
| 月 12:00 | **2コマ漫画（連載）** | 例「閉店まで、あと一服。#番号」。毎回2人。「◆登場人物◆ 名前…一言の肩書き」を添える。オチに決め台詞を置く。頻度は隔週〜月2回でよい（毎週に縛らない） |
| 水 19:00 | **Q&A画像** | 16:9の固定テンプレ（店の黒板風など）1枚で完結。§3の型 |
| 金 19:00 | **レシピ/配合カード** | キャラの看板ミックス1つをグラム比つきの保存したくなる1枚に。フレーバーは一般名（ミント・ダブルアップル等）で、実在の銘柄名は宣伝口調で出さない |
| 土 19:00 | **制作GIF/短尺** | パッキング→蒸らし→調整の手触りを10〜20秒で。画面の変化がひと目で分かるものに。ゲーム本編の新要素は出しすぎない（クローン量産対策＝#2475） |
| 不定期 10:00 | **漫画（2コマ以外）/問いかけ** | 1枚漫画や「この人の看板ミックス、何が入ってると思う？」の考察誘発。正解は翌週のQ&Aで |
| 不定期 10:00 | **キャラ誕生日** | 誕生日を公式設定するかは別途オーナー判断（#2516/#2465）。実施する場合のみ記念画像＋その日のミックス |
| 毎日少し | 返信・引用 | 質問への短い返信（店の口調）。ファンアートの紹介は§4に従う |

**投稿頻度の考え方**：無理なく続く数を最優先する。曜日枠は「毎週必ず全部」ではなく、埋まらない週は落としてよい。連投（1日に何枚も）はしない（「量産」への反発＝#2475）。

## 3. Q&A投稿の型と、ときどき漫画

### Q&A（#2471：伸びた投稿の主力）
- **見た目**：16:9（1600×900）の固定テンプレ画像1枚。「Q＋質問」と短い答えを毎回同じ枠に載せる。スクショで広まりやすい形にする。
- **本文**：短く。説明は画像に任せる。
- **答え方**：店の声か、キャラの声で短く。一言のユーモアを入れる。例（キャラの声）——
  - Q「この店で一番うまいのは誰が淹れた一台？」→ はじめ「俺が決めることじゃない。客が満足したなら、それでいい」
  - 月1回は**逆質問**にする。例「あなたの一口目は、何味でしたか」
- **質問の集め方**：リプライ・引用でもらった質問を拾う。小さな質問には個別に短く返す。
- **頻度**：序盤は週1、軌道に乗ったら月1〜2回。節目（告知の直後など）は集中して出す。

### 漫画（ときどき）
- 2コマ漫画を連載の軸に、1枚漫画も混ぜる。毎回2人ずつ出してキャラを少しずつ浸透させる。
- 本文は「◆登場人物◆ 神崎…映画の話ばかりする常連 / はじめ…見習い」のように名前へ一言の肩書きを付ける。
- **表情・衣装・小物の破綻は人が全コマ確認する**（「全ページ同じ顔」「チェック不足」は炎上の定番＝#2475）。セリフ・写植は人が入れる（AIに擬似文字を書かせない＝#2470）。
- オチや決め台詞で、はじめ＝俺／ましろ＝僕／神崎→はじめ「あんちゃん」の口調を守る。

## 4. ファンアート・二次創作・同人の方針

オーナー決定：**同人活動は自由、ファンアートも歓迎**（#2475）。ガイドラインの骨子は最小限にする。

- **歓迎する**：手描き・AI・立体・小説・配信・考察、いずれも歓迎。
- **公式ハッシュタグを一つ決めて案内する**（ゲームの略称タグ＋二次創作用タグ）。ファン同士の合言葉になる（#2471）。
- **公式が紹介するときは、作者の許可を取り、作者名を明記してから**リポスト/引用する（#2471）。無断転載はしない。
- **禁止事項は最小限**に留める（例：公式を騙る、転載を自作と偽る、特定個人への攻撃に使う——程度）。細かいレギュレーションで萎縮させない。
- 公式がAIで作った絵と、ファンの手描きが同じ場所・同じタグに並んでも揉めない前提で運用する。

## 5. 炎上・批判への対応手順

初動を決めておく（#2475 §8 を本作向けに整理）。一次情報は**固定ポストに集約**し、都度の長文反論はしない。

1. **0〜2時間：止める。** 予約投稿を止める。反論しない。削除もしない（削除は「隠した」と取られる）。ミュート・非表示は使ってよい。
2. **〜24時間：事実を確認する。** 何を指摘されているかを分ける——①開示の要否 ②既存作品に似ている ③画像の崩れ（文字・手・小物）を見落とした ④手描きと誤解された ⑤題材（タバコ）への批判。
3. **〜72時間：短く説明する。** 固定ポストかスレッドで、言い訳・感情語を入れずに事実だけ。
   - テンプレ（崩れの見落とし）「◯月◯日の画像で小物の描写に誤りがありました。差し替えます。ご指摘ありがとうございます」
   - 似ていると指摘されたら、該当投稿を差し替える。元の作品名は出さない。
4. **その後：** 再発防止を固定ポストに1行追記し、1週間は通常投稿に戻す（毎日謝らない）。
5. **他人が巻き込まれたら即明言する。** 手描きの人がAI扱いされた・ファンアート作者が叩かれた場合、公式から「その方の作品はAIではありません」とすぐ出す（他人の絵に「AIでは？」と公式から言うのは絶対にしない＝#2475）。

## 6. やらないことリスト

- **有料広告を出さない**（オーナー決定）。各社の広告ポリシー上、水たばこ・シーシャ関連の宣伝は審査に通らない前提でもある（#2475）。通常投稿だけで伸ばす。
- **クラウドファンディングをしない**（オーナー決定）。支援速報・ストレッチゴール・RPで情報解放、も使わない（#2471 §6）。
- **投稿に開示文を付けない／ツール名を書かない**（§0。オーナー決定が #2475 の3か所開示案を上書き）。ただしメタデータを消して自動ラベルを避けることはしない（「隠した」扱いになる）。
- **露悪・死・処刑トーンを前面に出さない**（まのさばの中身に合わせた口調。本作とずれる＝#2471 §6）。
- **人の創作の場に入らない**：ファンアートタグ・お絵描き系タグ・イラストコンテスト・pixivリクエストに公式のAI絵を出さない。実在の作家名・作品名・「◯◯風」をプロンプトに入れない（#2475）。
- **他作品・他ユーザーを攻撃しない**。他の公式の炎上に乗らない。反AIの人と言い争わない（#2475）。
- **引退済みキャラを一切登場させない**（SNS画像・漫画・Q&Aでも）。登場するのは現行の正本（`data/characters.json`）のキャラだけ。
- **喫煙をすすめる描き方をしない**：「吸うとモテる・成功する・みんな吸っている」とは描かない。若く見えるキャラの喫煙絵の投稿はオーナー決定で可だが、未成年を想起させる制服・学校の文脈は避ける（#2475／#2516）。法的な断り書きは創作して足さない。
- **開発中のゲーム画面を出しすぎない**（映像のクローン量産対策＝#2475）。漫画・キャラ・制作の手触りを前面にする。

## 7. 測る数字（毎週）

- 型ごとの いいね / RT / 表示 / **保存**。まのさばでは保存数の多さが「推し」の熱に比例していた（#2471）。
- フォロワーの増え方：Q&Aを出した日に跳ねるか（まのさばは跳ねた＝#2471）。
- 否定的な引用の割合・フォロー解除数。否定的な引用が目立ってきたら §5 の手順に入る（#2475）。
