## 2026-10-30 シーシャ制作システム監査（#1129）のオーナー決定

- 蒸らしの気候は気温と晴れ／雨だけで決める。湿度は画面に出さず、温まり方の計算にも使わない（旧セーブの湿度値は無視する）
- 気温・雨の日の補正係数（`remake/js/craft/steam-climate.js`）はゲーム用の調整値で、実物の測定値ではない。係数は現行のまま残す
- 吸い出しのダイヤルの左右は「熱を逃がす吸い」（左・温度を下げる）／「キープ」／「熱を入れる吸い」（右・温度を上げる）と呼ぶ。旧称「下げ吸い／上げ吸い」は使わない
- 結果カードの吸い心地の一行で足りるので、講評に水の一言は足さない。風防は足さず台詞の話題に留める。ロートスの蓋を調整中に動かす操作は #1081 E06 の調整方式が決まるまで入れない。マウスピースは見た目だけで性能差を持たせない。開けた葉の劣化は入れない

## 2026-10-26 温度による味の違い・表示・熟練度の重み

- 葉の特徴、配合時の予想、提供時の仕上がりを分ける。一覧は短いタグ、詳細は香りの主張／清涼感／酸味の3本。予想は甘い印象／清涼感／煙の厚みを範囲の棒で、提供結果は一本の棒で表示する。強さは品質点ではない。基本情報を熟練度で隠さない。
- 自然な甘い香り `sweet_natural` とお菓子の香り `sweet_confection` は素材の香り系統。実際に感じる甘さは別に計算する。AFストロベリーは既存の「甘くない」商品説明に合わせ、香り系統値を保持して `perceived_sweetness: 2` から推定する。
- `thermal_expression` を持つAFミント／AFレモン／AFダブルアップル／ドバジミントから温度による表情を導入。適温帯内の低め・中央・高めで味が変わり、対応葉だけの配合では帯全体を同じ温度品質100とする。中央だけを虹で称賛しない。未定義の葉は従来曲線、混合はg比率で両曲線を補間する。帯外の品質低下は連続し、高温ほど甘くなる一律則を設けない。
- 熟練度は配合g比率のLv.1〜5から、香りの再現に最大6／大会総合に最大8／蒸らし予測精度に最大0.45を加える。予測は洞察の精度 `p` に対して `p + (1-p) × 熟練補正`。味の表情自体を熟練で変えたり、熱の許容帯を広げたりしない。制作開始時の熟練を保存し、その一杯の終了後の成長で結果を変えない。
- 第1章の南雲の基準を72→84へ調整。穴・炭・完成品・調整1回目・調整2回目は各20%、準備加点と物語の10点投票は維持する。初期装備・Lv.1でも丁寧な操作で勝てる一方、最大熟練と準備でも粗い操作／調整放棄を埋め切らないことを `mastery_balance.mjs` で確認する。
- 結果は実際の提供・調整の記録から「今回よかったこと」と「次に変える一つ」を表示。器具の比較も実際の容量・適温幅・安定補正・炭の加熱倍率に限る。現行表示名はビッグタヌキッシュリッド、互換用内部IDは `winkwink_hagal`。
- 本節の数値・温度はゲーム用調整値で、実物の測定値ではない。葉の内部／表面の熱分離、炭の寸法別の寿命、混合配置の新たな解放、途中の炭種変更は今回追加しない。

## 4. 会話テキストの改行ルール [済 2026-06-12]

- 人が一目で読めるのは **1行あたり約25文字** まで。これを基準に改行を入れる。
- 厳密な25文字制限ではなく **読みやすさベース**。文節の切れ目が良ければ
  26文字以上になってもよい。逆に短くても意味の切れ目で折り返してよい。
- 対応方針:
  1. 表示側: テキストボックスの自動折り返しに頼らず、データ側の `\n` を尊重する。
  2. データ側: `data/dialogue/` の既存テキストを一括チェックし、
     1行が長すぎるものに改行を挿入するスクリプト（`tools/` に追加）＋目視調整。
  3. 今後の新規シナリオもこのルールで書く（CLAUDE.md に追記すること）。
- **実装メモ**: エンジン側 `autoWrap()`（約24文字・句読点優先・禁則処理）を
  入れた。データ側の一括 \n 挿入は不要になったが、新規執筆時は意味の
  切れ目で `\n` を入れるのは引き続き推奨。

## 6. 体力（スタミナ）システム [済 2026-06-12 初版]

日常パートに体力ゲージを追加する。コンセプトは
「若いのでそこまでシビアにしない。ただし無理を重ねると寝込む」。

### パラメータ案（バランスは実装後に調整）
- 最大値 100、毎朝の起床で表示。
- **減少**: シーシャを吸う（-10〜15）、バイト（-20前後）、大会・練習（-10〜20）。
- **回復**: 夜の自然回復は1行動ぶん程度（+12）。「家に帰る」は1コマを使い、最大体力の半分ぶん（+50）回復する。
  シーシャと無関係なスポット（散歩・銭湯など）で小回復（+10〜15）する。
- **しきい値挙動**:
  - 体力 低（例: 30未満）でシーシャ関連の行動（吸う・練習・バトル）をすると
    **「くらう」/ 酸欠** が発生 → 半日（1コマ）〜1日寝込んで強制スキップ。
  - 低体力のまま数日無理を続けると **風邪** → 1〜2日行動不能、
    その後しばらくシーシャ屋を控える（シーシャ系スポット選択不可）デバフ。
- **UI**: 日常画面に常時ゲージ表示。低下時は色が変わる＋
  シーシャ系コマンドに「⚠ 今日は無理しない方がいい」系の警告を出す。
- **設計意図**: 罰ゲームではなくペース配分の要素。通常プレイで毎日全コマ
  シーシャに突っ込まなければ事故らない程度のマイルド調整にすること。
- セーブデータ互換: 既存セーブには体力=100で補完。

### リメイク版の制作コンディション（2026-10-07 オーナー指定・GUI27）

HUD・ステータス画面・制作は `remake/js/core/condition.js` の同じ境界を使う。最大体力に対して50%超は緑＝好調、25%超〜50%は黄色＝通常、25%以下は赤＝不調。大会・自主練・リハーサルは一台を作り始めた時点で固定し、作業台にも調子を表示する。レッスンは体力によらず通常。

- 緑：穴あけ・吸い出しの周期を1.08倍にして少し遅く、成功幅を1.15倍にする。雑念は少し避けやすく、炭と熱管理の見極めも少し助ける。
- 黄色：従来の操作難度・売上ボーナスのまま。
- 赤：周期0.82倍で針が速く、成功幅0.65倍で判定が厳しい。雑念の出現間隔0.75倍・接触範囲拡大、炭と熱管理の予兆も読みづらい。結果に一律の減点は加えず、実際の操作を通して完成品に影響する。
- バイト：シフトの体力消耗を反映した色で、そのシフト中は固定。緑は魅力・対応選択の売上ボーナス1.15倍＋好調の上乗せ1,000円、黄色は通常、赤は売上ボーナス半分。最低給料8,000円・急なシフトの手当・雨の追加注文分・成長報酬は下記「リメイク版の自由行動と成長」に従う。

### リメイク版の風邪リスク（2026-10-07 オーナー指定・PF14）

体力を消耗する行動を終えた時に赤なら、残量が少ないほど翌朝の発病率が高くなる。黄色・緑は0%、赤の境界25%で4%、残量0で85%。赤の範囲では `4% + 81% × (1 − 残量割合 / 25%)^1.35` を使う。最大体力と根性による消耗軽減は実際の行動と同じ計算にする。
警告で引き返した時は抽選しない。残量0で消耗行動を続けた時も抽選し、運が良ければ無事に進む。家で休むと発病前の予約を解除する。翌朝の発病は初回半日・再発一日の休養だが、DAY14は飛ばさず、不調の体力で大会に参加する。

## 7. LIME の仕様（連投制限・小分け・選択肢返信） [部分済 2026-06-12]

- **1日1話題ルール**: 同一キャラとのLIMEは **1日に1話題のやりとりまで**。
  返事をしたのに同じ日にまた**別の話題**で送ってくるのは禁止。
- **小分け送信はOK**: 1つの話題を2〜3通に分けて送ってくるのはあり
  （「ねえ」「今日さ」「大会の話聞いた？」のような連続バブル）。
  これは1話題としてカウントする。リアルなLIME感を出す演出として推奨。
- 別キャラからのLIMEは同日でもOK。
- ストーリー進行上必要な強制イベントLIMEは例外フラグで許可
  （`forced_events.json` / `lime_events.json` 側に `ignoreDailyLimit` 等）。
- **返信は選択肢制**: プレイヤーの返信は2〜3個の選択肢から選ぶ。
  **選んだ返信によって好感度ポイント（#23）の増減が変わる**
  （例: 気の利いた返し +大 / 無難 +小 / そっけない ±0 or 微減）。
  どれが正解かは選択肢の文面から雰囲気で推測できるようにし、
  理不尽な引っかけにはしないこと。
- **微量上昇（#814）**: 通常の好感度に入る返信報酬は、整数丸め後・端数蓄積前に追加で0.25倍（提案値）。基本1点の返信なら0.2125点、2点なら0.425点が積もる。恋人の絆は既存の別倍率を維持する。
  雑談の返信確定時に、上限内の端数を含む実増分がある場合だけ、トークに「♡ ほんの少し仲良くなった」を一度添える。恋人は絆の文言にする。履歴の再表示・SAVE/LOADで加算や演出を繰り返さず、会話待ちで保留した分は上昇通知に含めない。
- **残作業**: 既存LIMEの返信選択肢に増減差（pts指定）を付けるデータ作業。

## 13. 吸い出し工程の「ジャスト判定」 [済 2026-06-12]

クリティカルに相当する精密入力を吸い出し（引き）系の操作に追加する。
**※「クリティカル」という用語はゲーム内で使わない。** 統一用語は **「ジャスト」**。

2026-10-17の現行リメイク版（#637、オーナー承認済みゲーム内モデル）: 正の有限なgを総量で割った比率wを使い、中心C=0.54×Σ(w×heat_tolerance)、幅倍率A=機材倍率E×Σ(w×メーカー幅W)とする。適温はC±0.12A、最適温はC±0.05A。幅に耐熱倍率や社数ペナルティを掛けない。配合中は合成横ゲージと文字の帯端点を常時表示し、未選択を明示する。全工程・判定・採点・背景・auto・調整の開始中心は同じtemperatureBandsを参照し、同じtでも幅変更を表示に反映する。温度だけの適合度は中心100→最適温端90→適温端65へ連続補間し、帯外はSlope=360固定で減衰して0〜100に制限する。葉ダメージ減算・整数丸め後の工程得点、最終品質点とは区別する。ドバジ添加で保証するのは移動後中心からの許容幅の非縮小であり、元の絶対温度での高得点保証ではない。黄金比の正解や審査員の好みはゲージに表示しない。同じ比率なら総gだけを変えても帯は変わらず、温まり方だけに影響する。空配合はt=1、未知の葉や未定義/不正なheat_toleranceはその葉の倍率1。危険.90・爆発1・冷え切り.06は絶対値のまま。旧.76などの演出位置は緑上端〜危険の相対位置へ移す。実測の美味しい温度データは追加しない。提供時の最適温への近さで評価し、針のジャスト回数では加点しない。弾幕は被弾数で評価し、その成績は吸い出しの成功帯の幅・針の速度へつなぐ。温度は時間で上がり、被弾によって減らない。

- **キープ操作**: ゲージのさらに中央の狭い帯で止めると「ジャスト」
  → 中央は温度を維持、左寄りは微増、右寄りは微減して最適温へ合わせられる。少穴による時間的な温度の揺れは維持する（2026-10-08改定）。
- **上げ / 下げ操作**: ジャストで止めると変化量が大きくなる
  （通常の上げ下げより強く効く）。
- **狙わない自由**: 大きく動かしたくない場面ではジャストを狙わず
  通常帯で止めればよい。ジャスト＝常に最適、にはしない設計。
- 演出: ジャスト成立時に専用SE＋フラッシュ＋小さなスタンプ表示。
- 既存の判定スタンプ演出（PERFECT等）と用語・見た目が混ざらないよう整理する。

## 23. 好感度システムの二層化（ポイントと段階の分離）[済 2026-06-12 基盤]

現状は「会うだけで好感度が1段階上がる」ため甘すぎる。
**内部ポイント（数値）と段階（ランク）を分離**して、攻略の手応えを作る。
- **好感度ポイント**: 隠し数値。以下で増減する。
  - 自分で選んでキャラに会う: +（基本値。個別訪問なら少し上がる。章の強制イベントで会うだけでは上げない）
  - 会話イベントの選択肢: 選択によって増加量が変わる（良い選択 +大 / 普通 +中 / はずれ +小 or ±0）
  - LIME返信の選択肢（#7）: 同様に変動
  - 浮気的行動（#24）: 恋人キャラに対して減少
- **段階（ランク）**: ポイントが閾値を超えると上がる。**会うたびに毎回上がるわけではない**。
  「今日は会ったけど段階は変わらなかったな」という回が自然に発生するのが正しい。
- **バランス基準**: 選択肢をそこそこ当てながら **7〜8回会えば最大段階に届く**。
  全部はずれ選択だと+2〜3回かかる程度。逆に全部正解でも5回未満では届かない
  （会う回数の下限を保証して、攻略の過程自体を遊びにする）。
- **可視化**: ステータスメニュー（#19）の人間関係タブで、段階＋次の段階までの
  ゲージ（おおまかでよい）を表示。上がった瞬間は演出を出す。
- 既存セーブの好感度段階は、対応するポイント値に変換して引き継ぐ。
- **伸びの速さ（2026-10-03 HF01・リメイク版）**: 普通の好感度は、従来の加算量（魅力★・占いの倍率込みで四捨五入）の

## 25. シーシャくじ（一番くじ風のボックス抽選）

### 基本仕様

  期待値設計（後述）でバランスを取る。
- 演出: 引く瞬間のドキドキ演出を必ず入れる（箱から引く→開封→ランク表示。
  上位賞は煙エフェクト＋プチュン系の特別演出。#22の品質ルール対象）。
  連続で引く時のための「結果スキップ/連続引き」も用意する。

### 賞品構成（案）
| ランク | 500円くじ | 1,000円くじ（第1章から） |
|---|---|---|
| 上位賞 | 人気フレーバー・限定グッズ | **台（シーシャ本体）**・上位機材 |

### 期待値の設計（2026-10-17 #647・オーナーの実プレイ修正）

- 両グレードとも新品箱は50枚、S賞は1枚（初期確率1/50）。抽選は無作為な順番を保存した非復元抽選なので、途中の確率は残り景品と残り枚数に従う。
- 「定価で買うなら期待値がある程度」に合わせ、実際に付与する葉のgを店頭の50g価格で換算。非売品・景品専用の機材や小物は、既存の中古評価額を保守的な比較額に使う。実在商品の定価や、売却で得られる現金とは区別する。
- 500円：通常賞25,391円相当／50枚＝1回507.82円（101.564%）。ラストワン込み28,391円相当（113.564%）。S1枚・A5枚・3gサンプル37枚・50gフレーバー7枚。
- 1,000円：通常賞50,660円相当／50枚＝1回1,013.20円（101.32%）。ラストワン込み53,660円相当（107.32%）。S1枚・パイプ1枚・2種各50gセット2枚・ミント50g20枚・ブルーベリー10g26枚。
- 以前の「現金還元100〜115%」はこの依頼で置換。通常賞の現金化は500円箱10,500円、1,000円箱2,000円で、葉は売却不可。非売品の台は初回に所持へ加わり、重複時だけ従来の1,500円補償。
- 炭・アルミ等の表示だけで使用在庫が増えなかった下位賞は、実在庫に入る少量の葉へ置き換える。人気フレーバー詰め合わせもグレープ／ローズ各50gを付与する。
- 旧20枚／12枚箱は残りの順番・景品・ラストワンを保存し、そのまま引き切る。空になった日から3日後に50枚へ補充する。価格・お金・既得景品を取り消さず、閲覧やロードで残り順を再抽選しない。
- 回帰：`node remake/test/kuji_balance.mjs`、`node remake/test/browser/ch1_feedback.mjs`。

### ボックス制とラストワン賞
- くじは**ボックス制**（両グレード50枚。残り枚数を表示）。
- ボックスの最後の1枚を引くと **ラストワン賞** を追加でもらえる。両グレードとも店頭は「シークレット」とだけ案内し、中身の名称・説明は獲得時に公開する。
  強さは**そこそこ**（限定グッズ・ちょっと良い機材クラス。台や激レアは入れない）。
- **補充は数日おき**（例: 空になってから2〜3日後に新ボックス）。
  空にした瞬間に次が湧くとラストワン賞の無限周回が成立してしまうため。
- 残り枚数が見えることで「あと3枚だから引き切るか」「今日はやめとくか」の
  判断が遊びになる。引き切るかどうかは完全にプレイヤーの自由で、
  引かなくても何も損しない設計を守ること。

- **凛の口すべり**: くじ売り場の店員は凛。初回購入時などに

## 1. アルミ穴あけパート — HOLE RHYTHM BATTLE

### 概要
アルミの円盤上をカーソルが円周状に回転し、タイミングよく穴を開けるミニゲーム。
メイン評価は **「穴をどれだけ均等に、美しく開けられたか」**。
穴数や位置は後工程のシーシャ性能にも影響するが、スコアの最重視は均等度。

### 画面仕様
- 中央に円形のアルミ盤
- 外周・中周・内周の3リング
- カーソルが現在のリング上を時計回りに回転
- 入力すると現在位置に穴が開く（黒い小さな点/丸で仮表示）
- 残り時間・現在リング・スコア・コンボを表示

### 操作
- Space / クリック / タップ: 穴を開ける
- Enter / 完成ボタン: 穴あけ終了
- 外周がある程度完成したら中周へ、中周がある程度完成したら内周へ移動
- 内周は開けすぎるとリスク上昇

### 評価項目とスコア比率
均等度 / 円形精度 / 穴サイズ安定 / 過密ペナルティ / 空白ペナルティ /
リング完成度 / 残り時間ボーナス

```text
穴あけスコア =
均等度 50%
+ 円形精度 20%
+ 穴サイズ安定 15%
+ リング完成度 10%
+ 残り時間ボーナス 5%
```

### 穴数による性能影響
穴が多い: ドロー↑ 煙量↑ 立ち上がり早 / 熱保持↓ 焦げリスク↑ 灰落ちリスク↑
穴が少ない: ドロー重 煙量↓ 立ち上がり遅 / 熱保持↑ 灰落ちリスク↓

### リング別の役割
```text
外周: 熱拡散、安定感、持続力
中周: ドロー、煙量、立ち上がり
内周: 抜け感、攻め要素、焦げリスク
```

### レモン大会での理想
外周: 多め・均等 / 中周: 普通 / 内周: 少なめ
（レモンの香りは熱で飛びやすい → 熱を全体に広げ、中心火力を強くしすぎない）

### 演出テキスト（定数化）
PERFECT / GOOD / BEAUTIFUL RING / AIR FLOW UP / RING COMPLETE /
TOO CLOSE / BLANK SPACE / TOO MANY / RISKY

## 2. 炭焼きパート — HEAT IGNITION

### 概要
炭の色・赤熱具合・灰の状態を**目で見て**、ベストタイミングで取り上げるミニゲーム。
**ゲージ停止ゲームではない**。炭の見た目を観察して判断するゲームにすること。
ジャストタイミングに入った瞬間、**炭の芯そのものが一瞬ピカッと光る**。
その瞬間に取ると最高評価。

### 画面仕様
- 炭を3つ表示。炭ごとに焼けるスピードを少し変える
- 時間経過: 黒 → 赤 → 赤熱 → **ピカン** → 白熱 → 灰かぶり

### 操作
- クリック / タップ: その炭を取り上げる
- 長押し / 右クリック: 炭を裏返す（後回しでよい。最初は「取る」だけで成立させる）

### 炭の状態と評価
| 状態 | 見た目 | 評価 | 影響 |
|---|---|---|---|
| 生焼け | 黒い芯が残る | 低 | 火力不足、立ち上がり遅 |
| 早取り | 端だけ赤い | やや低 | 炭臭さが出る、火力が安定しない、煙量不足 |
| 適温前 | 全体が赤くなり始め | やや低 | 炭臭さが出る、火力が安定しない |
| **ジャスト** | 赤熱＋芯が一瞬ピカッ | **最高** | 火力安定、香り保持、立ち上がり良好 |
| 攻め焼き | 白っぽく赤い | 煙量重視なら有利 | 煙量↑ 焦げリスク↑ 香り保持↓ |
| 焼きすぎ | 白すぎ（身が痩せる） | 低 | 持ちが短い（持続↓）、香り飛び |

> 灰かぶりについて: 炭に灰が厚くかぶると灰が断熱になり熱が弱まるため、灰かぶり自体は評価項目ではなく調整操作として扱う（灰を落とすと熱が戻る）。

### ピカン演出
- ジャスト付近で炭そのものが一瞬光る
- 光った瞬間に取る → 「JUST IGNITION!!」
- 早すぎ → 「CORE BLACK」 / 遅すぎ → 「OVER HEAT」
演出テキスト: JUST IGNITION!! / 赤熱一閃 / CORE BLACK / OVER HEAT /
HEAT STABLE / AROMA KEEP

### 性能影響の数値例
```json
早取り:   { "heatPower": -20, "heatStability": -20, "startupSpeed": -20, "burnRisk": -15, "aromaRetention": -10 }
ジャスト: { "heatPower": 20,  "heatStability": 30,  "startupSpeed": 15,  "burnRisk": 0,   "aromaRetention": 15 }
焼きすぎ: { "heatPower": 10,  "heatStability": -10, "startupSpeed": 25,  "burnRisk": 10,  "aromaRetention": -20, "duration": -20 }
```

### レモン大会での理想
ジャスト直前〜ジャスト。
（煙量よりも香り保持と焦げリスクの低さを重視する）

### 基本の流れ
```text

### アピールポイント（制作結果から自動生成される実績）

「リラックス系と言うには刺激が強くないか？」
「味濃いめと言うには主張が弱くないか？」
```

成功: 方針=香り重視、完成品レモン香88・香り保持82・焦げ12、

失敗: 方針=香り重視、完成品レモン香35・焦げ65・炭焼きすぎ → ぶつける: 香り重視

### 評価軸

# 第3部 BGM制作リスト（Suno用プロンプト集）— タイトル〜第1章

> 使い方: Suno の **Custom Mode** で、各曲の `Style of Music` 欄に

- 歌声が混ざったら没。`Exclude Styles` に `vocals, singing, choir` を入れると安定

`01 → 04 → 02 → 10 → 11 → 09 → 12 → 13 → 14/15 → 残り`
（タイトル・tonari・日常昼が揃うと通しプレイの印象が一気に締まるため）

上映作品はサメ映画・宇宙SF・着ぐるみ怪獣・白黒探偵の4本の固定レパートリー。訪れるたびに短い物語の顛末とはじめの感想を読む。同じ作品でも小道具・間・登場人物などへの注目が変わる再訪会話を用意し、毎回新作が増える映画館にはしない。上映背景は台本の作品IDから選び、非サメ作品には対応するスクリーンとポスターの背景を使う。
