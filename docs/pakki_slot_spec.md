# PUFF!PUFF!パッキー（日常リール）— 現行仕様と旧組み込み記録

## 現行リメイク版（2026-10-08 PF19・24）

現行コードは `remake/js/daily/reel.js` / `remake/css/reel.css`。旧 `web/` は削除済み。
自分で選び実際に体力を消費した自由行動だけ、終了時に1回抽選する。抽選と報酬は即確定、演出は後追い。夜の分は同じ夜に見せる。

### 初回導入の体験（2026-10-19・#708 / #701 元32）

C.STATIONで新しくアプリを導入した場合だけ、パッキーの説明と遊び方カードを閉じた直後に「はじめてのスロット」を見せる。体験のための追加の行動枠・体力・料金は使わない。通常と同じ決定論抽選・報酬・リプレイ連鎖・記録を使い、確定当たりにはしない。以後は従来どおり、体力を使った自由行動後に回る。

導入途中はイベント用flagsの`_pakki_first_spin_pending`で記録し、抽選・報酬と同じ保存で消す。説明中や説明完了直後の再開でも一度だけ体験でき、回転中の再読込で再抽選・二重付与しない。導入済みの旧セーブには体験をさかのぼって追加しない。回転の表示待ちと表示途中の再開は既存方式を使い、表示済み結果の再提示を新設したものではない。共通saveが失敗した環境で永続化を保証する変更ではない。

通常の能力成長を実増加1Pへ揃え、★帯の減衰を外したため、リールの育成ボーナスは次の値とする。章上限・振替後の実増加だけを通知し、演出時に二重加算しない。

| 役 | ボーナスポイント |
|---|---|
| ハズレ／リプレイ | 1P（無通知。リプレイは再遊技も維持） |
| チェリー | 2P |
| ベル | 3P |
| REG | 16P |
| BIG／プレミア | 24P |
| フリーズ | 36P |

### 経験値のしくみが有効なときの報酬「追い風」（#1281・stat-design SPEC 1.8／4.3）

経験値・レベル・火種のしくみ（`core/growth.js`、`GROWTH_BOARD` または開発用の `?growth=1`）が有効なときは、上の能力Pの代わりに **経験値のブースト「追い風」** を渡す。無効なとき（現在の公開版）は上の表のまま。

| 役 | 倍率 | 続く回数 | 見せ方 |
|---|---|---|---|
| ハズレ／リプレイ | — | — | 無通知 |
| チェリー | ×1.25 | 1回 | 追い風 ×1.25 |
| ベル | ×1.25 | 2回 | 追い風 ×1.25 |
| REG | ×1.5 | 3回 | 追い風 ×1.5 |
| BIG／プレミア | ×1.5 | 5回 | 追い風 ×1.5 |
| フリーズ | ×2.0 | 5回 | 大追い風 ×2 |

- 次の自由行動から、体力を使った行動1回ごとに残りを1減らし、その行動の中で入る経験値（自由行動・はじめて・好感度の段）に倍率を掛ける。行動のあとに回るスロットの当たりは次の行動から効く。大会・章クリア・広さボーナスには掛けない。
- 追い風は1本だけ。新しい当たりは**倍率は高い方・回数は足す**、上限は ×2.0・10回。章をまたいでも残る。チェリー重複のボーナスは REG/BIG として扱う。
- 役・確率・天井・救済・設定・決定論RNG・演出の順番・ノートは変えない。`r.exp`（役の旧ポイント）は記録として残し、能力には足さない。HUD の経験値ゲージ横に「追い風 ×1.5 あと3」を出す。保存先は `state.growth.boost = { mult, left }`。

役の確率・天井・ジャグ連・重複・フリーズ制御・救済・決定論RNGは従来どおり。現行の天井はハズレ連続8回・ペカ間15回。下記の2026-06-12の分布・旧報酬値・旧天井は履歴であり、現行の育成量ではない。
通知は **SLOT BONUS**・能力名・実増加の **+NP**（2026-10-08 PF31・32）。通知位置は従来のまま、煙なしの元の5色の金属枠を一度明るくし、短い控えめな専用音を添える。進化時だけレベルと短い恩恵を添える。ランク名はステータス画面に置く。

### パッキースロットノート
筐体のパッキー（ランプ）を、当たりの待ち以外でタップすると開く。総回転・BIG/REG/合算・チェリー/ベル/リプレイの回数と確率・現在/最大ハマり・当たり履歴10件・フリーズ殿堂入り（`note.freezeLog` に章・日・回転数）・設定示唆。

### プレイヤー向けの説明（#634・#639）
初回説明（パッキーの5ページ）のあとに、遊び方カード1枚（`GUIDE`・店のラミネートの遊技説明のように短い言葉と図柄）。説明済みの旧セーブには一度だけ通知（`settingGuideDone`）。ノートの遊び方（`GUIDE`）でいつでも読み返せる。プレイヤー向けの文には、設定が変わるスポットの名前を書かない（「特定のスポットでも設定が変わることがあるよ。街を歩いて見つけてみてね！」）。

### 遊び方（システムの説明）
ノートを1回タップすると2ページ目の「遊び方」（`GUIDE`）。キャラではなくシステムの文章で、確率の数字は出さない。観音堂に行くとシステムの通知「お参りした。パッキースロットの設定が変わったようだ」。

### フリーズと救済の調整
- フリーズ: 総回転12からベース1/250、22回転以降で未取得なら1/40、1セーブ1回（`FREEZE_CONTROL`）。1章28回転で約17%。昇格の上乗せぶんはハズレから移す。
- 裏確変: 実際の当たり率（約1/9.4）に合わせ、総回転8以降、生涯ペカが「回転数×10.6%」の70%を割ったら REG/BIG ×2.5。1章30回転で当たり1回以下の人は約12%→約2%。
- 最近の不調の補い（#1281 オーナー決定 2026-10-30）: 直近30回転（`reel.recent`、1=ペカ）の当たりが2回なら REG/BIG ×1.25、1回以下なら ×1.5。30回転そろうまで（最初の30回転・記録のない旧セーブ）は無効。生涯の裏確変（×2.5）とは掛け合わせず大きい方だけ使い、増えた分はハズレから移す。ジャグ連（×1.5）は従来どおり別に効く。固定シード4000本の実測では最初の30回転は完全に同一、31回転目以降の能力Pは1回転あたり約+0.6〜1.1%（設定3・150回転で 3.417→3.455P/回転）。
- 左リールのBAR狙い（#1281 K01 オーナー決定 2026-10-30・見た目だけ）: ハズレ目の70%で左リールを「上段リプレイ・中段煙・下段BAR」に止める（`LEFT_BAR_AIM`）。この配列はBARの真下がチェリーなので、BARを上段・中段に置くとチェリー（角チェリー／中段チェリー）に見えるため下段にする。ハズレの約8割で左の窓にBARが見える。役・確率・報酬は変えない（出目は各回転の乱数の最後の利用）。
- この節より下の「天井40G」「告知64/14/12/10%」「報酬+6」などは旧版の記録。現行は天井15・告知は先/後の半々・報酬は冒頭の表。

## 1. コンセプト（オーナー決定事項・2026-06-12）

- **Aタイプ＋天井**。ジャグラー型の完全告知1本——「パッキーの顔（ランプ）が光ったら大当たり」。
  スマスロ的なAT・上乗せ・ハラキリ系演出は**不採用**
- C.STATION公式マスコットアプリ。初めて会場を訪れ、参加登録する場面でインストールする（2026-10-08 PF56）。それ以前は筐体も抽選もない。
  **1行動=1回転**：導入後、日常パートで実際に体力を使った自由行動の終了ごと、マップ隅のミニ筐体が裏で1回転
- **お助けガチャ**：当たらなくてもクリアできる。外れても最低+1、天井で最終的に全員救われる
- **恩恵はステータスのみ**（現金・アイテムは出さない。「生々しい」ため廃止）。経験値のしくみが有効なときは能力Pではなく経験値の追い風（冒頭の節）。
  伸びる対象は**直前の行動で伸びたステータス**＝行動のアンコール抽選
  （行動がステを伸ばさなかった場合は一番低いステ。家シーシャと同じ思想）
- **初回のみパッキーがアプリの説明**をする（4行・タップ送り・1セーブ1回）
- リセマラ不可：抽選は決定論RNG（シード＋総回転数）。行動した瞬間に結果が確定保存され、
  ロードしても同じ結果が再生される

## 3. 天井（持ち越し制）

| 種類 | 条件 | 保証 |
|---|---|---|
| ゾーン天井 | **8連続ハズレ** | 次の回転が小役以上（格上げ抽選。プレミアは出ない） |
| 本天井 | **ペカ間40回転** | 次の回転がペカ確定（REG/BIGの相対weight。「おたすけパッキー！」） |

- カウントは**日・章をまたいで持ち越す**（昨日のハマりが今日の期待になる）
- 表に数字は出さない示唆型。プレミア（フリーズ・中段チェリー）は天井救済からは**出ない**＝直撃のみ

## 4. ジャグ連ゾーン

BIG級（BIG／プレミア／重複BIG／フリーズ）の後**5回転**は REG/BIG の weight が**×1.5**
（増加分はハズレから移譲）。実測の連チャン感はテストログで確認できる。

## 5. フリーズ制御 —「完全確率に見せかけて管理」（オーナー指示）

ゲーム通して**1回あるかないか**にするための見えない制御。抑制・昇格ぶんの weight は
BIG に折り込むため、**外から見たペカ合算は常に一定**（テストが検算している）。

| 状態 | フリーズ weight |
|---|---|
| 序盤（総回転 < 20） | 0（序盤に+8が出ると強すぎるため） |
| 通常 | 4/1000（1/250） |
| 総回転110以上で未取得 | **12/1000（1/83）に裏昇格**＝引き弱でも終盤に出会える |
| 1回取得後 | **0（1セーブ1回まで）** |

演出：回転が「ガッ」と止まる→全SE消失→EN:CODEグリッチ（「運命、再コンパイル中……」）→
FREEZE BONUS＋パッキー乱舞→赤7揃い→「殿堂入り！スロノートに刻まれた」。
取得日は `state.reel.note.freezeLog` に永久記録（章・日・回転数）。

## 6. 裏確変（引き弱救済）（オーナー指示）

生涯ペカ数が期待値（回転数×7.5%）の**55%を割っている**と、こっそり REG/BIG weight を
**×1.7**（ハズレから移譲）。総回転30未満では発動しない。表示・示唆は一切なし。
決定論RNGなので「ロードして救済を引き直す」こともできない。

## 7. 告知バリエーション（プレミア演出）

ペカ時に variant を抽選（フリーズ・プレミア役は専用）：

| variant | 率 | 内容 |
|---|---|---|
| 後プカ | 64% | リール停止→ペカッ＋「ぷぷぷっ！」（基本） |
| 先プカ | 14% | レバオンで光る |
| 遅れ | 12% | レバオン後に低い「……プゴッ」（ガコッのパロ） |
| 無音回転 | 10% | SEが消えてスローに回る＝プレミア告知 |

- **ガックン**：章の最初の1回転だけリールがガクッと揺れる（リセット判別の小ネタ）
- 中段チェリー/単独パッキー：プゴッ→**虹ランプ**（BIG確定）
- ランプは点いたまま放置可。タップで「赤7（/BAR）を狙えっ！」→3コマ点灯→ファンファーレ。
  放置しても次の回転前に自動精算（報酬は取りこぼさない）

## 8. 表示ルール・テンポの整合（CLAUDE.md準拠）

- ステ数値は見せない。バナーは既存 gainBanner の3段階表現（+1〜2=少し／+3〜4=上がった／+5+=大きく）
- ハズレ/リプレイ/の+1は**サイレント**（毎行動バナーが出るスパムを防ぐ）
- ハズレの演出は約0.3秒で終わる（テンポ最優先）。CONFIGに「スロット演出 フル/簡易/OFF」を追加
  （OFFでも抽選と報酬は生きていて、バナーだけ出る）
- 演出はマップ画面でのみ再生。夜の行動分は翌朝マップで再生（結果はキューに永続化済み）

## 11. 設計メモ（既知の割り切り）

- 報酬は**行動した瞬間に確定適用**（演出は後追いの祝祭）。演出前にリロードしても損はしないが、
  ペカの祝祭演出だけは飛ぶことがある（報酬は適用済みなので実害なし）
- リールのウィジェットは `#screen-map` 常駐・通常 pointer-events:none（ランプのみ押せる）。
  マップ左下（x=14px, y=bottom14px）はピン配置と干渉しない位置
- パッキーの顔は `D.face_icons.packii`（無ければ「ぷ」フォールバック）。図柄は絵文字/CSSの
  プレースホルダ——本番ドット絵に差し替える場合は `SYM_HTML` を書き換える
