## これは何か

オーナーの方針（AA11）: 次は画質の良い素材で本格的にする。3Dではなく、**背景を一枚絵の「ハリボテ」として生成し、その上をキャラが歩く**。
キャラは `asset_sources/images/proto_walk/tsumugi_walk_sheet.png` くらいの解像度（細かさ）で動かし、**背景もそれに合わせる**。

- キャラ（つむぎ・おばさん・大学生）の歩行シートは**今あるものをそのまま使う**ので、今回は生成しない
- ゲームの画面では、キャラの身長は**約72ドット**（上のシートの1コマを約1/6に縮めた細かさ）。背景もこれと同じドットの細かさになるように描く
- 通りは「画面3枚分」の長さ。**1枚＝ゲーム画面1枚分のパネル**を3枚描き、横につなげる

## Git の手順

1. 作業場所は正規のチェックアウト（`shisha.canonicalRoot` に設定されている shisha-game）。
2. `git status` が clean か確認する。未コミットの変更があれば何もせず止まって報告する（別の作業の途中の可能性がある）。
3. 安全確認は `web/`・`data/`・`assets/` があり `./tools/check_git_safety.sh` が通ればよい（`project.godot` の確認は古いルール）。
   repo root・hooksPath・canonicalRoot の確認は通常どおり行う。
4. `git fetch origin claude/admiring-goodall-m9bdg3` → `git checkout claude/admiring-goodall-m9bdg3` → `git pull`
5. 画像を生成して保存 → 追加した PNG だけを `git add` してコミット → このブランチへ push
6. main への push・マージ・`--force` は禁止。PRは作らない。
7. 終わったら、ローカルは作業前のブランチ（通常は main）に戻す。

## 画像の共通ルール

- 画風参考: bg_eden_shop.png を第一基準にする。温かい照明の2Dドット絵〜ピクセルペインター調で、輪郭・影・質感に細かいドット感を残す。リアル写真調や滑らかすぎる3D調にしない。シーシャ台の先端は小さい凸型の金属ポストにし、凹んだカップ型・ボウル一体型・大きな先端パーツにしない。
  （`tools/bg_prompts.txt` 冒頭の基準）
- **キャラと同じドットの細かさ**: `asset_sources/images/proto_walk/tsumugi_walk_sheet.png` を毎回参照画像に付け、
  「このキャラを背景の上に立たせたとき、背景だけが細かすぎたり粗すぎたりしない」ドットの大きさ・描き込み・輪郭の太さにそろえる。
  前回の `asset_sources/images/proto_street/facades_sheet.png` の建物の雰囲気（色味・素材感）は引き継いでよいが、今回はもっと大きく細かく描く
- 視点: キャラの歩行シートと同じ、**少し上から見下ろした3/4ビュー**。建物の正面がこちらを向き、屋根の上面と歩道の奥行きが少し見える。
  **消失点を作らない**（平行投影に近い描き方）。横に3枚つなげるので、パネルごとに見下ろす角度や地面の高さを変えない
- 光は左上から。昼は穏やかな午後の光
- できるだけ大きく生成して、拡大はしない（縮小・ドット化はこちらでやる）。強いノイズ除去・ソフト系アップスケーラは使わない
- 夜の画像に暗さを焼き込まない。平均輝度は 80〜110/255 が目安で、影の中も形が読めること（暗さはゲーム側で重ねる）
- **背景に人物・車・動物を描かない。歩道の上に物を置かない**（自販機・ベンチ・街灯などはゲーム側で別の画像として置き、キャラが前後に回り込めるようにする）
- 文字・ロゴ・数字・看板の文字・透かし・フレーム・マスの区切り線を入れない。看板は無地の板にする（店名はゲーム側で表示する）
- 各画像は最大3回まで作り直してよい。作り直した回は `_try2`・`_try3` のように連番で残し、一番良いものを指定のファイル名で保存する

## 背景パネルの決まり（1〜6枚目に共通）

1枚＝ゲーム画面1枚分。**横長16:9（2048×1152 推奨。無理なら 1920×1080 や 1536×864）**。
キャラを立たせる縮尺と、地面の位置を3枚とも同じにする（画像の高さ H に対する割合）:

| 部分 | 位置・大きさ（H に対する割合） |
|---|---|
| キャラの身長（参照シートのつむぎ） | 約 0.20 H（2048×1152 なら約230px） |
| 入口のドアの高さ | 約 0.24 H（キャラの約1.2倍）。**どの店のドアも同じ高さ・同じ大きさ** |
| 建物の足元（歩道との境目） | 上から約 0.69 H の**水平線**。3枚ともこの高さにそろえる |
| 歩道（キャラが歩く帯） | 0.69 H 〜 0.93 H。タイル敷き・ところどころ色違いのタイル・黄色い点字ブロックの列。**何も置かない** |
| 縁石 | 0.93 H 〜 0.95 H |
| 車道 | 0.95 H 〜 下端（アスファルトと白い破線が少しだけ見える） |
| 建物 | 2階建て程度で、屋根が画像の上端近くまで来る。低い建物の上や建物の隙間から、空と遠くの街並みが少し見える |

- **左右の端は建物と建物の隙間**（細い路地・空き地）にして、建物を画像の端で切らない（ここで次のパネルとつなぐ）
- 2枚目は1枚目を、3枚目は2枚目を参照画像に付けて、歩道のタイル・縁石・車道・空の色・光の向き・色味がそのままつながるようにする
