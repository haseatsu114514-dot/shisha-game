# 立ち絵プロンプト待機リスト（未生成キャラ）

書式・スタイル指針は `docs/image_generation_guide.md` が正本（このファイルは正本の写し＋キャラ別の中身）。
容姿の記述は `data/characters.json` の `visual_concepts` から一字一句そのまま流用している（創作しない）。

**運用**: このファイルはプロンプトの控えのみ。生成・組み込みは依頼が来てから行う。
組み込んだら `assets/sprites/characters/{id}/` ができるので、そのキャラの項目はここから削除してよい。
