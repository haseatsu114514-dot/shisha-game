## Git の手順

1. 作業場所は正規のチェックアウト（`shisha.canonicalRoot` に設定されている shisha-game）。
2. `git status` が clean か確認する。未コミットの変更があれば何もせず止まって報告する（別の作業の途中の可能性がある）。
3. 安全確認は `web/`・`data/`・`assets/` があり `./tools/check_git_safety.sh` が通ればよい（`project.godot` の確認は古いルール）。
   repo root・hooksPath・canonicalRoot の確認は通常どおり行う。
4. `git fetch origin claude/admiring-goodall-m9bdg3` → `git checkout claude/admiring-goodall-m9bdg3` → `git pull`
   （前回の納品後に Claude のコミットが積まれている）
5. 画像を生成して保存 → 追加した PNG だけを `git add` してコミット → このブランチへ push
6. main への push・マージ・`--force` は禁止。PRは作らない。
7. 終わったら、ローカルは作業前のブランチ（通常は main）に戻す。

## 画像の共通ルール

- 画風参考: bg_eden_shop.png を第一基準にする。温かい照明の2Dドット絵〜ピクセルペインター調で、輪郭・影・質感に細かいドット感を残す。リアル写真調や滑らかすぎる3D調にしない。シーシャ台の先端は小さい凸型の金属ポストにし、凹んだカップ型・ボウル一体型・大きな先端パーツにしない。
  （`tools/bg_prompts.txt` 冒頭の基準。あわせて、前回納品の `asset_sources/images/proto_street/facades_sheet.png` と同じ色味・光の向き〔左上から〕に揃える）
- できるだけ大きく生成して、拡大はしない（縮小はこちらでやる。拡大するとぼやける）。強いノイズ除去・ソフト系アップスケーラは使わない。
- 夜の画像に暗さを焼き込まない。平均輝度は 80〜110/255 が目安で、影の中も形が読めること（暗さはゲーム側で重ねる）。
- 文字・ロゴ・数字・看板の文字・透かし・フレームを入れない。人物・車を描かない。
- 各画像は最大3回まで作り直してよい。作り直した回は `_try2`・`_try3` のように連番で残し、一番良いものを指定のファイル名で保存する。

## 生成する画像（3枚）

--- 1/3: `asset_sources/images/proto_street/far_day.png` ---
（参照画像: `assets/backgrounds/bg_eden_shop.png`〔画風〕・`asset_sources/images/proto_street/facades_sheet.png`〔色味と光の向き〕）
2Dゲームの横スクロール用、**遠景の街並みのパノラマ**を1枚。日本の地方都市の繁華街の、少し離れたところに見える街並み。
【内容】昼。上の約1/3は空（薄い雲・やわらかな青〜地平線近くは暖かいクリーム色）。その下に、遠くの中層ビル・雑居ビル・マンション・
屋上の給水塔・室外機・アンテナ・遠くの鉄塔が、高さを不揃いにして横に連なる。窓は細かく、一部が空を映して明るい。
下の約1/3は建物の壁で埋める（道路・地面・地平線・手前の建物は描かない。ゲームではこの手前に商店の建物が並ぶ）。
【見え方】真正面から見た遠景。遠くにあるものらしく、手前の建物シートよりコントラストと彩度をやや抑えた、少し霞んだ空気感。
【構図】横長 3:1（2400×800 前後。生成できる範囲で大きく）。**左右の端が自然につながる**ように、両端の空と建物の高さを揃える
（継ぎ目はこちらでなじませるので完全でなくてよい）。
【禁止】文字・看板の文字・ロゴ・人物・車・鳥。

--- 2/3: `asset_sources/images/proto_street/far_night.png` ---
（参照画像1: 1/3 の far_day.png〔構図〕 ／ 参照画像2: `asset_sources/images/proto_street/facades_sheet.png`〔色味〕）
1/3 と**同じ構図・同じ建物の夜**の版。
【内容】空は濃い紺〜地平線近くは街明かりで少し紫がかる。窓の灯りがまばらに点く（全体の3割ほど・暖色と白が混ざる）。
屋上の赤い航空障害灯がいくつか。月や星は描かない。
【明るさ】真っ暗にしない。平均輝度 80〜110/255 が目安で、建物の形が読めること（暗さはゲーム側で重ねる）。
【構図・禁止】1/3 と同じ（横長 3:1・左右の端がつながる・文字や人物なし）。

--- 3/3: `asset_sources/images/proto_street/fg_utility_pole.png` ---
（参照画像: `asset_sources/images/proto_street/props_sheet.png`〔画風・縮尺感〕）
**日本の街の電柱（コンクリート柱）を1本**。ゲームでは画面のいちばん手前を横切る、ピントの外れた前景として使う。
【内容】灰色のコンクリート柱。上の方に腕木（電線をかける横棒）と白い碍子、その少し下に円筒形の柱上変圧器、
柱の中ほどに足場ボルト、目の高さあたりに無地の巻き看板（文字なし）。
【見え方】真横から見た、まっすぐ立った姿。少し使い込まれた汚れ。
【構図】縦長 1:3（800×2400 前後）。柱は画像の上端から下端まで届くように描き、上下の端で切れていてよい
（ゲームでは画面の上下にはみ出す）。腕木は上から約1割の高さに置く。**電線は描かない**（ゲーム側で次の柱まで線を引く）。
【背景】完全な単色マゼンタ（#FF00FF）。影を背景に落とさない。文字を入れない。
