# 交際後ゲームプレイ・デート企画メモ（2026-10-11）

> 企画段階。**ゲーム本体への実装や既存データの変更は行わない。** 全6ヒロイン共通の設計案。個別エピソードは既存キャラ設定との照合前の仮案。

## 基本方針
- ♥1〜5の段階制は維持。**♥5で交際するかどうか決定**し、交際後も♥5のまま。
- 交際後もゲーム内の日常・店への訪問・他ヒロインとの交流を継続できる。「恋人になったらコンテンツ終了」にはしない。
- 交際後は**恋人固有イベント（各3本程度）＋繰り返し遊べる汎用デート＋恋人専用LIME・来店会話＋節目イベント**の二層以上の構成。
- デートは店外・営業時間外を中心に。仕事中のキャラは店の仕事を優先する。
- 交際後のイベント進行度は好感度♥5とは別に管理。交際日、デート既読、記念日、予定、関係状態を保存。
- 恋人限定のイベントは親友ルートでは出さない。親友ルートも専用の交流を用意する。
- 複数恋人が成立するゲーム仕様を尊重。予定重複を防ぎ、既存の修羅場イベントとの整合を取る。恋愛関係の重複に関する分岐・罰則は別途設計。

## 交際後の遊びのループ（提案）
1. いつもの店に訪問すると、交際状態に応じた専用挨拶・短い会話が時々発生。
2. LIMEで恋人に連絡・デートに誘う／相手から誘われる。
3. デート場所・日付を選び、他の予定と衝突しなければ実施。
4. 固有デートが条件に応じて解放される。終了後も汎用デートを繰り返せる。
5. 一定期間・記念日に特別な短い会話やイベントを解放。頻繁な通知や毎日必須の作業にはしない。

## 全ヒロイン共通のデート先候補
- カフェ、映画、買い物、散歩。場所は共通でも**会話・反応は各キャラ固有**。
- 固有デート各3本程度を初期目標とし、内容を使い回さない。
- デートを断ってもイベントは失効せず、別途企画した全6ヒロイン共通の再招待・保留システムを適用。

## サメちゃん交際後デート案
1. **「初デートは水槽の向こう」**：交際後の水族館。サメの解説は得意だが、手をつなぐタイミングの研究で大混乱。コロちゃん「求愛行動の実践編じゃな」。
2. **「恋人限定・サメ映画上映会」**：恋人向け映画を厳選したと言うが「サメと人間の禁断の恋」。はじめがツッコむ。付き合う前のB級映画5本立てと区別する。
3. **「海辺のサメちゃん」**：海辺デート。泳げない秘密は既存の親密度開示タイミングと整合させる。サメちゃん「わしは陸上活動専門のサメじゃ！」。最後は少し素直になる。
- 汎用デートの反応例：買い物でサメの歯のペンダントをお揃いにしたがる、散歩のために服を何度も着替えたとコロちゃんが暴露。
- 恋人になってもコロちゃんは大切な相棒。サメちゃんは仕事中に接客を疎かにしない。
