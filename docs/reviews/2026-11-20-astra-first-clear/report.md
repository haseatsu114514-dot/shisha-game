**ネタバレあり｜横持ちスマートフォン相当 844×390｜公開版 551a2c9**

## 作品のいちばん強いところ
このゲームの面白さは、シーシャの作り方を覚えること以上に、**同じ一台でも「誰に出すか」で正解が変わる**ところにある。初日の静かな常連、点をくれる審査員、もう一度吸いたいお客さん。客の違いをもっと手元の判断に返すと、ノベルと制作が今以上にひとつになる。

**初周の結果：** 第1章NEW GAME → 第5章・通算69日、9000に45対35。通常エンド、スタッフロール、RESULT、NEXT CYCLE解放を確認。先に直したいのは「横持ちで読める説明」「繰り返す日課の短縮」「次の一手が分かる制作評価」の3つ。

## 同じ場面を、二つの目線で
**シーシャ未経験者なら。** 「サッパリ系」「計12g」「ぬるい」「温度を上げる」はゲームだけで分かる。初日は全用語を覚える前に、常連のお姉さんに出す理由ができるから手を動かせる。半円の針を右で止め、左の温度計が変わる瞬間は面白い。一方、針の現在位置・温度・葉の持ち・ランク・残り回数が同時に出る。**次にどこを見ればいいか**だけ迷いやすい。初回は「いまぬるい → 右の暖色で止める → 適温なら提供」の三つを、操作に合わせて一つずつ出したい。詳しい辞書も今のまま残す。

**シーシャ経験者なら。** 水・詰め・通気・炭・蒸らし・提供後の調整まで、出した瞬間に終わらないのがいい。炭を3個回収する時の緊張と、客のペースに合わせる落ち着きが別の遊びになっている。逆に、レモンを12gにする操作は＋を12回押しても判断は一つ。穴24個も、初めては手仕事らしいが習熟後は作業になりやすい。**火を扱う判断は残し、同意図の反復だけを短くする**のがよい。評価は現実の作り方の正誤ではなく、ゲーム内の判断が伝わるかを見ている。

## 操作の快適さ：大きさの問題は全画面一様ではない
- 初日の配合＋／−は実測 **44×44 CSS px**、炭は約69×62、吸うボタンは146×54。制作の主操作は押し先を見つけやすい。「スマホだからボタンを全部大きく」ではない。
- 会話中の「用語」を開いて戻れた。辞書の本文は設計値15pxでも、横持ちでパネルが0.52倍になり**実表示約7.8 CSS px**。「一台」という日常語まで説明する内容の親切さが、小ささで損をしている。用語を増やすより先に、今の用語だけを会話と同じ大きさで読めるようにしたい。
- 地図で店を選ぶと写真付きの行き先が出て、決定へ進む。初見の誤タップ防止と店の紹介には良い。行動が意図どおり消費される前に確認できる利点は残す。一方、二度目以降の「家」まで同じ手順だと、読者に新しく伝わるものがない。
- 県大会では途中票の「解説」を確認。炭の状態→誰が推したか→得点の順でつながる。得点の棒と順位は読みやすいのに、いちばん知りたい「なぜ」が小さい。理由を一行大きく、残り票の詳細は開いたときに読む順番が合う。

## 章別のプレイ日記：急ぐ日と、急がないほうがいい日
**第1章／地元（通算1–14日）｜引き込まれる。** 「サッパリ系」を頼む常連のお姉さんがいて、レシピより先に接客が始まる。初注文はレモン単体、穴あけ24回、炭3個の回収、4分に設定して蒸らし、2回吸って提供した。等速・自動成功なし。失敗を試す前から細かい用語を全部読む必要はなかった。つむぎが店を描き応募する横で、はじめも大会への支度をする。「店を持ちたい」という夢がカウンター以外にも広がる構図が効いている。

**第2章／県大会（15–28日）｜物語がいちばん強く、日課がいちばん弱い。** 配達で新しい店と人に会う初日は、地図を歩く理由がある。そこからは地元で休む選択を多くした。この経路では2～13日目の12朝、行き先選択で毎回「地元・橙須へ」を押した。新情報のない同意を繰り返す感触が強い。逆に、炭を落としたあとの焦げ跡、なるが店の客の話をしているのに採点表に目を落とすくだり、優勝しても味覚の問題は消えない章末は残したい。この周は章内4日目に昼夜とも休み、体力100。それでも前夜から練習で追い込まれた説明で事故が起きた。筋は通せるが、休んだ人向けに「体は休めても頭の中では点を数えていた」の一行があると、休養を無意味にせずに済む。

**第3章／東京（29–47日）｜回復の場面は削らない。** 昼は公園やmukai、夜は部屋を選んだ。何も書けないノートに「休んだ」という日が初めて入る。なるには点のつかない話を聞きたいと連絡する。東京で強い相手に会うこと以上に、この二つで第2章の主人公の視線が本当に変わったと感じた。ましろと茶を淹れて何もしない時間も、恋人にならなくても意味がある。公園そのものが退屈なのではない。余韻が出た後も「今日はどこへ→部屋→休む」を同じ操作で送る部分は短くしてよい。

**第4章／ドバイ（48–64日）｜土地が変わる意味がある。** 同行者なしで出発。スークの香辛料、中心地のカフェのダブルアップル、クリークの荷の積み方を見た。市場で名も知らずひと休みした相手が世界大会の壇上に立つ。「路地裏の約束」で大会相手との距離が縮まるのがいい。桜12gで挑み、優勝後、訪ねた場所と配合が章末に載った。反面、ドバイの中盤は同時に「！」が多く、体力も残り日数も扱っているのに、何が本筋で何が旅行の楽しみか一目で区別しにくい。全部行かせるより、今夜のお薦め1件と、自由な寄り道を分けたい。

**第5章／帰郷と9000（65–69日）｜最高の問いに戻ってくる。** 強い日のはじめを再現できるSHISHA-9000。博士には記録に載らない「ましろとお茶を飲んで一台も作らなかった日」の意味を話す。機械を悪役にせず、9000の一台にも人の手が残ると認めるのがよい。最後は同じダブルアップル12gを同じ客へ。1台目は19対21。2台目は水を長押しで0から47.85まで入れ、「ちょうどよく浸かっている」を確認。ふんわり詰めを選び、蒸らしは雑念に8回捕まって△。それでも提供と2回の調整を適温に収め、2台目26対14、合計45対35で勝った。「失敗した工程があっても、後の判断で立て直せる」を実際に体験できた。恋人なしの後日談がとくにいい。師匠から「tonari」は客の隣に座れる店だと聞き、最後にはいつもの鉄仮面さんが、自分から本名を名乗る。世界一の称号より、この人が少し笑ったことが結末になる。自由日程は博士へ連絡するまで任意。この5日を全員の必須尺とはしない。

## 退屈だった順／削ってはいけないもの
1. **第2章の朝の行き先確認。** この周の12朝はすべて同じ選択。同じ答えの再入力を減らし、未読の用件が来た日だけ立ち止まらせる。配達で店を知る初日と、事故・なるとのすれ違いの夜は残す。
2. **習熟後の同じ手仕事。** 初日の12タップと24穴は、手順を覚える体験として成立する。判断せず同じものを作る再訪時だけ、最後の配合・穴配置を再利用できるといい。炭をどこで取るか、いつ出すか、客の言葉を受けてどう直すかは手動に残す。
3. **終盤の場面と場面の間の「続きを読む」。** 第5章の結果、会場での会話、片づけ、帰店、フィナーレの区切りには意味がある。最終日にカードの「続きを読む」を7回押した。次の押し先が毎回一つのときは余韻よりページ送りを意識した。保存や休憩の目印は残し、章内の短い連続場面だけ「このまま次へ」も選べるといい。

## 改善の優先順位
1. **大きい文字で、次の判断を一つ。効果：大／工数：小～中。** まず辞書本文と県大会の審査理由を横持ち時だけ拡大。初注文は用語集へ飛ばなくても「状態→何をする」が読めるようにする。制作ボタン全体の拡大は不要。
2. **日課の同じ確認を省く。効果：大／工数：中。** 第2章の朝に「前回と同じ街」「今日は地元で休養」を追加。初訪問・費用・未読の店や夜の固定イベントを消費前に示し、読んでいない本筋は飛ばさない。
3. **各制作の最後に、次に変える一点を返す。効果：中～大／工数：小～中。** 最終戦は蒸らし△・被弾8回なのに、よかった点は「提供と2回の調整が適温」、次の練習は「今回の記録を見て、次に試すことを選ぼう」。前者は正確だが後者は誰にでも言える。例えば「次回は蒸らしで雑念を減らし、同じ配合で針の止めやすさを比較」。初心者の再挑戦にも、経験者の条件を一つずつ変える遊びにも効く。

## バグと好みは分けたい
- **表示の不整合（再現条件あり）。** 第4章を終え第5章の最初のカードを開くと、本文は「tonari」、左帯は「第五章 ドバイ 一日目」。後に地元の地図で「橙須」に変わる。移動する話なので数秒でも迷う。第5章開始時に現在地を更新する。実画面（PDF参照）
- **最終戦だけ客の呼称が食い違う。** 物語・票数画面では同じ「観客」が二台を判定するが、二台目の提供後と調整で「審査員」と表示された。この一戦だけ「お客さん」へ。等速の調整選択が出た直後には、大きいAランクの演出も炭の配置選択に一時重なった。演出中も選択対象がどこにあるか見えるとよい。操作が不能とは確認していない。実画面（PDF参照）
- **要再現（原因未確定）。** 章末会話を中央タップで速く送った第2章・第3章で、次章のボタンを選ぶ前にタイトルへ戻った。どちらも今回のクリア済みオートセーブから進行を再開でき、データ消失はない。第3章の完了画面は、会話を送った座標と「タイトルへ」の位置が重なる。タップが画面切替をまたぐ仮説はあるが、通常の読書速度や実機での再現は未確認。戻る操作の確定前に旧画面からの入力を無視するかを、追試してから決めたい。
- **好み。** 制作の派手なランク演出は残したい。プロらしさは演出を全部静かにするのではなく、「次の判断の前だけ視界が空く」ことで出せる。
