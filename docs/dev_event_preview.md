# 安全なイベント台本プレビュー

ゲーム起動後、ブラウザの開発者コンソールから実行します。

```js
__remake.inspect.events("mashiro") // イベントIDを検索
__remake.preview.open("ch1_tsumugi_first") // 実在するIDに置き換える
__remake.preview.close() // 閉じる
```

これは**実際のVNイベント再生ではありません**。画面上に台詞・選択肢・分岐を並べるだけの開発用プレビューです。背景・立ち絵・アニメーション・条件分岐・フラグ付与は再現しません。

セーブ保護のため、イベントエンジンを呼び出さず、ゲーム状態も変更しません。開発者が任意のIDを指定しても通常の進行を飛ばさない設計です。

本番のイベント動作確認は、従来どおりブラウザでの実プレイ・専用テストが必要です。公開する場合は開発者向け機能のアクセス制御を別途検討してください。
