# ChatGPT で作る画像リスト（2026-10-06）

Codex の利用制限中に、オーナーが ChatGPT で1枚ずつ作るための控え。
**1枚（または同じ会話内の2〜3枚）で完結し、合成や大量の差分が要らないもの**だけを選んだ。
コピペ用プロンプトは各項目のコードブロック。

## 進め方

1. ChatGPT に「参照として添付」と書いた画像を添付し、プロンプトを貼る
   （参照画像は GitHub の該当パスを開いて Download raw file で保存）
2. できた画像は GitHub の作業ブランチで `assets/sheets_inbox/` を開き、
   **Add file → Upload files** で、下の「ファイル名」どおりの名前にしてアップする
   （チャットに貼った画像はファイルとして届かない）
3. あとは Claude 側でやる: 16:9への切り出し・1280x720への縮小・立ち絵の透過・896x1200への配置・
   足元合わせ・`remake/tools/build_manifest.py`・`web/build_data.py`・テスト

ゲーム側は**全部組み込み済み**（`show_cg` や話者IDがもう台詞に入っている）。ファイルが届けばそのまま表示される。

## B. 立ち絵（新キャラ）

### 進め方（各キャラ共通）

1. 1枚目＝`normal` を作る（下のプロンプト）
2. **同じ会話の中で**、1枚目を添付して「表情差分」のプロンプトを貼り、残りの表情を1枚ずつ作る
   （別の会話にすると顔が変わる）
3. 縦長（1024x1536）でよい。サイズと足元の位置は Claude 側で揃える

画風の参照として毎回添付: `assets/sprites/characters/minto/chr_minto_normal.png`、`assets/sprites/characters/rin/chr_rin_normal.png`
（参照するのは画風だけ。顔・髪・服は真似させない）

#### 表情差分のプロンプト（2枚目以降・共通）

```
添付の1枚目とまったく同じ人物・服装・画風・頭身・大きさ・立ち位置で、
表情を「（ここに表情）」に変えた全身をもう1枚描いてください。
表情に合わせて、手・肩・首の角度を少しだけ変えてよい（全身が画面に収まること）。
背景は透過PNG。市松模様・床の影・背景の光は描かない（透過できないなら単色のマゼンタ #FF00FF）。
文字・ロゴ・サイン・透かしを入れない。
```
