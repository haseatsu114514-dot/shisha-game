# Post-Chapter 1 Roadmap

更新: 2026-10-13

## 方針

第1章完成の既存作業を維持しながら、2026-10-13のオーナー指示で**第2章の制作を開始**する。

GitHub Issuesには、近いうちに実装・検証する具体的な作業と、開発運用を安全に進める基盤タスクを置く。第2章は今回の着手範囲から小さな実装単位へ切り出し、遠い後章の構想を一度に戻さない。

第2章以降の物語・恋愛・章進行・後半解放など、着手時期が遠い構想はこのロードマップへ退避する。退避した旧Issueは `not planned` で閉じるが、**廃案ではない**。着手時にこの文書と旧Issueの履歴を確認し、最新仕様に合わせて必要な作業だけ新しいIssueへ切り出す。

## 第2章の制作開始（Issue #514）

### 街と物語の要件

- 第1章と同じ地方・県内の隣町。第3章の東京へ先に移動させない。
- 第1章の大須・栄に対して、第2章は**名古屋駅＋渋谷**を合わせた、規模と格式が一段上の都市。駅前の高層ビル、広い駅前通り、スクランブル交差点、大型ビジョン、ファッション街を軸にする。名古屋の主要都市の落ち着いた整備感と、渋谷の人の流れ・看板の密度を混ぜる。
- 高層部だけにせず、駅前・繁華街・一本入った古い路地・工業地区を一枚の街に配置する。看板型ピンと行き先案内は現行マップの操作を引き継ぎ、昼夜で建物・道路・入口位置を揃える。
- 正式章題は「第二章：才能の壁 / Jealousy Haze」。県大会はHAZE: OPEN CLOUD、準備期間13日＋DAY14の4人同時一戦。対戦相手はあげは・神崎竜二・零-REI-。ヴォルクは第3章で登場。2026-10-13追加訂正により第2章の先行展示・店・交流は外す。
- 導入は他人の手つき・感覚・準備への素直な驚きから始め、評価と自分の武器を気にする焦りの種を置く。味覚の回復、孤立の解決、あげはが去る理由の開示を先取りしない。

### 今回の実装範囲と未完

Issue #514は、独立した導入試遊として新都市の昼夜マップ、到着、3店舗の入口での初顔合わせ、C.STATIONと同じビルの県大会ホールの13日前の準備訪問、3地点の準備中の室内見学、帰路を接続する。台詞は `data/dialogue/ch2_city.json`。地図から任意の順で巡れる構成にし、店で本人が名乗ってから名前・紹介を表示する。既存の第2章台本・人物設定を参照し、初訪問の重複名乗りと古い日程を持ち込まない。

続行で本編DAY1も接続した。第1章クリア→章題→出発→到着→会場確認・任意の見学→帰路→tonariの夜まで。台本は試遊と同じ `ch2_city.json` と本編用 `remake_ch2.json`。既知の相手と未面識の博士は、名前の正本である `state.met` から分岐する。店の訪問順は自由だが、本編では会場を確認してから帰る。未訪問の店は帰路や帰店で体験済みにしない。

試遊は第1章クリア相当の一時状態で開始する。本編のセーブ、所持品、関係、能力・報酬に変更を残さず、第2章の自然な章移行や全章完走として扱わない。この独立試遊では日常を進めない。本編側はDAY13までのカレンダー・固定物語を接続し、競技と東京行きは未接続。店内見学は専用の準備中背景で短く読み、別店舗や大会舞台を代用しない。機材の実演や喫煙は後続。

- 共有素材は実物と採用記録を見て、人物の同一性・現行画風・用途・表示比率・品質で判定する。採用済み人物紹介・章題・第1章マップを根拠なく再生成しない。新街の昼夜素材と専用店舗背景は `assets/`、制作元・比較・QAは `asset_sources/` に保存する。
- REIとヴォルクの既存台本には店舗会話で `bg_tournament_stage` を使う仮指定が残る。現行の店舗背景があるとは扱わず、専用素材が揃ってから接続する。神崎の店名は現行 `data/characters.json` と台本の「神崎煙草店」を使う。
