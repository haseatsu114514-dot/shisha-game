# Post-Chapter 1 Roadmap

更新: 2026-10-12

## 方針

当面は**第1章を完成させることを最優先**とする。

GitHub Issues は、原則として「第1章完成のために近いうちに実装・検証する作業」と、現在の開発運用を安全に進めるための基盤タスクだけを置く。

第2章以降の物語・恋愛・章進行・後半解放など、着手時期が遠い構想はこのロードマップへ退避する。退避した旧Issueは `not planned` で閉じるが、**廃案ではない**。着手時にこの文書と旧Issueの履歴を確認し、最新仕様に合わせて必要な作業だけ新しいIssueへ切り出す。

## 第2章以降へ退避する構想

### シーシャ上級要素

- **4点置き・炭混合の解放**（旧 #303）
  - 第1章では三角3個など基礎配置を中心とする。
  - 4点置き・炭種類の混合は既存の解放フラグを再利用し、第2章以降の適切なイベント／進行条件で解放する。
  - 解放前後・旧セーブ・選択UIを確認する。

### つむぎ

- **第2章本筋で♥3分岐を解放**（旧 #328）
  - 第1章では本筋を通して♥2までを基本とし、第2章の物語進行に♥3の節目を接続する。
  - 条件通過後は自由交流へ戻し、二重再生・旧セーブ停滞を防ぐ。

### サメちゃん / SHISHARK

親構想: 旧 #276

- **SHISHARK交流と恋愛への入口**（旧 #337）
  - 第2章でSHISHARK店主としての交流を深める。
  - 店作りを通した好感度・恋愛分岐の前半を設計する。
  - 大会のライバル役とは混同しない。
- **♥MAX後の告白／友人選択**（旧 #338）
  - 恋人になる／友人のままを選択可能にする。
  - 恋人状態、複数交際、修羅場、旧セーブを共通システムへ接続する。
- **恋人絆Lv1〜5の専用イベント**（旧 #339）
  - コロちゃん、秘密の開示順、サメちゃんらしいコメディ→本気恋愛の流れを守る。
- **恋人LIME・デート・記念日**（旧 #340）
  - 恋人専用の誘い・デート・継続交流を追加する。
- 第4章では、恋人ルート成立時のみ海外同行候補にできる。友人ルートでは同行させない。

### 第3〜5章の章構成

親構想: 旧 #315

確定している大枠:

1. 第1〜2章: 地元
2. 第3章: 東京
3. 第4章: 東京で準備 + 海外
4. 第5章: 地域別の自由な展開
5. 9000との決着後: 真エンディング → スタッフロール → タイトルへ戻る

個別構想:

- **第3章東京への移行**（旧 #332）
  - 第1・2章から第3章へ章状態・マップ・関係・所持品を安全に引き継ぐ。
- **第4章準備／海外 → 第5章**（旧 #333）
  - 第3章から第4章、第4章から第5章の章骨格を接続する。
- **遠距離LIME・東京デート・帰郷**（旧 #334）
  - 地元恋人との遠距離関係を維持する。
  - 東京訪問時は自然な予約導線でデート可能にする。
  - 遠距離を理由に自動的な好感度低下・破局は追加しない。
- **海外同行・別便応援・予定競合**（旧 #335）
  - 同行は恋人1名または同行なし。
  - 同行と別便での応援を区別する。
  - 複数交際・予定競合時は安全に再調整する。
- **真END・スタッフロール**（旧 #336）
  - 9000決着後に真ENDへ進み、スタッフロール終了後はタイトルへ戻す。
  - 無期限自由行動へ誤遷移させない。

## 再Issue化するタイミング

以下を満たしてから、このロードマップの項目を実装Issueへ戻す。

- 第1章の通しプレイが安定している。
- 第1章の主要バグ・進行停止・チュートリアル・制作UI・大会・セーブの重要問題が片付いている。
- 第1章の主要ビジュアル／演出が採用状態まで整理されている。
- 第2章の制作に着手する意思が明確になった。

再開時は旧Issueを丸ごと復活させるのではなく、最新mainと最新設定を確認し、**1 Issue = 1実装単位**になるよう必要な部分だけ新規Issueへ切り出す。
