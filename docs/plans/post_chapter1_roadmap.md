# Post-Chapter 1 Roadmap

更新: 2026-10-12

## 方針

当面は**第1章を完成させることを最優先**とする。

GitHub Issues は、原則として「第1章完成のために近いうちに実装・検証する作業」と、現在の開発運用を安全に進めるための基盤タスクだけを置く。

第2章以降の物語・恋愛・章進行・後半解放など、着手時期が遠い構想はこのロードマップへ退避する。退避した旧Issueは `not planned` で閉じるが、**廃案ではない**。着手時にこの文書と旧Issueの履歴を確認し、最新仕様に合わせて必要な作業だけ新しいIssueへ切り出す。

## 第2章以降へ退避する構想

  - コロちゃん、秘密の開示順、サメちゃんらしいコメディ→本気恋愛の流れを守る。

- 第4章では、恋人ルート成立時のみ海外同行候補にできる。友人ルートでは同行させない。

### ましろ

- **第3章の本編接続後に、初対面→交際→恋人デートまで新規ゲームで通し検証**（旧 #382）
  - ましろの恋人デート自体は実装済みで、保存済み恋人からのLIME招待→承諾→予約→デート→選択→報酬／保存はPR #413で検証済み。
  - 既存6人のデート、旧セーブ、辞退／保留／期限切れ、未定義IDの非フォールバックもQA済み。
  - 残る確認は、設定上ましろが登場する**第3章**が本編接続された後の「新規ゲーム→初対面→交際→デート」の自然な全導線のみ。
  - 第1章完成のActive Issueには置かず、第3章着手時に最新mainから新しいQA Issueとして切り出す。

### ひより後半ルート

第1章で現在優先するのは、既に接続されている**序盤の遭遇・tonari再会・LIME・旧セーブの公開QA**（#341）。以下はその先の未制作／未接続の後半ルートであり、第1章完成のActive Issueから外す。

- **斧投げ背景・後半衣装／表情・追加ビジュアル**（旧 #342）
  - 斧投げシーシャ店専用の背景を用意し、別店舗背景で代用しない。
  - 後半用のひより人物差分は、顔・髪・衣装など同一人物性と既存画風を維持する。
  - ヒロインの見せ場用に、ひより専用のランダム画像**5パターン**を検討する。既存表情の単純流用ではなく、構図・表情・仕草・雰囲気に差を付ける。
  - 5枚を使う場面は再開時に決め、正体発覚など重要演出がランダムで崩れるなら固定表示を優先する。
  - PC／スマホ表示、透過、縮尺、ロード、欠落時エラーを確認する。
- **斧投げで「儚い女」モードの裏の素顔を知るイベント**（旧 #343）
  - tonari再会だけでは `_hiyori_real_self_known` を立てない。
  - 斧投げの正式イベントで、演じている外面と声量・語彙・行動など本来の個性のギャップを自然に見せる。
  - 旧セーブや未読状態から勝手に素顔既知へ移行しない。
- **素顔判明後の仕事相談と恋愛／友情の着地**（旧 #344）
  - 総務・OLとしての仕事の大変さ、「儚い女」を演じて精神を保つ背景を深掘りする。
  - 既存の関係システムへ友情／恋愛の問いかけ、段階的な結論・告白を接続する。
  - tonari序盤会話を重複再生せず、斧投げ素顔判明後から進む。
- **ひより専用ハガルと後半進行**（旧 #345）
  - 後半ルートを正しく進めた場合だけ専用ハガルを一度取得できるようにする。
  - 既読、一度きり、旧セーブ、他キャラの同機能との整合を確認する。
- 海外同行などさらに先の章構成は旧 #315 側のロードマップ項目として扱う。

再開時は #342 → #343 → #344/#345 の依存関係をそのまま巨大Issueに戻さず、素材制作・イベント接続・関係分岐・報酬を最新mainに合わせて小さなIssueへ切り直す。

### 第3〜5章の章構成

親構想: 旧 #315

確定している大枠:

1. 第1〜2章: 地元
2. 第3章: 東京
3. 第4章: 東京で準備 + 海外
4. 第5章: 地域別の自由な展開
5. 9000との決着後: 真エンディング → スタッフロール → タイトルへ戻る

個別構想:

- **第3章東京への移行**（旧 #332）
  - 第1・2章から第3章へ章状態・マップ・関係・所持品を安全に引き継ぐ。
- **第4章準備／海外 → 第5章**（旧 #333）
  - 第3章から第4章、第4章から第5章の章骨格を接続する。
- **遠距離LIME・東京デート・帰郷**（旧 #334）
  - 地元恋人との遠距離関係を維持する。
  - 東京訪問時は自然な予約導線でデート可能にする。
  - 遠距離を理由に自動的な好感度低下・破局は追加しない。
- **海外同行・別便応援・予定競合**（旧 #335）
  - 同行は恋人1名または同行なし。
  - 同行と別便での応援を区別する。
  - 複数交際・予定競合時は安全に再調整する。
- **真END・スタッフロール**（旧 #336）
  - 9000決着後に真ENDへ進み、スタッフロール終了後はタイトルへ戻す。
  - 無期限自由行動へ誤遷移させない。

## 再Issue化するタイミング

以下を満たしてから、このロードマップの項目を実装Issueへ戻す。

- 第1章の通しプレイが安定している。
- 第1章の主要バグ・進行停止・チュートリアル・制作UI・大会・セーブの重要問題が片付いている。
- 第1章の主要ビジュアル／演出が採用状態まで整理されている。
- 第2章の制作に着手する意思が明確になった。

再開時は旧Issueを丸ごと復活させるのではなく、最新mainと最新設定を確認し、**1 Issue = 1実装単位**になるよう必要な部分だけ新規Issueへ切り出す。
