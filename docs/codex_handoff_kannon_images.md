# Codex 依頼: 歩くシステムの新ステージ「古町の観音堂」の画像（画像だけ・10枚）

作成: 2026-10-06（Claude）／ 台帳: `docs/owner_requests.md` の AA14〜AA15
前回の同じ形の依頼: `docs/codex_handoff_street_set_images.md`（繁華街のハリボテ背景版・納品済み）

## これは何か

オーナーの要望（AA14）: 歩くシステムで、**愛知県の大須観音をイメージした**横スクロールのハリボテ背景のステージを作る。
お参りができる、鳩がいて近づくと飛んでいく、人と話せる、という境内。

- ゲーム内の名前は本編と同じ**「古町の観音堂」**（本編の観音堂の背景 `assets/backgrounds/bg_kannon_day.png` も大須観音に近い朱塗りの本堂）。
  大須観音の**雰囲気を借りた架空の寺**として描く。実在の建物の正確な写しにはしない
- 作りは繁華街のハリボテ背景版と同じ。**背景は画面1枚分のパネル×3枚**（昼・夜）を横につなぎ、その上を約72ドットのキャラが歩く
- 賽銭箱・常香炉・灯籠などは**別の画像**にしてゲーム側で置く（キャラが前後に回り込めるように）。鳩・猫も別の画像で、ゲーム側で動かす
- 遊びの部分（お参り・煙・おみくじ・鳩が逃げて戻る・会話）は Claude が仮の絵で実装済み（`web/proto/street/index.html?area=kannon`）。
  画像を置いて変換すれば、コードを変えずに差し替わる

## 担当範囲

**Codexの担当は「画像を生成して、元画像をリポジトリに上げる」ところまで。**
切り出し・つなぎ合わせ・ドット化・組み込み・位置の測り直しはすべて Claude が行う。

- コード・既存ファイルは一切変更しない（変換スクリプトも実行しなくてよい）
- 追加してよいのは、下に指定した `asset_sources/images/proto_kannon/` の PNG（＋作り直しの `_try2`・`_try3`）だけ

## Git の手順

1. 作業場所は正規のチェックアウト（`shisha.canonicalRoot` に設定されている shisha-game）。
2. `git status` が clean か確認する。未コミットの変更があれば何もせず止まって報告する（別の作業の途中の可能性がある）。
3. `./tools/check_git_safety.sh` が通ること（`web/`・`data/`・`assets/`・`remake/` があり、`project.godot` が無い）。
4. `git fetch origin` → **このファイル（`docs/codex_handoff_kannon_images.md`）が `origin/main` にあれば** `origin/main` から
   `codex/kannon-images` を切る。まだ main に無ければ `origin/claude/serene-carson-tu1ujt` から切る。
5. 画像を生成して保存 → 追加した PNG だけを `git add` してコミット → `codex/kannon-images` へ push
6. main への push・マージ・`--force` は禁止。PRは作らない。
7. 終わったら、ローカルは作業前のブランチ（通常は main）に戻す。

## 画像の共通ルール

- 画風参考: bg_eden_shop.png を第一基準にする。温かい照明の2Dドット絵〜ピクセルペインター調で、輪郭・影・質感に細かいドット感を残す。リアル写真調や滑らかすぎる3D調にしない。シーシャ台の先端は小さい凸型の金属ポストにし、凹んだカップ型・ボウル一体型・大きな先端パーツにしない。
  （`tools/bg_prompts.txt` 冒頭の基準）
- **繁華街のハリボテ背景と同じ見た目にそろえる**: `asset_sources/images/proto_street_set/street_panel_1_day.png` を毎回参照画像に付け、
  見下ろし角度・ドットの細かさ・色味・光の向きをそろえる（同じゲームの別の場所に見えること）
- **キャラと同じドットの細かさ**: `asset_sources/images/proto_walk/tsumugi_walk_sheet.png` も参照画像に付け、
  「このキャラを背景の上に立たせたとき、背景だけが細かすぎたり粗すぎたりしない」ドットの大きさ・描き込み・輪郭の太さにする
- 寺の見た目の参考: `assets/backgrounds/bg_kannon_day.png`（朱塗りの本堂・石段・灰色の瓦屋根・白い幟）
- 視点: 少し上から見下ろした3/4ビュー。建物の正面がこちらを向き、屋根の上面と境内の奥行きが少し見える。
  **消失点を作らない**（平行投影に近い描き方）。横に3枚つなげるので、パネルごとに見下ろす角度や地面の高さを変えない
- 光は左上から。昼は穏やかな午後の光
- できるだけ大きく生成して、拡大はしない（縮小・ドット化はこちらでやる）。強いノイズ除去・ソフト系アップスケーラは使わない
- 夜の画像に暗さを焼き込まない。平均輝度は 80〜110/255 が目安で、影の中も形が読めること（暗さはゲーム側で重ねる）
- **背景に人物・鳩・猫・その他の動物を描かない**（鳩・猫はゲーム側で動かす）。**石畳の上に物を置かない**（賽銭箱・常香炉・灯籠・幟・おみくじ・縁台はゲーム側で置く）
- 文字・ロゴ・数字・透かし・フレーム・マスの区切り線を入れない。**提灯・扁額・幟・賽銭箱も無地**（実物にある文字は描かない。名前はゲーム側で出す）
- 各画像は最大3回まで作り直してよい。作り直した回は `_try2`・`_try3` のように連番で残し、一番良いものを指定のファイル名で保存する

## 背景パネルの決まり（1〜6枚目に共通）

1枚＝ゲーム画面1枚分。**横長16:9（2048×1152 推奨。無理なら 1920×1080 や 1536×864）**。
キャラを立たせる縮尺と、地面の位置を3枚とも同じにする（画像の幅 W・高さ H に対する割合）:

| 部分 | 位置・大きさ |
|---|---|
| キャラの身長（参照シートのつむぎ） | 約 0.20 H（2048×1152 なら約230px） |
| 建物・塀の足元（境内の石畳との境目） | 上から約 0.69 H の**水平線**。3枚ともこの高さにそろえる（繁華街のパネルと同じ） |
| 境内の石畳（キャラが歩く帯） | 0.69 H 〜 0.93 H。灰色の四角い敷石、ところどころ色違いの石。**何も置かない** |
| 手前 | 0.93 H 〜 下端。低い石の玉垣（柵）と砂利が少しだけ見える |
| 建物 | 本堂は大きく、屋根が画像の上端近くまで来る。建物の隙間や後ろには空と、境内の木立・遠くの街のビルが少し見える |

- **左右の端は建物を切らない**（木立・空き・塀の途中など。ここで次のパネルとつなぐ）
- 2枚目は1枚目を、3枚目は2枚目を参照画像に付けて、石畳・玉垣・空の色・光の向き・色味がそのままつながるようにする
