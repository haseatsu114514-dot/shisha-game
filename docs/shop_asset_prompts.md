# ショップ商品画像 生成プロンプト集（Codex用・N21）

Dr.fookah のショップ画面（`web/js/game.js` の商品サムネイル・N17）用。
**実際のシーシャフレーバー缶・機材の商品写真を少し模した見た目**にしたいので、
Codexに投げるときは**このテキストプロンプト＋手元の参考写真1枚**を一緒に渡す想定。
届いた画像は `assets/ui/shop/` に置いてビルドすれば、コード変更なしで
CSSアイコンから自動的に差し替わる（`hasShopAsset()` が拾う）。

## 保存先・ファイル名・サイズ

- フレーバー: `assets/ui/shop/flavor_<フレーバーID>.png`（例: `flavor_mint.png`。IDは `data/flavors.json` の `id`）
- 機材: `assets/ui/shop/equip_<機材ID>.png`（例: `equip_silicone_bowl.png`。IDは `data/equipment.json` の `id`）
- 512×512px 目安・正方形。背景は単色かシンプルなグラデーション（透過は必須ではない。
  ショップのカードが `object-fit: cover` するので、四隅が切れても中央の商品が主役なら問題ない）

## 共通スタイル指針（プロンプト冒頭に付ける）

```
スタイル: 商品写真（プロダクトフォト）。中央に商品を大きく配置し、単色または
ソフトなグラデーション背景（スタジオ撮影風）。柔らかい上からのライティングと
自然な陰影。写実的〜セミリアルで、ゲームの背景アート（2Dペインター調）より
質感を上げた「実物の缶・箱・機材」に見えるタッチ。
NG: ゲームUI要素（価格・在庫数・ボタン等）の焼き込み、watermark、余計な手や人物。
```

- パッケージ表面の**商品名・ロゴ・簡単なアイコン等の印字はOK**（むしろ実物っぽさのために推奨）。
  ただしゲームの数値UI（価格・g数・☆評価など）は絶対に焼き込まない＝それはHTML側が出す。
- 参考写真を送る場合は「この写真の質感・構図・光の当たり方を踏襲して、色とラベルだけ
  下記の情報に差し替えて」と一言添えると再現性が上がる。

## 1. フレーバー缶・箱（`flavor_<id>.png`）

### テンプレート

```
{共通スタイル指針}
商品: シーシャフレーバーの缶（または小箱）。ラベルに「{フレーバー名（短縮表記）}」の文字。
香りの系統は{カテゴリ日本語}系（{カテゴリ英語}）。缶の色調は{色ヒントHEX}を基調にした
配色でラベルをデザインする。缶の質感は艶あり金属 or マット紙箱（好きな方でよい）。
やや斜め上から見た角度、蓋が少しだけ見える立たせ方。
```

`data/flavors.json` から埋める項目:
- `{フレーバー名（短縮表記）}` = `short_name`（無ければ `name`）
- `{カテゴリ日本語}` = cooling→清涼 / fruit→フルーツ / sweet→甘い / spice→スパイス / floral→フローラル
- `{色ヒントHEX}` = `web/js/game.js` の `FLAVOR_COLORS`（個別指定があれば）または `CATEGORY_COLORS`
  （カテゴリの既定色。清涼=#7fd6c8・フルーツ=#e69a4e・甘い=#f0c26a・スパイス=#c98a5a・フローラル=#dd93c4）

### 記入済み例（そのまま使える）

**mint（AF ミント・清涼系）**
```
{共通スタイル指針}
商品: シーシャフレーバーの缶。ラベルに「AF MINT」の文字。清涼系の香り。
缶の色調はミントグリーン（#8fe3c0）を基調に、白と銀のアクセント。清涼感を出す
細かい氷や葉のワンポイント柄。艶ありアルミ缶。やや斜め上から見た角度。
```

**double_apple（AF ダブルアップル・フルーツ系）**
```
{共通スタイル指針}
商品: シーシャフレーバーの缶。ラベルに「DOUBLE APPLE」の文字。フルーツ系の香り、
赤リンゴと青リンゴのイラストを小さく配置。缶の色調は深い赤（#d96a6a）と黄緑の
ツートン。艶ありアルミ缶。やや斜め上から見た角度。
```

**blueberry（AF ブルーベリー・フルーツ系）**
```
{共通スタイル指針}
商品: シーシャフレーバーの缶。ラベルに「BLUEBERRY」の文字。フルーツ系の香り、
ブルーベリーの粒を小さくあしらう。缶の色調は青紫（#7d8df0）を基調に、白文字。
艶ありアルミ缶。やや斜め上から見た角度。
```

64種すべてに同じ要領で名前・カテゴリ・色を当てはめれば量産できる
（`data/flavors.json` を順番に読んで埋めるだけの機械的な作業）。

## 2. 機材（`equip_<id>.png`）

### テンプレート

```
{共通スタイル指針}
商品: シーシャ機材の{種別日本語}。「{機材名}」。{説明文の要約}。
素材感は{素材ヒント}。中央に商品単体を大きく、影を柔らかく落とす。
```

`data/equipment.json` の `type` ごとの種別日本語・素材ヒント:
- `bowl`（ボウル/ハガル）: 陶器・シリコン・素焼きなど、`description` の質感語を素材ヒントに使う
- `hms`（ヒートマネジメントシステム/風防リッド）: 金属製の穴あきドーム
- `charcoal`（炭）: 商品パッケージ（箱に炭が並んだ写真）でも、炭単体のクローズアップでもよい
- `pipe`（パイプ本体）: ガラス製の水パイプ全体像
- `homeware`（家シーシャ一式）: パイプ＋ホース＋トレイのセット構図

### 記入済み例

**ボウル4種（2026-07-19 改訂・オーナー支給の参考写真つき）**

オーナーから実物の参考写真が4枚届いている（1=シリコン/2=素焼き/3=エイティ→ゲーム内
「80beatハガル」/4=イランボウル）。Codexへは**下のブロック＋該当写真1枚**をセットで渡す。
写真は「同じデザインの商品」を描き起こすための見本であり、写真の丸コピーではなく
共通スタイル指針の商品写真（スタジオ背景）として整える。

```
スタイル: 商品写真（プロダクトフォト）。中央に商品を大きく配置し、単色または
ソフトなグラデーション背景（スタジオ撮影風）。柔らかい上からのライティングと
自然な陰影。写実的〜セミリアルで、ゲームの背景アート（2Dペインター調）より
質感を上げた「実物の缶・箱・機材」に見えるタッチ。
NG: ゲームUI要素（価格・在庫数・ボタン等）の焼き込み、watermark、余計な手や人物。

共通仕様（4枚とも）: 512×512pxの正方形。1枚につきボウル1個だけを中央に大きく
（パイプ本体・炭・トング・手は写さない）。やや斜め上から見下ろし、カップの中が
少し見える角度。添付の参考写真と同じ形・同じ素材感・同じ色に忠実に描き起こし、
背景だけはスタジオ風の単色/ソフトグラデーションに差し替える。文字・ロゴ・数字は
一切入れない（ボウル本体に印字は無い）。影は真下に柔らかく落とす。

--- 1/4: equip_silicone_bowl.png（シリコンボウル・参考写真1枚目）---
マットな黒のシリコン製ボウル（ハガル）。肉厚で柔らかそうなシリコンの質感、
つや消しの黒一色。深いカップ→くびれ→裾広がりの台座のシルエット。カップ中央の
通気穴は写真どおりに。

--- 2/4: equip_suyaki_hagal.png（素焼きハガル・参考写真2枚目）---
テラコッタ色の素焼き陶器ボウル。リム外周をぐるりと囲む手彫りの刻み模様、
カップ内側の底に通気穴が数個見える。釉薬なしのざらっとした土の質感、焼きムラの
オレンジ〜薄茶。

--- 3/4: equip_hagal_80beat.png（80beatハガル・参考写真3枚目）---
ファンネル型（カップ中央に煙突状のスパイアが1本立つ）の陶器ハガル。上部の皿は
黒〜ダークグレーのマット釉薬、胴は生成り／クリーム色の陶土で、上から濃茶の釉薬が
少し垂れた景色。太い円筒の胴と裾広がりの台座。商品名の印字はしない。

--- 4/4: equip_iran_bowl.png（イランボウル・参考写真4枚目）---
イラン伝統の彩色陶器ボウル。コバルトブルー×ターコイズ×白×赤で花とペイズリーの
文様がエナメルの盛り上げ彩色で全面に施され、リムの上端だけ素焼きの土色が残る。
写真の木テーブル・店内背景は使わず、スタジオ背景に差し替える。
```

> ⚠️ `iran_bowl` は現状 `data/equipment.json` に無い（未実装機材）。画像だけ先行で
> `assets/ui/shop/equip_iran_bowl.png` に置いても表示先が無いため、ショップに並べる
> 場合は機材追加（価格・容量・ボウル種マッピング）のオーナー裁定が必要。

**flat_charcoal（フラット炭）**
```
{共通スタイル指針}
商品: シーシャ用炭のパッケージ。「フラット炭」。円盤型の炭が並んだ商品写真。
素材感は黒い炭に白い灰の質感。紙箱パッケージ、シンプルなロゴ。
```

## 組み込み手順（画像を受け取ったら）

```bash
# assets/ui/shop/flavor_<id>.png もしくは equip_<id>.png に配置
python3 web/build_data.py         # D.shop_assets に一覧を焼き込む
python3 web/build_standalone.py   # 配布版にも埋め込む
```

ショップ画面を開いて、対象の商品行・詳細パネルの画像が差し替わっていることを確認する。
