# 画像生成ガイド（コピペ用の指示例つき）

ChatGPT等で画像を作る → `tools/pixelize.py` に通す → ゲームに入る、までの手順書。

## 大原則

- **透過はAIに頼まない**。背景は単色マゼンタ（#FF00FF）で塗ってもらい、
  透過処理はスクリプトで確実にやる（緑は服や植物と被るのでマゼンタ推奨）
- **ドットの粗さもAIに頼まない**。普通の画質で生成して、スクリプトが
  全画像を同じ粒度・同じ色数に揃える
- **表情差分は1枚のシートで一度に生成する**。別々に生成すると顔が変わるため、
  同じ生成の中に5表情を並べてもらえば同一人物性が保たれる

## キャラ立ち絵の作り方（2ステップ）

### ① マスター1枚を作る（コピペ用）

```
ゲームの立ち絵用キャラクターイラストを1枚。
【キャラ】22歳の日本人青年。黒髪の無造作ショートヘア、焦げ茶の目、
中肉中背。白Tシャツの上にグレーのカーディガン、黒のスキニーパンツ、黒スニーカー。
穏やかで人当たりのいい、感じのいい普通の青年の雰囲気。
【構図】全身、正面やや斜め、直立。
【画風】レトロJRPG風のアニメ調ピクセルアート。輪郭は濃くはっきり。
【背景】完全な単色マゼンタ(#FF00FF)。キャラの影や光を背景に落とさないこと。
画面に文字・ロゴ・フレームを入れないこと。
```

気に入るまでここで粘る。**マスターが決まったらそれが「正」**。

### ② マスター画像を添付して表情シートを作る（コピペ用）

```
添付画像とまったく同一の人物・画風・服装・頭身で、表情だけを変えた
バストアップを 横3×縦2 のグリッドで1枚の画像にまとめてください。
【表情の順番】左上から → ①普通(normal) ②笑顔(smile) ③悲しい(sad)
④真剣(serious) ⑤驚き(surprise) ⑥は①と同じでよい
【条件】各マスで顔の位置と大きさを揃える。マスの区切り線は入れない。
背景は全マス単色マゼンタ(#FF00FF)。文字を入れない。
```

### ③ 変換コマンド（Claudeに頼めばやってくれる）

```bash
# マスター（全身1枚）
python3 tools/pixelize.py master.png --char hajime
# 表情シート（3x2を5表情に分割して所定フォルダへ）
python3 tools/pixelize.py sheet.png --char hajime --slice 3x2 \
    --names normal,smile,sad,serious,surprise
```

新スレッドでは「この画像をはじめの表情シートとして取り込んで」と
画像を添付するだけでOK（コマンドはClaudeが実行する）。

## 背景の作り方（コピペ用）

背景は透過不要なのでマゼンタも不要。サイズと「文字を入れない」だけ守る。

```
レトロアドベンチャーゲームの背景一枚絵。横長16:9。
【場面】夜のシーシャカフェ「tonari」の店内。木のカウンター、棚に並ぶボトル、
ゆっくり回る天井ファン、オレンジの間接照明、うっすら漂う紫煙。人物なし。
【画風】アニメ調ピクセルアート、落ち着いた配色。
画面に文字・ロゴ・透かしを入れないこと。
```

```bash
python3 tools/pixelize.py bg.png --key none --grid 360 \
    --out assets/backgrounds/bg_tonari_inside.png
```

## よくある失敗と対処

| 症状 | 対処 |
|---|---|
| 輪郭にマゼンタのフチが残る | スクリプトが自動で除去する（アンミックス＋2px侵食）。残ったら `--tolerance 90` を試す |
| キャラの影が背景に落ちて穴が開く | プロンプトに「影を背景に落とさない」を必ず入れる。それでもダメなら影なし指定 |
| 表情ごとに顔が変わる | 必ず①のマスターを**添付**して②を依頼。文章だけで再現させない |
| ドットの粒が画像ごとにバラバラ | 気にしない。`--grid` が同じなら出力は自動で揃う |
| マスに区切り線や文字が入る | プロンプト末尾の禁止指定を残す。入ったら該当マスだけ `skip` で除外して作り直し |

## 命名規約（これだけ守れば自動で組み込まれる）

- 立ち絵: `assets/sprites/characters/{id}/chr_{id}_{face}.png`
  - face: `normal / smile / sad / serious / surprise` ほか
- 背景: `assets/backgrounds/bg_{場所}_{時間帯}.png`（例: `bg_tonari_inside.png`）
- CG: `assets/cgs/cg_ch1_{イベント名}.png`

取り込み後は `python3 web/build_data.py && python3 web/build_standalone.py` で反映
（立ち絵の余白計測・表示正規化も自動で行われる）。
