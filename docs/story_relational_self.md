# 空・縁起・分人の場面と接続

物語の正本は [story_and_structure.md](../brand/story_and_structure.md)。改稿前の筋を併記せず、現在の実装状態と場面の役割をここで管理する。

## 実装済みと台本

第1・2章は `remake/` に接続済み。取材や交流で実際に読んだ場面は `data/relationship_memories.json` に記録される。第2章は、なるへの返答と応援を頼む／断る選択を追加。味の不調はDAY5から、翌日の受診へ。結果画面の祝福と本人の返しづらさを分ける。

第3〜5章とエンディングは未接続。再生順は `data/story_routes.json`。`remake/js/core/story-routes.js` は恋人・所在・約束を受け取る純粋な選択関数で、将来の章runner向け。今のゲームのマップや渡航・告白・再挑戦機能は増えていない。未読の締めくくりを、数値だけから完了したことにしない。

## 主題を担う行動

| 見方 | 場面 | プレイヤーに見える変化 |
|---|---|---|
| 空 | ダブルアップル事件から日々の一杯 | 分かったふりをやめ、作らない日にも座る |
| 縁起 | 全国の三人との練習、世界の同時制作 | 息を吐く、計測する、炭を離す、待つ。借りた手つきの相手を忘れない |
| 分人 | REIの交流、みんとの告白、あげはとの再会 | 舞台と人見知り、店と家、元気と静かな日を本物／偽物に分けない |
| 分人 | 第5章二本目 | 大会用の説明口調から、客に希望を聞く接客の声へ |
| 縁起 | 博士の研究の続き | 9000にも設計者・職人・店の仕事がある。次の記録で変わる |

スミさんに直接繋がる過去の謎は南雲とシェイクの二本。エミルは南雲と仕事仲間、王煙楼はシェイクの技術の師、REIのタトゥーはライブの客のデザイン。ムカイとは現在の協力店、ひよりは元アルバイトという生活上の関係で、偉大な技の起源をスミさんへ戻す伏線にはしない。

## 交流の記憶

回想は実際に読んだ記憶だけを使う。未交流なら共通の日常場面で成立する。記憶数、恋人数、好感度を大会加点へ変えない。安心が効く時も「安心したので勝利」ではなく、呼吸と観察が変わり、操作の判断へ続く。

繰り返し会話では毎回の格言と解説を避け、仕事の失敗、片付け、買い物、小さな言い争いなどを扱う。休むことも関係の一部。つむぎを主人公に心を与えられて救われる人にはしない。

## 検証

`python3 tools/check_story_canon.py` で台本・正本・旧稿の混線を検査する。`node remake/test/story_routes.mjs` で七人分、恋人なし／一人／複数、所在・約束・未解決の関係を確認する。第1・2章の接続は該当章のテストで確認し、台本の検査を後半のプレイテストと呼ばない。
