## 物語の中心テーマ（確定・main反映済み）

### 空・縁起・分人主義 —「混ざったままで、俺だった」

- **旧案からの転換**：「誰にも染まらない独自の核（オリジナル）を見つけなければ空っぽだ」という設定は**不採用**。
- **現行の正本テーマ（2026-09-30 / 2026-10-18 確定）**：
  - 人は最初から固定された「本当の自分」を1つ持っているわけではなく、出会った相手や場所、教わった技、休んだ時間や日常の積み重ねによってそのつど立ち上がる（**空・縁起・分人主義**）。
  - はじめの武器は「何でも屋」「誰かの真似」と揶揄されることもあるが、スミの教え、なるの情熱、アダムの火加減、神崎の安全な所作、ましろとの日常、客との会話が混ざり合ったその手つきこそが、すでに「はじめ自身の煙」である。
  - 第1章・第2章では「採点表の数字」と「目の前の客の顔」の間で揺れ、第3章東京で味覚を失いかけたとき、超人的な「利き煙」ではなく**休養・食事・皿洗い・お茶という生活の手順**と**「相手の一口を待つ」接客の基本**から立ち直る。

## 日常パート（1日の流れ）と行動システム（確定・main反映済み）

1日は **昼（Day）→ 夜営業（Work）→ 夜（Night）→ 就寝前（Bedtime）** の4フェーズで進行します。

1. **昼フェーズ（自由行動 1回）**
   - 街マップから行き先を1つ選ぶ（他店訪問・お出かけ・練習など）。
   - **0行動（時間を消費しない）スポット**：
     - **Dr.fookah（1階ショップ）**：フレーバー・機材の購入、1,000円ガチャ（アルファーヘブンくじ）。昼・夜いつでも時間消費なしで立ち寄れる。
     - **C.STATION**：大会エントリー、試煙会（第1章DAY3等）、ランキング確認。
     - **路上占い師**（第1章・第2章の特定日：DAY3 / 6 / 10 / 13）：1回3,000円でヒロインとの相性占い（時間消費なし）。
2. **夕方〜夜：tonari（第3章は mukai）での営業（バイト）**
   - 来店する常連客やヒロイン・ライバルのオーダーに合わせてシーシャを提供し、売上（所持金）とステータス・好感度を得る。
   - 主人公の**【魅力】**ステータスに応じて**指名売上ボーナス**（★1〜5で `0 / +500 / +1,200 / +2,000 / +3,000円`）が加算される。
3. **夜フェーズ（自由行動 1回）**
   - 夜の街へ出かける（コンセプトカフェ「ぺぱーみんと」、Dr.fookah 2階の匂坂凛デスク、斧投げBar、ボドゲカフェ夜TRPGバー、夜カフェ等）。
   - **家シーシャ（夜の行動後・就寝前、1日1回・葉12g・体力24消費）**：
     - 卓上台（`ミャア 卓上台`）は、第1章DAY2以降の帰宅前にスミから一度だけ受け取る。既所持・受取済みには重ねて渡さず、受け取った夜は試すか休むかを選べる。
     - 寝る前に体力と葉が足りるときだけ、その場で実施するか寝るかを選ぶ。大会前夜・体力が赤くなる場合は行わない。
     - 実施すると**葉12g・体力24を消費し、熟練度の合計経験値6（大会公式モデルは7.5）を配合比率で配分**する。**ステータス・能力経験値は一切増えず、レシピ発見時のセンス加算もない。**中止は無消費で、同じ夜の二重実行・再読込による再付与は行わない。
4. **就寝前フェーズ（LIME返信）**
   - その日に交流した相手や条件を満たした相手からLIMEが届き、3択で返信して好感度や約束が進行する。

## シーシャ作り（クラフト）と大会の要点（確定・main反映済み）

### クラフトの基本工程
1. **フレーバー選択・グラム配分（パッキング）**
   - ボウル容量（シリコン12g / 80beat 15g / 素焼き20g）に合わせて最大3種類まで配合。
   - **1g刻み**（微調整は±1g / ±5g）。ボウル容量の **±1g以内** で詰めると「ぴったりボーナス」（煙量+15%）。
   - 2種類以上混ぜた場合は**混ぜ方（ミックス / レイヤー / セパレート）**を選択できる。
2. **水入れ（ボトルの準備）**
   - **開始水量は 0（空の状態）からスタート**（#1081 E01）。ステム先端が水中に**約2〜3cm**浸かる適正ラインまで水を注ぐ。
   - **スミの水の説明（#1113 / #1128）**：ボトルの水の役割は**「煙を冷やして吸いやすくする」だけ**。ニコチンやタールなど有害物質への影響については**「諸説ある」とし、断定しない**。また、煙が濃く出る（爆煙）理由は水ではなく**「グリセリンと熱の仕事」**（K14）。
3. **炭の選択・配置（チャコール）**
   - フラット炭（初期）またはキューブ炭（炭の使い分け講習後に解放）、個数（2〜4個）を選択。
4. **蒸らし（キッチンタイマー実時間計測）**
   - 数値入力ではなく、画面上の**キッチンタイマーをスタートして実時間で止めたい秒数でストップ**する方式（#541 / E17）。
   - ゲーム内1秒＝1分換算（上限10分、通常5〜8分。神崎竜二のイベント後は「0分立ち上げ」の知見も登場）。
5. **吸い出し・温度帯の表現・途中調整（最大2回）**
   - 立ち上げ後、最大**2回**まで炭の個数やHMDの開閉で熱を調整できる。
   - 制作画面には**温度計（実温度・最適温・停止予測）を表示**し、**配合中は適温帯の合成横ゲージと文字の帯端点を常時表示**する。**ボウル周辺の陽炎・炭の赤熱・煙の立ち方・音・香りテキスト**などの感覚的な温度描写は、地の文・内心の演出として使う。

### 大会採点（5工程各20%＋別枠の加点・投票）
- ベーススコアは**穴・炭・完成品・調整1回目・調整2回目の5工程を各20%で集計**し、**準備加点と物語の10点投票が別枠で加わる**。
- **旧プレゼン比重は廃止済み**で、「提供演出」は現行の配点項目ではない。調整2回の実績は別々に保持し、両方を結果表へ表示する。
- **第1章の南雲特別ルール**：南雲修二は持ち点10点を**「基準（内部スコア84点以上）を満たした1人に一括投入する（該当者なしなら0点）」**という特別採点を行う。
