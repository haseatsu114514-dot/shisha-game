## シーシャ経験者に聞きたいこと（監修ポイント）

このゲームはシーシャの文化描写のリアリティを大事にしています。
実際に作ったことがある人・店によく行く人の感覚で、以下をチェックしてもらえると助かります。

### 現在のゲーム内ルール（考証の前提）

1. **葉**: 主人公が使うのはブロンドリーフのみ。ダーク／シガーリーフは用語と他キャラの演出専用
   （「普通の葉で世界一になる」が本作の背骨）
2. **蒸らし**: 0／3／5／8／10分の選択制。基本は5〜8分。0分（吸いながら立ち上げる）は
   ある人物との交友で解放される例外的な高等テク。2分は採用しない
3. **炭の配置**: 基本はトライアングル（三角配置）
4. **吸い出し**: 炭を置いて蒸らした後、提供前に何度か吸って温度を立ち上げる。
   最低2回・3回までは無傷、それ以上は葉が痩せる。やめ時は自分で選ぶ
5. **詰める量**: 基本12g。ボウルの容量までは増やせる（素焼き・大型は15〜20g）。
   多く詰むほど味の劣化は遅いが、必要な熱と葉代が増える
6. **接客**: ミントが苦手な客は自分から「ミント抜きで」と言う。毎回口頭確認はしない
   （常連の好みは店が覚えている）。「お任せで」は普通にある注文
7. **お金**: 日本のシーシャ屋にチップ文化はない。臨時収入は売上ボーナスやまかないで表現

### 聞きたいこと

- 上の1〜7、**実際の感覚とズレているところはある？**（特に蒸らし時間・吸い出し回数・詰め量）
- 大会課題の「ストロベリーは甘さの輪郭が見えにくい高難度フレーバー」という設定は納得感がある？
- 「シーシャ職人がダブルアップルの味が分からない＝ラーメン屋が醤油が分からないくらいの絶望」
  という例えは、経験者的に伝わる？
- **「現役だけがわかるディテール」の実体験募集**: 各章に1つずつ、作り手が体で知っている一行を
  入れる枠があります（例: 蒸らし中の沈黙が会話の「間」になる／炭替えで話が一度切れて戻ってくる／
  閉店後に自分用の一台を作る背中／「今日の炭は乗りが悪い」という独り言）。
  あなたの「あるある」をぜひください
