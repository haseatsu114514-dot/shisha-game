# ストーリー編 — 『水煙前線 -EN:CODE-』全5章

⚠️ 最終章までのネタバレ全開の制作資料です。

## 作品概要

- **タイトル**: 水煙前線 -EN:CODE-
- **ジャンル**: シーシャ屋アドベンチャー＆育成シミュレーション（ブラウザゲーム・一人称視点）
- **主人公**: シーシャ屋「tonari」のバイト青年・**蒸野 始（むしの はじめ）**
- **物語の骨格**: 地元大会 → 県大会 → 全国大会 → 世界大会 → そしてAIとの最終決戦。
  勝ち上がりの階段を、**主人公の「慢心 → 転落 → 回復」**の心情アークに重ねる
- **テーマ**: **「素直さ」**＝他人の良さに素直に気づける力。それは嫉妬にもなるが、吸収と継承の源でもある
- **タイトルの意味**: 「-EN:CODE-」の意味は第5章まで作中で明かさない。
  **煙を作る＝生き方のエンコード、吸う＝デコード**。それまでは大会ロゴ等の意匠としてのみ見せる

### ゲームの流れ（ざっくり）

各章は「準備期間（14日間など）＋大会当日」で構成。準備期間はバイト・修行・キャラ訪問で
5つのステータス（技術・センス・根性・魅力・洞察。画面上は★1〜5と抽象表現のみで数値は見せない）と
好感度を育て、大会当日は配合 → 蒸らし → 吸い出し → 調整 → 審査（FLAVOR TRIAL）の
ミニゲーム連続で一台を作り上げる。

## 大会システム（全章共通）

- **4人一斉対決形式**。4人が同時にシーシャを作り、審査員が評価する
- **1位のみが次の大会へ進出**。2位以下はその場で敗退（プレイヤーはGAME OVER。敗者復活戦はない）
- **審査員持ち点投入制**: 各審査員は持ち点10を、大会中の好きなタイミングで任意の選手に投入できる。
  一度入れた点は戻せない。早入れは「目利きの自信」の賭けであり、誰がいつ入れたかが実況されてドラマになる
- 審査員長・南雲は**最後まで持ち点を温存**し、「もう一口吸いたい一台」にだけ最終発表で一括投入する流儀
- **FLAVOR TRIAL（審査パート）**: 提供後、コンセプト（制作前の方針）と、制作結果から生成された
  アピールポイント（実績）を審査員のザワザワに「ぶつける」ことで、
  「言ったことと作ったものの一致」を証明する
- **章ごとの課題フレーバー（レギュレーション）**:

| 章 | 大会 | 課題 | 狙い |
|---|---|---|---|
| 1 | SMOKE CROWN CUP（地元） | ミント2g以上 | 入門の定番で基礎勝負 |
| 2 | HAZE: OPEN CLOUD（県） | ストロベリー指定（県特産タイアップ） | 輪郭の見えにくい高難度。味覚スランプ中のはじめに最も残酷な課題 |
| 3 | HAZE: NATIONAL TOKYO（全国） | 自由（ましろとの作戦会議で軸を選ぶ） | 「自分のシーシャとは何か」を問う |
| 4 | HAZE: GRAND SMOKE（世界・ドバイ） | 自由＋日本アピール（**和風一本**） | 日本代表として、和素材の一台で世界へ |
| 5 | SMOKE LAB（AI戦・非公式） | **ダブルアップル単体・配合自由度ゼロ** | 王道でAIと同じ土俵。純粋技術＋ch3の贖罪の回収 |

# 第1章 一吸目（ファーストドロー）— SMOKE CROWN CUP編

**テーマ: 「僕には何もない」／始まりは「なんとなく」でいい**

ゲームは開幕30秒、**ch4ドバイ決勝の瞬間**（歓声と煙だけ。顔は見せない）から始まり、
「──1年前。」でtonariの日常へ巻き戻る。

バイト歴3ヶ月のはじめに、店主のスミさんが地元大会SMOKE CROWN CUPへの出場を勧める。
理由はひとこと、**「お前の煙は優しい。それだけでいい」**。褒められた気がしないまま、
はじめはよく分からず出場を決める。

偵察を兼ねた交流で出会うのが、地元最強格の好敵手**なる**（教え惜しみをしない人格者）、
ダブルアップル一筋の変人**アダム**、コンカフェ「ぺぱーみんと」の人気キャスト**みんと**。
みんな「自分のシーシャ」を持っている。はじめには、何もない。
tonariの常連**つむぎ**だけが、はじめの煙の小さな変化に誰より敏感に気づいている
（「……今日の煙、いつもと色が違う」）。

大会当日。会場は大手チェーンC.STATIONの超大型旗艦店。華やかな技術も哲学もないはじめは、
バイトで毎日やってきた丁寧な仕事をそのまま出す。技術点・個性点は下位。
だが最終発表、審査員長**南雲**だけが確信を持って持ち点を一括投入し、僅差の逆転優勝。
なぜ勝てたのかは、本人にも分からない。

**優勝の夜に、転落の種が全部まかれる**:

- つむぎ「最後の方だけ、ちょっとだけ──**濁ってた**」（共感覚の初警告）
- スミさんのLIME: 開示された採点表を突きつける。「お前を勝たせたのは南雲さんの総合印象点ひとつ。
  **『実力で勝った』とは思うな**」
- 未知の送信者「？？？」から:「本日のあなたの試合データは、すべて記録させていただきました」
- 南雲がすれ違いざまに「……**懐かしい味だ**」とだけ言って去る（最終盤まで引っ張る縦糸）
- 観客席の隅にノートPCの白衣の男（後のチャコール博士）

それでも、承認の快感を覚えたはじめの「薄さ」は静かに加速していく。

このほか第1章には、後の章の顔見せカメオが仕込まれている:
謎のギャル（＝アゲハ）、正体を伏せたV系の客（＝零-REI-）、
「葉巻の葉っぱで化け物みたいな煙を出す」という都市伝説**シガーマン**の噂、
そして私服で来店する「お姉さん」（＝みんとの素の姿。訪問イベントを進めると章内で正体判明）。

# 第2章 才能の壁（ジェラシー・ヘイズ）— 県大会編

**テーマ: 他人の武器を「ずるい」と思ったとき、素直さを失う。妬みは煙に出る**

県大会HAZE: OPEN CLOUDの出場者リストに愕然とする。元極道の丁寧すぎる職人**神崎竜二**、
V系カリスマ**零-REI-**、そしてバイブスだけで最高の一杯を作る天才ギャル**アゲハ**。
街の工業地区の店「鉄の煙」では、ロシア人の精密職人**ヴォルク**の完璧な仕事も間近に見る
（彼が選手として立ちはだかるのは全国大会から）。

全員のシーシャを「すごい」と素直に思えていたはじめが、初めて**比較**を始める。
「ずるい」。妬みが煙を窮屈にし、バイトでもミスが続き、ついに客席へ真っ赤な炭を落とす。
そして──**自分の作ったシーシャの味が、分からなくなる**（味覚スランプの始まり）。

アゲハが「あんたの煙吸ってると、なんか安心するんだよね」と励ましてくれるが、
それは処方箋ではなく鎮痛剤だった。**味覚は戻らないまま**、はじめは筋肉の記憶と
借り物の理論で勝ち続ける道を選んでしまう。

すると今度は、仲間が一人ずつ静かに離れていく。誰も怒鳴らないのが一番怖い:

- なる「今日のお前のシーシャ、俺は好きじゃない。全部入ってて、**お前がどこにもいない**」
- アダム「……俺の宇宙、いる？」
- みんと（完璧な営業スマイルのまま）「勝つことだけが正解じゃないって、いつ気づくの？」
- アゲハ（決勝前夜のLIME）「ごめん、明日行けない。理由は聞かないで」
- つむぎ「……**色が、見えないんです**。はじめさんの煙」

決勝の煙は自分史上もっとも綺麗にまとまり、はじめは県の頂点に立つ。
だが観客席に知った顔はなく、スマホの通知は0件。祝勝の一服を自分で作って吸う。**味は、しない。**
味のしない舌と静かすぎるトロフィーだけを持って、はじめは東京へ向かう。

# 第3章 虚ろな王冠（ホロウ・クラウン）— 全国大会編

**テーマ: 技術が上がっても「自分のスタイル」がないのは普通。空っぽは弱さじゃない**

全国大会HAZE: NATIONAL TOKYO。伝統のスパイス使い**ナンディ**、繊細な巨漢**スティーブ**、
精密機械の**ヴォルク**、そして県大会から続く因縁の**零-REI-**。世界の広さに圧倒されるはじめを、
スミさんは姉妹店「mukai」の**ムカイさん**に預ける。そこで出会うのが、
おっとりダウナーな同僚バイト**ましろ**──巷で噂の凄腕職人「シガーマン」の正体（本人は無自覚）。

**ダブルアップル事件（本作のハイライト）**: ある夜、ましろが無言で一台差し出す。
「はい。──ダブルアップル」。吸っても、林檎の輪郭がどこにもない。
言えるわけがない。県大会覇者がダブルアップルが分からないなんて。だから話を合わせた。
「懐かしい味。皮の苦みが、奥にちゃんとあって」──

ましろは静かに言う。「──これ、**シトラスミント**。ダブルアップル、一粒も入ってないよ」

なるは正面から叩いた。みんとは笑顔で刺した。スミさんは問いを投げた。
**ましろだけが、問わない**。「私、何も聞かない。ただ毎日、一杯作る。はじめくんは、毎日それを吸う」。
はじめはここで初めて泣く。負けて泣くのではなく、**許されて泣く**。

以後、ましろの「毎日の一杯」で舌の地図を引き直す日々。味ではなく温度から、香りではなく煙の重さから。
何十杯目かの夜、舌の奥で何かが灯る。「──林檎だ。林檎です、これ」。ましろの返事は三文字、「──おかえり」。

大会は、別ブロックのなるがレイに僅差で敗れ、はじめは優勝する。だが表彰式の夜、ホテルで一人思う。
*勝った。でも、僕の「これ」は、どこにあるんだ？*──答えは大会の外にあった。
tonariに戻ると後輩ができ、教えることで自分の中に「方法論」が積み上がっていたことに初めて気づく。
酸っぱい顔の客に、自然といつもと違う一台を出す。「なんか、ちょうどこういうのが吸いたかった」。
*──これだ。これが、僕のシーシャだ。*

なるからの連絡で章が締まる。「HAZE: GRAND SMOKE、一緒に行くぞ。お前は……お前の答え、見つけに行けよ」

※恋愛ルート（付き合う／友達のまま）は全ヒロインこの章までに着地する。

# 第4章 継承の煙（レガシー・スモーク）— ドバイ編

**テーマ: 全部背負って、最後に出す一台。交わらないから面白い**

世界大会HAZE: GRAND SMOKEへ。出発前、スミさんが初めて自分からカウンターの向こう側に来て、
何夜にもわたる特訓をつける。ただの店長とは思えない精度。「……長くやってりゃ、な」。

ドバイでは、カラフルなシーシャバー「FESTA」の**ダ・シルヴァ太陽**に、ショーの見せ方と
楽しむ原点を教わる（→実は審査員、というミスディレクション）。
そして路地裏のカフェで3度出会う「謎のおじさん」。大会当日、彼こそが決勝の相手、
ドバイの絶対王者**シェイク・アル=ガリヤーン**だと明かされる。
15年前、同じ路地裏のカフェで無名の日本人の煙に出会ったのが彼の原体験──**師弟の系譜が、同じ場所で円環する**。

決勝は**4人一斉の最終決戦**──はじめ・なる・王煙楼・シェイク。はじめが出すのは「和の一台」ひとつ。

**vs なる（ゲーム最大の感動パート）**: 敗北のたびに地元大会からイチで勝ち直してきた男が、
はじめの全試合データを分析して最高傑作をぶつけてくる。はじめの一台は、旅で出会った全員の技を
誰も予想しなかった「和」の器に束ねたもの。僅差で前に出る。
なるの返事は「…最高のシーシャだったよ。優勝、絶対勝ち取れよ」。

**vs 王煙楼（アジアの壁）**: 陰陽五行の理で審査員一人ひとりに合わせ切る「薬のような煙」と、
龍のようにうねる伝説の技。「目の前の人に合わせる」というはじめの武器の完成形が、
五十年先を歩いてそこにいた。はじめは合わせにいかず、「間」と「余白」で吸い手のほうから
歩み寄ってくるのを待つ煙を貫き、僅差で前に出る（この「究極に合わせる煙」は、
ch5のAIによる最適化の人間側の予告編でもある）。

**vs シェイク（最終盤）**: 純金機材の完璧な一台に対し、はじめが出すのは**日本の一台**。
抹茶の苦み、柚子の立ち上がり、ほうじ茶の余韻──派手さの代わりに「間」と「余白」で組んだ、
tonariの丁寧さそのままの和の煙。南雲の「……悪くない」で最高評価、**はじめ、世界一に。**

優勝後、シェイクの屋敷で明かされる。15年前の路地裏の日本人店員の名は──**墨田丈一郎**。
帰国後、スミさんが初めて過去を語る。「負けたから折れたんじゃない。
**勝つための煙ばっかり作ってるうちに、客の顔が見えなくなった**」──東京のはじめの、完全な鏡像。

章の最後は打ち上げ（恋人が複数いると修羅場イベント発生）と、スミさんとの無言の一杯。
帰り道、はじめは自分の上着にtonariの匂いが染みついていることに気づく。
*（店、持ちたいな。……今度は、ちゃんと言える気がする）*

# 第5章 機械仕掛けの神（Deus Ex Machina）— SHISHA-9000戦

**テーマ: 「AIにシーシャは代替されるのか」──タイトル「-EN:CODE-」の回収章**

世界一となったはじめに、審査員**チャコール博士**から研究所SMOKE LABへの招待状が届く。
待っていたのは究極のAIシーシャマシン**SHISHA-9000**──過去の全大会データと、
**はじめの全試合データ**を学習済み。課題はダブルアップル単体、配合自由度ゼロの技術勝負。
この章だけ採点UIを一切出さない。勝敗は観客の「もう一回吸いたいのはどっち？」の挙手のみ。

9000の煙は完璧で、しかも「優しい」。はじめの武器を完全に再現し、
観客の咳にすら人間より速く適応する。*（じゃあ……何が残るんだ。僕らには、何が）*

絶望しかけたはじめは、観客席にあの**酸っぱい顔の客**（ch3）を見つける。
最後の一台で「誰にでも優しい最適解」を捨て、あの人の今日の顔だけに向けた、
外したら立ち直れないくらい尖った一台を差し出す。挙手は僅差で、はじめ。

> 客「あっちの煙は、うまかった。──こっちの煙は、**俺に話しかけてきた**」

ここでタイトルが回収される。**シーシャとは、作る人の生き方を煙にエンコードするもの。
吸うことは、それをデコードすること。** 9000の煙は何万人のエンコードの平均であって、
誰の生き方でもない。コードはあるのに、誰もエンコードしていない。宛先がない。

敗北を認めた博士は眼鏡を外す──廊下の古い大会写真の、若き選手の顔。
彼もまた、自分の一台を全否定されて**味覚を失った元職人**だった（はじめのch2の鏡像）。
はじめは9000を壊さず、博士に「一台だけ、一緒に作りませんか。データなしで。──宛先は、僕で」と誘う。
十数年ぶりに自分の舌で作った不完全な一台を、はじめはゆっくり吸って笑う。
「……うまいです。博士の煙、ちょっとせっかちだ。──博士っぽい」。博士は声を出さずに泣く。

9000は破壊されず、名職人たちの煙を学ぶ「世界一の教材」として稼働を続ける。
最終稼働ログ: `re: encode — sender not found. learning.`

**ラストシーン**: tonariの変わらない日常。常連のサラリーマンが「今日の新人さんのシーシャ、凄かったよ」と、
はじめを抜き去る新人を絶賛する。世界王者は完敗だと笑う。「人の好みはそれぞれ。だからシーシャは面白い」。
（The End）

## 全編を貫く縦糸（伏線メモ）

| 縦糸 | 流れ |
|---|---|
| **店の匂い** | 「店を持つとは、匂いを背負うこと」。なるの潰れた実家喫茶店 → みんとの精肉店の幻臭 → ch2で焦げ跡の匂いを店に刻む → ch4ラスト、自分の上着に染みたtonariの匂いに気づく。各章に一度だけ、説明せずに置く |
| **「顔」（誰のために作るか）** | ch1決勝でサラリーマンの顔がよぎる → ch2「誰の顔も、浮かばなかった」→ スミさんのLIME「誰のために作ってる？」→ ch4告白「客の顔が見えなくなった」→ ch5宛先のある一台で完結 |
| **継承の対句** | ch1スミ「技は盗め。ただし、誰から盗んだかは忘れるな」→ ch2なる「盗むのと、借り物で着飾るのは違う」→ ch5のDA単体勝負（誰から始まった味かを忘れない） |
| **つむぎの煙の色** | 淡いオレンジ（基調）→ 濁り（慢心）→ 灰色・透明（自分の喪失）→ オレンジ回復。浮気時は「知らない色」、バッドエンドは無色（ホワイトアウト） |
| **南雲の「懐かしい味」** | ch1の謎の一言 → 正体はスミさんの系譜への反応。スミさんと南雲は真逆の道を選んだ旧知のライバル |
| **シガーマンの噂** | ch1都市伝説 → ch2組長ルート → ch3で正体（ましろ）へ段階的に接近 |

## エンディング分岐

- ヒロイン好感度は5段階。MAXで「付き合う」か「友達のまま」の選択が出る
- 恋人が2人以上だと打ち上げで**修羅場イベント**。さらに「うしろめたさ」の蓄積によっては
  特殊バッドエンド**「ホワイトアウト」**（全員に同時にバレる夜。誰も叫ばず、煙が無色になる）
- 一途ルートは浮気システムが一切作動しない。誠実プレイが一番気持ちいい設計
- クリア後はヒロイン個別エンド、またはtonariの日常へ
