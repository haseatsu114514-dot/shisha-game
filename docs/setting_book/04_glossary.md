## 作中シーシャ基本用語・機材（確定・main反映済み）

### パイプ・本体構造
| 用語 | 作中での説明・役割 |
|---|---|
| **シーシャ（水タバコ / フーカー）** | ボウル（ハガル）に詰めたフレーバーを炭の熱で温め、発生した煙をステムからボトルの水にくぐらせて冷やし、ホースから吸う嗜好品。 |
| **ハガル（ボウル / トップ）** | フレーバー（葉）を詰める皿。材質や形状によって容量・熱伝導率・適したフレーバーが変わる。 |
| **シリコンボウル** | 初期装備（容量 **12g**）。割れにくく熱が穏やかに伝わる初心者向けのボウル。 |
| **80beatハガル（エイティビート）** | 専門店「Dr.fookah」で購入できる陶器製ファンネルボウル（容量 **15g** / 8,000円）。熱回りが良く味が濃く出る中級者向け。 |
| **素焼きハガル（クレイトップ）** | 無釉薬の土製ボウル（容量 **20g** / 3,000円）。熱をしっかり蓄え、吸うほどに香りが育つ伝統的なボウル。さらにヒロイン・師匠・ライバルとの絆が深まると、特定フレーバーの香りを引き出す**「専用素焼きハガル（全8種）」**を譲り受けることができる。 |
| **ナイトサイド プレミアハガル** | Dr.fookahの1,000円くじ「ラストワン賞」で入手できる黒曜石調の特製ボウル（容量 **15g**）。※固有補正値は現在検討中（`status: "tbd"`）。 |
| **HMD（ヒートマネジメントデバイス）** | ボウルの上に載せて炭を入れる金属製の器具。アルミホイルの代わりに熱を均一に伝え、蓋（スリット）の開閉で温度を調整する。 |
| **ロートスHMD** | 初期装備の標準的なHMD。扱いやすく安定した火力管理が可能。 |
| **タヌキッシュリッド** | 風防一体型のHMD（6,000円）。熱効率が高いが、**口径の都合で「素焼きハガル（20g）」には非対応**。 |
| **ビッグタヌキッシュリッド** | 第2章から入荷する大口径版タヌキッシュリッド（9,000円）。**素焼きハガル（20g）にも装着可能**。 |
| **アマバースト** | 高い熱保持力と精密なエアフロー制御を備えた上位HMD（15,000円）。 |
| **ステム** | ボウルからボトルの水中へと煙を導く金属管。tonariの初期パイプは真鍮製の**『ハリーザムーン』**。 |
| **ボトル（ベース）と水** | ステムの下端を浸すガラス瓶。**水入れ工程では開始水量0（空の状態）からスタート**し、ステム先端が水中に**約2〜3cm**浸かる適正ラインまで水を注ぐ（#1081 E01）。 |

### ボトルの水の役割（スミの説明：#1113 / #1128・厳守）
- **水の役割は「煙を冷やして吸いやすくする」だけ**。
- ニコチンやタールなど**有害物質への影響については「諸説ある」とし、作中では断定しない**（「水が不純物や有害物質を濾過する」といった断定表現は使わない）。
- また、煙が白く濃く出る（爆煙になる）理由は水のせいではなく、フレーバーに含まれる**「グリセリンと熱の仕事」**によるもの（K14）。

## クラフト工程・技術用語（確定・main反映済み）

| 用語 | 作中での説明・ゲーム内仕様 |
|---|---|
| **パッキング（葉詰め）** | ボウルにフレーバーを詰める工程。**1g刻み**（±1g / ±5gボタン）で最大3種類まで配合する。ボウル容量の**±1g以内**に収めると「ぴったりボーナス（煙量+15%）」が発生。ふわっと空気を含ませる「フラッフィー」が基本。 |
| **混ぜ方（ミックス / レイヤー / セパレート）** | 2種類以上のフレーバーを詰める際の配置方法。<br>・**ミックス**：最初から全体を混ぜ合わせる（最初から一体感のある味）。<br>・**レイヤー**：上下の層に分けて重ねる（時間経過や熱の入り方で味が変化）。<br>・**セパレート**：ボウル内を区切って別々に詰める（それぞれの輪郭がくっきり立つ）。 |
| **水入れ** | ボトルに水を注ぐ工程。**開始水量0（空）からスタート**（#1081 E01）し、ステム先端が約2〜3cm浸かる適正ラインに合わせる。多すぎると吸い心地が重くなり、少なすぎると煙が十分に冷えない。 |
| **チャコール（炭）** | ココナッツ殻を原料とするシーシャ専用炭。<br>・**フラットチャコール**（初期）：平たい形状で火力の立ち上がりが早い。<br>・**キューブチャコール**（2,500円・炭の使い分け講習後に解放）：立方体で火持ちが良く、長時間安定した高熱を維持できる。 |
| **蒸らし（キッチンタイマー方式）** | ボウルにHMDと炭を載せ、葉全体に熱が回るのを待つ工程。数値入力ではなく、**画面上のキッチンタイマーをスタートさせ、止めたいタイミングでストップを押す実時間計測方式**（#541 / E17、ゲーム内1秒＝1分換算）。上限10分、通常5〜8分。 |
| **0分立ち上げ** | 第2章で**神崎 竜二**から教わる特殊技術（`_kumicho_zero_steam`）。熱に強い葉（ドラゴンフルーツ等）に対し、蒸らし時間を置かずに強い火力と吸い出しで一気に立ち上げる荒技。 |
| **吸い出し（立ち上げ）** | 蒸らし終えたボウルに空気を通し、煙と香りを安定軌道に乗せる工程。 |
| **温度帯の表現（低温 / 中温 / 高温 / 過熱）** | 制作画面には**温度計（実温度・最適温・停止予測）を表示**し、**配合中は適温帯の合成横ゲージと文字の帯端点を常時表示**する。**ボウル周辺の陽炎・炭の赤熱具合・煙の濃さ・水の音・立ち上る香り**などの感覚的な温度描写は、地の文・内心の演出として使う。 |
| **途中調整（最大2回）** | 提供・審査中に最大**2回**まで、炭の個数増減やHMDのスリット開閉で温度帯を微調整できる。 |
| **ブロンドリーフ / ダークリーフ** | ・**ブロンドリーフ**：洗浄工程を経てニコチンを抑えた明るい色の葉（ダークリーフ2種を除く全銘柄）。<br>・**ダークリーフ**：未洗浄の黒い葉。ニコチンが強く重厚な喫味と高い耐熱性を持つ（現行データでは**『アルファーヘブン ダーク アールグレイ』**（水瀬ましろの好み）と**『アルファーヘブン シーガ』**の2種）。 |

### メディア・SNS・街の仕組み
- **LIME（ライム）**：作中のスマートフォン用メッセージアプリ。就寝前フェーズにヒロインやライバルから連絡が届き、3択の返信で親密度や翌日の約束が変化する。みんとは営業用の「みんと＠ぺぱーみんと」と恋人化後の私用「栞」の2アカウントを持つ。
- **シガーマン（Cigarman）**：東京の常連客のあいだで「あの恐ろしく重い煙を作るヤツ」として噂される人物のあだ名。噂は大柄な怖い男の話に膨らんでいる。その正体は第3章ヒロインの**水瀬 ましろ**だが、**本人は自分がシガーマンだと気づいておらず**、別に怖い人がいると思って怯えている。本人の前で正体を告げる場面は作らず、手元の癖から読者が結びつける。
- **HOOKAH PRESS（フーカー・プレス）**：**上園 文太郎**が編集長を務めるシーシャ専門誌。
- **アルファーヘブンくじ（1,000円ガチャ）**：Dr.fookah 1階で1回1,000円で引けるくじ（時間消費なし）。S賞の**『大会公式モデルの台』**（家シーシャの熟練度経験値×1.25）や、各種フレーバー、ラストワン賞の**『ナイトサイド プレミアハガル』**などが当たる（※演出・表記は現行仕様のまま）。
- **プリクラ（プリントシール）**：ヒロインとのお出かけ（デート）イベント等で撮影できる記念写真コレクション要素。
