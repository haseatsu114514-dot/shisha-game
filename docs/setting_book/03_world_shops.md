# 世界観・店舗編 — 『水煙前線 -EN:CODE-』

⚠️ 最終章までのネタバレ全開の制作資料です。

## 世界観の骨格

舞台は現代日本。地方都市の小さなシーシャ屋「tonari」から始まり、章が進むごとに
**街→県→東京→ドバイ→研究所**と世界が広がっていく。

大会は4階層のピラミッド構造:

| 段階 | 大会名 | 開催地 |
|---|---|---|
| 地元大会 | SMOKE CROWN CUP | 地元・C.STATION旗艦店 |
| 県大会 | HAZE: OPEN CLOUD | 同県（会場は同じくC.STATION） |
| 全国大会 | HAZE: NATIONAL TOKYO | 東京・巨大イベントホール |
| 世界大会 | HAZE: GRAND SMOKE | ドバイ |
| （番外） | SHISHA-9000戦 | SMOKE LAB（大会ではなく私的な果たし合い） |

### 日常パートのサイクル（ゲームの回し方）

- 各章は**大会までの14日間**の準備期間。1日に使える行動は限られており、
  バイト（稼ぐ＋接客経験）・キャラ訪問（交友・好感度）・修行スポット（ステータス）を選んで過ごす
- 体力（スタミナ）があり、無理をすると風邪で1日潰れる。「家に帰る」で回復
- **天気**: 日替わりで約3割が雨。雨の日は行ける場所・イベント・バイトの客が変わる
- **LIME**: ゲーム内メッセンジャー。朝の連絡、デートの約束、噂話、そして
  優勝の夜に届く「例の通知」まで、物語の重要な導線
- 金策: バイトのほか、スロット・シーシャくじ・レシピ指名注文など。稼いだ金は
  フレーバー・機材・訪問費・占いに消える
- **路上占い師**: 週2日だけ現れるタロットの老婆。3,000円で誰かとの「縁」を見てくれる

## 第1章の街（地元）

### tonari — 主人公の店

スミさんが営む小さなシーシャ屋で、はじめのバイト先。バイト・客席（常連席につむぎ）・
シフト後の自主練とスミさんとの会話、すべての起点。染みついた匂いは蜜と炭とコーヒー、
そしてスミさんのカルダモン。**「店の匂い」モチーフの中心地**で、ch4ラストではじめは
自分の上着にこの匂いが染みていることに気づく。

### KEMURIKUSA（ケムリクサ）— なるの店

商店街の外れの人気店。焼き菓子のような甘い匂いが漏れている。なるが一人で回す。
はじめの「偵察」を笑って迎え、詰めから炭の置き方まで全部見せてくれる場所。

### EDEN — アダムの店

下町の店。焼き林檎みたいな甘い匂い。ダブルアップル以外の注文は「なぜかいつも品切れ」。

### PEPPERMINT（ぺぱーみんと）— みんとの店

繁華街のポップなコンカフェ風シーシャ屋。SNSで人気。実は**みんとの実家の純喫茶の跡地**
（自己破産で精肉店に居抜きされた物件を、彼女が死に物狂いで買い戻して開いた店）。
彼女の心にだけ残る「生肉の幻臭」を、ミントの煙で上書きし続けている。

### Dr.fookah — 問屋街の卸直営店

1階は機材・フレーバーの物販＋一応吸える試飲席。2階は黒フィルムで塞がれた薄暗い
ショールームで、凛が海外メーカーNIGHTSIDEの日本代理店デスクを仕切る。
機材・フレーバーの買い物はここで。ch2では正体を伏せたスティーブがカメオ来店する。

### C.STATION — 大会会場

南雲が会長を務める大手チェーンの超大型旗艦店。**C.STATIONが店舗ブランド名で、読みは「シーステーション」**。普段はカフェのような
大衆店だが、大会当日は特設ステージに変貌する。日常パートでは噂や大会情報が集まる場所。

## 第2章の街（同県・県大会編）

- **神崎煙草店**: 旧市街の老舗。暖簾の奥にシーシャ。組長が一人で回す。
  2回通うと高等テク「蒸らし0分立ち上げ」が解放される
- **パラパラ（アゲハの店）**: 繁華街の派手な店。SNSで人気のギャル店主。
  シーシャ好き・ギャル仲間・オタクと客層がとびきり広い
- **零-ZERO-**: 重いロックが鳴る薄暗いV系コンセプトカフェ。店長は零-REI-
- **鉄の煙（Железный Дым）**: 工業地区の計器だらけの店。無愛想なロシア人ヴォルクの店
  （ヴォルクが選手として立ちはだかるのは第3章から）

## 第3章の街（東京）

- **mukai**: tonari姉妹店で、東京編の溜まり場。店長はムカイさん（次元大輔風のダンディ）、
  同僚バイトにましろ。裏口には猫のテツコ。味覚を失ったはじめが「毎日の一杯」で
  回復していく再生の場所
- **東京のシーシャシーン**: 海外から来て根を張った職人も多く、国籍もスタイルもバラバラ。
  味持ちの良さ・煙の厚み・余韻のレベルが地元とは段違いで、はじめを打ちのめす
- **エミルのナルギレ体験会**: 大会前日に参加できる、審査員エミルによる伝統式ナルギレの体験。
  「新しいだけでは深みは出ない」

## 第4章の街（ドバイ）

- **スーク（市場）**: 旧市街の巨大市場。はじめはここで安い無名のフレーバーを見つけ、
  「高い機材じゃなくても、僕の手で最高の一杯を作る」と決意する
- **路地裏のカフェ**: 観光客が来ない、この街で一番うまい煙が吸える店。
  変装したシェイクとの3度の出会いの場所であり、**15年前に若きシェイクが
  無名の日本人（スミさん）の煙に出会った場所**でもある。師弟の系譜が円環する舞台
- **FESTA**: ジュメイラ地区のカラフルなシーシャバー。壁はブラジル国旗色で、
  ライブDJと煙のトリックショーが毎晩開催されている。ダ・シルヴァ太陽が、大会前のはじめに
  ショーの見せ方と「楽しむ原点」を教えてくれる（旧キャラ「チャド」と店「SHOWTIME」は
  太陽とFESTAに完全統合済み・2026-07-18確定）
- **HAZE: GRAND SMOKE会場**: 世界最高峰の大会会場。決勝は4人一斉
  （はじめ・なる・王煙楼・シェイク）

## 第5章の舞台

- **SMOKE LAB**: チャコール博士の研究所。廊下には古い大会写真が並び、その中に
  眼鏡をかけていない若き選手時代の博士がいる（はじめは気づかない）。
  最深部にSHISHA-9000。戦いのあとも、9000は「世界一の教材」としてここで稼働を続ける
