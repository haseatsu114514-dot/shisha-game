# tonari 五卓営業｜シーシャ店の長居をゲームにする
**企画・調査資料 v0.1｜2026-11-19｜未採用・未実装**

結論：**卓が長く埋まるのに、やることは短く途切れて来る。そこを遊びにする。** 電車までの二人を予定どおり帰し、読書客はそっとしておき、別の卓の「おかわり」の意味を聞き分ける。その間、出し口の一台と入口の一組からも目を離せない。『龍が如く』の優先順位と即時反応を借り、売上フィーバーの代わりに「約束どおりの時間をつくる」ゲームにする。

- **推奨**：五卓の全画面と確定操作で進む手番制を残し、ショート／通常／長居を「時間の約束」にする。最初に試すのは、普通の六組が来る一晩だけ。
- **おかわりの分離**：飲み物の追加、同じ一台のトップ替え、別の一台、席の延長、シェア、無料の熱ケアは別の意味。初回版では料金や操作の要らないものまで一律に有料化しない。
- **日常との両立**：旧「短い勤務」と物語専用接客はそのまま。長版と短版で基本日当・ゲーム内行動枠は同じ。プレイ時間ではなく今日の具体的な仕事を選ぶ。企画書・画像参照集のみで、ゲームの変更、PR更新、公開はしていない。
- 見た目の参照は別紙「Tonari・画面と店舗写真の参照集」。試作の画像であり、本提案の完成画面ではない。

## 4. 推奨ルール：座席の約束が衝突する夜

### 4.1 時計とフロア

- **1手＝店内時計5分、18:00開始、t=0〜47の48手、t=48（22:00）で担当を引き継ぐ**。プレイヤーの実時間は初回4〜6分、慣れて3〜5分を仮目標。盤面を読む時間は無制限。1回の確定だけで1手進む。卓を選ぶ、見積もる、閉じる、ポーズ、スクリーンリーダーを読む操作では進まない。
- **3つの締切**：入口の待ち上限／初回提供の見込み／この卓の退出予定。売上の数字と混ぜない。入店待ち期限は来店＋5手、初回提供の約束はショート＋4手・その他＋5手。店の受付で確認した個別退出予定があれば優先。
- **料金と滞在**：席料¥500／人、標準のソフトドリンク初杯¥400／人。一組一台。提供からの標準プラン時間と個別の退店時刻は別。下表はゲーム内の約束で、実際の吸える時間の説明ではない。

|---|---:|---:|---|
| ショート | 60分＝12手 | ¥1,400・¥2,300 | 提供目安と「何時までに出たい」を強く見せる。先に動くと片付けが間に合い、次客を通せる。押し売り・常設のおかわり通知なし。 |

- `checkoutAt = min(firstServedAt + planTurns, departureBy)`（個別期限なしなら後者は無限）。本来のプラン時間を確保できない提案は自動で短縮・割増せず、「ショートなら ○時まで／飲み物のみ／見送り」を提示。ショート客だけに機械的優先をつけず、待ち列と約束を見て選ぶ。通常の精算は退出予定を過ぎても受け付けるが、2手超の遅れで一度だけ評価減。硬い退出期限は当時刻で「スミに会計を頼む」が使える。待たせて電車を逃がす演出や長引かせる報酬はなし。
- **空席は片付け完了後**。中央通路は背景の空間で、移動・タイムロス・仮座席を作らない。待ち列は原則着順、遊びの誤解を避けるため優先予約・抜かしは後回し。入口案内で第一杯を決め、次手にスミが出す。最初はドリンク製作や材料の入力を増やさない。
- **次の変化まで**：すべての新規期限・到着・棚の完成・決済に関わるイベントのうち最初の時刻まで飛ばす。他に取れる行動があれば「○卓を後回しにして進む」確認を置く。同手にイベントがなければ最短1手。見守りを連打させない。章のゲーム内行動枠は48手とは無関係に1枠。

### 4.3 人と道具。強い道具が全部を解決しない

- 一手でできることは一つ。**部屋＝見通し**、**作業台＝準備**、**受渡棚＝配る順番**、**レジ後の清掃＝回転**。負荷はキャストHPではなく「作業台が塞がる」「棚が埋まる」「客が待つ」の三つだけで表す。
- 伝票は「香りの希望1＋外せない条件1」。例：果物の甘さ＋ミント抜き／涼しい柑橘。ただし3軸以上のレーダー、葉の調達、陶器の重量、炭管理の技術画面は追加しない。既存の配合資産を使い、五卓版は抽象的な仕込み。既存の本格ミニゲームへ分岐させない。
- 追加テスト用の道具は**開店前に一つ**。「回転セット」＝シフト中一度だけショートの開始→完成が1手。「安定セット」＝一度だけ指定卓のケア猶予を＋2手。「スミにひと言」＝開店前の人気予報／一度だけ水・初杯の整流。いずれも仮効果。数値成長・購入作業・装備ガチャを入れず、回転と丁寧さの判断が生まれるかで採否を決める。
- 相談／体調の申し出は即時引き継ぎ、売上や失敗ペナルティの対象にしない。暴力、過剰摂取を促す演出、消費量でファン数を増やす仕組みは持ち込まない。

## 6. 評価、進行、交友との両立

- **数字は裏で、表は理由**。授業用の暫定スコア：各組60開始、香り一致＋20（飲み物のみは明示した希望一致で同等）、初回約束または提示した代案履行＋10、希望のペース・個別の合図を尊重＋10。一組の加点は買った額や品数によらない。無料ケアの約束忘れ−10、会計の猶予超過−5、望まない押し付けをした場合−10、それぞれ同じ原因では一回だけ。0〜100で丸め、UIには「間に合った」「落ち着けた」「会計を待たせた」などの要因だけ。見送り客は平均の分母に紛れ込ませず別個に表示。失敗で日当・本編の交友・好感度を下げない。
- 適合しない台を出して回復したら「最初は違った→聞き直して直した」を別記する。代案がある拒否は加点対象同様に扱う。トップを受けた人だけ評価満点にする、無断延長で売上を積む、ケアをわざと怠って有料追加を誘う、などはできないようにする。
- 初回夜の目標は一つだけ。「20:00までに手前4を会計」または「希望した最初の香りを4組に届ける」。未達ならリザルトに次回のヒント一行、次の任意勤務へ持ち越し。友達を優先した日、店に行かなかった日を警告しない。深掘りは「同じ条件の練習」でいつでもやり直せるが、本編の所持金・評判・物語フラグには加算しない。
- **評判は初回は金銭でも新しいゲージでもない**。「時間を守る店」のような一晩の振り返り1行だけ。将来、#3915 の黒板候補を試すなら「次の任意勤務に、普通の客が黒板の『涼しい』を見て『ミントは抜きで』と聞く」一件。次回に持ち越すデータも一件だけで常連台帳にしない。
- **本編との接続**：地図の札に「今夜は電車待ちの二人が来る」等の仕事予報。「短い勤務」／「五卓を担当」の明示。重要な恋愛・友人イベントを消さない。旧勤務でも基本日当と1行動枠は同じ。追加の必須解放なし。お忍びの同業者は背景にいなくても成立。置くなら同じ短い希望の普通の客として、身元に気づかなかった回も再会などで回収可能とする。
- 日替わりの候補は「午後の読書席」「終電組と長居が重なる金曜」「雨の閉店前」の3種まで。初回の役割を運に任せない。途中加入で新しい味クイズを覚え直すより、来店の時刻と、席か仕込みかの優先が変わることを重視。

## 7. 画面／データ／保存（未実装の契約）

- **メイン画面**：部屋と客を中央。上に店内時刻・担当売上・休止。入口に待ち組数＋最初の約束、厨房側は仕込と棚の状態。各卓に番号＋主アイコン1個（注文／準備／配膳／待機／呼出／会計／片付け）。急ぐときだけ短ラベルか残り分数を一段追加。長文、明細、香り候補は選択卓の下段伝票だけ。ホバー必須にしない。
- **優先表示**：硬い退出／入口待ち期限／提供の約束、次にケア、最後に追加希望。既定で並びを変えて卓の位置を動かさない。姿勢は本を読む、目線、手を挙げる程度。アイコンだけでも音だけでも色だけでもなく「図形＋短語」。選択時の読み上げ例「4卓、2名、会計、20時まで」。警告は音・振動オフ可。動きを減らす設定では点滅・連続ズームを使わない。
- **スマホ**：まず横持ち844×390・740×320を検証、セーフエリアを除いて押下領域44×44 CSS pxを設計目標。狭い場合は卓の番号を動かさず下段を二段化／下から開く伝票で文字を確保。縦持ちは「席一覧で操作」へ切替、回転強制しない。物理iPhoneのSafariと読み上げ、Android Chrome、小型でも確認。PCは矢印で卓、Enterは選択・伝票フォーカスと確定を分離、Escは伝票を閉じる→休止。
- **状態**：入口 `未着→待機→着席` または `案内なしで退出`。卓 `空席→注文済→準備→棚待ち→提供可能→滞在→会計→片付け→空席`。滞在に `ケア希望／追加希望／相談` を別レーンで付ける。トップ準備中も卓は滞在状態のまま。会計に移ったら未提供の作業はキャンセルし、棚は解放。客情報・明細・作業台は `卓ID` 単独ではなく `来店ID＋卓ID` で照合。別客に古い台や伝票を出さない。
- **同時刻の順**：tの開始で到着、初杯、棚完成、予定時刻、合図を更新し、次の一手を一つ選ぶ。同じtの締切はその操作まで有効。tの終わりに未処理の期限を失効。t=48はスミへ締めを渡す。静かに間に合わなかった追加は無料で取り消し、作業割当解除。押された行動が古ければ何も進めず再表示する。
- **保存**：シフトID、ルール版、シナリオ・seed、時刻、来店ID、各締切、仕込み／棚、明細、既済フラグ、旧勤務セーブとの互換。1確定1保存、画面が落ちても直前の確定状態へ。バックグラウンド・休止で進行なし。「中断し再開」と「残りをスミへ」を別ボタンにする。後者は終業処理と賃金・日枠・物語トリガーをシフトIDで一度だけ反映。練習プレイは別スロットで永続報酬なし。
