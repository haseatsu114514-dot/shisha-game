# 正面視点の斧投げ（#542）

投げ手が的を見るカメラで、頭上・右寄りのリリースから奥へ進む斧を描く。画面内で横見本PNGを回す旧方式を、厚みのある金属/木の面の透視投影へ置き換えた。横軸を中心に前へ倒れ、柄の短縮・反転・木口/刃面の切替が見える。的の平面への刃の接触位置は、既存の得点モデルの着地点と一致する。

保存した5フレームは同じ実ミニゲームで、ボタンを実クリックして3つのゲージを止め、その後ブラウザの時計を制御して捕捉した。すべて目視確認済み。時計を制御した描画検証であり、自然な日常進行を証明するケースとは分ける。フレームJSONにpitch/depth/見える面を記録する。初回は描画/操作のassert後、Promise版fsへの同期書込み呼出しで成果出力が失敗した。await fs.writeFileに直し、同じassertで再実行PASS。初回失敗も保存した。

純粋16・斧20・本編ひより11・旧セーブ6＝独立53ケースとLIME VMがPASS。斧20にはPC/タッチ縦横、説明中の飛行/落下停止、動き軽減、Abort/二重開始/撤去、旧友人/恋人/LIME不変、刃の投影接触、前後回転の5フレームを含む。本編11は実3投と正式前後VN、未読/取消/LOAD、新規ゲームへの切替、費用・好感度・関係の一度だけの処理を検証。自然なNew Game PC/タッチは最終headのCIで別途確認し、未取得の結果を推測しない。
