# 立ち絵のサイズ・配置点検

ユーザーの追加指示「他キャラの規格と比べて変な立ち絵がないか確認し、おかしければサイズを合わせる。再生成するかは見つかってから決める」に対応。全22キャラ・100表情のキャンバス、可視範囲、足元、実ゲームの拡縮率と、キャラ間の頭・全身の大きさを比較した。

**全体の表示倍率を変えるほどの異常は見つからず。会社員の笑顔1枚の位置だけ補正した。今回のサイズ点検では再生成していない。** パッキーの高さの差は座るポーズによるもの。原画由来の画質については、再生成の判断をユーザーに残す候補として記録した。

## 結果

| 対象 | 根拠と対応 |
|---|---|
| 会社員 `smile` | 通常より足元の重心が右3.60px・下3px。画像全体を左4px・上3pxへ移動し、差を横0.40px・縦0pxにした。拡縮や描き直しなし |
| 会社員のmanifest | 通常の足元アンカーが旧計測値0.5318だったため再計測し0.5309へ更新。PNG/WebPも更新 |
| パッキー `surprise` | 通常より全高が約10%低いが、制作指示に「seated leaning back with both rounded soles visible」。座って足裏を見せるポーズで、頭・身体の縮尺違いではない。高さを維持 |
| パッキーの画質 | 原画の小さいスライスを約2.11倍拡大した既存素材。大きく表示すると線が柔らかく、外周に極めて薄い白の残留がある。別AIでも約300px高表示では白点はほぼ気にならないと確認。低〜中優先の高解像度化候補。現状維持、再生成は未実施 |
| 占い師 | 唯一1084×1451（他99枚は896×1200）。VNは画像の余白と本体高で補正するため、実際の表示倍率は正常。解像度を下げて寸法を統一する必要なし |
| ひよりの投擲など | 脚の開き・体の傾きに伴う足元の重心差。ポーズの違いとして保持。全13枚の可視高は1000pxで、全身が縮む表情はない |
| その他 | 身長設定・マスコット専用倍率を考慮した比較で、極端な拡大縮小や頭・横端の見切れなし。通常からの全高差は、座るパッキー以外は3%以内。設定上の低身長や帽子・角、顔つきの細さは維持 |

整列ツール `tools/align_sprite_anchor.py` に、`axe_normal` を通常の基準と誤認する条件も見つかった。キャラの `normal` / 私服の `ura_normal` の完全一致を優先するよう修正した。ひよりの画像へ一括整列はしていない。

## 検証

- [修正前の計測](measurements-before.json)・[修正後の計測](measurements.json)に全100表情の寸法・可視範囲・拡縮率・足元を保存。修正後は全キャラでmanifestの再計測値が一致。
- 会社員は、平行移動に対応する全RGBA画素の一致と、可視画素の欠けなしを確認。PNGと配信用WebPも全RGBA一致。サイズ点検中に変えた立ち絵は会社員 `smile` の1枚だけ。[統合記録](../../../asset_sources/portraits/size-alignment-review/integration.json)
- 会社員の通常→笑顔をPC1280×720・スマホ844×390の実VNで、素材の修正前後を同じ現行manifestで差し替えて比較。[ブラウザ確認](browser-check.json)、[修正後スマホ寸法](salaryman-after-844.jpg)。表情間の配置枠・寸法が一致、JSエラーなし。
- 直前の目・顎の点検で、ゲームに表示する21キャラ95表情を実VNのスマホ寸法で確認済み（先行2キャラはPCも）。その実測位置に可視範囲を重ね、頭・横端の見切れがないことも確認（[境界の実測](bounds-check.json)）。主人公はじめ5表情は一人称のVNでは立ち絵を出さないため素材比較で確認。
- 会社員の整列dry-runは変更0。修正した整列ツールは、ひよりの実ファイルで通常を移動対象にしないこと、みんとの営業姿／私服の基準を保つことをdry-runで確認した。

`build_report.py` は素材を変更せず計測・比較を再生成する。`check-salaryman.cjs` は実VNの確認用。元の会社員笑顔は `asset_sources/portraits/size-alignment-review/salaryman-smile-before.png` に保持。
