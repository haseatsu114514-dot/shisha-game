# 占いトリビア 仮案40本

意外性を増やした第2稿。いずれも占い師の話で、正史の事実として断定しません。名前・関係の秘密を先出しせず、最後ははじめが半信半疑で受け取ります。

## スミさん

1. 占い師「店の外の猫に、たまに営業報告をしてるんじゃないかね。相手は返事もせんのに」
   はじめ「（猫相手なら、あの調子で普通に話しそうだ……）」

2. 占い師「壊れた道具を捨てる前に、一度だけ「お疲れさん」って言う人だね」
   はじめ「（ふざけて言ってるようで、ちゃんと本気な気がする）」

3. 占い師「新しい家電に「前ので十分」と文句を言って、便利な機能は誰より使っとるよ」
   はじめ「（使い方を教えてくれる顔まで、想像できてしまった）」

4. 占い師「あの店の客が使う変な言い回し、元を辿るとあの人だったりするんじゃないかい」
   はじめ「（店全体に口癖が移ることって、確かにありそうだ）」

5. 占い師「自販機で当たりが出ると、機械に軽く頭を下げる。そんな札が出たね」
   はじめ「（……当たりより、その瞬間を見てみたくなった）」

## なる

1. 占い師「コンビニの新作菓子を「資料代」って呼んで買う人だね」
   はじめ「（言い訳なのか、本当に研究なのか。なるさんだと両方ありそうだ）」

2. 占い師「立派な菓子の缶を開けたら、中からドライバーが出てくることがあるよ」
   はじめ「（捨てられない箱を道具入れにするの、妙に納得できる）」

3. 占い師「目隠しでプリンを食べ比べようとして、先に容器を替えて、答えが分からなくなったことがあるかもね」
   はじめ「（研究熱心すぎて準備で失敗するの、ちょっと見てみたい）」

4. 占い師「気に入った菓子が値上がりすると、何円上がったかまで覚えてる人だよ」
   はじめ「（いつもの買い物より、そっちの数字の方が正確そうだ）」

5. 占い師「「ひと口だけ」と言ってもらった菓子を、まずきれいに二つに割るんじゃないかね」
   はじめ「（断面まで確かめたい、ってことなのかな。ありそうだ……）」

## アダム

1. 占い師「りんご飴を見て、「これはシングルアップルだな」と真顔で言ったことがあるね」
   はじめ「（そんなこと言うの、あの人しか思い浮かばない……）」

2. 占い師「傘を持つ姿だけは妙に決まっとるのに、その傘をどこかに忘れてくる人だね」
   はじめ「（帰りだけ雨に濡れてても、堂々としてそうだ）」

3. 占い師「自動ドアが開かないと、立つ位置より先に目つきを変えるんじゃないかい」
   はじめ「（機械にまであの顔をするのか……。否定しきれない）」

4. 占い師「洗剤の香りが強いと、「服が主役になってしまう」と無香料を選ぶ人だよ」
   はじめ「（言い方は大げさだけど、あの人ならちゃんと気にしそうだ）」

5. 占い師「料理の「少々」が気に入らなくて量を測り、鍋に火をつける方を忘れたことがあるね」
   はじめ「（正確なのに、肝心なところで抜ける。その絵は浮かぶ）」

## みんと

1. 占い師「電話の営業を断るときだけ、声が一段低くなる人だね」
   はじめ「（店で聞く声と違ったら、ちょっとびっくりするかも）」

2. 占い師「ひとりで店の会議をして、ひとりで自分の案を却下したことがあるよ」
   はじめ「（ちゃんと反対意見まで出すところ、みんとさんっぽいな）」

3. 占い師「可愛い電卓を買ったのに、会計は結局、数字のでかい業務用を使うんじゃないかね」
   はじめ「（可愛さと使いやすさ、そのへんは分けて考えそうだ）」

4. 占い師「自分の写真は撮り直すけど、丼ものの写真は一枚。冷める前に食べる人だよ」
   はじめ「（そこは迷わないんだ……。なんだか少し安心した）」

5. 占い師「店でちょうどよく響く拍手を、閉店後にひとりで試したことがあるね」
   はじめ「（楽しい空気って、そんなところでも作ってるのかな）」

## つむぎ

1. 占い師「窓の汚れが変な顔に見えて写真を撮ったのに、きれいに拭かれて少し残念がった人だね」
   はじめ「（他の人には汚れでも、つむぎちゃんには何かいたのかも）」

2. 占い師「うまく描けた絵ほどレシートの裏にあって、捨てられないことがあるよ」
   はじめ「（お店の名前まで作品の一部になってそうだ）」

3. 占い師「眠い日に猫を描くと、だんだん丸い芋みたいになるんじゃないかね」
   はじめ「（……それはそれで、見せてもらいたくなった）」

4. 占い師「新しいノートの一ページ目は大事に空けて、落書きは最後のページから始める人だよ」
   はじめ「（きれいな最初のページって、逆に緊張するのかな）」

5. 占い師「紙を丸めて捨てようとして、しわの中に顔を見つけて、また広げたことがあるね」
   はじめ「（つむぎちゃんの机に紙が増える理由、少し分かる気がする）」

## 凛

1. 占い師「立派な機材はいくらでも知ってるのに、最後に信用するのは安い輪ゴムなんじゃないかね」
   はじめ「（仮止めにはこれが一番、とか。真顔で言いそうだ）」

2. 占い師「通販のレビューは星ひとつから読む。品物より、梱包の雑さに腹を立てる人だね」
   はじめ「（仕事で荷物を見る目、そのまま使ってそうだ）」

3. 占い師「読めない手書きラベルには厳しいのに、自分の走り書きは自分しか読めん日があるよ」
   はじめ「（聞いたら「これは分かるでしょ」って返されそうだな……）」

4. 占い師「福袋の「総額」をその場で暗算して、店の人を黙らせたことがあるかもね」
   はじめ「（買う前の確認が、ちょっとした交渉になりそうだ）」

5. 占い師「怪しい勧誘を断るときほど、やけに丁寧な敬語になる人だよ」
   はじめ「（あの人が急に丁寧になったら、俺もちょっと身構えるかもしれない）」

## ひより

1. 占い師「カラオケの曲を選ぶ画面では、指が少しも迷わない人だね」
   はじめ「（普段より決断が速いひよりさん、ちょっと気になる）」

2. 占い師「予定帳に「何もしない日」と書いて、空いた余白へ用事を足してしまうんじゃないかい」
   はじめ「（休む予定まで、ちゃんと埋めちゃうんだろうか……）」

3. 占い師「可愛い入浴剤を使うのが惜しくて、新しいのをもう一つ買ったことがあるよ」
   はじめ「（特別な日に、って考えてる間に増えていくのは分かる気がする）」

4. 占い師「自動レジにも一度「すみません」と言ってから、お金を入れることがあるね」
   はじめ「（相手が機械でも、あの感じが出るのかな。ありそうだ）」

5. 占い師「要らない箸を断りそびれて、家に割り箸が少しずつ増える人だよ」
   はじめ「（いつか使うし、って引き出しを閉める姿が浮かんだ）」

## サメちゃん

1. 占い師「あの小さな王さまを叱ったあと、王さまの声で言い返されて、結局自分が謝る日があるよ」
   はじめ「（全部ひとりでやってるのに、勝ち負けがあるんだ……）」

2. 占い師「サメのしおりを挟むとき、本に噛みついてる向きへ直す人だね」
   はじめ「（向きまでちゃんと大事なんだ。サメちゃんらしいな）」

3. 占い師「サメの形のグミを食べるとき、どれから食べるか一度相談するんじゃないかい」
   はじめ「（相談相手は……やっぱり、あの王さまかな）」

4. 占い師「丸いパンを見ると、ここに背びれを付けたら、と一瞬考える人だよ」
   はじめ「（パン屋でもサメになるのか……。でも、そう言われると想像できる）」

5. 占い師「写真で自分が少し見切れても、王さまがきれいに写っていれば採用する人だね」
   はじめ「（あの子の写真を見たら、どっちが主役かすぐ分かりそうだ）」
