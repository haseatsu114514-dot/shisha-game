# #644 ひよりの台詞改稿：変更前後と検証記録

Issue #644 の確定方針（「儚い女」を自分で大げさに盛る演技、心の声の現実ツッコミ、限られた見せ場での「だから儚いんだってば！！」）に合わせ、ひよりの台詞本文を改稿した記録。

- 変更したのは台詞本文だけ。話者・制御行（フラグ・選択肢・分岐・条件）・補間変数・イベントID・報酬・好感度・保存形式は変えていない。改稿スクリプトは、場面ごとに制御行の並びが改稿前と同じであることを検査してから書き込んだ。
- 解禁順・匿名目撃・既視感の分岐は #577 の担当。初対面の台詞には匿名目撃・斧投げ・既視感の要素を入れていない。登場カットインの台詞（「……煙みたいに、もう遠い昔だけどね」）も変えていない。
- 初対面には心の声を付けていない（演技の裏側は、従来どおりスミさんの回想で初めてプレイヤーに見える）。
- 大声の逆ギレは、空腹の回（`hiyori_shop_repeat_3`）と斧投げでの発覚（`hiyori_axe_reveal_close`）の2場面だけ。スミさんがいる場面・仕事相談・告白の核心は、素直な口調のまま残した。
- 心の声が付く行では、本文が1ページ1行に制限される。新しく足した心の声は、1行に収まる短い台詞に付けた。
