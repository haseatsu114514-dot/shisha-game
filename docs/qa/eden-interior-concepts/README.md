# EDEN 内装：採用済みドット調整版

## 採用：ドット感の調整版

![ドット感の調整版](eden-pixel-matched.png)

[調整版PNGを開く・保存](eden-pixel-matched.png?raw=true)

窓なしの修正版を内容の基準とし、他店の背景はドットの描き方だけの参考にして生成。壁・布・木部の不均一な大きな塗りの塊を細かく整理し、輪郭の段差と色のまとまりをそろえています。完全な固定グリッド変換ではなく、画像生成による描画調整です。

維持する条件：窓なし、現行に近い構図・カーテン・ランプ・ソファ・暗めの暖色照明。各りんごの絵は左が緑・右が赤。シーシャ台は木製テーブル・展示台上に配置し、ソファ座面へ置かない。

## 確認・実装状況

オーナーの「これで採用ゲームに反映して」により正式採用。原画を1280×720に縮小し、ゲーム用PNGと配信用WebPへ反映。画像内に台が含まれるため、旧背景用のシーシャ台4台の合成をEDENだけ撤去しました。旧名の背景参照は既存エイリアスを通して採用画像を表示します。

確認：PC・タッチでマップからの入店と実際のアダム訪問会話（計4件）のブラウザテストが成功。画像デコード・1280×720・WebP目録登録・二重合成なしを確認し、PC会話画面とタッチ入店後画面を目視。構文チェックと差分の空白検査が成功。
