# 神崎竜二 白系チェック 一式

立ち絵は通常・笑顔・真剣・驚き・男泣き（sad）の5表情。896×1200 RGBA、足元下端1174px付近。PNGとlossless WebPのRGBA画素は一致。

登場カットインの肩書きは「水煙の龍」、呼び名「神崎竜二」、一言「回し飲みはな、盃と同じだ」。文字は背景へ焼き込まずゲームの実テキストで表示する。白系大柄チェックのダブル、黒シャツ、紫のネクタイ、色付き眼鏡、53歳の基準で制作。小指はどの表情もポケットで隠し、有無を設定しない。

assets/ と remake/img/ は想定導入先。PNG・WebP・顔アイコン・登場背景を同梱。portrait-manifest-entry.json と intro-manifest-entry.json は目録への追加値、character-update.json は既存人物へ適用するフィールド差分で、他の人物データを置き換えない。

これは完成素材と実エンジンでの表示確認をまとめたデータパッケージ。本編のファイルはまだ差し替えていない。追加するPNG/WebPはリポジトリ規約に沿ってGit LFSへ保存し、導入時にmanifest・表情割当・人物データと確認を更新する。

validation.json は透過境界・足元・ファイルハッシュ、browser-validation.json はPC/タッチでの5表情と登場カットインの表示確認。
