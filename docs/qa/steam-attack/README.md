# アタックの画面確認

`steam_attack_growth.mjs` をPCとタッチ端末相当で実行し、実際の弾を斬って撮影した。`strike-*` は6コンボ以上の金色の弧、`tier-1-mobile-reduced.png` は中間段階、`ready-mobile-reduced.png` は被弾後に0へ戻った状態。スマホ側は「動きを減らす」設定。

`word-cut-*` だけは、30度回転した文字を描画する視覚確認用fixture。描画した刃と同じ曲線から切断方向を計算し、文字の回転を残すことを確認する。fixtureは撮影直後に除き、ゲームの衝突・コンボ判定には使わない。

代表的な刃と破片が見えるよう、撮影中だけ装飾のCSSアニメーションを100msに止めている。ゲームの命中判定・タイマー・コンボは実際の処理で検証する。

`tournament-*` は大会モードの見出しとヘルプの配置。PC／タッチのレッスン・練習・大会すべてで、ヘルプがモード説明・工程セル・弾幕と重ならないことをブラウザで確認した。
