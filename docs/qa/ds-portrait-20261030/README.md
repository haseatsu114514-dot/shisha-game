# DS風（縦持ち・上下2画面）の見直し — 2026-10-30

オーナー「縦画面のDS版の設計を見直してほしい。微妙な見た目になったり上手くいかない」を受け、スマホ縦 390×844 と 320×568 のDS風を実機サイズのヘッドレスChromiumで全画面撮影し、切れ・重なり・極小文字を直した。変更はDS専用CSS（`remake/css/game-ds.css`・`title-ds.css`・`vn-lounge.css` のDS節）と `game_layout.mjs` の期待値だけで、通常版・進行・保存・原画は変えていない。

## 残っている設計上の課題（オーナー判断待ち）

- **上画面の黒い帯**: 上画面は「上下半々」（2026-10-24指定）で4:3前後になるが、地図・背景は16:9なので地図では上下に約90pxずつ帯が出る。地図だけ `cover`（左右を切る）にすると端のピンが隠れるため据え置き。HUDは上の帯、「商店街を歩く」は下の帯に置いてある。
- **座標操作の工程の縮小**: 穴あけ・炭・蒸らし・吸い出しは760pxの盤面を約0.47倍に縮めて下画面に収めているため、文字・ボタンが小さい（44px目標が約20px）。盤面を横スクロールさせる（0.6倍）か、工程ごとにDS専用の組み方を作るかの判断が要る。今回は水入れだけ組み直した。
- **場面転換**: 円ワイプ・斜め帯は1280×720のステージ全体に描かれるため、DSでは2画面をまたいで一瞬だけ白い面や紫の帯が見える（約0.5秒）。DSでは2画面を個別に暗転させる案がある。
- 320×568では下画面が265pxしかなく、地図の行き先は1.5段しか見えない（スクロール可）。
- 実機Safari・横持ち（左右2画面）は未検証。横持ちは `ds-geometry.js` の `side` 配置で、今回の変更はほぼ縦持ち（`stacked`）の寸法にしか効かない。
