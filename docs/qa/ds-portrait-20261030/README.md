# DS風（縦持ち・上下2画面）の見直し — 2026-10-30

オーナー「縦画面のDS版の設計を見直してほしい。微妙な見た目になったり上手くいかない」を受け、スマホ縦 390×844 と 320×568 のDS風を実機サイズのヘッドレスChromiumで全画面撮影し、切れ・重なり・極小文字を直した。変更はDS専用CSS（`remake/css/game-ds.css`・`title-ds.css`・`vn-lounge.css` のDS節）と `game_layout.mjs` の期待値だけで、通常版・進行・保存・原画は変えていない。

## 見つかった問題と対応（左=修正前、右=修正後）

| 画面 | 問題 | 対応 | 比較 |
|---|---|---|---|
| タイトル | 縦長原画が上画面の中央に小さく、周りに同じ絵のぼかし。ロゴが絵と「表示設定」に重なる。320×568では章名が切れる | 原画を上画面いっぱい（顔側を残して上下を少し切る）、ぼかしをやめ、ロゴは左上の暗い帯へ。設定入口はヒンジ。低い端末は章名の行を詰める | [title](title.webp) / [small-title](small-title.webp) |
| 会話 | AUTO／SKIP／LOG／用語／設定が上画面の上端で立ち絵の頭を覆う。3択の3つ目が切れ、320×568では本文2行目に選択肢がかぶる。下端のタッチバーが空 | 操作バーを下画面のタッチバーへ。本文枠の高さを下限つきにし、3択が収まる大きさに | [vn](vn.webp) / [small-vn](small-vn.webp) |
| 地図 | 行き先が「KEMURIKU…」「PEPPERMI…」と切れ、4段目（家）が案内パネルに隠れる | 店名を2行まで折り返し、カードを50pxにして4段を見せる | [map](map.webp) |
| 制作・配合 | 工程バーの「前日リハーサル」が「01 パッキング」と重なり工程名同士も重なる。「外観を選ぶ」が中身に重なる。決定ボタンの文字が「フレ…」で切れる | モード名は1行、工程の絵は今の工程だけ、矢印なし。「外観を選ぶ」は小さな札にして中身を札ぶん下げる。決定ボタンを折り返し | [mix](mix.webp) |

| 共通 | ヒンジの「表示」ボタンが上下の画面の角に食い込む | 22px高の小さな丸札に | — |

| 画面 | 対応 | 比較 |

## 残っていた設計課題の決定（オーナー「判断は任せる」・同日）

| 課題 | 決定 | 理由 |
|---|---|---|
| 上画面（ほぼ4:3）に16:9の地図を収めると上下に黒い帯（[比較](map-bands.webp)） | 地図は全体表示のまま、帯を同じ地図のぼかし（暗め）で埋める | 左右を切ると端の行き先ピンが隠れ、ピン位置の計算も崩れる。帯にはHUDと「商店街を歩く」が載っているので帯自体は活かす |
| 穴あけ・炭・蒸らし・吸い出しの盤面を約0.47倍に縮小 | 縮小のまま維持。押す所が44px未満になる炭のつまみだけ、見た目を変えずに当たり判定を広げる（320×568でも45px以上） | タイミング操作中に盤面をスクロールさせると操作ミスの元になる。装飾の小さな文字は前回省いた |
| 場面転換の斜め帯・円・店ロゴの幕が2画面をまたぐ（[比較](transition.webp)） | DSでは全体の暗転（覆う・開くの時間と入力停止は既存のまま）。店に入るときのロゴは上画面の中に小さく出す | 1280×720用の幕を縦長に引き伸ばすと白い面や巨大な円が一瞬見える |

## まだ確認できていないこと
