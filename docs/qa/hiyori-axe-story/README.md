# ひよりの正式斧投げ・検証

旧 #343 / #492 / PR #495。既存の前半は維持し、正式な前段→実3投→後段を追加する。

- 新11ケースは本番台本/ゲーム/保存/取消/ロード/旧関係/LIME/calendar入口。保存6、共通関係API9もPASS。共通関係APIの後半台本fixtureと、実斧投げの読了証明を区別する。
- 自然New GameのPC/タッチは通常の訪問/支払い/LIME返信を通り、どちらもDAY9に正式斧投げを読み終えた。seedのみ固定し、日・好感度・既読は注入しない。自然結果は対象の進行/支払いを抽出して保存し、全結果は専用CIのartifactに残す。
- 4画面はその自然プレイからコピーした実VN。新しい素材は生成せず、採用済み背景/立ち絵を使用。PC/タッチの会話・人物・背景・内心が読み取れることを目視確認した。
- 途中の未読後段/ゲーム中/前段でstateが変わった場合はキャンセルし、料金・行動・進行を新セーブへ加えない。通常の読了時は料金/体力/行動/既読を一緒に保存する。

失敗も区別する。初回の既存ミニゲーム12ケースは11PASS/1FAIL（狭いキルショットを物理入力で外した）。当たり判定を変更せず、投げる前の表示位置を確認して実際の「狙い直す」で再照準するfixtureへ改め、そのケースはPASS。VMバイト/遭遇頻度の未対応mockも修正した。最終headの全CI成功と公開確認はマージ前後に別途確認する。

自然確認はoptional VNキャンセルの追加前に開始したため、最終headの自然確認は専用CIで必須とする。第2章以降の新規到達性、仕事相談/告白/ハガル/海外/AI対戦はこの検証の完了範囲ではない。
