### 1-6. 現行実装の課題（なぜIssue #1081 E06が必要か）
1. **「吸いで温度が完全復元できてしまう」不自然さ**:
   - 炭交換を「0個（交換しない）」に選んでも、上げ吸いを2〜3回ジャストで止めることで、低下した温度（-0.075）を取り戻して最適温に復元できてしまう。
   - 炭交換が実質的にオプショナルになっており、ゲームプレイの主役が「針止めアクション」に偏っている。
2. **実店舗のシーシャ運用との解離**:
   - リアルな店舗運用では、時間の経過で小さくなった炭や灰を被った炭のまま吸い込んでも熱は戻らず、むしろ葉にえぐみが出たり煙が薄くなったりする。温度の復元・維持は「炭の交換と配置調整」が9割以上を担う。
3. **操作テンポの重さ**:
   - 調整1回ごとに「個数選択 → 炭焼きミニゲーム → 針止めミニゲーム」と二重のゲームが挟まるため、特に2回の調整をこなす大会本番でテンポが間延びしやすい。

## 2. 実店舗の運用に沿った共通モデルの設計思想

### 2-1. 実店舗におけるシーシャの熱管理（炭交換・ローテーション）の実態
- **炭の劣化と交換サイクル**:
  - シーシャ提供後、約20〜30分で炭（ココナッツチャコール等）は燃焼が進んでサイズが一回り小さくなり、外側が白い灰で覆われて伝熱効率が落ちる。
  - スタッフは巡回（ローテーション）時に炭をチェックし、専用の炭壺・トングで灰を払い落とすか、十分に熱された新しい炭と交換する。
- **炭の配置と熱量コントロール**:
  - **位置（内外）**: ボウルの外周寄りに置くと穏やかな加熱（焦げ付き防止）、中心寄りに寄せると強い加熱（立ち上げ・熱入れ）。
  - **個数・向き**: 炭を寝かせるか立てるか（フラット・キューブ）、個数を2個にするか3個にするかで総熱量をコントロールする。
- **ヒートマネジメントシステム（HMD）とアルミ直炭の運用差**:
  - **HMD（ロータス等）**: 上蓋（リッド）のベントスリットの開閉で内部の空気対流と保温・放熱をコントロール。炭の追加や位置替えもHMD内で行うため、アルミへの灰落としや破れのリスクが少ない。
  - **アルミ直炭**: アルミホイルの上に直接炭を載せるスタイル。灰を落とす「灰払い」や、アルミの穴を塞がない位置への炭移動が重要になる。
- **「吸い（テイスティング / 呼び水）」の役割**:
  - 炭を交換・移動させた直後は、葉に熱が馴染むまで少し間がある。
  - スタッフはホースで1〜2口吸い（テスト吸い）、煙の量感、温度、焦げ付き（いがらっぽさ）がないかを確認する。
  - 吸うこと自体は「炭へ空気を送る呼び水」および「状態確認」であり、**「吸い込む行為そのもので冷えた一台を適温まで加熱復元する」ことは物理的にあり得ない**。
  - むしろ過度な吸い（過剰なテスト吸引）は、客への提供前にフレーバーを消費し、はじめの酸欠・疲労を招く。

### 2-2. ゲームモデルへの落とし込み指針
- **役割の明確な逆転**:
  - **熱の復元・維持**: 100%「炭交換（個数・質・配置）」が担う。
  - **吸いの役割**: 「温度を稼ぐアクション」から、「仕上がり確認（テイスティング）と微調整・提出」へ移行する。
- **数値の扱い（疑似精密の排除）**:
  - 「0.5秒」「1ミリ」のような疑似精密な数値は排除し、「大・中・小」「適正・過剰・不足」などの段階的・直感的なモデルとする。
  - 確信のない実務詳細（特定メーカーのHMD開閉による厳密な熱伝導率など）は「要確認」として扱う。

## 3. 全章共通モデル案の比較（候補3案）

全章（第1章・第2章・第3章の大会、日常の自主練、まかない練習）で共通に使える設計案を3つ提示する。

### 案A: 【推奨】「炭交換で目標到達温度を決定 ＋ 吸いは確認＆微調整」モデル
- **概要**:
  - 調整に入ると、まず「炭の交換・配置」を行う。交換した炭の個数・配置（外寄り／標準／内寄り）によって、その調整後のベース温度がほぼ決定される。
  - その後の吸いは「針を止めて温度を激変させる」のではなく、キープを中心としたテイスティング（1〜2回の確認吸い）とし、針が中央ジャストなら狙い通りの味を引き出せ、過度な吸いは葉にダメージを与えるのみとする。
- **炭交換の条件**: 提供後または前回の調整から約20分経過（大会ROUND 3・4、練習調整）。
- **所要時間**: 短縮（炭交換選択＋必要に応じた簡易炭焼き＋1口の確認吸いで約15〜20秒）。
- **回数**: 炭交換1回、確認吸い1〜2回（3回以上は過剰吸引ペナルティ）。
- **温度変化**:
  - 炭交換直後: 選択した個数と配置に応じた適正量が一気に戻る（例: 2個交換・標準配置で低下分がジャスト復元、3個・内寄りは過熱傾向、1個はぬるい）。
  - 吸い時: 吸いによる温度変動はごく微小（±わずかな補正）。上げ吸いによる無理な温度復元は不可。
- **利点**:
  - 実店舗の「炭で温度を作り、吸いで味を確かめる」リアリティと完全に一致する。
  - アクションの理不尽なミスによる大事故が減り、炭のマネジメントという戦略性が際立つ。
- **懸念**:
  - 吸い出し（ROUND 2）と調整（ROUND 3・4）で針ダイヤルの意味合いが変わり、プレイヤーへのチュートリアルが必要。
- **変更が必要なファイル**:
  - `remake/js/craft/pull.js`: 調整モード（`care`）時の `actionAt()` の delta を微小化し、上げ吸いの急激な温度上昇を制限。
  - `remake/js/craft/pull.js`: `prepareCoals()` に配置（外・中・内）の選択肢を追加。
  - `remake/js/craft/conditions.js`: 炭交換後の復元計算式を「個数×配置×焼け具合」の一括決定型へ調整。

### 案B: 【臨場感重視】「炭の灰落とし＆ローテーション作業 ＋ 呼び水吸い」モデル
- **概要**:
  - 炭交換を作業台上のインタラクティブな工程として深掘りする。
  - 「古い炭の灰をトングで払う」「新炭を投入する」「炭の位置をローテーションする」操作を視覚的に行い、炭の状態を整える。
  - 吸いは「呼び水（パフ）」と「吹き返し（パージ：過熱時の熱気抜き）」の2種類から選択し、温度を微調整して完了する。
- **炭交換の条件**: 調整フェーズ開始時。
- **所要時間**: 中程度（炭のトング操作と配置＋パフ/パージで約25〜35秒）。
- **回数**: 炭操作1サイクル、パフ/パージ1〜2回。
- **温度変化**:
  - 灰落としと新炭投入により安定した燃焼温度へ移行。
  - 「パージ（吹き返し）」を選ぶと、ボウル内の余分な熱気を逃がして温度が少し下がる。
- **利点**:
  - シーシャ専門店のスタッフとしての本格的な職人感（トングさばき・灰落とし・パージ）がゲーム内で体験できる。
- **懸念**:
  - トング操作や灰落としの新規UI/アニメーション実装が必要となり、開発規模・検証工数が大きくなる。
- **変更が必要なファイル**:
  - `remake/js/craft/heat_view.js` / 新規 `care_view.js`: 炭の灰落とし・トング操作UIの実装。
  - `remake/js/craft/pull.js`: パージ（吹き返し）アクションと専用SE・演出の追加。
  - `remake/js/craft/session.js`: 新規工程ステップの登録とアセット先読み。

---

### 案C: 【最小改修型】「炭交換による確定復元 ＋ 吸いは温度維持（キープ）のみ」モデル
- **概要**:
  - 現行の「個数選択 → 炭焼きミニゲーム → ダイヤル吸い」のUI構造を一切変えず、パラメータと判定ロジックのみを修正する。
  - 炭交換によってのみ温度が回復する。交換個数が適正（2個など）なら適温中央に戻り、少なければぬるく、多すぎれば過熱する。
  - ダイヤルゲームでの「上げ吸い」を廃止（または微増にとどめ）、吸いは「キープ（維持）」と「下げ吸い（冷ます）」だけを有効にする。
- **炭交換の条件**: 調整フェーズ開始時（現行通り）。
- **所要時間**: 現行と同等（約20〜30秒）。
- **回数**: 炭交換1回、吸い1〜2回（現行の `min: 1, safe: 2` を維持）。
- **温度変化**:
  - 炭交換時に復元熱量が確定加算される。
  - ダイヤル吸いでは「キープ」で現状の温度を保ったまま提出するか、「下げ吸い」で少し冷ますことしかできず、吸いで温度を上げることはできない。
- **利点**:
  - 既存のUI、アセット、テストスイートをほぼそのまま再利用でき、破綻やデグレのリスクが極めて低い。
  - 「吸いだけで温度を完全復元できてしまう」というIssue #1081の直接の課題を最速で解消できる。
- **懸念**:
  - 炭の個数選択（0/1/2/3個）が「正解か不正解か」の択一になりやすく、ゲームプレイとしての駆け引きがやや淡白。
- **変更が必要なファイル**:
  - `remake/js/craft/pull.js`: `MODES.care` 実行時に `ZONES` の上げ吸い効果を無効化または大幅縮小（`delta: 0.02` 等）。
  - `remake/js/craft/pull.js`: 炭交換個数に応じた熱量係数（`COAL_HEAT`）を、低下分（-0.075）を相殺する適正カーブに再調整。
