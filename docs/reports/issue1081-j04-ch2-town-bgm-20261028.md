## 1. 概要と背景

第2章「才能の壁」の舞台となる隣町・**柚ヶ谷（ゆずがや / Widehanga）**は、第1章の地元・**橙須（とうす）**の気だるい下町・商店街とは対照的に、高層ビルがそびえ、広い交差点と大型ビジョンがあり、全国から選手が集まる洗練された都市です。

しかし現在のゲーム実装では、柚ヶ谷の街マップおよび各スポットにおいて、第1章の日常昼・マップ曲である **`kansetsu_shomei_to_black_coffee`（間接照明とブラックコーヒー）** がそのまま仮当てとして流用されています（`remake/js/chapters/ch2.js:31-32` にも「通常の日常・買物と同じ既存曲。J04の街用新曲選定とは分ける」と明記）。

本レポートでは、Issue #1081 J04 の指示に基づき以下を明らかにします：
1. 第2章の街（柚ヶ谷）の全場面で現在鳴っている曲と再生トリガー（ファイル:行付き一覧）
2. リポジトリ内の既存全音源（15曲）の現況、第2章街BGMへの転用可能性、他場面との重複状況
3. 柚ヶ谷の街として真に必要な新曲の需要（場面、雰囲気、テンポ、長さ、ループ仕様）
4. 過去の素材読み込み不具合（LFS未取得による画像読み込み障害など）との明確な峻別

### 【既存曲検討の結論】
リポジトリ内の既存全15曲は、すべて固有の機能・場面に1対1で紐付いており、**「第2章の柚ヶ谷の街マップにそのまま流用できる余剰の曲」は存在しません**。
既存曲の中で無理に別の曲（例: `tonari` や `bgm_trpg` など）を当てはめても、別の場所との重複やイメージの乖離が発生するため、**柚ヶ谷の街のための新曲導入が本質的な解決策**となります。

## 5. 音声読込不具合の調査と混同防止の整理

「第2章の街BGM変更」を議論・実施するにあたり、過去に発生した素材読み込みトラブルと混同しないよう、事実関係を明確に記録します。

### 5.1 実ファイルと manifest.json の整合性
- `remake/data/manifest.json` の `"bgm"` 配列に登録されている15ファイルは、すべてリポジトリ上の `assets/audio/bgm/` 直下に実在し、ファイルサイズも正常です（0バイトやプレースホルダは存在しません）。
- `remake/tools/build_manifest.py:390` により、`assets/audio/bgm/` 配下の `*.mp3` および `*.bgm` は自動走査されて漏れなく登録されています。
- `remake/js/core/data.js:316-320` の `bgmUrl` 関数は、渡されたキー名に対して `.bgm` → `.mp3` の順で `manifest.json` と照合してURLを返す設計となっており、暗号化BGMと通常MP3の透過的な再生が担保されています。

### 5.2 `audio.js` の `SYNTH_FALLBACK` について
- `remake/js/core/audio.js:511-519` には、実音源が存在しない場合の代用として `SYNTH_FALLBACK`（WebAudioによるシンセサイザー合成シーケンス）が定義されています：
  ```javascript
  const SYNTH_FALLBACK = {
    bgm_tournament_edm: "battle",
    bgm_tournament_craft: "battle",
    bgm_tournament_wait: "tension",
    bgm_continue_urgent: "panic",
    bgm_result_emotional: "calm",
    bgm_map: "calm",
    bgm_rival_shop: "calm",
  };
  ```
- ここにある `bgm_map` や `bgm_rival_shop` は実ファイルが未制作のスタブ用キーですが、現行のゲーム進行コード（`ch2.js` や `calendar.js`）ではこれらのキーを呼ばず、直接 `kansetsu_shomei_to_black_coffee` などの実在曲キーをハードコードして再生しています。
- したがって、「キーが見つからずシンセ合成に落ちる」「曲が再生されずエラーになる」といった読込不具合は**発生していません**。

### 5.3 過去の不具合（画像LFSポインタ等）との峻別
- Issue #1044 / #1081 A02 などで報告されていた「室内を読み込めませんでした」という画面停止は、Git LFS の実体画像（`bg_yuzugaya_kumicho.webp` 等）が未取得の131バイトポインタのまま配信され、ブラウザの画像デコード（`imageReady`）が失敗したことによる**画像素材の障害**でした。
- 音声・BGMシステムにおいては、同様のポインタ配信や読み込みエラーは発生しておらず、現在第2章で第1章の曲が鳴っているのは不具合ではなく、**「仕様・選定が未完了のため既存曲が指定されている」**という純粋なアセット選定・割り当ての課題です。

## 6. まとめと今後の対応提案

1. **現状の結論**:
   - 第2章の柚ヶ谷の街（昼・夜マップ、および各店舗・屋外イベント）は、現在すべて第1章の日常曲 **`kansetsu_shomei_to_black_coffee`** が鳴っており、既存の別曲を流用しても他場面との重複を招くため、**柚ヶ谷用の新曲追加が最も自然かつ効果的**です。
2. **推奨される最小改修（1曲の導入）**:
   - オーナーが **「柚ヶ谷・昼の街マップBGM」**（都会的チルホップ、約88 BPM、シームレスループ）を1曲選定・生成する。
   - `assets/audio/bgm/bgm_ch2_city.bgm`（または `.mp3`）として保存。
   - `build_manifest.py --audio-only` を実行して `manifest.json` に登録。
   - `remake/js/chapters/ch2.js:32` の `CITY_BGM` をそのキー（例: `"bgm_ch2_city"`）に差し替える。
   - これだけで、第2章の初日下見・配達・自由行動の昼マップがすべて新曲に切り替わり、第1章との明確な世界観の差別化が完了します。
3. **将来的な発展（夜マップ・店舗曲）**:
   - 余裕があれば「柚ヶ谷・夜マップBGM」（切ないシンセウェイヴ/ダウンテンポ）を導入し、`timeOfDay() === "night"` で切り替え可能にする。
   - さらに店舗固有の店内BGM（MELTY PUFF、神崎煙草店、零-ZERO-）を順次追加していく構成が理想的です。
