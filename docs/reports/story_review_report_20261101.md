## 1. まとめ

1. **土台は両方の目線で強い**。「炭は落ちる。店の格が出るのは落ちたあと」「最後の炭替えで客の帰る時間を見る」「炭、一つ余らせたな／……離したやつです」のような現場の手触りは、作れる人ほど刺さる。名前を隠しても誰の台詞か分かる口調は、ライト層がキャラを覚える助けになっている。
2. **作れる人が一番冷めるのは、温度と味の話が画面の表示や現実と逆になっている箇所**（みんとのミント、アダムのダブルアップル、REIの林檎味、ブラストミントの「重さ」、詰め方の説明）。それに、**吸い口・年齢確認・ヤニクラといった店の基本**が抜けているところ。
3. **ライト層が一番損をしているのは、山場の一行が抜けている、またはコードの差し替えで消えている箇所**。第2章の「味が消える瞬間」、ダブルアップル事件の重み、第4章決勝が成績表の文に差し替わる点、水と煙の説明が新規プレイで流れない点がこれにあたる。

## 4. 残したい良い場面（変えないで）

## 6. 作者判断が要る点（主なもの）

ゲームのルールや設定に関わるので、書き換え案ではなく判断を仰ぐもの。

1. **「下げ吸い」の説明が現実と逆**（付録B）: 用語集の「長く強く吸えば熱が落ち着く」に対し、現実には強く長く吸うほど炭に空気が入り熱は上がる。あげはの「ズボー」（一気に深く吸って熱を上げる）とも衝突している。説明を「ゆっくり浅く、間を空けて吸う」に寄せるか。
2. **神崎の「トングは根元を持て」**（付録E）: ピンセット型のトングは、根元を持つほど先端の挟む力が弱くなる。現場では「短く持つ」「炭の真ん中を深く挟む」と言う。意図の確認。
3. **神崎の「炭を一つ抜く」はゲームで再現できない**（付録E）: 制作は三角3個が基本で、2個にする手段がない。0分立ち上げも、♥1で「やってみなせえ」と言われるのに、解放は♥5（付録F）。
4. **0分立ち上げの描写**（F-3・F-4）: 二口で、蒸らした時と同じ濃さになっている。現実は最初は煙が薄く、十口ほど吸い続けて熱を引き込む。途中でやめると焦げる理由（最初から火を強めに置く）も一言ほしい。
5. **嗅覚の扱い**（付録E）: 第2章では焦げた革の匂いまで嗅げているのに、第3章のダブルアップル事件は香りまで分からないことが前提になる。第2章の終わりに「苺の香りまで、少し遠い」の一行を置くか。
6. **第4章の結果モーダルが発表の溜めを先に割る**（付録H）: 順位を見せた後にパッキーの沈黙→「勝者は……」が流れる。
7. **全国大会に「客」が説明なしで出る**（付録G）: 審査員以外の試喫者がいるルールにするか。
8. **バイトの能力値の配分**（付録J）: 本文が「良くない」と描く対応の方が多く上がる回がある。
9. **はじめ→各ヒロインの敬語の段階**（前回C3・付録C・G・I・J）: ましろ・みんと・あげは・サメちゃん、それぞれいつタメ口になるか決める。
10. **博士の持ちネタ「作ったの、俺だもん」**（前回C5・付録C・H）: 固定事項「博士は私」に、機材自慢の時だけの例外を一行足すか。
11. **素焼きの縁の色**（付録D）: 実物の素焼きは飴色〜焦げ茶に育つのが普通で、葉の色（紫・緑）で縁が染まることはまずない。香りで見分ける描写に寄せるか。
12. **「店の匂い」モチーフの回数**（付録C・J）: 第1章で、なるの「匂いだけ残ってんだよな」とみんとの幻臭が重なる。ランダムのバイト回でも「それがtonariの匂い」と言葉で説明している。
13. **ラベンダーの「眠った時の体力回復が増える」**（付録B、心得の盤・未公開）: ニコチンを含む嗜好品の寝る前の効能を、数値で保証する形になる。
14. **`ending_normal[5]`「明日から、店はお前が回せ」**（付録H）: 一日の留守番か、店の引き継ぎか。ライト層には「独立をやめてtonariを継ぐ」とも読める。

### 作者判断が要る点（あれば）
- **「下げ吸い」と「ズボー」の吸い方が衝突している（ゲームのルールと現実のずれ）** — 用語集の吸い出しは「長く強く吸えば熱が落ち着く（下げ吸い）」。一方 `lesson_ageha_zuboo[6][7]` の「ズボー」は「一気に深く」「頬をへこませて、長く吸い込んだ」で熱が上がり、同じ説明の吸い方で効果が逆になっている。現実では、強く・長く吸うほど炭に空気が入って赤くなり熱は上がる。熱を下げる手は、炭を縁へずらす・HMDの蓋を開ける・炭を外す・吸う間を空けるなど。案: (a) 下げ吸いの説明を「ゆっくり浅く、間を空けて吸う」に寄せる、(b) 台詞側の最小修正として zuboo[7] を「あげはさんが頬をへこませて、一気に強く吸い込んだ。HMDの中で、炭がぐっと赤くなる。」にする（42字）。
- **就寝前シーシャの回復効果** — `lesson_tsumugi_lavender` の台詞自体は主観で問題ない。ただ、心得の盤の効果「夜、家シーシャにラベンダーを入れると、眠った時の体力の回復が増える」は、ニコチンを含む嗜好品の寝る前の効能を数値で保証する形になる。健康表現を慎重にしている方針（K14）と並べると、効果を「気持ちが落ち着く」程度に留めるかどうか判断が要る。
- **大会のやり直しのたびに流れる固定台詞** — 第1章の大会は、ゲームオーバーから再挑戦するたびに arrival・opening・rule_recap（パッキー約25行）を最初から流す（既読SKIPはある）。2回目以降は開会を短縮版にする（例: opening は[3][4][26][27]だけ）かどうか。

- **内省（growth_reflection）を接続するとき** — 5か所とも「（ここまでに学んだこと、ひとつずつ思い出してみる）」「思い出したことが、胸の奥で小さな火になっていく。」が同じ文。接続時に場所ごとの一行を足すか（例: 観音堂「線香の煙が、まっすぐ上へ伸びていく。」）。現状は未接続なので急がない。

### 作者判断が要る点
- **耐熱データと台詞のずれ**: `data/flavors.json` ではドラゴンフルーツの heat_tolerance が 0.9 で、ゲーム内ガイドの区分は「標準温度帯」。一方で神崎は「火を入れても崩れねえ」（second[28]）「火に強え」（bond_finale[17]）と言う。ホワイトグミベアも 0.9 の標準なのに、あげはは「白は熱いの苦手」（gummy[9]）と言う。ガイドを見たプレイヤーには矛盾に見える。データを台詞に合わせる（ドラゴンフルーツを 1.05 以上、白グミを 0.88 以下）か、台詞を「標準だが、越えたときの崩れ方が穏やか／急」程度に寄せるか。
- **0分の実演と解放の間**: ch2_kumicho_second（♥1）で「あんちゃんも一度やってみなせえ」[34] と言われるのに、実際に00:00で始められるのは ♥5 の `lesson_kumicho_zero` 以降。直後にタイマーで試すと弾かれる。台詞を「いつか、あんちゃんにも仕込んでやりやす。……覚えときゃ、損はねえ」にして後の教えにつなぐか、実演の時点で解放するか。
- **3人の締めくくりが同じ型**: あげは・神崎・REIの bond_finale は、どれも「奥から包みを持ってくる→長年同じ葉を詰めた素焼き→香りが染みている→『そんな大事なもの』」の流れ。全員を最大まで上げると3回同じ場面を見ることになる。贈り物の設計は残すとして、はじめの受け方だけでも変えると印象が分かれる。例: 神崎 bond_finale[7]「そんな大事なもの……」→「……俺、両手で受け取った方がいいですよね」（直後の「こいつは盃の代わりでさ」が生きる）。

### 総評
- プロ目線: 炭替えの見極め、炭を端へ寄せる、灰を落としてすぐ戻さない、といった手つきはだいたい自然です。ヴォルクの「強い葉は雑な火を隠す」、スティーブの「タイマーを置く」の理屈は、経験者が読んでも頷けます。ダブルアップル事件は、アニスとリコリスという正史を守ったまま「スイカやマンゴーと混ぜても芯が消えない」まで書けていて本物らしい。弱いのは次の3点です。①課題のチョコが「熱に弱く、焦げるとすぐ苦くなる葉」だと一度も語られないので、本番で炭に手が伸びる怖さが立たない。②ミントを「重い煙」と書いている。③閉店作業の「灰皿」など、小さな手つきの不足。

### 設定・事実の誤り
- **第3章の課題が資料と実装で食い違っている**: 現物は `ch3_main / ch3_registration[6]`「ドバジ チョコレートを4g以上」、`ch3_tournament_day[1]`「課題はチョコレート！」、`remake/js/chapters/ch3-tournament.js` 184行目のコメント（オーナー決定 2026-10-28）。一方、正本の `docs/gameplay_agent_reference.md`「大会名・大会システム」は「ch3=自由（ましろと作戦会議3択）」、`brand/story_and_structure.md` の大会表は「自由、ましろと作戦会議」のまま。直す先は2つの資料（台詞は正しい）。
- **ブラストミントの「重さ」がデータと逆**: 台詞は `ch3_volk_first[27][28][29][50]`・`ch3_volk_second[8][12]` で「重く冷たい煙」「ブラストミントの重さ」。データは `data/flavors.json` の nightside_blast_mint が smoke_weight 0.7・「鋭い立ち上がり」で、比べられるナイトサイドのアールグレイは 1.05。直す先は台詞（指摘#11）。ヴォルクの火力で重く見せる意図なら、`second[3]`「重さは熱で支える」のように熱の話として書き分ける。

### 作者判断が要る点
- **全国大会の「客」が誰なのか**: `ch3_national_adjustment[12][13]` と `ch3-verdict.js` の customerLine に「客」が出てくるが、`ch3_tournament_day` の紹介は審査員3人だけで、第1・2章の大会にもcustomer話者はいない。ライト層は「誰が吸っているの？」、経験者は「審査員以外が試喫するルール？」と迷う。大会のルールを足すことになるので判断を仰ぎたい。案: `tournament_day[2]` の後にパッキーの一行→`第参条ッ！ 各台には客席から試喫の方が一人ずつ！ 吸い心地の声も審査の材料だッ！`。逆に「客」を審査員に置き換えるなら、`ch3-verdict.js` の文も直す必要がある。
- **置換キーの同期**: `ch3_national_adjustment` と `ch3_national_result` の多くの行は、`remake/js/chapters/ch3-verdict.js` が「文の完全一致」で差し替えている（例: `君の炭は動かなかった。助言は、本当だよ`、`客の一口を待てました。どっちも急がず、俺の一台を選べた`、`このくらいなら、もう少し吸ってたい`、adjustment[1][2][4][5][10][11][12][14][17]）。さらに作戦の一行は、正規表現 `/俺の一台を選べた|俺が選べた/` の位置に挿入される。どれかの文を変えるときは、JSの表も同時に変える必要がある（指摘#14②はこの末尾を残してある）。
- **はじめの口調（指摘#3）**: 事件のあとの気まずさから、わざと敬語にしているなら意図は分かる。ただ、それなら `ch3_taste_return[8]`「……ただいま」を境にタメ口へ戻す、といった切り替えを見せた方が伝わる。今は回復後の `ch3_abyss_recovery` や `ch3_kuze_mashiro_tea_tin` も敬語で、意図が読み取れない。
- **自動整形の「、……」**: text-style の規則3は「続きが独立した文なら『。……』のまま」だが、話題が変わる文まで「、……」になっている。`ch3_tournament_day[13]`「よかった、……僕も忘れてないよ」、`ch3_kuze_first[41]`「昔なじみなんだ、……続きは、また今度」（[39]とも重複）、`ch3_national_defeat[2]`「聞くよ、……まず、お水」、`ch3_volk_after_ch3[6]`「一番役に立つ、……今日の体温は」。手で「。……」に戻しても、tidyがまた変えるおそれがあるので、行を分けるか、ツールの判定を見直すか判断がほしい。
- **久世の事前の忠告**: `ch3_outings / ch3_outing_enmaku_answer[3]`「大会の日は、僕の一口に引っぱられないでね」は、任意の外出で本番の仕掛けをほぼ予告している。「親切も勝ちたい気持ちも本物」という人物像には合うが、読んだ人には本番の豹変（「あはっ、動いた！」）の驚きが弱まる。残すか、`大会の日は、最初の一口だけで決めないでね` 程度にぼかすか。
- **指摘#5の新しい小さな嘘**: 会場で「狙いです」と答える一行は、主人公に新しい嘘を一つ足す案。前夜に打ち明ける嘘はダブルアップル事件のまま変えない前提。

### 作者判断が要る点
- **C7（告白直後に「やっぱり友達」）への意見**: ひよりの分は解消済み。友達の選択肢そのものは残すのが正本（HF04〜06、恋人成立を価値の条件にしない）に合う。直すのは「選択肢の前にはじめが好意を言い切っている文」だけでよい（#1）。告白はヒロインが恋愛寄りに答えを重ねた時にしか起きないので、選択肢は「最後に踏みとどまる」意味になる。踏みとどまる側にも一言の誠実さ（例: サメちゃん reject[1][2] のような説明）を他の人の分にも置くか、つむぎのように何も言わずに流すかは好みで決めてよい。つむぎは「先回りして振る」より「いつも通りに返して、つむぎが言葉をしまう」方が、彼女の静けさに合うと考える（#1の案）。
- **C14（凛の同文リフレイン）への意見**: 現行の `confession_rin_accept`・`lover_rin_lv1〜lv5` に「即答か。モルモットのくせに」「在庫で一番」「非売品」はもう無く、指摘は解消している。残っているのはLIMEの `declineLines.rin`「サンプルのくせに生意気」と `morningStamp.rin`「モルモットくん」で、決め台詞として自然。C14は閉じてよい。代わりに、恋人編のどこか1か所で意図的に回収すると締まる（#8の「同意書、いりますか」）。
- **はじめの敬語の段階**: あげはは恋人lv1で「敬語もナシ」と切り替わる（良い演出）。ところが `shuraba_ageha[4]`・`shuraba_talk_ageha[4][5]` では「あげはさん」と敬語に戻っている。距離の演出なら、あげはに気づかせると効く（例: あげは「……『さん』、戻ってんじゃん。……今日は、それでいいけど」）。意図しないものなら「あげは」とタメ口に戻す。サメちゃんには恋人編（告白・lv1〜5・前夜デート・gameday・anniversary）で敬語なのに、`remake/data/lover.json` の dates.samechan.optA「今日は、お互いの話をゆっくりしよう」、privateAccount「朝から声を聞けて嬉しい」、`friends.json` の返信（寄るよ／今度見に行く等）はタメ口。友人の方が恋人よりくだけて見えるので、どちらに揃えるか、どこかで切り替えの一場面を作るかを決めてほしい。
- **前夜デートの章別化**（#2）: 条件分岐を足すのは台本側だけで済む（既存の `tournament_finished`）。第4章を全員分書き下ろすか、冒頭数行だけ差し替えるかは作業量で判断してほしい。第3章の前夜デートを読んだかどうかで呼び返しを入れる案は、保存フラグが増えるので避け、単独で成り立つ文にした。
- **ましろのシガーリーフの蒸らし**: `lover_mashiro_lv2[7][8]`「じわって熱を通すの。急ぐと、えぐみが出ちゃう」「最初の蒸らしを、長めに取る感じか」→「さすが」。ダーク／シガーの手順は #1126 で確定待ちなので、ましろが肯定する形で手順を断定している点は、確定後に照合する（`docs/shisha_reference.md` §5）。
- **みんとの「傷だらけのトング」**（`lover_minto_lv3[1]`）: 実家の喫茶店のトングを今も店で使う、という良い小道具。喫茶店でトングをどう使っていたか（氷や炭火焙煎など）を一言足すと、シーシャの炭ばさみへの繋がりが生まれる。ただし新しい設定の追加になるので、採否は作者が決める。
- **「ヤニクラ」の冗談**（#13）: ニコチンに触れる笑いを避ける方針なら、「もうお腹いっぱい？ｗ」にする。
