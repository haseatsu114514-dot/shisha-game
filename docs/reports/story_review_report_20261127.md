# ストーリー添削レポート（継承・バトン・帰る場所・つむぎの伏線）2026-11-27

オーナー依頼「このゲームのストーリー全体を添削して欲しい。すみさんからはじめへ、はじめからつむぎへといった感じで最終章でバトンが渡るとこにエモさをだしたいし、やっぱりはじめに帰ってくる安心感や感動を入れたい。あとは継承もテーマとして扱いたくて、すみさんや会長の過去の話も途中とかで挟んだり、つむぎが働くって言い出すのが唐突に感じないように伏線を途中にいれたりもしていきたい」。

**範囲**: 第1〜5章と終幕を、依頼の4つの線（バトン／はじめに帰る／継承とスミさん・会長の過去／つむぎの応募の伏線）に関わる場面に絞って、再生順に読んだ。全場面の総点検ではない。2026-11-24 の添削（N1〜N10・STK39〜49）と、#4288 で入れた第5章冒頭（STK50〜64）は再指摘しない。台詞案は全角48字以内で確かめてある。

---

## 1. 変えないでほしい所

1. **第1章冒頭と終幕の円環**: 鉄仮面さんの「……今日の、良かったよ」が終幕で名乗りになる。「いつか俺にも、自分の店があったら」が、賄いで店の名前を書きかけて止める所へ着く。作品の背骨なので崩さない。
2. **会長「……懐かしい店の味だ。人が帰ってくる店の」（第1章の大会後）**: 「帰ってくる店」の主題の種。以下の提案の多くは、この一言の回収に向かう。
3. **第1章の戸締まりの夜（`ch1_sumi_closing`）**: スミさん「炭を扱う前に、息を吐くようになったな」「最初の頃は息を止めて置いてた。トングが震えてたぞ」「暇だったからな」「戸締まり、頼む。明日の朝、返せ」。手のひらの鍵束が、思ったより重い。バトンを形にする材料が、もう第1章にそろっている。
4. **第2章の水（`ch2_tsumugi_color`）**: つむぎ「はじめさん、いつも言ってますよね。客の顔を見るって」「今日は、私が、はじめさんの顔を見てました」。受け売りの逆流の最初で、必ず読む場面にある。
5. **第3章帰郷（`ch3_tsumugi_result`・必読）**: 「次の絵は、シーシャを作る手を描きたいです」「いつか、自分の手も」と、スミさん「ボウルの洗い方から見てけ」「見るだけならな」。応募の伏線の芯はここにある。
6. **第2章の沈黙（`ch2_sumi_silence`）**: 終電を逃した鉄仮面さんが、スミさんの灯りの下にいる。会長の「終電を逃した晩に、古い小さな店へ入った」（第4章）とそのまま重なる。
7. **第4章のスミさんとシェイク**: 名も知らない店員の一台が、人を作る側へ回す。継承を「教えた」形でなく「渡ってしまった」形で書いている。

## 2. 全体の見立て

- **継承は「上から受け取る」線が厚く、「下へ渡す」線と「スミさんも受け取った」線が薄い。** なる・スティーブ・ヴォルクの手、名前を塗って書き戻すノート、「混ざったままで、俺だった」までの流れは強い。一方でスミさんの手前が空白なので、スミさんが「最初の人」に見える。つむぎの「私で三人目です」も、そこで数え終わってしまう。
- **バトンの場面が散っていて、手で渡す物がない。** スミさん→はじめは、第4章末の店長の任命と終幕の「tonariは任せた」。はじめ→つむぎは、三人目・千須への返事・シフト表。どれも言葉で渡している。第1章の鍵束と「明日の朝、返せ」が、そのまま使える。
- **「帰ってくる」が一点に結ばれていない。** 会長の第1章の一言、各店の「おかえり」、第5章でスミさんが言う「おかえり」が別々にある。視点がはじめへ戻る瞬間と、終幕の「おかえり」の受け渡しに結ぶと、安心感が出る。
- **つむぎの応募は、第4章が空いている。** 必ず読む流れでは、第2章の水 → 第3章の「いつか、自分の手も」のあと、第4章で何も起きずに第5章の面接になる。第4章でボウルを洗い始めた一行があれば、面接は「やっと言えた」に変わる。
- **会長の過去は第2・3章の本編に無い。** 第1・2章で各地の店に偶然居合わせる任意の場面（`roam_sensu_*`）にだけある。スミさんの過去も、第2・3章では「誰かの話」の形だけ。継承を章の途中で一度立ち上げる場所が要る。

## 4. 設定まわりの注意（canon）

- **判断A（tonari の前身とじいさん）は新しい設定。** 採る場合は、`data/characters.json` の sumi・sensu の `background_secret` と、`brand/story_and_structure.md`（はじめと店の人たち・二組のライバル・第4章）へ先に書く。tonari が「老舗」（舞台となる街）であることと、「客の隣に座れる店にしたかった」（賄い）とは矛盾しない。スミさんが継いで名前を変えた形になる。
- 第1章の SMS01（スミさんの大会歴を第4章の到着日まで明かさない）には触れない。#4・#8 は大会の話を含まない。
- 第2章の「スミさんは言葉が見つからない」設計（`ch2_sumi_silence`）は崩さない。#8 は助言ではなく、事実を一言だけ認める形にとどめる。
- 「おかえり」は各店の挨拶でも多く使われている（みんと・夜・ましろほか）。#3 は tonari の中だけで、スミさんとはじめの間に限る。

## 5. オーナー判断が要る点

1. **判断A**: tonari の前身を、スミさんが若い頃に働いたじいさんの店にするか。会長が救われた店もここにするか。採らない場合は、#4・#8・#9 と台詞案Aの「四人目」を外し、会長の店は名前のない店のままにする。
2. 終幕の鏡写し（#1）を『表さん』の後ろに続けるか、独立した短い場面にするか（推奨は続ける。終幕を何度も閉じない STK27 に合わせる）。
3. 会長の第3章の昔話（#7）を、全国大会の夜の新しい短い会話にするか、既存の `ch3_national_result` の末尾に足すか。
