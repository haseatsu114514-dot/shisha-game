- 選別ページ: https://haseatsu114514-dot.github.io/shisha-game/remake/fortune-trivia-selection.html （main へのマージ後。カードに系統と「AI推奨」「AI次点」の印が付き、絞り込みもできます）
- データの正本: `remake/data/fortune-trivia.json`（本編に入っている既存候補）と `remake/data/fortune-trivia-selection.json`（選別用の追加候補・系統・AI一次選別）。この一覧はそこから作った写しです。
- 対象: 好感度見直し（#2750・PR #2765）後の好感度名簿19人（`remake/js/core/state.js` の `AFFINITY_CHARACTERS`）。

## 決定ルール（オーナー確定・2026-11-07）

- 占い師（占いオババ）は相手に会ったことがない。会わないと分からないこと（見た目・容姿・個人的な詳細）を言わない。
- 占いは「当たってそう」な言い回しで、4系統: ①性格論「こういう性格の人だよ」②出来事の推測「こういうことあるんじゃないかな」③言いそうなこと「こういうこと言ってなかったかい」④その人への接し方（攻略法）。
- いずれも占い師の推測・性格論として出し、具体化は、はじめが対象キャラの具体的な様子を連想する側（はじめの心の声）で担う。占い師の台詞とはじめの連想は1組のデータ（`teller` と `reaction`）として持つ。
- もう一歩踏み込んだ占い（例: 生き物を飼っていそう）は可。例: `samechan_21` は占い師が「肌身離さん相棒」とだけ言い、はじめがコロちゃんだと気づく。
- 従来どおり、重大な秘密・本名・恋愛の結末・旧名は含めない。吹き出し1枚・文末に句点なし。

## 削除の基準（今回この基準で削除した）

| 分類 | 内容 | 例 |
|---|---|---|
| 外見 | 見た目・身なり・髪・装身具・体格・声・会えば見える持ち物を言う／前提にする | 帽子、メガネ、三つ編み、ツノの飾り、パペットの王さま、タイマー |
| 事実の言い当て | 会わないと分からない本人の具体を、事実として言う。過去の出来事（〜したことがある）、伝聞（〜そうだ／〜んだと）、店の中・身近な生き物・持ち物・物語で知る趣味を知っている前提の断定 | 店のクマのぬいぐるみ、猫の名前、サウナ通い、初めてのこたつ |
| 秘密 | 秘密・正体・重い過去に近い | 推しのグミの由来（通院の思い出） |
| 正史と矛盾 | 台詞データ（正史）と食い違う。はじめの連想が正史に無い出来事を記憶として言い切るものを含む | 絵文字の無いLIMEに「湯気の絵文字」、正史に無い「余り物のカレー」 |

性格の読み（〜な人だね）と推測（〜んじゃないかね）は、上の前提が無ければ残しました。推測の形でも、店の中・持ち物・好物・仕事の中身を知っている前提なら削除しています。仕事や作風の分野（菓子・香り・絵など）に寄せた読みは、占い師が「縁」から読める範囲として残しました。削除した候補の良い着想は、ルールに沿う形に書き換えて新規候補にしています（各候補の「書き換え元」）。削除したIDは欠番として残し、再利用しません。

候補はすべて、作成者と別の監査（第1〜2章の11人と第3〜4章の8人の2本、台詞データと進行コードで照合）にかけ、指摘を反映しました。

## 一次選別の観点

1. ルールに合う（上の削除基準に当たらない）ことを前提にする。
2. 「当たってそう」さ: 誰にでも当てはまりそうでいて、そのキャラの話に聞こえる。
3. はじめの連想の確かさ: 正史と食い違わず、そのキャラらしい具体が浮かぶ。占いは、そのキャラと最初に会った直後から読める（配達・説明会・試煙会などで先に会う経路を含む）。はじめが「言ってた」と記憶で言い切る連想は、最初に会う場面で必ず聞く台詞に限り、それ以外は「〜しそうだ」の推量にした。
4. 系統のばらけ: 推奨5本に4系統をなるべく混ぜ、攻略法を1本以上入れる。
5. 重複を避ける: 同じモチーフ・同じ構図を推奨に並べない。
6. いつ読んでも成り立つ: 後の出来事や任意の場面（好感度の段階会話・寄り道・店での初回会話など）を知っている前提にしない。
7. 読後感: 秘密や重い過去に寄らず、相手に会いたくなる。
