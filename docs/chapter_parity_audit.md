# 第1章基準の完成度チェック（章・キャラの不足一覧）

確認日 2026-10-31・main `7825b06b`。オーナー「キャラによってLIMEがあったりなかったり統一性が弱い。第1章をベースに他の章も作りたいので、何が足りないかをリストアップしてほしい」への回答。コードとデータを読んで作った**現状の一覧**で、ゲームは変更していない。直したら該当行を消すか ✅ にする。

**作業はIssueで管理する**：親 [#2020](https://github.com/haseatsu114514-dot/shisha-game/issues/2020)（子 #2021〜#2036。構造 #2021、ましろ #2022、あげは #2023、恋人の再生 #2024、第1章ヒロイン #2025、未接続 #2026、第2章ライバル #2027、第3・4章ライバル #2028、授業 #2029、9000 #2030、大会 #2031、第2章日常 #2032、第5章 #2033、素材 #2034、実装の統一 #2035、資料の食い違い #2036）。

## 結論：ばらつきの原因は3つ

1. **第3〜5章が第1章の「日常の仕組み」に乗っていない。** 第1章と第2章は共通の日常ループ `runDaily()`（`remake/js/daily/calendar.js`）で動き、LIMEの受信箱・バイト・占い・スロット・天気・睡眠と風邪・家シーシャ・好感度・恋人LIME・締めくくりが自動で付く。第3〜5章は章ごとに作った場面カード式（`ch3-*.js`／`ch4*.js`／`ch5*.js`）で、これらがまとめて抜ける。**キャラのLIMEや好感度の差の大半もここから来る**（第3〜5章のコードには `gainAffinity` も恋人の段階更新もない）。
2. **第1章のキャラは「6段の会話＋LIME＋味の会話＋締めくくり＋専用ハガル」のフルセット、第2章以降のキャラは一部だけ。** 第2章のライバルは♥3で止まり、第3〜4章のライバルは好感度もLIMEもない。
3. **同じ機能が章ごとに別の書き方で作られている。** 訪問会話、LIME連絡先の付け方、大会、強制イベント、章の開始日がそれぞれ章ごとに違うので、「第1章をコピーして作る」ができない。
