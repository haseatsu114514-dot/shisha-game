# 隔離イベント試写モード

ゲーム起動後、開発者コンソールで使います。

```js
__remake.inspect.events("mashiro")    // IDを探す
__remake.rehearsal.open("イベントID")  // 会話を1行ずつ進めて選択肢を試す
__remake.rehearsal.close()            // 試写画面を閉じる
```

試写は `sandbox="allow-scripts"` の iframe 内で動作します。親ページのゲーム状態・localStorage・sessionStorage・イベントフックにアクセスせず、台詞と分岐のコピーだけを受け取ります。ゲーム本編のイベントエンジンは実行しません。

**再現するもの:** 台詞送り、選択肢、同一イベント内の `next` 分岐、`next_id` の行き先ID表示。

**再現しないもの:** 本物の立ち絵・背景・BGM・アニメーション、条件分岐・変数補間・フラグ更新、別イベントへの自動遷移、ゲームの進行。

本番演出の確認には通常プレイやブラウザテストが必要です。試写は台本の導線を短時間で点検するための機能です。
