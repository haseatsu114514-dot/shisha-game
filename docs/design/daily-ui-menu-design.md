## 0. 結論（先に要点）

1. **日常パートは「紙×ラベンダー＋琥珀」の明るい1路線に統一する**。Dr.fookah の店内画面（`shop.css`）の生成り `#f7f3ed` とラベンダー `#69497e` をそのまま基調にし、3色目は**琥珀 `#d8963f`**（炭の火・大会・火種・新しい話にだけ使う）。日常では黒×金を使わない。STATUS UP の通知も使わない（§1）。
2. **MENU は全画面・4タブ**（ステータス＝Lv・EXP・火種・3つの盤のゲージ／人間関係／持ち物／システム）。三角形のグラフ・五角形・今日タブ・次の一手・行動回数・記録は入れない（§4）。
3. **HUD は紙の板1枚にラベンダーの DAY 札**。行動回数なし。右上は緑の角丸四角の `LIME`（そのまま）と `MENU`（§2）。
4. **地図は「店のロゴ・在店の顔・店名」と「施設のシール風アイコン」を残す**。看板は案A（白い看板を整える）と案B（ラベンダーの板にロゴ窓）の2つ。`商店街を歩く` は無い機能なので置かない（§3）。
5. **会話ウインドウは「紙の窓」1案に絞る**。生成りの紙にラベンダーの名前札、本文は既存のゴシック（`Suien Gothic`）30px・2行。明朝の案は取り下げ（§5）。
6. **「シンプルすぎる」は画像生成で埋める**。板・会話窓・名前札とボタン・MENUの背景の4枚を生成し、九分割（nine-slice）で全画面に使う。プロンプトは作成済み・未生成（§6）。
7. **不具合**: 看板の店名が切れて見えたのは、ロゴ画像が読めなかった時の代替表示。折り返して窓に収めるよう修正済み（§A）。

## 5. 会話ウインドウ「紙の窓」（決定・DUI08。画板 03）

- 紙 1216×186px（左右32px・下22px）、角丸8px、ラベンダーの線1px、柔らかい影。上辺の20px下に薄いラベンダーの罫線1本。
- 名前: 紙の上辺から出る**ラベンダーの札**（白抜き19px/900・字間.14em）。地の文・心の声では札を出さない。

## 付録A. 直した不具合: 看板の店名が切れる

- 現象: `KEMURIKUS`・`PEPPERMIN`・`tonar` のように店名が途中で切れる。
- 原因: 看板は店のロゴ画像（`assets/ui/store_logos/*.webp`）を 82×46px の窓に表示し、**画像が読めなかった時だけ**店名の文字を同じ窓に出す（`store-logos.js` の `onerror`）。その代替表示が 15px・折り返しなしで、窓より長い店名が `overflow: hidden` で切れていた。撮影した環境は LFS の画像が未取得だったので代替表示になっていた。ロゴが読める通常の表示では切れない（ロゴ取得後に確認済み）。
- 修正（`remake/css/store-logos.css`）: 代替表示を 12px・行間1.15・折り返しありにし、長い店名を2行で窓に収める。ロゴの表示・看板の大きさ・判定は変えない。
- 確認: ロゴ取得後の通常表示と、ロゴの読み込みを遮断した代替表示の両方を 1280×800 で撮影。代替表示の5店で `scrollWidth == clientWidth`。`node remake/test/typography_css.mjs` OK。
