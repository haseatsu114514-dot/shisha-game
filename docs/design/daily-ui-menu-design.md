## 0. 結論（先に要点）

1. **いまのUIの弱さは「部品が画面ごとにバラバラで、置き場所にも理由がない」こと**。HUD・地図・店の選択・ショップ・スマホ・ダイアログが別々の見た目を持ち、MENU は6つの文字ボタンが並ぶだけで、ゲームの状況を何も映していない（§1）。
2. **デザイン言語を一つに決める**: 「墨紫の夜 × 真鍮の縁 × 薄い煙」。外枠だけ真鍮の豪華な枠、内側は軽い線（GUI31）。P5風の鋭い角は使わない（2026-10-24 オーナー決定）。書体は既存の `Suien Gothic` と会話の明朝のみ（#1352）。色は `base.css` の既存トークンに2色（真鍮の暗色・紙色）を足すだけ（§2）。
3. **MENU は「はじめの手帳」として、6つのタブを持つ全画面の覆いにする**: `今日` / `ステータス` / `人間関係` / `持ち物` / `記録` / `システム`。今の STATUS モーダル（3タブ）は `ステータス`・`人間関係`・`持ち物` へそのまま吸収し、HUDの五角形ボタンは「MENUをステータスタブで開く」近道にする（§5）。
4. **いちばん効くのは `今日` タブ**: 日付・天気・残り行動・大会までの日数と課題の葉・今夜の予定（LIMEの約束／固定イベント）・今日の定休日・次の一手。これはすべて**保存データにある値から組める**（新しいパラメータを足さない）。「次に何をすればいいか分からない」初見の人への答えになる（§5.1）。
5. **HUD は1枚の真鍮プレートにまとめ、残り行動を●○で常時見せる**。右上は `LIME` と `MENU` の2つだけ（§3）。
6. **地図の看板で店名が切れている（`KEMURIKUS`・`PEPPERMIN`・`tonar`）のは実機で再現した不具合**。看板の中身を「ロゴまたは顔＋店名1行（自動縮小）＋状態チップ」に組み直す（§4）。
7. **実装は4段階**。P0（看板の切れ・HUD・MENUの骨格と `今日` タブ）が半日〜1日。P1（STATUS統合・人間関係カード・持ち物）、P2（ショップ・店・スマホ・設定・セーブを共通部品へ）、P3（遷移の演出・効果音）。全部で PR 5〜6本（§11）。

## 2. 設計の軸（デザイン言語）

### 2.1 ことば: 「夜のラウンジの手帳」

- 日常パートは**落ち着いた夜のラウンジ**（master_spec #22「落ち着いた日常パート」）。大会パートの黒×ネオンとは分ける。
- MENU は、はじめが持ち歩く**手帳**。手帳の中に、今日の予定・自分の調子・会った人・持ち物・記録が綴じてある、という見立て。文字と小さな絵で成り立つので、画像生成に頼らず CSS/SVG だけで品質を出せる（#22「アセット不要の演出はコードで最高品質」）。
- P5のような鋭い角・斜めの帯は使わない（2026-10-24「このゲームにP5のパキッとしたトゲトゲは合わない」）。動くUIも最小限（2026-10-24「動くUIはまだ作らなくていい」）。

### 2.2 3つの層

| 層 | 中身 | 見た目の決まり |
|---|---|---|
| 常駐（HUD） | 日付プレート・LIME・MENU | 真鍮の縁の小さな板。場面の絵を隠さない。画面の四隅に寄せる |
| 場面 | 地図・店の中・ショップ・会話・家 | 場面の絵が主役。UIは**下か右**の一帯に寄せる。看板・選択肢・案内は同じ「板」部品 |
| 覆い | MENU・スマホ・ダイアログ・セーブ | 背景を暗く・少しぼかし、中央または全画面に板を置く。MENU だけ全画面、他は中央の板 |

### 2.3 色（`remake/css/base.css` の既存トークンを使う）

| 役割 | トークン | 値 | 使う場所 |
|---|---|---|---|
| 地 | `--ink` / `--ink-2` | `#0b0812` / `#151024` | 板の面・覆いの幕 |
| 板 | `--panel` | `rgba(16,12,28,.88)` | HUD・MENU・ダイアログの面 |
| 縁 | `--panel-edge` → **`--brass`（新）** | `#e8c27a` の38% → `#b8975a`（新・暗い真鍮） | 外枠。明るい金 `--gold` は見出し・選択中だけに限る |
| 文字 | `--text` / `--text-dim` | `#f4ede0` / `#b6aa96` | 本文 / 補足 |
| 強調 | `--gold` / `--gold-hi` | `#e8c27a` / `#ffe2a6` | 見出し・選択中・数字 |
| 紙（新） | **`--paper`** | `#f1e8d8` | ショップ・LIMEの白い面に使う**暖かい白**。純白をやめる |
| 意味色 | `--good` / `--danger` / `--amber` | 既存 | 体力の緑・赤・黄。好感度のピンク、能力5色（`--stat-*`）は既存のまま |

新しいトークンは `--brass` と `--paper` の2つだけ。能力色・調子の色・地図の役割色（GUI13・14）は変えない。

### 2.4 書体と大きさ（#1352 に従う）

- UI は `var(--font)`（`Suien Gothic` 500/700/900）。数字・金額も同じ。会話本文の明朝は会話の中だけ。
- 階層は4段で固定する: 見出し 22px/900 ・ 項目名 17px/700 ・ 本文 15px/500 ・ 補足 13px/700（12〜13pxは700以上）。12px未満は使わない。
- 大きな数字（DAY・金額）だけ 28〜36px/900。英字の見出し（`MENU`・`STATUS UP`）は 12〜13px/700・字間0.12em で小さく置く（PF26 で英字の見出しは好評）。

### 2.5 共通部品キット（これだけで全画面を組む）

| 部品 | 形 | 使う場所 |
|---|---|---|
| 板（panel） | 面 `--panel`・外枠1px `--brass`・四隅に小さな切り欠き（既存の `panel.webp` の九分割でも可）。内側の区切りは `--brass` の25%の線だけ（GUI31） | HUD・MENU・案内・ダイアログ |
| 札（plate） | 板の上辺から少し出る小さな見出し板。中に英字見出し＋日本語 | MENUのタブ名・地図の看板の店名・会話の名前札（既存） |
| ボタン | 高さ44px以上。通常＝面 `--ink-2`・枠 `--brass` 40%。選択中・主ボタン＝枠 `--gold`・文字 `--gold-hi`・下辺に2pxの金線。無効＝文字 `--text-dim`・枠なし | すべて |
| タブ | 縦（MENU左）と横（持ち物の中など）。選択中は左に4pxの金の縦線（縦タブ）／下に2pxの金線（横タブ） | MENU・持ち物・設定 |
| チップ | 高さ24px・角丸12px・13px/700。意味で色分け: 無料＝緑／体力＝黄／料金＝真鍮／新しい話＝金／定休日＝灰／恋人＝琥珀 | 地図の案内・持ち物・人間関係 |
| 行（row） | 左に48pxの顔か漢字バッジ、中に名前と補足、右に状態。高さ64px。タップで選択（左に金の縦線） | 人間関係・持ち物・記録 |
| ゲージ | 既存の `gauge-frame/fill`。幅は役割で固定（体力 160px・熟練度 96px） | HUD・ステータス・持ち物 |
| ●○（pips） | 残り行動・熟練度Lv・絆Lv。塗り＝`--gold`、空＝`--brass` 30% | HUD・持ち物・人間関係 |
| トグル／スライダー | 標準部品を使わず、板の中の真鍮のつまみ（`appearance:none`） | 設定 |
| トースト | 既存。種類の色（warn/good/charm/insight）は維持 | 全体 |

## 3. HUD（常駐）

### 3.1 左上: 日付プレート（1枚）

```
┌──────────────────────────────────────┐
│ DAY 5 /14   昼 ☀   SMOKE CROWN CUP まで あと9日 │  ← 上段: 大きな数字＋時間帯＋天気＋大会
│ 行動 ●○    体力 ▓▓▓▓▓▓░░ 好調    ¥42,000      │  ← 下段: 残り行動・体力（調子の文字つき）・所持金
└──────────────────────────────────────┘
```

- 幅 420px・高さ 84px。地区名（`TOSU`／隣町）は上段の左端に 12px の英字で小さく。第2章の隣町では色だけ変える（既存の `data-region`）。
- **残り行動の ●○** を新設。`2 - state.slot` を●で、使った分を○で。帰宅後（`slot>=2`）は「帰宅」の文字に変わる。これは地図の案内パネルの「今日はあと2回動ける」と同じ値（`calendar.js` の `takeAction` ループ）。
- 体力は既存の `staminaRatio()`＋`conditionForRatio()`。バーの右に**調子の一語**（好調／通常／不調）を添える。根性の上乗せ（`guts-extra`）と最大体力で伸びる仕様（GUI26）は維持。
- 所持金の `+1,200円` のポップ（既存 `money-pop`）はそのまま。
- 天気（`weatherOf()`）は小さな記号（☀／☁／☂をSVGで）。雨の日は時間帯の横に「雨」と出す既存仕様と同じ内容。
- 経験値（`GROWTH_BOARD` 有効時の `hud-exp`）は下段の右に `Lv.3 ▓▓░░` として入る場所を予約しておく。

### 3.2 右上: 2つのボタン

- `LIME`（未読の赤丸つき）と `MENU` の2つ。高さ 44px で揃え、どちらも真鍮の板。LIME だけ中に緑の小さな吹き出しアイコンを置く（緑はLIMEの識別色として残す）。
- 五角形のステータスボタンは**廃止し、MENU の `ステータス` タブへ**。火種がある時の琥珀の個数バッジ（REPORT R6）は MENU ボタンに移す（MENU の右上に小さな数字）。
- キーボード: `M`／`Esc` で MENU、`L` で LIME。会話中は従来どおり（Esc はログを閉じる）。

### 3.3 置けない時の振る舞い（既存の条件を保つ）

- LIME は「行き先を選んでいる時だけ開ける」（`phoneButton`）、セーブも同じ。MENU は会話中も開けるが、`セーブ` と `タイトルへ戻る` は行き先選択中だけ有効（既存の `isChoosingDestination()`）。無効なときはボタンを薄くして理由を1行で添える（「行き先を選んでいる時にセーブできる」）。トーストで叱らない。

## 4. 地図

### 4.1 看板（ピン）の作り直し

```
┌─────────────┐
│ [顔/ロゴ] KEMURIKUSA │  ← 1行。長い名前は字を 15→13px へ自動縮小（既存の名前札の fit と同じ考え）
│ ！新しい話  体力  ¥3,000 │  ← 状態チップ（最大3つ・13px）
└──────┬──────┘
       ▼
```

- 面は暗い板（`--panel`）＋役割別の差し色（GUI14: スチール／アイボリー／石墨／茶）を**縁の色**に使う。白い面はやめる。街の絵より暗い板の方が、絵が主役になる。
- 「〜へ行く」の別ラベルは廃止し、看板をタップ→右下の案内パネルで `ここへ行く`（既存の流れ）に一本化。
- 定休日・営業時間外は看板全体を灰色にして `定休日` のチップ。閉じていても店名は読める。
- `！`（新しいイベント）は看板の右上に丸で（PF22 維持）。未面識は `？？？` と人影（既存）。
- 在店の顔（`pin-people`）は看板の下辺に重ねる小さな丸（既存の仕組み）。

### 4.2 案内パネル（右下）と「今日の予定」

- 右下の案内パネルは良いので形を保つ。上に**今日の予定の帯**を1行足す: 「今夜 19:00 みんとと PEPPERMINT（LIMEの約束）」「今夜は固定の予定がある」「定休日: EDEN」。値は `state.pendingInvite`・`nightPlan()`・`SPOTS[].closedOn` から。
- 何も選んでいない時の文（「気になる場所をタップしよう」）は初回だけにし、2回目以降は今日の予定の帯だけにする。
- `商店街を歩く` は案内パネルの中の副ボタン（`ここへ行く` の下）へ移す。地図の左下に浮かせない。

### 4.3 第2章の隣町・第3章の東京

- 第2章の2つの街の切り替え（駅）は看板と同じ板の部品で。第3章の東京（`ch3-map.js` のダイアログ式）は**同じ看板・案内パネルの部品**に乗せ換える。中身の進行（場面カード式）は変えない。

## 5. MENU（はじめの手帳）

### 5.1 情報設計

全画面の覆い。左に縦タブ6つ、右に内容。上辺に日付プレートの要約（HUDと同じ値）、右上に `閉じる`（Esc）。

### 5.2 「今日」タブの「次の一手」の決め方

状況から**最大3件**を選ぶ。文はすべて既存の案内文を再利用する。

| 条件 | 文 | 出どころ |
|---|---|---|
| 未読のLIMEがある | 「LIMEに未読が N件」 | `unreadCount()` |
| 約束が今日の後の枠にある | 「今夜、みんとと PEPPERMINT で」 | `state.pendingInvite` |
| ♥の節目が待っている人がいる | `relationshipStatus(id).hint`（例: 「夜、PEPPERMINTで会うと、特別なイベントへ」） | `relationship-status.js` |
| 第1章で DAY3／7／13 の練習が未体験 | 「tonari で基礎練習ができる」 | 既存の練習フラグ |
| 私物の葉が 0g | 「Dr.fookah で葉を買っておく」 | `ownedFlavorIds()` |
| 体力が赤 | 「今日は家で休むと翌朝の発病を防げる」 | `currentCondition()` |
| 盤が有効で火種が残る | 「観音堂で火種を灯せる（N個）」 | `hidaneTotal()` |

優先順位は上から。何も無いときは「今日は自由に動ける」。**ゲームの正解を教えない**（どの選択肢が恋愛寄りか、くじがお得か等は出さない）。

## 6. 会話画面（枠は変えない。中の3点だけ）

1. **操作バーの板化**: `AUTO SKIP LOG 用語 設定` の5つを、会話枠の上辺から出る「札」の部品に揃える（UIT24 で決めた位置はそのまま。見た目だけ共通部品に）。`AUTO`／`SKIP` の有効中は札の文字を金に。
2. **LOG の読みやすさ**: 話者名を左の 88px の列に固定し、本文を右に。話者ごとに名前の色を能力色ではなく**淡い真鍮**に統一。`remember` で思い出に残った行には左端に小さな栞の印。地の文は斜体にせず `--text-dim`。
3. **用語のその場表示**: 本文中の用語（`data/glossary.json` にある語）に細い下線を引き、タップで枠の上に一行の意味を出す（既存の `用語` モーダルは残す）。初見の人がシーシャ用語で置いていかれないための一級市民（`vn/glossary.js` の方針）。

会話中に MENU を開く場合は、`設定` の札から**同じ MENU（システムタブ）**を開く。会話中は `今日`・`人間関係` なども閲覧できるが、セーブ・タイトルへ戻るは無効（§3.3）。
