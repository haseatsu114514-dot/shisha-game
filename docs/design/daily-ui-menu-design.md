## 0. 結論（先に要点）

1. **MENU は全画面・4タブだけ**: `ステータス`（Lv・EXP・火種・心得の盤の三角）／`人間関係`／`持ち物`／`システム`（セーブ・ロード・設定・用語集・大会の規則・タイトルへ）。今の STATUS モーダルと MENU モーダルを1つに畳み、HUD右上の五角形ボタンは廃止する（§4）。
2. **HUD は1枚の板**: DAY・時間帯・大会まで・体力（調子の一語つき）・所持金。行動回数は出さない。右上は緑の `LIME`（そのまま）と `MENU` の2つ（§2）。
3. **地図の看板は「ロゴ・在店の顔・店名」を必ず残す**。案A＝今の白い看板を整える、案B＝墨の板にロゴ窓。どちらも店名を1行の札に出し、定休日は札の中に入れる（§3）。
4. **会話ウインドウは枠から作り直す。案A「煙の帯」と案B「紙の窓」**。Aは枠を描かず画面下を煙の帯で暗くし、本文は明朝（Shippori Mincho B1）。BはDr.fookahの白×ラベンダーをそのまま会話へ持ち込み、本文はゴシック（既存の Suien Gothic）。どちらも名前は本文の左上、操作は右上の小さな文字、▼は右下（§5）。
5. **ショップの白×ラベンダーは「明るい面」の正式な部品にする**。Dr.fookah・くじ・紙の会話窓・LIMEの面がこの路線、HUD・MENU・看板・暗い会話窓が墨×真鍮の路線。2路線をトークンで固定し、それ以外の色を増やさない（§1）。
6. **不具合**: 看板の店名が切れて見えたのは、**店のロゴ画像が読めなかった時の代替表示**だった（ロゴが読めれば切れない）。代替の店名を窓の中で折り返すよう直した（§A）。

## 付録A. 直した不具合: 看板の店名が切れる

- 現象: `KEMURIKUS`・`PEPPERMIN`・`tonar` のように店名が途中で切れる。
- 原因: 看板は店のロゴ画像（`assets/ui/store_logos/*.webp`）を 82×46px の窓に表示し、**画像が読めなかった時だけ**店名の文字を同じ窓に出す（`store-logos.js` の `onerror`）。その代替表示が 15px・折り返しなしで、窓より長い店名が `overflow: hidden` で切れていた。撮影した環境は LFS の画像が未取得だったので代替表示になっていた。ロゴが読める通常の表示では切れない（ロゴ取得後に確認済み）。
- 修正（`remake/css/store-logos.css`）: 代替表示を 12px・行間1.15・折り返しありにし、長い店名を2行で窓に収める。ロゴの表示・看板の大きさ・判定は変えない。
- 確認: ロゴ取得後の通常表示と、ロゴの読み込みを遮断した代替表示の両方を 1280×800 で撮影。代替表示の5店（tonari／KEMURIKUSA／EDEN／PEPPERMINT／Dr.fookah）で `scrollWidth == clientWidth`（はみ出しなし）。`node remake/test/typography_css.mjs` OK（12px は 700 以上の決まりに適合）。
