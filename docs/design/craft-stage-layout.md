# シーシャ作りのレイアウト案「一枚の舞台」（2026-11-10・提案）

オーナー依頼「現在のシーシャ作りパートがあまり面白くなく、UIや配置に楽しさがない。ミニゲーム内容やシステムは変えずに、スマホで16:9の画面でやる場合の見た目やレイアウトを再構成してみて。主人公の様子が見える・熱ゲージがある、は必ず残す」への提案。**まだ本編には入れていない**（静止モックだけ）。採否は `docs/owner_requests.md` の CSL。

- モック: `remake/previews/craft-stage-layout/`（`?step=mix|pack|holes|heat|timer|steam|pull|care`、`?mode=tournament`、`?zones=1` で置き場所の図、`?bare=1` で切り替えを隠す）。本編の JS・CSS は読まず、今ある絵（`remake/img/ui/making/` ほか）を新しい配置に並べただけ。
- 変えないもの: 工程の順番・各ミニゲームの中身・判定・点数・操作方法・保存。新しい絵も要らない。

## 今の画面で気になった点（スマホ16:9＝667×375・倍率0.52で確認）

1. 上の帯・左のカード・右のカードの三分割で、どれも同じ太さの枠と同じ濃さ。主役がない。
2. はじめは額縁の中の絵で、右のパネルの作業と別の場所に見える。ライバルの小窓・工程の灯・温度計が絵に重なる。
3. 熱ゲージは高さ360（画面の半分）。穴あけ・炭焼きでは出ず、詰め方では位置が変わる。
4. 上の帯（高さ64）に空の工程チップと「外観を選ぶ」が常に出る。「？」が炭壺・調整の説明文・はじめの頭に重なる。
5. 決定ボタンの場所と大きさが工程ごとに違い、横持ちの親指（左下・右下）に合っていない。

## オーナーに決めてもらう点

1. この方向で本編に組み込むか。
2. 工程バーと工程の灯を1本にまとめるか（別々のままなら灯ははじめの足元に残す）。
3. 蒸らしのスティックは右のままでよいか（左スティック・右ボタンにもできる）。
4. 火を入れる前の工程（穴あけ・炭焼き）でも熱の柱を消灯で立てておくか。

## 本編へ入れる時の進め方（採用後）

- 寸法・判定の座標は変えず、作業台（`.bench`）の配置だけを新しいCSS1枚（`craft-paper.css` の後に読む）で組み替える。アルミと雑念の場は中身の座標系を保ったまま `transform: scale()` で拡大する。
- 1PR＝1工程の単位で、山場の順（吸い出し→蒸らし→穴あけ→炭焼き→配合・詰め方→残り）に進める。各PRで `craft_layout_*`・`phone_density`・`craft_materials` などの関連ブラウザ検査を通す。
- DS風2画面（`game-ds`）とPCの広い画面は、この案の対象外（別に決める）。
