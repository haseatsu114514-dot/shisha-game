- 見本（静止モック）: `remake/previews/craft-stage-layout/`（`?step=mix|pack|holes|heat|timer|steam|pull|care`、`?mode=tournament`、`?zones=1` で置き場所の図、`?bare=1` で切り替えを隠す）。本編の JS・CSS は読まず、今ある絵を新しい配置に並べたもの。本編の実装はこの見本に合わせる。

## 今の画面で気になった点（スマホ16:9＝667×375・倍率0.52で確認）

1. 上の帯・左のカード・右のカードの三分割で、どれも同じ太さの枠と同じ濃さ。主役がない。
2. はじめは額縁の中の絵で、右のパネルの作業と別の場所に見える。ライバルの小窓・工程の灯・温度計が絵に重なる。
3. 熱ゲージは高さ360（画面の半分）。穴あけ・炭焼きでは出ず、詰め方では位置が変わる。
4. 上の帯（高さ64）に空の工程チップと「外観を選ぶ」が常に出る。「？」が炭壺・調整の説明文・はじめの頭に重なる。
5. 決定ボタンの場所と大きさが工程ごとに違い、横持ちの親指（左下・右下）に合っていない。

### 熱の柱の見せ方（2026-11-10 オーナー決定）

「熱ゲージは消灯で大丈夫」「蒸らしてる最中とかは『ぬるい』とかでなくていい。吸い出し以降に出す」。柱は全工程で同じ場所に立て、**状態の札（ぬるい・適温…）は吸い出し以降だけ**出す。

| 工程 | 柱 | 札 |
|---|---|---|
| 配合・詰め方 | 配合の温度帯の予想（今と同じ中身） | 「温度帯」（見出し。状態ではない） |
| 穴あけ・炭の配置・炭焼き | 消灯（灰色） | なし |
| 蒸らし時間 | 目盛りを暗めに出し、蒸らし後の目安の点線だけ（時間を決める材料なので残す） | なし |
| 蒸らし（雑念よけ） | 上がっていく温度と矢印（今と同じ中身） | なし |
| 吸い出し・提供・調整 | 今の温度・適温の線・矢印 | あり（ぬるい／適温・低／最適温／熱い…） |

### 工程ごとの決めごと

- **配合**: 葉の行に商品パッケージ（ショップと同じ絵 `flavorPackageArt`）を高さ約110で出す。1行は122で、4種が一度に見える。
- **炭焼き**: 決定ボタンが無い工程なので下の列まで使い、コンロを幅約850・炭を幅約176に大きくする。炭壺は右上へ小さく、案内は上の札に。
- **蒸らし（雑念よけ）**: スティックと補助ボタン（リフレッシュ・アタック・精密）は**今と同じく近くにまとめて右下**に置く（押しやすさのための配置。オーナー指示）。雑念の場は舞台の幅いっぱい。
- **蒸らし時間**: タイマーの数字は本編の7セグ（`digital-clock.js`）。液晶とボタンの位置の割合も本編（`.timer-display`・`.timer-button`）のまま。
- **ランク**: 制作中は上のレールに**文字だけの略形（D〜SSS）と次のランクまでの進み**を出す。細かい文字の入った全文の絵は、工程の結果と一台の結果の画面で大きく見せる。絵はオーナーが以前選んだ7枚（#2473）を使うが、**リポジトリに未保存**なので、保存されるまでは今の文字表示（`rank-hud.js` の代わりの表示）のまま。

## まだ決まっていない点

1. 工程バーと工程の灯を1本にまとめる件は、反対が無ければ見本どおり進める（別々のままなら灯ははじめの足元に残す）。
2. ランクの絵7枚の置き場所（原画の保存）。
3. 熱ゲージの虹（最適温の帯）: 2026-10-26 の作り分け（FEX01）で、作り分ける4葉（AFミント・AFダブルアップル・AFレモン・ドバジミント）だけの配合では中央の虹を出さない作りになっている。戻すかどうかは未決（本設計では今の挙動のまま）。

## 本編へ入れる進め方

- 寸法・判定の座標は変えず、作業台（`.bench`）の配置だけを新しいCSS（`craft-paper.css` の後に読む）で組み替える。アルミと雑念の場は中身の座標系を保ったまま拡大する。
- 切り替え: 全工程がそろうまでは既定で切。`?craftStage=1` で入（端末に覚える）、`?craftStage=0` で戻す（`js/craft/stage-layout.js`・`css/craft-stage.css`）。そろったら既定で入にする。
- 操作の案内文は画面に常設しない（「？」と初回の説明で読む。CSL15）。
- 最初に骨組み（背景・はじめ・熱の柱・上のレール・下の列）を入れ、そのあと1PR＝1工程で、山場の順（吸い出し→蒸らし→穴あけ→炭焼き→配合・詰め方→残り）に進める。各PRで `craft_layout_*`・`phone_density`・`craft_materials` などの関連ブラウザ検査を通す。
- DS風2画面は廃止予定（#3078）なので対象外。PCの広い画面は同じ骨組みをそのまま拡大する。
