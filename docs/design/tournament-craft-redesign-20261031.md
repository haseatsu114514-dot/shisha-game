## 0. 要約

1. **いま弱いのは個々の画面ではなく「構造」**。作業台は LESSON と大会で中身が同じで、ライバル3人は文字でしか存在せず、審査員の持ち点は最後まで動かず、工程の出来は左下の小さな一言で終わる。盛り上がりが結果発表の10カウントに全部寄っている。
2. 解決の軸は **「生中継」の枠組みを大会モードの作業台に被せる**こと。上に試合時計と4人の進行チップ、右に対戦席（ライバルの台）、下に「会場の熱」ゲージと流れるコメント、右上に審査員の持ち点ボード。工程を終えるたびに**決めカード**（◎○△のスタンプ＋審査員の顔＋熱の増減）で区切り、熱が溜まると**審査員4分割カットイン**が出る。
3. 結果発表は **10カウント → 南雲の10点 → 4位から順に呼ぶ順位発表 → 表彰（ハイライト3枚・審査員一言・称号）** の4段にし、優勝の「溜め」を作る。
4. 採点・勝敗・難度は変えない（`score.js`・`NAGUMO_BAR`・調整2回の配点は現行のまま）。中間投票だけ、実績に連動させる案（§3.4）を推奨するが、これはオーナー判断。

## 2. 体験の目標と守ること

**目標**: 「4人同時に作る60分の生中継を、はじめの席から戦う」。
操作は変えずに、①相手が見える ②会場が反応する ③審査員の判断が動く ④工程ごとに決め所がある ⑤最後に溜めて爆発する、の5点を画面で成立させる。

**守ること（既決事項）**
- 採点（`score.js`）、南雲の基準 90.8、配点 20%×5（第1章アルミ省略時の 40%）、吸い出し・調整の操作、焦げ／冷え／葉切れの失敗はそのまま。**新しい演出は点数に影響させない**。
- 表示は ◎（90以上）／○（65以上）／△。大きな S・A 等の等級表示は出さない。
- 制作中に話すのは左下の審査員またはパッキー1人。大会・リハーサルではメタ発言をしない。南雲は静かに考える表情にとどめる。
- 中間票は「実際に投入された持ち点だけ」。南雲は最後まで10点を温存し、1位は南雲票の前から首位（#1282）。
- FLAVOR TRIAL（プレゼン）は再実装しない。蒸らしの雑念は「はじめ自身の内心」。
- 「クリティカル」の語は使わない（ジャスト◯◯で統一）。
- 動きを減らす設定では、閃光・揺れ・強い点滅を止める（#1950 の設定と同じ境界）。

## 3. 設計の柱（7本）

### 3.1 生中継フレーム — 大会モードだけの作業台クローム

`bench[data-mode="tournament"]` のときだけ、作業台の外側に次を足す（LESSON／PRACTICE／REHEARSAL は現行のまま）。

```
┌ LIVE ● SMOKE CROWN CUP │ ROUND 1 準備 │  ⏱ 12:40 / 60:00  │ [は][な][ア][み] 進行チップ │ 審査員ボード ┐
├──────────────┬────────────────────────────────────┬───────┤
│ 作業風景     │ 工程パネル（現行のまま）                 │ 対戦席 │
│ 審査員の一言 │                                      │ なる   │
│              │                                      │ アダム │
│              │                                      │ みんと │
├──────────────┴────────────────────────────────────┴───────┤
│ 会場の熱 ▮▮▮▮▮▮▮▯▯▯  ──── 流れるコメント（作業中も薄く流れる） ──── │
└───────────────────────────────────────────────────────┘
```

- **試合時計**: 「経過 mm:ss」のカウントアップ。実際の工程時計（`clock.js`）が動いている間だけ進み、会話中は止まる。制限時間 60:00 は表示だけで、**時間切れの失敗は作らない**（現行の工程ごとの時計がすでに制限）。ラウンドの切れ目で「R1 終了 23:18」のように刻む。
- **4人の進行チップ**: 顔アイコン＋現在工程の小アイコン＋細い進行バー。はじめは実際の工程、ライバルは §3.2 の台本で進む。
- **審査員ボード**（右上）: 上園・博士・南雲のチップに「投入 n／残り m」。南雲は錠前付きで「10」。票が動く瞬間に光る。
- **会場の熱**（下）: §3.3。
- 1280×720 では対戦席を右に 160px、844×390（スマホ横）では対戦席を上バーのチップに畳み、熱ゲージは上バーの下に 6px の細い帯にする。工程パネルの入力座標は変えない（`craft-landscape.css` の既存境界を使う）。

### 3.2 対戦席 — ライバル3人を画面に置く

- 右端に3枚の**対戦席カード**（顔・名前・いまの工程アイコン・小さな台のシルエット・煙）。台のシルエットは所持機材ではなく `tournament-graphics.js` 系の共通シルエットに、その人の色（`RIVAL_COLOR`）を乗せる。
- ライバルの進行は**実時間ではなく、はじめの工程の節目で進む台本**（`rival-timeline.json`／章別）。例・第1章:

| はじめの節目 | なる | アダム | みんと | 事件（実況・コメント・熱） |
|---|---|---|---|---|
| 配合開始 | 配合 | 配合 | 配合 | — |
| 配合終了 | **穴あけ**（速い） | 詰め | 詰め | 「なる選手はもう配合を終えた！」 |
| 穴あけ終了 | 炭 | 穴あけ | 穴あけ（丁寧） | — |
| 炭焼き終了 | 蒸らし | **炭を取りすぎ・白煙** | 炭 | アダムの席から大きい煙 → コメント増 |
| 蒸らし終了 | 蒸らし | 蒸らし | 蒸らし | R1 終了 |
| 提供 | 提供済み | 提供済み | 提供（遅い） | 「みんと選手、最後の一人」 |
| 調整1回目 | 炭交換 | 吸い込み多め | 調整 | — |
| 調整2回目 | 安定 | 熱が落ちる | 安定 | 「アダムの台、煙が細い」 |

- 既存の `broadcast.json rivalFeed`・`chapterN.rivalComments` をこの表に紐づけ、該当カードの吹き出し＋流れるコメントの両方に出す。文面の追加はこの表の「事件」行ぶんだけ。
- カードをタップすると、その人の現在の一言（既存のライバル実況）が吹き出しで出る。時間・体力は消費しない（情報の確認だけ）。
- 第2〜4章は出場者が変わる（あげは・神崎・REI／久世・スティーブ・ヴォルク／なる・王煙楼・シェイク）。台本は章ごとに1枚ずつ、第1章を先に作る。

### 3.3 会場の熱（HYPE）— 盛り上がりを1本のゲージにする

- 0〜100 の**演出専用の値**。採点・勝敗・難度には一切使わない（`NAGUMO_BAR` の較正を崩さない）。
- 増減（案）: 工程の ◎ +12／○ +6／△ −8、穴あけ EXCELLENT 1個 +1（上限 +8）、ジャスト炭 +4、蒸らし無被弾 +6、提供が適温帯 +8、焦げ・過熱 −12、ライバルの事件 ±3。
- 段階: **40 ざわめき**（流れるコメント×2・照明がゆっくり流れる）／**70 沸騰**（コメント×3・歓声SE・初回に審査員4分割カットイン §3.4）／**95 MAX HEAT**（舞台照明が色を変える・コメント×4・2回目の4分割）。動きを減らす設定では照明の変化を止め、ゲージの色だけ変える。
- 熱が高いほど観客の体感スコア（旧 RM18 の +N P）を出す、は**しない**（TH42 で SCORE に一本化済み）。
- 結果発表で「会場の熱 最高 97」をハイライトに1枚使う（§3.7）。

### 3.4 審査員の持ち点を見せる — 投票ボードと「中間票の実績連動」

**A. ボード（演出・必ず入れる）**: §3.1 右上のチップ。上園・博士が票を入れる瞬間に、`vote_token` の札がはじめ／ライバルの進行チップへ飛ぶ。南雲は錠前のまま「まだ動かず」。

**B. 中間票の実績連動（推奨・オーナー判断）**: 現行は `interimPointTable(round)` が固定で、はじめの出来と無関係。これを次に変える。

- 上園は R1（配合・穴あけ）と R2（提供）の後、博士は R1（炭）と R3（調整1）の後に票を入れる。はじめへの票は **◎=2／○=1／△=0**（各イベント）。ライバルへの票は台本のまま（なる 2→4、アダム 1→3…現行値）。
- **#1282 の規則を保つための上限**: 最終集計の前に、`outcomeOf(total)` が1位なら上園＋博士のはじめ票を **6以上**、1位でなければ **4以下**に丸める（丸めた差分は最後の投入で合わせる）。これで「1位は南雲票の前から首位」「敗北時は南雲票でなるが抜く」が必ず成立する。
- `pointTable(rank)` の役割は「最終の着地」に変わり、はじめの列だけ上の実績値で置き換える。ライバル同士の順位は現行のまま。
- 中間投票の盤は、票が入る行だけ札が飛んで数字が増えるアニメーション（現行の南雲カットインと同じ部品 `countUp`）。表示は 3.6 秒固定から**「読み終わるまで」＋最短 2.5 秒**（タップで送る）に変える。

### 3.5 決めカード — 工程ごとの「決まった！」

- ミニゲーム終了後、現行の `resultCard`（詳細）を出す**前に 1.1 秒の決めカード**を全幅で出す: `stamp_ring` の輪の中に大きな ◎／○／△、右に担当審査員の顔（96px・表情は評価に連動）と一言（既存 `feedbackLine`）、下に「会場の熱 +12」。◎は `hype_burst` の閃光と歓声、△は輪が灰色で静か。
- 途中の山場にも**小さい決め**: 穴あけの EXCELLENT 連続3、炭の「全面が赤い」をジャストで取った、蒸らし終盤を無被弾、提供が適温帯の中央、調整で温度を帯の中へ戻した → 画面端に短い光とコメント（既存の `comment`）。
- 等級の語（S／A）やスコアの数字は出さない。詳細はこれまでどおり任意に開く。

### 3.6 ラウンド構成とテンポ

- 見出しを**放送のセグメント**にする: `ROUND 1 準備` を **R1-A 仕込み（機材・水・配合・詰め・穴あけ）** と **R1-B 火入れ（配置・炭・蒸らし）** に見た目だけ分け、R1-A の終わりに 1.2 秒のタイトルプレート（`round_plate`）を挟む（会話は増やさない）。中間投票は R1-B の後だけ（現行どおり）。
- ラウンド間の非操作時間の目安: **25 秒以内**（会話はそのまま、中間投票を会話の裏の盤面として出し、速報 2 行はティッカーへ移す）。R2 後の 10＋9 行は、`ch1_tournament_served` の一口の感想を**決めカード風の「一口カード」**（審査員3人の顔＋一言ずつ・一画面）にまとめる案を推奨（台詞の削除はしない。表示形式の変更のみ。dialogue-edit スキルの対象）。
- R3・R4（調整）に**見せ場**を足す: 調整ごとに審査員が一口吸う「一口審査」演出（審査員ボードのチップが表情を変える・熱が動く）。アダムの台の煙が細る「事件」を R4 に置き、終盤へ向けて会場が沸く。
- BGM は現行（`bgm_tournament_craft` → `bgm_judging`）のまま。熱 70 以上で低音のレイヤーを足すのは Suno 発注待ちの任意項目。

### 3.7 結果発表 2.0 — 溜めて、呼び上げて、表彰する

1. **審査（試喫）会話** … 現行。
2. **RESULT 10 COUNT** … 背景を `result_backdrop`（スポットライトの台座）に。カットインは言葉の札から**その試合の実カット**（穴あけのアルミ・取った炭・温度計の帯・提供の煙＝既存の工程画像を小さな額で）に。4人のカードは対戦席と同じ部品。プチュン／パリン／フライングは現行。
3. **南雲の10点** … 現行に `vote_token` ×10 が南雲チップから飛ぶ動きを足す。
4. **順位発表**（新規）… 4位 → 3位 → 2位 の順に、名前と持ち点を呼び上げる（各 1.4 秒・顔の額が光る）。1位の前で 0.8 秒の暗転 → スポットライト → **「CHAMPION」**。はじめが2〜4位の場合も同じ順で呼ばれ、自分の順位で止まり、敗北会話へ（CONTINUE は現行）。
5. **表彰**（`resultTable` の拡張）… 左: 最終順位と持ち点（現行）。右: ◎○△の6枠（現行）＋**ハイライト3枚**（例「ジャスト炭」「外周12穴が揃った」「調整2回目で帯の中央へ」。候補は `craftRecognition` と熱の記録から選ぶ）＋**審査員の一言3つ**（上園・博士・南雲。南雲だけ短い）。賞金・称号「SMOKE CROWN CUP 優勝」を右下に表示し、称号はタイトルのギャラリー／記録へ残す。
6. 表彰のあとは現行の会話・LIME（スミさんの採点表）へ。

### 3.8 面白さの追加（小さく・点数を変えない）

- **雑念に試合の出来事を映す**: 蒸らしの雑念（`DODGE_WORDS`）に、その試合のライバル事件から選ぶ内心の言葉を混ぜる（「アダムの煙、気にするな」「なるはもう吸ってる」）。**弾の数・速度は変えない**（文面だけ）。雑念は内心、という既決に沿う。
- **一口審査**（§3.6）と**対戦席のタップ**（§3.2）: 情報を見る楽しさ。時間・体力は消費しない。
- **記録**: 大会ごとの自己ベスト（総合・各工程の◎数・最高の熱）とハイライトをセーブに残し、タイトルのギャラリーから見返せる。再挑戦（CONTINUE）の動機になる。
