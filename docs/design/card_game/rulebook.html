1このゲームについて

あなたはシーシャの大会に出る作り手です。棚に並んだ葉から好きなものを選んで一台を詰め、炭で熱を入れ、審査員に吸ってもらいます。葉にはそれぞれ「いちばんおいしい温度」があります。炭を置くと、熱はじわっと上がります。上げすぎれば焦げ、炭は弱り、葉は減っていきます。炭を焼いて足し、審査員の一口に熱を合わせます。

勝ち方

審査員の一口ごとに入る点、相手より印象に残る一口を出したときの一票、最後にもらう決め手のボーナスを合計します。大会が終わったとき、合計がいちばん高い作り手の勝ちです。

覚えることは3つ

熱は、火力へ1ずつ近づく

炭の火の合計が火力。一台の熱は、自分のターンの終わりに、火力へ1だけ近づきます。火力が上なら上がり、下なら下がります。炭は4つまで。

炭は弱る。焼いて、入れ替える

提供では、自分のターンのたびに炭の火が1下がり、0で灰に。火は戻りません。炭カードは炭焼き場で焼いてから、のせます。先を読んで火を起こします。

吸い方を見て、熱を合わせる

ラウンドのはじめに、審査カードをめくります。長く吸われれば熱は上がります。2人ともそれを見てから、熱を上げるか・保つか・下げるかを決め、技を仕込みます。

セッティングカード

ゲーム開始から場に出ている、あなたの道具です。ボウル1枚とHMD（ヒートマネジメント）1枚を組み合わせます。ボウルには容量（詰められる葉の上限）があります。

  3. フレーバー場を作る　20種から10種を選び、各16枚の山にして並べます。
  4. セッティングを選ぶ　ボウル1枚とHMD1枚を選び、同時に表にします。

  1. 先手を決める　じゃんけんなどで決め、先手マーカーを渡します。

2つのフェイズ

準備フェイズ（7ページ）　全員が4ターンずつ。葉を詰めながら、炭を焼いてのせます。熱は0から、1ターンに1ずつ上がります。

提供フェイズ（8ページ）　ラウンドをくり返します。はじめに審査カードを1枚めくり、2人がターンを終えたら、審査員が一口吸います。葉は、一口ごとに1枚減ります。

手番　3〜4人で遊ぶときは16ページ

先手、後手の順に1ターンずつ行います。先手マーカーは、ラウンドが終わるたびに相手へ渡します。後手だった人は、次のラウンドの先手として続けてターンを行います。

いつも守ること

  • ターンの終わりに、熱を火力へ1近づけます。炭は4つまで、熱は0〜10。
  • 自分のターンの終わりに手札が8枚以上あれば、7枚になるまで灰にします。
  • 山札がなくなったら、灰置き場を切り直して新しい山札にします。
  • カードの文とルールが食い違うときは、カードの文に従います。

カードを使う

カードの左上の数字は必要な熱です。自分の熱がその数以上なら、そのカードを使えます。熱は払いません。

熱が7なら、必要な熱7までのカードを使えます。使っても熱は7のままです。
  • カードは自分のターンに1枚。炭を足す・外す、炭カードを置くのは数えません。
  • もう1枚 ひと息・追い炭・トングさばき・仕切り直しは、使ったあとそのターンにもう1枚使えます。
  • 熱−1 は熱を落として使うカード。使うと、熱がその場でその数だけ下がります（炭は弱まりません。ターンの終わりに、熱はまた火力へ1近づきます）。葉−1 は主役の葉を減らして使う。必要な熱は、落とす前の熱で確かめます。
  • 一口のカードは、提供の自分のターンに使い、そのラウンドの自分の一口に仕込みます（8ページ）。
  • 熱を上げるほど強いカードに届きますが、焦げにも近づきます。

熱の動き

適温4〜6の葉の例。黒い線は自分のターンを終えたときの熱、黄色い丸は一口の判定熱（熱＋審査カード）。準備の4ターンで、熱は0から1ずつ上がります。審査カードを見て、判定熱が帯に入るように、熱を1つ上げるか・保つか・下げます。

5炭と熱 このゲームの中心

火力と、熱

炭には火があります。炭の火の合計が火力。熱は一台の温度で、審査されるのはこちらです。

蒸らし　自分のターンの終わりに、熱を火力へ1だけ近づけます（上なら+1・下なら−1・同じなら動かない）。

炭は4つまで。低温の葉は1〜2個、高温の葉は3〜4個がめやす。HMDがC1のときだけ、2つまでです。

火力を上げる

炭の火は戻りません。火力を上げるには、空いている炭の枠に新しい炭を足します。

炭を足す①　チャージ＆ドロー

炭は1ターンに、1つ足せて、1つ外せます。足す手の1つめ。手札を1枚、裏向きで火力ゾーンに置き、山札から1枚引きます。置いた札は種火になり、火力+1。置かずに引くことも、引かずに置くこともできません。しなくてもかまいません。

炭を足す②　炭カードを焼いて、のせる

炭カードは、自分のターンならいつでも炭焼き場に置けます（フラットは縦向き、キューブは横向き）。カードを使う1枚には数えません。枠があれば何枚でも置けます。

火おこし中
フラット縦向きキューブ横向き
焼けた
フラット→ 火力ゾーンへ
炭焼き場の枠は4つ。火おこし中と焼けた炭を合わせて4枚まで。カードでは増えません。
  • 自分のターンのはじめに炭焼き場を進めます。縦向きの炭は「焼けた」へ。横向きの炭は縦向きに。フラットは次のターン、キューブは2ターン後に焼けます。
  • 焼けた炭は、炭の枠が空いていれば、自分のターンにいつでものせられます。取っておくこともできます。

炭が弱る

提供フェイズでは、自分のターンのはじめに炭が弱ります。炭を1つ選んで、火を1下げます。

外す（1ターンに1つ）

自分のターンに1つだけ、炭を選んで外せます（灰置き場へ）。準備でも提供でも。火がいくつ残っていてもかまいません。

  • 火力を下げる　熱を止めたい・下げたいときに、炭を1つ外します。
  • 入れ替える（炭交換）　弱った炭や種火を外して、焼けた炭をのせます。はじめの種火も、こうして替えていきます。

6準備フェイズ 葉を詰めながら、蒸らす

全員が4ターンずつ、先手から交互に行います。自分のターンには次の順で進めます。

  1. 火を見る　炭焼き場を進めます（準備のあいだ、炭は弱りません）。
  2. 引く　山札から1枚引きます。
  3. 手を打つ　葉を詰める（1回）・炭カードを置く・炭を1つ足す／1つ外す・カードを1枚（器具・人物・「準備」「いつでも」）。好きな順で。
  4. 蒸らし　熱を火力へ1近づけます。手札は7枚まで。

詰める

フレーバー場の山から葉カードを合計4枚まで取り、自分のボウルに置きます。何種類でもかまいません。ボウルの容量を超えては取れません。

蒸らす

「蒸らす」という手はありません。炭を置いておけば、ターンの終わりに熱がひとりでに上がります。はじめの炭（火力3）のままなら、熱は3で止まります。

  • 葉は4ターンで16枚まで。一口ごとに1枚減るので、多いほど長くもちます。
  • 提供に入るとき、熱は4まで。低い熱の葉は、火力を熱と同じにして止めます。

4ターンが終わったら、主役の葉に主役マーカーを置き、提供フェイズに進みます。

主役の相性のしるしと同じ系統の脇役がいれば、さらに+1。

8審査員の吸い方に合わせる

審査カードは、ラウンドのはじめにめくります。2人とも吸い方を見てから、熱と仕込みを決めます。

吸い方判定熱この一口の決まり

仕込みは相手に見える

後手は、先手の熱と仕込みを見てから動けます。ジャスト狙いの渾身の一口は、実況の煽り（判定熱+1）で焦がされるかもしれません。先手は毎ラウンド交代します。

吸い方に合わせる。後手の揺さぶりに備える

ブルーベリー（適温4〜6・ジャスト5）。熱5で「長く吸う」（+1）がめくられたら、火力を熱より下にして、熱4でターンを終えます。「ゆっくり吸う」（−1）なら、火力を上にして熱6です。熱が動くのは1ターンに1なので、+1・−1には、ちょうど合わせられます。

マンゴー（適温5〜6・ジャスト6・焦げ7）は、熱6で「長く吸う」なら、熱5へ下げてジャスト。下げられなければ、判定熱7で焦げます。「深く吸う」（+2）は、1ターンでは合わせきれません。

そこで熱を逃がす吸い（判定熱−2）やブロー（焦げない）を仕込みます。次のラウンドの吸い方を「吸い方を読む」で先に見ておけば、1ターン早く熱を動かせます。

9葉の体力と、セッションの区切り

葉の体力　ボウルの葉の枚数が、その一台の体力です。葉は、吸われるたびに減っていきます。

燃え尽き　体力が0になったら、その一台は燃え尽きです。以後の一口はすべて0点で、印象も0です。

セッションの区切り　3ラウンド目の審査が終わったら、区切りです（最終セッションのあとを除く）。

  1. 効果が切れる　「このセッションの終わりまで」の効果が終わります。「各セッション1回」の能力は、また使えます。

  • 焦げたら「焦げ」、ジャストなら「ジャスト」の記録チップを取ります。決め手で数えます。

10ゲームの終わり

最終セッションの3ラウンド目の審査が終わったら、ゲーム終了です。

  1. 決め手　場に出ている審査員カードを1枚ずつ確かめ、条件を満たした作り手に点を加えます（12ページ）。
  2. 勝敗　合計点が高い作り手の勝ちです。

同点のとき　ボウルに残った葉が多い方、次に手札が多い方の勝ち。それでも同じなら引き分けです。

使ったら灰にします。会場で起きる出来事で、相手に影響するものがあります。相手に効くカードはすべて手番です。

      一台勝負　ルールブック 第0.8版3〜4人で遊ぶ・調整メモ

      203〜4人で遊ぶ 1対1対1対1

      3人でも4人でも、同じカードと同じ流れで遊べます。チームは組まず、全員が自分の一台で競います。変わるのは下の7つだけです。2人で遊ぶときは、どれも今までどおりです。

      変わる決まり

      1. 手番は席の順　先手から時計回りに、1人ずつターンを行います。はじめの炭、準備フェイズ（1人4ターン）、提供フェイズのどれも同じです。
      2. 先手は次の席へ　ラウンドが終わるたびに、先手マーカーを時計回りの次の席へ渡します。「後の先」を使った人は、次のラウンドのいちばん後になります。
      3. 一票は1人だけ　印象がいちばん高い1人に+2点（点で上の人がいれば+3点）。いちばん高い印象が2人以上で並んだら、だれにも入りません。
      4. ねらうカードは相手を選ぶ　「実況の煽り」と「すきま風」は、使うときに相手を1人選びます。すきま風で選べるのは、炭のある相手だけです。「会場の熱気」は、今までどおり全員に効きます。
      5. 場の葉を増やす　フレーバー場の山は、1種につき3人なら24枚、4人なら32枚にします（1人8枚ぶん）。
      6. 決め手はいちばんの1人に　審査員の決め手は、条件でいちばんの1人に入ります。いちばんが並んだら、並んだ人に2点ずつです（カードの「同点なら全員+2」は、こう読みます）。
      7. 順位　点の高い順です。同じなら、残った葉が多い方、次に手札が多い方が上。上の2人がどれも同じなら、引き分けです。

      審査カードの山は12枚のままで、ラウンドのはじめに1枚めくります。
