一台勝負　ルールブック 第0.6版このゲームについて

1このゲームについて

あなたはシーシャの大会に出る作り手です。棚に並んだ葉から好きなものを選んで一台を詰め、炭で熱を入れ、審査員に吸ってもらいます。葉にはそれぞれ「いちばんおいしい温度」があります。熱は放っておくと冷めます。炭を焼いて足し、審査員の一口に合わせて熱を整えます。

勝ち方

審査員の一口ごとに入る点、相手より印象に残る一口を出したときの一票、最後にもらう決め手のボーナスを合計します。大会が終わったとき、合計がいちばん高い作り手の勝ちです。

覚えることは3つ

炭の火の合計が、熱で、火力

火力ゾーンに置いた炭の火を足した数が、一台の熱です。炭は4つまで。熱が上がるほど、強いカードに手が届きます。手札はどれでも、裏向きに置けば種火（火1）になります。

火は下がる。炭を焼いて足す

自分のターンのたびに炭の火は下がり、0で灰になります。火は戻りません。火の大きい炭カードは、まず炭焼き場で焼きます。先を読んで火を起こします。

吸い方を見て、熱を合わせる

ラウンドのはじめに、審査カードをめくります。長く吸われれば熱は上がります。2人ともそれを見てから、吸い方に合うように熱を整え、技を仕込みます。

セッティングカード

ゲーム開始から場に出ている、あなたの道具です。ボウル1枚とHMD（ヒートマネジメント）1枚を組み合わせます。ボウルには容量（詰められる葉の上限）があります。

審査員の吸い方です。ラウンドのはじめに1枚めくり、全員に効きます。大きな数字は判定熱の変化。審査員1人につき4枚あり、大会に出る3人ぶんの12枚で山を作ります（12ページ）。

  1. 大会を決める　大会カードを1枚選びます。セッションの数、審査員3人、課題フレーバーが決まります（12ページ）。
  2. 審査カードの山を作る　審査員3人の審査カード（各4枚）をよく切り、12枚の山にして裏向きで置きます。
  3. フレーバー場を作る　20種から10種を選び、各12枚の山にして並べます。
  4. セッティングを選ぶ　ボウル1枚とHMD1枚を選び、同時に表にします。
  5. 山札を作る　自分のデッキ40枚をよく切って置きます。
  1. 先手を決める　じゃんけんなどで決め、先手マーカーを渡します。
  2. 最初の火（立ち上げ）　山札から7枚引きます。そのうち1〜4枚を選び、裏向きで火力ゾーンに置きます。これが立ち上げの炭（種火・火1ずつ）です。ふつうは3枚で熱3。残りが最初の手札です。

ヒント種火にしたカードは戻ってきません。炭カードと、あとで使いたい器具や人物は手札に残しましょう。4枚置けばすぐ熱4ですが、手札は3枚。1枚だけなら、手札を6枚残せます。HMDがC1なら、置けるのは2枚までです。

2つのフェイズ

準備フェイズ（7ページ）　全員が6ターンずつ。場から葉を取ってボウルに詰め、詰め終えたら炭を焼いて蒸らします。この間、炭は冷めません。

提供フェイズ（8ページ）　ラウンドをくり返します。はじめに審査カードを1枚めくり、2人がターンを終えたら、審査員が一口吸います。3ラウンドごとに葉が2枚減ります。

手番　3〜4人で遊ぶときは16ページ

先手、後手の順に1ターンずつ行います。先手マーカーは、ラウンドが終わるたびに相手へ渡します。後手だった人は、次のラウンドの先手として続けてターンを行います。

いつも守ること

  • 炭は4つまで、熱は10まで。それを超えるようには炭を置けません。
  • 自分のターンの終わりに手札が8枚以上あれば、7枚になるまで灰にします。
  • 山札がなくなったら、灰置き場を切り直して新しい山札にします。
  • カードの文とルールが食い違うときは、カードの文に従います。

カードを使う

カードの左上の数字は必要火力です。自分の火力がその数以上なら、そのカードを使えます。火力は払いません。火力は熱と同じ数です。

種火火1フラット火1フラット火2キューブ火3火力7
熱7は火力7。必要火力7までのカードを使えます。使っても熱は7のままです。
  • カードは1ラウンドに1枚（準備フェイズは1ターンに1枚）。チャージと、炭カードを置く・のせるは数えません。
  • もう1枚 ひと息・追い炭・トングさばき・仕切り直しは、使ったあとそのラウンドにもう1枚使えます。
  • 火力−1 は火力を落として発動するカード。火力（熱）がちょうどその数だけ下がります。火のいちばん小さい炭（同じなら種火）から、火を1ずつ下げます。0になった炭は灰です。葉−1 は主役の葉を減らして発動。必要火力は、落とす前の火力で確かめます。
  • 一口のカードは、提供の自分のターンに使い、そのラウンドの自分の一口に仕込みます（8ページ）。
  • 熱を上げるほど強いカードに届きますが、焦げにも近づきます。手札をチャージして届かせるのも手です。

熱の動き

適温4〜6の葉の例。黒い線は自分のターンを終えたときの熱、黄色い丸は一口の判定熱（熱＋審査カード）。審査カードはラウンドのはじめに見えるので、判定熱が帯に入るように熱を合わせます。提供では毎ターン炭が1つ冷めて熱が1下がるので、新しい炭を足して保ちます。

5炭と熱 このゲームの中心

炭の火と、熱

炭には火があります。熱は、火力ゾーンにある炭の火の合計です。炭の数ではありません。

炭は4つまで

火力ゾーン（HMDの上）の炭の枠は4つ。5つ目の炭は置けません。ふつうは2〜3個で、立ち上げは3個が多い。低温の葉は1〜2個、高温の葉は3〜4個がめやすです。HMDがC1のときだけ、枠は2つです。

熱を上げる

炭の火は戻りません。熱を上げるには、空いている炭の枠に新しい炭を足します。

チャージ＆ドロー（1ターンに1回）

手札を1枚、裏向きで火力ゾーンに置き、山札から1枚引きます。置いた札は種火になり、すぐ熱+1。1ターンに1回だけです。置かずに引くことも、引かずに置くこともできません。しなくてもかまいません。

炭カードを焼いて、のせる

炭カードは、自分のターンならいつでも炭焼き場に置けます（フラットは縦向き、キューブは横向き）。カードを使う1枚には数えません。枠があれば何枚でも置けます。

炭焼き場の枠は4つ。火おこし中と焼けた炭を合わせて4枚まで。カードでは増えません。

  • 焼けた炭は、炭の枠が空いていれば、自分のターンにいつでものせられます。取っておくこともできます。

灰にする（1ターンに1回）

蒸らすターンと、提供の自分のターンに1回だけ、炭を1つ選んで灰にできます。火がいくつ残っていてもかまいません。

  • 熱を下げる　熱すぎるときに、炭を1つ外します。
  • 入れ替える（炭交換）　枠がいっぱいのとき、弱った炭や種火を外して、焼けた炭をのせます。立ち上げの種火も、こうして替えていきます。

ヒント同じ熱6でも、キューブ炭2つ（火3＋火3）なら枠が2つ空いています。炭が4つだと、足す前に1つ灰にします。

6準備フェイズ 葉を詰めて、蒸らす

全員が6ターンずつ、先手から交互に行います。自分のターンには次の順で進めます。

  1. 火を見る　炭焼き場を進めます。準備のあいだ、炭は冷めません。
  2. 「詰める」か「蒸らす」　どちらか1つを行います。
  3. カードを使う　器具・人物と、「準備」「いつでも」のカードを1枚使えます。2の前でも後でもかまいません。
  4. 手札の上限　8枚以上なら7枚になるまで灰にします。

詰める

フレーバー場の山から葉カードを合計4枚まで取り、自分のボウルに置きます。1ターンに取れるのは2種類まで。ボウルの容量を超えては取れません。先手の最初の「詰める」だけ、2枚までです。

蒸らす

山札から2枚引きます。そのあと、チャージ＆ドロー（1回）、炭カードを置く・焼けた炭をのせる（何回でも）、炭を灰にする（1回）ができます（6ページ）。

3つの決まり

  • 蒸らすには、ボウルに葉が8枚以上必要です。
  • 一度でも蒸らしたら、もう詰められません。
  • 炭に触れるのは蒸らすターンだけです。詰めるターンには、チャージも炭カードを置くこともできません。

6ターンが終わったら、主役の葉に主役マーカーを置き、提供フェイズに進みます。

ミックスの決まり

主役
いちばん枚数の多い種類。同数なら持ち主が選びます。主役マーカーは、ほかの種類が主役の枚数を上回ったときだけ移します。
脇役
主役以外で2枚以上ある種類。1枚だけの葉は枚数には数えますが、脇役ではありません。
ミックス
脇役が1種類でもあれば成立。毎口+1。
相性
主役の相性のしるしと同じ系統の脇役がいれば、さらに+1。
3種類以上
加点は増えません。そのかわり脇役それぞれの能力が働き、弱点を補えます。
単品
葉が1種類だけの一台。ミックスの加点はありませんが、単品を強くするカードがあります。
濃厚
ボウルの葉が合計10枚以上あるあいだ、毎口+1。印象も+1。

7提供フェイズ 熱を整えて、一口を競う

1ラウンドは、審査カードをめくる → 先手のターン → 後手のターン → 審査の順です。めくった1枚が、このラウンドの吸い方です。3ラウンドで1セッションになります。

自分のターン

  1. 火を見る　①炭焼き場を進める　②冷める（炭を1つ選んで、火を1下げる）
  2. 引く　山札から1枚引きます（普通のドロー）。
  3. 手を打つ　次のことを、好きな順で行えます。
    • チャージ＆ドロー（1回。手札を1枚置いて、1枚引く。炭の枠が空いているとき）
    • 炭カードを炭焼き場に置く・焼けた炭をのせる（何回でも）
    • 炭を灰にする（1回。熱を下げる・入れ替える）
    • カードを1枚使う（手番いつでも一口）。もう1枚のカードなら、続けてもう1枚
  4. 手札の上限　8枚以上なら7枚になるまで灰にします。

チャージしないターンに引けるのは、普通のドローの1枚だけです。置かずに引くことも、引かずに置くこともできません（山札も灰置き場も空なら、置けません）。

ターンを終えたときの熱と仕込みが、そのまま審査に出ます。吸い方は見えているので、判定熱が帯に入るように合わせます。ターンを終えたあとは、動かせません。

一口のカードを仕込む

一口のカードは、自分のターンに使って、自分の前に表向きで置きます。そのラウンドの審査で、自分の一口にだけ効きます。相手にも見えるので、後手は先手の仕込みを見てから決められます。

審査（一口）

  1. 採点　はじめにめくった審査カードの吸い方で、2人とも点を数えます（右）。
  2. 一票　印象の高かった方が+2点。点で負けている方なら+3点（右下）。
  3. 次へ　仕込んだカードを灰にし、先手マーカーを相手に渡します。

使った審査カードは、表向きのまま横に並べておきます。山に何が残っているかは、だれでも数えられます。

8審査員の吸い方に合わせる

審査カードは、ラウンドのはじめにめくります。2人とも吸い方を見てから、熱と仕込みを決めます。

吸い方判定熱この一口の決まり

仕込みは相手に見える

後手は、先手の熱と仕込みを見てから動けます。ジャスト狙いの渾身の一口は、実況の煽り（判定熱+1）で焦がされるかもしれません。先手は毎ラウンド交代します。

吸い方に合わせる。後手の揺さぶりに備える

ブルーベリー（適温4〜6・ジャスト5）。「ふつうに吸う」なら熱5でジャスト。「長く吸う」（+1）がめくられたら、熱4に合わせます。「ゆっくり吸う」（−1）なら熱6です。

マンゴー（適温5〜6・ジャスト6・焦げ7）は、「長く吸う」なら熱5がジャスト。熱6のままだと、判定熱7で焦げます。先手は、合わせたあとで後手に煽られる（+1）こともあります。

熱を1つ上げて熱を逃がす吸い（判定熱−2）を仕込めば、適温に旨みの+1点。煽られてもジャストです。次のラウンドの吸い方は、山に残る枚数を数えるか、「吸い方を読む」で先に見ます。

9セッションの区切りと、葉の体力

3ラウンド目の審査が終わったら、セッションの区切りです（最終セッションのあとを除く）。

  1. 葉が減る　全員、自分のボウルから葉を2枚選び、箱に戻します。
  2. 効果が切れる　「このセッションの終わりまで」の効果が終わります。
  3. 進める　セッションマーカーを1つ進め、次のラウンドに入ります。

どの葉を減らすかは自分で選べます。主役を多めに減らせば脇役が残り、ミックスが長く続きます。10枚を切ると濃厚（点と印象の+1）がなくなります。

燃え尽き　体力が0になったら、その一台は燃え尽きです。以後の一口はすべて0点で、印象も0です。

葉の体力　ボウルの葉の枚数が、その一台の体力です。

体力が減る場面いつ減る葉
消耗セッションの区切り2枚（自分で選ぶ）
焦げ判定熱が主役の焦げライン以上だった主役を1枚
見せ煙葉を減らして発動するとき主役を1枚
  • 葉を失った結果、ほかの種類が主役の枚数を上回ったら、主役マーカーを移します。帯も味値も新しい主役のものに変わります。
  • 焦げたら「焦げ」、ジャストなら「ジャスト」の記録チップを取ります。決め手で数えます。

10ゲームの終わり

最終セッションの3ラウンド目の審査が終わったら、ゲーム終了です。

  1. 決め手　場に出ている審査員カードを1枚ずつ確かめ、条件を満たした作り手に点を加えます（12ページ）。
  2. 勝敗　合計点が高い作り手の勝ちです。

同点のとき　ボウルに残った葉が多い方、次に手札が多い方の勝ち。それでも同じなら引き分けです。

11サポートカードの種類

炭

炭焼き場で焼いてからのせる、火の大きい炭です。必要火力はなく、カードを使う1枚にも数えません。チャージして種火として置くこともできますが、その場合はふつうの種火（火1）と同じです。

技

使って効果を処理したら灰にします。手番の技は炭の扱いや次への備え、一口の技は吸わせ方で、自分のターンにその一口へ仕込みます。

器具

使うと自分の場に残り、効果が続きます。場に置けるのは3枚まで。4枚目を出すときは、どれか1枚を灰にします。準備フェイズにも使えます。

人物

使うと自分の場に残ります。場に置けるのは1人まで。新しい人物を出したら、前の人物は灰にします。準備フェイズにも使えます。

イベント

使ったら灰にします。会場で起きる出来事で、相手に影響するものがあります。相手に効くカードはすべて手番です。

「次の一口」と書かれた効果

相手の「次の一口」に効くカードは、次の審査で働きます。先手が使えば、相手は自分のターンで熱を動かして受けられます。後手が使えば、先手はもう動けません。同じ効果が重なったら、すべて足します。

15デッキの組み方

はじめは15ページの組み済みデッキを使ってください。

  • デッキはちょうど40枚。

炭カードは何枚入れるか

めやすは8〜12枚。フラット炭は2回、キューブ炭は3回冷めるまでもちます。入れすぎると、使えるカードが減ります。

高温の葉（コーヒー・ダブルアップル）は12枚以上、キューブを多めに。必要火力6〜7の大技に届きます。

味値4の葉は印象が強い葉。焦げやすいので、ブロー・熱を逃がす吸いを切らさないこと。

      一台勝負　ルールブック 第0.6版3〜4人で遊ぶ・調整メモ

      203〜4人で遊ぶ 1対1対1対1

      3人でも4人でも、同じカードと同じ流れで遊べます。チームは組まず、全員が自分の一台で競います。変わるのは下の7つだけです。2人で遊ぶときは、どれも今までどおりです。

      変わる決まり

      1. 手番は席の順　先手から時計回りに、1人ずつターンを行います。最初の火、準備フェイズ（1人6ターン）、提供フェイズのどれも同じです。
      2. 先手は次の席へ　ラウンドが終わるたびに、先手マーカーを時計回りの次の席へ渡します。「後の先」を使った人は、次のラウンドのいちばん後になります。
      3. 一票は1人だけ　印象がいちばん高い1人に+2点（点で上の人がいれば+3点）。いちばん高い印象が2人以上で並んだら、だれにも入りません。
      4. ねらうカードは相手を選ぶ　「実況の煽り」と「すきま風」は、使うときに相手を1人選びます。すきま風で選べるのは、炭のある相手だけです。「会場の熱気」は、今までどおり全員に効きます。
      5. 場の葉を増やす　フレーバー場の山は、1種につき3人なら18枚、4人なら24枚にします（2人の12枚に、1人6枚ぶんずつ足す）。
      6. 決め手はいちばんの1人に　審査員の決め手は、条件でいちばんの1人に入ります。いちばんが並んだら、並んだ人に2点ずつです（カードの「同点なら全員+2」は、こう読みます）。
      7. 順位　点の高い順です。同じなら、残った葉が多い方、次に手札が多い方が上。上の2人がどれも同じなら、引き分けです。

      先手の最初の「詰める」が2枚までなのは、先手の1人だけ。審査カードの山は12枚のままで、ラウンドのはじめに1枚めくります。
