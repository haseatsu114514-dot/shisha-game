# 一台勝負　カードとプレイマットのデザイン依頼書（Codex用）

2026-11-11。オーナーの決定で、見た目の方向を定めました。

> 「カードデザインとかはやはり**トレカ風**にしたい。ゲーム内で**集める楽しみ**もあるし。
> あと**ハガルもカードに**したり、**炭焼き場も本物を出すんじゃなくてプレイマット上でカードゲームとして作る**。
> コーデックスに依頼して**ちゃんとデザインを作って**」

この依頼書は、ゲーム内のミニゲーム「一台勝負」（`remake/ichidai.html`）のカードとプレイマットを、Codex が**トレーディングカードゲームとしてデザインする**ためのものです。
**いちばん下のコードブロックを、そのまま Codex に貼ります。** その上は、依頼の考え方と、オーナーが出来上がりを選ぶときの物差しです。

- 規則: [第0.5版ルールブック](ichidai_shobu_rulebook_v0.5.pdf)。カードの数値と文は [`cards.js`](cards.js)（ゲーム内は `remake/js/minigames/ichidai-data.js`）。
- 同じ日の朝に書いた「卓上（印刷）向けの3方向の見本」の依頼は、この決定で置き換えました（前の版は Git の履歴にあります）。

## 1. いまの状態（仮の見た目）

`remake/ichidai.html` を開くと、もうプレイマットの上でカードゲームとして動きます。**仕組みと並びは出来ていて、見た目だけが仮**です。

| もの | いま | 頼みたいこと |
|---|---|---|
| カードの枠 | CSSの面と線（種類ごとに色を変えただけ） | トレカとしての枠をデザインする |

## 2. 卓の作り（変えないでほしい骨組み）

卓に出るものは、**葉・ボウル（ハガル）・HMD・炭もふくめて全部カード**です。現物の絵（コンロ・ボウル・炭の塊）は卓に置きません。

**2026-11-11 追記: 卓は「対面で囲む見え方」になりました**（オーナー「3D要素を入れたり、実際に対面でカードゲームしてる感が欲しい。のっぺり2dよりコンシューマーのカードゲームみたいに」。`docs/owner_requests.md` ICG30）。カードとマットのデザインは、この見え方の上で確かめてください。

- **部屋**（店の中・暗くぼかした背景）の手前に **相手の席**（相手のバストアップと、胸の前に持った手札の裏）があり、その手前に **奥行きを付けて傾けた卓**（木の縁つきのプレイマット）があります。
- 卓は**自分と相手で点対称**です（2026-11-11 オーナー「プレイマットが相手と自分で非対称なのが気になる」。ICG34）。手前の段＝自分の札（左から 炭焼き場・ボウルとHMD・器具と人物・山札と灰）、奥の段＝相手の札（同じ並びを180度まわしたもの。札は向こう向き＝上下逆さ）、あいだの帯＝「相手の一口」・審査の山と審査員・「自分の一口」。**奥の札は小さく、縦につぶれて見えます**（幅 約40px・高さ 約35px）。絵と左上のしるしだけで見分けられることが大事です。
- **火力ゾーンは卓の両端の縦の柱**です（左端＝自分、右端＝相手。オーナー「判定のゲージと火力ゾーンは近づけたい。ダメージゾーンみたいに横において積み上げて火力にしてもいい」。ICG34）。札を**横向きに寝かせて**、自分は手前から奥へ、相手は奥から手前へ積みます。1段＝熱1（表向きのキューブ炭は2段ぶんの高さ）。柱のすぐ外側に**判定のゲージ**（1〜10 の目盛り。主役の葉の帯の色と★）が並び、積んだ高さがそのまま判定の位置になります。裏面（種火）は横向きで並ぶので、**横にしても熾火の列に見える**ことが大事です。
- **第0.4版（ICG40〜43）: 火力ゾーン＝HMDの上の炭で、炭は4つまで**。炭そのものに火があり（フラット炭2・キューブ炭3・裏向きの種火1）、熱は火の合計です。柱には**炭1つを火の段数ぶんの高さ**で積み（キューブ炭は3段ぶんの地に札が1枚）、札の横に「いまの火」の数字の印が付きます。火は下がるだけなので、弱った炭は少し暗く出ます。炭カードの絵は、**3段ぶんの地の中に置いても、横向きでも何の炭か分かる**ことが大事です。
- 数字と文は、卓の手前に立てた HUD に出します: 左上＝相手の点・票と火力のゲージ、上＝ラウンド、右上＝案内、右＝ボタン、左＝いまの熱・火力の数字、下＝自分の顔と点・**扇形に持った手札**・選んだ札の説明（選んでいないときは「審査員の声」の掲示板＝一口ごとの結果と一言のログ。ICG47）。右上の案内には、炭の手引き（熱・炭・次の3行。ICG45）が出ます。準備のあいだだけ、葉の札の山10種の盆が卓の上に立ちます。
- 札は卓の上を飛んで置かれます（手札 → 火力ゾーン・炭焼き場・この一口。相手の札は席から裏のまま出て、表になる）。**裏面は飛ぶあいだ大きく見える**ので、裏面のデザインも見どころです。
- 対戦の前に「VS」の演出が入ります。絵は**登場カットインのグラフィック絵柄（顔の白い人物絵）と、その人の背景**で、あいだを電撃が走ります（ICG31・ICG33。その絵が無い人は顔アイコン）。
- 対戦中、相手は場面に合った**一言**を言います（席の顔の左に吹き出し。ほかの HUD に重ならない幅。ICG35・ICG38）。
- 相手の席は**動きます**（ICG48）: ふだんの揺れとしぐさ、カードを使うときの身の乗り出しと放射の光、審査の結果への反応（跳ねる・のけぞる・沈む）、頭のそばの気持ちのしるし（きらめき・汗・♪・！）。
- **詰めた葉は葉の札の束**としてボウルの札の横に置きます（ICG37）。種類ごとに表向きで束ね、帯に枚数（金＝主役・銀＝脇役）。枚数が多いほど束が厚く見えます。葉の札は卓の上では小 52px なので、**箱絵の色と形だけで種類が分かる**ことが大事です。
- マットの枠の線と名前は、札の邪魔をしないよう**細く薄く刷った**ものにしました（ICG36。空いた置き場は四隅の印だけ。相手の側の名前は出さない）。カードやマットのデザインでも、枠より札が目立つことを大事にしてください。

| マットの枠 | 置かれるもの | 大きさ（幅） |
|---|---|---|
| 熱（HUD・卓の左に立てる） | いまの熱・火力の数字と、残りのカード枚数。目盛りは火力ゾーンの横へ移した | — |
| 葉・ボウル・HMD | 葉の札の束（種類ごと・帯に枚数）と、ボウルの札・HMDの札（タップで葉とセッティングの中身） | 束 小 52px／ボウル・HMD 中 76px |
| 火力ゾーン（卓の両端の柱） | HMDの上の炭（4つまで）。表向き＝炭カード（火2〜3）、**裏向き＝種火（火1）**。横向きに寝かせ、火の段数ぶんの高さで積む。札の横に火の数字。外側に判定のゲージ（1〜10・帯の色・★） | 小 64px を寝かせる（約90×64px）。1段 約46pxで、少し重なる |
| 炭焼き場 | 4枠。置いたばかりは横向き、火がまわると縦向き、焼けたら光る | 小 70px |
| 器具・人物 | 器具3枠・人物1枠 | 小 64px |
| 山札・灰 | 裏面の山と枚数 | 小 64px |
| 審査の山（中央） | 審査カードの裏面の山。めくると、山から裏返りながら手前に来て大きく出る | 56px／拡大 250px |
| この一口（中央） | 仕込んだ一口のカードを表向きに置く枠。相手のぶんと自分のぶん | 小 56px |
| 準備の場（準備のあいだだけ・HUDの盆） | 葉の札の山が10種 | 86px |

| 相手の札（卓の奥） | 上と同じ枠を、向かい合わせに並べたもの。札は向こう向き | 奥 52px（傾きで約40×35pxに見える） |

- 画面は 1280×720 を基準に、スマホ横持ち（844×390）では全体が約0.54倍になります。**手札の札は実寸で幅60pxほど**になります。

## 3. カードに載せる情報

数値と文はコードが出します。**絵の中に文字や数字を描きません。**

| 部分 | 中身 | 出る大きさ |
|---|---|---|
| 左上のしるし | 技・器具・イベント・人物＝必要火力（自分の火力がこの数以上なら使える。払わない）／炭＝熱／葉＝味値／ボウル＝容量／HMD＝なし | 全部 |
| 名前 | 2行まで | 中より上 |
| 絵 | 1題材。レア度の札が右下に重なる | 全部 |
| 種類の行 | 種類（炭・技・器具・イベント・人物・ボウル・HMD、葉は系統）＋ 使える時（手番／一口／準備／いつでも）か着火 | 手札・場・拡大 |
| 温度の帯 | 葉だけ。0〜10 の11マス（ジャスト＝金★・適温＝緑・ズレ＝淡い黄・外れ＝灰青・焦げ＝赤） | 手札・場・拡大 |
| 文 | 効果の文 | 拡大だけ |
| 番号とレア度 | `No.001/066`・レア度の名前 | 拡大だけ |

- 種類は色でも分けます（いまの仮の色: 炭＝橙、技＝ラベンダー、**一口の技＝珊瑚**、器具＝青鋼、イベント＝金、人物＝緑、ボウル＝素焼き、HMD＝銀、葉＝系統の色）。色みは変えてよいですが、**「一口」の札だけ手札で一目で分かる**ことは守ります。
- 系統の色: フルーツ＝橙、清涼＝青、スパイス＝赤茶、フローラル＝紫、スイート＝黄土。色だけに頼らず、しるしでも区別します。
- 通し番号は 66（葉20・ボウル4・HMD4・デッキのカード38）。レア度は C／U／R／SR の4段で、**いまの割り当ては見た目のための仮**です（`ichidai-data.js` の `rarityOf`）。集める遊び（入手・図鑑）はまだありません。

## 4. トレカ風にするとは（この依頼でいう意味）

- **枠に種類とレア度の顔がある。** 名前の帯・絵の窓・種類の行・文の箱・番号の行が、決まった場所にある。並べると同じ弾のカードに見え、種類は取り違えない。
- **レア度で欲しくなる。** C は素直な枠。U は縁に金属。R は箔の縁と名前の帯の光。SR は絵が枠を越える・全面の箔など、引いた時にうれしい加工。動く光は CSS で作り、動きを減らす設定では止める。
- **裏面がそのゲームの顔になる。** デッキの裏面は、火力ゾーンに裏向きで並ぶと**熾火（種火）の列**に見える。上下対称。審査カードの裏面は別の色で、山を見れば区別がつく。
- **プレイマットがある。** 石や革や布の面に、枠が刷ってある。枠の名前は読めるが、置いた札より目立たない。自分の側と相手の側が向かい合っている。
- **飾りに理由がある。** 意味のない宝石・渦・紋章を足さない。本編の夜紫UI（深い夜紫・ラベンダーの光・細い金の線・薄い煙）と地続きで、熱いところ（炭・一口・ジャスト）だけ橙と金が効く。

## 5. 物差し（オーナーが選ぶとき・Codex が自分で確かめるとき）

1. **手札で種類と必要火力が分かるか。** 幅112px（スマホでは実寸60px）で、左上のしるし・種類の色・「一口」が分かる。
2. **小さい札で炭が読めるか。** 幅70pxと36pxで、表向きの炭（熱1／熱2）と裏向きの種火の区別がつく。
3. **拡大で読めるか。** 幅240pxで、名前・文・番号・レア度が気持ちよく読める。
4. **レア度が並べて分かるか。** C・U・R・SR を並べて、説明なしで順番が分かる。
5. **マットの上で札が主役か。** 枠の線と名前が、札と白い文字の邪魔をしていない。火力ゾーンに10枚並んでも崩れない。
6. **家族に見えるか。** 葉・炭・技・人物・ボウル・審査カード・裏面を並べて、同じゲームのカードに見える。
7. **白黒でも読めるか。** 数字・帯のジャストと焦げ・種類の区別が、色を落としても残る。
8. **集めたくなるか。** 拡大した1枚を見て、ほかの札も見たくなる。

## 6. 作り方の決まり

- **カードを画像生成で丸ごと描かない。** 枠の形・文字・数字・温度の帯はコード（CSS／SVG）で組み、画像生成で作るのは「質感」（金属・紙・布・石・箔の模様など、敷きつめたり引き伸ばしたりできるもの）と「絵」だけ。どちらにも文字・数字・ロゴ・透かしを描かない。
- 画面の文字は 12px 以上（12〜13px は太字）。`node remake/test/typography_css.mjs` が確かめます。
- 規則と操作は変えない（`ichidai-rules.js`・`ichidai-ai.js`・`ichidai-data.js` の数値と文、`ichidai.js` の `data-test`）。札の中の要素を足したいときは、`ichidai.js` の `tcg()` と `cardView()` だけを触る。
- 人物は正規の顔アイコン・立ち絵を使う（描き起こさない）。シーシャ台・ハガル・HMD・炭・ホースが写る絵を新しく作るときは `docs/shisha_reference.md` の「4. 画像生成の必須手順」。実在の銘柄・製品・ロゴは描かない。
- 画像は WebP にして `remake/img/ui/ichidai/` の下へ。元の PNG は `assets/ui/ichidai/`、生成したままの原画と記録は `asset_sources/card_game/design-20261111/`（どれも Git LFS）。

## 7. 差し替え口（実機で見比べる）

見た目の案は、**本体の CSS を書き換えずに重ねて**見比べます。

- `remake/ichidai.html?skin=a` で開くと、`remake/css/ichidai-skin-a.css` が重なり、卓の根に `data-skin="a"` が付きます（`a` の所は英小文字・数字・ハイフン）。
- 案の画像は `remake/img/ui/ichidai/skin-a/` に置き、その CSS から読みます。
- 札の作り（`ichidai.js` の `tcg()`）:

## 8. Codex へ貼る依頼文

```

オーナーの決定: トレカ風にする（ゲーム内で集める楽しみもある）／ハガルもHMDも炭もカードにする／炭焼き場は現物を出さず、プレイマットの枠にカードを置く。
今回は第1段階（デザインの案を2つ、実機で見比べられる形にする）です。規則・操作・数値は変えません。

■ 先に読むもの（この順）
1. docs/design/card_game/card_design_brief.md … この依頼の全体。2〜4節が条件、5節が物差し、6節が作り方の決まり、7節が差し替え口。

   準備（葉の札を選ぶ）・提供（火力ゾーンと炭焼き場）・審査・相手が札を使ったとき・顔やボウルをタップして開く札、を一通り見る。
3. remake/css/ichidai.css の「札（トレカ）」「プレイマットの枠」「火力ゾーンの札・炭焼き場の札」の節、remake/js/minigames/ichidai.js の tcg() と cardView()。
4. 本編の夜紫UI: asset_sources/ui/craft-night-20261102/prompts/style.txt と remake/img/ui/craft-night/（色と描き方の基準）。

■ 作るもの（案ごとに）
A. 札の枠: 炭／技（手番）／技（一口）／器具／イベント／人物／ボウル／HMD／葉（5系統）／審査カード。
   名前の帯・左上のしるし・絵の窓・種類の行・温度の帯（葉）・文の箱・番号の行。大きさ6段（240／112／104／82／64／36px）それぞれで成り立つこと。

F. 審査カードの表: めくったときに中央へ大きく出る札（.ichi-puff-card）。判定熱の変化（±0・+1・−1・+2）がいちばん大きい。
```
