# 一台勝負 第0.3版の設計（2026-11-11）

オーナーの要望（`docs/owner_requests.md` ICG23〜ICG29）を、規則として組み立て直した記録。ゲーム内の規則は `remake/js/minigames/ichidai-rules.js` の `RULES`、カードは `ichidai-data.js`、比べた計算は `sim_v03.mjs`。

> 自分が今回どんなフレーバーミックスで戦ってるのかとか、フレーバーの体力はどこかに出したい
> このゲームコスト制ではなくてどの火力まであがってたら使えるみたいなのがいい。その代わり基本は1ターンに1枚しか使えず。チャージとか炭焼きゾーンに送るのは自由にできるけど
> 結構熱を下げる系の技は高めの時に使えるけど下げることで美味しい部分を吸わせて点数を得るカードとか強烈な味を出して印象に残したりライバルの作ったシーシャの印象に勝つとか
> ちょっとこの辺のシステムはしっかり考えてみて欲しい自信無いので
>
> （続けて）カードによっては熱を下げて発動とか追加コストあるの作ってもいい。あと火力いくつから使えるカードなのかはバランス調整して

## 1. 決めた規則

| | 第0.2版 | 第0.3版 |

| 灰にする | 何回でも | **1ターンに1回**（追加コストで灰にするのは数えない） |
| 一票 | 帯の良い方に+2点 | **印象の高い方に+2点**。同じなら入らない |
| 印象 | なし | **味値＋帯の分＋濃厚1＋カード**。帯の分はジャストも適温も+1、ズレ−1、外れ−2、焦げ−3。葉が無ければ0 |

### カードの必要火力と追加コスト（調整後）

熱は採点の帯でもあるので、必要火力の段で「どの葉なら届くか」が決まる。低温の葉（ローズ3〜4）は3まで、真ん中の葉（ブルーベリー4〜6）は5〜6、高温の葉（ダブルアップル6〜8）は7まで、ふだんの熱で届く。

| 必要火力 | 役目 | カード（追加コスト） |
|---|---|---|
| 0 | 読む・回す | 吸い方を読む、追い炭（山札から種火2枚・もう1枚使える）、ひと息（1枚引く・もう1枚使える）、買い占め |
| 1 | 小さな調整 | 熱を入れる吸い（帯に入れば印象+1）、火おこし、キッチンタイマー、後の先、詰め直し |
| 2 | 器具・人物 | 風防、会場の熱気、なる・みんと・ましろ・つむぎ・パッキー |
| 3 | 印象・揺さぶり・低温でも使える技 | **見せ煙（葉1・印象+4）**、**内寄せ（このセッション印象+1）**、勝負の一服、灰落とし、葉をほぐす、**トングさばき（炭1・2枚引く・もう1枚使える）**、すきま風、チャコスタ、ディフューザー、スミさん、アダム |
| 4 | 守り | ブロー（焦げを適温として採点）、外寄せ、アイスホース |
| 5 | 熱を下げて立て直す・攻め | **仕切り直し（炭2・3枚引く・もう1枚使える）**、実況の煽り |
| 6 | 熱を下げて点にする | **熱を逃がす吸い**（判定熱−2・帯に入れば+1点）、**渾身の一口（炭1・ジャストなら+3点・印象+2）** |
| 7 | 大技 | **アンコール（炭2・最終セッションの一口の点をもう一度）** |

## 2. なぜこの形にしたか

### 火力を「払うもの」から「届いたら開くもの」へ

熱は採点の帯でもあるので、熱を上げるほど強いカードが開くかわりに、焦げ・ズレに近づく。高温の葉（ダブルアップル・コーヒー）は帯の中で必要火力6〜7に届くが、味値は3〜4。低温の葉（ローズ）は大技に届きにくいが、味値4で印象が強い。

「熱を下げる系の技は高めの時に使えるけど、下げることで美味しい部分を吸わせて点数を得る」は、熱を逃がす吸いを **必要火力6・判定熱−2・帯に入れたら+1点** にして形にした。ローズなら熱6まで上げて（そのままなら焦げ）、熱を逃がす吸いで4のジャストに落とす、という攻め方になる。

### 追加コスト: 熱を下げて発動する

「熱を下げて発動」は、追加コストで**自分の炭を灰にする**カードにした（渾身の一口・トングさばき・仕切り直し・アンコール）。必要火力は払う前の火力で見るので、**高い熱でしか使えず、使うと熱が下がる**。熱を上げて大技を開け、払って帯へ降りる流れになる。灰にする操作（1ターン1回）とは別に数えるので、熱を下げる手段にもなる。

見せ煙の追加コストは**主役の葉1枚**（＝葉の体力）。体力を使って印象を取りにいくか、残して濃厚（10枚以上で点と印象+1）を保つかの選択になる。

### 1ラウンドに1枚と、枠を返すカード

カードを使う機会を毎ラウンド1回の決断にした。チャージは何回でもなので、手札はいつも「熱に変える」か「効果として使う1枚」かを選ぶ。

計算で見ると、**手札はほぼいつも7枚近くあって、1局に約7枚捨てている**（毎ターン2枚引くうえ、熱は炭カードでまかなえて、チャージは提供の1ターンに0.12回）。足りないのは手札ではなく「1枚の枠」なので、「カードを引くだけ」「熱を上げるだけ」のカードは枠を使う値打ちがなく、CPUが一度も使わなかった（追い炭・トングさばき・仕切り直しなど8枚）。そこで引くカードと追い炭に**「このラウンド、カードをもう1枚使える」**を付け、枠を返す形にした。熱を上げるだけだった熱を入れる吸いには「帯に入れば印象+1」を、意味がなくなっていた内寄せ（判定熱+1）は「このセッションの印象+1」（葉を内に寄せて濃くする）にした。

毎ターン引くのを1枚に減らす案（下の表の I）も試した。手札は締まるが、強いCPUとやさしいCPUの差が縮み（96%→86%）、熱の要る高温の一式が弱くなりすぎた（29%）ので採らない。

### 灰にするのは1ターンに1回

何回でも灰にできると、チャージで一気に上げて大技を使い、同じターンに灰で帯へ戻せてしまい、「上げると危ない」が消える（CPUはこの使い方をしないので計算の数字にはほぼ出ないが、人が遊ぶと抜け道になる）。熱を一気に下げたいときは、追加コストのカードが役目を持つ。

### 一口のカードは、めくる前に仕込む

1枚しか使えないのに、めくったあとで受けられると、外れても直せて読みが効かない。仕込みにすると、

- 「カードは自分のターンに1枚」で言い切れる（オーナーの「1ターンに1枚」どおり）
- 後手は先手の仕込みを見てから決められる（印象で上を行く・揺さぶりに切り替える）
- 審査カードをめくる瞬間が「当たるか」の見せ場になる

という利点がある。計算の差は小さいので、主な理由は分かりやすさと読み合い。めくったあとに使う形は `rules.reactAfterReveal: true` で戻せる。

### 印象は「味の強さ」で競う

第0.2版の一票は帯の良い方に入るだけだった。印象を作っても、帯の分をジャスト2・適温1にすると、印象の差はほぼ帯の差になる（計算で、帯が悪いのに一票を取ったのは5%）。

ジャストと適温の差はすでに点（ジャスト+2）で付いているので、印象ではジャストも適温も同じにして、**味値（味の強さ）・濃厚・カード**で競うようにした。帯が悪くても強い味が一票を取る場面が21%になり、一票の約半分（49%）はカード（見せ煙・熱を入れる吸い・内寄せ・渾身の一口）の印象で取っている。「強烈な味を出して印象に残す」「ライバルの印象に勝つ」（勝負の一服）が、温度合わせとは別の軸になった。

### 葉の体力

ボウルの葉の枚数が、そのまま一台の体力。見せ煙で削れ、焦げで主役が削れ、セッションの終わりに2枚減る。画面では、自分のボウルの下に「主役・脇役のミックス」と体力の棒（10枚の濃厚の位置に印）を出す。相手は主役と体力だけ。

## 3. 計算で確かめたこと

### 規則の案（`node docs/design/card_game/sim_v03.mjs --games 150`）

ゲームの規則とCPUで、強いCPUどうし150局＋強い対やさしい150局。カードと一式は調整後のもの。

| 案 | 帯（ジャスト・適温） | 帯が悪いのに一票 | 強い対やさしい | 一式の勝率 a / b / c |
|---|---|---|---|---|
| A めくったあとに一口のカード（チャージ1・灰1・印象は帯しだい） | 75%・22% | 5% | 95% | 48% / 54% / 47% |
| B A＋チャージ何回でも | 77%・20% | 5% | 93% | 48% / 50% / 53% |
| C B＋灰も何回でも | 77%・20% | 5% | 92% | 50% / 49% / 52% |
| D （参考）A＋カード2枚 | 75%・20% | 5% | 83% | 48% / 50% / 52% |
| E 一口のカードは仕込む（チャージ1・灰1） | 69%・26% | 7% | 93% | 41% / 73% / 35% |
| F E＋チャージ何回でも | 70%・25% | 7% | 94% | 46% / 67% / 36% |
| **G 採用: F＋印象はジャストも適温も同じ** | 69%・26% | **21%** | **96%** | **48% / 53% / 47%** |
| H G＋一票3点 | 69%・26% | 21% | 95% | 42% / 52% / 56% |
| I G＋毎ターン引くのは1枚 | 61%・31% | 28% | 86% | 54% / 29% / 68% |

読み取り:

- **カード2枚（D）は強い対やさしいの差が縮む**（83%）。1枚の方が、どのカードを使うかの判断が勝ち負けに出る
- チャージの回数（A→B）・灰の回数（B→C）は、CPUどうしではほとんど差が出ない。決め方は上の「なぜ」による
- 熱を逃がす吸いは、使った回のほぼすべてで適温以上に入っている（243回中238回）
- 仕込み（E・F）は、印象が帯しだいのままだと高温の一式 b が強くなりすぎる。印象を味の強さにする（G）と、3つの一式がそろう。一票3点（H）では味値4のローズを使う c が強くなりすぎる

### カードごとの使われ方（調整後・強いCPUどうし300局）

「使用率」は、そのカードが提供の自分のターンの手札にあったうち、使ったターンの割合。

| 追い炭 | 0 | 14% | 6.5 | | ディフューザー | 3 | 41% | 4.6 |

| 熱を入れる吸い | 1 | 11% | 3.3 | | すきま風 | 3 | 30% | 5.7 |
| 後の先 | 1 | 14% | 4.0 | | トングさばき | 3 | 19% | 2.2 |
| キッチンタイマー | 1 | 33% | 4.0 | | ブロー | 4 | 2% | 4.5 |
| 風防 | 2 | 54% | 4.0 | | 仕切り直し | 5 | 9% | 4.7 |
| 会場の熱気 | 2 | 14% | 2.7 | | 実況の煽り | 5 | 28% | 5.5 |

（使ったときの熱は、追加コストを払ったあとの熱。人物は省略。外寄せは一式に入っていない）

調整の前は、追い炭・火おこし・トングさばき・内寄せ・灰落とし・外寄せ・仕切り直し・ブローの8枚が0〜1%だった。調整で変えたこと:

| カード | 必要火力 | 変えたこと |
|---|---|---|
| 見せ煙 | 4 → **3** | 追加コスト 葉1・印象+3 → +4（9% → 21%）。低温の葉でも使える |
| 内寄せ | 2 → **3** | 判定熱+1 → このセッションの印象+1（使われ方44%で強めなので3に） |
| 実況の煽り | 4 → **5** | 使った人の勝率59%で強め。中温以上の葉の揺さぶりに |
| トングさばき | 2 → **3** | 追加コスト 炭1・2枚引く・もう1枚使える |
| 仕切り直し | 7 → **5** | 追加コスト 炭2・3枚引く・もう1枚使える（熱を下げて立て直す） |
| ブロー | 5 → **4** | 焦げライン以上なら、ズレではなく適温として採点。焦げたときの保険（CPUは焦げないので2%） |
| 外寄せ | 5 → **4** | 判定熱を下げたまま熱を上げて、必要火力に届かせる組み合わせ用 |
| 渾身の一口 | 6 | 追加コスト 炭1 を足した（87%使われる強いカード。払うと熱が下がるので、ジャストの1つ上で使う） |
| アンコール | 7 | 追加コスト 炭2 を足した |
| 熱を入れる吸い | 1 | 帯に入れば印象+1 を足した |
| 追い炭・ひと息 | 0 | 枠を返す形に（追い炭は種火2枚、ひと息は1枚引く） |

一式の入れ替え（ゲーム内の組み済み3式。300局で a 50% / b 55% / c 45%、上の表の G は150局で 48% / 53% / 47%）:

- b（単品の火持ち型）: ブロー2・仕切り直し1 → 熱を逃がす吸い2・ひと息1
- c（低温の攻め型）: ローズでは届かない渾身の一口2と外寄せ1 → 見せ煙1・勝負の一服1・内寄せ1

まだ残る課題: 強いCPUは95%の一口を適温以上に入れる。熱合わせそのものは易しく、点の差は葉と一式の選び方、印象、カードの使いどころで付く。人が遊んで「熱合わせが簡単すぎる」と感じたら、審査カードの振れ幅（判定熱+2の「深く吸う」を増やす等）で調整する。渾身の一口は持っていればほぼ使う強いカードなので、強すぎると感じたら必要火力7（高温の葉だけ）にする。
