## 2. なぜこの形にしたか

### 火力を「払うもの」から「届いたら開くもの」へ

熱は採点の帯でもあるので、熱を上げるほど強いカードが開くかわりに、焦げ・ズレに近づく。高温の葉（ダブルアップル・コーヒー）は帯の中で必要火力6〜7に届くが、味値は3〜4。低温の葉（ローズ）は大技に届きにくいが、味値4で印象が強い。

「熱を下げる系の技は高めの時に使えるけど、下げることで美味しい部分を吸わせて点数を得る」は、熱を逃がす吸いを **必要火力6・判定熱−2・帯に入れたら+1点** にして形にした。ローズなら熱6まで上げて（そのままなら焦げ）、熱を逃がす吸いで4のジャストに落とす、という攻め方になる。

### 火力を落として発動する

「熱を下げて発動」は、**火力を落として発動**するカードにした（渾身の一口・トングさばきは1、仕切り直し・アンコールは2）。はじめは「追加コスト：自分の炭を灰にする」と書いていたが、オーナーの「炭を使うのではなく火力を落として発動って感じ」に合わせて言い換えた。炭を払うのではなく、火力ゾーンの札が減って、熱（＝火力）が**ちょうどその数だけ**下がる。札の印は「火力−2」。

落とす順は、種火 → 表向きのフラット炭（どちらも灰にする）。**表向きのキューブ炭しか無ければ、灰にせず裏返して1落とす**（熱2 → 1）。キューブ炭を灰にすると熱が2下がるので、落とす数と下がる熱をそろえるための決まり。

必要火力は落とす前の火力で見るので、**高い熱でしか使えず、使うと熱が下がる**。熱を上げて大技を開け、落として帯へ降りる流れになる。「灰にする」操作（1ターン1回）とは別に数えるので、熱を下げる手段にもなる。

見せ煙は**主役の葉を1枚減らして発動**する（＝葉の体力。札の印は「葉−1」）。体力を使って印象を取りにいくか、残して濃厚（10枚以上で点と印象+1）を保つかの選択になる。

### 1ラウンドに1枚と、枠を返すカード

カードを使う機会を毎ラウンド1回の決断にした。チャージは何回でもなので、手札はいつも「熱に変える」か「効果として使う1枚」かを選ぶ。

計算で見ると、**手札はほぼいつも7枚近くあって、1局に約7枚捨てている**（毎ターン2枚引くうえ、熱は炭カードでまかなえて、チャージは提供の1ターンに0.12回）。足りないのは手札ではなく「1枚の枠」なので、「カードを引くだけ」「熱を上げるだけ」のカードは枠を使う値打ちがなく、CPUが一度も使わなかった（追い炭・トングさばき・仕切り直しなど8枚）。そこで引くカードと追い炭に**「このラウンド、カードをもう1枚使える」**を付け、枠を返す形にした。熱を上げるだけだった熱を入れる吸いには「帯に入れば印象+1」を、意味がなくなっていた内寄せ（判定熱+1）は「このセッションの印象+1」（葉を内に寄せて濃くする）にした。

毎ターン引くのを1枚に減らす案（下の表の I）も試した。手札は締まるが、強いCPUとやさしいCPUの差が縮み（96%→86%）、熱の要る高温の一式が弱くなりすぎた（29%）ので採らない。

### 灰にするのは1ターンに1回

何回でも灰にできると、チャージで一気に上げて大技を使い、同じターンに灰で帯へ戻せてしまい、「上げると危ない」が消える（CPUはこの使い方をしないので計算の数字にはほぼ出ないが、人が遊ぶと抜け道になる）。熱を一気に下げたいときは、火力を落として発動するカードが役目を持つ。

### 一口のカードは、めくる前に仕込む

1枚しか使えないのに、めくったあとで受けられると、外れても直せて読みが効かない。仕込みにすると、

- 「カードは自分のターンに1枚」で言い切れる（オーナーの「1ターンに1枚」どおり）
- 後手は先手の仕込みを見てから決められる（印象で上を行く・揺さぶりに切り替える）
- 審査カードをめくる瞬間が「当たるか」の見せ場になる

という利点がある。計算の差は小さいので、主な理由は分かりやすさと読み合い。めくったあとに使う形は `rules.reactAfterReveal: true` で戻せる。

### 印象は「味の強さ」で競う

第0.2版の一票は帯の良い方に入るだけだった。印象を作っても、帯の分をジャスト2・適温1にすると、印象の差はほぼ帯の差になる（計算で、帯が悪いのに一票を取ったのは5%）。

ジャストと適温の差はすでに点（ジャスト+2）で付いているので、印象ではジャストも適温も同じにして、**味値（味の強さ）・濃厚・カード**で競うようにした。帯が悪くても強い味が一票を取る場面が21%になり、一票の約半分（49%）はカード（見せ煙・熱を入れる吸い・内寄せ・渾身の一口）の印象で取っている。「強烈な味を出して印象に残す」「ライバルの印象に勝つ」（勝負の一服）が、温度合わせとは別の軸になった。

### 葉の体力

ボウルの葉の枚数が、そのまま一台の体力。見せ煙で削れ、焦げで主役が削れ、セッションの終わりに2枚減る。画面では、自分のボウルの下に「主役・脇役のミックス」と体力の棒（10枚の濃厚の位置に印）を出す。相手は主役と体力だけ。

## 5. 第0.4版: 炭の火（2026-11-11）

第0.3版の炭は「火力ゾーンの札の数＝熱」（表向きのキューブ炭だけ2）で、札は10枚まで並び、冷めると炭カードが種火に変わった。オーナーの指摘（`docs/owner_requests.md` ICG40〜ICG43）を受けて、**炭まわりだけ**を作り直した。続けて、引く枚数を変え（下の表の 11〜13。`docs/owner_requests.md` ICG44・ICG49）、炭1個で回す低温用のHMDと4つ目の一式を足した（14・15。ICG50）。ゲーム内の規則は `ichidai-rules.js`（`RULES.coalMax`・`startEmbersMin`／`startEmbersMax`・`draw`・`chargeDraw`・`steamDraw`、`chargePerTurn`、`coalHeat`・`coalMaxOf`・`coolStepsOf`・`dropFire`、`charge`・`steam`・`startServeTurn`・`afterCool`）、炭カード・HMD・一式は `ichidai-data.js`。

> 炭は基本立ち上げは3か4、提供後は2〜4ってのがリアルなシーシャでは多い。本当に多いのは立ち上げ3、その後は2〜3
> 炭の数が5個とか置けるようになるとゲームとして崩壊する
> 炭の温度が回復するのも変な話で、基本はゆるやかにはできても、って感じ

### 5.2 なぜこの形か

**熱＝炭の数にしない。** 「火力＝炭の数にもしたくなく、あくまでも10段階の適温を狙うゲーム」。炭の数をそのまま熱にすると、4つまでの炭では熱が4までしか出ず、葉の帯（0〜10）も必要火力（0〜7）も作り直しになる。炭に火を持たせて合計を熱にすれば、帯・必要火力・審査カードは第0.3版のまま使える。同じ熱6でも「キューブ炭2つ」と「フラット炭2つ＋種火2つ」は別の盤面になり（枠の空き・次に灰になる炭が違う）、数ではなく組み合わせを選ぶ遊びになる。

**回復しない。** 「炭の温度が回復するのも変な話で、基本はゆるやかにはできても」。どの炭も、冷めれば火が1下がるだけで、上がることはない。第0.3版のフラット炭は冷めても熱が下がらない受け方ができたが、これもやめた。残したのは「ゆるやかにする」手段だけ（風防＝カウンターで受ける、灰落とし＝次のターン冷めない、ビッグタヌキッシュリッド＝セッション最初のターン冷めない）。熱を保つには新しい炭が要るので、炭焼き場で次の炭を焼いておく段取りが毎ターンの仕事になる。

**4つまでで崩れない。** 「炭の数が5個とか置けるようになるとゲームとして崩壊する」「立ち上げは3か4、提供後は2〜4」。枠が4つなので、種火だけでは熱4まで、フラット炭だけでは新品4つで熱8まで。それより上はキューブ炭を混ぜないと届かない。枠がいっぱいのとき、自分で外せる炭は1ターンに1つ（灰にするのは1ターンに1回）。弱った炭で枠が埋まると、高い熱は保てない。

**フラットは早い・キューブは火が大きい。** 「炭自体に火力をつけるのはフラットとキューブで個性を出せていい。フラットにもメリットは欲しい。早く焼けるとか」。種火＝火1・すぐ置ける（手札を1枚使い、1回冷めると灰）。フラット炭＝火2・置いた次の自分のターンに焼ける（すぐ足せて、細かく合わせやすい。2回冷めると灰）。キューブ炭＝火3・焼けるまで2ターン（少ない数で高い熱になり、3回冷めるまでもつ）。早さと火の大きさの引き換えにした。

**1個や4個もあり得る。** 「戦略によっては炭4個や1個で立ち上げも珍しいけどあり得る」。立ち上げの枚数を3枚固定から1〜4枚に広げた。4枚はすぐ熱4になるかわりに手札が3枚、1枚は熱が低いかわりに手札が6枚残る。立ち上げの種火は火1で枠をふさぐので、準備の蒸らすターンにも灰にできるようにして、焼けた炭と入れ替えられるようにした。

**引くのは1枚。チャージで札を入れ替える。** 「チャージ&ドローに加えて普通のドローもしたい。チャージ＆ドローはドローだけは無理だけど、チャージしないなら普通に1ドロー」。第0.3版のチャージは、手札を熱に変えるだけの手だった（毎ターン2枚引くのは決まっていて、チャージすると手札が1枚減る）。第0.4版は、普通のドローを1枚にして、チャージを「置いて1枚引く」にした。チャージは、要らない札を種火にして新しい札に替えながら火を足す手になる。置かずに引くことはできないので、もう1枚引きたければ火を1つ足すことになり、炭の枠がいっぱいのときは1つ外さないと引けない。

**チャージ＆ドローは1ターンに1回。** 「ターン1。バディファイトと同じ。引かないと置けない」。はじめは「最初の1回だけ引く。2回目からは引かないが、置ける」としていたが、置くことと引くことを1つの動作にそろえた（置かずに引けない・引かずに置けない）。覚えるチャージが1種類で済む。種火を何枚も重ねて熱を上げることはできなくなり、熱を2つ以上上げるには焼けた炭をのせるしかない。熱は炭カードで上げ、種火は1ターンに1つだけの小さな調整と札の入れ替え、という役割になる。カードの「追い炭」（山札から種火2枚）は、カード1枚ぶんの効果として残した。計算では、一式の勝率が a 44%・b 54%・c 52% → a 49%・b 53%・c 47% で3つの差が縮み、CPUのチャージは1ターンに0.41回 → 0.37回でほとんど変わらなかった（5.3）。

**蒸らすは2枚引く。** 引く枚数が毎ターン2枚から1〜2枚に減るので、ほかを変えないと手札が尽きる。蒸らすが1枚のままだと、ターンの終わりの手札は1.6〜3.6枚、手札0枚で終えるターンが一式 b で31%になり、キューブ炭の多い b の勝率が28%まで落ちた（5.3 の比べ）。第0.3版でも「毎ターン引くのは1枚」の案（3. の表の I）は、高温の一式が弱くなりすぎて採らなかった。今回は提供のドローをオーナーの決めた形にして、足りないぶんを準備で補う。「蒸らす」で引くのを2枚にすると、提供に入るときの手札が厚くなり、一式の釣り合いが戻った（a 44%・b 54%・c 52%）。最初の手札を増やす案・準備の毎ターン引く案も比べたが、蒸らす2枚がいちばん釣り合った。

**炭1個で回すHMDは、4つ目の一式として足す。** 「たまに機材によっては1個でいけるのとかあるけど低温用の」「実際にそういう機材あるから作る」。炭は4つまで・火は下がるだけ、の中に「炭1個で回す」を作るために、置ける炭を2つまでに絞り、炭が1つだけのあいだは冷めないことにした。キューブ炭1つ（火3）で熱3をずっと保てるので、炭を足す手間と札が要らない。そのかわり熱は最大6（キューブ炭2つ）で、必要火力の高いカードは使えない。2つ目を足すと、次のターンからふつうに冷める（2つとも火が1下がる）ので、上げた熱は長くもたない。「炭が1つだけなら判定熱+1」を足す案も試したが、ローズが焦げやすくなり、CPUにも人にも分かりにくいのでやめた。置き場所は、はじめ一式 c（ローズ主役）のHMDを替えてみたが、b が強くなりすぎた（a 45%・b 59%・c 46%）。そこで a・b・c は変えず、4つ目の一式として足した。4つ目は葉とボウルで強さが大きく振れたので（ローズ主役で76%、ピーチ主役で18%）、雲窯ファンネルハガル・ピーチ8ローズ5・揺さぶりのイベントを各1枚、の形に落ち着けた（a 42%・b 57%・c 59%・d 43%。5.3）。

ルールブックには、この目安を1か所（6ページ「炭は4つまで」）に入れた: 炭はふつう2〜3個、立ち上げは3個が多い。低温の葉は1〜2個、高温の葉は3〜4個。

読み取り:

- **一式の釣り合い。** 4つの一式で a 42%・b 57%・c 59%・d 43%。3つだけなら a 49%・b 53%・c 47% で、d が入ると a が下がり c が上がる。d は葉とボウルで76%から18%まで振れた
- **カードの使われ方に大きな崩れは無い**（必要火力は変えていない）。3. の「カードごとの使われ方」の表は第0.3版で測ったもので、第0.4版では作り直していない

まだ確かめていないこと: 人が遊んだときの手ざわり（CPUは「灰にする」を1ターンに0.10回しか使わないので、入れ替えの読み合いは計算に出ていない。CPUのチャージ＆ドローは1ターンに0.38回で、人が毎ターン札を回したときの速さも見ていない）。ワンコールリッドを人が組んだときの強さ（葉とボウルで大きく振れる）。ルールブックの「火チップ」（炭カードの上に火の数だけ置き、冷めたら1個取る）は紙で遊ぶための仮の数え方で、ゲーム内は自動で数える。`sim_v03.mjs` はゲーム内の規則を読むので、いま走らせると第0.4版の規則での数字が出る（3. の表は第0.3版のときの数字）。

## 6. 3〜4人で遊ぶ（ICG52・2026-11-11）

> 1:1もあるし1:1:1:1の4人のやつとかもある
> 5（4人対戦）もいるけどみんなのやると狭くなるからライバルは簡易的にUIして表情やセリフメインに

2人用の規則を、同じカード・同じ流れのまま2〜4人で遊べるように広げた。チームは組まず、全員が自分の一台で競う（1対1対1対1）。ゲーム内の規則は `ichidai-rules.js`（`createGame`・`pileOf`・`startPrepTurn`・`startRound`・`resolveJudge`・`finish`・`targetsOf`・`targetOf`）。ルールブックは16ページ「3〜4人で遊ぶ」。2つ目の言葉は画面の決まりで、相手が2人以上いるときは相手の卓を簡易に出し、表情とセリフを主にする（画面の実装は `remake/js/minigames/ichidai.js`。この資料では扱わない）。

### 6.1 決めた規則

| | 2人 | 3〜4人 |
|---|---|---|
| 人数と手番 | 先手 → 後手 | 2〜4人。席の順（時計回り）に、先手から1人ずつ手番を回す。最初の火・準備（1人6ターン）・提供のどれも同じ。先手の最初の「詰める」が2枚までなのは、先手の1人だけ |
| 次のラウンドの先手 | 相手に替わる | 次の席へ回る。「後の先」を使った人は、次のラウンドのいちばん後になる |
| 一票 | 印象の高い方。同じなら入らない | 印象がいちばん高い**1人**にだけ入る。いちばん高い印象が2人以上で並んだら、票は入らない |
| 相手を1人ねらうカード | 相手は1人 | 実況の煽り・すきま風は、使うときに相手を1人選ぶ（ゲーム内で選ばなければ、点がいちばん高い相手）。すきま風は炭のある相手だけ。「会場の熱気」は全員に効く（変更なし） |
| 場の葉の山 | 1種12枚 | 3人は18枚、4人は24枚（1人6枚ぶんずつ増やす） |
| 審査員の決め手 | 高い方に。同じなら2人とも+2 | いちばんの1人に入る。いちばんが並んだら、並んだ人に同点ぶん（2点）ずつ。チャコール博士の「焦げ0回なら+2」は、当てはまる人それぞれに入る（変更なし） |
| 順位 | 点 → 残った葉 → 手札 | 点 → 残った葉 → 手札の枚数。上の2人がどれも同じなら引き分け |

2人のときの決まりは、どれも今までどおり（上の決まりは、2人なら同じ結果になる）。審査カードの山（審査員3人×4枚＝12枚）・セッションの数・採点・葉の体力・カードの文は変えていない。

### 6.2 なぜこの形か

**2人の決まりを、そのまま広げた形にした。** 「先手は毎ラウンド交代」は「次の席へ回る」、「後の先＝後手になる」は「いちばん後になる」、「印象の高い方に一票。同じなら入らない」は「いちばん高い1人に。並んだら入らない」、「決め手は同点なら2人とも+2」は「並んだ人に2点ずつ」。どれも2人で遊べば今までと同じ結果になるので、2人用の規則と計算（5.3）は変わらない。覚え直すことも無い。

**一票は1人だけ。** 2人の「印象の高い方に入る。同じなら入らない」を、そのまま人数に広げた。票は1ラウンドに1つのままで、勝負の一服（一票を取ったら+3点）などのカードの文も読み替えが要らない。計りでは、一票が入らないラウンドが4人で37%・3人で36%（2人は30%）で、大きくは増えなかった。

**場の葉は1人6枚ぶんずつ。** 2人で1種12枚＝1人6枚ぶん。人数が増えても同じ割合にして、同じ葉の取り合いの厳しさを2人のときとそろえた。

**ねらうカードは相手を選ぶ。** 実況の煽りとすきま風は「相手」に効くカードなので、だれに使うかを選ぶ読み合いが増える。全員に効く「会場の熱気」はそのまま。

**席は簡易に。** 画面では4人ぶんの卓を同じ大きさで出すと狭くなるので、相手は簡易に出して表情とセリフを主にする（オーナーの言葉。画面の決まり）。

### 6.3 計算で確かめたこと

計り方: CPUのつよい同士・4つの一式（a・b・c・d）を1つずつ・200局。手元の計りで、リポジトリのスクリプトには無い。

4人（そろえば1位は25%ずつ）:

| 一式 | 1位の割合 | 平均順位 | 平均点 | 1局の一票 |
|---|---|---|---|---|
| a ミックスの構え型 | 17% | 2.67 | 79.6 | 0.45 |
| b 単品の火持ち型 | 42% | 2.04 | 85.5 | 2.17 |
| c 低温の攻め型 | 29% | 2.35 | 81.9 | 2.07 |
| d 一つ火の低温型 | 13% | 2.93 | 76.7 | 1.98 |

一票が入らなかったラウンド37%。引き分け0%。1局の手数312。席ごとの1位は 30%・19%・24%・28%。

3人（a・b・c・d から3つ）: 1位の割合 a 17%・b 55%・c 41%・d 21%。一票が入らなかったラウンド36%。

2人の数字（a 42%・b 57%・c 59%・d 43%、つよい対やさしい96%）は変わっていない（400局で確かめた。5.3）。

席の並べ方と種を変えて計り直した結果（同じく200局・手元の計り）:

| 計り（数字は1位の割合） | a | b | c | d | 一票が入らなかったラウンド |
|---|---|---|---|---|---|
| 4人・一式の席を1局ごとに1つずつずらす | 15% | 45% | 22% | 19% | 38% |

| 3人・外す一式を順に替える | 29% | 48% | 24% | 32% | 35% |

4人対戦の1口あたりの印象（席をずらす計りの200局）:

| 一式 | 印象の平均 | うちカードの印象 | 主役の味値 | 一票を取ったラウンド |
|---|---|---|---|---|
| a | 4.92 | 0.17 | 3.00 | 4% |
| b | 5.35 | 1.15 | 3.00 | 22% |
| c | 5.49 | 0.47 | 3.94 | 17% |
| d | 5.36 | 0.71 | 3.03 | 18% |

読み取り:

- **一式の強さは2人対戦に合わせて調整したもので、4人ではまだ偏る。** b が強く（1位42〜45%）、a と d が弱い。b はどの計りでもいちばん強い。c と d の順は席の並べ方と種で入れ替わる（c 29%・d 13% ／ c 22%・d 19%）ので、200局ではまだ決めきれない
- **a は一票がほとんど入らない**（1局に0.45。ほかは約2）。主役の味値は a・b・d とも3で差が無く、差はカードの印象にある。a は印象を足すカードをほとんど持たず（1口あたり0.17。b は1.15）、いちばん上に1人で立てるラウンドが4%しかない。2人なら相手1人を上回ればよいが、4人では3人を上回らないと一票にならない
- **3人は、組み合わせでさらに振れる。** b が強いのは同じ（48〜55%）。ほかの3つは、どの一式が外れるかで17%から41%まで動いた
- **進み方は崩れていない。** 引き分けは0%。一票が入らないラウンドは36〜39%で、2人の30%から少し増えるだけ。席による偏りは計りごとに向きが変わり（30・19・24・28% ／ 24・17・25・35%）、決まった有利不利は見えていない
- **4人用の調整は次の課題。** たとえば、a に印象を足す手段を持たせる、一票の入り方を人数で変える（2位にも1点、など）といった手があるが、どれもまだ試していない。人が遊んでから決める

まだ確かめていないこと: 人が遊んだときの時間（CPUの1局の手数は、2人の154に対して4人は312で、およそ2倍）と、だれをねらうかの読み合い。CPUは、点がいちばん高い相手をねらう（実況の煽りは、もう手番を終えた相手の中から。すきま風は、炭があって守られていない相手の中から）。

## 7. 第0.5版: 冷めるのは炭1つ・審査カードは先にめくる（ICG55・2026-11-12）

第0.4版をCPU同士で計って、「初心者でも遊べるか」「上級者でも深さがあるか」「シーシャ作りの再現度」の3つで見立てを出した（7.2）。オーナーの答えは「それら全てお願い」。それを受けて、冷め方・審査カードをめくる時・カード2枚・一式の札を変えた。ゲーム内の規則は `ichidai-rules.js`（`RULES.cool`・`RULES.revealFirst`、`startRound`・`drawJudge`・`startJudge`・`scorePuff`）、葉・カード・一式は `ichidai-data.js`（`FLAVORS`・`CARDS`・`KITS`）。ルールブックは第0.5版（`ichidai_shobu_rulebook_v0.5.pdf`）。

### 7.1 決めた規則

| | 第0.4版 | 第0.5版 |
|---|---|---|
| 1. 冷める | 炭を2つ選んで、火を1ずつ下げる（同じ炭は1ターンに1段階まで） | **1ターンに、炭1つ・火1だけ**（`RULES.cool` 2 → 1）。熱は毎ターン1下がる。「同じ炭は1ターンに1段階まで」は要らなくなった。風防のカウンター2個は2ターンぶん持つ。灰落としは「次の自分のターン冷めない」のまま（1ぶんの価値）。立ち上げの種火3つは、3ターンかけて1つずつ灰になる。ワンコールリッドは、炭が2つあれば、どちらか1つが冷める |
| 2. 審査カードをめくる時 | 全員がターンを終えたあと | **ラウンドのはじめ**（`RULES.revealFirst`）。全員が吸い方を見てから、熱を合わせる。全員がターンを終えたら、そのカードで審査する |
| 3. 吸い方を読む | 審査カードの山のいちばん上を自分だけ見て、元に戻す | **「次のラウンドの審査カードを、自分だけ先に見る。」** 山のいちばん上が、次のラウンドの分。最後のラウンドには使えない |
| 4. ダブルアップル | 適温6〜8のどこでもジャスト【表情】 | **ジャストは熱7だけ**（適温6〜8）。【表情】をやめて **「【原点】ボウルがこの葉だけなら、適温の一口+1。」**（ジャストでも適温でも+1。素焼きハガル・アダムの単品の+1と重なる）。レモンの【表情】はそのまま |
| 5. 組み済みの一式（ゲーム内） | — | a ミックスの構え型: 吸い方を読む2枚 → 内寄せ2枚。b 単品の火持ち型: 渾身の一口3 → 2、ひと息1 → 2。c 低温の攻め型: 吸い方を読む3 → 2、内寄せ1 → 2。d 一つ火の低温型: 変更なし |
| 6. CPUの強さ（紙の規則ではない） | — | やさしい＝めくられた吸い方に合わせない。ふつう＝合わせるが、次のラウンドの先読みと、相手を揺さぶるカードは使わない。つよい＝先読みして、揺さぶる |

変わらないもの: 炭は4つまで・炭の火（フラット炭2・キューブ炭3・種火1）・火は下がるだけ、普通のドロー1枚とチャージ＆ドロー（1ターンに1回）、蒸らす2枚、カードは1ラウンドに1枚、印象と一票、3〜4人の決まり。後手は、先手が熱を合わせ終えたあとで動ける（実況の煽りなど）。

ルールブックの「組み済みデッキ」（A・B）は `cards.js` の `DECK_A`・`DECK_B` で、ゲーム内の一式と同じ中身ではない（A は葉がレモン8＋ミント4で、札は吸い方を読む2枚のところがゲームの a では内寄せ2枚。B は6種の枚数が違う）。5 の入れ替えは、ゲーム内の一式だけの話。

### 7.2 なぜ（第0.4版をCPU同士で計った見立て）

**初心者: 炭を保てないと、試合にならなかった。** 対やさしいで、打ち方ごとの勝率と点はこうだった。

| 打ち方（第0.4版・対やさしい） | 勝率 | 点 |
|---|---|---|
| 提供で何もしない | 0% | 14 対 86 |
| チャージ＆ドローだけ | 0% | 28 対 83 |
| 焼けた炭を全部のせる（熱を見ない） | 5% | 31 対 84 |
| 炭は合わせるが、カードなし | 63% | 81 対 71 |
| ガイドどおり | 93% | 98 対 64 |

熱が毎ターン2下がるので、2ターン先を見て炭を焼き続ける必要があった。1局の約76〜81手のうち、炭の世話（置く・のせる・チャージ・外す）が約22手、カードは約11〜12手。

**上級者: 腕の差が出るのは「炭を保てるか」まで。** つよい対やさしいは97%、つよい対ふつうは48%で差が無かった。点の5〜7割は、詰めた葉で決まる。次の審査カードを知っている側は勝率78%・1局で+10点（ジャスト86%対61%）。これは同じ腕どうしの点差（平均12点）とほぼ同じで、審査カードの運が勝負を決めていた。

**再現度: 炭を替える回数が多すぎた。** 1局で炭を7〜8回のせていた。実際のシーシャは、1回の提供で炭を替えるのは1〜2回程度、という理解（オーナーには未確認の理解）。オーナーは以前「炭の温度は、ゆるやかにはできても」と言っている。

**単品の火持ち型は、温度を合わせる勝負が無かった。** ダブルアップルが「適温のどこでもジャスト」で、ジャスト96%。

そこで、(1) 冷めるのを炭1つ・火1にして、炭の世話を減らし、炭を保てない人の底を上げる。(2) 審査カードを先にめくって、運だった吸い方を「合わせる腕」の勝負にする。(3) ダブルアップルのジャストを熱7だけにして、温度を合わせる勝負を作る。

### 7.3 第0.5版の計り

計り方: つよいCPU同士。手元の計りで、リポジトリのスクリプトには無い（帯と、提供の1ターンあたりの回数は `node docs/design/card_game/sim_v03.mjs --coals --games 400` で出る）。
