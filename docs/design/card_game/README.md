## 第0.2版で変えたこと（2026-11-11）

オーナーの指示（調整パートをなくす／炭カードと炭焼き場／時間差で入る熱／チャージは任意）と、「ボードゲーム以上トレカ以下」のゲーム性にするための提案を合わせた版。第0.1版のPDFは Git の履歴にある。

| 項目 | 第0.1版 | 第0.2版 |
|---|---|---|
| 流れ | 準備8ターン → 提供3ターン → 調整 をくり返す | 準備6ターン → 提供（3ラウンドで1セッション）。**調整フェイズなし** |
| 熱を足す | 調整のときだけ、手札を炭にする | 自分のターンに、**チャージ（手札1枚を種火に。1ターン1回・しなくてもよい）**と**炭カード** |
| 炭カード | 表向きで置ける炭（8枚まで） | **炭焼き場に火力なしで置き、フラットは1ターン後、キューブは2ターン後に焼ける。** 焼けた炭は好きなときにのせる。フラット炭とキューブ炭は枚数の上限なし |
| フラットとキューブ | 急加熱に数えない／1回だけ残る | フラット＝着火1・熱1・裏返しても熱が下がらない【小回り】。キューブ＝着火2・熱2・のせているあいだ冷めるのが1段階【火持ち】 |
| 冷める | 毎ターン炭1枚が灰になる | 毎ターン**2段階**。表向きの炭カード→裏返す→灰。炭カード1枚で2段階ぶん受けられる |
| 引く | 毎ターン1枚 | 毎ターン**2枚**（1枚を熱に、1枚を効果に、が基本の形） |
| 審査員 | ゲームの終わりのボーナスだけ | **審査カード**（吸い方）を毎ラウンドめくる。2人がターンを終えた**あと**にめくるので、熱は読んで決める。めくったあとは「一口」の技で受ける |
| 相手との勝負 | 合計点だけ | **一票**: そのラウンドで相手より良い帯なら+2点 |
| なくしたもの | — | 調整フェイズ、急加熱 |
| 葉 | — | 味値4の葉は、ジャストのすぐ上を焦げにした（攻めるか、1つ下で待つか） |

提案で足した3つ（審査カードをあとからめくる・一口の技・一票）は、オーナーの指示にはない部分。足した理由は次のとおり。
調整をなくして毎ターン熱を足せるようにすると、どの葉でも毎回ジャストに合わせられて、味値の高い葉が勝つだけになった（下の計算で確認）。
「吸い方はめくるまで分からない」を入れると、帯の広い葉は安全、味値の高い葉は高得点だが危ない、という役割が分かれ、熱を動かすカードと相手を揺さぶるカードに使いどころができる。

## 計算で確かめたこと

`node sim.mjs --games 400` の結果（席は交互に入れ替え。コンピュータは審査カードの残りを数えて期待値で熱を決め、1ターン先まで読む単純な手筋）。

- **炭カードを入れる意味がある。** 炭0枚のデッキは、同じ葉の炭10枚のデッキに 4〜7% しか勝てない。8〜12枚がいちばん点が高く、16枚以上にすると使えるカードが減って負け越す。
- **フラットとキューブに向き不向きがある。** 低温のローズはフラットだけが最良（フラット12枚で勝率59%、キューブ12枚で35%）。高温のコーヒーはフラットとキューブを半々にしたときがいちばん点が高い。
- **葉ごとの点は大きく開かない。** 主役8＋脇役4のミックスで、3セッションの大会（HAZE: OPEN CLOUD）は 77〜91点（単品向けのダブルアップルとデスバイアイスを除く17種）。帯の広いレモンは点が低め（79点）だがジャスト率95%で票を取られにくく、味値4のマンゴーは点が高い（87点）がジャスト率69%で、相手に2.7票を渡す。審査カードが荒れる大会（HAZE: GRAND SMOKE）では、レモン98点に対しマンゴー101点・相手に4.8票（+9.6点）で、帯の広い葉が逆転する。
- **1ターンに使うカードは 0.8〜1.3 枚**（一口の技を含む）。チャージは 0.2〜0.4 回。手札は 4〜6 枚で回る。
- **ルールを戻して比べた。** 審査カードを先にめくると、ローズのジャスト率は 74% → 95% に上がり、帯のせまさが弱点にならない。毎ターン1枚しか引かないと、コーヒーのジャスト率は 38% まで落ちて苦しい。冷めるのを1段階にすると、低温〜中温の葉では炭カード0枚のデッキが勝ち越す（勝率53〜64%）。2段階なら4〜7%。
- **組み済みデッキ2組**は、練習試合で A 38%：B 54%、HAZE: OPEN CLOUD で A 56%：B 38%、HAZE: GRAND SMOKE で A 83%：B 15%。審査カードが荒れるほど、帯の真ん中に置けるAが有利。
- **先手と後手**: 最初の先手の勝率は 35〜49%。同じ葉を取り合う対戦（デッキBどうし）で後手がやや有利。先手の最初の「詰める」を2枚までにした影響で、数値は調整の余地がある。

## まだ確かめていないこと

- 人どうしの対戦。コンピュータは読み合い・はったり・手札の温存をしない。
- 個々のカードの強さ（人物・器具・イベント）。手筋が使いこなせていないカードがある（後の先・葉をほぐす・吸い方を読む など）。
- セッティングの釣り合い。素焼きハガルは単品向けで、ミックスだと負け越す。シリコンボウルは焦げない葉では利点が出ない。
- 遊ぶ時間。1ターンに扱うカードが増えたので、めやすの時間は対戦で測る。
- 審査員と人物カードの能力は、既存の設定（審査の重み・育てたハガルの来歴）から起こした仮のもの。
