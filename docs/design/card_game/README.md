# 一台勝負（仮題）— シーシャのカードゲーム案

オーナー未決定の提案。採用扱いにしない（ミニゲームにするか、本編の制作パートにするかも未定）。

- `ichidai_shobu_rulebook_v0.1.pdf` … ルールブック（A4・14ページ）。読むのはこれ。
- `rulebook.html` / `rulebook.css` / `render.js` … ルールブックの原稿と組版。
- `cards.js` … カードの数値と文面（フレーバー20種・セッティング8種・サポート32種・審査員5人・組み済みデッキ2組）。図と一覧はここから作る。
- `economy_sim.mjs` … カード効果を使わないときの点の伸びを数える確認用の計算。`node economy_sim.mjs`
- `build_pdf.mjs` … PDFの作り直し。`node build_pdf.mjs <書体フォルダ>`（書体は Noto Sans JP と Zen Antique。リポジトリには入れていない）

## 状態（第0.1版）

- 計算で確かめたのは、カード効果を使わない場合の点の伸びだけ（1セッションおよそ15〜21点）。
- 個々のカードの強さ、先手と後手の差、デッキどうしの相性は未確認。対戦で試してから数値を動かす。
- 審査員と人物カードの能力は、既存の設定（審査の重み・育てたハガルの来歴）から起こした仮のもの。
