# 登場カットインへのつなぎ「シルエット化」設計書

2026-10-31 オーナー採用（「シルエット化いいね」）。対象は登場カットインのグラフィック絵柄（要望台帳 CIG・#2141）。

## 1. 目的

会話の立ち絵（描き込みの多いアニメ調）から、カットインの一枚絵（目を髪で隠した平面ポスター調）へ急に切り替わると、別の絵が割り込んだように見える。
**画面にいる本人が、その場でテーマ色の影（シルエット）になり、その影から色面が画面を切り裂いてカットインが現れる**つなぎを入れ、「同じ人が変身した」と読めるようにする。

新しい絵柄は「目を髪で隠した影の人物」なので、影になる動きがそのまま二つの絵柄の橋渡しになる。

## 2. 適用範囲

| 条件 | 動き |
|---|---|
| 設定「登場カットインの絵柄」= グラフィック（既定） | シルエット化のつなぎを入れる |
| 設定 = 立ち絵（旧） | 今のまま（つなぎを入れない） |
| 端末の「動きを減らす」（`prefers-reduced-motion`）または設定「揺れ・閃光を減らす」（`config.reduceShake`） | 切り裂きと閃光をやめ、200ms のクロスフェードだけ |
| 正体を伏せた版（サメちゃんの「？？？」など `variant`） | 同じ（影の色はその人のテーマ色） |
| 画面に本人の立ち絵が無い・読み込み失敗 | 3.4 の代わりの出方 |
| テストの高速送り（`vnTest.turbo`） | 今と同じくカットイン自体を出さない |

会話の進行・既読・保存・カットインの表示時間（`MOTIONS` の hold）は変えない。つなぎの分（約0.5秒）だけ全体が長くなる。

## 3. 動き

### 3.1 タイムライン（基本形、合計 約480ms）

| 時刻 | 段 | 内容 |
|---|---|---|
| 0–160ms | ① 影になる | 画面上の本人の立ち絵の上に、同じ形の影を重ね、不透明度 0→1。色はテーマ色（`introArt[id].color`）を暗くした色（`shadow` 寄り）。立ち絵の輪郭がそのまま影になる |
| 120–340ms | ② 切り裂く | 影の輪郭（立ち絵の中心）から、テーマ色の色面が斜め（カットインの帯と同じ +4°）に左右へ広がり、画面全体を覆う。先頭に `secondary` 色の細い線（2〜3px）を走らせる |
| 300–480ms | ③ 現れる | 色面の下にカットインを置き、色面が反対側へ抜けて（または帯の形に縮んで）カットインを見せる。抜けきった瞬間から、今の `animateIntro`（名前・二つ名・一言の登場）を始める |

- 時刻はすべて `MOTIONS` の hold の前に足す。hold（読む時間）は削らない。
- ②の色面とカットインの名前の帯は同じ角度にそろえ、色面が帯に「変わる」ように見せる。

### 3.2 動きの型ごとの味付け（`intro_cutin.motion`）

基本形は共通にし、型ごとに②③だけ少し変える。新しい部品は増やさない。

| 型 | 人物の例 | ②③の違い |
|---|---|---|
| sharp（刃） | ライバル | 基本形。色面の縁は硬く、抜けるときに既存の判子の音（`SE.stamp`） |
| soft（余韻） | 静かな人・私生活 | 全体を 600ms に伸ばし、色面の縁を 24px ぼかす。音は足さない |
| still（静） | 審査員・王者・機械 | 切り裂かず、影→色面→カットインを 2コマずつで切り替える（`steps`）。既存の `SE.hit` |
| bounce（跳） | マスコット・にぎやか | 色面を斜めでなく、影の中心からの円で広げ、少し行き過ぎて戻る（オーバーシュート） |

### 3.3 退場（カットイン → 会話へ戻る）

今の `exitIntro` の後に、逆向きの短いつなぎ（約300ms）を入れる。

1. カットインが消えたあと、テーマ色の色面が一瞬だけ画面を覆う（100ms）。
2. 色面が本人の立ち絵の位置へ縮み、影になる（120ms）。
3. 影が薄くなり、元の立ち絵に戻る（80ms）。

退場のつなぎは、オーナー確認の結果で外せるよう、入場とは別の関数にする（7章の未決事項）。

### 3.4 本人の立ち絵が画面に無いとき

台本の指定（`line.intro`）で立ち絵より先にカットインが出る場合や、画像の読み込みに失敗した場合は、①を飛ばす。色面は、カットインの人物が出る位置（画面の左 0〜40%）から広がる。

## 4. 実装

### 4.1 ファイル

| ファイル | 変更 |
|---|---|
| `remake/js/vn/intro-transition.js`（新規） | `silhouetteIn(...)`／`silhouetteOut(...)`。DOM の生成・アニメーション・後片付けだけを持つ |
| `remake/js/vn/intro.js` | `playIntro` のグラフィック絵柄の分岐で、`mountIntro` の前後に `silhouetteIn` を呼ぶ。`holdIntro` の後に `silhouetteOut` |
| `remake/css/intro.css` | `.ci-silhouette`・`.ci-wipe` の見た目（色・角度・縁） |

### 4.2 部品

- **影（`.ci-silhouette`）**: 本人の立ち絵 `.vn-portraits img.portrait[data-speaker="<id>"]` の画面上の位置（`getBoundingClientRect`）に、同じ大きさの `div` を置く。背景色をテーマ色にし、`mask-image: url(<立ち絵のsrc>)`（`mask-size: 100% 100%`）で立ち絵の形に切り抜く。新しい画像は作らない。
- **色面（`.ci-wipe`）**: 画面全体の `div`。`clip-path: polygon(...)` を Web Animations API で動かして、斜めの帯を広げる・抜く。先頭の線は同じ要素の `::after`。
- 置き場所はカットインと同じ FX レイヤー（`layers.fx`）。影は立ち絵の座標、色面は `mountIntro` と同じ 1280×720 の拡大縮小（`--intro-fit-scale`）に合わせる。DS（縦持ち2画面）では立ち絵のある上画面の座標で計算する。

### 4.3 順番（`playIntro` のグラフィック絵柄）

1. 画像の読み込み待ち（今の `imageReady`）。終わるまでつなぎを始めない（影のあとに空白が出ないように）。
2. `silhouetteIn` の①②を再生。
3. ②の終わりで `mountIntro`（カットインを色面の下に置く）。
4. ③で色面を抜き、`animateIntro` と `introSound("appear")` を始める。
5. `holdIntro` → `exitIntro`（今のまま）。
6. `silhouetteOut`（3.3）。終わったら影と色面を消す。

- つなぎの間も、今のカットインと同じくクリック・Enter・SKIP では短くしない（入力は吸収する）。
- どの段で中断（会話の中断・ロード）しても、`finally` で影と色面を必ず消す。

## 5. 確認

`remake/test/intro_cutin.mjs` に追加する。

- グラフィック絵柄: `.ci-silhouette` が本人の立ち絵の位置に出てから `.cutin.in` になり、カットインが閉じたあと影と色面が残らない。
- 旧絵柄: 影と色面を作らない。
- 動きを減らす設定（`config.reduceShake`）: `clip-path` の動きを作らず、フェードだけ。
- 立ち絵の無いカットイン: 影を作らず、色面だけで出る。
- つなぎの間の Enter・クリックで、カットインが短くならない。
- `SHOTS=<フォルダ>` で、80ms・240ms・400ms の3コマを保存し、オーナー確認用の連続画像にする。

関連する回帰: `intro_art.mjs`（旧絵柄）、`browser/recent_intros.mjs`、DS の `browser/ds_overlay_layers.mjs`。

## 6. 進め方

1. 試作: `character-intros-preview.html` で、なる（sharp）・凛（soft）・南雲（still）・パッキー（bounce）の4人を再生できるようにし、連続画像と動画でオーナーに見せる。
2. 採用後に本実装とテスト。1つのPRにまとめる（`intro-transition.js`・`intro.js`・`intro.css`・テスト）。
