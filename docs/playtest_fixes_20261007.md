## 動作

- 能力アップ・回復の通知は元の縁、質感、5色、漢字バッジを残して煙だけを外した。回復カードの割合と色は、消耗・容量変更・待機列・ロード後もHUDの実残量に追従する。小さくした炭ブランクは不透明度を0.38から0.54へ上げた。
- 通知からLIMEを開くと初回案内を片付ける。交換済みのサメちゃんは連絡先に通称を表示し、腹話術の名前欄とログは「コロちゃん（腹話術）」に分けた。テーマは本人が画面に登場した時に始まり、音量を通常の55%にする。SHISHARKのピンは第2章になってから追加し、解放前に章の案内を出さない。
- 初登場演出はクリック・Enter・Control・SKIPで短縮できない。バイトのSKIPは一連の会話で続き、選択肢で待ち、シフト終了時に解除する。
- みんとの初対面は店へ向かう途中の出勤姿への気づきと、照れて「みんとです」と名乗る場面にした。読んだ旧LIMEや既知の正体・本名を後の会話に引き継ぐ。私服の約束の後に恋愛／友情の質問を出し、本人との夜の約束ならその夜に告白を続けられる。友情を選んだ場合も締めくくりと贈り物を受け取れる。
- 赤い体力で消耗行動を終えると、残量に応じて翌朝の風邪を抽選する（25%で4%、0で85%）。断った行動では抽選せず、家で休むと保留中の発病を回避できる。0でも運が良ければ無事に行動でき、大会当日に発病しても日を飛ばさない。
- 定休日限定だったなるの機材探し・みんとの買い出しは、平日にも臨時休暇で午後に進む。大事な私的イベントも固定の夜の予定があれば午後へ回す。LIMEの実際の配信時に当日の休業を確定し、マップに「本日臨時休業」を表示する。承諾した午後の約束はLIMEの再表示・保存・ロードで消えず、休業は翌日・次章へ持ち越さない。
