# サメちゃんの新衣装3案：確認用

## 最新：添付の服装を保ち、黒髪＋少量の青メッシュへ

オーナー「髪色は一部青とかのメッシュあってもいいけど黒髪にしたい」（PRT61）に続き、3案目の画像を添付して「サメちゃんの服装これが好き」（PRT62）。最新の具体的な服装選択を優先し、黒×淡い青・アイボリーの衣装をそのまま基準にし、銀白の髪を黒へ変更した通常と腹話術を各1枚保存した。青衣装へ全面変更した案は履歴とする。

[最新2枚の比較](../../asset_sources/portraits/samechan-gothic-shark-concepts-v1/selected-outfit-black-hair-v3/comparison.png)、[原画・実参照・プロンプト・検証](../../asset_sources/portraits/samechan-gothic-shark-concepts-v1/selected-outfit-black-hair-v3/README.md)。腹話術は王冠のコロちゃんを両手で顔の前へ上げ、本人の顔全体を隠す。服・髪・体格と表示倍率は通常と共通。

確認用PRは [#206](https://github.com/haseatsu114514-dot/shisha-game/pull/206)。4人の登場カットイン素材も同PRに保存。ゲームの現行画像・設定・台詞は変更していない。

## 最新：3案目を青ベースへ変更し、腹話術を追加

オーナー「サメちゃんはあくまでも青ベースのシスターがいい この中だと三枚目」「あと腹話術してる時の立ち絵も欲しい サメのぬいぐるみで顔隠して喋ってる感じ」（PRT59／60）。3案目の服の構成を残し、フード・ジャケット・スカートの主色を青へ変更した通常と、王冠のコロちゃんを両手で顔の前へ上げて本人の顔を隠した腹話術を各1枚制作。

[青版2枚の比較](../../asset_sources/portraits/samechan-gothic-shark-concepts-v1/blue-sister-v1/comparison.png)、[暗い背景](../../asset_sources/portraits/samechan-gothic-shark-concepts-v1/blue-sister-v1/comparison-dark.png)、[元データ・プロンプト・実参照・検証](../../asset_sources/portraits/samechan-gothic-shark-concepts-v1/blue-sister-v1/README.md)。共通倍率と足元で896×1200に配置。顔の切り貼り・体のワープ・描き足しはない。

衣装の方向は3案目を基準に選択されたが、青版の仕上がりと腹話術は今回の確認用。現行ゲーム素材・台詞は更新していない。腹話術は専用ポーズ候補であり、今後の採用と会話への表情指定は別の作業。

---

オーナーは、がうる・ぐらとの差別化のため「サメ＋ゴシックなシスター」をカジュアルなストリート服にしたいと依頼。GGSTブリジットのフード／服の構成を参考に、3案をまず1枚ずつ生成する指示（PRT55〜58）。

成果物は [全身と顔の比較](../../asset_sources/portraits/samechan-gothic-shark-concepts-v1/comparison.png)、[暗い背景](../../asset_sources/portraits/samechan-gothic-shark-concepts-v1/comparison-dark.png)、[制作元と記録](../../asset_sources/portraits/samechan-gothic-shark-concepts-v1/README.md)。①黒・アイボリー・青緑の深海シスター、②ボルドーと映画モチーフ、③くすんだ水色とスケーター風の服。

3案は通常表情のみ、本人の青い瞳・ギザ歯・コロちゃん・成人の体格を共通にした。髪・衣装・配色の変更は今回の試案について明示的に依頼されている。従来の銀髪と青いパーカーを維持する制作規則より、この最新依頼を優先する。

採用とゲーム反映はまだ指示されていない。現行5表情のゲーム素材と設定はそのまま。選ばれた案を基準に今後の表情を揃え、採用指示の後でPNG／可逆WebP・アイコン・manifest・外見メモを更新する。
