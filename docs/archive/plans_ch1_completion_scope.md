# Chapter 1 Completion Scope

更新: 2026-10-12

## 当面の優先順位

開発は**第1章の完成を最優先**する。

ActiveなGitHub Issueは原則、次のどれかに限定する。

1. 第1章の進行停止・バグ・セーブ互換性・公開版QA
2. 第1章のシーシャ制作・大会・チュートリアル・UI/UX
3. 第1章で実際に登場する人物・関係イベントの不整合修正
4. 第1章の背景・スチル・タイトル・章遷移など、完成品質へ直接効く演出
5. Codex / Claude Code を安全に運用するため、現在必要な開発基盤

第2章以降の章進行、遠距離、海外、後半恋愛、将来の上級解放などは `post_chapter1_roadmap.md` で管理し、実装直前までIssueへ戻さない。

## Issueを増やすときの基準

新しいアイデアが出ても、すぐIssue化しない。

- 第1章完成に必要 → Issue
- 今動いている実装の残作業 → Issue
- 数週間以内に着手する具体作業 → Issue
- 第2章以降の構想・いつかやる案・仕様アイデア → roadmap / planning document

これにより、Open Issue数を「今やるべき作業量」に近づける。
