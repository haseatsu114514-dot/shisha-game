大会のベーススコアは、以下の5工程を各20%で集計します。**準備加点と物語の10点投票は別枠**で加わります。

| 工程 | 比重 |
|---|---:|
| **穴** | **20%** |
| **炭** | **20%** |
| **完成品** | **20%** |
| **調整1回目** | **20%** |
| **調整2回目** | **20%** |

調整1回目と調整2回目の実績は別々に保持し、両方を結果表へ表示します。**旧プレゼン比重は廃止済みで、「提供演出」は現行の配点項目ではありません。**

### 第5章：エキシビションマッチ — 人間 vs AI（日本・SMOKE LAB）
- **会場**：SMOKE LAB 特設ステージ（主催：チャコール博士／火浦 理一）
- **対戦カード（1対1）**：**蒸野 はじめ** vs **SHISHA-9000**（AI搭載・自動火力制御シーシャ機）
- **課題レギュレーション**：
  - **『ダブルアップル単体 12g』**（ミックスなし、純粋なパッキング・熱管理・提供の間だけで競う究極の課題）。
- **審査方式（二本勝負・同じ観客による挙手投票の2回合計票）**：
  - 審査員による採点ではなく、**会場に集まった同じ観客全員が「1本目」と「2本目」の両方を吸い、それぞれ良いと思った方に挙手投票し、1本目＋2本目の合計票数で勝敗を決する**。
- **試合展開**：
  - **勝負の対比（2026-10-30 オーナー決定・#1346）**：**「縁のない寄せ集め（SHISHA-9000）対 縁で混ざった自分（はじめ）」**。正確さや「待つ」技術の優劣で決着させない（詳細は [`01_story.md`](01_story.md) 第5章）。
  - **1本目**：名手たちとはじめの大会記録を学んだ9000が、室温・湿度・観客の咳き込みにミリ秒単位で即応し、大会で覚えた待ち方まで再現して **僅差で先取**。
  - **2本目**：記録をなぞって追いつこうとしていたはじめは、客席にいたtonariの客へ、普段のカウンターでかける**接客の声（「いつもの、少し軽めにしますか」）**で話しかけ、記録にない今日の事情（「今日は時間、あるから」）を聞いてから炭を決める。縁で混ざった自分の手の一台で2本目に一本目の差を返して上回り、**2回分の合計票で僅差の逆転勝利**を収める。
