## スミさん音声の作り方（Claude Code引継ぎ）
前提: MacにNode.js(20以上)、ffmpeg、VOICEVOX本体を用意し、VOICEVOX ENGINEが http://127.0.0.1:50021 で応答できる状態にする。
1. `git fetch origin && git checkout -b feature/continue-recorded-voices origin/main` で最新版を起点に作業。
2. `node tools/generate_continue_voice.mjs --dry-run --target sumi` で3パターンの台本を確認。
3. `node tools/generate_continue_voice.mjs --list` で音声モデルの識別子を検証。標準は `--voice 麒ヶ島宗麟` を使用。
4. `node tools/generate_continue_voice.mjs --target sumi --voice 麒ヶ島宗麟 --speed 1.48` で3つのMP3を `assets/audio/voice/continue/` に生成。
5. 生成先は `sumi_together.mp3`、`sumi_disaster.mp3`、`sumi_meeting.mp3`（script.idに準拠）。各ファイルを実際に聴いて読み誤り、語尾、間、音量、歪みを検品。20秒へ過度に圧縮される場合は、収録用台詞やキュー時刻を調整して再生成する。
6. `remake/js/chapters/gameover.js` の3つの `audio: null` を正しいURL（例 `../assets/audio/voice/continue/sumi_together.mp3`）へ変更し、生成済み音声の再生を優先する。音声がない場合は従来のブラウザTTSへ戻る。
7. `VOICEVOX:麒ヶ島宗麟` をゲーム内のクレジット画面などで明示し、キャラ利用規約・エンジン規約を再確認。
8. 音声の開始タイミング、画面離脱時の停止、字幕、iPhone Safariのタップ再生、リトライ遷移を検証。未来の口パク時は音声の実測または口形タイムラインを優先。
9. 生成した音声もGitHubの新規作業ブランチへcommit、push、PR。mainへ直pushしない。

VOICEVOX 公式:
- https://voicevox.hiroshiba.jp/product/kigashima_sourin/
- https://github.com/VOICEVOX/voicevox_engine
- https://github.com/VOICEVOX/voicevox_vvm/blob/main/TERMS.txt

恋人版の音声は各キャラに似合う権利上問題ない別ボイスを選定して順次生成。デフォルトでは生成対象をスミさんの3本に限る。つむぎは序盤の息の弱い声と終盤の異様に静かな笑顔の落差が最優先。**VOICEVOXの『春日部つむぎ』は本作の『つむぎ』とは別キャラであり、名前が同じだからという理由だけで音声イメージを決めない。** 各ボイスの正確な利用クレジットを追加。

## 指定YouTube BGM：素材採用フロー
- 希望動画: https://www.youtube.com/watch?v=66_2hxiaA4o
- **現段階で動画メタデータ、曲名、作曲者、音源のダウンロード元、ゲームへの再利用・改変許可が確認できていない**。YouTubeで公開されているだけでは、ゲーム同梱・速度加工の許諾にはならない。
- 音源の配布元／作者から**ゲーム用途と加工利用が許諾**されていると分かった時点でのみ採用。非許諾の場合はその曲の音源を流用せず、緊迫感のある独自曲または許諾済み曲に差し替える。
- ライセンス確認後、配布元から正規入手したファイルをオフラインで試聴し、1.0倍と1.08倍（必要なら1.12倍）を比較。`ffmpeg -i input.wav -filter:a "atempo=1.08" -c:a libmp3lame -q:a 2 continue_108.mp3` は速度だけ上げ、通常はピッチを維持する編集例。
- 音量は声が明瞭に聞こえるようBGMを下げる。ボイス開始時はBGMを短くフェードイン、最後の『大会に戻る』直前は音圧を上げ、選択時は止める。
- ブラウザで単体で抜き出せる公開MP3の再配布は許諾次第で不可になるため、曲の配布形態とクレジット方法も確認する（既存の `bgmUrl` は `bgm_continue_urgent.bgm` を優先、`bgm_continue_urgent.mp3` も検出できる）。`remake/data/manifest.json` は自動生成なので直接編集しない。
- 指定曲が採用できるまでは **168→196 BPMへ漸増するゲーム内オリジナルの緊迫ループ**を鳴らす。

## 恋人プレミア演出仕様
- 低確率：1画面につき1回、20%抽選。恋人が1人もいない場合は通常スミさん版のみ。恋人候補が複数なら eligible 内で等確率。
- `state.lovers` の確定交際のみ（好感度、デート回数、予兆からは判断しない）。`state.chapter===1` の `minto` を抽選から除外。第2章以降のみ解禁。
- つむぎ：弱々しい心配→未完成の絵→執着→笑顔で『ずっと見てますから』。突然強い口調にならず、**静かに怖いギャップ**にする。通常描写のつむぎの人格は書き換えない（コンティニューという演出空間内の誇張）。
- みんと（栞）：プライベートの素の小声（`ura_`表情）。営業の小悪魔声で出さない。第1章は強制除外。
- 凛：香りと恋人の特権／アゲハ：勢いとバイブス／ましろ：ダウナーで眠そうな応援。
- 演出：独立した `premium` データ属性で見た目を微調整可能。声の違いとテーマ色を後で追加。恋人が出演しても大会巻き戻し・終了操作はスミさん版と同じ。特別扱いで難易度は変えない。
