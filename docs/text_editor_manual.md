# 台詞エディタ マニュアル

ゲーム内の台詞（`data/dialogue/*.json` の `text`）を、ブラウザで検索・編集・保存し、
そのままビルド反映・Gitコミット/プッシュまでできる開発ツールです。

## 起動

リポジトリのルートで：

```
python3 tools/text_editor_server.py
```

ブラウザで **http://127.0.0.1:8321/** を開きます（`127.0.0.1` からのみアクセス可＝外部公開しません）。
終了は起動したターミナルで `Ctrl+C`。

前提: `python3`。ビルド反映まで使うなら `pip install Pillow numpy scipy`（立ち絵計測に必要）。

## 画面の見かた

- **左ペイン**: ファイル選択 → その中の全台詞行の一覧。
  - 検索窓（本文・話者・dialogue_id で絞り込み・`Ctrl+F`）
  - `⚠のみ` … 要注意行だけ表示
  - `次の⚠へ` … 次の要注意行へジャンプ
  - 各行の `⚠2` は「要注意ポイントが2件」。`●` は「このセッションで保存済み」。
- **右ペイン（エディタ）**: 選んだ行の本文・プレビュー・手動改行グリッド。
  - **本編プレビュー**: 本編とまったく同じ改行規則（`remake/js/vn/text.js` の `autoWrap` 実物）で表示。
    点線は「▼ 改ページ」＝ここでページが分かれる（本編は最大2行で改ページ）。
  - **手動改行グリッド**: 文字をクリックするとその直前で改行が入り、`⏎` をクリックすると解除。
    ※手動改行は原則入れない方針（下の「要注意ポイント」参照）。

## 要注意ポイント（⚠の意味）

`text-style` スキルの規範に沿った目安です（正本チェックは `python3 tools/lint_dialogue.py`）。

- **全角48字超** … 1台詞が2行を超え、自動改ページで文の途中が割れます。台詞を分けてください。
- **「。……＋短い続き」** … 「頑張れますよね。……えへへ」→「頑張れますよね、……えへへ」。
- **冒頭の間投詞のあとは「、」** … 「え。俺が」→「え、俺が」。
- **台詞の末尾「。」は取る** … 「わかりました。」→「わかりました」（ナレーションは付けてOK）。
- **「。」3個以上** … テンポが重い。台詞を分割。
- **手動改行を含む** … `autoWrap` に任せるのが基本。演出でどうしても要るときだけ。

## 編集の流れ

1. 左でファイルと行を選ぶ。
2. 右のテキストを直す。プレビューで改行・改ページを確認。
3. **保存**（`Ctrl+S`）。連続で直すなら **保存して次へ**（`Ctrl+Enter`）。
   - この時点では `data/dialogue/*.json` に書き込まれるだけで、まだゲーム本体には反映されません。

## ゲームに反映する

現行版（`remake/`）は `data/dialogue/*.json` を直接読むので、ビルドは不要です。保存後、ゲームを再読み込みすれば反映されます。

- ツールバー **🔨 台詞の検査** で `python3 tools/lint_dialogue.py` を実行し、ERROR が無いか確認できます。

## リポジトリに反映する（コミット & プッシュ）

ツールバー **⬆️ コミット & プッシュ** で、編集内容を現在のブランチへコミット（と push）できます。

- 実行内容: **台詞の検査 → `git add data/dialogue` → `git commit` →（任意で）`git push`**。
  - 検査で ERROR が出たらコミットしません。
  - `main` / `master` では**コミットしません**（PR運用を壊さないための安全装置）。作業ブランチに切り替えてから使ってください。
  - push はチェックを外せばローカルコミットだけにできます。

## AI（Claude）に任せる場合

自分でコミットせず、**編集だけして Claude に反映を頼む**運用もできます（推奨のひとつ）。

1. エディタで直して各行を **保存**（JSON に書き込まれる）。
2. Claude に「`data/dialogue` の変更をコミット・プッシュして」と頼む。
3. Claude が台詞の検査 → 該当箇所の確認 → `git commit` → `git push` まで行います。

この方法なら、コミットメッセージの整え・ヘッドレステストの確認・複数ファイルのまとめも Claude 側でできます。

## よくある質問

- **保存したのにゲームが変わらない** → ゲームを再読み込みしてください（ブラウザのキャッシュが残っている場合はハードリロード）。
- **プレビューと本編で改行が違う** → 起きません。プレビューは `remake/js/vn/text.js` の `autoWrap` を配信して使っています。
- **`text` 以外（話者・分岐・条件）を編集したい** → このエディタは `text` 専用です。構造の編集は
  直接 JSON を編集してください。
- **どのブランチに入る？** → 画面右上の `branch:` 表示のブランチです。`main`/`master` のときはコミットボタンが無効化されます。
