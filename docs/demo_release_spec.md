## 1. 体験版の終わり方（ch2ロック＋「ここまで」画面）

現状: ch1クリア → `showClear()` → 「第2章へ」ボタン → `startChapter2()` でch2がそのまま始まる。
ch2は未調整箇所が多く、体験版でそのまま遊ばせると印象を損ねる。

実装:
- ビルドフラグ `DEMO_BUILD = true` を **`web/build_data.py` が `D.build.demo` に焼き込む**
  （環境変数 `SHISHA_DEMO=1` で切替。コードに直書きしない＝製品ビルドと分岐が1箇所）。
- `showClear()` 内: `D.build.demo` なら「第2章へ」ボタンを
  **「体験版はここまで！」パネル**に差し替える:
  - 文言案: 「SMOKE CROWN CUP 優勝、おめでとう！　第1章体験版はここまで。
    続き（県大会編〜）は製品版で。セーブデータは製品版に引き継げます」
  - ボタン: 「感想を送る」（→ §2のリンク）／「タイトルへ戻る」
- `startChapter2()` の頭に `if (D.build && D.build.demo) return;` の保険。
- ch2セーブの読込: 体験版ビルドで chapter>=2 のセーブをロードしたら
  クリア画面へ流す（壊さない・消さない）。

## 3. セーブ互換の方針

- SAVE_KEY は現行 `shisha_ch1_save_v1` を**体験版でもそのまま使う**
  ＝製品版で自動的に引き継がれる（「引き継げます」と告知してよい）。
- 将来 state 構造を壊す変更をする場合は、キーを変えるのではなく
  **ロード時マイグレーション**（`loadGame` 冒頭の互換ブロックに追記）で吸収する。
  既にその流儀で運用中（visitStory・flavorStock 等の互換コードが前例）。
- 体験版限定の状態（`D.build.demo` 下で作られたセーブ）に特別な印は不要。
