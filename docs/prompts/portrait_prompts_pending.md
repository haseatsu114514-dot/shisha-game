## 常連のおっちゃん（mob_occhan）— 煙の輪っか名人

### ①マスター1枚

```
ゲームの立ち絵用キャラクターイラストを1枚。
【キャラ】50代の日本人男性、下町の常連客。恰幅がよく、人の好さそうな
日焼けした顔に無精ひげ。ゆったりした開襟シャツにスラックスのラフな普段着。
いつもの席でくつろぎ、煙で輪っかを作るのが得意な、店の空気のような存在。
【構図】全身、正面やや斜め、直立。
【画風】レトロJRPG風のアニメ調ピクセルアート。輪郭は濃くはっきり。
【背景】完全な単色マゼンタ(#FF00FF)。キャラの影や光を背景に落とさないこと。
画面に文字・ロゴ・フレームを入れないこと。
```

### ②表情シート（標準5表情）

```
添付画像とまったく同一の人物・画風・服装・頭身で、表情だけを変えた
バストアップを 横3×縦2 のグリッドで1枚の画像にまとめてください。
【表情の順番】左上から → ①普通(normal) ②笑顔・ニカッと人懐こい笑い(smile) ③悲しい(sad)
④真剣・煙の輪っかに集中(serious) ⑤驚き(surprise) ⑥は①と同じでよい
【条件】各マスで顔の位置と大きさを揃える。マスの区切り線は入れない。
背景は全マス単色マゼンタ(#FF00FF)。文字を入れない。
```

```bash
python3 tools/pixelize.py master.png --char mob_occhan
python3 tools/pixelize.py sheet.png --char mob_occhan --slice 3x2 \
    --names normal,smile,sad,serious,surprise
```

## 立ち絵不要（意図的に対象外）

- `tetsuko`（mukai裏口の猫）— 猫。人物立ち絵の対象外（別途アイコン/カットで表現するかは別途検討）
- `shisha_9000`（ch5隠しボス）— AI/機械のキャラのため、通常の人物立ち絵ではなく専用CG/演出で表現する想定
- `customer` / `old_man` / `shop_clerk` / `everyone` / `staff_choizap` / `mystery_girl` — モブ枠。個別立ち絵は不要（文字バッジ表示で足りる）
