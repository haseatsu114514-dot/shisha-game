## 共通の考え方
- **表面的にAIっぽくないこと**より、プレイヤーが「この世界の登場人物・背景・画面・空気だ」と納得できる一貫性を優先。
- 同じテンプレートの多用、過剰に均一な仕上がり、根拠のない装飾、完璧すぎる整い方を漫然と繰り返さない。
- むやみに不均一にしたり、わざと汚したり、全体品質を下げて「人間らしさ」を演出することはしない。
- 先に**使う場面・視点・動線・キャラの気持ち・光源・質感**を指定してから生成。既存の正規素材と比較する。
- 不自然さを直す際は、何を固定して何を変更するか明記し、望まない顔・衣装・構図の変化を防ぐ。

## 画像・背景・立ち絵
- **画風を統一する：** `CLAUDE.md` と採用済み立ち絵・背景を参照。同一作品内で画素密度・塗り・影・線の太さ・色調が浮かないか確認する。
- **キャラを別人化しない：** 顔つき、目、髪型、服装、体格、年齢感、表情の癖は `data/characters.json` と正規立ち絵に合わせる。生成の度に「よくあるAI美少女」に寄せない。
- **均一な「盛り」を避ける：** すべてをシネマティックな光・強烈なグロー・過剰な煙・過密ディテール・左右対称にしない。照明は現場にある光源から考える。
- **素材の構造を確認する：** 机・椅子・窓・ボトル・機材・手・指・服が物理的に自然かを見直す。シーシャのホース接続・マウスピース・炭・ボウルの描写は `AGENTS.md` にある専用QAを優先。
- **構図に理由を持たせる：** 見せたい行動・人物の距離感・視線・画面の読める余白を先に設計。意味なく同じ正面センター配置を繰り返さない。
- **不要な文字を焼き込まない：** 看板文字・UIラベルはできるだけゲーム側で正確に表示する。生成画像に意図しない擬似文字を残さない。
- **採用判定は実画面で：** 画像単体の映えより、既存の正規シーンと並べたときの馴染み方を優先する。

## 台詞・説明文
- **説明調の型を繰り返さない：** 全キャラが「なるほど」「つまり」「大切なのは」などを同じ頻度で話さないようにする。
- **短文と長文を使い分ける：** 同じ長さ、同じ語尾、同じ接続語が続く単調さを避ける。短い応答と沈黙も必要に応じて使う。
- **キャラ固有の声を守る：** 語彙、距離感、照れ方、間、言い切り方を正規の人物像・前後の関係に合わせる。全員を優しく丁寧な説明係にしない。
- **感情を言いすぎない：** 結論や教訓で毎回締めず、行動、言い淀み、反応、場面の余韻で伝える。
- **自然さのためのわざとらしい口癖は禁止：** 「正直」「実は」などの前置きや三点リーダーを万能薬として増やさない。
- **情報の正確さは維持：** チュートリアルや大会ルールは分かりやすさを犠牲にしない。

## UI・音楽・SE
- 既製テンプレートのようなカード・グラデーション・発光・装飾を過剰に積まず、ゲームの情報階層と既存UIスキンのルールに合わせる。
- シーシャ店内の効果音は機材動作と連続性を重視。異なる出典の素材を使う際、響きや音量・空間が不自然に飛ばないか確認。
- 無料の効果音・背景などの採用は `docs/prompts/external_asset_sources.md` にある商用ライセンス確認と別に行う。

## AIへの追記プロンプト例（必要なものだけ抜き出す）
> **画像**：既存のゲーム画面・採用済み立ち絵と同じ作品の絵として統一する。構図、光源、質感、小物の構造に具体的な理由を持たせ、不要な光沢・盛りすぎた装飾・無意味な左右対称を避ける。人物の同一性と実物のシーシャ機材構造を最優先。生成後は現行ゲームの実画面と比較して不自然な箇所だけ修正する。
>
> **台詞**：登場人物固有の語彙と距離感に合わせ、説明文の型・同じ語尾・不自然な感情の総括を減らす。意味が伝わる長短のリズムで書き、行動と沈黙にも感情を担わせる。無理に乱暴な言葉や誤字を足さない。

## 納品前QA（必要に応じて）
- [ ] 正規キャラと同じ人物である
- [ ] 既存画像・UIと並べて同一作品の質感になっている
- [ ] シーシャの構造や小物の物理的な矛盾がない
- [ ] 不要な発光・装飾・擬似文字・同じ構図の反復がない
- [ ] 台詞に本人らしい言葉遣いがあり、説明の定型文を繰り返していない
- [ ] 画面や物語の目的に沿い、必要な情報が伝わる

## 納品前「AIっぽさ」排除チェックリスト（#2470）

立ち絵・CG・背景を**採用する前に**自分で潰す。2026年は指の本数では判別できず、見られるのは「塗り（テカリ）・顔（量産型）・文字（擬似文字）・小物（崩れ・接続）」（出典 [#2470](https://github.com/haseatsu114514-dot/shisha-game/issues/2470)）。上の「納品前QA」と重なる項目はそちらで足り、ここは画像の具体チェックを足す。全AI作画方針（オーナー決定）では、この自己点検が品質の生命線になる。

**必須（これだけは毎回・制作を止めない範囲で）**
- [ ] 肌・髪・金属（ハガル・HMD）にテカリやエアブラシのグラデがない。影は2〜3段のはっきりした形
- [ ] 正規立ち絵と顔を拡大して比べ、マスピ顔・汎用美少女に寄っていない（目・眉・鼻・口の形と年齢感）
- [ ] 擬似文字・読めない看板・サインのような線がない（文字はゲーム側で表示。保管シールの手書きだけ例外）
- [ ] 小物・ホースの接続が崩れていない（経路を両方向に追い、分岐・途切れがない）→ [シーシャCGの出力後必須QA](../asset_ai_guidance.md#シーシャcgの出力後必須qa2つの実例ミス)
- [ ] 既存の採用素材と**実際のゲーム画面で並べて**、同じ描き手に見える

**任意（余裕があれば。重くして制作を止めない）**
- [ ] 完全な正面・左右対称・正面センターの構図ばかりになっていない
- [ ] 左右で対になる装飾（ピアス・ボタン）が食い違っていない
- [ ] リムライト・グロー・全体に散った白い光の粒がない。煙はその場の光源で見える量に収める
- [ ] 画面全体が黄色・琥珀色にかぶっていない（店の照明に理由がある場合だけ暖色）
- [ ] 主な色が髪と肌のほか3〜4色程度。彩度が上がりすぎていない。輪郭線は外側がやや太く内側が細い
- [ ] 意味のない小物・反復パターン・あり得ない建築・理由のない観葉植物がない
- [ ] （ドット絵素材のときだけ）格子が合っている・16〜32色・ディザなし・半透明ピクセルなし・輪郭1px

SNSに出す画像もこのチェックを通す。SNS運用の方針は [SNS運用ルール](../marketing/sns_operation.md) を参照。

**優先順位**：ユーザーの個別指示 ＞ 最新 `CLAUDE.md` / `AGENTS.md` に記された正式仕様 ＞ このガイドの提案。これを根拠に既存の決定済み画風・UIを無断で大改造しない。
