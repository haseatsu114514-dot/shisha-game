# 追加仕様（2026-10-30 00:44 オーナー指示）: 五角形表示と、未使用の火種のアピール

> 2026-10-30 注記: 五角形は必須にしない（オーナー「五角形にこだわらなくていい」）。進み具合は盤の札の線で見せる。未使用の火種の印は火の色（赤丸にしない）。[SPEC.md](SPEC.md) 第2版 6.1。

## 五角形のステータス表示

- 5ステータスの五角形（レーダーチャート）表示は、**盤の解放状況で伸びる**形にする。能力の現在値は盤の解放そのものであり、五角形はその写像として描く（盤で解放するほど五角形が広がる）。
- 盤を開かなくても、五角形を見れば「どの系統が育っていて、どこがまだか」が分かること。

## 未使用の火種のアピール

- 火種が **溜まっていて、まだ振っていない時** は、プレイヤーに気づかせるアピールを出す。
- 第一候補は **赤丸（バッジ）**: メニューの盤への入り口などに、未使用の火種がある間は赤丸を出す。個数表示までやるかは詳細設計で決める。
- うるさくしすぎないこと（盤を開いて使い切れば消える、という基本で設計する）。
