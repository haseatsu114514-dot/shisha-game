## シェイク（アル・ワルダ／現世界王者／理タイプ・理論盤を提案）

ドバイ王族で世界大会の現王者（第4章のラスボス）。声を荒げず、急がず、「全部、受け止めよう」。葡萄一筋で「あれ以外は舌が浮気する」と言っていたが、はじめとの対戦のあと、葡萄の隣にtonariのブロンドを置いて新しい出会いを楽しむようになる。

> **盤の提案: 理論盤**。旧設定の成長の主が「洞察」（characters.json の growth_stats）で、正史ではじめの調整に残るのも「シェイクの道具と手順」（story_and_structure 第4章）だから。盤ごとの数をそろえたい時は、二つめの「魅力」に寄せて才能盤でもよい（下の「盤の数」）。

### SH-1 葡萄の隣 🔥🏠 ★推し
- **種類**: 特殊な技
- **効く場面**: 作り・配合（と、葉を買う日常）
- **効果**: 配合で、いちばん育てた葉（推しの葉）の「隣」に、まだ熟練度の低い葉を置ける。隣に置いた葉は、その一台に限って推しの葉に近い熟練度として扱われ、初めての葉でも点が落ちにくい。一度隣に置いた葉は、その後ひとりで使う時の伸びも少し良い。
- **その人らしさ**: 「葡萄だ。あれ以外は舌が浮気する」（ch4_stranger_first）から、屋敷の「では一袋、送ってくれ。葡萄の隣に置いてみよう」（ch4_ending）へ。王宮に安い日本のフレーバーを置き、新しい出会いを楽しむようになった本人の変化（characters.json の growth_stats.notes）。
- **楽しみ方**: 店で知らない葉を買う理由ができ、「得意の一台に新顔を一つ」という試し方が強くなる。アダム「単体の美学」（1種を極める）とは逆向き、熟練の舌・理論の熟練度の伸び（全部の葉が早く育つ）とは別で、「育てた葉が新しい葉を引っぱる」効き目。
- **注意**: はじめの葉はブロンドリーフのまま（葡萄もブロンドのフレーバーとして扱う）。シェイクから高価な葉や機材を贈られる描写にはしない（はじめが一袋送る側）。

### SH-2 急がない手 🏆
- **種類**: 特殊な技
- **効く場面**: 大会・中間の結果のあと → 蒸らし・調整
- **効果**: 大会の途中で誰かに上回られている時、焦りが手に出ない。蒸らしで被弾しても心が「動揺」まで揺れにくく、そのあとの調整1回目・2回目のジャスト帯が少し広い（後を追う時だけ効く）。
- **その人らしさ**: 「……急いでいるところが、一つもない」（ch4_final）。入場だけで会場が静まり、勝負中も焦る手が一つもない風格（character_profiles 2026-10-30 オーナー指示）。王座で「本気で向かってくる者がいない」人が、挑む側の構えを教える。
- **楽しみ方**: 中間で負けていても「ここから」と思える逆転の支え。大一番の胆力（大会の体調）・声援（リフレッシュでメンタル回復）とは別で、「負けている時」にだけ効く。
- **注意**: 第5章の決め手（縁から出た声で今日の事情を聞く）や第3章の勝因（待つ）を、この授業の効き目として先取りしない。台詞は「焦りを手に出さない」までにとどめる。

### SH-3 煙より先に水 🏠
- **種類**: 特殊な技
- **効く場面**: 日常・バイトと自主練（大会は除く）
- **効果**: 疲れた日でも、日常の作り（バイトの一台・自主練・家シーシャ）では体調を1段良く扱う。朝の画面で「水を一杯」と出て、効いた日はバイトのあとに「水のおかげで手が落ちなかった」と一言出る。
- **その人らしさ**: 初めて会った市場で「疲れた顔だな。煙より先に水だ」（ch4_stranger_first）。自分が疲れた客として扱ってもらった一台を大事にしてきた人（background_secret）。
- **楽しみ方**: 疲れて練習を諦めていた日にも一台作れる。大一番の胆力（大会本番の一台だけ）と住み分け、日常だけに効く。
- **注意**: 「十五年前に先に水を置いてくれた店員＝スミさん」は屋敷の場面（ch4_ending）で初めて明かされる。授業の台詞でスミさんと結びつけるのは ch4_ending を読んだ後だけにする。

## ダ・シルヴァ太陽（FESTA／ゲスト審査員／才タイプ・才能盤を提案）

ブラジル出身の陽気な店主で、第4章のゲスト審査員。「シーシャはフェスタ！楽しくなけりゃ意味がねぇ！」「美味いだけじゃ誰も振り向かねえ」と見せ方を教える。派手な祝祭の裏で、疲れた人の席・店を回すスタッフ・水と休憩・閉店の札まで見ている（ch4_festa）。

> **盤の提案: 才能盤**。旧設定の成長が「魅力」主・「根性」副（characters.json）で、人を沸かせる力と体力の両方が才能盤の中身（カリスマ・体力）だから。今いちばん授業が少ない才能盤（3）を埋められる。

### DS-1 ボトルのフェスタ 🔥🏆 ★推し
- **種類**: スキル
- **効く場面**: 作り・準備（ボトルに水を注ぐ工程）→ 提供
- **効果**: ボトルに水を注ぐ時に「飾り」を一つ選べる（果物の輪切り・氷・何もしない）。果物は見た目で客と観客の受け止めが良くなり（大会の中間の反応・バイトの客の反応）、配合の葉と同じ系統なら香りにもほんの少し乗る（合わなければ見た目だけ）。氷は煙を少し軽く冷たくし、暑い日や重めの配合に合う。果物は店で少し買う。
- **その人らしさ**: 「美味いだけじゃ誰も振り向かねえ」（character_profiles）。南国フルーツのお祭りミックスが得意（characters.json の specialty_flavor）。
- **楽しみ方**: 作る前に「今日はどう見せるか」を選ぶ小さな楽しみ。才能5段の第一印象の加点（自動）や、みんと M-3「煙で魅せる」（吸い出しの最後の一口）とは別で、配合と組み合わせて選ぶ準備の一手。
- **注意**: 実在のシーシャで行うボトルの果物・氷の範囲にとどめ、着色や食べられない物は入れない。

### DS-2 休みの札 🏠
- **種類**: スキル
- **効く場面**: 日常・予定（週に1日）
- **効果**: 週に一度、「休みの札」を掛ける日を決められる。その日に遊び（映画・斧バー・くじなど）や人と会うことに使うと、体力が大きく戻り、遊びのご褒美が一段良くなる。札の日は練習・バイトを選ばない（選ぶと札が外れる）。
- **その人らしさ**: 店を持ちたいはじめに「休みの日は誰が開ける？」と聞き、閉店の札を見せて「明日は俺も休み」（ch4_festa）。祝祭を続けるために休みを決める店主。
- **楽しみ方**: 「休む日」を自分で選ぶと得になり、遊びのスポットに行く理由ができる。早寝早起き（ふつうに眠った時の戻り）とは別で、札を掛けた日の遊び方に効く。はじめの店を持つ夢と、第5章の「作れない日にも席がある」にもつながる。

### DS-3 言葉のいらない一台 🏠
- **種類**: 特殊な技
- **効く場面**: 日常・交流（会話のあと）
- **効果**: 会話で仲が深まる選択肢を外した時、その場で「一台を出す」を選べる（1日1回）。出せば、その会話の好感度の伸びが、合う選択肢を選んだ時と同じになる。告白・締めくくり・大事な場面では出ない。
- **その人らしさ**: シーシャを通じた「言葉不要のパフォーマンス」に自分の居場所を見つけた人（characters.json の background_secret）。言葉より先に椅子を回し、手拍子を一つ増やす（ch4_festa）。
- **楽しみ方**: 会話の失敗を一台で取り返せる安心。空気を読む（選ぶ前に印が出る）とは逆で、外した「後」に効く。好感度の伸び（才能の効き目）とは別で、外した時だけ働く。
- **注意**: 太陽の生い立ち（貧困と暴力の中で育った・夢の挫折）は授業の場面で説明しない。明るさの裏は、休みや疲れた人の席への目配りで見せるだけにする。

### 推しの理由（1行ずつ）

- **シェイク／葡萄の隣**: 「葡萄以外は浮気」から「葡萄の隣に置いてみよう」への本人の変化が、そのまま新しい葉を試す遊びになる。決定済みの授業とどれも重ならない。
- **太陽／ボトルのフェスタ**: 「美味いだけじゃ誰も振り向かねえ」を、準備で選ぶ見せ方の一手にできる。決定済みの授業に「準備（ボトル）」の工程に効くものはまだ無い。

### 盤の数

- 提案どおり（シェイク＝理・太陽＝才）だと、授業は **才4・感5・理7＝計16**。理論盤が多くなる。そろえたい時はシェイクを才能盤（二つめの「魅力」・王の器）にすると **才5・感5・理6** になる。どちらでも、盤の型（#1801）の要所を2つ足す。
- 2人の授業は第4章の要所（第4輪）より奥に置き、第5章で道が届く形にする。
