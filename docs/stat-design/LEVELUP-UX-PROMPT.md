## 目的
レベルアップの一連の流れ（経験値ゲージ → レベルアップ → 火種の付与 → 盤での割り振り → 効果の実感）の **触り心地** を評価し、第二弾（盤・火種・レベル本体）の実装前に、使用感の問題を先に潰す。

## 進め方
1. **実物で評価**: 第一弾で着地した部分（見せ方の改善など表示系）は、実ビルドを実際に触って評価する。手順はリポジトリの通常の起動・テストの流儀に倣う。
2. **モックで先行評価**: 盤など未実装の部分は、評価用のモック／プロトタイプを作って触る。モックは使い捨て前提で軽く作る（HTML プロトタイプ等）。見た目の素材が要る場合は自分で生成せず、Codex の生成レーンへの依頼として切り分ける（依頼文を REPORT に残す）。
3. **比較の軸**: 龍が如くのレベルアップ体験と比べてどうか（上がった実感の強さ／割り振りの気持ちよさ／次に何が解放されるかの見通し／迷いのなさ／テンポ）。第1章のテイスト基準も外さない。
