## 1. 結論（先に3つ）

1. **骨格は良い。** 1日の行動で経験値が貯まり、ゲージで「今夜上がる」が分かり、寝ると上がって火種を手に、盤で自分で選ぶ、という流れは龍が如くの「稼ぐ → 振る」の気持ちよさに近い。第1章の中央の遊び方では、大会までの13夜でレベルが8つ上がる（1.6：大会前 Lv.9）。5晩のうち3晩ほどで、頻度はちょうどよい。
2. **一番の弱点は「効果の実感」。** 火種1つ＝能力1段の伸びは 2〜5%（3.2〜3.6）で、数値も出さない方針なので、**初めて振った直後に何も変わった気がしない**。モックで センス1段→2段 を試すと、色で塗った伸び分は帯の両端に約1.7pxずつしかなく、目では分からない（`shots/mock-5-feel-2dan.jpg`）。チュートリアル手順6（11.3）が「前後を並べて見せる」設計なので、ここがそのまま空振りする。
3. **レベルアップの精算を差し込む位置が、SPEC の想定とずれている。** 「寝る時の振り返り（`presentSleepRecovery` の直前）」は、今のコードでは **夜明けの演出が終わった翌朝の家の画面** にあたる（`daily/calendar.js:827-835`）。このため「今日学んだこと」が翌朝に出るうえ、**大会前夜に上がった分の火種は、盤を開けない大会当日の朝に届く**（2.2「大会当日は使えない」と衝突）。

## 3. 引っかかるところ（場面に紐づけて・推奨つき）

### P1. 初めて振った1段の効果が体感できない【最重要】

- **場面**: チュートリアル手順5→6（11.3）。初めての火種で第1輪の2段目を取り、「センスが2段になった。ジャスト帯がほんの少し広くなる」とお手本が流れる。
- **何が起きるか**: 1段→2段の差は、技術 ×1.02（ゲージ）、センス ×1.05（帯）、根性 体力+5、魅力 指名ボーナス+250円、洞察 明瞭度 0→0.11。モックの炭焼きで センス2段 を色付きで試すと、伸び分は両端に約1.7pxずつで見えない。お手本を「前後に並べて」も同じ絵に見える。**プレイヤーが最初に盤から受け取る手応えがゼロになる。**
- **今のビルドでも同じ傾向**: STATUS UP カードは「今回 +1P」だけで、効果に届くまで（★の境目まで）は何も変わらない。第一弾の「次の段まで」（7.2）がまだ無いので、+1P の意味が分からない。
- **推奨**（SPEC の数値は変えずにできるもの）:
  1. 手順6のお手本は「1段 vs 2段」ではなく、**「今（1段）」と「この章で届く段（5段）」を並べる**。キャプションは「1段ずつ、ここまで広がっていく」。第1章の上限5段のセンスなら帯は ×1.20 で、色の部分が目で見える幅になる。
  2. 盤と効果プレビューに、**質が変わる段の印（✦）** を出す。根性5段「弾消しでメンタル回復」、洞察3段「配合の相性ヒント」・5段「黄金比のヒント」、魅力2段「指名ボーナス」。これらはどれも、新しくできることが増える段（3.4〜3.6 の ○ の入口）。モックでは右欄の「✦3段で『配合の相性ヒント』」が、次に振る理由として一番効いた。
  3. 依存関係の修正: B17（チュートリアル1）は作り画面の色付け（A6〜A8、7.3）を手順6のお手本に使うが、9章の依存表は B8・B9・B12 だけで **A6〜A8 が入っていない**。A6〜A8 を B17 の前提に加える。

### P2. レベルアップの精算が翌朝に出る／大会前夜の火種が使えない

- **場面**: 寝る → 夜明けの演出（DAY がめくれる）→ 家の朝 → 体力の回復ゲージ（`presentSleepRecovery`）。SPEC 6.3 はレベルアップ演出を「`presentSleepRecovery` の直前」に置く。
- **何が起きるか**: `daily/calendar.js:827-835` では、`presentSleepRecovery` は `dayTurn`（夜明けの演出）が終わった後に呼ばれる。その直前に置くと、
  - 「**今日**学んだこと：…」が翌朝の画面に出る（前日のことなのに「今日」）。
  - 大会前日の夜は `fadeBlack` で大会当日に入る（`calendar.js:833`）。大会前夜に上がった分の火種は大会当日の朝に届くが、**大会当日は盤を開けない**（2.2）。「盤を開く」を押せないか、押しても大会に間に合わない。1.7 の「大会日の朝の精算は前夜の寝る演出に含め」と、2.2 の「大会前夜に何に賭けるか決める」が実装上かみ合わない。
- **推奨**: 精算と演出は **寝る直前（`dayTurn` の前、夜の家の画面）** に置く、と SPEC 6.3／1.7 の文言を直す。こうすれば「今日学んだこと」の言葉が合い、大会前夜も「盤を開く」でそのまま決められる。体力の回復ゲージは今どおり翌朝に残す。
  - 参考: 夜のイベント・家シーシャの選択も同じ夜に続くので、順番は「夜の行動を終える → 家シーシャの選択 → レベルアップ（あれば）→ 盤／あとで → 寝る」が自然。

### P3. 夜のレベルアップが毎晩のモーダルになり、テンポが重くなる

- **場面**: 第1章の中央の遊び方では、大会までの13夜でレベルが8つ上がる（1.6：大会前 Lv.9）。そのたびに「LEVEL UP → 今日学んだこと → 盤を開く／あとで」を挟む。今の夜はすでに、夜のイベント → 家シーシャを試すか → 寝る → 夜明け → 体力回復、と段数が多い。
- **モックで触った感覚**: 1回目と節目は気持ちいい。3回目あたりから「あとで」を押す作業になる。火種1つで決めることは「5色のどれか」だけなので、毎回フル画面を開く理由が薄い。
- **推奨**:
  1. フル演出（ゲージが弾けて火種が飛ぶ）は **初回・節目のレベル（Lv.10・20…）・1晩に2つ以上上がった時** だけにする。それ以外は約1.5秒の短い帯「Lv.12 → 13　火種＋1　［盤］」にして、押さなければそのまま寝る。
  2. 「今日学んだこと」は短い帯にも1行で残す（G2 の強みは消さない）。
  3. 早送り（タップで最後へ）は SPEC どおり必須。モックでも、2回目以降は早送りを毎回使った。

### P4. HUD のゲージの置き場所が SPEC の想定と合わない

- **場面**: SPEC 6.1a は「レーダーの下に横長の細いゲージ（幅はレーダーと同じ）。左に Lv.12、右に あと120」。
- **今のビルド**: HUD のレーダーは右上の 44px の正方形ボタンで（`daily/hud.js:72,94`、`css/daily.css:194`）、左上の情報カード（所持金・大会まで・体力）とは別の場所にある（`shots/now-1-levelup-card.jpg`）。幅44pxには「Lv.12」と「あと120」が並ばない。
- **推奨**: ゲージは **左上の情報カードに1行足す**（体力の行の下）。モックはこの形で、1331×760・844×390・591×1280 のどれでも収まった（`shots/mock-1-chips-gauge.jpg`）。追い風はその行の右に小さく出す。火種の個数は次の P5 の印に任せ、HUD の行を増やしすぎない。

### P5. 未使用の火種の「赤丸」が LIME の未読と並んで紛れる

- **場面**: ADDENDUM-0044 の第一候補は、盤への入り口に赤丸。
- **今のビルド**: 右上はレーダー・LIME・MENU の3つのボタンが並び、**LIME の未読がすでに赤丸**。隣のレーダーにも赤丸が付くと「何か来ている」とだけ伝わり、LIME と区別しにくい。モックで赤丸と火の色を切り替えて比べると、火の色（琥珀の炎のような丸と個数）の方が「火種が余っている」とすぐに結びついた（「未使用の火種を赤丸で出す」で比べられる）。
- **推奨**（0044 の「詳細設計で決める」の範囲）: 印は **火種の色（琥珀）で、個数入り**。付ける場所は **右上の五角形のボタン（レーダー）を第一** にする。0044 の「五角形は盤の写像」とそろい、「五角形を押す → 盤」が覚えやすい。MENU の「盤」項目にも同じ印を付ける。
  - 「使える火種がある時だけ」出す（輪の鍵で今は使えない限定の火種だけなら出さない）。モックではこの条件で、出しっぱなしのうるささが減った。

### P6. 経験値のチップが1行動で縦に積み上がる

- **場面**: 店に1回行くと、モックでは「EXP +30」「はじめて +40」「会話を読んだ +20」「仲が深まった +30」が別々のチップで最大4つ出て、そこにスロットの追い風カード、実ビルドなら熟練度アップと AFFINITY UP のカードが重なる（`shots/mock-1-chips-gauge.jpg`、`shots/now-2-visit-cards.jpg`）。
- **推奨**: SPEC 6.3 の「同じチップに足す」を **1行動につきチップ1枚** と明記する（例「EXP +120　はじめて・会話・仲」）。合計と内訳の言葉だけを出し、内訳の数字は出さない。

### P7. 色のついた火種の種類が増えて、払える／払えないが読みにくくなる

- **場面**: 盤の上部の火種の表示とノードの払い。1.9 の「系統限定の火種」（節目・大会。技・感・根・魅・察の5色）に、ADDENDUM-0042 の「キャラの色の火種」（好感度 MAX）と「色ロックのノード」、ADDENDUM-0035 の「修行で開くノード」が加わる。
- **モックで重ねた感触**（「追加要件の札も盤に重ねる」）: ノードの状態が5つ（解放済み・今取れる・火種不足・段の順待ち・輪の鍵）から7つ（＋修行がまだ・その色がない）になる。系統の色とキャラの色が同じ5色なら、**節目でもらった「感の火種」で、つむぎの色のノードが開くのか** が画面から読めない。開くなら、好感度 MAX の報酬としての意味が薄れる。開かないなら、同じ色なのに使えない火種が2種類できる。
- **推奨**（第二弾の詳細設計で詰める時の条件として）:
  1. キャラの火種は **キャラの名前で呼び、見た目で区別する**（「つむぎの火種」。炎の中に頭文字か顔の小さな印）。系統の火種（「感の火種」）とは別の物として、色ロックのノードは「つむぎの火種でだけ開く」と書く。
  2. 盤の凡例と「？」に、7状態を一覧で出す。色ロック・修行のノードは、払えない理由を下の帯に1行で出す（モックでは「修行がまだ」「その色の火種がない」）。

### P8. 盤のノードの見た目が単調で、「欲しい」が生まれにくい

- **場面**: 盤を初めて開いた時（`shots/mock-3-board.jpg`）。能力ノード45個は、どれも漢字1文字（技・感…）の丸。スキル14個は ②③④ の六角形。
- **感触**: 全体の形は分かりやすいが、どれも同じ粒に見えて、**「あれを取りたい」と思う目印がない**。龍が如くの盤は、ノードごとに技の名前と絵があり、外側の大技が遠くに見えていることが「次へ」の動機になる。
- **推奨**: (1) スキルは六角形の中に名前の頭（「段取」「火番」…）か専用アイコンを出し、輪の鍵がかかっていても名前は見せる。(2) P1 の ✦（質が変わる段）を能力ノードに付ける。(3) 第4輪の「決め手」スキル4つは、少し大きく描く。アイコンが要る場合は 6章末の「画像素材の依頼」に回した。

### P9. 844×390 で、チュートリアルの案内文が操作を塞ぐ

- **場面**: 手順5「光っているノードは今取れる。好きなものを1つ選んで…」を出したまま、下の帯の「仮置きする」「決定して閉じる」を押す。
- **モック**: スマホ横（844×390）で、画面下に出した案内文が決定ボタンを覆い、押せなかった（自動操作が実際に詰まった）。盤は下の帯に操作が集まるので、下に案内文を出すと必ずぶつかる。
- **追記（秘孔盤ふうの版）**: 案内文を上に移すと、今度は盤の札（入れ替え）を覆った。盤は上下とも操作が並ぶので、置き場所だけでは解けない。
- **推奨**: 案内文は **文字の部分ではタップを素通りさせ、ボタンだけ押せる** ようにする（モックはこの形で、上下どちらに出しても操作が詰まらなくなった）。置き場所は盤の中央寄り。11.6 に「案内文が操作を塞がない（3解像度）」を加える。

### P10. 細かい点

- 今のビルドのステータス画面の根性1段は「中くらいの範囲の弾を消す」のまま（7.4 で直す予定の誤り。`shots/now-3-status.jpg`）。A1 は小さいので先に入れてよい。

### 触った評価

- **良くなった点**
  - 「どの色の火種で何が取れるか」が、下の所持数と色つきのノードで一目で分かる。P7（火種の種類が増えて読みにくい）は、秘孔盤の「珠の色＝ノードの色」の約束でかなり解ける。キャラの火種も、この行に名前つきで並べれば紛れない（R8 と同じ方向）。
  - 右の大きなパネルがあるので、能力ノード1つでも「技術 2段：ゲージがほんの少しゆっくりに」が主役として読める。P8（どれも同じ粒に見える）は、一枚絵が入ればかなり解ける。札を選ぶと「次に取れる段」が自動で選ばれるので、**札 → 仮置き の2タップで振れる**。
  - 中央の「極み（10段）」が鍵つきで見えているのは、龍が如くの「遠くの大技が見えている」に近い。見通し（4章）の不足を少し埋める。
  - 五角形を進捗度にすると、スキルに振った分も五角形が広がる。「スキルに振ると能力が育たず五角形が縮んだように見える」という損した感じがなくなる。
- **引っかかるところ**
  - **スマホ横（844×390）ではノードが小さい**。7×7 の格子を高さ約280pxに収めるとノードは直径約17pxで、SPEC 6.2 の「最小44px」に届かない（`shots/mock-7-hokuto-844x390.jpg`。PCは `mock-7-hokuto-pc.jpg`、縦は `mock-7-hokuto-591x1280.jpg`）。秘孔盤はテレビの画面が前提。推奨: 小さい画面では、ノードを直接押すより **札で盤を選ぶ → 右のパネルに次の段が出る → 仮置き** を基本の操作にし、ノードを押すのは任意にする（モックはこの形）。スキルは右のパネルの「この盤のスキル」一覧から選べるようにする。
  - 盤が5枚に分かれると、全体の見渡しは札の％と五角形だけになる。2色のスキル（空気を読む・火の番）は2枚に出るので、取ったことが両方に出ることを説明に1行添える（モックは2つの盤のどちらにも解放済みで出る）。
  - 五角形を進捗度にすると、**能力の強さ（段）とは別の物差しになる**。スキルを多く取った盤は、段が低くても五角形が大きい。ステータス画面で強さを見たい時は、札とピップの「N段」で見る、と役割を分ける。0044 の「能力の現在値は盤の解放そのもので、五角形はその写像」の文言は、「五角形は盤の進捗度」に直す必要がある。
