# 追加仕様（2026-10-30 00:42 オーナー指示）: 色（系統限定）の火種とキャラのつながり

> 2026-10-30 注記: 色は能力の3色（才・感・理）。キャラのタイプがその人のくれる色を決め、♥5で贈られる。その人の特別な修行も同じ色の盤にある。色ロックのマスは置かず、色つきの火種はその色の盤にだけ使える形にした。[SPEC.md](SPEC.md) 第2版 1.9・2.7。

ステータス設計 案A への追加要素。色つきの火種（系統限定の火種）と、キャラ・好感度・修行を結びつける。

## 要件

- **色つきの火種は、キャラによって分かれる**。各キャラには対応する色（系統）があり、どのキャラと深く関わるかで、もらえる色が変わる。
- **好感度が MAX になると、そのキャラの色の限定火種がもらえる**（関係を深めきった節目の報酬として置く）。
- 盤には **万能の火種では開けられないノード** がある。そのノードは、対応する色の火種でないと開けられない。
- **修行もこの仕組みに対応する**（ADDENDUM-0035 の修行は、キャラ・色と結びつけて設計する。修行の相手や内容が、色や色ロックのノードと対応する形を基本とする）。

## 設計上の注意（詳細設計で守ること）

- 色ロックのノードは盤の一部にとどめ、大半は万能で進めるようにする（特定のキャラへの義務的な張り付きを生まないため）。
- 「通う相手で育つ」を不採用にした決定は維持する。色の火種は訪問回数ではなく **好感度という関係の深さ** から出るもので、行き先の損得計算とは別軸にする。
- キャラと色の対応表、好感度 MAX 以外の入手経路（節目・大会の限定火種との兼ね合い）、色ロックノードの数と置き場所は、第二弾の詳細設計（Opus）で詰める。

## 追加（2026-10-30 00:43 オーナー指示）: どのキャラがどの色か「分かる」ようにする

- キャラと色の対応は、プレイヤーが **なんとなく分かる・納得できる** 付け方にする。根拠はキャラの既存のイメージ（テーマカラー、得意なこと、性格・役割）から素直に引く。
- ゲーム内でも分かるように出す（隠し情報にしない）: キャラの紹介や好感度まわりの表示に、そのキャラの色がさりげなく分かる手がかりを置く。火種をもらう場面では、なぜその色なのかが伝わる見せ方にする。
- 詳細設計では対応表に「このキャラがこの色である理由」を1行ずつ添えて、納得感を検品できる形にする。
