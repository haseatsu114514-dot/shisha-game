# 追加仕様（2026-10-30 オーナー指示）: 心得の盤は能力ごとの盤で、スフィア盤のようにつながる

ステータス設計 案A（SPEC.md）への追加要素。オーナーの指示は2回あり、後の指示を正とする。

1. 北斗が如くの秘孔盤の画面写真とともに「こんな感じで管理したい。五角のはあれは進捗度で判断」。
2. 続けて「右にイメージ出したり、技ならそれ発動してるイラスト。次はあれが欲しいってなるようにしたい」「レベルアップはいつでもメニューからできるようにするか、それともどこか振れるスポット作ってもいいかも、観音とか」「五角形にこだわらなくていいや」「修行で解放はロックしておいて欲しい。そしてみんととの交流で開放とか、そういう感じでヒントは出しつつ」「スフィア盤みたいに繋がったり、画面全体というよりは洞察盤、魅力盤みたいなのを作って、それぞれの盤で伸ばしてく」。
3. さらに「龍が如くシリーズみたいに同じ盤でも好きな方向から攻めれるようにしたい」。
4. さらに「もっと手に入る玉の数とか細かくしたい、龍が如く並みに。そして盤の形も龍が如くみたいに斜めは無しで4方向で進んでく」。

5. さらに「今5項目あるけどゲームとして三項目とかに減らしていいかも、多すぎる」「ライバルも3タイプに分けて」「魅力は没」「項目やタイプ名も変えていいかも」。3つの案を示したところ「体、センス、あとどうしよう」。3つ目はこちらの推奨「知」で進めた（名前は差し替え可）。

## 能力は3つ（体・センス・知）

| 新しい能力 | 札 | 中身（旧の能力から） | 効くところ |
|---|---|---|---|
| **体** | 体 | 旧 根性（体力の上乗せ・減りにくさ、蒸らしの当たり判定、リフレッシュの範囲、5段からメンタル回復） | 体力・蒸らし |
| **センス** | 感 | 旧 センス（ジャスト帯が広い）＋旧 技術（ゲージがゆっくり） | 穴あけ・炭焼き・吸い出し |
| **知** | 知 | 旧 洞察（配合の相性ヒント・黄金比のヒント・炭の気配・蒸らしの弾の間隔・蒸らし予測） | 配合・炭焼き・蒸らし |

- **魅力は没**。バイトの指名ボーナスと好感度の伸びの倍率は、能力に結びつけない（指名ボーナスは固定の額にするか無くす。好感度は倍率なし）。
- 段の効き方（SPEC 3章）の上限・下限は変えず、3つの能力の表に組み直す。センスは2つの効き目（帯とゲージ）を同じ段で伸ばす。
- スキル14個は3つに付け替える（モックの仮: 体＝早寝早起き・二枚目のリフレッシュ・疲れ知らず・大一番の胆力・声援（体×センス）／センス＝段取り八分・人見知りしない・熟練の舌・火の番・声援／知＝香りの記憶・空模様・空気を読む・審査員の目・炭の声）。
- 盤は3枚（体盤・センス盤・知盤）。盤の合計を SPEC の5倍（430）に近く保つため、1段＝能力のマス8つにした（3盤で216＋スキル205＝421）。1周目の埋まりの比率はほぼ変わらない。

## ライバルは3タイプ（体・センス・知）

各章のライバルが1人ずつ3タイプにそろうよう分けた（案。人物の設定は変えず、札だけ付ける）。

| 章 | 体タイプ（粘り・熱さ・持久） | センスタイプ（感覚・手さばき） | 知タイプ（理論・読み・計算） |
|---|---|---|---|
| 第1章 | みんと（実家を取り戻すまで貯め続けた執念） | アダム（ミリ単位の熱管理の職人の手） | なる（菓子の味から組み立てる理論派） |
| 第2章 | 組長（スジを通す熱さ、純粋な葉への執念） | アゲハ（理論ぬきのバイブスと直感） | 零（黙って相手を見て、言葉に詰まった人を待つ観察） |
| 第3章 | スティーブ（二口目まで残す低温の粘り） | 久世（香りの物語で一口目を立たせる） | ヴォルク（データと温度管理の精度） |

- 大会でタイプが何に効くか（例: 相手のタイプで審査の重みが変わる、三すくみ）は未定。今は「ライバル紹介と札で、相手の持ち味が分かる」までを要件にする。


- **盤は能力ごとに分ける**: 技術盤・センス盤・根性盤・魅力盤・洞察盤の5枚。画面全体に1枚の大きな盤は作らない。上の札（盤の名前・段・進み具合の線）か左右の切り替えで入れ替える。今取れるノードがある盤の札には印を出す。
- **盤は方眼で、上下左右の4方向に進む（斜めは無し）**: 各盤の真ん中に「はじまり」があり、そこから上下左右に方眼が広がる。線は上下左右の隣だけ。**取れるのは、上下左右の隣が解放済み（か、はじまり）のマスだけ**（SPEC 2.2 の「経路でつながなくてよい（玉方式）」を置き換える）。どの方向から攻めてもよい。
- **遠いほど後の章**: はじまりから何マス離れているか（上下左右に数える）で輪を決める。モックは 第1輪＝1〜3マス、第2輪＝4マス、第3輪＝5マス、第4輪＝6マス、第5輪＝7マス（外側の輪は左右の腕の先）。
- **方向ごとに先にあるものを変える**（モック: 左＝第1輪スキル、左上の枝＝第2輪スキル、右＝第3輪スキル、左の腕の先＝第4輪スキル、下＝修行、右の腕の先＝極み）。
- **火種は龍が如く並みに細かく**: SPEC の量を5倍にそろえる。レベルアップ1回で火種5（節目は限定の火種がさらに5、各章の大会の限定の火種も5）。能力のマスは火種1で「段の1/5」、**5つ灯すと1段**。スキルは火種10／15／20（SPEC の 2／3／4 の5倍）。盤ぜんぶで 能力225＋スキル205＝430（SPEC の86の5倍）なので、1周目の埋まり（7〜8割）・章ごとの到達の比率は SPEC のまま。修行は火種10（仮）。
- 段＝その盤で灯した能力のマス÷5＋1（SPEC 3.1 の段の効き方は変えない）。SPEC 2.2 の条件3「その色の次の段」は外す。
- 2色のスキル（空気を読む・火の番）は両方の盤に出し、どちらの盤から届いても取れる。取れば両方で解放済み。
- **右に大きなパネル**: 選んだノードの一枚絵・名前・効果・コスト・状態・何で払うか。**スキルは、その技を発動している場面のイラスト**。能力の段は、その能力を発揮している場面のイラスト。まだ取れないノードも絵と名前は見せる（「次はあれが欲しい」を生むため）。
- **目標（欲しいものへの道しるべ）**: ノードを目標にすると、そこまでの道を盤の上に金の点線で出し、「火の番まで 火種12」と残りを盤とHUDに出す。届いたら目標は外れる。
- **修行のノードは錠つき**: 修行のノードは最初から盤に見えているが錠がかかっている。キャラとの交流で開く（例：みんととの交流で魅力盤の修行が開く）。錠のあいだは名前と絵を伏せ、**ヒントを出す**（「みんとと交流を深めると、何か教えてもらえそう」・交流の進み具合）。開いた後は火種で取る（ADDENDUM-0035 の「修行＝鍵、火種＝コスト」）。
- **火種は下の帯に色別の所持数で並べる**（万能・技・感・根・魅・察。キャラの火種〔ADDENDUM-0042〕もここに名前つきで並べる）。
- **五角形は必須にしない**（1回目の指示の「五角形は進捗度」は、2回目の「こだわらなくていい」で取り下げ）。進み具合は盤の札の線で見せる。ADDENDUM-0044 の五角形の要件はこれに合わせて外す。

## 詳細設計で詰めること（第二弾の着手前）

- 1マス（段の1/5）にも効き目を持たせるか。今の SPEC は段ごとに効くので、5つ灯すまで効き目が変わらない。内部値（今の能力値 10〜100）は1マス＝+2 にそろうので、連続的な効き目（技術のゲージ・センスの帯など）は1マスごとに少しずつ効かせることもできる（上限・下限は SPEC のまま）。
- NG+ の P＝min(45, 周回開始時の獲得玉)/45 は、225 と火種の数にそろえる。

- 各盤の道の数と形、どの道の先にどのスキル・修行を置くか（盤ごとに変えてよい）。つながりを条件にしたので、スキルの手前には能力の +1 がいくつか挟まる（モックの第4輪のスキルは、はじまりから4つ先）。SPEC 2.4「スキルを取ると能力が遅れる」の重さは、「どの方向から攻めるか」の選択に変わる。8章の計測と 1.6 の到達表で、1周目の埋まりと第1章の勝率を確かめ直す。
- 修行の中身（誰の・何を・どの盤の・何章で）と、交流の条件（好感度の段など）。ヒントの文。ADDENDUM-0042 のキャラの火種・色ロックとの関係。
- SPEC 2.1〜2.6・6.2・11.3（手順4のお手本）・ADDENDUM-0044 の書き換え。
- 一枚絵（能力ごと・スキル14・修行・極み）の素材（`levelup-ux/REPORT.md` 7章）。
