# 追加仕様（2026-10-30 オーナー指示）: 心得の盤は秘孔盤式で管理し、五角形は進捗度で描く

ステータス設計 案A（SPEC.md）への追加要素。オーナーが北斗が如くの秘孔盤の画面写真を示し、「こんな感じで管理したい。五角のはあれは進捗度で判断」と指示した。

## 要件

- **盤は能力ごとに分け、入れ替えて見る**（技術・センス・根性・魅力・洞察の5枚）。画面の上に5枚の札（能力名・段・進捗の％と線）を並べ、札か左右の切り替えで盤を入れ替える。今取れるノードがある盤の札には印を出す。
- **各盤は格子にノードを並べ、線でつなぐ**。段のノード（2〜9段）が外側から中央へ向かい、**中央の大きなノードが10段（極み）**。その色のスキルは、同じ輪の段から枝分かれした位置に置く。2色のスキルは両方の盤に出し、どちらで取っても両方で解放済みにする。
- **選んだノードの説明は、右の大きなパネルに出す**（一枚絵・名前・効果・コスト・状態・何で払うか）。
- **火種は下の帯に色別の所持数で並べる**（万能・技・感・根・魅・察。キャラの火種〔ADDENDUM-0042〕もここに名前つきで並べる）。色つきのノードは、その色の火種で払うものと一目で分かる見た目にする。
- **五角形は各盤の進捗度で描く**: 軸の値＝その盤で解放したノードの火種の合計÷その盤の火種の合計（スキルを含む。2色のスキルは両方の盤に数える）。HUD の五角形、ステータス画面、盤の見出しと札の％を同じ値にそろえる。能力の強さは「N段」とピップで別に見せる。ADDENDUM-0044 の「五角形は能力の現在値の写像」をこの定義に置き換える。

## 変えないこと

- 取れる条件は SPEC 2.2（輪が開いている・火種が足りる・段の順）。盤の線は段の順と所属を見せる飾りで、隣とつながっていなくても取れる。秘孔盤のように隣接を条件にするかどうかは、オーナー判断待ち（玉方式〔23:46〕の決定に関わるため）。
- 輪（章で開く）、コスト、スキル14個、限定の火種の払い方、仮置き・決定、組み直しの機会。
