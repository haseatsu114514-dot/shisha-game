# 追加仕様（2026-10-30 オーナー指示）: 心得の盤は能力ごとの盤で、スフィア盤のようにつながる

ステータス設計 案A（SPEC.md）への追加要素。オーナーの指示は2回あり、後の指示を正とする。

1. 北斗が如くの秘孔盤の画面写真とともに「こんな感じで管理したい。五角のはあれは進捗度で判断」。
2. 続けて「右にイメージ出したり、技ならそれ発動してるイラスト。次はあれが欲しいってなるようにしたい」「レベルアップはいつでもメニューからできるようにするか、それともどこか振れるスポット作ってもいいかも、観音とか」「五角形にこだわらなくていいや」「修行で解放はロックしておいて欲しい。そしてみんととの交流で開放とか、そういう感じでヒントは出しつつ」「スフィア盤みたいに繋がったり、画面全体というよりは洞察盤、魅力盤みたいなのを作って、それぞれの盤で伸ばしてく」。
3. さらに「龍が如くシリーズみたいに同じ盤でも好きな方向から攻めれるようにしたい」。

## 要件

- **盤は能力ごとに分ける**: 技術盤・センス盤・根性盤・魅力盤・洞察盤の5枚。画面全体に1枚の大きな盤は作らない。上の札（盤の名前・段・進み具合の線）か左右の切り替えで入れ替える。今取れるノードがある盤の札には印を出す。
- **ノードはスフィア盤のようにつながり、同じ盤でも好きな方向から進められる**: 各盤の真ん中に「はじまり」があり、そこから複数の方向（モックは3方向）に道が伸びる。**取れるのは、手前のノードを解放した先だけ**（SPEC 2.2 の「経路でつながなくてよい（玉方式）」を、この指示で置き換える）。どの方向から進めてもよい。
- **能力のノードはどれも「その能力 +1段」**。段＝その盤で解放した能力ノードの数＋1（SPEC 3.1 の数え方）。どの道で取っても同じだけ伸びる。SPEC 2.2 の条件3「能力ノードはその色の次の段であること」は外す（段は位置ではなく数で決まる）。
- **道ごとに先にあるものを変える**ことで、方向の選び方に意味を持たせる（モック: 左＝第1・3輪のスキル、右上＝第2・4輪のスキル、右下＝修行の枝といちばん奥の「極み」）。外側ほど後の章で開く（輪＝はじまりからの遠さ）。輪・火種のコスト・限定の火種の払い方は SPEC のまま。
- 2色のスキル（空気を読む・火の番）は両方の盤に出し、どちらの盤から届いても取れる。取れば両方で解放済み。
- **右に大きなパネル**: 選んだノードの一枚絵・名前・効果・コスト・状態・何で払うか。**スキルは、その技を発動している場面のイラスト**。能力の段は、その能力を発揮している場面のイラスト。まだ取れないノードも絵と名前は見せる（「次はあれが欲しい」を生むため）。
- **目標（欲しいものへの道しるべ）**: ノードを目標にすると、そこまでの道を盤の上に金の点線で出し、「火の番まで 火種12」と残りを盤とHUDに出す。届いたら目標は外れる。
- **修行のノードは錠つき**: 修行のノードは最初から盤に見えているが錠がかかっている。キャラとの交流で開く（例：みんととの交流で魅力盤の修行が開く）。錠のあいだは名前と絵を伏せ、**ヒントを出す**（「みんとと交流を深めると、何か教えてもらえそう」・交流の進み具合）。開いた後は火種で取る（ADDENDUM-0035 の「修行＝鍵、火種＝コスト」）。
- **火種は下の帯に色別の所持数で並べる**（万能・技・感・根・魅・察。キャラの火種〔ADDENDUM-0042〕もここに名前つきで並べる）。
- **五角形は必須にしない**（1回目の指示の「五角形は進捗度」は、2回目の「こだわらなくていい」で取り下げ）。進み具合は盤の札の線で見せる。ADDENDUM-0044 の五角形の要件はこれに合わせて外す。

## オーナーが決めていない点（判断待ち）

- **火種を灯せる場所**: (a) メニューからいつでも、(b) 観音堂などのスポットで。モックで両方を触れる。評価と推奨は `levelup-ux/REPORT.md` 11章（推奨は a を基本に、観音堂は修行の手がかりや節目の場面として使う）。

## 詳細設計で詰めること（第二弾の着手前）

- 各盤の道の数と形、どの道の先にどのスキル・修行を置くか（盤ごとに変えてよい）。つながりを条件にしたので、スキルの手前には能力の +1 がいくつか挟まる（モックの第4輪のスキルは、はじまりから4つ先）。SPEC 2.4「スキルを取ると能力が遅れる」の重さは、「どの方向から攻めるか」の選択に変わる。8章の計測と 1.6 の到達表で、1周目の埋まりと第1章の勝率を確かめ直す。
- 修行の中身（誰の・何を・どの盤の・何章で）と、交流の条件（好感度の段など）。ヒントの文。ADDENDUM-0042 のキャラの火種・色ロックとの関係。
- SPEC 2.1〜2.6・6.2・11.3（手順4のお手本）・ADDENDUM-0044 の書き換え。
- 一枚絵（能力ごと・スキル14・修行・極み）の素材（`levelup-ux/REPORT.md` 7章）。
