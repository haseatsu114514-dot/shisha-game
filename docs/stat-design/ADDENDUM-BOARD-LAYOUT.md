## ライバルは3タイプ（才・感・理。能力と同じ名前）

※ 才能・感覚・理論の定義に合わせて組み直した案。

各章のライバルが1人ずつ3タイプにそろうよう分けた（案。人物の設定は変えず、札だけ付ける）。

| 章 | 才タイプ（体力・カリスマ・社交性） | 感タイプ（直感） | 理タイプ（知恵・身につけた理論） |
|---|---|---|---|
| 第1章 | みんと（客の心理と魅せ方で人を惹きつける） | アダム（ダブルアップル一筋の職人の勘） | なる（菓子の味から組み立てる理論派） |
| 第2章 | 零（V系の店のカリスマ） | アゲハ（理論ぬきのバイブスと直感） | 組長（無臭の世界で葉の香りを引き出す、スジ＝道理を通す） |

- 大会でタイプが何に効くか（例: 相手のタイプで審査の重みが変わる、三すくみ）は未定。今は「ライバル紹介と札で、相手の持ち味が分かる」までを要件にする。


- **盤は能力ごとに分ける**: 才能盤・感覚盤・理論盤の3枚（能力を3つにしたため。上の表）。画面全体に1枚の大きな盤は作らない。上の札（盤の名前・段・進み具合の線）か左右の切り替えで入れ替える。今取れるノードがある盤の札には印を出す。
- **盤の形は、如くシリーズの能力盤（北斗が如くの秘孔盤）のように**: 真ん中に盤の大きな紋（才・感・理。ここが「はじまり」）。マスは方眼（9×7）に並ぶが、**隣どうしを全部はつながない**。紋から上下左右に4本の道が出て、曲がり・枝分かれしながら行き止まりの要所へ向かう。隣にあっても線のないマスは別の道（秘孔盤のように離れている）。形は点対称（半分を設計して180度回す）。計34マス。
- **特別なマスは8か所**: 道の行き止まり（要所）に、修行・スキル6・極みを置く（龍が如くの盤で、技や奥義が道の先に並ぶ形）。近い所から 修行・第1輪のスキル…、いちばん奥の隅が極み。ほかの26マスは能力のマス。
- **取れるのは、線でつながった隣が灯っている（か、紋の隣の）マスだけ**（SPEC 2.2 の「経路でつながなくてよい（玉方式）」を置き換える）。どの方向から攻めてもよい。
- **遠いほど後の章**: 紋から道を何マス歩くかで、能力のマスの章が決まる。特別なマスは、それぞれの輪（章）で鍵が開く。
- **方向ごとに先にあるものを変える**（スキル・修行・極みを、輪ごとに左・上・右・下へ振り分ける）。
- **火種の細かさ**（「細かすぎる」を受けて戻した）: レベルアップ1回で火種2（節目は限定の火種がさらに2、各章の大会の限定の火種も2）。能力のマスは火種1で、**3つで1段**。スキルは火種4／6／6／8（SPEC の 2／3／3／4 の2倍）。盤1枚＝能力27（極みを含む）＋スキル6＋修行1＝34マス。中央の遊び方の1周目で盤の約8割が埋まる見込み（SPEC の7〜8割とそろう。第二弾で計測し直す）。
- 段＝その盤で灯した能力のマス÷3＋1（SPEC 3.1 の段の効き方は変えない）。SPEC 2.2 の条件3「その色の次の段」は外す。
- 2色のスキル（空気を読む・火の番）は両方の盤に出し、どちらの盤から届いても取れる。取れば両方で解放済み。
- **右に大きなパネル**: 選んだノードの一枚絵・名前・効果・コスト・状態・何で払うか。**スキルは、その技を発動している場面のイラスト**。能力の段は、その能力を発揮している場面のイラスト。まだ取れないノードも絵と名前は見せる（「次はあれが欲しい」を生むため）。
- **目標（欲しいものへの道しるべ）**: ノードを目標にすると、そこまでの道を盤の上に金の点線で出し、「火の番まで 火種12」と残りを盤とHUDに出す。届いたら目標は外れる。
- **修行のマスは錠つき**: 最初から盤に見えているが、錠がかかっている。**開く条件は「その相手の好感度が決まった♥」かつ「盤の道が修行のマスの手前まで届いている」**。錠のあいだはヒントと好感度の進み具合（♥2/5 など）、道が届いているかを出す。**修行は火種いらず**（指示14）: 錠が開いて、盤の道が届いていれば、そのまま灯せる（ADDENDUM-0035 の「火種＝コスト」の第一候補は採らない）。

  - **2周目以降**: 関係は毎周やり直すので、**前の周で取っていない修行は、また好感度を上げないと開かない**。取った修行は盤と一緒に引き継ぐ。

## 火種を灯す場所: 観音堂（指示14で決定）

- **火種を灯せるのは観音堂だけ**。プレイヤーが選ぶ設定にはしない。メニューの盤は **見るだけ**（目標は決められる。道しるべとHUDの「火の番まで 火種N」はいつでも見える）。
- 観音堂で手を合わせると盤が開き、火種を灯す（「学んだことが火になる」）。
- 詳細設計で決めること（REPORT 11・22章の評価から）: 観音堂で灯すのに1行動を使うか（使わない＝買い物と同じ扱い、が推奨）。大会前夜に上がった火種を大会までに灯せるようにするか（前夜の夜に観音堂へ行ける、または大会の朝に観音堂へ寄れる）。

## 詳細設計で詰めること（第二弾の着手前）

- 1マス（段の1/3）にも効き目を持たせるか。今の SPEC は段ごとに効くので、3つ灯すまで効き目が変わらない。連続的な効き目（理論のゲージ・感覚の帯など）は1マスごとに少しずつ効かせることもできる（上限・下限は SPEC のまま）。
- NG+ の P＝min(45, 周回開始時の獲得玉)/45 は、能力のマスの合計（3盤で81）と火種の数にそろえる。

- 各盤の道の数と形、どの道の先にどのスキル・修行を置くか（盤ごとに変えてよい）。つながりを条件にしたので、スキルの手前には能力の +1 がいくつか挟まる（モックの第4輪のスキルは、はじまりから4つ先）。SPEC 2.4「スキルを取ると能力が遅れる」の重さは、「どの方向から攻めるか」の選択に変わる。8章の計測と 1.6 の到達表で、1周目の埋まりと第1章の勝率を確かめ直す。
- 修行の中身（誰の・何を・どの盤の・何章で）と、交流の条件（好感度の段など）。ヒントの文。ADDENDUM-0042 のキャラの火種・色ロックとの関係。
- SPEC 2.1〜2.6・6.2・11.3（手順4のお手本）・ADDENDUM-0044 の書き換え。
- 一枚絵（能力ごと・スキル14・修行・極み）の素材（`levelup-ux/REPORT.md` 7章）。
