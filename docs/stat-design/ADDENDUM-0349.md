# ADDENDUM-0349: ミニゲーム・活動を「極める」と火種がもらえる（2026-10-30 03:49 オーナー追加指示）

> 2026-10-30 注記: 要件はそのまま有効。火種の量が第2版で変わった（レベルアップ1回で2）ので、極めた時の付与量は第2版の量に合わせて詳細設計で決める。

## 要件
- TRPG・斧投げ・DJ など、作中のミニゲームや活動を **極める（上達の到達点に達する）と、火種がもらえる** ようにする。
- 火種の入手経路はレベルアップだけにしない。いろんなことをやって極めることが、そのまま盤の解放に繋がる形にする（SPEC の「いろんな人と絡む・いろんなことをするほど貯まる」方針と同方向）。

## 詳細設計は第二弾の着手前に詰める点
- 「極めた」の定義（各ミニゲームごとの到達条件: ランク到達、記録更新、特定課題の達成 等）。
- 付与量とバランス（レベルアップ由来の火種との比率、盤の埋まり目安「1周目で7〜8割」との整合）。
- 繰り返しで稼げない形にする（初回到達時のみ、段階ごとの1回限り 等）／周回（NG+）での扱い。
- 対象の範囲（TRPG・斧投げ・DJ 以外のミニゲーム・スポット活動をどこまで含めるか）。

## 位置づけ
- 第二弾（盤・火種・レベル本体）の要件。第一弾（見せ方＋計測）の範囲には含めない。


## #2455 採用したバランス（2026-11-11 オーナー「それでバランス調整を実装して」）

連続成功・全ゲーム制覇は要求しない。失敗しても途中経過を失わず、既存の色火報酬に加え、以下の認定で万能の白火を各1つ。6種で計6（ラクダは既存分なので今回の純増は5）。198上限は維持し、認定・称号と実際の火種付与を分ける。最高記録・上級称号にさらなる火種は付けない。

| 遊び | 達人・認定の線 | 残す上級目標 |
|---|---|---|
| 斧投げ | 10投でSを1回、またはA以上を累計3回。部門不問。3投練習は対象外 | 高得点・部門別記録 |
| DJ | 異なる2セットでA以上。SYNC使用可 | S・全セットの記録 |
| ラクダ | 標準で3位以内、声かけ20点以上、スタミナ20点以上、連打1回以内 | 上級1位・85点以上・連打0の称号 |
| サンドボード | ヌールに1勝、またはA以上を累計3回。追加トリック条件なし | なるへの勝利・S |
| TRPG | 異なる2冊で見立てと提案の両方を達成。サイコロの出目は問わない | 既存の★3色火報酬 |
| てつこ | お世話4段階を経て、思い出3種類。基本のふれあいだけでも可 | 思い出帳の収集 |

`growth.playMastery` に途中経過・認定・称号の根拠を保存し、`growth.rewards` で受取を管理する。保存／読込とNG+で両方を継承。旧セーブは既存のS、異なるDJセット、TRPG★3、ラクダ認定、砂丘勝利、てつこの思い出など証明できる実績を取り込む。過去の総プレイ数からAの回数を推測しない（旧Aベストなら1回）。初回の新しい結果を二重に数えない。

結果の確定時に進捗・認定を知らせ、火種は既存の精算経路で一度だけ受け取る。上限時は認定を残し、火種+1を偽表示しない。第5章東京のてつこにもふれあい画面を接続し、章3で取り逃しても達成できる。

### ミニゲームが苦手でも盤を完成できる経路

第5章の決戦日をまだ決めていない日常では、実際に消費した昼・夜の行動を各1回、章倍率適用後180XP以上に底上げする。初回交流などの既存加算は残す。同じ枠の再通知・無料の滑り直し・中断には追加の底上げをしない。通常の仕事・交流・休息で育ち、恋愛・くじ・ミニゲームを必須にしない。第1〜4章・大会日程を決めた後の曲線は変更しない。

本番関数を使った合成状態（Lv57、初回報酬取得済み、同じ行動を繰返し）で、140→198は80行動／40日、155→198は60行動／30日。これは実プレイ所要時間・初見達成率の測定ではない。提案した追加2〜4時間は人間の通しプレイで要確認。検査は `remake/test/play_mastery.mjs`。
