# ADDENDUM-0349: ミニゲーム・活動を「極める」と火種がもらえる（2026-10-30 03:49 オーナー追加指示）

> 2026-10-30 注記: 要件はそのまま有効。火種の量が第2版で変わった（レベルアップ1回で2）ので、極めた時の付与量は第2版の量に合わせて詳細設計で決める。

## 要件
- TRPG・斧投げ・DJ など、作中のミニゲームや活動を **極める（上達の到達点に達する）と、火種がもらえる** ようにする。
- 火種の入手経路はレベルアップだけにしない。いろんなことをやって極めることが、そのまま盤の解放に繋がる形にする（SPEC の「いろんな人と絡む・いろんなことをするほど貯まる」方針と同方向）。

## 詳細設計は第二弾の着手前に詰める点
- 「極めた」の定義（各ミニゲームごとの到達条件: ランク到達、記録更新、特定課題の達成 等）。
- 付与量とバランス（レベルアップ由来の火種との比率、盤の埋まり目安「1周目で7〜8割」との整合）。
- 繰り返しで稼げない形にする（初回到達時のみ、段階ごとの1回限り 等）／周回（NG+）での扱い。
- 対象の範囲（TRPG・斧投げ・DJ 以外のミニゲーム・スポット活動をどこまで含めるか）。

## 位置づけ
- 第二弾（盤・火種・レベル本体）の要件。第一弾（見せ方＋計測）の範囲には含めない。
