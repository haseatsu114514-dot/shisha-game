## 0. 全体像と用語

### 0.1 一文で

行動・会話・スポットでの体験・制作・大会で **経験値** が貯まり、寝る前にレベルが上がると **火種** をもらう。火種は観音堂などの参拝の場所で **内省** すると灯せる。能力ごとの **心得の盤**（才能盤・感覚盤・理論盤）で、真ん中の紋から道をたどってマスに火を灯すと、能力が少しずつ伸び、道の先のスキルや、仲良くなった人に教わる **授業** に届く。

### 0.2 用語

### 1.3 新鮮さ（張り付きより広く関わる方が得になる仕掛け）

- **鍵**: X1 の行動を次の単位で数える。相手のいる行動は **相手のキャラID**（店に行って話す、誘い、デート、一服）。相手のいない行動は **スポットID**（観音堂・喫茶こはく・チョイザップ・斧Bar・シネマ・C.STATION・東京の施設）か **行動の種類**（バイト `tonari_shift`、まかないで練習 `tonari_practice`）。バイトでスミと話すのはバイトの鍵1つ（相手の鍵と二重に数えない）。
- **数える範囲**: 章ごとにリセット。
- **係数**: その章でその鍵の **1・2回目 ×1.0、3回目 ×0.8、4回目 ×0.6、5回目以降 ×0.4**。
- 2回目まで満額にする理由: 「ある人の話の続きを聞きに行く」「気に入った場所にもう一度行く」のは自然で、2回で減らすと関係を深める行動を罰してしまう。3回目以降を減らすのは「同じ所だけに通う」を不利にするため。
- 下限0.4: 張り付きを罰ではなく「少し損」にとどめる。好きなキャラに通うのは恋愛・好感度の面で報われるので、経験値で追い打ちしない。

### 1.5 レベル曲線と火種の数

- **Lv L → L+1 に必要な経験値 ＝ 200 ＋ 5×L**。上限 Lv.80（第1版のまま）。
- **レベルアップ1回で火種2つ（万能）**。
- **節目のレベル（Lv.10・20・…・70）では、さらに色つきの火種2つ**（直前の10レベルで一番火種を灯した盤の色。同数なら段の低い盤）。
- **各章の大会で色つきの火種2つ**（その大会で一番点の良かった工程の色: 提供後の調整＝才、炭焼き・蒸らし＝感、穴あけ・完成品＝理）。
- **好感度が♥5（最大）になった人から、その人のタイプの色の火種2つ**（2.7）。
- 盤が全部埋まった後は火種は増えない（「盤は埋まった」）。

### 1.7 経験値の入り方と精算のタイミング

- 経験値は行動の確定時に **その場で累計に入る**（セーブにも即時に残る）。通知は小さな「EXP +30」チップ（6.3）。
- **レベルアップの演出と火種の付与は、その日の終わり、寝る前（夜明けの演出の前。#1690）にまとめて行う**。日中に閾値を越えても、火種はまだ増えない（`growth.pendingLevels` に積む）。会話や制作の途中でレベルアップが割り込まないため（DESIGN 4.4）。
- 章の締めくくりでは、X8〜X11 を入れたあと、章クリア画面の前に精算する（その章の振り返りとして見せる）。
- 大会前夜も寝る前に精算する。火種が残っていれば内省の強制の場面（2.8）。大会の経験値は章の締めくくりで精算する。

### 1.8 パッキースロット: 経験値のブースト「追い風」（オーナー指示 23:48）

**形**: 当たりの役に応じて、**次の自由行動から数えて N 回分**、日々の学びの経験値に倍率が掛かる。時間（日数）ではなく **行動の回数** で数える（スロットは行動ごとに回るので、同じ物差しにそろえる。寝て起きたら消える、のような取りこぼしも無い）。

| 役 | 倍率 | 続く回数 | 見せ方 |
|---|---|---|---|
| ハズレ／リプレイ | — | — | 無通知（今と同じ） |
| チェリー | ×1.25 | 1回 | 「追い風 ×1.25・あと1回」 |
| ベル | ×1.25 | 2回 | 「追い風 ×1.25・あと2回」 |
| REG | ×1.5 | 3回 | 「追い風 ×1.5・あと3回」 |
| BIG／プレミア | ×1.5 | 5回 | 「追い風 ×1.5・あと5回」 |
| フリーズ | ×2.0 | 5回 | 「大追い風 ×2・あと5回」 |

- **掛かる範囲**: X1〜X7（自由行動・はじめて・好感度の段・固有会話・スポットの場面・発見）。**X8〜X11（大会・章クリア・広さボーナス）には掛けない**（1回の大きな額に倍率を掛けると、当たりのタイミングだけで1レベル以上ぶれるため）。
- **重ねがけ**: 追い風は1本だけ持つ。新しい当たりが来たら、**倍率は高い方、残り回数は足す**。**上限は ×2.0・10回**。例: ×1.5 あと2回 の時に BIG → ×1.5 あと7回。フリーズ → ×2.0 あと7回。
- **使い方の順番**: 行動の経験値を確定するとき（`paidAction` の確定部）に倍率を掛け、残り回数を1減らす。その行動のあとに回るスロットの当たりは、**次の行動から** 効く（その行動の結果はもう確定しているため）。
- **期限**: 章をまたいでも残る。周回開始で消える。体力を使わない行動（休養・買い物・LIME）は回数を減らさない。
- **量**: 1章30回転・ペカ合算 約1/9.4（設定3）で、ボーナス約3回＋小役。倍率の上乗せを「(倍率−1)×回数」で数えると1章あたり約7.3回分。中央の遊び方（1行動あたりの日々の学び 約72）で **約+526**、章の経験値の約20%（1.4）。設定1〜6の差（`pakki_slot_spec.md` 設定表で能力P 91.5〜101.9、±5%）はそのまま追い風の差になる。
- **総量の前提との関係**: 追い風込みの量で 1.5 の曲線を合わせてあるので、「1周目で盤の7〜8割」の前提を超えない。追い風が最大（毎章フリーズ級の大当たり）でも、1章の上振れは +600 程度（中央の約1.5レベル分）にとどまり、1周目クリア時の埋まりは中央で約80%まで。追い風の量は 8.3 の成長モデルで確認し、外れたら倍率表を一律に縮める（8.4）。
- **実装**: `growth.boost = { mult: 1, left: 0 }`。`commitSpinSeries` で役から上の表を引いて合成する。`r.exp`（役の旧ポイント）は記録用に残し、能力にも経験値にも足さない。`pickTarget`・`statBuffer`（`stat-raw` の購読）は削除。結果は今どおり行動時に seed から確定し、演出は後追い（ロードで変わらない）。


### 1.9 色つきの火種

- 色は3つ（才・感・理）。**その色の盤の能力のマスとスキルにだけ使える**。万能の火種より先に使う（盤の下の「万能を使う」で切り替え可）。
- 出どころ: 節目のレベル・各章の大会・♥5の人（1.5）。
- 受け取った時点で、その盤の未解放のマスが無ければ万能の火種として渡す。持っている間に埋まれば万能に変わる（第1版のまま）。
- 組み直しでは、払った種類のまま戻す（`growth.paid`）。

## 2. 心得の盤

### 2.1 盤は能力ごとに3枚

- 才能盤・感覚盤・理論盤を、上の札（能力名・段・進み具合の線・今取れるマスの印）で入れ替える。画面全体で1枚の盤にはしない。

### 2.2 形: 秘孔盤のように道でつながる

- 9×7 の方眼に36マス（要所10か所）。真ん中に盤の大きな紋（才・感・理。ここが「はじまり」）。
- 紋から上下左右に4本の道が出て、直角に曲がり・枝分かれしながら、行き止まりの **要所**（10か所）へ向かう。線は上下左右の隣だけ（斜めは無し）。**隣にあっても線のないマスは別の道**。形は点対称。
- 要所には、近い順に 第1章のスキル → 授業 → 第2章以降のスキル、いちばん奥に **極み**（その盤の最後の能力のマス）。使わない要所は盤に出さない。
- 型の座標はモック `levelup-ux/mock/index.html` の `LAYOUT`（半分の道を設計して180度回す）。

### 2.3 取れる条件

1. **線でつながった隣が灯っている**（か、紋の隣）。
2. その章の範囲に入っている（紋から道を何マス歩くかで章が決まる。遠いほど後の章）。
3. 火種が足りる（授業は火種いらず）。
4. 授業は、その盤が3段以上で、相手の好感度が♥5（スミさんは条件なし）（2.6）。

第1版の「経路は見ない」「能力は次の段だけ」は廃止。能力の段は **灯した能力のマスの数** で決まる（3つで1段）ので、どの道の能力のマスでも同じだけ伸びる。

### 2.4 方向の選び方

- どの方向から攻めてもよい。道ごとに先にあるスキル・授業・極みが違うので、「どれが欲しいか」で方向を選ぶ。
- **目標**: マスを目標にすると、そこまでの一番安い道（灯した所は0、未解放はその火種）を金の点線で出し、盤と HUD に「火の番まで 火種6」と残りを出す。「目標まで灯す」で、火種と章の範囲が許すところまでまとめて仮置き。

- タイプ（才・感・理）は、**その人が♥5でくれる色つきの火種の色だけ** を決める。その人の特別な授業も同じ色の盤に置く。大会の採点には使わない。

  earned: 0,                 // 受け取った火種の総数（NG+ の P）

## 5. 組み直しと周回

### 5.1 盤への適用: 「解放のリセット」として定義する

- **組み直す** ＝ HUB 以外の解放済みノード（能力・スキルとも）をすべて未解放に戻し、**使った火種を全部返す**（オーナー指示 23:46「振り直しでは使った火種が戻り、盤の解放をやり直せる」）。返す火種は払った時の種類のまま（`growth.paid`。限定の火種で払った分は限定の火種に戻る）。レベル・経験値・輪の開き具合・追い風は変わらない。
- 部分的な戻し（1つだけ外す）は作らない。理由: 能力の段は下から順に積むので、途中の段だけ外すと「段の順」の条件（2.2）が崩れる。全部戻して考え直す方が、大会前の決断として分かりやすい。
- 組み直しの画面では、戻した直後に **「前の形に戻す」** ボタンを置く（組み直しをやめて元に戻す。確定前の取り消し）。
- 対象は「自分で振った分」（オーナー決定）。案A では行動で伸びる分が無いので、盤のノードは **すべて** 対象。移行で置いたノード（4.5）も対象に含める（自分で選んだ結果ではないので、組み直せる方が救済になる）。
- 費用: 無料。回数: 開いている間は何度でも。

### 5.2 いつ開くか

| 機会 | 開く時点 | 閉じる時点 |
|---|---|---|
| **章はじめ**（第2〜5章） | `state.chapter` が上がり、新しい章の日常に最初に入った時（章タイトルと冒頭の強制イベントの後） | その章で最初の自由行動（`paidAction` が経験値を確定した時）の直前、または日付が変わった時の早い方 |
| **周回開始** | `startNextCycle`（`core/cycle-start.js`）で新しい周回が始まり、第1章の日常に最初に入った時 | 同上 |
| **移行直後**（1回だけ） | SCHEMA 23 への移行後、最初に日常に入った時 | 同上 |

- 第1章の1周目は、組み直すものが無いので開かない。
- 「章はじめ」を「最初の自由行動まで」にした理由: 章の冒頭は強制イベントが続くことがあり、日付の初日だけにすると開ける時間が実質無い章が出る。逆に、行動を1つでもしたら閉じることで、大会に向けた振り方を「章の頭で決める」ものにし、ミニゲームごとの付け替えを防ぐ（DESIGN 案A の理由をそのまま採る）。
- 開いている間、マップの上部に「組み直しは最初の行動まで」の細い帯を出す（6.2）。閉じる直前（行動の確認ダイアログ）に「この行動をすると、この章の組み直しは閉じます」を一度だけ添える。章はじめの短い再案内は 11.4。
- 閉じた後に新しく得た火種は、通常どおり盤で使える（新しく解放するのは振り直しではない）。

### 5.3 周回開始時の引き継ぎ

- 能力の引き継ぎ（`carryOptions.groups.stats`、今は既定で引き継ぐ。`core/cycle-start.js` `startNextCycle`）を選んだ場合: `growth` を丸ごと引き継ぐ（レベル・経験値・火種・解放済みノード・`ringsOpen`）。周回で消えるもの（`fresh`・`firsts`・`read`・`chapterLog`・`tournamentXp`・`boost`）は空に戻す（関係と物語は毎周やり直すため。DESIGN 2.3）。
- 引き継がない場合: `growth` は Lv.1・HUB だけ。
- 周回開始の組み直しを開く（5.2）。
- `cycleStartPoints = growth.earned`（4.4）。`cycleStartStats` は今どおり組み直し **前** の能力を記録する（表示・旧式の互換用）。


### 5.4 引き継いだ周回での範囲

- 能力を引き継いだ周回では、前の周回で開いていた章の範囲をそのまま開いておく（第1版 5.4 のまま）。
- 授業: 取った授業は引き継ぐ。取っていない授業は錠に戻り、その周回でまた♥を上げると開く。♥5でもらう色つきの火種（`gifted`）も周回ごとにもらい直せる。

## 11. チュートリアル

- 始まり: 初めてのレベルアップの夜（第1版 11.2 のとおり）。
- 流れ（実際に操作して覚える）:
  1. 寝る前の振り返り: 「今日学んだことが、形になった。火種を2つ手に入れた」。
  2. 「火種は、静かな場所で振り返ると灯せる。観音堂へ行ってみよう」（地図の観音堂に矢印。時間は使わない）。
  3. 観音堂の内省の場面 → 盤が開く。「盤は能力ごとに3枚。真ん中の紋から道がつながっている」（札と紋に枠）。
  4. 「光っているマスが次に取れる。3つ灯すと1段上がる」。好きなマスを選ばせる（誘導しない）。
  5. 決定 → 「このマスで：ジャスト帯がわずかに広がる」と、作り画面の色付けのお手本（#1691 の推奨: 1段と、その章で届く段を並べる）。
  6. 「盤はメニューからいつでも見られる。灯すのは観音堂で。欲しいスキルは目標にしておこう」。
- 案内文は文字の部分でタップを素通りさせ、操作を塞がない（#1692）。
- 再案内: 章はじめ（新しい範囲・新しいスキル・組み直し）、初めての授業の錠、初めての♥5の色つきの火種、東京・ドバイで初めての参拝の場所。
