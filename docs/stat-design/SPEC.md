## 0. 全体像と用語

### 0.1 一文で

行動・会話・スポットでの体験・制作・大会で **経験値** が貯まり、寝る前にレベルが上がると **火種** をもらう。火種は観音堂などの参拝の場所で **内省** すると灯せる。能力ごとの **心得の盤**（才能盤・感覚盤・理論盤）で、真ん中の紋から道をたどってマスに火を灯すと、能力が少しずつ伸び、道の先のスキルや、仲良くなった人に教わる **授業** に届く。

## 1. 経験値・レベル・火種

### 恋人EXPの先行公開（2026-10-30 オーナー承認）

恋人の節目（6人×Lv1〜5）とひよりの専用恋人場面は、通常プレイでも初読時にX5の20 EXP×章倍率を貯め、「EXP +獲得量（累計）」を通知する。能力値へ直接加算しない。既存の `growth.xp` を使い、取消・別セーブ・再読・既読の旧セーブへ再付与しない。能力のNG+引継ぎを選ぶと累計と精算済みの状態を保持し、恋人場面の初読記録は周回で戻す。

これは経験値の保存と獲得表示だけの先行公開。`GROWTH_BOARD=false`、盤・火種・レベルアップの非公開は維持し、公開まで貯めた経験値は使えない。他の経験値源の公開条件は変えない。開発previewのON/OFFで累計を移し替えたり、再付与・精算したりしない。

### 1.3 新鮮さ（張り付きより広く関わる方が得になる仕掛け）

- **鍵**: X1 の行動を次の単位で数える。相手のいる行動は **相手のキャラID**（店に行って話す、誘い、デート、一服）。相手のいない行動は **スポットID**（観音堂・喫茶こはく・チョイザップ・斧Bar・シネマ・C.STATION・東京の施設）か **行動の種類**（バイト `tonari_shift`、まかないで練習 `tonari_practice`）。バイトでスミと話すのはバイトの鍵1つ（相手の鍵と二重に数えない）。
- **数える範囲**: 章ごとにリセット。
- **係数**: その章でその鍵の **1・2回目 ×1.0、3回目 ×0.8、4回目 ×0.6、5回目以降 ×0.4**。
- 2回目まで満額にする理由: 「ある人の話の続きを聞きに行く」「気に入った場所にもう一度行く」のは自然で、2回で減らすと関係を深める行動を罰してしまう。3回目以降を減らすのは「同じ所だけに通う」を不利にするため。
- 下限0.4: 張り付きを罰ではなく「少し損」にとどめる。好きなキャラに通うのは恋愛・好感度の面で報われるので、経験値で追い打ちしない。

### 1.5 レベル曲線と火種の数

- **Lv L → L+1 に必要な経験値 ＝ 200 ＋ 5×L**。上限 **Lv.99**（2026-10-30 オーナー指示で80から引き上げ。1.6a）。
- **レベルアップ1回で万能の火種2つ**（2026-10-30 オーナー「いろんな盤をあけてく爽快感も欲しい」→「1レベル2つ・盤を細かく」SBD60。SBD58 の1つを置き換え）。
- **節目のレベル（Lv.10・20・…・90）では、さらに色つきの火種2つ**（直前の10レベルで一番火種を灯した盤の色。同数なら段の低い盤）。
- **各章の大会で色つきの火種2つ**（その大会で一番点の良かった工程の色: 提供後の調整＝才、炭焼き・蒸らし＝感、穴あけ・完成品＝理）。
- **好感度が♥5（最大）になった人から、その人のタイプの色の火種2つ**（2.7）。
- **遊びのご褒美**（2026-10-30 オーナー指示）: 斧投げ（才）・TRPG（理）・DJ（感）をやり込んで水準に届くと、色つきの火種を **1つ**（一度だけ）。斧投げ＝自己ベストで Aランク、TRPG＝★3の卓、DJ＝Aランク（DJ は本編に入ったら接続）。量は小さく保つ（オーナー: 「あげすぎ。♥5まで上げてやっと色の火種がもらえるぐらい」「ミニゲームをやりたくない人もいる」）。遊ばなくても盤の進みはほとんど変わらない。
- **くじのラストワン賞**（中身はシークレット）: 箱を引き切るたびに、景品に加えて色つきの火種1つ（いちばん伸びの少ない盤の色）。
- ♥5・遊びのご褒美・ラストワン賞は、寝る前のレベルアップでまとめて知らせる（レベルが上がらない夜は短い帯）。データは `core/growth-board-data.js` の `PLAY_REWARDS`。
- 盤が全部埋まった後は火種は増えない（「盤は埋まった」）。

### 1.6a 全開放の目安（2026-10-30 オーナー指示・SBD51・SBD54・SBD58・SBD60）

オーナー: 「2周目最終ぐらいで99いって全開放」「1周目で7割開けたい。7割というのは3つの盤全てが7割行けること」「バランスをとって。いろんな盤をあけてく爽快感も欲しい」→「1レベル2つ・盤を細かく」。

- レベルの火種は2つ。曲線は変えない（中央は1周目 Lv.57、2周目の終わり Lv.90前後）。
- 盤は **3つとも同じ大きさの66**（能力のマス26・関門4・スキル6つで火種36）、合計 **198**。第1章で開く範囲もどの盤も17（v9。能力のマス9・スキル2つ）。どの盤から攻めても、1段の重さ・スキルの数と値段・第1章で使える量が同じ。

### 1.9 色つきの火種

- 色は3つ（才・感・理）。**その色の盤の能力のマスとスキル、そして関門に使える**。
- **払う順（2026-10-30 #1801 引継ぎ B）**: 能力のマス・スキルは **万能を先に** 使い、足りない分だけその盤の色を使う。ただし **まだ越えていない関門の数ぶんの色は残す**（普通のマスに色を使い切って関門で詰まらないように）。受け取りが上限（198）に届いてもう火種が来ない時は、関門を万能でも越えられ、普通のマスもほかの盤の色で払える（総量は増やさない）。どんな順で灯しても、受け取った198で全部灯せる（`growth_board.mjs` で乱順30回を検査）。
- 「盤は埋まった」は、受け取りの上限ではなく **全部のマスを灯した時** に出す。
- **色の台座（もとの関門。2026-10-31 オーナー「章のロックに加えて、色の火種しか使えない所も作って欲しい。色火種をはめると進めて、その能力もゲットできる」SBD89）**: 色の火を1つはめると先へ進めて、台座の能力が手に入る。各盤の4つの台座に、その盤の4つの能力を1つずつ（才能＝人柄・眠り・体力・華、感覚＝吸い・かわし・火加減・呼吸、理論＝炭の持ち・段取り・葉・舌）。強さは台座1つで台座の先のマスの×4/3（`GATE_TIER` ×4）。盤では、ひし形の台座にその盤の色の火（紅火・蒼火・翠火）の絵がはまり、**はめる前からその色で光る**（台座のまわりに色の光の輪。SBD90「この色しかはまらないと分かるよう」）。はめられる時は火が脈打ち、はめると満ちて輪が強くなる。画面の言葉は「関門」でなく「色の台座」「はめる」。
- **関門（v3）は色つきの火種1でだけ越える**（万能では越えられない）。その盤の色を先に使い、無ければほかの色でもよい（色が偏って詰まらないように）。オーナー: 「基本的には白の万能玉はガンガン使ってあげていく。たまに色の玉を使って突破と解放して広げていく」。
- 出どころ: 節目のレベル・各章の大会・♥5の人（1.5）。
- 受け取った時点で、その盤の未解放のマスが無ければ万能の火種として渡す。持っている間に埋まれば万能に変わる（第1版のまま）。
- 組み直しでは、払った種類のまま戻す（`growth.paid`）。

### 4.5 セーブ互換（加算では保存の形を変えない）

現在の形の抜粋。全フィールドの正本は `core/growth.js` の `newGrowth()`。加算方式では旧能力の既存キーを保持する。経験値の発見記録 `discoveries: { recipes: [], golden: [] }` は任意の追加キーで、旧セーブで欠けていれば空から始める。新レシピは既存の `recipes` 登録の瞬間に判定するため、旧セーブの既知レシピを読み直しても新発見の経験値は付かない。黄金比は有効化後の最初の一致から数える。両記録は周回でリセットし、能力と累計経験値は減らさない。

固有場面は `read`（開始台本ID）へ記録する。VN の `growthScene` が付いた全編の正常完読だけを自由行動へ預け、行動確定時に X5/X5s を付与する。取消・部分再生・無料会話・強制イベント・別セーブからの完了では記録しない。専用の恋人場面報酬と重ねない。`chapterLog` は章ごとの人・場所の重複なし一覧、`tournamentXp` は参加・最高順位の基礎報酬・色の火種済み、`cleared` は X10/X11 精算済みの章。いずれも任意キーで、NG+で空に戻す。大会の再挑戦による資源の巻き戻しには含めない。

```js
growth: {
  level: 1, xp: 0, settledXp: 0,
  hidane: { any: 0, body: 0, sense: 0, wisdom: 0 },
  earned: 0,
  nodes: [], paid: {},          // 確定IDと実際に払った内訳
  ringsOpen: 1, target: null,
  learned: [],                  // 相談を完読した授業
  gifted: {}, rewards: {}, milestones: [],
  boardVersion: 13              // 盤の型の版。旧型は既定の火種返却を行う
  // このほか、その日の経験値・新鮮さ・初回の記録など
}
```

- **2026-11-01 オーナー決定が優先**: `stats` の旧5能力は既存の強さの基礎として保持し、盤の確定マスの恩恵を計算時に加算する。旧能力を3キーへ縮約したり、能力値に相当する無料マスを追加したりしない。既存の盤マスと支払記録は保持する（盤の型が変わった時の既定の返却処理は維持）。この加算では保存データの形を変えない。
- 授業の錠は `growth` に持たない（未点灯の授業は好感度と道から毎回判定）。授業を灯すと `nodes` に確定IDと `paid` に支払記録（授業は火種不要なので空の内訳）が入り、相談未完でも保持する。相談を完読して習得すると `learned` にもIDが入る。`nodes` にあるだけでは習得済みとは扱わず、次周の未習得授業の相談条件は5.4に従う。

**詰め方の互換（schema25）**: K18 は新規の盤モードでデンスパックを解放する。schema24以前の保存には `_dense_pack_legacy` を付け、既存の選択肢を保持する。公開前の旧モードで詰め方を見たschema25の保存も同じ許可を持ち、周回へ引き継ぐ。能力や経験値はこの移行で変えない。

**旧セーブ互換（2026-11-01）**: 旧5能力・体力・経験値・火種・確定ノード・支払記録をそのまま読む。例えば旧最大体力160でB1「＋2」を灯すと162、保存／再読込でも162のまま。旧5能力に対応するノードを無料で重ねて与えず、盤の恩恵も旧statsへ加算保存しない。旧フラグ `_sumi_attack_learned`・`_coal_cube_learned`・`_coal_four_unlocked`・`_coal_mix_unlocked` は従来どおり対応する習得済み授業へ読み替える。過去の味の話の不足補完は当時の基礎量だけを補い、現在の盤の熟練度倍率を遡って掛けない。

旧版に記載していた「旧段から必要マス数を計算し、能力マスを無料で灯す」移行は履歴であり、この加算方式では行わない。

## 5. 組み直しと周回

### 5.1 盤への適用: 「解放のリセット」として定義する

**現在の適用規則（2026-11-01、残件4点の本人承認）**: 授業は忘れない。`kind=lesson`の点灯・支払・相談待ち・完読記録を保持し、通常能力／スキルだけを外す（報酬がskillでも授業は保持）。`paid`にある実際の種類と量だけを返し、旧5能力・XP・レベルを書き換えない。支払不明なら推測返金しない。保持授業は効果を維持するが、HUBまで道が再接続するまではその先の有料ノードへ無料で飛び越せない。確定前の「前の形に戻す」・閉じる取消・LOADでは元の盤を保つ。章／周回の最初の実自由時間から、最初の実行動確定または日付変更まで無料で何度でも使える。第3章の強制場面中の`daily`は開始とみなさない。メニューからの閲覧中も、この機会内の組み直しと再配分はできる。旧セーブの初読だけで機会や無料ノードを付与しない。

以下の旧設計の「全ノード」「段の順」「案A／移行ノード」は履歴であり、上記の授業保持・加算方式を優先する。

- **組み直す** ＝ HUB 以外の解放済みノード（能力・スキルとも）をすべて未解放に戻し、**使った火種を全部返す**（オーナー指示 23:46「振り直しでは使った火種が戻り、盤の解放をやり直せる」）。返す火種は払った時の種類のまま（`growth.paid`。限定の火種で払った分は限定の火種に戻る）。レベル・経験値・輪の開き具合は変わらない。
- 部分的な戻し（1つだけ外す）は作らない。理由: 能力の段は下から順に積むので、途中の段だけ外すと「段の順」の条件（2.2）が崩れる。全部戻して考え直す方が、大会前の決断として分かりやすい。
- 組み直しの画面では、戻した直後に **「前の形に戻す」** ボタンを置く（組み直しをやめて元に戻す。確定前の取り消し）。
- 対象は「自分で振った分」（オーナー決定）。案A では行動で伸びる分が無いので、盤のノードは **すべて** 対象。移行で置いたノード（4.5）も対象に含める（自分で選んだ結果ではないので、組み直せる方が救済になる）。
- 費用: 無料。回数: 開いている間は何度でも。

### 5.2 いつ開くか

| 機会 | 開く時点 | 閉じる時点 |
|---|---|---|
| **章はじめ**（第2〜5章） | `state.chapter` が上がり、新しい章の日常に最初に入った時（章タイトルと冒頭の強制イベントの後） | 最初の自由行動の確定（XPの有無を問わない）、または日付が変わった時の早い方。取消では閉じない |

- 閉じた後に新しく得た火種は、通常どおり盤で使える（新しく解放するのは振り直しではない）。

### 5.3 周回開始時の引き継ぎ

- 能力の引き継ぎ（`carryOptions.groups.stats`、今は既定で引き継ぐ。`core/cycle-start.js` `startNextCycle`）を選んだ場合: `growth` を丸ごと引き継ぐ（レベル・経験値・火種・解放済みノード・`ringsOpen`）。周回で消えるもの（`fresh`・`firsts`・`read`・`chapterLog`・`tournamentXp`・`boost`）は空に戻す（関係と物語は毎周やり直すため。DESIGN 2.3）。
- 引き継がない場合: `growth` は Lv.1・HUB だけ。
- 周回開始の組み直しを開く（5.2）。
- `cycleStartPoints = growth.earned`（4.4）。`cycleStartStats` は今どおり組み直し **前** の能力を記録する（表示・旧式の互換用）。


### 5.4 引き継いだ周回での範囲

- 能力を引き継いだ周回では、前の周回で開いていた章の範囲をそのまま開いておく（第1版 5.4 のまま）。
- 授業: 相談を完読して習得した授業は、好感度を上げ直さず引き継ぐ。**点灯済み・相談未完の授業は、点灯と支払記録を残したまま、次周でまた♥5まで仲良くなると相談できる**（2026-11-01 オーナー決定）。相談候補と完読時の確定の両方で今の周の好感度を確認し、途中中断・LOAD前の完了では習得しない。好感度条件のないスミさんの授業はその条件のまま。♥5でもらう色つきの火種（`gifted`）も周回ごとにもらい直せる。

## 11. チュートリアル

- 始まり: 初めてのレベルアップの夜（第1版 11.2 のとおり）。
- 流れ（実際に操作して覚える）:
  1. 寝る前の振り返り: 「今日学んだことが、形になった。火種を2つ手に入れた」。
  2. 「火種は、静かな場所で振り返ると灯せる。観音堂へ行ってみよう」（地図の観音堂に矢印。時間は使わない）。
  3. 観音堂の内省の場面 → 盤が開く。「盤は能力ごとに3枚。真ん中の紋から道がつながっている」（札と紋に枠）。
  4. 「光っているマスが次に取れる。一つ灯すごとに、そのマスの恩恵が増える。ひし形の関門は色の火種で越える」。好きなマスを選ばせる（誘導しない）。段を上げる説明はしない（SBD63）。
  5. 決定 → 「このマスで：ジャスト帯がわずかに広がる」と、作り画面の色付けのお手本（そのマスを灯す前後を並べる）。
  6. 「盤はメニューからいつでも見られる。灯すのは観音堂で。欲しいスキルは目標にしておこう」。
- 案内文は文字の部分でタップを素通りさせ、操作を塞がない（#1692）。
- 再案内: 章はじめ（新しい範囲・新しいスキル・組み直し）、初めての授業の錠、初めての♥5の色つきの火種、東京・ドバイで初めての参拝の場所。
