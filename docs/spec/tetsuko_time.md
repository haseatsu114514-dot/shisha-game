# てつこといっしょ / TETSUKO TIME（#2454）

mukai の裏口で、看板猫のてつこと気軽に過ごすふれあい画面。**育つのは猫の姿ではなく、はじめとの距離・一緒にできること・裏口の居場所・思い出**。設計の経緯と受け入れ条件は Issue #2454（本文と 2026-11-06 の実装計画コメント）。本書は実装した決まりの正本。

## 入口と時間

- 第3章の東京で、mukai で行動を使った帰りの「裏口のてつこ」から選ぶ（`ch3-tokyo-daily.js` の `offerTetsuko`）。地図のピンや自由時間カードの入口は作らない（2026-11-04 オーナー判断）。
- 選択肢は「てつこといっしょ」（既定）／「少し構っていく」（会話だけの短い過ごし方。巡回の会話3本もここで読める）／「今日はそっとしておく」。
- 行動・日付・時間帯は進めない。制限時間・最低滞在時間・点数・ランクは無い。「帰る」はいつでも押せる。
- 第5章の東京の裏口は従来どおり「少し構っていく」だけ（未接続）。

## 関係（段階）

- 新しい数値を作らず、既存の来訪回数 `flags._ch3_outings.tetsuko` から決める: 0=まだ様子見、1=顔なじみ、2=待ってくれる、3以上=気を許す。
- 「てつこといっしょ」でも、段階の会話（初回→ブラシ→待つ→すり寄る。`ch3-outing-progress.js` の `stages`）がまだあれば先に読み、それから画面へ。旧セーブで懐いた人は最初から段階3（読み直しなし）。
- 関係は下がらない。撫ですぎても「今はもういいらしい」で手を休めるだけ。

## 回復と保存（確定点 `settleTetsukoTime`）

- 意味のあるふれあい（段階の会話を読んだ／なでる・あそぶ・ブラシ・おやつ・見守るを一度でもした）で帰ると、**体力12と来訪+1を一度だけ**。訪問キー（章:日:時間帯）で二重にしない。何もせずに帰ると付かない。
- 置いた小物・しぐさの発見・アルバム・おやつの記録・荷ほどきは、画面から戻った時に `flags._tetsuko_time` へ残す（周回では持ち越さない）。
- 能力・経験値・火種・好感度は増えない。中断・LOAD・章跨ぎでは何も確定しない。

## 通販（おやつと小物）

専門店が近くに無いので、スマホの通販で頼み、**注文した次の日に mukai へ届く**（2026-11-06 オーナー）。お金は注文の時に引き、同じ処理の中で保存する。小物は一度買えば無くならない（耐久・買い直しなし）。性能差は付けない。

| 品 | 値段 | 置ける場所 | 見える過ごし方 |
|---|---|---|---|
| 古いボール | 最初から | 床 | 目で見送る・前足でつつく |
| 段ボール箱 | 最初の荷物の箱 | ベンチ・床・寝床の角 | 中に入る・顔だけ出す・ベッドより箱 |
| 猫用のおやつ（6本入り） | 600円 | ― | 一日一本まで。届く前の注文がある間は重ねて頼めない |
| 猫用の座布団 | 1,200円 | ベンチ・寝床の角 | 上で丸くなる |
| 段ボールの爪とぎ | 800円 | 床 | 爪をとぐ |
| 猫用のトンネル | 1,800円 | 床 | しっぽだけ出す |
| 猫ベッド | 3,200円 | 寝床の角 | 中で寝る（箱があると箱へ行く） |

届いた物は空いている場所に置いておく（買った物が先、箱は最後）。置き直しは「もようがえ」で、3つの場所（ベンチ・床・寝床の角）に一つずつ。

## ふれあいと自律行動

- 気分（のんびり・眠い・遊びたい・甘えたい）は通算日で決まり、開き直しても変わらない。気分は反応の出やすさだけを変え、操作を閉じない。
- 猫じゃらしは3回揺らすと「じゃらしを止める」になり、止めると捕まえる（段階1から抱えこむ）。反射神経の勝負にしない。
- ブラシは段階1から。見守るは1回目で前足をそろえ、気を許した後は膝に乗る（しばらくすると自分で降りる）。
- 画面を開いている間、てつこは置いた物に応じて自分で過ごす（約3秒ごと、1回おきに落ち着く。直近の行動は続けない）。条件を満たした未発見のしぐさを7割で優先し、置いた直後はその物を確かめに来る。閉じている間は進めない。
- ムカイさんの一言（荷物・ベッドより箱・膝）とましろちゃんの通りがかりは短く、人の一言は初めて見た時だけ。

## しぐさ図鑑とアルバム

- 図鑑は12件で自動記録（写真を撮らなくても失わない）。未発見は緩い手がかりを出す。
- 写真は今のしぐさか表情を一枚。同じものは一枚だけ（撮り直すと差し替え）、12枚まで、消して整理できる。画像は保存せず、しぐさ・表情・日付の言葉だけを残す。

## 画像と操作

- 猫は会話と同じ立ち絵（5表情・立ち絵の設定に従う）から猫の部分だけ切り出して大きく見せる。新しい猫の絵は作らない。小物とベンチは CSS・SVG。
- ボタン・猫のタップ・押したままゆっくり動かす、のどれでも撫でられる。PC・スマホ横（DS 表示でもこの画面は通常の16:9）、動きを減らす設定、無音で遊べる。
