## 2. 保存と確定

`state.flags._tetsuko_time = { v: 1, props: { bench, floor, bed }, found: [しぐさid…], album: [{ moment, day, props }…], treatDay, sessions, lastKey }`

- 関係の段階は新しい数値を作らず、来訪記録 `_ch3_outings.tetsuko`（回数）から導く: 0〜1→0 まだ様子見／2→1 顔なじみ／3→2 待ってくれる／4以上→3 気を許す。画面の段階は、入口で読む段階会話の分を含めた「回数+1」で見る（ブラシの会話を読んだその日からブラシが使える）。旧セーブで膝・見送りまで来ている人は最初から段階3。
- `_tetsuko_time` が無い旧セーブは既定（小物なし・未発見）で入れる。SCHEMA は上げない。周回では持ち越さない（`carry.js`・progression）。
- `settleTetsukoTime(state, result)`（同期の純関数）: `result.meaningful` が真で、訪問キー（`章:通算日:時間帯:来訪回数`）が未確定のときだけ、同じ処理の中で来訪 +1 と `_tetsuko_time` を書き、`{ committed: true, stamina: 12 }` を返す。呼び出し側が同じ処理で `addStamina(12)` と toast「てつこに、少し元気をもらった」。それ以外は保存に触らない。
- 意味のあるふれあい = 段階会話を読み終えた ／ 主操作（なでる・あそぶ・止める・ブラシ・おやつ・見守る）を1回以上 ／ 画面で新しいしぐさを見届けた（見守ったのと同じ扱い）。もようがえ・図鑑を開くだけ・写真だけでは確定しない（その日の配置の変更は残らない）。
- 二重押し・LOAD・章跨ぎ: 画面の `done` ガード・`isCurrent()`・訪問キーで止める。LOAD で画面が差し替わったら確定せずに閉じる。
- 増やさないもの: 経験値・能力・火種・好感度・お金・日付・時間帯。#2455 の「白火+1」は入れていない（`found` が残るので後から読める）。

## 3. 遊び（モデルの数値）

**気分**（通算日で固定・開き直しで変わらない）: のんびり／眠い／遊びたい／甘えたい。段階0〜1の「甘えたい」は「こちらを気にしているみたいだ」と言い換える。気分は反応の出やすさ（自律行動の重み・膝に乗る条件）だけを変え、どの気分でも全部の操作ができる。

| 操作 | 条件 | 反応 |
|---|---|---|
| なでる（ボタン／猫をタップ／猫の上をゆっくりなぞる） | いつでも | 段階0 目を閉じて流す／1 目を細める／2 頭を寄せる／3 すり寄って喉を鳴らす（⑤）。4回続けると「しっぽをぱたんと振った。今は、もういいらしい。」→ ほかの操作で戻る。関係は下がらない |
| あそぶ（猫じゃらし） | いつでも | 1回目 目で追う／2回目 身を低くして狙う／3回目以降 前足（①）。「止める」で捕まえる（段階0は押さえてすぐ離す、1以上は抱える＝②）。5回振ったら自分から捕まえる |
| ブラシ | 段階1以上 | 1回目 力が抜ける（③）／2回目以降 前足が手を追う。採点なし |
| おやつ | ゲーム内の1日に1回 | 小皿に出す→匂いを確かめる→食べる→顔を洗う。同じ日は「今日はもうあげた」 |
| そっと見守る | いつでも | 1回目 前足をそろえる（⑧）。段階3で甘えたい日か2回目以降は膝で寝る（⑩・ムカイさん「……起こすなよ」）。ほかは自律行動を1つ |

**自律行動**（画面を開いている間だけ・2.4〜3.2秒ごと／動きを減らす設定では4秒）: あくび・毛づくろい・壁にもたれる・戸を見る・しっぽ・うとうと（眠い）・手前へ来る（段階2以上）・箱に入る／箱から顔だけ（⑥）・ボールを転がす／見送る（⑦）・爪とぎ・座布団で丸くなる・ベッドで寝る・変な寝相（⑨）・ベッドより箱（⑪・ムカイさん「……そっちか」）・トンネルからしっぽだけ・ましろちゃんが戸の向こうを通る（面識あり・段階1以上・1訪問に1回）。1回おきに落ち着く間（見た目を変えない）を挟み、直前と同じ行動は引かない。条件を満たした未発見のしぐさを 70% で優先。乱数は「通算日×31＋来訪回数」が種。

**小物**（3枠: ベンチ／床／寝床。同じ物は一か所だけ・使っていない物も失わない・通貨や買い直しなし）

| 小物 | 置ける枠 | 使えるようになる時 |
|---|---|---|
| 段ボール箱 | ベンチ・床・寝床 | 最初から |
| ボール | 床 | 最初から |
| 座布団 | ベンチ・寝床 | 段階1（ムカイさんに借りた） |
| 爪とぎ | 床 | 段階2（店の奥で見つけた） |
| 小さなトンネル | 床 | 段階2 かつ ましろちゃんと面識（ましろちゃんが持ってきた） |
| 猫ベッド | 寝床 | 段階3（ムカイさんが買ってきた） |

その訪問で新しく使える物があると「もようがえ」に「新」が付く。

**しぐさ図鑑（12件・自動で記録）**: ①はじめて前足が出た ②じゃらしを抱える ③ブラシでうっとり ④こちらを待っていた（段階2以上で画面を開いた時） ⑤初めてすりすり ⑥箱から顔だけ ⑦ボールを見送る ⑧前足をそろえる ⑨変な寝相 ⑩膝で寝る ⑪新しいベッドより箱 ⑫帰りの見送り（段階3で、ふれあいの後に「帰る」）。未発見は「箱があると……」等の一言ヒント。いろいろ試す人なら4回ほどの訪問で揃う（`tetsuko_time.mjs` が上限8回を確かめる）。

**写真**: 今見えているしぐさだけを撮れる。同じしぐさは1件（撮り直すと新しい方）、最大12件。保存はしぐさid・通算日・配置だけで、画像は保存しない。手帳では写真のある札が白い額になり、右のページに「東京 N日目」の写真が出る。

**てつこメモ**: 見つけたしぐさごとの一言（地の文）を手帳の右のページに出す。例: 「箱があると、とりあえず入る。」「新しいベッドより、その箱。ムカイさんは少し寂しそうだった。」（`MOMENTS[].memo`）

人物の一言は名乗りを受けた相手だけ、その訪問で一度だけ。長い会話は挟まない。ましろとの恋愛は前提にしない。

## 4. 画面（最初の版。v2 は §6）

- `#stage`（1280×720）の `#screen` 層に重ねる。背景は既存の `bg_street`（昼夜・天気は本編のまま）、HUD もそのまま（#2717 でこの画面の間は隠す。§7）。裏口の壁・戸・ベンチ・地面・小物は CSS で描く（文字を絵に焼き込まない）。
- 猫は既存の5表情（`portraitInfo("tetsuko", 表情)`・プレイヤーの絵柄設定に従う）を、どの表情でも同じ枠（元絵 896×1200 の x278〜636・y786〜1158）で切り出し、高さ約280px で見せる。表情を変えても位置が飛ばない。姿勢は CSS の小さな動き（低く構える・前足・箱の中で沈む・膝の上・ひっくり返る）。
- 居場所: ベンチ（左）・床（中央）・寝床（右）・手前・膝。小物のところにいる時は、その枠の位置。
- 上段右: もようがえ／しぐさ図鑑／写真／帰る、その下に題と今日の様子の一行（左上は日常の HUD。#2717 で左上を題の札と今日の様子にした。§7）。下段: 反応の一行（`aria-live`）と主操作。止めるは、じゃらしを振っている間だけ出る。
- 「帰る」はいつでも押せる（膝に乗られていても）。段階3でふれあいの後なら、戸の前まで見送る一言を出してから閉じる。
- 動きを減らす設定（`prefers-reduced-motion`）では移動・揺れ・浮かぶ演出を止め、自律行動は4秒おき。音は既存の `SE.select/click/cancel` だけ（無音でも反応の文と表情で伝わる）。
- DS風表示（`body.game-ds`）は対応画面（地図・会話など）だけで有効になる仕組みなので、この画面は通常表示で出る。16:9 のスマホ横でも猫・操作・帰るが見切れない。

| 道具 | 直接の操作 | ボタン1回 |

## 7. 専用テーマ「茶トラと段ボール」（#2717・2026-11-06）

オーナー「てつこといっしょの画面は、通常画面の『ラベンダー×白』のUIとは違う、専用のUIテーマにしたい。理由は『ミニゲームが始まった感』を出すため」。日常の紙×ラベンダーは使わず、入った瞬間に別の遊びが始まったと分かる画面にした。遊び・確定・保存・猫と小物の位置・当たり判定は変えていない。

**色**（てつこ本人と段ボールから取る。差し色は mukai の裏口の戸）

| 役 | 色 | 使う所 |
|---|---|---|
| 生成り（胸の白） | `#fff5e4`・`#fbe7c8` | 札・帯・手帳の中紙の面 |
| 焦げ茶（輪郭の線） | `#3b2416`・`#6e4325` | 文字・太い線（3px）・札の下に落ちる影 |
| 茶トラの橙 | `#f08a2e`・`#c25e1c`（文字は `#a24a12`） | 持っている道具・選んだ物・しま模様・肉球の判 |
| 段ボール | `#c9965c` 前後 | 外枠・もようがえのトレー・手帳の表紙・入る演出の箱 |
| 戸の青灰 | `#4e6b78` | 「帰る」・キーボードの選択の枠 |
| 鼻の桃色 | `#f39aa6` | 「止める」・「新」の札 |

文字は生成りの上の焦げ茶（コントラスト 13:1）か、橙の上の焦げ茶（5.8:1）。橙の文字は `#a24a12`（生成りの上で 5.5:1）だけ。キーボードの選択の枠は青灰（生成りの上で 5.3:1）。

**画面の作り**
- **日常の HUD を隠す**（`body[data-screen="tetsuko-time"]`。作業台と同じく押せない・読み上げない）。帰ると戻る。この画面では日付・時間帯・お金は変わらず、体力は帰る時の確定で戻るので、見えなくても困らない。
- **全画面の外枠**: 段ボールを角の丸い窓に切り抜いた枠（幅14px＋切り口6px。切り口の波の段も描く・SVG）。窓の内側は少し落として奥行きを出す（猫・小物・部品は暗くしない）。
- **左上の題の札**: 「てつこといっしょ / TETSUKO TIME」。てつこの小さな折れ耳と、下の縁に茶トラのしま、左に肉球の丸。その下に「今日のてつこ」の吹き出し（題の文字は札にあるので、吹き出しの題は読み上げだけ残す）。
- **押せる物は全部「焦げ茶の太い線＋下に落ちる影」の札**: 右上の道具（帰るは戸の青灰）、右下の手元の道具（持っている道具は橙に変わり、折れ耳が付く＝てつこの顔の形）、もようがえの品・おわる・閉じる。押すと沈む。
- 反応の帯は角の丸い札で、左の端が茶トラのしま。人物の名前は橙の札。もようがえは段ボールのトレー、てつこ手帳は段ボールの表紙に生成りの中紙と茶トラのしまの背。写真の白い縁はそのまま。
- 外枠の分だけ、下の帯・手元の道具・トレー・手帳を内側へ寄せた（右上の道具は HUD が無くなった分だけ上へ）。座布団の仮の絵は紫をやめ、素材の依頼どおりのからし色に。

**入った時の演出**（約1.2秒・`tetsuko-theme.js`・毎回）: 閉じた段ボール箱（肉球の判が押してある）の真ん中に題の札が出る → 封のテープが上へはがれる（`SE.pour`）→ ふたが左右に手前へ開く（`SE.jingle`）→ 真ん中の題が左上の札の位置へ縮んで収まる。演出は `pointer-events` を持たず、開いてすぐ道具も帰るも押せる（`tetsuko_theme.mjs` が演出の間に押せることを確かめる）。終わると演出の層は外れる。動きを減らす設定では演出を出さない（題の札はすぐ出る）。

**素材（#2691・PR #2697 の UI 原画）の扱い**: 紙×ラベンダーで作った UI 部品のうち、**アイコン10個・テープ・肉球の判は形をそのまま使える**（組み込む時に線を焦げ茶、琥珀を茶トラの橙、テープを段ボールのテープ色、判のインクを `#c25e1c` へ色を変えてから使う）。**手帳・写真の枠・今日の札・反応の帯は使わない**（ラベンダーの二重線と煙の渦が日常の紙UIの印で、入れると日常の画面に戻って見える）。この4つはテーマの CSS で描く。`tetsuko-art.js` の `ART_READY.ui` に `notebook`・`photo_frame`・`memo`・`caption` を書かない。小物の原画は UI ではないのでテーマに関係なく使える。
