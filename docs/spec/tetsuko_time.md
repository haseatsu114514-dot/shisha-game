## 2. 保存と確定

`state.flags._tetsuko_time = { v: 1, props: { bench, floor, bed }, found: [しぐさid…], album: [{ moment, day, props }…], treatDay, sessions, peaks, lastKey }`（`peaks`＝ごきげんがいっぱいになった通算の回数。§10 で追加。無い旧セーブは 0）

- 関係の段階は新しい数値を作らず、来訪記録 `_ch3_outings.tetsuko`（回数）から導く: 0〜1→0 まだ様子見／2→1 顔なじみ／3→2 待ってくれる／4以上→3 気を許す。画面の段階は、入口で読む段階会話の分を含めた「回数+1」で見る（ブラシの会話を読んだその日からブラシが使える）。旧セーブで膝・見送りまで来ている人は最初から段階3。
- `_tetsuko_time` が無い旧セーブは既定（小物なし・未発見）で入れる。SCHEMA は上げない。周回では持ち越さない（`carry.js`・progression）。
- `settleTetsukoTime(state, result)`（同期の純関数）: `result.meaningful` が真で、訪問キー（`章:通算日:時間帯:来訪回数`）が未確定のときだけ、同じ処理の中で来訪 +1 と `_tetsuko_time` を書き、`{ committed: true, stamina: 12 }` を返す。呼び出し側が同じ処理で `addStamina(12)` と toast「てつこに、少し元気をもらった」。それ以外は保存に触らない。
- 意味のあるふれあい = 段階会話を読み終えた ／ 主操作（なでる・じゃらし・ブラシ・おやつ・見守る）を1回以上 ／ 画面で新しいしぐさを見届けた（見守ったのと同じ扱い）。もようがえ・図鑑を開くだけ・写真だけでは確定しない（その日の配置の変更は残らない）。→ §10: 「見守る」はボタンではなく、7秒ほど触らずに眺めていると見守ったことになる。置いた物で誘う・とっておきも、ふれあいに数える。開いてすぐ帰れば、今までどおり何も確定しない。
- 二重押し・LOAD・章跨ぎ: 画面の `done` ガード・`isCurrent()`・訪問キーで止める。LOAD で画面が差し替わったら確定せずに閉じる。
- 増やさないもの: 経験値・能力・火種・好感度・お金・日付・時間帯。#2455 の「白火+1」は入れていない（`found` が残るので後から読める）。

## 3. 遊び（モデルの数値）

**気分**（通算日で固定・開き直しで変わらない）: のんびり／眠い／遊びたい／甘えたい。段階0〜1の「甘えたい」は「こちらを気にしているみたいだ」と言い換える。気分は反応の出やすさ（自律行動の重み・膝に乗る条件）だけを変え、どの気分でも全部の操作ができる。

| 操作 | 条件 | 反応 |
|---|---|---|
| なでる（ボタン／猫をタップ／猫の上をゆっくりなぞる） | いつでも | 段階0 目を閉じて流す／1 目を細める／2 頭を寄せる／3 すり寄って喉を鳴らす（⑤）。続けすぎると「しっぽをぱたんと振った。今は、もういいらしい。」→ ほかの操作で戻る。関係は下がらない（→ §10: 触った場所で反応が変わる。6回で休止、てつこが自分で動いても戻る） |
| あそぶ（猫じゃらし） | いつでも | 1回目 目で追う／2回目 身を低くして狙う／3回目以降 前足（①）。「止める」で捕まえる（段階0は押さえてすぐ離す、1以上は抱える＝②）。5回振ったら自分から捕まえる（→ §10: 「止める」のボタンは無い。4回目で飛びつき、先がそこにあれば捕まえ、引いていれば空振り） |
| ブラシ | 段階1以上 | 1回目 力が抜ける（③）／2回目以降 前足が手を追う。採点なし |
| おやつ | ゲーム内の1日に1回 | 小皿に出す→匂いを確かめる→食べる→顔を洗う。同じ日は「今日はもうあげた」 |
| そっと見守る | いつでも | 1回目 前足をそろえる（⑧）。段階3で甘えたい日か2回目以降は膝で寝る（⑩・ムカイさん「……起こすなよ」）。ほかは自律行動を1つ（→ §10: ボタンは無い。触らずに眺めていると、この反応になる） |

**自律行動**（画面を開いている間だけ・2.4〜3.2秒ごと／動きを減らす設定では4秒。→ §10: 1.7〜2.4秒ごとにし、おねだり・鳴く・つつく・のびを足した）: あくび・毛づくろい・壁にもたれる・戸を見る・しっぽ・うとうと（眠い）・手前へ来る（段階2以上）・箱に入る／箱から顔だけ（⑥）・ボールを転がす／見送る（⑦）・爪とぎ・座布団で丸くなる・ベッドで寝る・変な寝相（⑨）・ベッドより箱（⑪・ムカイさん「……そっちか」）・トンネルからしっぽだけ・ましろちゃんが戸の向こうを通る（面識あり・段階1以上・1訪問に1回）。1回おきに落ち着く間（見た目を変えない）を挟み、直前と同じ行動は引かない。条件を満たした未発見のしぐさを 70% で優先。乱数は「通算日×31＋来訪回数」が種。

**小物**（3枠: ベンチ／床／寝床。同じ物は一か所だけ・使っていない物も失わない・通貨や買い直しなし）

| 小物 | 置ける枠 | 使えるようになる時 |
|---|---|---|
| 段ボール箱 | ベンチ・床・寝床 | 最初から |
| ボール | 床 | 最初から |
| 座布団 | ベンチ・寝床 | 段階1（ムカイさんに借りた） |
| 爪とぎ | 床 | 段階2（店の奥で見つけた） |
| 小さなトンネル | 床 | 段階2 かつ ましろちゃんと面識（ましろちゃんが持ってきた） |
| 猫ベッド | 寝床 | 段階3（ムカイさんが買ってきた） |

その訪問で新しく使える物があると「もようがえ」に「新」が付く。

**しぐさ図鑑（12件・自動で記録）**: ①はじめて前足が出た ②じゃらしを抱える ③ブラシでうっとり ④こちらを待っていた（段階2以上で画面を開いた時） ⑤初めてすりすり ⑥箱から顔だけ ⑦ボールを見送る ⑧前足をそろえる ⑨変な寝相 ⑩膝で寝る ⑪新しいベッドより箱 ⑫帰りの見送り（段階3で、ふれあいの後に「帰る」）。未発見は「箱があると……」等の一言ヒント。いろいろ試す人なら4回ほどの訪問で揃う（`tetsuko_time.mjs` が上限8回を確かめる）。

**写真**: 今見えているしぐさだけを撮れる。同じしぐさは1件（撮り直すと新しい方）、最大12件。保存はしぐさid・通算日・配置（と、夜に撮った時は `night: true`）だけで、画像は保存しない。手帳では写真のある札が白い額になり、右のページに「東京 N日目」の写真が出る。→ 2026-11-11（TKT30）: 撮った写真は、裏口の絵（撮った時の昼・夜）を背にして見せる。まだ撮っていないしぐさは色を薄めず、点線の窓で区別する。

**てつこメモ**: 見つけたしぐさごとの一言（地の文）を手帳の右のページに出す。例: 「箱があると、とりあえず入る。」「新しいベッドより、その箱。ムカイさんは少し寂しそうだった。」（`MOMENTS[].memo`）

人物の一言は名乗りを受けた相手だけ、その訪問で一度だけ。長い会話は挟まない。ましろとの恋愛は前提にしない。

## 4. 画面（最初の版。v2 は §6、てつこを主役にした配置は §8）

- `#stage`（1280×720）の `#screen` 層に重ねる。背景は既存の `bg_street`（昼夜・天気は本編のまま）、HUD もそのまま（#2717 でこの画面の間は隠す。§7）。裏口の壁・戸・ベンチ・地面・小物は CSS で描く（文字を絵に焼き込まない）。
- 猫は既存の5表情（`portraitInfo("tetsuko", 表情)`・プレイヤーの絵柄設定に従う）を、どの表情でも同じ枠（元絵 896×1200 の x278〜636・y786〜1158）で切り出し、高さ約280px で見せる。表情を変えても位置が飛ばない。姿勢は CSS の小さな動き（低く構える・前足・箱の中で沈む・膝の上・ひっくり返る）。
- 居場所: ベンチ（左）・床（中央）・寝床（右）・手前・膝。小物のところにいる時は、その枠の位置。
- 上段右: もようがえ／しぐさ図鑑／写真／帰る、その下に題と今日の様子の一行（左上は日常の HUD。#2717 で左上を題の札と今日の様子にした。§7）。下段: 反応の一行（`aria-live`）と主操作。止めるは、じゃらしを振っている間だけ出る。
- 「帰る」はいつでも押せる（膝に乗られていても）。段階3でふれあいの後なら、戸の前まで見送る一言を出してから閉じる。
- 動きを減らす設定（`prefers-reduced-motion`）では移動・揺れ・浮かぶ演出を止め、自律行動は4秒おき。音は既存の `SE.select/click/cancel` だけ（無音でも反応の文と表情で伝わる）。
- DS風表示（`body.game-ds`）は対応画面（地図・会話など）だけで有効になる仕組みなので、この画面は通常表示で出る。16:9 のスマホ横でも猫・操作・帰るが見切れない。

## 6. UI の本格化（v2・2026-11-06・TKT01〜05）

**手元の道具**（下のボタンを押すと、その道具に持ち替えて1回行う。持ち替えた後は直接も触れる）

| 道具 | 直接の操作 | ボタン1回 |
|---|---|---|
| なでる手 | 猫をタップ／押したまま猫の上をゆっくりなぞる（90px ごと・0.6秒あけて1回） | 1回なでる |

**絵の差し替え**（`tetsuko-art.js` の `ART_READY`）: 届いて採用した素材の名前を書くと、その素材だけ CSS の絵から差し替わる。書いていない素材は読みに行かない（404 を出さない）。

- UI: アイコン・手帳・写真の枠・テープ・今日の札・肉球の判・反応の帯（九分割）・道具箱（九分割）・丸い札。

**検証**: `node remake/test/tetsuko_time.mjs`（てつこメモの文・絵の名前が依頼した12枚のどれか・`ART_READY` に書いた素材のファイルがある）、`node remake/test/browser/ch3_tokyo_daily.mjs` の `tetsuko-time-toolbox-toy-drag-and-notebook`（道具箱で箱を床へ・じゃらしをマウスで動かして前足・手帳に記録・帰ると配置と発見が残る）。絵の差し替えの経路は、仮の画像を返す検査で配置・重なり・読み込みの無駄がないことを確かめた（素材の到着後に本物で撮り直す）。

## 7. 専用テーマ「茶トラと段ボール」（#2717・2026-11-06）

オーナー「てつこといっしょの画面は、通常画面の『ラベンダー×白』のUIとは違う、専用のUIテーマにしたい。理由は『ミニゲームが始まった感』を出すため」。日常の紙×ラベンダーは使わず、入った瞬間に別の遊びが始まったと分かる画面にした。遊び・確定・保存・猫と小物の位置・当たり判定は変えていない。

**色**（てつこ本人と段ボールから取る。差し色は mukai の裏口の戸）

| 役 | 色 | 使う所 |
|---|---|---|

## 8. てつこを主役にする配置（TKT17・2026-11-07）

オーナー「レイアウトをもっとてつこがメインにしたい」。前の画面では、てつこ（約270×280px）が画面の1割ほどしかなく、四隅の部品のほうが目立っていた。遊び・確定・保存・小物の置き場所・当たり判定の考え方は変えていない。

- **カメラ**（`TETSUKO_CAMERA`・`tetsukoCameraFor`）: 裏口の舞台（奥の飾りの層と、小物・猫・じゃらしの層）を **1.4倍に寄せ**、てつこの体の真ん中を画面の (640, 330) に映す。舞台の外は映さない（端では寄せたまま止まる）。てつこが居場所を移ると、歩くのと同じ速さ（0.9秒）で追う。向き先は CSS の `.tt-cat[data-at]` の `--x`・`--y`・`--s` を読む（箱やボールの中の位置の上書きも含む）。入った時と、動きを減らす設定では動かさずに合わせる。
- **もようがえの間は引く**（zoom 1）。置き場所（ベンチ・床・寝床）が全部見えて選べる。閉じると、てつこへ寄り直す。
- 指・マウスの位置は、寄せた（動いている途中の）カメラから舞台の座標に戻す。じゃらしを振った長さは画面の上で測るので、手の動きの感じは前と同じ（170px で1回）。手帳へ飛ぶ写真は、映っている猫の位置から飛ぶ。
- **周りの部品を一回り小さく**（PC）: 題の札（文字 23px）・右上の道具（82×62）・手元の丸い札（62px）・反応の帯（幅 520）。スマホ横持ちの下限（文字・押せる大きさ・間隔。§7 の `@media`）はそのまま守る。
- **代わりの背景はぼかす**: 裏口の絵が届くまでの街並みは遠くの景色としてぼかし（3px）、てつこを浮かせる。裏口の絵が届いたらぼかさない。窓の内側の陰（`.tt-vignette`）は奥の飾りと猫の層の間にあり、猫・小物は暗くしない。
- **裏口の絵（#2695）**: 絵はベンチ・戸・地面を含むので、舞台と一緒に寄せる層（`.tt-cam-set` の `.tt-backdrop`）に置いた（2026-11-11）。絵のベンチの座面は y≈420 なので、ベンチの上の居場所・置き場所だけ y=424 に合わせた（`[data-art-bg="true"]`）。

**検証**: `node remake/test/tetsuko_time.mjs`（寄せは1.3倍以上・CSS のすべての居場所で、てつこの枠が外枠の内側に収まる・舞台の外を映さない）、`node remake/test/browser/tetsuko_theme.mjs`、`node remake/test/browser/ch3_tokyo_daily.mjs` のてつこの3件（じゃらしをマウスで動かして前足が出る＝寄せた座標の戻しが合っている）。PC（1280×720）とスマホ横（844×340）で、もようがえ・箱・ベッド・座布団の上・じゃらしを撮って確かめた。



## 9. 発見を遊びにつなぐ（2026-11-11）

オーナーの「ゲーム性が分かりづらい・動きがぎこちない」という試遊を受けた改善。点数や失敗を増やさず、**試す → てつこが反応する → しぐさを見つける → 写真と手帳に残す**を短い遊びの単位にする。

- 反応の帯の下に、今の段階でできる未発見しぐさへの一言を出す。対応する道具には橙の点線。手帳の未発見しぐさから「このしぐさを探す」で目的を選べる。条件を満たさないしぐさは誘導しない。選択は訪問内だけで、保存形式は変更しない。→ §10: 一言の文はやめ、てつこの頭の上の「おねだりの吹き出し」（道具のアイコン）に置き換えた。
- 小物を置いたら、次の自律行動でまずその物を確かめる。箱なら顔を出す、ボールなら見送る。模様替え中は勝手に動かず、閉じた後に反応する。片付けた箱の中に猫が残る不具合も修正。
- 初めて見つけたしぐさは6.5秒、自律行動で上書きしない。写真ボタンを橙で囲み、反応の帯に写真の案内を出す。撮影後は次の発見へ。操作すればいつでも別の遊びに移れる。
- 距離に応じて移動時間を420〜1600msに変え、猫とカメラを同じ補間にする。呼吸が歩行アニメーションを上書きする問題を直し、歩行の上下動は4pxに抑える。じゃらしを抱えた位置は移動中の猫に追従する。
- なでる／ブラシの移動距離は舞台座標で測り、縮小されたスマホだけ何度も大きくなぞる必要がないようにする。押下中はポインターを捕捉する。手帳・説明・模様替え中は操作と自律行動を止め、じゃらしの遅延捕獲も止める。
- 動きを減らす設定・帰る・中断・来訪／体力／保存の確定点は維持。背景としぐさの未採用素材PRはこの変更では取り込まない。

## 10. 手応えの作り直し（2026-11-11・TKT18〜24）

オーナーの試遊「操作性や何をするゲームなのかが分かりづらい／面白さが弱い。ついハマってしまったり楽しめるように／UIの文字が多い・やや複雑／こちらから何かしないと動かない／反応が面白くない」を受けた作り直し。前の版は、表情1枚の差し替えと説明の文が反応の中心で、道具が11個並び、触らない間の変化が小さかった。

**遊びの芯**（文を読まなくても分かる形）: てつこが「してほしいこと」を吹き出しで見せる → 応える（触る・振る・置く）→ その場で体と擬音が返ってくる → **ごきげんのハート**がたまる → いっぱいになると**とっておき**のしぐさ → 写真と手帳に残る。点数・ランク・失敗・時間制限・関係の低下は今までどおり無い。確定点（来訪+1・回復12）・段階・図鑑12件・小物・入口の3択は変えていない。

### 10-1. ごきげん（題の札の下のハート5つ）
- 0〜100（`JOY_MAX`）。**減らない**・その訪問の間だけ（持ち越さない）。操作ごとの量は `JOY`（例: なでる6／お気に入りの場所12／じゃらしを抱える14／空振り8／おやつ22／新しいしぐさ+8／おねだりに応えた+10／眺めている間の、てつこのしぐさ3）。40秒〜1分ほど遊ぶといっぱいになる。猫のところからハートが一つ飛んできて満ちる。
- いっぱいになると、少し間を置いて**とっておき**（`peakReaction`）: 段階0 ゆっくりまばたきを返す／1 指先の匂いをたしかめに来る／2 手のひらに頭をぶつけてくる／3 膝に乗って丸くなる（⑩）と、何度も頭をこすりつける（⑤）を交互。画面が明るくなり、ハートときらきらが弾ける。ハートは空に戻り、またためられる。
- 通算の回数だけ `_tetsuko_time.peaks` に足し、手帳に「ごきげん n回」と出す（能力・お金・好感度・解放の条件には使わない）。「少し構っていく」では増えない。

### 10-2. おねだり（頭の上の吹き出し・道具のアイコン）
- 開いて最初の拍で出る。まだ見つけていないしぐさへの手がかり（`discoveryGuide`）を優先し、全部見つけた後は気分で決める（遊びたい日はじゃらし、甘えたい日はなでる、など）。なでる／じゃらし／ブラシ／おやつ／「……」（何もせずそばにいる）／箱（もようがえ）。様子見の段階は、なでてとは言わない。使えない道具はねだらない。
- 応えられる道具の札が小さく身を振る。応えると音符が出て、ごきげんが多めにたまる。**応えなくても損はなく**、てつこが3回ほかのことをすると忘れる。寝ている・膝の上では出さない。
- 手帳の「このしぐさを探す」を選ぶと、次のおねだりがそのしぐさの手がかりになる（前の版の一行案内の置き換え）。

### 10-3. なでる（触った場所で反応が変わる）
- 場所は広い4つ: 頭／あご／背中／しっぽ（`petZoneAt`。座った絵は上から頭・あご、下の左がしっぽ。丸くなった絵は右が頭）。一点の正解探しにはしない。
- **今日のお気に入り**（頭・あご・背中のどれか。通算日で決まり、同じ日は同じ）に触れると「そこが、今日のお気に入りらしい。喉が鳴りだした。」きらきらとゴロゴロ。しっぽは「ぷいっ」と向こうを向くだけ（ごきげんは減らない・続けた回数にも数えない）。
- なぞっている間は、手のほうへ体を少し寄せ、手の下に小さな光が出る。6回続けると「もういいらしい」。ほかの遊びをするか、てつこが自分で動くと戻る。ボタンの「なでる」は頭→あご→背中の順に手を移す（ボタンだけでも、お気に入りが見つかる）。

### 10-4. じゃらし（飛びつく・空振りする）
- 先は指・マウスを少し遅れて弾みながら追う。てつこは先のあるほうを向く。1回目 目で追う → 2回目 身を低くしてお尻を振る → 3回目 前足（①）→ **4回目で飛びつく**（弧を描いて跳ぶ・約0.4秒）。
- 着いた所に先があれば抱えこむ（②）。引いていれば「すかっ」と空振り（汗・滑る）。**ゆっくり動かす・止めると届き、速く振る・切り返すと空振り**（手の向きを少しだけ先読みして跳ぶ）。空振りもごきげんが上がる（てつこの負けではなく、遊びの一コマ）。空振りは2回まで続き、その次は必ず捕まえる。止めて近くに置いておいても捕まえる。
- 遊んでいる間のカメラは、てつこを追わずに少し引いて床の真ん中（`TETSUKO_TOY_VIEW`）。様子見の段階と、動きを減らす設定では跳ばない（その場で前足／結果だけ出る）。ボタンの「じゃらし」は押すたびに1回振る。

### 10-5. 自分から動く・眺めているだけでもいい
- 自律行動の間隔を 1.7〜2.4秒にし、落ち着く拍には小さな身じろぎ（首をかしげる・揺れる・向きを変える・小さくはねる）を入れた。鳴く（顔なじみから）・前足でつついてくる（待ってくれる段階から）・のび・横目で見る（様子見〜顔なじみ）を足した。
- **7秒ほど触らずにいると、隣で見守ったことになる**（`WATCH_IDLE_MS`。「そっと見守る」のボタンは無い）。前足をそろえる（⑧）・膝で寝る（⑩）は、眺めているだけで起きる。膝に乗ったら、しばらく降りない。
- 置いてある物はタップして誘える（`invite`）: 箱なら顔を出す・入る、ボールなら見送る・転がす。

### 10-6. 画面（文字と道具を減らす）
- 道具は 11 → 8: 右上は もようがえ・てつこ手帳・？・帰る。右下は なでる・じゃらし・ブラシ・おやつ。「止める」「そっと見守る」「写真」のボタンは無い。
- **写真は、しぐさが見えた時だけ猫のそばに出る丸いカメラ**（まだ撮っていないしぐさは橙で光る）。押すと今までどおり光って手帳へ飛ぶ。
- 反応の一行は、自分の操作への反応・新しいしぐさ・人物の一言・最初のおねだりの時だけ出て、3.8秒で消える。てつこが勝手にしている、いつものしぐさは**擬音**（「ごろごろ」「ぺしっ」「がしっ」「すかっ」「ぷいっ」など5字以内）と体の動き・小さな粒（ハート・きらきら・音符・Zzz・汗・肉球のあと・毛）で見せる。
- 「今日のてつこ」の吹き出しは廃止（文は「？」と読み上げに残る）。通いはじめ（2回目まで）は、なでる手の手本が頭の上を往復する（触ると消える）。
- 音（合成）: 鳴き声 `mew`・飛びつく風切り `swish`・空振り `boing`・ぽん `pon`・とっておき `twinkle`。
- 動きを減らす設定: 跳ぶ・はねる・粒・飛ぶハートを出さない（擬音は動かさずに出す。結果は同じ）。スマホ横持ちの下限（文字 実寸11px・押せる所 実寸38px）は、カメラの札とハートも守る。
