## 操作と一人称配置

- 本編・試遊ページの既定は `inputMode: "tap-pull"`。的だけの正方形窓をやめ、レーン全体に的・手元・飛ぶ斧を置く。手元とレーンは仮のコード描画。未承認生成絵は採用しない。
- 的をタップして直接照準。右の取っ手を下へ引き、緑で離す。速さ/イベント頻度ではなく距離が回転を決める。
- 矢印で照準、Space長押し→離す、Fで1投1回集中。タップ/6%未満/元へ戻す/Escは投擲を消費せずキャンセル。
- Pointer Capture。複数指、pointercancel/capture消失、リサイズ・回転、blur/タブ非表示、説明表示、Abortでは投げずに中止。active-time時計は一時停止し、復帰時に一気に進めない。
- 入力の距離は実画面px、表示はstage-fitのCSS縮尺を逆変換して一致させる。板は逆SVG CTMで正規化。狙いとHUDのletterbox外操作を混同しない。
- 青のタップは照準だけ。宣言はボタンで明示し、既存の回数/高さ制限を使う。
- 無料レッスンも新操作で「説明→的→引いて離す→結果→終了」。旧操作の説明を新操作へ流用しない。
- 旧3ゲージ操作は明示 `inputMode: "gauges"` で残す。試遊URLの `?input=gauges` は旧操作の回帰確認用。既定を旧操作へ戻す隠れたfallbackではない。

### 購入・所持・記録

商品情報は既存 `core/hobby-gear.js` のHOBBY_GEARへ集約。価格/名前の二重定義や循環importを作らず、購入は全段階で既存 `buyGear` へ委譲。`owned`、帰宅運賃200円の留保、二重購入防止、ステータスの「遊びの道具」表示を共用する。

斧投げBarの「マイ斧を見る・選ぶ」から専用画面を開き、3商品を購入し、所有斧＋店の斧から今回使うものを選ぶ。通常の店メニューへ商品を縦積みせず、専用画面は4枚のカードを2×2に配置する。24px文字・82px操作部品を保ち、「店に戻る」またはEscで元のメニューとフォーカスへ戻る。来店時の既定は所有最上位。選択は来店内だけで、新しいセーブフラグは不要。購入後は全購入ボタンとプレイ可否を更新。無料レッスンと従来の物語対戦は店の斧。購入品効果は店の有料3/10投へ渡す。

旧15,000円で買った `gear_hatchet` はID/所有/10%効果を維持。新規購入価格のみ値下げ。**返金・自動上位交換・追加報酬は実装しない。** 過去成績は再計算せず、新記録に `inputVersion` と `equipment:{id,version,steady,powerErrorScale}` を追記する。

補正は `ideal + (raw - ideal) * powerErrorScale`。rawキャンセルを先に判定。緑帯を逆変換し、予測・投擲・着弾は同じ補正後powerを使う。得点加算、刃拡大、キル増加、相手AIの隠れた弱体化なし。最高級でも極端な入力は落下し、無料斧でもブルを取れる。

#3471の認定報酬はmainへマージ済み（9953e716）。競合解消ではplay-mastery import、メニュー認定説明、完走後sync、記録後recordの4接続を保持する。新入力やマイ斧購入が独自に報酬を加算することはない。
