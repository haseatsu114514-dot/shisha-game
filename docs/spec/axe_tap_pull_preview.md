## 操作

1. 木の的をタップ。画面内の窓でなくレーン全体を一人称で見て照準を置く。
2. 右側の取っ手を下へ引く。距離230論理pxを100%とし、54〜70%を緑で示す。
3. 離すと投げる。速さ/イベント頻度は判定に使わない。元の高さへ戻す・6%未満で離すとキャンセル。
4. F/集中ボタンで1投1回、既存モデルの1200ms集中。長く構えるほど既存の手ぶれが増える。

- 青に照準を置くだけではキルショットを宣言しない。左のボタンで明示宣言し、既存の回数/上下ルールで制限する。
- キーボードは矢印で照準、Spaceを長押しして離す、Fで集中、Escで引く動作をキャンセル/説明を開く。
- Pointer Capture、pointercancel、capture消失、複数指、画面回転/リサイズ、タブ非表示、blur、設定表示では引く動作をキャンセル。意図しない投擲は記録しない。
- 的は16:9の描画領域で逆変換。右の取っ手は画面UIなので、letterbox外でも画面座標差から距離を計算。両者を混同しない。
- 待機中はactive-time時計を止める。復帰時にいきなり最大パワー/命中に進めない。

## 採点と互換

`AxePullSession` は入力・進行の薄い層。`resolveThrow` / `releaseAimAt` / `takeTurn` が採点の唯一の正本で、リング・刃の接触判定・回転・落下・Rec/Am/Pro閉鎖・キル宣言・10投の前後半・同点決着を再実装していない。

試作には練習3投、スコア10投、ひよりとの1ゲーム対戦（easy/normal/hard）。裏ボス解放やBO3は追加しない。結果は既存の completed/cancelled/throws/total/grade/ruleset/mode/division/throwCount/maximum/challenges/rank/title/stats/match/series に合わせ、`inputVersion` を追加。ただし**現時点では本編イベントへ結果を渡さない**。

localStorage/sessionStorage/IndexedDB・セーブ・親密度・通貨・達成報酬を書き換える経路はない。既存セーブの移行もない。保存データの互換は「既存データを変更しない」で確保しており、本編へ統合後の報酬互換を実機検証済みという意味ではない。
