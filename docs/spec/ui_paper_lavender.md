## 2026-11-06 TRPGの専用テーマ「夜の卓」（#2719）

オーナー指示（2026-11-06）: TRPGの画面は通常のラベンダー×白ではなく専用のUIテーマにして、「ミニゲームが始まった感」を出す。読みやすさと操作の分かりやすさは落とさない。進行・判定・セーブには触らない。

- 対象はTRPGの画面一式（ボドゲカフェの本棚・部活の提案・昼の試遊・対面の勧誘・卓の表紙・会話・座席・調査・聞き込み・宣言・判定・キャラ作り・シート・遊び方・ログ・メモ・記録・結末）と単独の試遊ページ。UIデザインの設定（`data-ui-theme`）に関係なく同じ見た目。紙×ラベンダーへの上書き `css/trpg-paper.css` は削除した。テーマに関係なく効かせていた結末の下地・絵のない本の場所名・メモのふせんの3規則はそのまま、紙テーマの時だけ効いていたダイス窓の読みやすさの直し（2d20の数字を1列で面の中央へ・縮小時の最小の文字の大きさ・スクロール端の余白・押せない決定ボタンの濃さ）はどのテーマでも効くようにして、新しいファイルへ移した。
- 色と素材: 地は深緑のフェルト、縁はウォルナットと真鍮、文字を読む紙は生成りのシナリオ紙、ダイスは象牙。開幕のダイスと見出しの帯だけ、ボドゲカフェの看板（真鍮・ガーネット・生成り）に合わせてガーネット。素材は既存の `img/ui/trpg/deep-teal-felt.webp`・`walnut-brass-frame.webp` を再利用し、新しい画像はない。実装は `css/trpg-theme.css`（`trpg.css` から読込）。色は `--tt-*` の変数にまとめた。
- 部品: 本棚と店の画面はウォルナット×真鍮の額で囲む（中身がスクロールしても額は動かない）。卓の上の見出しはウォルナットのレール、台詞はフェルトの窓に真鍮の縁。決定の札は真鍮、それ以外の札はフェルトに真鍮の縁。遊び方・ログ・メモ・記録・確認は額に入った生成りの紙。判定・相談・宣言・シート・キャラ作りの舞台は既存のフェルトと額のまま。紫が残っていた部品（紙テーマの時の判定のダイス、チュートリアルのダイスの図、絵のない本の文字の選択カード）も卓の色にした。
- 開幕（`js/trpg/entrance.js`）: 本棚（店・タイトルの思い出の本棚・試遊）に入った瞬間、閉じたフェルトの幕の中央に「TABLETOP RPG／小さな卓の冒険」の札が出て、ダイスが転がってきて止まり、幕が上下に開く（約1.5秒）。本棚から卓を始めた時は幕が短く開く（約0.7秒。本棚の開幕が出ている間は重ねない）。演出の層に重ねるだけで操作は塞がない（`pointer-events: none`）。動きを減らす設定では、動かさずに札を短く見せて消す。地図から店への場面転換（`daily/trpg.js`）は変えていない。
- ミニゲーム共通のUI方針（2026-11-06 オーナー指示・#2719 のコメント）: 文字を密集させない／操作や遊び方は「？」を開いて見る（常時表示しない）／基本画面は必要なUIだけ。TRPGでは次のように当てた。
  - 店の本棚（`campaign-view.js`）と試遊の本棚（`library.js`）の右上に「？」（`js/trpg/shelf-help.js`）。部活と勧誘・本の購入・夜の1枠・昼の試遊の決まり、操作の案内は、画面から外してこの紙へ移した。試遊の札には目当ての一文だけ残す。
  - 卓: 遊び方は右上の「？」だけ（表紙の「遊び方」の札は重複なので外した）。遊び方の中身は「用語／この物語の進め方／判定／札と盛り上がり／操作」の見出しで区切る。進行は上のレールの小札（今の段）だけにし、下の進行の帯は出さない。座席の帯は話している人と名前だけ（能力値と切り札の残りはキャラクターシート）。
  - 見出しが隠れる舞台では、その場に「？」: 宣言（宣言のしかた・目標値）とキャラ作り（能力の説明・計算の一言）は、押した時だけ出る。シートの前置きは遊び方と同じなので出さない。判定の舞台は、すでに見通しを「判定の詳細」に畳んでいるのでそのまま。
- 変えないもの: 進行・判定・料金・報酬・台詞・セーブ、部品の寸法・座標・当たり判定・タッチ領域。くじ・ギャラリーは引き続き紙とラベンダー（斧投げは #2718 で別の専用テーマ「レーン」）。

## 2026-11-02 全画面MENU（4タブ）

設計 [daily-ui-menu-design.md](../design/daily-ui-menu-design.md) §4 の段階P2。台帳は `docs/owner_requests.md` の MN01〜08（DUI03〜05）。

- 入口は日常パート（`daily/calendar.js` の `runDaily`）の HUD の MENU。`daily/menu.js` の `openMenu({ tab, canSave, current, leave })` が4タブの全画面を開き、選んだシステムの操作（セーブ・ロード・設定・用語集・大会の規則・タイトルへ戻る・心得の盤）まで行う。日常は `canSave: isChoosingDestination`（手動セーブとタイトル前の保存は地図で行き先を選んでいる時だけ・#638）。
- タブ: ステータス（盤を使う時は Lv・EXP・火種・3盤の横ゲージ、盤の公開前は旧5能力の段と呼称。グラフは出さない）／人間関係（1人1行、タップで思い出・次の進め方・贈り物）／持ち物（フレーバー・機材・遊びの道具・レシピ帳・試したい配合・記念品）／システム。人の並びと贈り物の札・レシピの詳細は `daily/status.js` と共有する。
- 保存データは読むだけ。HUD の五角形のステータスボタンは廃止し、火種の印は MENU の右上（`hud.js`）。能力アップの通知の光（`core/ui.js` の `flyStatGain`）と寝る前の火種の粒（`levelup.js`）も MENU へ飛ぶ。旧STATUS画面 `openStatus` は第2章の配達地図のMENUが使うので残している。
- 見た目は `css/daily-menu.css`。どのUIテーマでも紙×ラベンダー＋琥珀。紙は生成画像 `assets/ui/paper/menu-bg.png` を `remake/tools/build_ui_skin.py`（`build_menu_bg`）で 1536×838 の `img/ui/paper/menu-bg.webp` にしたもの（上の枠線と左下のシーシャ台の絵はそのまま、無地の中ほどだけ縦に詰める）。1280×720 の舞台に 1232×672 で置き、タブの帯と枠線の位置を絵に合わせる。絵が読めない時も同じ色の紙と帯で開く。
- DS風は絵を引き伸ばさず、上下2画面ぶん（横持ちは左右2画面ぶん）の紙と線で描く。縦持ちはタブを下の帯に4つ、横持ちは左の帯。MENU を開いている間はヒンジの「表示」を隠す。
- キー: 地図で行き先を選んでいる間は M で開く。MENU の中は M・Esc で閉じる（レシピの詳細・チェキの拡大を開いている時は Esc でそれだけ閉じる）、1〜4・Q/E・タブ上の矢印でタブを移る。
- 検証: `node remake/test/browser/daily_menu.mjs`（4タブ・読むだけ・キー・レシピとチェキの戻り方・盤の入口・手動セーブの可否・1280×720／横持ちタッチ／DS縦 390×844・320×568）。MENUを経由する既存の回帰（`save_load`・`ds_overlay_layers`・`growth_levelup`・`lime_badge`・`game_layout` など）はシステムタブを選んでから押す。
