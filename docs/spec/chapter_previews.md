### 章タイトルの直前の巻頭ポエム（OSP03・OSP05〜OSP10・2026-11-08）

各章の章タイトル（タイトルコール）の**直前**に、その章の巻頭ポエムを専用の読ませる画面で出す（第1章は `poem_ch1`、第2〜5章は `poem_ch2`〜`poem_ch5`）。**第1章の詩は序詩を兼ね**、第1章のコールドオープンの後に出る（序詩は独立させない・OSP10）。会話ウインドウではなく、暗い面に縦書きの明朝で、右の行から1行ずつ浮かべる。詩の連ごとに場面を分けて1場面ずつ読ませる（第1〜3章・第5章は2場面、第4章は1場面。読み終えた場面は消えて次の連が浮かび、最後の場面のあとに章タイトルへつなぐ）。本文と意図・評価は `brand/chant_poems.md`、台本は `data/dialogue/chapter_poems.json`（1要素 = 詩の1行、`gap: true` が連の切れ目。各詩は空白を除いて34〜101字・4〜11行で、章ごとに長短を散らした。候補集と選んだ理由は同書 §9・§4）、再生は `remake/js/scenes/chapter-poem.js`、見た目は `remake/css/motions/chapter-poem.css`。

- **コマ絵**: 詩の上に、横長の漫画風の絵を細い枠つきで出す（比率は絵のまま、4:1〜5.6:1）（`chapter_poems.json` の `metadata.panel`・`panel_alt`、`remake/img/ui/poems/`）。絵が先に浮かび、一拍おいて詩が始まり、詩が終わるまで残る。読み込んでデコードし終えてから出す。絵は**必ず出す**（2026-11-13 オーナー「横長の漫画はマストで出したい」・OSP20）: 届くまで待ち（0.5秒を超えたら、ほかの待ちと同じロード表示「詩を準備しています…」）、通信の失敗は1回だけ読み直す。壊れた絵・つながらない時だけ、枠ごと出さず詩だけを全面に出す。第1章はコールドオープンの間に、第2章以降は前の章の詩を出した時に、次の詩の絵を先に読んでおく。絵は**各章のゲームの場面を漫画風に描いた絵**（Codexで生成した5枚を採用済み）。差し替えは `tools/poem_panel_cut.py` で枠を検出して横長の WebP に整えて当てはめる（場面・参照画像・プロンプト・手順・採用した絵の記録は `brand/chant_poems.md` §8）。詩の列は、下の▼の印と重ならないよう場面の下に44pxの余白を取る。
- 章タイトルの表示時間・入力ガード・画像失敗時の文字表示は変えない。詩が閉じた後に章タイトルが始まる。章タイトルの絵は詩を読んでいる間に先読みする。
- 操作: 読んでいる途中のタップ／Enter／Space はその場面の残りの行を出し、読み終えたらもう一度で次の場面へ（最後の場面なら閉じる。直後の誤タップは無視）。Ctrl（SKIP）は全場面を飛ばして閉じる。放置でも場面ごとに字数に応じた時間で進む。動き軽減では場面の行を最初から全部出す。`vnTest.turbo` では演出を飛ばす。
- 章ごとの `titleSeen`（第1章は `introDone`）は、詩と章タイトルを両方見終えてから立てる。詩の途中で中断した再開では詩と章タイトルをもう一度出し、読了後の再開では出さない。
- 第3章は章タイトルの出し方が3経路（章頭・出発前の準備つき・準備なしの序章）あり、どの経路でも章タイトルの直前に出す。
- 後ろ（章タイトルの直後）へ置く案に切り替えるときは、各章の `playChapterPoem` の呼び出しを章タイトルの後ろへ動かす。
- 検証: `node remake/test/chapter_poems.mjs`（台本の短さ・場面の数・文書との一致・接続点・絵のファイル）、`node remake/test/browser/chapter_poems.mjs`（表示順・縦書き・コマ絵・操作・再開）。

### 出現アニメーション（#2611・2026-11-06）

採用画像のある全章（第1〜5章）で共通の出現を使う。「煙が晴れて章題が見える」控えめな動きで、画像1枚のまま位置・大きさは動かさない（transformなし）。

- 画像: 約1.5秒かけて、不透明度0・ぼかし6px・やや暗い状態から元の絵へ戻る（第1章は白地のため暗くしない）。
- もや: 画像の手前に下ほど濃いもや（CSSの疑似要素。画像ファイルは増やさない）を重ね、約2.1秒で少し上へ流れながら消える。第1章は白、ほかの章は暗い紫。
- 実装: `remake/css/motions/chapter-title.css` の `.ct-reveal`。共通章題（`ui.js` の `chapterTitle()`）と第1章（`chapters/ch1-title-motion.js` の `playCh1Title()`）の両方が同じクラスを付ける。章ごとに別の動きにはしていない（第1章も今は一枚絵表示なので、同じ品位でそろえる方が保守しやすい）。
- 契約は変えない: 画像の読み込み完了後に表示、失敗・15秒のタイムアウトで文字表示へ、表示時間（第1章4.8秒・共通4.4秒・文字3.6秒）、入力シールド、SAVE・フラグ。カードの出入りの不透明度フェードも従来どおり。
- 動き軽減（prefers-reduced-motion）では画像の動きともやを出さない。
- 接続点: 新しい章の画像を `chapter-title-art.js` に登録すれば、`chapterTitle()` 経由で自動的に同じ出現になる。明るい地の絵は `data-tone="light"` を付けるともやが白になる。
