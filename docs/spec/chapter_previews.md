### 章タイトルの直後の巻頭ポエム（OSP03・OSP05・2026-11-08）

各章の章タイトル（タイトルコール）の直後に、その章の巻頭ポエムを会話エンジンで読ませる（第1章は `poem_ch1`、第2〜5章は `poem_ch2`〜`poem_ch5`）。序詩 `poem_prologue` は、タイトルから「はじめから」を選んだ直後（第1章のコールドオープンの前）。本文と意図は `brand/chant_poems.md`、台本は `data/dialogue/chapter_poems.json`（話者なしの地の文）、再生は `remake/js/scenes/chapter-poem.js`。

- 章タイトルの表示時間・入力ガード・画像失敗時の文字表示は変えない。詩は章タイトルが消えた後に始まる。
- 章ごとの `titleSeen`（第1章は `introDone`）は詩を読み終えてから立てる。詩を読み終える前に中断した再開では、章タイトルと詩をもう一度出す。読了後の再開では出さない。
- 第3章は章タイトルの出し方が3経路（章頭・出発前の準備つき・準備なしの序章）あり、どの経路でも章タイトルの直後に出す。
- 検証: `node remake/test/chapter_poems.mjs`（データ・文書との一致・接続点）、`node remake/test/browser/chapter_poems.mjs`（実際の再生順と再開）。

### 出現アニメーション（#2611・2026-11-06）

採用画像のある全章（第1〜5章）で共通の出現を使う。「煙が晴れて章題が見える」控えめな動きで、画像1枚のまま位置・大きさは動かさない（transformなし）。

- 画像: 約1.5秒かけて、不透明度0・ぼかし6px・やや暗い状態から元の絵へ戻る（第1章は白地のため暗くしない）。
- もや: 画像の手前に下ほど濃いもや（CSSの疑似要素。画像ファイルは増やさない）を重ね、約2.1秒で少し上へ流れながら消える。第1章は白、ほかの章は暗い紫。
- 実装: `remake/css/motions/chapter-title.css` の `.ct-reveal`。共通章題（`ui.js` の `chapterTitle()`）と第1章（`chapters/ch1-title-motion.js` の `playCh1Title()`）の両方が同じクラスを付ける。章ごとに別の動きにはしていない（第1章も今は一枚絵表示なので、同じ品位でそろえる方が保守しやすい）。
- 契約は変えない: 画像の読み込み完了後に表示、失敗・15秒のタイムアウトで文字表示へ、表示時間（第1章4.8秒・共通4.4秒・文字3.6秒）、入力シールド、SAVE・フラグ。カードの出入りの不透明度フェードも従来どおり。
- 動き軽減（prefers-reduced-motion）では画像の動きともやを出さない。
- 接続点: 新しい章の画像を `chapter-title-art.js` に登録すれば、`chapterTitle()` 経由で自動的に同じ出現になる。明るい地の絵は `data-tone="light"` を付けるともやが白になる。

原画と採用の正本は `asset_sources/chapter-title/ch2-5-style-studies-385-20261013/type-polish/adoption.json`。
`python3 tools/build_chapter_titles.py` は対象4枚だけをSHA256照合して無劣化WebPへ変換し、全画素一致を検証する。
採用記録の `runtime_integrated:false` は、採用画像4枚の本編表示が当時は部分導入だったことを示す記録。実際の導入は `js/core/chapter-title-art.js` と [検証記録](../qa/chapter-titles/README.md) を参照。
