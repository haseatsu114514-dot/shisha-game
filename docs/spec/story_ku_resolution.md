# 「空」の着地と第5章

正史は [物語と構成](../../brand/story_and_structure.md)。この文書は主題の実装判断を補助する。第3章の必須本編は東京到着から全国大会・帰郷まで接続。任意スポット・前夜デートと第4章以降は未接続台本。

独立した本当の自分を取り出せないことを、欠落や万能の吸収能力へ置き換えない。混ざった来歴を消さず、今いる相手と一台を作る。結論を各章で繰り返し説明せず、手つき・呼び名・話し方・休み方で見せる。

第2章は比較から会話を聞けなくなる。第3章は嘘を認め、作れない日にも関係が続く。第4章では誰かの手順を自分で選び、四人同時の競技を最後まで行う。第5章では、勝った日の大会記録に映らない生活が、今日の判断を支える。

9000にも記録を提供した作り手と、設計・加工・保守の仕事がある。環境にも適応する。機械に魂がないから負けるという説明をしない。はじめと博士の違いは、失敗を減らす仕組みと、失敗した後も座れる場の経験にある。両方を次の道具作りへ持ち寄れる。

二本ともダブルアップル単体12g。同じ客の二回の投票を合計する。二本目が良かったというだけでは総合勝利を宣言しない。負け・同数も後日談へ進む。交流人数や恋人による加点なし。

二本目前は、休憩→呼吸→相手を見る→「いつもの、少し軽めにしますか」→炭を離す→待つ。客は第3章帰郷後のtonariの客を思い出す。診断も奇跡的治癒も起こさない。

第5章の結論の独白は「混ざったままで、俺だった」一度。服に残った店の匂いもここへ一度だけ置く。その後の七人の後日談や友人の日常は、世界大会凱旋当日の続きにしない。最終場面では「世界大会の人」と呼ばれた主人公が「はじめくん」と呼ばれ、次の注文を聞く。優勝の写真を捨てる必要はない。
