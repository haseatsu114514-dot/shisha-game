## 2. 遊び方

後方視点の疑似3D（Canvas 1280×720）。本番は `COURSE_PACKS`（稜線・左のボウル・右の稜・切り替えの4本。約1,700m・同じ難易度帯でカーブと配置だけが違う）から1本をランダムに選んで滑り下りる（`pickCourse(runSeed)` は決定的。検査・単体ページは `?course=ridge` や `seed` で固定できる）。評価の境目は従来どおり `DEFAULT_SEED = 7`（コース「稜線」）。スタートの合図（3・2・1・GO、約2.4秒。時計は進まない）のあと、**ヌールと競走**する（DSR15）。

2026-11-02 オーナー「もっとスピード感やエフェクトとか派手にしたい。今シンプルすぎるからゲーム性もなんか面白くできないかな」→ 選択「空中トリック・ブースト・ヌールと競走」で、下の DSR12〜15 を足した。

| 操作 | PC | スマホ |
|---|---|---|
| 左右移動 | ← →（A/D） | 画面左下の大きな「◀ 左へ」「右へ ▶」ボタン（押している間） |
| ジャンプ | Space（↑/W） | 右下の大きな「ジャンプ／着地」ボタン。画面の上の方をタップしても同じ |
| 着地直前に姿勢を整える | 空中でもう一度 Space | 空中でもう一度ジャンプボタン |
| 空中トリック（回転） | 大ジャンプ中に ← か → を押し続ける | 大ジャンプ中に左右ボタンを押し続ける |
| ブースト | ↓（S・Shift・B） | 右下の「BOOST」ボタン（ゲージが満タンの時だけ光る） |
| やめる | Esc／「やめる」 | 「やめる」 |

- **慣性**: 横移動は加速と砂の抵抗で少し遅れてついてくる（`STEER`）。カーブでは外へ流される（下の「カーブの手応え」）。小さなホップの空中は効きが弱く、大ジャンプ中の ← → は回転に使う（横へは動かない）。
- **空中トリック（DSR13・`SPIN`）**: 大ジャンプ中に ← か → を押している間だけ縦の軸で回る（1.7回転/秒）。離すと次の半回転（180・360・540・720…）まで速く回り切る。着地の瞬間に半回転の区切りから 0.1回転以上ずれていると「回り切れず」転倒。得点は 180=150・360=400・540=700・720=1,100…（コンボ倍率がかかる）。跳んだ瞬間から押していた向きは一度離すまで回転に使わない（岩をよけながら跳んだだけで回り出さない）。ホップ・起伏で跳ねただけでは回らない。
- **ブースト（DSR14・`BOOST`）**: ゲージ（0〜1）は かすめ+0.12・大ジャンプを転ばず着地+0.05（完璧ならさらに+0.22・良いなら+0.1）・トリック 半回転ごと+0.1 で貯まり、転倒で −0.3。満タンで発動すると3秒間、速度の上限が 34→46 m/s（画面の表示で約166 km/h）になり、当たった岩は「粉砕」（+100・転ばない）。終わった後も最高速を3 m/s 以上超えている間は砕ける（終わった瞬間に目の前の岩で転ばないように）。滞空時間は通常最高速の上限を保ち、ブースト速度のぶん高さはさらに伸びる（高さのために滞空を延ばさない）。**立て直し（2026-11-10）**: 岩に当たった直後 `recoverWindow`（0.45秒）のあいだにゲージが残っていれば、ブーストで転倒を取り消して元の速さのまま加速できる（コストはゲージ全部。空なら通常の転倒）。回転の失敗では使えない。画面には「リカバリー」。**ブースト中の曲とオーラ（2026-11-11）**: ブーストの間は曲が1.18倍の速さになり（音程は保つ。約0.2秒で滑らかに切り替わり、終わると戻る。`core/audio.js` の `setBgmPlaybackRate`）、人物を揺れる炎のオーラが包む（下の「演出」）。
- **カーブと複数コース（2026-11-10）**: コースは要所のカーブ（`curveAt`、smoothstep で緩急）を持つ。描画は疑似3Dで、進路の向きに合わせて路面・岩・旗・遠景が横へずれ、人物は傾く。カーブはたまに入り、始まりと終わりはまっすぐ。先のカーブは手前の看板（`curve_left`／`curve_right`）で知らせる。
- **カーブの手応え（2026-11-11）**: オーナー「カーブがなんかほんとにしてるのか分かりづらかった」。見た目と規則の両方で「曲がっている」ようにした。
  - 見た目: 路面の曲がりを約2.8倍に（`CURVE_SCALE` 0.0016→0.0045。見た目だけの値）。曲がっている間は遠くの砂丘が横へ流れ続ける（向き1あたり `YAW_PX`=600px、空は半分。絵の端は左右反転でつなぐので途切れない）。カーブの外側の縁に小さな矢印板が約32mおきに並び、列ごと曲がって見える。カメラは内側へ傾く（最大約6度。下の角は砂を画面の外まで描いて埋める）。太陽は曲がり始めに動いて、その先は画面に残る。
  - 外へ流される力（`STEER.curveDrift`=1）: カーブでは何もしないと外へ流され（c=1・最高速で毎秒 約0.25 レーン。数秒で端の深い砂に出て遅くなる）、**曲がる向きへ切っている間は流されない**（板が砂を噛む。よける力は直線と同じなので、岩をよける難しさは変わらない）。外へ切ると流れが乗ってより速く外へ出る。
  - カービング（`CARVE`）: カーブ（|c|≥0.4）の地上で曲がる向きへ切り込んでいる間、ブーストのゲージが貯まる（毎秒+0.1×倒し量）。0.8秒ぶんごとに「カービング +30」（コンボ倍率はかかるが、コンボは増やさない）。空中・転倒中・端の深い砂では貯まらない。切り込んでいる間は体が内側へ倒れ、外側へ砂しぶきが上がり、BOOSTのゲージの縁が光る。結果画面に「カービング ○回」。
  - 案内: 本番で最初のカーブに入った時に一度だけ「カーブ！ 曲がる向きへ切り込むと、ブーストが貯まる」（3.6秒。一度切り込めたら次の滑走からは出さない）。遊び方（？）にも1行。
- **速度メーター（2026-11-10）**: 右上に km/h の数字と小さな弧のゲージ。表示は滑らかに追従し、速いと赤、ブースト中は光る。走路や障害は覆わない。文字盤背景・弧・数字は同じ中心に揃え、弧長は描画と同じ半径46で計算する。
- **ヌールと競走（DSR15・`rivalRun`）**: ヌールは同じコースを自動操作（着地が少し遅い・ブーストは使う・出だしが少しだけ速い `RIVALS.noor.startSpeed`）で滑る。決定的なので毎回同じ（固定コースで約51.1秒・転倒なし）。前後が入れ替わった瞬間（3m以上の差）に「ヌールを抜いた！／ヌールに抜かれた…」。相手がブーストしている間は相手にもオーラ（ヌールは金、なるは銀紫）。人物とは当たらず、コースの少し左を並んで滑る。先にゴールすれば勝ち（+600）。HUD の進み具合の線にヌールの印と「ヌールまで ○m／ヌールに ○m 差／ヌールと並走」。リザルトの上に「ヌールに勝った！ ○秒差」／「ヌールの勝ち あと○秒」。着地を決めてブーストを使えば勝てる、ヌールと同じ滑り（着地が遅い）では届かない、跳ばないと負ける（ボットで照合）。
- **起伏（ジャンプチャンス）**: 手前（`JUMP.bumpWindow`=0.36秒）で押すと大ジャンプ（滞空約1.1〜1.4秒・通常最高速まで速いほど長い）。押さずに乗ると小さく跳ねて少し減速（転倒ではない）。平地で押すと小さなホップ（小岩だけ越えられる。離陸・着地とも得点・コンボ・加速・ブースト回復なし。端の砂の抵抗も地上と同じなので連打で速度を稼げない）。
- **速度とジャンプの高さ（2026-11-10）**: 離陸速度で頂点を固定。大ジャンプは `1.25 + 1.1 × clamp(速度 / 46, 0, 1)`、小ホップは `0.65 + 0.35 × clamp(速度 / 46, 0, 1)`。8／15／34／46 m/s の大ジャンプは約1.44／1.61／2.06／2.35となり、ブースト中も高くなる。高度は `sin(π × 空中の経過割合) × 頂点`。空中でブーストしても軌道は飛ばない。自動の小さな跳ねは高さ0.5のまま。滞空時間・着地判定・岩の回避・採点は従来通りで、低速でもジャンプが0にならない。人物・影・相手の描画は同じ高度を使う。
- **着地**: 空中で押した時点の残り滞空時間が 0.3秒以内＝完璧（加速＋250）、0.6秒以内＝良い（+120）、押さない＝普通（少し減速）。
- **岩**: 大岩・小岩。地上で触れると転倒 → 速度42%・コンボ解除・−150点、約1.1秒で自分で起き上がる（ゲームオーバーなし）。岩のすぐ横（+0.22）を抜けると「かすめた」+60。大ジャンプ中はどの岩も越える。

## 3. 本編への接続（第4章）

- 入口は2つ。**14日のドバイ（版2・日常ループ `ch4-dubai-daily.js`）**では、ドバイの地図に「砂漠ツアーのデスク」（宿・FESTA・Dr.fookah の間）→誘いの後は「ヌールと砂丘へ」（左下＝街の外）が出る（`desertDailySpots`。行き先の処理は `performDesertSpot`）。版2より前の保存（5日の自由行動）は従来のカードの一覧（`ch4-map-model.js` → `desertDestinations`）。どちらも昼の寄り道で、大会・本線には関係しない。
- デスクの会話は時間を使わない（1日1回）。砂丘は昼だけ・1日1回。日常ループでは、外出の確定で `slot` を使い済みなので、日常ループに追加の消費をさせない（`slotsUsed: 0`）。体力は使わない（日常ループが外出のたびに経験値を足さないようにし、育成は初回完走の分だけにする）。
- **行動枠**: 砂丘へ出かけると昼の行動を1つ使う（`value.slot` を 1 にする。ラクダレースと同じ判定で、同じ日の昼にサンドボードとラクダレースの両方へは行けない）。同じ日は二度行けない（`flags._ch4_desert.lastOutingDay`）。宿で日を終えればまた行ける。日常ループ化（#2273・runDaily）の後も、同じ slot を calendar が進めるだけでよい。
- **同じ外出の中のリトライ**は何度でも、追加の消費なし（ゲームの「もう一度滑る」）。
- **記録**: `state.desert = { runs, best（readResult の形）, legacyBest（旧ルールの自己ベスト）, bestRank, firstClear: {chapter, day}, rewarded, wins }`。完走ごとに保存。途中でやめた滑走は記録しない。`wins` はヌールに勝った回数。以前の形の記録（トリック・ブースト・競走・wins が無い）もそのまま読める。2026-11-03の着地回復ルールは `rulesVersion: 2`。初回の新ルール完走時に旧bestをlegacyBestへ保管し、新旧の点数は比較しない。旧記録はメニューで別表示する。bestRankは新旧の最高ランクを維持し、Aランクの火種・初回報酬済み・勝利回数・なる解放を失わない。
- **ヌールに勝った時**: その完走のひとことは `venue_noor_result_<ランク>` の代わりに `venue_noor_race_win`（「スゴイ！ 今日は、私の負け」）。初めて勝った外出では、砂丘を下りた後・夕日の会話の前に `ch4_desert_race_first_win`（ゴールの旗の下。負けたヌールがカラク・チャイをおごる）を1回だけ読む。好感度・報酬は変えない。
- **報酬（初回完走だけ）**: `core/growth.js` の `awardActionExp({ key: "desert_ride", place: "dubai_dunes", person: "noor" })`（心得の盤 `GROWTH_BOARD` が有効な時だけ経験値が入る。無効なら何も入らない）。2回目以降は呼ばない（`rewarded`）。能力値の直接加算（`earnStat`/`applyStats`）はしない。Aランク以上の自己ベストで、寝る前の「遊びのご褒美」（`growth-board-data.js` の `PLAY_REWARDS` `desert-a`: 体の火種1）。
- **SAVE/LOAD・中断**: 外出は到着の場面を読み終えた時点で確定して保存。その後に LOAD・タイトルへ戻る・再読込しても外出の消費は残り、未完走の記録は増えない。会話は読み終えた時だけ確定。
- **時系列**: 大会前提の会話（2回目・初回の夕日）は `tournament_finished`（章4）の分岐を持つ。
- 地図の座標はデスク（20,18）・砂丘（92,86）。ラクダレース（別チャット）の人物・地点とは別IDにしてある（`noor` / `tour_desk` / `dunes`）。

## 5. 14日化・ラクダレースとの関係

- 日常ループ化（#2273）では、`desertDestinations(value, day)` を昼の行き先に、`visitDesert` を `performSpot` 相当から呼び、`beginDesertOuting` が true を返したら昼の slot を進める。夜は出さない。
- ラクダレース（別チャット）とは、人物ID（`noor`）・地図ID（`tour_desk`/`dunes`）・保存キー（`flags._ch4_desert`・`state.desert`）・台詞ファイル（`ch4_desert.json`）を分けた。共通ファイルの変更は `ch4-map-model.js`（1行）・`ch4.js`（`visit()` の分岐1つ）・`growth-board-data.js`（`PLAY_REWARDS` 1行）・`growth.js`（判定1行）・`index.html`（CSS 1行）・`tools/ci/suites.json`（2件）だけ。
