## 2. 遊び方

後方視点の疑似3D（Canvas 1280×720）。本番は `COURSE_PACKS`（コースA〜D の4本。2026-11-11 オーナー「左のボウルって意味が分かりずらいのでコースAとか」で、稜線・左のボウル・右の稜・切り替えから改名。id は ridge・left-bowl・right-crest・switchback のまま。約2,000m（2026-11-13・DSR70 で 1,700m から延ばした）・同じ難易度帯でカーブと配置だけが違う）から1本をランダムに選んで滑り下りる（`pickCourse(runSeed)` は決定的。検査・単体ページは `?course=ridge` や `seed` で固定できる）。評価の境目は従来どおり `DEFAULT_SEED = 7`（コース「稜線」）。スタートの合図（3・2・1・GO、約2.4秒。時計は進まない）のあと、**ヌールと競走**する（DSR15）。

2026-11-02 オーナー「もっとスピード感やエフェクトとか派手にしたい。今シンプルすぎるからゲーム性もなんか面白くできないかな」→ 選択「空中トリック・ブースト・ヌールと競走」で、下の DSR12〜15 を足した。

- **慣性**: 横移動は加速と砂の抵抗で少し遅れてついてくる（`STEER`）。カーブでは外へ流される（下の「カーブの手応え」）。小さなホップの空中は効きが弱く、大ジャンプ中の ← → は回転に使う（横へは動かない）。
- **空中トリック（DSR13・`SPIN`）**: 大ジャンプ中に ← か → を押している間だけ縦の軸で回る（1.7回転/秒）。離すと次の半回転（180・360・540・720…）まで速く回り切る。着地の瞬間に半回転の区切りから 0.1回転以上ずれていると「回り切れず」転倒。得点は 180=150・360=400・540=700・720=1,100…（コンボ倍率がかかる）。跳んだ瞬間から押していた向きは一度離すまで回転に使わない（岩をよけながら跳んだだけで回り出さない）。ホップ・起伏で跳ねただけでは回らない。
- **ブースト（DSR14・`BOOST`）**: ゲージ（0〜1）は かすめ+0.04〜0.14（近いほど大きい。下の「岩」）・大ジャンプを転ばず着地+0.05（完璧ならさらに+0.22・良いなら+0.1）・トリック 半回転ごと+0.1 で貯まり（**2026-11-13・DSR67**: 滑りの中で貯まる量には一律に `CHARGE`=0.85 を掛ける＝それまでより約15%ゆるやか。オーナー「ブーストの溜まり具合をもう少しだけゆるやかに全体で」。練習の説明が渡す量には掛けない）、**使わないと減る（2026-11-13・DSR65）**: 最後に貯まってから 2.5秒たつと、毎秒 0.033 ずつ減る（満タンから空まで約30秒。ブースト中は減らない）。オーナー「ブーストは使わないとじわじわ減ってく仕様も欲しい」。転倒で −0.3。ただし転倒前の半分は残す（0なら0のまま）。通常のブーストはゲージが目印（`BOOST.minGauge` = 0.3）以上で発動し、未満で押すとゲージが短く反応する。残量に比例して加速し、満タンなら3秒間、速度の上限が 34→46（内部の単位。画面の表示で約67→91 km/h）になり、当たった岩は「粉砕」（+100・転ばない）。**代償（2026-11-13・DSR56）**: 砕くたびにブーストの残りが 0.35 秒減り（残り 0.2 秒までは削らない）、端の深い砂（|x|>0.86）に入るとその場で切れる（「深い砂でブースト切れ…」）。よけて、カーブでは切り込んで進むほど長く速い。終わった後も最高速を3 m/s 以上超えている間は砕ける（終わった瞬間に目の前の岩で転ばないように）。滞空時間は通常最高速の上限を保ち、ブースト速度のぶん高さはさらに伸びる（高さのために滞空を延ばさない）。**立て直し（2026-11-10）**: 岩に当たった直後 `recoverWindow`（0.45秒。練習は 0.9秒。転倒の止め 0.12秒の間は時計が進まないので、押せる実時間はそのぶん長い）のあいだは、転倒前にゲージが少しでもあれば、ブーストで転倒を取り消して元の速さのまま加速できる（コストはゲージ全部。空なら通常の転倒）。回転の失敗では使えない。画面には「リカバリー」。立て直せる間は、転んだ人物の頭の上に緑の札「↓ BOOST で立て直せ！」が出て、BOOST ボタンが緑に光る（DSR57）。**ブースト中の曲とオーラ（2026-11-12）**: 速度・ブーストによるBGMのテンポ変更は廃止。曲は通常の速さを保ち、人物の炎のオーラと効果音で加速を伝える（下の「演出」）。
- **カーブと複数コース（2026-11-10）**: コースは要所のカーブ（`curveAt`、smoothstep で緩急）を持つ。描画は疑似3Dで、進路の向きに合わせて路面・岩・旗・遠景が横へずれ、人物は傾く。カーブはたまに入り、始まりと終わりはまっすぐ。先のカーブは手前の看板（`curve_left`／`curve_right`）で知らせる。
- **カーブの手応え（2026-11-11）**: オーナー「カーブがなんかほんとにしてるのか分かりづらかった」。見た目と規則の両方で「曲がっている」ようにした。
  - 見た目: 路面の曲がりを約2.8倍に（`CURVE_SCALE` 0.0016→0.0045。見た目だけの値）。曲がっている間は遠くの砂丘が横へ流れ続ける（向き1あたり `YAW_PX`=600px、空は半分。絵の端は左右反転でつなぐので途切れない）。カーブの外側の縁に小さな矢印板が約32mおきに並び、列ごと曲がって見える。カメラは内側へ傾く（最大約6度。下の角は砂を画面の外まで描いて埋める）。太陽は曲がり始めに動いて、その先は画面に残る。
  - 外へ流される力（`STEER.curveDrift`=1）: カーブでは何もしないと外へ流され（c=1・最高速で毎秒 約0.25 レーン。数秒で端の深い砂に出て遅くなる）、**曲がる向きへ切っている間は流されない**（板が砂を噛む。よける力は直線と同じなので、岩をよける難しさは変わらない）。外へ切ると流れが乗ってより速く外へ出る。
  - カービング（`CARVE`）: カーブ（|c|≥0.4）の地上で曲がる向きへ切り込んでいる間、ブーストのゲージが貯まる（毎秒+0.1×倒し量）。0.8秒ぶんごとに「カービング +30」（コンボ倍率はかかるが、コンボは増やさない）。空中・転倒中・端の深い砂では貯まらない。切り込んでいる間は体が内側へ倒れ、外側へ砂しぶきが上がり、BOOSTのゲージの縁が光る。結果画面に「カービング ○回」。

## 3. 本編への接続（第4章）

- 入口は2つ。**14日のドバイ（版2・日常ループ `ch4-dubai-daily.js`）**では、ドバイの地図に「砂漠ツアーのデスク」（宿・FESTA・Dr.fookah の間）→誘いの後は「ヌールと砂丘へ」（左下＝街の外）が出る（`desertDailySpots`。行き先の処理は `performDesertSpot`）。版2より前の保存（5日の自由行動）は従来のカードの一覧（`ch4-map-model.js` → `desertDestinations`）。どちらも昼の寄り道で、大会・本線には関係しない。
- デスクの会話は時間を使わない（1日1回）。砂丘は昼だけ・1日1回。日常ループでは、外出の確定で `slot` を使い済みなので、日常ループに追加の消費をさせない（`slotsUsed: 0`）。体力は使わない（日常ループが外出のたびに経験値を足さないようにし、育成は初回完走の分だけにする）。
- **行動枠**: 砂丘へ出かけると昼の行動を1つ使う（`value.slot` を 1 にする。ラクダレースと同じ判定で、同じ日の昼にサンドボードとラクダレースの両方へは行けない）。同じ日は二度行けない（`flags._ch4_desert.lastOutingDay`）。宿で日を終えればまた行ける。日常ループ化（#2273・runDaily）の後も、同じ slot を calendar が進めるだけでよい。
- **同じ外出の中のリトライ**は何度でも、追加の消費なし（ゲームの「もう一度滑る」）。
- **記録**: `state.desert = { runs, best（readResult の形）, legacyBest（旧ルールの自己ベスト）, bestRank, firstClear: {chapter, day}, rewarded, wins }`。完走ごとに保存。途中でやめた滑走は記録しない。`wins` はヌールに勝った回数。以前の形の記録（トリック・ブースト・競走・wins が無い）もそのまま読める。2026-11-03の着地回復ルールは `rulesVersion: 2`。初回の新ルール完走時に旧bestをlegacyBestへ保管し、新旧の点数は比較しない。旧記録はメニューで別表示する。bestRankは新旧の最高ランクを維持し、Aランクの火種・初回報酬済み・勝利回数・なる解放を失わない。
- **ヌールに勝った時**: その完走のひとことは `venue_noor_result_<ランク>` の代わりに `venue_noor_race_win`（「悔しいけど、今日は私の負け。次は負けないからね」）。初めて勝った外出では、砂丘を下りた後・夕日の会話の前に `ch4_desert_race_first_win`（ゴールの旗の下。負けたヌールがカラク・チャイをおごる）を1回だけ読む。好感度・報酬は変えない。
- **報酬（初回完走だけ）**: `core/growth.js` の `awardActionExp({ key: "desert_ride", place: "dubai_dunes", person: "noor" })`（心得の盤 `GROWTH_BOARD` が有効な時だけ経験値が入る。無効なら何も入らない）。2回目以降は呼ばない（`rewarded`）。能力値の直接加算（`earnStat`/`applyStats`）はしない。Aランク以上の自己ベストで、寝る前の「遊びのご褒美」（`growth-board-data.js` の `PLAY_REWARDS` `desert-a`: 体の火種1）。
- **SAVE/LOAD・中断**: 外出は到着の場面を読み終えた時点で確定して保存。その後に LOAD・タイトルへ戻る・再読込しても外出の消費は残り、未完走の記録は増えない。会話は読み終えた時だけ確定。
- **時系列**: 大会前提の会話（2回目・初回の夕日）は `tournament_finished`（章4）の分岐を持つ。
- 地図の座標はデスク（20,18）・砂丘（92,86）。ラクダレース（別チャット）の人物・地点とは別IDにしてある（`noor` / `tour_desk` / `dunes`）。

## 砂流れ・本番の文字・ヌールの練習（2026-11-25・DSR86〜DSR88）

## 派手なアクション: 図解の絵に、実際の滑走を近づける（2026-11-27・DSR99）

オーナー「サンドレースも見本みたいな派手なアクションをちゃんと実際できるようにしたい」。見本＝遊び方の図解の絵（DSR98）。実際の滑走を上手なボットに走らせて各アクションの瞬間を撮り、図解と見比べた。差が大きかったのは、**大ジャンプが低く見える**（人物を少し持ち上げるだけで、地面も影も動かない。踏み切りは音と「JUMP!」だけ）・**跳ね上げた砂が見えない**（淡い砂煙だけで、明るい砂の上に溶ける）の2つ。規則（当たり判定・得点・時間）は変えず、見た目だけを足した（`remake/js/minigames/desert-ride.js`。数値は `FEEL` の末尾）。

- **大ジャンプ**
  - 人物は跳んだ高さの `airLift`（1.15）倍だけ持ち上げて描く（それまで 0.9）。同時に、跳んだ高さの `airRise`（0.5）倍だけ**カメラも上がる**（`view.rise`。上限 `airRiseMax` 1.6m）。地面・走路・相手・岩が下へ遠ざかり、高く跳んで見える。地平線と遠くの砂丘は動かない。
  - **踏み切りの砂**（`takeoffSand`）: 板が砂丘の肩を蹴って、砂煙（`takeoffSand` 34粒）と砂つぶ（`takeoffStreaks` 44本）を後ろへ扇に跳ね上げる。視界も一瞬広がる（`takeoffKick`）。
  - **上っている間**は、板に乗った砂がこぼれ落ちて尾を引く（`airTrail`／秒）。空に風の線が流れる（`airLines`。頂点で最も多い。画面の中央は今までどおり空ける）。
  - **影**: 高く跳んでも地面に影が残る（それまでは 2.5m で濃さ 0.12 まで薄れて、ほとんど見えなかった。下限 0.26）。
- **スピン**: 回っている間、板の先から砂つぶが横へ飛ぶ（`spinSpray`／秒）。半回転ごとに、体のまわりへ金のきらめきが散る（`spinSparks` 粒。輪は足していない）。
- **ブースト**: 板の左右へ、砂の波が低く広がる（`boostWake`／秒。発進の直後ほど多い）。発進の瞬間は砂を大きく蹴り（`boostKickSand`）、左右へ砂つぶが鋭く飛ぶ。**走路の先と人物を隠さない高さ**にしてある（2026-11-13「ブースト中のオーラのせいで画面見づらい」を守る。オーラの強さ・炎の絵を読み込まない決まりは変えていない）。
- **鋭く切った時**（よける・寄せる）: 板の外の縁から、砂つぶが外へ飛ぶ（`steerRoost`／秒）。カービングの演出（DSR90〜93）は変えていない。
- **砂つぶ**（粒の種類 `grain`）: 濃い砂色の芯に明るい縁を重ねた短い線（動きのぶれ）。明るい砂の上でも、空の前でも見える。重さは砂の筋と同じ。粒の上限（360）は今までどおり。
- **動き軽減**では、カメラは上げず、人物の持ち上げは 0.9 のまま、足した砂つぶ・きらめき・風の線は出さない（踏み切りの砂煙だけ 8粒）。
- 本番に説明の文字は足していない（DSR87）。カービングに輪・楕円は足していない（DSR93）。
- 検査用の入口 `__desertRide.fx` に `rise`（カメラの上がり・m）・`grains`・`puffs` を足した。
