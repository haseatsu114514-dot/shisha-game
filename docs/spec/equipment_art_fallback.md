# 機材の絵が無いときの表示（装備画のフォールバック）と「博士の試作HMD」（M-W9）

- Issue #2922（M-W9 装備画のフォールバック仕様）。もとは PR #2833 の「残した範囲」3番と、判断デスクの DC-3 の2番（「`data/equipment.json` に機材が無く、機材の絵も無い。機材として追加するか、効果自体を見直すかの判断が前提」）
- 状態: **仕様案**（Draft PR）。PR のマージで採用とする。判断点は末尾の「判断点」にまとめ、本文は推奨案で書く
- 現行の挙動は main `56cff05cf` のコードで確かめた（行番号はその時点のもの）
- ここで決めるのは、絵の扱いと、データでどう見分けるかだけ。試作HMD の熱の性能（適温幅・熱の安定）や、授業の習得で手に入れる処理は M-W9 の効果の接続（SPEC 2.6・C5）で決める

## 1. 結論（推奨案）

1. **新しいプレースホルダ画像は作らない。** 絵の無い機材は、ショップにある文字の札（`.shop-type-mark`。HMD なら「HMD」）をそのまま使う。HMD の5つのうち3つ（タヌキッシュリッド・アマバースト・ビッグタヌキッシュリッド）が、もうこの形で出ている
2. **「博士の試作HMD」は絵が無いまま機材として足してよい。** 絵が無いことは M-W9 の実装を止める理由にならない（DC-3 の2番の前提は「機材として足す」で済む。SBD92 のオーナー採用文「HMDに『博士の試作HMD』を選べる」とも合う）
3. **ほかの HMD の絵を流用しない（`art` で別の機材を指さない）。** 台詞では「見たことない形のHMD」「蓋の裏には、細かい刻みが渦のように入っていた」とある。ロートスなどの絵を出すと、台詞と見た目が合わなくなる
4. 絵が後で届いたら、ショップの機材の絵の表（`SHOP_EQUIPMENT_ART`）に1行足すだけで、文字の札から絵に替わる。データ（`equipment.json`）とセーブは変えない

## 2. 適用範囲

### 2.1 機材の種類

`data/equipment.json` の機材すべて（`bowl`・`hms`・`charcoal`・`homeware`・`pipe`）。主な対象は、これから足す「博士の試作HMD」（`hms`）。フレーバーの箱絵（`flavorPackageArt`）は対象外で、今の仕組み（植物画 → 文字「フレーバー」）のまま。

### 2.2 機材が出る画面と、いま絵を使っているか

| 画面 | 場所（コード） | 機材の絵 | 試作HMD での扱い |
|---|---|---|---|
| ショップの品ぞろえ・詳細 | `daily/shop.js` の `productRow`・`detail`（`productArt`） | 使う | **出ない**（非売品にする。`forSale` は `not_for_sale` を外す。`shop.js:76`） |
| ショップの「売る」一覧 | `daily/shop.js:314-325` の `sellRows`（`productArt`） | 使う | **出る**（持っていて装備していない時）。絵が無いので文字の札「HMD」 |
| 制作の機材選び | `craft/steps.js:99-142` の `stepSetup`（`choose`） | 使わない（名前と説明の文字だけ。`steps.js:68-88`） | 名前と説明の文字。変更なし |
| 制作の「一式の性能」・「性能を見比べる」 | `craft/equipment-preview.js`・`craft/flavor-guide.js` の `equipmentGuide` | 使わない（文字の表） | 文字の表。変更なし |
| 作業台の一台（リグ） | `craft/art.js` の `buildRig` | ボウル・炭・アルミだけ。**HMD は描いていない** | 描かない。変更なし |
| MENU の持ち物・ステータスの持ち物 | `daily/menu.js:418-420`・`daily/status.js:294-295` | 使わない（名前の札） | 名前の札。変更なし |
| 贈り物の演出 | `motions/gift.js`（`giftOpen`） | ボウルの絵だけ | **使わない**（2.3） |
| くじの景品 | `daily/kuji.js` | 機材の絵は使わない | 景品にしない |
| 心得の盤の授業の札 | `daily/growth-board-screen.js:80` | 博士の顔アイコン | 変更なし（機材の絵ではない） |

試作HMD の絵の欄があるのは、実際には **ショップの「売る」一覧だけ**。そこも、すでにある文字の札で足りる。

### 2.3 贈り物の演出を使わない理由

`motions/gift.js:31` の `bowlFile` は、`art` の無い機材を素焼きハガルの絵（`bowl_empty_clay.png`）で描く。HMD をこの演出に通すとボウルが出てしまう。試作HMD を受け取る場面は、授業の台詞（「博士が、鞄から銀色の蓋を一つ取り出した」）が受け持つ。`gift` の項目は付けず、`giftOpen` も呼ばない。

## 3. 絵が無いときの見た目（いまの規格をそのまま正本にする）

ショップの `productArt` の `textArt`（`daily/shop.js:128-138`）と `.shop-type-mark`（`css/shop.css:35-38`）。

- **形**: 角丸の枠の中に、種類の名前を中央に置く。幅58px・高さ44px、角丸8px、枠線1px `#baa5c3`、文字の色 `#795c8c`、`--font` 17px、字間 .04em。外側の箱（`.shop-product-art`）は76×66px。スマホでは文字の大きさが `--shop-text` に変わる（`css/shop.css:117`）
- **文字**: `hms` は「HMD」、`homeware` は「台」、そのほかは `TYPE_LABEL`（「ボウル」「炭」）、どれにも当たらなければ「機材」。試作HMD は「HMD」
- **読み上げ**: 札は `aria-hidden`。機材の名前は隣の行（`shop-main` の `<b>`）が読むので、札に名前を重ねて書かない
- 試作であることを札に足さない（「試作」の文字や別の色にしない）。どの機材でも同じ札にして、画面の中で浮かないようにする

## 4. データでの見分け方と、絵が届いた時の差し替え

### 4.1 「絵が無い」の見分け方（いまのまま）

`productArt` は次の順に探し、どれにも無ければ文字の札にする。

1. `SHOP_EQUIPMENT_ART[item.art || item.id]`（ショップ用に作った絵。`daily/shop-equipment-art.js`）
2. `EQUIP_ART[item.art || item.id]`（作業台の素材を流用するボウル4つ。`daily/shop.js:97-100`）
3. どちらも無ければ `textArt()`

さらに、表にあっても配信に失敗した時（`<img>` の `error`）は文字の札に戻る（`windowArt` の `onerror`、`daily/shop.js:103-117`）。

**絵が無いことを示す旗は足さない。** 「表に載っていない」が、そのまま「絵が無い」になる。旗を足すと、表と旗が食い違うおそれが増える。

### 4.2 試作HMD のデータ（M-W9 の実装で足す時の決まり）

`equipment.json` に足す時、絵まわりは次のとおりにする（id は例。実装時に決めてよい）。

```json
{
  "id": "dr_kemuri_proto_hmd",
  "type": "hms",
  "name": "博士の試作HMD",
  "chapter_min": 99,
  "not_for_sale": true,
  "unsellable": true,
  "buy_price": 0,
  "sell_price": 0,
  "description": "…"
}
```

- `art` は**書かない**（別の機材の絵を指さない。1章の3）
- `not_for_sale`・`chapter_min: 99`: 専用ハガル（`suyaki_*`）と同じく、ショップの品ぞろえに出さない
- `unsellable`: 博士の手作りの試作品で、「売っていません」の台詞とも合う。「売る」一覧では文字の札「HMD」と「売却不可」になる（売れる形にするかは判断点 J3）
- `gift` は書かない（2.3。MENU の「点線の札は贈り物」にも載らない）
- `description` と熱の性能（`craft/temperature-model.js` の `EQUIPMENT_SPECS`、`craft/flavor-guide.js` の `EQUIPMENT_USE`）は M-W9 の効果の接続で決める。そこが無いと、制作の「一式の性能」の「熱の安定」が +0 と出る（`equipment-preview.js:16`）ので、機材を足す PR と同じ PR で入れる

### 4.3 絵が届いた時

1. 絵を `asset_sources/` に原画として置き、`tools/build_shop_equipment_art.py` で WebP にする（今の規格は、正方形の RGBA の原画を368px角に縮め、512px角の透明な台の中央に置く。中身の範囲 `box` を測って表に書く）。このツールは採用した id の一覧を固定で確かめているので、一覧に試作HMD を足す
2. `daily/shop-equipment-art.js` の `SHOP_EQUIPMENT_ART` に `"<id>": { url, size: [512, 512], box: [...] }` が1行増える
3. これだけで、「売る」一覧の文字の札が絵に替わる。`equipment.json`・セーブ・制作の処理は変えない
4. 作業台の一台に HMD を描くことは、この仕様では決めない（今はどの HMD も描いていない。描くなら、全部の HMD をまとめて別に決める）

## 5. いまある、ほかのフォールバックとの関係

| もの | 絵が無い・読めない時 | この仕様との関係 |
|---|---|---|
| ショップの機材（`productArt`） | 種類の文字の札。配信の失敗も同じ札 | **正本**。このまま試作HMD にも使う |
| ショップ・制作の葉選びのフレーバー（`flavorPackageArt`） | 植物画 → 文字「フレーバー」 | 同じ考え方（新しい絵を作らず文字の札） |
| 作業台のボウル（`craft/art.js` の `BOWL_ART`） | 表に無いボウルはシリコンボウルの絵で描く（`art.js:83・89・109・133`） | 使わない。HMD は作業台に描かないので当たらない。※雲窯ファンネルハガルは `BOWL_ART` に無く、今は作業台でシリコンボウルの絵になる（この仕様の範囲外。気づいた事として記録） |
| 作業台の素材（`artImg`） | 灰色の箱 `div.art-missing` | 使わない（作業台の素材が見つからない時の非常用で、見せる前提の形ではない） |
| 心得の盤の授業の札（顔アイコン） | 顔が無い・読めない時は名前の1文字（SPEC 2.6） | 別の物（人の顔）。考え方（文字に倒す）は同じ |
| 贈り物の演出（`gift.js`） | `art` が無いと素焼きハガルの絵 | 試作HMD では使わない（2.3） |

いまテストで確かめているもの: `remake/test/browser/shop_ui.mjs:28,139-146`（絵の無い HMD は文字の札「HMD」で、`<img>` が無い）、`shop_ui.mjs:171-186`（絵の配信を止めると文字の札に戻る）、`premium_shop.mjs:32`（台の絵が届くまで文字の札「台」）。

## 6. 実装の切り分け（実装 Issue の素案）

M-W9 の効果を接続する Issue（#1801 の残りの1つ）に、次の受入条件を足す。絵のための Issue は新しく立てない。

1. **機材を足す**（データ）: 4.2 のとおり `equipment.json` に試作HMD を足す。`art`・`gift` は書かない。熱の性能（`EQUIPMENT_SPECS`）と使い方の文（`EQUIPMENT_USE`）を同じ PR で入れる
2. **習得で手に入れる**（M-W9 の効果）: `lesson_dr_kemuri_hmd` を最後まで読んで習得したら `state.owned` に足す。重ねて足さない。`giftOpen` は呼ばない
3. **テスト**（`shop_ui.mjs` か、M-W9 の新しいテスト）: 試作HMD を持っていて装備していない時、「売る」一覧の行が文字の札「HMD」で `<img>` が無く、「売却不可」であること。ショップの品ぞろえに出ないこと。制作の機材選びで選べること
4. **絵（任意・後回し）**: 判断点 J2 で作ると決まった時だけ、4.3 の手順で足す。足した後は 3 のテストを「絵が出る」に替え、配信を止めたら文字の札に戻る確かめ（`shop_ui.mjs:171-186` と同じ形）を足す

ゲームのコードは、この仕様の PR では変えない。

## 判断点

推奨は本文に書いたとおり。覆す場合は、その番号の欄を変える。

- **J1 絵の無い時の見た目**
  - (a) いまの文字の札「HMD」をそのまま使う（**推奨**。HMD の5つのうち3つがすでにこの形で、テストもある）
  - (b) 新しいプレースホルダ画像（HMD の影絵など）を作り、絵の無い機材すべてに使う（画像の発注と、3つの HMD・台・パイプの見た目の変更が要る）
  - (c) ほかの HMD の絵を `art` で流用する（台詞の「見たことない形」と合わないので推奨しない）
- **J2 試作HMD の絵を発注するか**
  - (a) 今は作らない。出る所が「売る」一覧の札だけで、文字の札で足りる（**推奨**）
  - (b) 作る。4.3 の規格（512px角の WebP、中身は368px角の中）で、台詞の「銀色の蓋」「裏に渦の刻み」「縁に日付の違う傷」に合わせる
- **J3 売れるか**
  - (a) 売れない（`unsellable`。**推奨**。手作りの試作品で、台詞も「売っていません」）
  - (b) 中古で売れる（ほかの HMD と同じ）。売った後に取り戻す方法が無いので、授業で得た物を失える形になる
