# tonari フロア営業 — バイトを「一人で店を回す遊び」にする（2026-11-20・TFL01〜）

オーナー「バイトパートを龍が如く0や極2にあるキャバクラ経営ゲームみたいにしようと思ってます」（2026-11-20）から始まった。同日の「一人でワンオペで回す」（TFL14）、「原価とか仕入れとか利益とかは気にしない。ただ満足させて売上をいかに上げるかのゲームにする」（TFL20）を経て、いまの形は同日のこの指示で決まっている（TFL22〜28）:

> 一旦はシステムをしっかり作っていくことにします。見た目は後回しに。／今までの店の画面も使いたいからこの時のデザインや配置を元にやりたい。／延長という言葉をおかわり中にしたりとか細かい部分をシーシャの世界観に合わせて。／顔マークは◎○△の中に顔を描いたりとか少し見た目を調整。／シーシャってお客さんが言わなくても調整に行く必要はあるから、そこはゲームに落とし込みたい。プラスで熱下げて欲しいとかリクエスト入れてもいい。／この卓はどんな気分で来てるかを出して、提供するシーシャはミックス一覧が並んでてそこから選ぶ感じ（キャバ嬢の代わりにミックス名）。ミックス一覧はかなり種類あって全部は出せないからシャッフル機能もある。／〇〇単体でとかそういうリクエストは無くす。フルーツ系が吸いたいとかお菓子系が吸いたいとか吹き出しで言うぐらいにする。スイートとかリラックスとかそういうのを出す。

この文書は、実装した形の仕様の正本。試遊で変えたらここを直す。

## 1. 遊びの芯と、原作との対応

**一人で全卓を見る**／**客は気分を言うだけ。並んでいるミックスの中から、気分に合う一台を選んで出す**／**仕込みは自動で進むので、その間にほかの卓へ回る**／**炭は、頼まれる前に自分から整えに行く**／**おかわりは誘わず、満足した客が自分から言い出す**／**フィーバーは3段**。

| 原作の営業パート | この遊び | 補足 |
|---|---|---|
| 客の好み（キュート・ビューティなど）が卓に出る | **客の気分**が卓の札に出る: **フルーティ／スイート／リフレッシュ／リラックス** | 客は来店の時に吹き出しで一言だけ言う（「フルーツ系が吸いたいな」「お菓子系が吸いたい」）。フレーバーの名指し・NG・おまかせは無い（TFL28） |
| 控えのキャストの列から、合う人を選んで付ける | **ミックスの一覧**（5つ並ぶ）から、合う一台を選んで出す。ミックスごとに**メインの属性（大きい印）とサブの属性（小さい印）**があり、客の気分と同じ印の札を出す（◎・○） | ミックスは34種あって全部は並ばない。**シャッフル**で5つとも入れ替える（TFL27・29・30） |
| 付けたキャストは列から外れる | 出したミックスは一覧から外れ、山から次の一つが入る | 山が尽きたら、並んでいない物から組み直す |
| 客からのサイン（おしぼり・灰皿など）に応える | **頼み**（煙が薄い・熱を下げて・喉が渇いた・むせている・話したそう）に、5つの手から選んで応える | §3「頼み」 |
| （無い） | **炭の調整**: 炭の残りが少なくなったら、客が何も言わなくても自分から行く。行かないと、客のほうから頼まれる | シーシャならではの手入れ（TFL26） |
| 延長 | **おかわり**（トップ替え・＋1,500円） | 「延長」という言葉は使わない（TFL24） |
| 満足の顔（5段） | **◎ ○ △ ▽ ◇ の形の中の顔**（大満足・満足・普通・不満・激怒） | TFL25 |
| フィーバー | 同じ（3段。Lv1＝2卓／Lv2＝4卓／Lv3＝全卓） | |
| 会計 | 卓を押すだけ（選ばない）。ファンは満足の段で決まる | TFL20 |

- 卓は**5つ**。店の画面は、**今までの店内（会話用の店内画に卓の札を重ねる形）のデザインと配置**を元にする（TFL23）。
- 単価: シーシャ一台2,000円・チャージ700円（ひとり）・おかわり（トップ替え）＋1,500円・ドリンク600円（TFL12）。**仕入れ・原価・利益は扱わない**（TFL20）。
- スミさんは営業に出ない（奥で帳簿をつけている）。助言の代わりに、はじめの心の声（今いちばん先に見る所）が下の帯に出る。スミさんの一言は、締めの精算にだけ出る。

入れていないもの: フレーバーを自分で組む調合・定番（プリセット）の登録（TFL27 で、一覧から選ぶ形に替えた）、名指しの注文（TFL28）、仕入れ・原価・利益、ライバル戦、キャストの育成にあたる成長、常連帳（#1267）。店のファンは**合計の数だけ**を持ち越す（誰が常連かは持たない）。

**満足させて、売上を上げる遊び**（TFL20）: お金の出入りは売上だけ。売上は、卓を早く回す（注文を待たせない・会計をすぐ受ける）・満足を上げて追加ドリンクとおかわりを引き出す・フィーバーで伸びる。東京編・ドバイ編でほかの店のバイトをする時も同じ遊びを使えるよう、店ごとの事情を持ち込まない。いま開いているのは第1〜2章の tonari だけ（ほかの章は §8）。

守ったこと: 常連帳・職場の好感度を作らない（#1267）。チップを描かない（売上ボーナスは店から）。失敗で日当・体力・交友は減らない。本編の人物は、たまに遊びに来るだけで、好感度は動かない（§3「レアな来店」）。いつものシフト（短い接客）はそのまま選べる。画面の構成は原作の営業パートに寄せ、絵・ロゴ・固有の意匠は写さない。

## 2. 入口と本編への接続

- 勤務札に「フロアを任される（バイト）」。**第1〜2章**（はじめがバイトとして立つ間）で、最初のシフトを一度済ませた後に出る。第3章以降はいつものシフトだけ。
- 行動枠・体力・能力の伸び・経験値・シフト上がりのスミさんの会話は、いつものシフトと同じ。同じ日にどちらか一方。
- 流れ: 前掛けの一行 → （はじめての日だけ）スミさんの `tonari_floor_first`（「今日は、店を一人で回してみろ」）／二回目から `tonari_floor_start` → その日の接客の話（カメオ・抽選の接客） → **フロア営業** → 閉店の一行・日当 → スミさんの会話。
- フロア営業は「今日の注文」（#1073）の代わり。ワンオペの営業は、その日の注文の記録（`_shift_order_`・`_shift_mix_`）に触れない（想起 #1415 は、いつものシフトでだけ進む）。
- 本編の常連の話として入るシフト（`story`）と、スミさんに呼ばれたシフト（`called`）は、いつものシフト。
- 営業中は保存しない（途中の体力や訪問記録だけが残らないよう、`holdActionSave`）。本編メニューは休止の窓から開け、離れると勤務前の保存へ戻る。LOAD・タイトルへ戻った時は何も残さない。
- 保存する値は `state.flags._tonari_floor = { nights, best, fans }`（回した回数・いちばん良かった評価・店のファンの合計）。SCHEMA は上げない。前の形で保存された `presets`（定番ミックス）は読み飛ばし、次の保存で消える。

## 3. 一回の営業

時間は刻み（tick）で進む。1刻み＝実時間0.5秒。営業は320〜384刻み（2分40秒〜3分強）。操作は刻みを使わない。

卓ごとの段階と、押した時に起きること:

| 段階 | 卓の札の見出し | 押すと |
|---|---|---|
| 空席 | （空席） | 何も起きない。客は来たら自分で座る（番号の若い空席から） |
| 注文待ち | 注文（残り秒が減っていく） | **ミックスの列**が開く（接客ビュー。時間停止）。右の一覧から押せば、列を開かずにそのまま出せる |
| 仕込み | 仕込み中／順番待ち（進みの棒） | 何も進まない。仕上がると自動で卓へ運ばれる |
| くつろぎ | くつろぎ中／おかわり中（円＝滞在の残り、棒＝炭の残り） | 「炭はまだ大丈夫」と出るだけ |
| 調整どき | **炭の調整**（炭の残りが35%を切った時） | **その場で炭を整える**（ひと押し。選ばない） |
| 頼み | 頼みの言葉、または「様子が変だ」 | 接客ビューが開く。5つの手から選ぶ。正解は◎、外すと× |
| 会計 | 会計 | その場で会計する（ひと押し。選ばない） |
| 片付け | （片付け中） | 3秒で空席に戻る |

- **客の気分（＝ミックスの属性）**: 4つ。色と印が決まっている。来店の時に卓の上の吹き出しと出来事の行で一言だけ言い、注文を聞くまで卓の札の帯に色・印・名前が出ている。どの気分で来るかは、客の種類に関係なく4つから同じ割合で決まる。

  | 気分 | 色 | 印 | 客の一言 |
  |---|---|---|---|
  | フルーティ | 橙 | りんご | 「フルーツ系が吸いたいな」 |
  | スイート | 桃 | 包みのあめ | 「お菓子系が吸いたい」 |
  | リフレッシュ | 水色 | 雪の結晶 | 「さっぱりしたのが吸いたいな」 |
  | リラックス | 藤 | 三日月 | 「まったりできるのがいいな」 |

- **ミックス**: 34種（材料は30種のフレーバーから1〜2種。「レモンミント」「ミルクティー」「ダブルアップル」など）。実在の銘柄名は使っていない。
- **ミックスの属性**（2026-11-20 オーナー「一目で何属性がメインなのかわかりやすくして」・TFL29）: どのミックスにも**メインの属性が一つ**あり、**サブの属性**を一つ持つ物もある（持たない物もある）。合い方はこの二つだけで決まる: **客の気分がメインと同じ＝◎／サブと同じ＝○／どちらでもない＝×**（△は無い）。属性はミックスごとにデータで決めてあり（`MIXES` の `main`・`sub`）、材料の系統にある属性から選ぶ。目安は「〜ミント＝リフレッシュがメイン」「〜ミルク・〜バニラ・ハニー〜＝スイートがメイン」「茶葉・スパイス・花＝リラックスがメイン」。メインの数は、リフレッシュ10・フルーティ8・スイート8・リラックス8。
- **一覧とシャッフル**: 開店の時に34種を混ぜ、5つが並ぶ。一台出すと、その所へ山から次の一つが入る。**シャッフル**は5つとも入れ替える（並んでいた物は山の後ろへ回るので、同じ顔ぶれには戻らない）。一度使うと4秒は使えない（選んでいる間は時間が止まるので、一度の注文につき実質一回）。回数の上限は無い。
- **一台の評価**（提供した時の満足）: ◎＝90（ぴったり）／○＝72（いい感じ）／×＝30（ちがうかも）。こだわりの客（香り好きの方・年配の方）は、◎でないと少し辛い（○は−6、×は−4）。
- **仕込み**: 材料1種のミックスは5秒、2種は7秒。**同時に2台**まで。三台目は順番を待つ。
- **お代**: 注文を受けた時にチャージ（ひとり700円）と初回のドリンク（ひとり600円）、提供した時にシーシャ（2,000円）が売上に入る。追加ドリンクは600円、おかわりは1,500円。
- **くつろいでいる間**: 満足は炭が進むぶん少しずつ下がる（持続性の高いミックスほどゆるやか）。追加ドリンクは22秒ごとに抽選（大満足70%・満足40%・普通10%。客ごとに上限あり）。
- **炭の調整**（頼まれる前に、自分から行く）: 提供してから20〜25秒ほどで炭が尽きる（持続性の高いミックスほど長い）。残りが35%を切ると、卓の札が「炭の調整」に変わり、卓を押すだけで整えられる（満足＋6、フィーバーのゲージ＋8、炭は満タンに戻る）。残っているうちに押しても何も変わらない。**行かないまま尽きると**、満足−7のうえ、客のほうから「煙が薄い」か「熱を下げて」と頼まれる（下の「頼み」と同じ形で応える）。
- **頼み**（待ってくれるのは11秒。過ぎると満足−10）: 煙が薄い→炭を替える／熱を下げて→炭を下ろす／喉が渇いた→お水を出す／むせている（初めての客）→吸い方を案内する／話したそう（話好きの客）→雑談する。正解で満足＋5、外すと−8。炭に関わる頼み（煙が薄い・熱を下げて）は、正しく応えれば炭も整う。雑談がはずむと、もう一杯入ることがある。同時に頼まれるのは店全体で2卓まで。
- **おかわり**: 滞在が終わる時、大満足の客は35%、満足の客は10%で「おかわり、お願いできますか？」と言い出す（こちらからは誘わない）。トップ替え＋1,500円で、滞在が15秒延び、札は「おかわり中」になる。一卓に一度。閉店まで20秒を切ると言い出さない。
- **会計**: 卓を押すだけ（見送りの言葉は出来事の行に出る）。待ってくれるのは8秒（過ぎると満足が下がる）。ファンは満足の段で決まる（大満足＋3／満足＋2／普通＋1／不満0／激怒−2、帰ってしまった組−3）。
- **注文を待たせると**: 9秒（はじめての営業だけ15秒）で怒って帰ってしまい、ファン−3。
- **レアな来店**（TFL19）: 本編の人物が、5回に1回ほど、三組目の客として遊びに来る。来るのは**顔見知り（`met`）で好感度1以上、その章に来られる人**だけ（面識だけ・好感度だけでは来ない）。はじめての営業には来ない。卓の札とドックに顔アイコンが出て、札が金に灯る。その人の言葉で気分を言い、その人の言葉で返す。精算に「今日は、〇〇が遊びに来た」と残る。**好感度は動かさない**。台詞は大会の話をせず、大会の前後どちらでも通る（交流の時系列ルール）。
  - つむぎ（第1〜2章）: 「……はじめさん。落ち着くのを、お願いします」＝リラックス。
  - なる（第1章だけ。第2章は店を休んで修行に出ている）: 「よう、はじめ。甘いやつ、頼むわ」＝スイート。
  - アダム（第1〜2章）: 「……はじめよ。今日は、果実の煙を頼む」＝フルーティ。
  - 来る条件は `tonari.js` の `floorVisitor`、気分と台詞は `tonari-floor-data.js` の `VISITORS`。人を足す時は、その章にいるか（旅・休業）を正本で確かめる。
- **フィーバー**: ゲージは◎の一台＋14・○の一台＋7・正しいケア＋10・自分から行った調整＋8・満足以上の見送り＋4で溜まる（100で1段、最大3段）。押すと、溜まった段までを一度に使う（Lv1＝2卓／Lv2＝4卓／Lv3＝全卓。くつろいでいる卓のうち、滞在の残りが長い卓から）。16秒の間、対象の卓は満足100で固定・頼みが出ない・炭が進まない・5秒ごとに追加ドリンク。明けたあとは、元の満足＋10。
- **締め**: 全組を送り出すか、時間が来たら終わり。残った卓はその時点の満足で会計し、注文前の客は帰る（数えない）。休止の窓から早じまいもできる。

## 4. 回すほど変わるもの

`nights`（回した回数）で決まる。数値の成長・装備・解放の作業は無い。持ち越すのは、回した回数・いちばん良かった評価・店のファンの合計だけ。

| 回 | 営業 | 頼み |
|---|---|---|
| 1回目 | はじめてのワンオペ（五組・ゆっくり。注文は15秒待ってくれる）。心の声が指す卓が光り、進め方が4行出る | 吸い方の案内と、炭に関わる頼みだけ。言葉で伝わる |
| 2回目 | いつもの昼／夜（七組）。本編の人物がたまに来る | ＋喉が渇いた・話したそう。言葉で伝わる |
| 3回目 | 種から選ぶ（短い客が続く日・初めてさんの日・いつもの日。雨の日は長居の日）七〜九組 | 同上 |
| 4回目〜 | 同上 | 「様子が変だ」だけが出て、接客ビューの様子の一文から読む |
| 6回目〜 | 満席の日（十一組）が混ざる | 同上 |

勤務札には「今日の予報」（営業の種類）と、これまでの最高の評価が出る。昼のシフトは時計が12:00〜16:00、客の呼び名も昼のもの（昼休みの二人など）になる。

## 5. 評価と報酬

全組の満足の平均（帰ってしまった組は0）で決まる。

| 評価 | 条件 | 店からの売上ボーナス |
|---|---|---|
| 大入り | 88以上、かつ誰も帰していない | 1,500円 |
| 上々 | 74以上 | 1,000円 |
| まずまず | 56以上 | 500円 |
| ばたばた | それ未満 | なし |

日当（基本8,000円＋大会の実績＋魅力の指名ボーナス等）は評価に関係なくいつもどおり。店の売上とファンは、はじめの所持金には入らない。

検査用のボット（`remake/test/tonari_floor_bot.mjs`。全営業×12の種）での目安: 並んでいる中でいちばん合う一台を出し（◎も○も無ければシャッフル）、調整にも回れば大入り（平均97）。調整に行かず頼まれてから応えると、大入りと上々が混ざる（90）。合い方を見ずに一つ目を出すと、まずまずが中心（65）。8秒に1操作のほぼ放置や、わざと合わない一台を出すと、ばたばた。

## 6. 画面

構成（どこに何を置くか・選ぶ時の見せ方）は原作の営業パートに寄せ、絵そのものは本作のもの。**土台は、今までの店の画面**（会話用の店内画 `bg_tonari_inside` に、卓の札を重ねる形。`STAGES.classic`）。

**文字で説明しすぎない**（2026-11-20 オーナー「龍が如くと比べて画面が小さいので文字で説明しすぎないようにしたりアイコンにしたり」・TFL31）: 営業中の画面は、色と印で読めるようにする。言葉を出すのは、ミックスの名前・客の一言・押すと進む用件・出来事の行だけ。印だけにした所の言葉は、読み上げ（`.tf-sr`・`aria-label`）に残してある。

印の約束:

- **属性の印**（`attrBadge`）: ミックスの札の左。**メイン＝大きい角丸の札**（その気分の色に、りんご・あめ・雪・月の印）、**サブ＝右下に重なる小さい丸**。右の一覧・注文の列・仕込み中の一台・卓のドック・精算で同じ形。
- **気分の札**（`wishChip`）: 客の気分。属性の印と同じ色と印に、名前を添える。卓の札の帯・注文の列の上・卓のドック・開店前の見本で同じ形。
- 客の気分の色と、ミックスのメインの色が同じなら◎、サブの色と同じなら○。

営業中（店内の全体が見える）:

- **上の帯**: 左に**仕込み中の一台**（器の印。2枠。卓番号・属性の印・ミックス名・進みの棒。空いている枠は点線。順番待ちは「待ち N台」）、**まん中に残り時間**（時計の印と大きな数字、減っていく帯。残り30秒で赤くなる）、右に店の売上（硬貨の印と金額）と休止。
- **卓の札**: 押すと進む用件がある卓だけ、箱の上に**見出し**が出る（金＝注文・頼みの言葉・会計／橙＝炭の調整／緑＝おかわり中）。くつろいでいる卓・仕込み中の卓は、見出しを出さない（札の色と中身で分かる）。**空席の卓は、札ごと出さない**（卓の番号札だけ）。片付け中は、印だけの小さな札。
  - 箱の上の帯: **注文待ちの間だけ、客の気分**（気分の札）。出したあとは畳む。
  - 左の窓に卓番号と客。右の窓は、注文待ち＝時計の印と残り秒／仕込み中＝器の印と残り秒（順番待ちは時計の印だけ）／提供後＝満足の顔（◎○△▽◇の形の中の顔）。
  - 箱の下の棒は仕込みの進み（提供後は炭の残り）。左下の円は滞在の残り、右下の赤い札は頼み・会計を待たせている残り秒。
- **来店の吹き出し**: 客が座った時、卓の上に気分の一言が出る（出来事の行にも残る）。
- **右にミックスの一覧**（5つ）: 札の左に属性の印、まん中に名前。注文待ちの卓がある間は、**その客に合う札の右上に判（◎・○）**が付き、◎の札は金の縁で灯る。合わない札は、名前と地が沈む（属性の印は沈めない）。一覧の縁は、その客の気分の色になる。押すと、いちばん急ぎの注文待ちの卓へそのまま出す（出す先の卓は点線で囲まれる）。
  - 上の行: **出す先の卓の番号**（丸。色はその客の気分。出す先が無い間は出ない）と、**シャッフルのボタン**（金のボタン。印と名前。TFL30）。合う一台（◎・○）が並んでいない時は、シャッフルが光って知らせる。使ったあと4秒は灰色。
- **下の帯**: 左に**卓のドック**（選んでいる卓の番号・客・注文を聞くまでは気分の札／出したあとは属性の印とミックス名・硬貨の印とご利用の金額）、まん中に**出来事の行**（来店と気分の一言・仕込みはじめ・客のひとこと・調整・頼み・追加ドリンク・おかわり・会計・売上の区切り）とはじめの心の声（押すとその卓へ）、**右にフィーバーのゲージ**（3段）。

接客ビュー（注文待ち・頼みの卓を押した時。時間停止。調整と会計はひと押しなので開かない）:

- 店内がその卓へ寄る（1.3倍。選んだ卓が画面の右寄りに来る）。仕込み中の一台・右の一覧・出来事の行は引っ込み、ほかの卓の札は薄くなる。
- 左に選択肢の列（数字キーでも選べる）。列の上の札に客の言葉・様子と、気分の札。下に大きなドック（満足と滞在のゲージ・ご注文の言葉と出している一台・ご利用の金額）。
- **注文**: 並んでいる5つのミックス（左に属性の印・名前・右にこの客との合い方 ◎ ○ ×。合わない札は沈む）。下に「あとで」（閉じても注文は残る）と、金の「シャッフル」（列を開いたまま入れ替わる）。説明の文は置かない。選ぶと、仕込みが始まって閉じる。
- **頼み**: 5つの手（炭を替える／炭を下ろす／お水を出す／吸い方を案内する／雑談する）。選んだあと、判定の印（◎ ×）が列の右に大きく出て、列の上の札が客の返事に替わる。1秒で閉じ、押せばすぐ閉じる。

そのほか:

- **開店前**: 営業の種類と予報、店のファン、**気分の札の見本**（4つ）。はじめての営業だけ、進め方を4行（「客の気分と同じ印のミックスを出す」など）と、時間が止まる時の一文を出す。
