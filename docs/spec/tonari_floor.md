## 1. 何を借りて、何を変えたか

『龍が如く0／極2』の水商売アイランドの面白さは「卓が同時に埋まり、どの卓を先に見るかを自分で決める」「合図を読んで正しく応えると、その場で客の機嫌が上がる」「会計の時に客の機嫌を見て声をかけ、うまくいけば延長してもらえる」「店が盛り上がった時にフィーバーを切る」「締めで売上と評価が出る」の5つ。これをシーシャの店に置き換えた。

2026-11-20 オーナー「UIとかシステムとかこの龍が如くのキャバクラのプレイパートを参考にしてみて　ここまでスピード感はいらないけど」（『龍が如く0』の営業中の動画）を受けて、営業中の画面の組み立て（§6）と、会計の声かけ・延長（§3）を原作の営業パートに合わせた（TFL10）。速さは上げていない（選んでいる間は時間が止まり、判定の印も1秒見せる）。

| 水商売アイランド | tonari フロア営業 |
|---|---|
| 客の好みに合うキャストを着ける | 客の言葉に合う一台（配合）を3つから選ぶ。ぴったり／悪くない／外れ |
| キャストの合図（手の形）に応える | 卓の合図に、固定の5つの手入れ（炭を替える・炭を下ろす・飲み物を聞く・ひと声かける・そっとしておく）で応える |
| 卓を選ぶと、その卓へ寄って選択肢の列が出る。選んでいる間は時間が止まる | 接客ビュー（店内がその卓へ寄り、左に選択肢の列・下に客のドック）。開いている間・休止中・別タブの間は、店の時間が止まる |
| 選んだ結果が、その場で ◎○△× で出る | 合図への手入れと会計の声かけで、判定の印（◎ ○ △ ×）と客の返事が出る |
| 会計の時、客の機嫌を見て「ご延長は？」「ありがとうございました」「申し訳ありませんでした」から選ぶ | **会計の声かけ**。客の顔を見て「もう少し、いかがですか？」（笑顔＝延長してトップ替え）「ありがとうございました」（ふつう）「お待たせして、すみません」（曇り顔）から選ぶ |
| フィーバー | **ボーナスタイム**（2026-11-20 オーナー「チルタイムはボーナスタイムとかに名前変えて」で改名）。いい接客で店の空気が溜まると使える。その間は合図も待ち時間も止まり、くつろいでいる卓の満足が上がる（売上は増えない） |
| 売上・評価 | 店の売上（はじめの所持金には入らない）と、満足の平均で決まる4段の評価。評価に応じて、店からの売上ボーナスが日当に付く |
| 営業前の準備 | 3回目から、今日の段取りを一つ選ぶ（仕込み／炭／レジ） |
| リーグ・ライバル・同伴・キャスト育成 | 作らない。回した回数で営業の種類が増え、合図が「言葉」から「様子を読む」へ変わる |

#3915 の五卓案（手番制）から変えたのは**時間の流し方**。確定のたびに1手進む形は考える遊びとして筋が通っていたが、「見守る」を押して待つ時間が長く、店が動いている手触りが出なかった。原作と同じく、流れる時間＋選ぶ間だけ止まる形にした。休止の窓に「ゆっくり」（0.6倍）を置いてある。五卓・作業台1つ・受渡棚・会計と片付けの分離・人数分の席と初杯・提供した分だけの会計・引き継ぎ・営業中は保存しない、は #3921 から引き継いだ。

守ったこと: 常連帳・職場の好感度を作らない（#1267）。チップを描かない（売上ボーナスは店から）。本編の登場人物を客にしない。失敗で日当・体力・交友は減らない。いつものシフト（短い接客）はそのまま選べる。

## 2. 入口と本編への接続

- 勤務札に「フロアを任される（バイト）」。**第1〜2章**（はじめがバイトとして立つ間）で、最初のシフトを一度済ませた後に出る。第3章以降はいつものシフトだけ（店長としての営業は別の形にする余地を残す）。
- 行動枠・体力・能力の伸び・経験値・シフト上がりのスミさんの会話は、いつものシフトと同じ。同じ日にどちらか一方。
- 流れ: 前掛けの一行 → （はじめての日だけ）スミさんの `tonari_floor_first`／二回目から `tonari_floor_start` → その日の接客の話（カメオ・抽選の接客） → **フロア営業** → 閉店の一行・日当 → スミさんの会話。
- フロア営業は「今日の注文」（#1073）の代わり。その日の注文の客は、二組目として営業の中に来る。受け取った一台（`_shift_mix_<注文ID>`）は、後日いつものシフトで同じ注文が来た時の想起（#1415）へ渡る。反応の台本は営業の後には重ねない。
- 本編の常連の話として入るシフト（`story`）と、スミさんに呼ばれたシフト（`called`）は、いつものシフト。
- 営業中は保存しない（途中の体力や訪問記録だけが残らないよう、`holdActionSave`）。本編メニューは休止の窓から開け、離れると勤務前の保存へ戻る。LOAD・タイトルへ戻った時は何も残さない。
- 保存する値は `state.flags._tonari_floor = { nights, best }` だけ（回した回数・いちばん良かった評価）。SCHEMA は上げない。

## 3. 一回の営業

時間は刻み（tick）で進む。1刻み＝実時間0.5秒。営業は300〜384刻み（2分半〜3分強）。操作は刻みを使わない。

卓は五つ（今の店内画では、卓4つ＋カウンター）。卓ごとの段階と、押した時に起きること:

| 段階 | 卓の吹き出し | 押すと |
|---|---|---|
| 空席（入口に客がいる） | ご案内 | 先頭の客をその卓へ通す。来てすぐ（10刻み以内）なら満足＋5 |
| 注文待ち | 注文 | 接客ビューが開く。客の言葉と、配合3つ（ぴったり・同じ注文のもう片方・外れ） |
| 仕込み待ち | 仕込み中／順番待ち | 何も進まない（様子の一言だけ） |
| 一台が受渡棚にある | 配膳 | 運ぶ。ここで合否が分かる。外れは少し後に「相談」が出る |
| くつろいでいる | （なし。番号札から煙） | 何も進まない |
| 合図 | 合図の言葉、または「！」 | 接客ビューが開く。手入れ5つから選ぶ（選び直しはできない）。正解は◎、外すと× |
| 相談（外れた一台） | 相談 | 作り直す（お代はそのまま・先に作る）／台代を外す |
| 会計 | 会計 | 接客ビューが開く。客の顔を見て声をかける（下の「会計の声かけ」）。延長に応じた卓は、トップ替えを運ぶまでくつろぎ、あとでもう一度会計になる。それ以外は売上に入り、卓は「片付け」へ |
| 片付け | 片付け | 空席に戻る。片付けるまで次の客は通せない |

- **作業台は1つ**。伝票は来た順に作られ、14刻みで仕上がる。受渡棚は2つまでで、埋まっている間は次が出てこない。作業台の伝票を押すと、その卓を先に作る。
- **待たせすぎ**: 入口は56刻みで帰ってしまう（その組の満足は0）。注文18・提供44・会計16刻みを過ぎると、満足が少しずつ下がる。合図は28刻みで消え、満足が下がる（「夢中」の客は下がらない）。
- **満足**（0〜100）: 着席50。ぴったり＋22／悪くない＋8／外れ−14（作り直してぴったりなら＋16）。正しい手入れ＋8、外した手入れ−8。ボーナスタイム中は1刻み＋0.6。卓の札のまわりの輪と顔で見える。会計時に★1〜3（80以上で3、58以上で2）。
- **合図**（客の種類で決まる。最初の営業は上の3つだけ）: 煙が薄い→炭を替える／喉にくる→炭を下ろす／グラスが空→飲み物を聞く（もう一杯400円）／聞きたそう→ひと声かける／夢中→そっとしておく（声をかけると下がる。放っておいても下がらない）。
- **会計の声かけ**（TFL10）: 客の顔は満足の段（笑顔＝80以上／ふつう＝45以上／曇り顔＝45未満）。顔に合った一言が◎。
  - 「もう少し、いかがですか？」: 笑顔の客は延長に応じる（まん中に「延長、いただきました！」）。同じ注文のもう片方へのトップ替え（800円）を仕込み、運ぶと滞在が26刻み延びて、あとでもう一度会計になる。笑顔でない客には断られ（満足−6）、そのまま会計。延長は一卓に一度まで。閉店まで40刻みを切った時・台代を外した卓には誘えない（選択肢が押せない）。
  - 「ありがとうございました」: ふつうの顔に◎（満足＋5）。笑顔の客には○（延長の機会を逃すだけ。延長できない時は◎）。曇り顔には△。
  - 「お待たせして、すみません」: 曇り顔に◎（満足＋14）。ほかの顔には△（変化なし）。
  - ◎は店の空気＋4。はじめの2回は、選び方の一言（「顔を見て選ぶ。笑顔なら延長を誘える、曇り顔にはお詫び」）が列の上に出る。
  - 段取り「レジをスミさんに頼む」の日は、スミさんがお礼で会計する（延長は誘わない。自分で先に押せば声をかけられる）。
  - 客からトップ替えを頼む合図（旧）は無くした。延長はこちらから誘う。
- **ボーナスタイム**: 店の空気はぴったりの一台＋18、正しい手入れ＋10、すぐの案内＋4、★3の会計＋8、顔に合った声かけ＋4などで溜まり、100で使える（28刻み）。卓が埋まっている時に使うと満足が多く上がり、手が回らない時に使うと立て直せる。
- **締め**: 全組を送り出すか、時間が来たら終わり。残った卓はスミさんが引き継ぐ（提供済みの卓だけ会計・提供前の卓はお代なし）。休止の窓から自分で引き継ぐこともできる。

価格（店の売上の内訳）: 席500円／人、初杯400円／人、一台はショート1,400円・ふつう1,600円・ゆっくり1,800円、もう一杯400円、トップ替え800円。

## 4. 回すほど変わるもの

`nights`（回した回数）で決まる。数値の成長・装備・解放の作業は無い。

| 回 | 営業 | 合図 | 段取り |
|---|---|---|---|
| 1回目 | はじめてのフロア（四組・ゆっくり）。スミさんの一言が指す卓が光る | 3種・言葉で伝わる | なし |
| 2回目 | いつもの昼／夜（六組） | 5種・言葉で伝わる | なし |
| 3回目 | 種から選ぶ（短い客が続く日・初めてさんの日・いつもの日。雨の日は長居の日）六〜七組。会計の声かけの「選び方の一言」が出なくなる | 5種・言葉で伝わる | 一つ選ぶ |
| 4回目〜 | 同上 | 「！」だけが出て、接客ビューの様子の一文から読む | 一つ選ぶ |
| 6回目〜 | 満席の日（八組）が混ざる | 同上 | 一つ選ぶ |

段取り: 仕込みを先に済ませる（一台が9刻みで仕上がる）／炭を多めに熾しておく（合図を1.6倍待ってもらえる）／レジをスミさんに頼む（会計はスミさんが受ける）。

勤務札には「今日の予報」（営業の種類）と、これまでの最高の評価が出る。昼のシフトは時計が12:00〜16:00、客の呼び名も昼のもの（昼休みの二人など）になる。

## 5. 評価と報酬

全組の満足の平均（入れなかった組は0、提供前に引き継いだ組は40まで）で決まる。

| 評価 | 条件 | 店からの売上ボーナス |
|---|---|---|
| 大入り | 88以上、かつ全組を迎えて送り出した | 1,500円 |
| 上々 | 74以上 | 1,000円 |
| まずまず | 55以上 | 500円 |
| ばたばた | それ未満 | なし |

日当（基本8,000円＋大会の実績＋魅力の指名ボーナス等）は評価に関係なくいつもどおり。いつものシフトの接客の抽選ボーナス（0〜800円）より少し多く、3分遊ぶ分の上乗せにとどめた。

検査用のボット（`remake/test/tonari_floor_bot.mjs`）での目安: 1秒に1操作なら全営業で大入り、3秒に1操作・8割正解で上々〜まずまず、ほぼ放置でばたばた。延長を取りにいくと、店の売上は2割ほど増える（評価は満足の平均なので、延長しなくても大入りは取れる）。

## 6. 画面

2026-11-20 オーナー「レイアウトとかUIとかかなり龍が如くのキャバクラに寄せていい」「UIとかシステムとかこの龍が如くのキャバクラのプレイパートを参考にしてみて」。**構成（どこに何を置くか・選ぶ時の見せ方）は原作の営業パートに寄せ、絵そのものは本作のもの**にする（ほかの作品の画面・ロゴ・固有の意匠は写さない）。

営業中（店内の全体が見える）:

- **上の帯**: 左に店の時計（営業の種類・18:00〜・来店した組数）、**まん中に残り時間**（大きな数字と減っていく帯。残り30秒で赤くなる）、右に店の売上と休止。
- **卓**: 客（丸い札、または座った姿）の上に、金のマーカー（いま出来ること。急ぎの輪つき）。待ちの表示は暗い札、会計は緑。卓の番号札のまわりの青い輪は滞在の残りで、輪が無くなると会計になる。客の顔の印は満足の段。手応えは ◎○△× の印つきで卓に出る。
- **左上の下に入口の列、右上の下に作業台と受渡棚**（順番待ちの伝票は、作業台の見出しの横）。
- **下の帯**: 左に**卓のドック**（選んでいる卓の番号・客・人数とコース・ご利用の金額・顔。マウスを乗せるか、卓を押すか、矢印キーで替わる）、まん中にスミさんの一言（今いちばん先に見る所。押すとその卓へ）、**右にボーナスタイムのゲージ**（店の空気。満ちたら押せる）。

接客ビュー（注文・合図・相談・会計で、卓を押した時）:

- 店内がその卓へ寄る（1.3倍。選んだ卓が画面の右寄りに来る）。入口・作業台・スミさんの一言は引っ込み、ほかの卓の札は薄くなる。
- **左に選択肢の列**（縦に並ぶ。選んでいる行は金の札になる。数字キーでも選べる）。列の上の札に、客の言葉・様子（読むところ）と、会計では客の顔。
- **下に大きなドック**: 客の絵・呼び名・人数とコース・満足と滞在のゲージ／ご注文の言葉と出している一台／ご利用の金額／顔。
- 選んだあと、合図と会計では**判定の印**（◎ ○ △ ×）が列の右に大きく出て、列の上の札が客の返事に替わる。1秒で閉じ、押せばすぐ閉じる。延長が決まった時は、まん中に「延長、いただきました！」の札。
- 開いている間は、店の時間が止まる（「あとで」で閉じても、卓の用件は残る）。

そのほか:

- 一回押すだけで進むもの（案内・配膳・片付け）と、読んで選ぶもの（注文・合図・相談・会計）を分けた。
- **結果**: 店の売上を大きな金の数字で、評価はメダル（大入り＝金・上々＝銀・まずまず＝銅・ばたばた＝無地）。組ごとの★、ぴったり・いい手入れ・延長・ボーナスタイムの数、スミさんの一言、売上ボーナス。
- 板と札は、ゲーム共通の暗い板（`img/ui/lounge/panel.webp`）と `img/ui/craft-night/` の札・メダルを九分割で使っている（専用の部品は §7 の依頼）。
- PC は矢印キーで卓を移り、Enter で押す。Esc で休止／接客ビューを閉じる。B でボーナスタイム。列の選択肢は数字キー 1〜5。
- 横持ちのスマホ（844×390）で、押す所は実画素40px以上。`prefers-reduced-motion` では動きを止める。

## 7. 見た目の計画（専用の店内と部品）

2026-11-20 オーナー「専用の画像生成で見た目とか作って見栄えからよくしたい。内装のレイアウトは変えてもいい」「席の形は『席席席／席　席』みたいにしたい。ソファで、下の2段は内側を向いた配置で」。会話用の店内画に丸い札を重ねる今の形（`STAGES.classic`）は、絵が届くまでの仮。

- **専用レイアウト**（`STAGES.floor`）: 少し上から見た店内に、ソファの席が上に3つ・下の左右に2つ。上の3席はソファがこちら向きで卓は手前、下の2席は内向き（左のソファは右向き、右は左向き）で卓は内側。左の端が入口、右の端がカウンター（作業台と受渡棚）。
- **重ねる順**: 店内 → 客 → 前景（上の段の卓・下の段のソファの手前の肘掛け）→ 卓の上の一台と煙 → 番号札 → 卓のマーカー。上の段の客は卓が膝から下を隠し、下の段の客は肘掛けが腰のあたりを隠す。
- **客の絵は1枚に1人**（右斜め前向きの、座った全身）。上の席では横に並べ（二人組は右の人を反転して向かい合わせる）、下の席では奥と手前に重ね、右の席は反転して内側を向かせる。こうすると、1人1枚の絵でどの席にも座れる。
- 位置の正本は `tonari-floor-stage.js`。配置図と画面見本（`asset_sources/ui/tonari-floor-20261120/layout-guide.png`・`screen-mock.png`）は、同じ数値から `remake/test/tonari_floor_guide.mjs` で描いたもの。
- 依頼の順: 0 完成見本（画面全体を1枚の絵で。ここで絵柄を決める）→ A 店内（昼・夜・前景）→ B 客（15人＋笑顔15枚）→ C 卓の上の一台 → D UI の部品と記号。
- 受け口はコードに入っている: `FLOOR_ART.stage` を `"floor"` にすると専用レイアウトへ切り替わり、`FLOOR_ART.guests`（ひとりずつ。二人組は `種類-a`・`種類-b`）・`props` に絵を登録すると影絵が絵に替わる。客の絵だけ先に届いた時は、今の丸い札に顔のまわりが出る。満足が80以上の卓は、登録があれば笑顔の絵に替わる。
- 検査: `remake/test/browser/tonari_floor.mjs` の `seated-stage`（配置図の舞台で、席の形・重なりの順・マーカーの位置・絵の差し替え・接客ビューで卓が隠れないことを見る）。
