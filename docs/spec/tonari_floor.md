# tonari フロア営業 — バイトを「一人で店を回す遊び」にする（2026-11-20・TFL01〜）

オーナー「バイトパートを龍が如く0や極2にあるキャバクラ経営ゲームみたいにしようと思ってます」（2026-11-20）から始まった。同日の「一人でワンオペで回す」（TFL14）、「原価とか仕入れとか利益とかは気にしない。ただ満足させて売上をいかに上げるかのゲームにする」（TFL20）を経て、いまの形は同日のこの指示で決まっている（TFL22〜28）:

> 一旦はシステムをしっかり作っていくことにします。見た目は後回しに。／今までの店の画面も使いたいからこの時のデザインや配置を元にやりたい。／延長という言葉をおかわり中にしたりとか細かい部分をシーシャの世界観に合わせて。／顔マークは◎○△の中に顔を描いたりとか少し見た目を調整。／シーシャってお客さんが言わなくても調整に行く必要はあるから、そこはゲームに落とし込みたい。プラスで熱下げて欲しいとかリクエスト入れてもいい。／この卓はどんな気分で来てるかを出して、提供するシーシャはミックス一覧が並んでてそこから選ぶ感じ（キャバ嬢の代わりにミックス名）。ミックス一覧はかなり種類あって全部は出せないからシャッフル機能もある。／〇〇単体でとかそういうリクエストは無くす。フルーツ系が吸いたいとかお菓子系が吸いたいとか吹き出しで言うぐらいにする。スイートとかリラックスとかそういうのを出す。

## 1. 遊びの芯と、原作との対応

**一人で全卓を見る**／**客は気分を言うだけ。並んでいるミックスの中から、気分に合う一台を選んで出す**／**仕込みは自動で進むので、その間にほかの卓へ回る**／**炭は、頼まれる前に自分から整えに行く**／**おかわりは誘わず、満足した客が自分から言い出す**／**フィーバーは3段**。

| 原作の営業パート | この遊び | 補足 |
|---|---|---|
| 客の好み（キュート・ビューティなど）が卓に出る | **客の気分**が卓の札に出る: **フルーティ／スイート／刺激系／リラックス** | 客は来店の時に吹き出しで一言だけ言う（「フルーツ系が吸いたいな」「お菓子系が吸いたい」）。フレーバーの名指し・NG・おまかせは無い（TFL28） |
| 控えのキャストの列から、合う人を選んで付ける | **ミックスの一覧**（5つ並ぶ）から、合う一台を選んで出す。ミックスごとに**メインの属性（大きい印）とサブの属性（小さい印）**があり、客の気分と同じ印の札を出す（◎・○） | ミックスは80種（第1章は71種）あって全部は並ばない。**シャッフル**で5つとも入れ替えるが、**入れ替えに4秒かかる**（TFL27・29・30・33・34） |
| 付けたキャストは列から外れる | 出したミックスは一覧から外れ、山から次の一つが入る | 山が尽きたら、並んでいない物から組み直す |
| 客からのサイン（おしぼり・灰皿など）に応える | **頼み**（煙が薄い・熱を下げて・喉が渇いた・むせている・話したそう）に、5つの手から選んで応える | §3「頼み」 |
| （無い） | **炭の調整**: 炭の残りが少なくなったら、客が何も言わなくても自分から行く。行かないと、客のほうから頼まれる | シーシャならではの手入れ（TFL26） |
| 延長 | **おかわり**（トップ替え・＋1,500円） | 「延長」という言葉は使わない（TFL24） |
| 満足の顔（5段） | **◎ ○ △ の形の中の顔**（大満足＝◎／満足＝○／普通＝△／不満＝△に下がり口）と、形に入れない**怒りの印**（激怒・待たせている客） | TFL25・35・36 |
| フィーバー | 同じ（3段。Lv1＝2卓／Lv2＝4卓／Lv3＝全卓） | |
| 会計 | 卓を押すだけ（選ばない）。ファンは満足の段で決まる | TFL20 |

- 卓は**5つ**。店の画面は、**今までの店内（会話用の店内画に卓の札を重ねる形）のデザインと配置**を元にする（TFL23）。
- 単価: シーシャ一台2,000円・チャージ700円（ひとり）・おかわり（トップ替え）＋1,500円・ドリンク600円（TFL12）。**仕入れ・原価・利益は扱わない**（TFL20）。
- スミさんは営業に出ない（奥で帳簿をつけている）。助言の代わりに、はじめの心の声（今いちばん先に見る所）が下の帯に出る。スミさんの一言は、締めの精算にだけ出る。

入れていないもの: フレーバーを自分で組む調合・定番（プリセット）の登録（TFL27 で、一覧から選ぶ形に替えた）、名指しの注文（TFL28）、仕入れ・原価・利益、ライバル戦、キャストの育成にあたる成長、常連帳（#1267）。店のファンは**合計の数だけ**を持ち越す（誰が常連かは持たない）。

**満足させて、売上を上げる遊び**（TFL20）: お金の出入りは売上だけ。売上は、卓を早く回す（注文を待たせない・会計をすぐ受ける）・満足を上げて追加ドリンクとおかわりを引き出す・フィーバーで伸びる。東京編・ドバイ編でほかの店のバイトをする時も同じ遊びを使えるよう、店ごとの事情を持ち込まない。いま開いているのは第1〜2章の tonari だけ（ほかの章は §8）。

守ったこと: 常連帳・職場の好感度を作らない（#1267）。チップを描かない（売上ボーナスは店から）。失敗で日当・体力・交友は減らない。本編の人物は、たまに遊びに来るだけで、好感度は動かない（§3「レアな来店」）。いつものシフト（短い接客）はそのまま選べる。画面の構成は原作の営業パートに寄せ、絵・ロゴ・固有の意匠は写さない。

## 2. 入口と本編への接続

- 勤務札に「フロアを任される（バイト）」。**第1〜2章**（はじめがバイトとして立つ間）で、最初のシフトを一度済ませた後に出る。第1章で、本編の「常連さんの話」を次のシフトの接客として読む間（DAY2 以降で未読。#3819）は出さず、その話のシフトを済ませてから出る。第3章以降はいつものシフトだけ。
- 行動枠・体力・能力の伸び・経験値・シフト上がりのスミさんの会話は、いつものシフトと同じ。同じ日にどちらか一方。
- 流れ: 前掛けの一行 → （はじめての日だけ）スミさんの `tonari_floor_first`（前振り。下の「前振りの物語」）／二回目から `tonari_floor_start` → その日の接客の話（カメオ・抽選の接客） → **フロア営業** → 閉店の一行・日当 → スミさんの会話。
- **前振りの物語**（2026-11-20 オーナー「うちは地区でも老舗で混む店だとスミさんから説明させたい。大会の時みたいに一台ずつ向き合うというより手際の良さが大事みたいな前振り。大会とは別競技みたいな」・TFL38）: はじめての営業の前に、スミさんが話す。「うちは、この地区じゃ老舗でな。ありがたいことに、よく混む」「大会や、家で作る一台とは別物だ。一台ずつ向き合ってる暇はない」「手を抜けって話じゃない。店で要るのは、手際だ」「待たせない。炭を切らさない。卓を、まんべんなく見る」「大会とは、別の競技だと思え」。そのあと、遊び方の芯（気分を聞いて合う一台を出す・炭は言われる前に見に行く・灯りが教えてくれる）を一言ずつ。大会の前後どちらでも通る言葉にしてある（はじめの戦績には触れない）。店の設定（小さいが、橙須の地区では老舗でよく混む）は `brand/story_and_structure.md` に足した。
- フロア営業は「今日の注文」（#1073）の代わり。ワンオペの営業は、その日の注文の記録（`_shift_order_`・`_shift_mix_`）に触れない（想起 #1415 は、いつものシフトでだけ進む）。
- 本編の常連の話として入るシフト（`story`）と、スミさんに呼ばれたシフト（`called`）は、いつものシフト。
- 営業中は保存しない（途中の体力や訪問記録だけが残らないよう、`holdActionSave`）。本編メニューは休止の窓から開け、離れると勤務前の保存へ戻る。LOAD・タイトルへ戻った時は何も残さない。
- 保存する値は `state.flags._tonari_floor = { nights, best, fans, top }`（回した回数・いちばん良かった評価・売上の最高＝`top`・店のファンの合計）。SCHEMA は上げない。前の形で保存された `presets`（定番ミックス）は読み飛ばし、次の保存で消える。

## 3. 一回の営業

時間は刻み（tick）で進む。1刻み＝実時間0.5秒。営業は320〜384刻み（2分40秒〜3分強）。操作は刻みを使わない。

卓ごとの段階と、押した時に起きること:

| 段階 | 卓の札の見出し | 押すと |
|---|---|---|
| 空席 | （空席） | 何も起きない。客は来たら自分で座る（番号の若い空席から） |
| 注文待ち | 注文（残り秒が減っていく） | **接客の画面**へ替わり、ミックスを選ぶ（時間停止）。右の一覧から押せば、列を開かずにそのまま出せる |
| 仕込み | 仕込み中／順番待ち（進みの棒） | 何も進まない。仕上がると自動で卓へ運ばれる |
| くつろぎ | くつろぎ中／おかわり中（円＝滞在の残り、棒＝炭の残り） | 「炭はまだ平気」と出るだけ |
| 調整どき | **炭の調整**（炭の残りが35%を切った時） | **その場で炭を整える**（ひと押し。選ばない） |
| 頼み | 頼みの言葉、または「様子が変だ」 | 接客の画面へ替わる。5つの手から選ぶ。正解は◎、外すと× |
| 会計 | 会計 | その場で会計する（ひと押し。選ばない） |
| 片付け | （片付け中） | 3秒で空席に戻る |

- **客の気分（＝ミックスの属性）**: 4つ。色と印が決まっている。来店の時に卓の上の吹き出しと出来事の行で一言だけ言い、注文を聞くまで卓の札の帯に色・印・名前が出ている。どの気分で来るかは、客の種類に関係なく4つから同じ割合で決まる。
- **一卓に一人・一人一台**（2026-11-20 オーナー「2人が一卓に座るのは無くす。2人同時にきたら1席1席で1人一台ずつ」・TFL51）: 二人連れ（終電前・散歩帰り・学生・話し好き・友だち連れ）は**同じ時に来て、空いている卓へ一人ずつ座る**。気分・注文・満足・会計・ファンも一人ずつ。空いている卓が一つしか無ければ、もう一人は卓が空くまで待ってから座る。呼び名は一人ずつ（「散歩帰りの方」など。二人とも同じ呼び名で、卓の番号で見分ける）。一晩の客の数は、これまでの「組」の数より増えた（下の表）。満席の日は来店の間隔を少し空け、手際が人並みなら大入りに届くように合わせた（検査用のボットで、12の種の平均が97）。

  | 気分 | 色 | 印 | 客の一言 |
  |---|---|---|---|
  | フルーティ | 橙 | りんご | 「フルーツ系が吸いたいな」 |
  | スイート | 桃 | 包みのあめ | 「お菓子系が吸いたい」 |
  | 刺激系 | 水色 | 稲妻 | 「ピリッとしたのがいいな」 |
  | リラックス | 藤 | 三日月 | 「まったりできるのがいいな」 |

- **ミックス**（2026-11-20 オーナー「ミックスはもっと種類用意したい。このゲームの大会とかで使えるフレーバーでの組み合わせで」・TFL33）: **104種**（単品14・2種のミックス66・3種のミックス24。第1章の店では91種、第2章で13種増える）。材料は**本編のフレーバー**（`data/flavors.json`）から選んだ52種で、1〜3種の組み合わせ。大会で使えない物・非売品は使わない。名前は材料の呼び名をつなげる（「レモンミント」「ピーチマンゴー」「キャラメルナッツ」「ジャスミンティー」「ダブルアップル」など。メーカー名は付けない）。出回る章は、材料のいちばん遅い章（ミルク・チェリー・パッション・グミ・サクラを使うミックスは第2章から）。本編のデータとの食い違い（無い id・系統のずれ・章のずれ）は、検査が止める。
- **単品は「〜単」、ミックスは2種と3種**（2026-11-20 オーナー「ミックスは3種のも入れて欲しい。わたあめはコットンキャンディ単体ならミックスじゃないので成り立たない。単品ならダブルアップル単とかにする」・TFL47）:
  - **フレーバー1種の物は、ミックスではない**。作った名前（わたあめ など）は付けず、名前は「**本編のフレーバー名＋単**」（ダブルアップル単／コットンキャンディ単／カプチーノ単／ペパーミントシェイク単／アールグレイ単 など14種）。名前がそのまま中身なので、（）は付けない。
  - **3種のミックス**（24種。第1章で20種）: モヒート（レモン・ミント・ハニー）／トロピカル（パイナップル・マンゴー・バナナ）／ベリーズ（ブルーベリー・ラズベリー・カシス）／ティラミス（チョコレート・コーヒー・バニラ）／クリームソーダ（メロン・バニラ・コーラ）／チャイ（ブラックティー・シナモン・ハニー）／フラワーガーデン（ラベンダー・ローズ・ジャスミン）／アップルパイ（ダブルアップル・シナモン・バニラ）など。属性は、どの気分にも5種前後ある。
  - **1種・2種・3種の違い**: 仕込みは 1種＝5秒／2種＝7秒／3種＝9秒。**3種は、仕込みが長いぶん、合った時（◎・○）の満足が＋4**（◎＝94、○＝76。合わない時は同じ30）。急ぐ時は単品、余裕がある時は3種、という選び方になる。
  - 3種のミックスの名前と材料は、札に収まる形で決める（名前は5字までの切れ目。材料は、右の列で（）が2行に収まる並び。検査で確かめる）。
- **名前のあとに、使ったフレーバーを必ず（）で出す**（2026-11-20 オーナー「ミックス名はわたあめとかにしてもいいけど必ず()で何のフレーバー使ったミックスなのかお願い。グラム数までは書かなくていい」・TFL44）: 書き方は「**名前（フレーバー・フレーバー）**」（1種の物だけは、上のとおり「〜単」で（）なし）。例: カフェモカ（コーヒー・チョコレート）／ミルクティー（アールグレイ・ミルク）／キャラメルナッツ（キャラメル・ヘーゼルナッツ）／レモンミント（レモン・ミント）。
  - （）に出すのは、**本編のフレーバー名からメーカー名を除いたもの**（`FLAVORS` の `full`）。名前を組むための短い呼び名（わたあめ・ナッツ・ティー・アップル・ベリー・イチゴ・パイン・チョコ・グミ・ムスク・サクラ など）とは別に持つ。本編の名前と食い違うと検査で止まる。グラム数・割合は出さない。
  - 名前が材料そのままのミックス（レモンミント など）にも、同じ形で必ず出す（札によって出たり出なかったりしない）。
  - 出す所: 右の列のミックスの札・接客の画面のミックスの札・接客の画面の卓の様子（出している一台）・精算の「好評だったミックス」・読み上げ。出来事の行は、幅が無いので名前だけ（上の帯の仕込み中は名前を出さない）。
- **ミックスの属性**（2026-11-20 オーナー「一目で何属性がメインなのかわかりやすくして」・TFL29）: どのミックスにも**メインの属性が一つ**あり、**サブの属性**を一つ持つ物もある（持たない物もある）。合い方はこの二つだけで決まる: **客の気分がメインと同じ＝◎／サブと同じ＝○／どちらでもない＝×**（△は無い）。属性は**本編の系統**から決まる: フルーツ（fruit）＝フルーティ／スイーツ（sweet）＝スイート／清涼（cooling）＝リフレッシュ／スパイス・フローラル（spice・floral）＝リラックス。メインは材料の系統から、サブはもう一方の材料の系統か、その材料が持つ別の顔（柑橘の爽やかさ、茶葉の落ち着き、など）から選ぶ（`MIXES` の `main`・`sub`）。目安は「〜ミント＝リフレッシュがメイン」「ほかは、名前の先に来る材料がメイン」。ダブルアップルは本編でスパイスの系統なので、リラックスがメイン（サブがフルーティ）。メインの数は、第1章でリフレッシュ18・フルーティ18・スイート17・リラックス18。
- **一覧とシャッフル**: 開店の時に、その章のミックスを混ぜ、5つが並ぶ。一台出すと、その所へ山から次の一つが入る。**シャッフル**は5つとも入れ替える（並んでいた物は山の後ろへ回るので、同じ顔ぶれには戻らない）。回数の上限は無い。
- **シャッフルの代償**（2026-11-20 オーナー「良いのが出るまでシャッフルとかしちゃうのでそこどうしよう。シャッフルしすぎるとタイムロスだからそこで損するとか？」・TFL34）: **入れ替えには4秒かかり、その間はミックスを出せない**（一覧が「入れ替え中」になる。注文の列も開かない。調整・頼み・会計は出来る）。注文の列から押した時は、列を閉じて店へ戻る。客の待ち時間は減り続けるので、待たせた分だけ損をする: ①注文を9秒待たせると帰ってしまう ②**待たせた分だけ、提供した時の満足が下がる**（待ち時間の3分の1までは下がらない。そこから最大−9）。ボタンには「4秒」と出ている。◎が出るまで回し続ける遊び方は、満席の日に人並みの速さで回すと、必要な時だけ回す遊び方に比べて、帰ってしまう組が16回で4組→30組に増える（検査で確かめている）。
- **一台の評価**（提供した時の満足）: ◎＝90（ぴったり）／○＝72（いい感じ）／×＝30（ちがうかも）。こだわりの客（香り好きの方・年配の方）は、◎でないと少し辛い（○は−6、×は−4）。

## 4. 回すほど変わるもの

`nights`（回した回数）で決まる。数値の成長・装備・解放の作業は無い。持ち越すのは、売上の最高（精算の「自己ベスト」に使う）と、回した回数・いちばん良かった評価・店のファンの合計だけ。

| 回 | 営業 | 頼み |
|---|---|---|
| 1回目 | はじめてのワンオペ（六人・ゆっくり。注文は15秒待ってくれる）。心の声が指す卓が光り、進め方が4行出る | 吸い方の案内と、炭に関わる頼みだけ。言葉で伝わる |
| 2回目 | いつもの昼／夜（十人）。本編の人物がたまに来る | ＋喉が渇いた・話したそう。言葉で伝わる |
| 3回目 | 種から選ぶ（短い客が続く日・初めてさんの日・いつもの日。雨の日は長居の日）十〜十三人 | 同上 |
| 4回目〜 | 同上 | 「様子が変だ」だけが出て、接客の画面の様子の一文から読む |
| 6回目〜 | 満席の日（十七人）が混ざる | 同上 |

勤務札には「今日の予報」（営業の種類）と、これまでの最高の評価が出る。昼のシフトは時計が12:00〜16:00、客の呼び名も昼のもの（昼休みの方など）になる。

## 5. 評価と報酬

全組の満足の平均（帰ってしまった組は0）で決まる。

| 評価 | 条件 | 店からの売上ボーナス |
|---|---|---|
| 大入り | 88以上、かつ誰も帰していない | 1,500円 |
| 上々 | 74以上 | 1,000円 |
| まずまず | 56以上 | 500円 |
| ばたばた | それ未満 | なし |

**いまの調子**（TFL46）: 営業中も、いま締めたらどの評価かが分かる。見送った組の満足と、いま一台が出ている卓の満足の平均で見る（`floorOutlook`）。売上の下のゲージに出て、評価の段が変わると出来事の行で知らせる（「いまの調子：上々」）。締めの評価と同じ計算。

日当（基本8,000円＋大会の実績＋魅力の指名ボーナス等）は評価に関係なくいつもどおり。店の売上とファンは、はじめの所持金には入らない。

検査用のボット（`remake/test/tonari_floor_bot.mjs`。全営業×12の種）での目安: 並んでいる中でいちばん合う一台を出し（◎も○も無い時だけシャッフル）、調整にも回れば大入り（平均97）。調整に行かず頼まれてから応えると、大入りと上々が混ざる（89）。合い方を見ずに一つ目を出すと、まずまずが中心（64）。8秒に1操作のほぼ放置や、わざと合わない一台を出すと、ばたばた。◎が出るまでシャッフルし続けると、手際が人並みの速さの時に客を待たせて帰られる（満席の日で顕著）。

- **フィーバーの入り**: 画面が一瞬、暗→明に光る。**明け**: やわらかく光って、その間に増えた売上を出来事の行で知らせる（「フィーバーが明けました（＋4,800円）」）。
- **客が帰ってしまった時**: 画面の縁が赤く沈む。
- **ラストオーダー**: 新しい客が来なくなる時（残り20秒）に、まん中の札と音で知らせる。**残り10秒**は、時計が1秒ごとに脈を打って刻む音が鳴る。
- **精算**: 店の売上が0から数え上がる。**これまでの売上の最高を超えた夜は「自己ベスト！」**（合計の下の行。これまでの最高も出す）。大入りは紙吹雪。いちばん長かった流れ（「ぴったり N連続」）も残る。
- 動きを減らす設定の時は、数え上げ・紙吹雪・刻む音を省く。

**文字と文字を重ねない**（2026-11-20 オーナー「（言葉どうしが重なった画面を示して）こういうの見ると文字と文字が重なってるの避けたい」・TFL45）:

- **同じ卓の言葉は一つだけ**: 手応えの言葉・客のひとことが続けて出た時は、新しい言葉に替える（前の言葉の上に重ねない。出来事の行には両方残る）。
- **言葉の幅は、卓の札の幅まで**（190px）。出はじめに1.08倍へふくらんでも、隣の卓の言葉・見出し・札に届かない。収まらない言葉は折る（客のひとことは2〜3行）。言葉が出ている間は、その卓の見出しと怒りの印を隠す。
  - 幅に収まるよう、長い言葉は短くした: 「帰った…」「ちがった…」「ちがうかも」「炭はまだ平気」。
- **帯が出ている間は、卓の札を出さない**: 帯が消えきるまで（1.5秒）、卓の札・言葉・番号札・まん中の札を透明にする。フィーバーで時間が止まる長さも、帯の長さにそろえた（明けた時に、帯の残りが札に掛からない）。

- **順番待ちの台数**は、仕込み中の枠の外へはみ出す札をやめて、器の印の隅の数にした。
- はじめの心の声が行に収まらない時は「…」で切る（行の外へはみ出さない）。
- **検査**: 満席の日を、言葉が消える前に次の出来事が起きる速さで回し、文字の箱（言葉・卓の札・見出し・番号札・帯の文字・まん中の札・上下の帯・右の列）がどのコマでも重ならないことを、PC とタッチで確かめる（`remake/test/browser/tonari_floor.mjs` の `*-no-text-overlap`）。
