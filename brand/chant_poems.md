# 煙の巻頭ポエム集（「型」を借りた新作）

> 2026-11-08 オーナー依頼「ブリーチのオサレポエムを全て集めて、このシーシャのゲームに合うものを作って。一部を差し替えとかではなく、特徴を捉えて新たに作る」（OSP）。
> 2026-11-08 追指示「巻頭ポエムみたいなのがいい。技というより」。さらにミューズの仮判断（オーナーが後から変更できる）で、技型（煙道・起動句）は削除し、**巻頭ポエム（序詩＋第1〜5章）に一本化**。一行ナレーション10本は残した。
> 状態: **巻頭ポエムはゲーム内に接続済み**（§6）。一行ナレーションは素材のみ。
> 原作の詠唱・台詞の**原文は書き写していない**（著作物のため）。集めたのは「型」と「効き方」で、語句の差し替えはしていない。

## 1. 集めた「型」（原作の6種類）

| 型 | 中身 | 本作での写し先 |
|---|---|---|
| ① 鬼道の詠唱＋術名 | 破道・縛道の2系統、番号は1〜99（大きいほど高位）。詠唱のあとに術名を言って発動する。詠唱を省く「詠唱破棄」もある | 採用せず（技型。オーナー指示で削除） |
| ② 解号＋刀の名 | 短い命令句と刀の名で力を解く | 採用せず（同上） |
| ③ 卍解の名乗り | 最終段階の名乗りと能力名 | 採用せず（同上） |
| ④ 戦闘中の独白・決め台詞 | 1〜3行の断定。言い切って間を置く | **一行ナレーション集**（§5） |
| ⑤ 章頭・節目の語り | 比喩を重ねて世界の真理のように語る | **巻頭ポエム**（序詩＋第1〜5章。§4） |
| ⑥ 英語まじりの章題・ルビ | 漢字に外来語のルビを振る | 章題のルビ（スモーク・アンド・ミラーズ等は既存の章題をそのまま使う） |

参考（構造の確認だけに使った）: [鬼道（BLEACH）- pixiv百科事典](https://dic.pixiv.net/a/鬼道(BLEACH))

## 2. オサレ詩の特徴（12）

1. **呼びかけで始める**。「〜よ」と人ではなく概念や物に語りかけ、主語を大きくする。
2. **短い句を空白で刻む**。句点を打たず、1行を息の一拍にする。
3. **漢字熟語を多用し、音で読ませる**。難読は《》のルビで補う。
4. **大仰な名詞を連ねる**。スケールを一気に広げる語（宇宙・神・世界級の語）を置く。
5. **対の語を向かい合わせる**（光と闇、始と終、生と死）。
6. **否定→反転**。「〜ではない」と外してから「〜だ」で言い直す。
7. **命令形・使役で閉じる**。呪文として声に出せる終わり方にする。
8. **最後に技名で落とす**。番号つきの術名に漢字＋外来語ルビ。
9. **数字へのこだわり**。段の番号、「千」「万」「九十九」などの大きな数。
10. **観念を物のように扱う**。孤独・沈黙・静寂に重さや形を与える。
11. **断定のあとの間**。言い切って余白を残す。説明はしない。
12. **意味が分かりそうで分からない飛躍**。余韻が残る。省略（詠唱破棄）が逆に決め技になる。

技型は **呼びかけ → 性質の描写 → 命令 → 技名** の四拍子。巻頭ポエムはこの型ではなく、⑤の型（景色から入る→一段抽象へ上がる→言い切らずに終える）で書いた。

## 3. 本作へ移すときの決まり

- **強さの置き場所を変える**。原作の詠唱は「己の霊圧で理を従える」。本作は「理（葉・熱・炭・水・待つ時間・相手）に寄り添い、関わりを通す」。主語は己でなく**煙・熱・葉・炭・水・待つ時間**、否定→反転の反転先は**核ではなく関わり**に置く（`brand/story_and_structure.md`「全ルートを通る主題」）。
- **詩は結果を変える魔法にしない**。章の空気を整えるだけで、勝敗は手と葉と熱で決まる。
- **数字は実データに合わせる**（第5章の「十二グラム」は、同じ条件のダブルアップル単体12g。`docs/gameplay_agent_reference.md`・`docs/shisha_reference.md`）。
- **水は煙を冷ますだけ**。濾過・浄化と言わない。**炭は炎を出さず灰をまとう**。
- **「結論を言い換えた独白」は各章一度まで**。「混ざったままで、俺だった」は第5章専用なので、ここでは使っていない。「-EN:CODE-」の意味も説明していない（第5章まで作中で説明しない）。
- **原作語を使わない**。万象・灰燼・君臨者・卍解など原作の固有語・詠唱の語句は入れていない。
- ゲーム内の台詞にするときは `text-style`（台詞は1つ48字以内・手動改行をしない）と `dialogue-edit` に従う。詩は地の文なので末尾の「。」は付けない。

## 4. 巻頭ポエム（⑤の型。技ではなく、章の幕開けに置く詩）

2026-11-08 オーナー追指示「巻頭ポエムみたいなのがいい。技というより」。技型は削除し、この節の詩に一本化した。

巻頭ポエムの書き方（§2の特徴から、巻頭に効くものを選んだ）:
- 具体の景色から入り、途中で一段抽象へ上がり、**言い切らずに宙づりで終える**（結論を言い換えた独白にしない）。
- 各章の主題と章題に沿い、その章の山場や結末は先に言わない。
- 1本は10〜14行。置き場所は §6（序詩はタイトル直後、各章の詩は章タイトルの直後）。

### 序詩「煙前口上」

タイトル・全体の巻頭向け。

```
煙は 形を 持たぬ
ゆえに 人は 器を 与え
器に 水を 与え
水に 名を 与えた

だが 煙は 知っている
己が 誰のものでも ないことを

葉のもの
炭のもの
手のもの 風のもの
そして ──
今 それを 吸う者のもの

熱と 縁の 交わる 一点に
一筋 煙が 立つ

その名を 人は
水煙と 呼ぶ
```

### 第1章「煙がつなぐ街」
題材: 憧れと目の前の仕事、最初の一人。
```
路地には 音がある
シャッターの 上がる音
氷の ほどける音
そして 名もない 靴音

靴音は 注文より 先に 語る
疲れた 靴音
急ぐ 靴音
誰かを 待つ 靴音

憧れは 遠くを 見る
仕事は 足元を 見る
その 二つの 間を
細い 息が 通っていく

煙は まだ 誰のものでもない
今夜 最初の 一人に 渡すまで
```

### 第2章「才能の壁」（Hollow Crown）
題材: 壁は両側にある。空の冠。
```
壁は 高さで 壁になるのではない
向こう側を 知りたがる 目が
壁を 壁にする

こちらから 見れば
越えられぬ 才能
あちらから 見れば
越えてこられぬ 才能

王冠の 内側は いつも 空っぽだ
空っぽの冠を 戴いた者は
何を 入れて 歩けばいい
```

### 第3章「嘘つきたちの夜」（SMOKE AND MIRRORS）
題材: 煙（ごまかし）と鏡（見たくない顔）。嘘を免罪せず、選ばせて終える。章頭の幼少期の場面の直前に置く案。
```
煙は 嘘が 上手い
輪郭を ぼかし
見たいものだけを 見せてくれる

鏡は 嘘が 下手だ
見たくないものまで
そのまま 映してしまう

その二つを 同じ部屋に 置いた夜
嘘つきたちは
はじめて 己の 顔を 見る

吐く煙で 隠すか
顔を 上げて 見るか
夜は まだ 選ばせてくれる
```

### 第4章「継承の煙」（Legacy Smoke）
題材: 手渡せないものが渡ってくる。15年前の一台は先に明かさない。
```
煙は 手渡しできない
渡せるのは 器と 火と 手順だけ

それでも 煙は 渡ってきた
名も知らぬ 誰かの 一服から
別の 誰かの 一服へ
年月を 越えて

渡した者は 渡したことを 忘れ
受け取った者は 受け取ったことに 気づかない

それでいい
継承とは
気づかぬうちに 誰かの 手つきで
己の 手が 動いていること
```

### 第5章「機械仕掛けの神」（Deus Ex Machina）
題材: 同じ条件で残るもの。9000を貶めず、結論も言わない。「混ざったままで、俺だった」は使っていない。
```
同じ葉 同じ器具 同じ十二グラム
条件が すべて 揃ったとき
それでも 残るものが あるとしたら

数字に ならなかった もの
あるいは
数字に した 誰かの 手

神は 舞台の 上から 降りてくる
だが 舞台を 組んだのは
いつも 人間の 手だ

幕が 上がる
同じ葉で 二本
```

## 5. 一行ナレーション集（④の型・未接続）

章頭の独白、工程の合間などに1つずつ。「／」は行の区切り。

1. 熱は 嘘をつかない／嘘をつくのは いつも／吸う前の 期待だ
2. 水は 煙を 冷ますだけだ／浄めは しない／それでも 人は 水を通す／通して はじめて 優しくなるものが 在るから
3. 一台に 関わる者を 数えたことが あるか／葉 炭 水 風 雨／疲れ 客 そして 昨日の己／数え終わる前に 煙は 立つ
4. 待つ時間を 無駄と呼ぶ者は／まだ 煙の重さを 知らない
5. 勝ち負けは 煙の後に 来る／煙は 勝ち負けの前に 在る
6. 同じ葉 同じ手 同じ炭／それでも 今日の一台は 今日だけのもの
7. 雨の日の 煙は 重い／重さを 嫌う者は 雨を 知らない
8. 炭は 灰を着て はじめて 熱くなる／赤は 内に 在れ
9. 「上手く作れ」と言う者は 多い／「誰に」と問う者は 少ない
10. いい煙の席は 静かだ／言葉の要らない時間が 回っている証拠だ

## 6. ゲーム内の接続（2026-11-08 実装）

ミューズの仮判断（オーナーが後から変更できる）で、巻頭ポエムをゲーム内の台詞データにした。

| 詩 | 出る場所 | 台詞ID |
|---|---|---|
| 序詩「煙前口上」 | タイトルから「はじめから」を選んだ直後、第1章のコールドオープンの前 | `poem_prologue` |
| 第1章 | 第1章の章タイトルの直後、スミさんの場面（`ch1_opening`）の前 | `poem_ch1` |
| 第2章 | 第2章の章タイトルの直後、出発の場面の前 | `poem_ch2` |
| 第3章 | 第3章の章タイトルの直後（幼少期の公園の回想→綾取の調べもの→章タイトル→この詩の順） | `poem_ch3` |
| 第4章 | 第4章の章タイトルの直後 | `poem_ch4` |
| 第5章 | 第5章の章タイトルの直後 | `poem_ch5` |

- 台詞は `data/dialogue/chapter_poems.json`（話者なしの地の文）。詩の連（空行で区切った塊）を1ページにしてあり、連の中の行は全角空白で区切る。表示は既存の会話エンジンで、特別な演出は足していない。
- 出すのは章タイトルを出す時と同じ「初めてその章を始める時」だけ。読み込み直しやセーブからの再開では繰り返さない（章ごとの `titleSeen` と同じ判定）。共通の出し方は `remake/js/scenes/chapter-poem.js`。
- 一行ナレーションは接続していない（置き場所が決まっていない）。置くなら章頭の独白、工程の合間、共通ロード画面の待ち時間。ロード画面は現状2コマ漫画の基盤（`docs/spec/loading_screen_and_comics.md`）なので、漫画と競合しない位置をオーナーが決める。
- 検証は `node remake/test/chapter_poems.mjs`（データの形・全角48字以内・組版・章ごとの接続点）と `python3 tools/lint_dialogue.py chapter_poems`、`node remake/test/text_wrap.mjs`。
