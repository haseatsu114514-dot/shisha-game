## 1. 集めた「型」（原作の6種類）

| 型 | 中身 | 本作での写し先 |
|---|---|---|
| ① 鬼道の詠唱＋術名 | 破道・縛道の2系統、番号は1〜99（大きいほど高位）。詠唱のあとに術名を言って発動する。詠唱を省く「詠唱破棄」もある | **煙道《えんどう》**の六式（工程の詠唱） |
| ② 解号＋刀の名 | 短い命令句と刀の名で力を解く | 人物ごとの**起動句**と技名 |

| ④ 戦闘中の独白・決め台詞 | 1〜3行の断定。言い切って間を置く | **一行ナレーション集** |
| ⑤ 章頭・節目の語り | 比喩を重ねて世界の真理のように語る | **序詩「煙前口上」** |

## 2. オサレ詩の特徴（12）

1. **呼びかけで始める**。「〜よ」と人ではなく概念や物に語りかけ、主語を大きくする。
2. **短い句を空白で刻む**。句点を打たず、1行を息の一拍にする。
3. **漢字熟語を多用し、音で読ませる**。難読は《》のルビで補う。
4. **大仰な名詞を連ねる**。スケールを一気に広げる語（宇宙・神・世界級の語）を置く。
5. **対の語を向かい合わせる**（光と闇、始と終、生と死）。
6. **否定→反転**。「〜ではない」と外してから「〜だ」で言い直す。
7. **命令形・使役で閉じる**。呪文として声に出せる終わり方にする。
8. **最後に技名で落とす**。番号つきの術名に漢字＋外来語ルビ。
9. **数字へのこだわり**。段の番号、「千」「万」「九十九」などの大きな数。
10. **観念を物のように扱う**。孤独・沈黙・静寂に重さや形を与える。
11. **断定のあとの間**。言い切って余白を残す。説明はしない。
12. **意味が分かりそうで分からない飛躍**。余韻が残る。省略（詠唱破棄）が逆に決め技になる。

四拍子の型にまとめると **呼びかけ → 性質の描写 → 命令 → 技名**。本書の詠唱はすべてこの順で書いた。

## 3. 本作へ移すときの決まり

- **強さの置き場所を変える**。原作の詠唱は「己の霊圧で理を従える」。本作は「理（葉・熱・炭・水・待つ時間・相手）に寄り添い、関わりを通す」。主語は己でなく**煙・熱・葉・炭・水・待つ時間**、否定→反転の反転先は**核ではなく関わり**に置く（`brand/story_and_structure.md`「全ルートを通る主題」）。
- **詠唱は結果を変える魔法にしない**。やることを言葉にして気持ちを整える祝詞で、勝敗は手と葉と熱で決まる。
- **数字は実データに合わせる**: 炭は三角3個、蒸らしは基本5〜8分（上限10分）、吸い出しは最大5回、工程は 詰める→炭→蒸らし→吸い出し→提供→調整（`docs/gameplay_agent_reference.md`・`docs/shisha_reference.md`）。
- **水は煙を冷ますだけ**。濾過・浄化と言わない。**炭は炎を出さず灰をまとう**。
- **「結論を言い換えた独白」は各章一度まで**。「混ざったままで、俺だった」は第5章専用なので、ここでは使っていない。「-EN:CODE-」の意味も説明していない（第5章まで作中で説明しない）。
- **人物の詠唱は本人の設定の範囲で**。組長は正体を断定しない、王煙楼は老人語・仙人語にしない、シェイクは短く静かに、など `brand/character_profiles.md` に従った。
- **原作語を使わない**。万象・灰燼・君臨者・卍解など原作の固有語・詠唱の語句は入れていない。
- ゲーム内の台詞にするときは `text-style`（台詞は1つ48字以内・末尾に「。」を付けない・手動改行をしない）と `dialogue-edit` に従う。本書の空白区切りは表示の都合で全角空白にするか、1行を1台詞に割る。

## 5. 煙道《えんどう》（工程の詠唱・技型の参考）

煙道は九十九式まで。**百番目だけは作り手に敷けず、吸う者が踏む**（原作の番号が1〜99であることを写し、「目の前の一人」に結んだ）。制作画面の6群（パッキング／炭焼き／蒸らし／吸い出し／提供／調整）に一式ずつ当たる。詠唱破棄は2回目以降や連続制作で技名だけ出す想定。

### 煙道の一 詰《パック》
```
葉よ 隙間を 恐れるな
満ちることは 満たすことではない
詰めるな 敷け
息の通る 道を 一本 残して

煙道の一 詰《パック》
```
詠唱破棄 → 「煙道の一 詰」

### 煙道の二 熾《エンバー》
```
灰を 纏《まと》う ものよ
赤は 隠してこそ 熱《あつ》い
燃えるな 熾《おこ》れ
三つの 点が 結ぶ 見えぬ 面《めん》の上に

煙道の二 熾《エンバー》
```
詠唱破棄 → 「煙道の二 熾」

### 煙道の三 蒸《スチーム》
```
待つことは 何もせぬことではない
時は 葉の内側で 満ちていく
胸の ざわめきは 蒸気《じょうき》に 預けよ
五分《ごふん》 八分《はっぷん》 十分《じゅっぷん》
数えるな 聴け

煙道の三 蒸《スチーム》
```
詠唱破棄 → 「煙道の三 蒸」（蒸らしは雑念弾幕なので、はじめの内心として静かに出す案）

### 煙道の四 吸《ドロー》
```
熱よ 上れ 熱よ 退《ひ》け
焦がすな 冷やすな
吸うは 多くて 五度 やめ時は 己で 決めよ
その 狭間《はざま》に 立つ者を
人は 職人と 呼ぶ

煙道の四 吸《ドロー》
```
詠唱破棄 → 「煙道の四 吸」

### 煙道の五 供《サーブ》
```
握る手より 差し出す手が 重い
この一台は もう 己のものではない
葉も 炭も 水も 時も
すべて 手放して はじめて 届く

煙道の五 供《サーブ》
```
詠唱破棄 → 「煙道の五 供」

### 煙道の六 整《チューン》
```
相手の 眉が 動く
その 一刹那《いっせつな》を 逃すな
整えるのは 台ではない
台の向こうに 座る人の 時間だ

煙道の六 整《チューン》
```
詠唱破棄 → 「煙道の六 整」

### 煙道の百 貴方《ユー》（最終式）
```
九十九までの 道は 作り手が 敷く
百番目だけは 敷けない
それは 吸う者が 自ら 踏む 一歩
吸われて はじめて 煙は 立ち上がる

煙道の百 貴方《ユー》
```
最終式は、使う場面が決まるまで温存する。「結論の独白」にならないよう、進行の山場の前後どちらか**一度だけ**にする。

## 6. 起動句（人物ごとの解号と技名）

②の型。命令・性質・技名の順。台詞化するときは本人の口調に直す（ここでは詠唱としての体裁）。

**スミさん**（基本に忠実、かつ自由。客の顔を思い出す仕事へ戻った人）
```
型を 守れ
型に 縛られるな
手が 覚えた 道は
客の顔へと 続いている

一客一煙《いっきゃくいちえん》
```

**なる**（甘さの追求と誠実な理論。「俺の台は丸見えだ」）
```

火入れを 信じ 焼き上がりを 待て
甘さは 逃げではない
店を 続ける者の 覚悟だ

隠すものは 何もない
俺の台は 丸見えだ

焼成《ベイク》
```

**アダム**（ダブルアップル特化。私生活は破綻）

**鴉葬レヰ**（薔薇の余韻を曲間のように聴かせる）

## 7. 一行ナレーション集（④の型）

章頭の独白、工程の合間などに1つずつ。「／」は行の区切り。

1. 熱は 嘘をつかない／嘘をつくのは いつも／吸う前の 期待だ
2. 水は 煙を 冷ますだけだ／浄めは しない／それでも 人は 水を通す／通して はじめて 優しくなるものが 在るから
3. 一台に 関わる者を 数えたことが あるか／葉 炭 水 風 雨／疲れ 客 そして 昨日の己／数え終わる前に 煙は 立つ
4. 待つ時間を 無駄と呼ぶ者は／まだ 煙の重さを 知らない
5. 勝ち負けは 煙の後に 来る／煙は 勝ち負けの前に 在る
6. 同じ葉 同じ手 同じ炭／それでも 今日の一台は 今日だけのもの
7. 雨の日の 煙は 重い／重さを 嫌う者は 雨を 知らない
8. 炭は 灰を着て はじめて 熱くなる／赤は 内に 在れ
9. 「上手く作れ」と言う者は 多い／「誰に」と問う者は 少ない
10. いい煙の席は 静かだ／言葉の要らない時間が 回っている証拠だ

## 8. 使いどころの案（未実装・オーナー判断待ち）

- **煙道の六式**: 制作画面の工程ヘッダーを切り替える瞬間に、技名だけを小さく出す（詠唱破棄）。初回や練習では全文を出す。蒸らしは雑念弾幕の外側に置く。ミニゲームは文字を密集させない方針（#2717・#2718）なので、常時表示や説明文にはしない。
- **起動句**: 大会の山場での人物カットイン、または大会の勝負が決まる前の短い演出。
- **巻頭ポエム（序詩＋第1〜5章）**: 序詩はタイトル画面の後か第1章の前、各章の詩は章カードの直後に1本ずつ。第3章は章頭に幼少期の場面があるため、その直前。会話エンジンの文字送りで、1行ずつ静かに出す案。
- **一行ナレーション**: 章頭の独白、工程の合間、共通ロード画面の待ち時間。ロード画面は現状2コマ漫画の基盤（`docs/spec/loading_screen_and_comics.md`）なので、置くなら漫画と競合しない位置をオーナーが決める。
- 実装する場合は、置く場所をオーナーが決めてから、台詞は `data/dialogue/` に入れて `python3 tools/lint_dialogue.py` を通す。
