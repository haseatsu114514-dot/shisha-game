# 煙の巻頭ポエム集（本家の巻頭詩を調べて作り直した版）

> 2026-11-08 オーナー依頼「ブリーチのオサレポエムを全て集めて、このシーシャのゲームに合うものを作って。一部を差し替えとかではなく、特徴を捉えて新たに作る」（OSP）。
> 追指示の流れ: 「巻頭ポエムがいい。技というより」→ 技型（煙道・起動句）は削除 →「結構長いかも」→ 連ごとの場面に分けて読ませる →「ポエムの上に横長の漫画風画像」→ 絵はゲームの場面を漫画風に（Codexで作る）→ **「序詩と1章は分けなくていい」「詩をまずは本気で考えて。本家を把握して、ブリーチ風になるかに加え、ゲームのストーリーに合っているか」**。
> 状態: 巻頭ポエムはゲーム内に接続済み（§6）。本家の巻頭詩を調べ（§2）、物差しを作り（§3）、詩を作り直した（§4・§7）。候補集（各章8本）を §9 に置き、そこから組み合わせた詩を §4・ゲーム内に反映した。2026-11-11、ブリーチらしさとシーシャらしさを両立させる再考の候補35本と、推し10本のコマ絵のプロンプトを §10 に置いた（選ぶ前の材料。§4 の採用詩はまだ替えていない）。一行ナレーションは素材のみ。
> 原作の詩・詠唱の**原文は書き写していない**（著作物のため）。集めたのは「型」と「効き方」で、語句の差し替えはしていない。

| ① 鬼道の詠唱＋術名 | 破道・縛道の2系統、番号は1〜99。詠唱のあとに術名を言って発動する | 採用せず（技型。オーナー指示で削除） |

## 2. 本家の巻頭詩を調べた結果（2026-11-08）

方法: 各巻の詩を整理した記事3本（下の出典）から、全文が載っている **70巻分・71篇**を数えた（71〜74巻は冒頭の数語しか無く集計外）。改行がWeb上で潰れているため**行数は目安**、29〜74巻の一部は要約の抽出で、解釈は個人の感想。数字は**概算**。本文は引用しない。

| 観点 | 結果（71篇の概算） |
|---|---|
| 長さ | 最頻は**2〜3行**。1行で言い切るものが約3割、4行以上の長いものが約1/3。字数（空白・句読点を除く）は**中央値 約40〜50字**、最短は7〜10字、最長は約200字（25巻）、110〜120字級が数篇 |
| 主語・人称 | 一人称複数（我等・我々・俺達・ぼくたち等）約2割／一人称単数約1.5割／二人称（お前・あなた・君）約2割／**主語なし、または物・概念が主語（死・世界・誇り・運命・戦い）約4割** |
| 表記 | 漢字とかなは**半々**。古語・難字（旧仮名、疵・冥冥・真逆様など）が少数。**ふりがなは1篇だけ**。**本文に英語は無い**（英題は巻題として別にある） |
| 修辞 | 否定形 約30％／反復 約25％／「〜のように」の比喩 約20％／対句・対比 約17％／問いかけ 約11％／命令形 約10％ |
| 型 | **反復→最後に一句でひねる**／**列挙→最後にひねる**／**対句で並べる**／**一行で言い切る（約20篇）**／長い独白（5篇） |
| 最後の一行 | 言い切り（〜のだ・〜からだ）約15／名詞止め約12／宙づり約10／反転（前の意味をひっくり返す）約10／問い約8 |
| 物語との関係 | 後の展開の**伏線**として効くもの約20／その巻の**主題を直接言う**もの約30／キャラの美学だけを語るもの約10。題と本文が対になるものもある |
| リズム | 「七五調」と評する記事もあるが、数えた限り**定型は少ない**。畳語・同じ句の反復・「〜のように」の繰り返しで律動を作る |
| 人気の詩に共通すること | **短く言い切る**／**一言でその人物だと分かる**／解釈の余地があり、**読み返すと本編と結びつく**／作品の中心語（誇り・死・愛など）を使う |
| その他 | 1巻と最終巻の詩は対になっている。詩と英題はセット |

## 3. 物差し（詩を採点する基準）

**A. ブリーチらしさ**（§2から）
- A1 **短い**: 空白を除いて約60字以内、2〜5行（最頻2〜3行、中央値40〜50字）。
- A2 **型が1つ見える**: 反復→ひねり／列挙→ひねり／対句／比喩／一行の言い切り。
- A3 **最後の一行が効く**: 言い切り・名詞止め・宙づり・問い・反転のどれか1つで終える。
- A4 **語彙**: 平易な語を中心に、ときどき硬い漢字・古い言い回し（半々）。英語ルビなどの飾りに頼らない。
- A5 **主語・声**: 物・概念が主語、または「その人の詩」と一言で分かる声。
- A6 **解釈の余地**: 全部は言わず、読み返すと本編とつながる（伏線）。

**B. ゲームの物語への適合**
- B1 その章の核の葛藤・主題に沿う（`brand/story_and_structure.md`）。
- B2 章の人物の手がかり（声・視点・小道具）が立つ。
- B3 伏線として効く（章の途中・終わり・後の章で意味が変わる）。
- B4 ネタバレしない／正本に反しない（「混ざったままで、俺だった」は第5章専用、「-EN:CODE-」の意味は説明しない、「結論の言い換えの独白」は各章一度まで）。
- B5 作品の主題（空・縁起・分人）と矛盾しない（核の誇示・勝敗＝価値・「借り物だから空虚」にしない）。

## 4. 巻頭ポエム（5章ともオーナー採用）

置き場所と見せ方は §6。**序詩は第1章の詩に統合した**（オーナー確認「統合で合ってる」）。

### 序詩・第1章「煙がつなぐ街」
```
葉は 遠い 国の 畑から
炭は 南の 椰子の 殻から
水は 今朝の 蛇口から

一台の 煙は
一度も 会わない ものたちの
待ち合わせだ
```
- **オーナー採用**（2026-11-11）: 再考の候補 R1-2（§10）。2場面（3行／3行）。**型**: 列挙→ひねり。**声**: なし（物が主語）。
- **シーシャ**: 葉・ココナッツ（椰子の殻）から作る炭・瓶に入れる水。
- **接点**: 一台は、遠くの畑・南の椰子・今朝の水という、一度も会わないものが落ち合う場所（縁起）。章題「煙がつなぐ街」を、街より大きな縮尺で言う。ゲーム全体の序詩を兼ねる。第5章の「縁のない寄せ集め／縁で混ざった自分」の対比へ、遠くでつながる。

### 第2章「才能の壁」（Hollow Crown）
```
勘で 煙を 立てる 者は
崩れた 日の 帰り道を 知らない
手順で 煙を 立てる 者は
手順の ない 道を 歩けない

壁は 一枚
両側から 高い
```
- **オーナー採用**（2026-11-11）: 再考の候補 R2-7（§10）。2場面（4行／2行）。**型**: 対句→言い切り。**声**: なし（誰のことかは言わない）。
- **シーシャ**: 煙を立てる（勘で作る／手順で作る）。
- **接点**: 第2章の核「才能の壁は両側にある」。勘で作るあげはは崩れた日の直し方が分からず、手順で作るはじめは自分の言葉を持てない。章頭では天才はあげはに見えるが、章末のあげはの心の声（「こんなの、ズルいよ」）で壁の向こう側が分かる伏線。

### 第3章「嘘つきたちの夜」（SMOKE AND MIRRORS）
```
平気な 顔で
席を 一つ 空けておく

何も 聞かないのは
僕も 一つ
嘘を ついたからだ
```
- **オーナー採用**（2026-11-11）: 再考の候補 R3-6（§10）。2場面（2行／3行）。**型**: 独白→告白。**声**: ましろ。
- **シーシャ**: 店の席（作れない日にも空けておく席）。
- **接点**: 作れない日にも席を空け、何も聞かないましろ（DAY4の壁際の席と白いカップ）。何も聞かない理由は、材料の名前ではじめを試した自分の嘘（DAY3のダブルアップル事件）。再会の嬉しさと心配を平気な顔で隠すましろ。章題「嘘つきたちの夜」の嘘つきの一人。
- **ネタバレ**: あり（ましろの嘘を章タイトルの前に先に言う。オーナー判断で採用）。

### 第4章「継承の煙」（Legacy Smoke）
```
言葉は 海を 渡れなかった

だから 俺は
生まれた 国の 匂いを
一台に 詰めて 置いた
```
- **オーナー採用**（2026-11-11）: 再考の候補 R4-6（§10）。2場面（1行／3行）。**型**: 独白。**声**: はじめ。
- **シーシャ**: 葉を詰める・一台を置く（提供）。
- **接点**: 英語を流暢に話せず、通訳アプリで補うはじめ（出発前にスミさんへ話す言葉の不安）。世界大会では、言葉の代わりに和の一台を出す。受け継いだ手つきで「生まれた国の匂い」を渡すことが、章題の継承へつながる。

### 第5章「機械仕掛けの神」（Deus Ex Machina）
```
何を 吸っても 砂の 味が した

だから 私は
舌の いらない 神を
組み立てた
```
- **オーナー採用**（2026-11-11）: 再考の候補 R5-3（§10）。2場面（1行／3行）。**型**: 独白。**声**: チャコール博士。
- **シーシャ**: 吸う・舌（味覚）。
- **接点**: 博士にも、何を吸っても砂のように感じる時期があった（試合後に明かす過去。`dr_kemuri.background_secret`）。だから舌が利かなくても作れる一台として SHISHA-9000 を作った。章題 Deus Ex Machina（機械仕掛けの神）。「舌のいらない神」は博士の言い方で、9000 を空っぽ扱いしない。
- **ネタバレ**: あり（博士の過去を章タイトルの前に先に言う。オーナー判断で採用）。

## 5. 一行ナレーション集（④の型・未接続）

章頭の独白、工程の合間などに1つずつ。「／」は行の区切り。

1. 熱は 嘘をつかない／嘘をつくのは いつも／吸う前の 期待だ
2. 水は 煙を 冷ますだけだ／浄めは しない／それでも 人は 水を通す／通して はじめて 優しくなるものが 在るから
3. 一台に 関わる者を 数えたことが あるか／葉 炭 水 風 雨／疲れ 客 そして 昨日の己／数え終わる前に 煙は 立つ
4. 待つ時間を 無駄と呼ぶ者は／まだ 煙の重さを 知らない
5. 勝ち負けは 煙の後に 来る／煙は 勝ち負けの前に 在る
6. 同じ葉 同じ手 同じ炭／それでも 今日の一台は 今日だけのもの
7. 雨の日の 煙は 重い／重さを 嫌う者は 雨を 知らない
8. 炭は 灰を着て はじめて 熱くなる／赤は 内に 在れ
9. 「上手く作れ」と言う者は 多い／「誰に」と問う者は 少ない
10. いい煙の席は 静かだ／言葉の要らない時間が 回っている証拠だ

- **なぜ章タイトルの前か**: 詩を前奏にして、章タイトル（第3章なら「嘘つきたちの夜」、第5章なら「機械仕掛けの神」）が詩の結びの答えとして落ちるようにするため。後に置く案に切り替えるときは、各章の `playChapterPoem` の行を章タイトルの後ろへ動かすだけでよい。
- **場面の分け方**: 詩の連（空行の区切り）ごとに場面を分け、1場面ずつ読ませる（第1〜3章・第5章は2場面、第4章は1場面）。読み終えた場面は消え、次の連が浮かぶ。最後の場面のあと全体が暗く閉じ、続けて章タイトルが出る。
- **見せ方**: 暗い面に**縦書きの明朝**（会話の明朝 `Suien Blue Mincho`）。右の行から1行ずつ、ぼかしが晴れて浮かぶ。漢字には「漢字《よみ》」のふりがなを付けられる（いまの詩では使っていない）。最後の場面の最後の行だけ少し明るく、差し色の光をまとう。詩ごとに差し色が違う（第1章=琥珀、第2章=金、第3章=鏡の水色、第4章=砂、第5章=機械の水色）。
- **コマ絵（詩の上の横長の漫画風画像）**: 詩の上に、横長の細い枠つきの絵を出す（比率は絵のまま、4:1〜5.6:1）。絵が先に浮かび、一拍おいて詩が始まり、詩が終わるまで残る。絵が無い・読めない詩は、枠を出さず詩だけを全面に出す。絵は台本の `metadata.panel`（ファイル名）で指す。**Codexで作った本物の絵5枚を採用済み**（§8）。詩の列は、下の▼の印と重ならないよう、場面の下に44pxの余白を取る。
- **操作**: 読んでいる途中のタップ／Enter／Space は、その場面の残りの行を出す。読み終えた場面でもう一度で次の場面へ、最後の場面なら閉じる（直後の誤タップは無視）。Ctrl（SKIP）は全場面を飛ばしてすぐ閉じる。放っておいても、場面ごとに字数に応じた時間で進む。読み終えた場面には小さな▼が脈打つ。動き軽減では場面の行を最初から全部出し、フェードだけ。テストの自動送り（`vnTest.turbo`）では演出を飛ばす。
- **再開**: 章ごとの `titleSeen`（第1章は `introDone`）を、詩と章タイトルを両方見終えてから立てる。詩の途中で中断した再開では、詩と章タイトルをもう一度出す。読了後の再開では出さない。

- **前の版（各36〜44字・4行）から**: 短さを優先しすぎて、人物や出来事の手がかりを削っていた（オーナー「内容薄くなったかも」）。いまは**人物の声**（スミさん・はじめ・博士・9000）と、**章の出来事の具体**（一台目・順位・公園の嘘・勝った方が作る・九千の夜）を入れた。本家の巻頭詩にも、人物の声で語るものが約半数、100字を超える長い独白が数篇ある（§2）。
- **オーナーの採用**（2026-11-11）: 第1章=R1-2、第2章=R2-7、第3章=R3-6、第4章=R4-6、第5章=R5-3（§10 の再考の候補から）。声は、物が主語（第1章）・概念（第2章）・ましろ・はじめ・博士と散り、本家の主語の配分に近づいた。第1章と第2章はシーシャの道具や作り方そのものが詩の芯になっている。
- 前の採用（2026-11-08）: 第1章=H1-7、第2章=H2-4、第3章=3-G、第4章=4-H、第5章=5-A。第1〜4章ははじめの声で、自分の目と手で見たことを最後の一行でひっくり返す詩、第5章は列挙→ひねりの語り。
- **先取りについて**: 第1・2・4章は、章の中で明かされることを弱く匂わせる。誰の声か・誰のことかは言わないので、読み返して初めて意味が分かる形（本家の伏線の使い方に近い）にとどめた。
- **残る弱み**: A4（硬い漢字・古い言い回し）は本家の半々に届いていない。
- **2026-11-08 初版（各64〜96字・5〜8行）からの流れ**: 景色→抽象→宙づりを毎回同じ形で書き、英語ルビを使っていた。本家の巻頭詩を調べ（§2）、型を詩ごとに変え、英語ルビを外した。

**共通の指針**（各枚の冒頭にそのまま貼る）:

```
添付の下敷き画像（1536×1024、クリーム色の紙に黒い横長の枠が1つ）を編集して、ゲーム『水煙前線』の巻頭の詩に添える、横長の漫画のコマ絵を1枚描いてください。ゲームの場面を漫画風に描き直します。

■ 寸法
- 出力は1536×1024。下敷きの枠（x=48〜1488、y=377〜647、1440×270、16:3）の位置と大きさを変えない。**枠を縦に伸ばさない**（高さ270pxのまま）。
- 絵は枠の内側だけに描く。枠の外は紙色 #EEE3CF のまま、何も描かない。枠線（3px、黒）は残す。
- 枠の縁から内側4%（約58×11px）には、顔・重要な線を置かない。
- 超横長なので、映画のレターボックスのように横に広い構図にする。見せたいものは、枠の左右の中央6割に収める。

■ 画風
- 白黒の墨線と、指定の1色のトーン（網点と薄いベタ）だけの、漫画の1コマ。紙色・墨・トーンは下の【色】で指定する。細い線と太い影のベタを使い分け、ベタ・網点・集中線・かすれ線で漫画らしくする。
- 人物は、添付の立ち絵と同じ髪型・服・小物の同一人物。頭身は立ち絵に合わせ、デフォルメしない（2〜3頭身にしない）。
- 写真風・3D風・水彩風にしない。90年代のOVA・セル画風にしない。特定の既存の漫画・アニメの絵柄や人物をまねない。

■ 入れてはいけないもの
- 文字・数字・ロゴ・吹き出し・効果音の文字・題名・署名・透かし。
- シーシャの台・ハガル・HMD・炭・ホース（描きたくなっても描かない。必要なら枠の外に置く）。

- 添付の背景画像は、構図と雰囲気の参考。そのままコピーせず、漫画のコマ向けに描き直す。
- 添付の背景にシーシャの台・ホースが写っていても、絵には描かない（棚・瓶・缶・照明・窓・客席だけを参考にする）。
```

### Claudeの推しの理由

- **序詩・第1章「煙がつなぐ街」**: 1-C は2行で最初の一行に効き、コールドオープンの「一台目の話」に続き、第4章で「吸った側だけが覚えていた」と分かって読み返せる。1-B はスミさんの声が立ち、DAY5で意味が分かる（本家の「一言でその人物と分かる」に近い）。
- **第2章「才能の壁」（Hollow Crown）**: 2-F は一行で章の核（壁は両側）を言い切り、章末のあげはの心の声で読み返せる。2-D ははじめの慢心となるとの決裂を具体に持ち、内容が厚い。
- **第3章「嘘つきたちの夜」（SMOKE AND MIRRORS）**: 3-B は章頭の公園の少年と少女の直後に置くと、「嘘が少しだけ本当になった」が綾取とましろの関係に重なる。3-A は章題をそのまま像にした対句で、短く強い。
- **第4章「継承の煙」（Legacy Smoke）**: 4-D は「勝った方が作る」という約束の言葉を引き、決勝で負けた翌日の路地裏の一台を、読み返すと分かる問いで指す。4-C はシェイクの声で、観ること・待つことの継承を並べる。
- **第5章「機械仕掛けの神」（Deus Ex Machina）**: 5-D は9000の声で、人の記録からできていることを貶めずに言い、「今夜だけがまだ記録にない」で章の核（記録にない日）へ落とす。5-C は博士の動機を敵の思想にせずに見せる。

#### Claudeの推しの理由

- **第1章**: H1-2 は、借りた台・借りた手つきでも「目の前の客の顔は自分が初めて見たもの」と言い、作品の主題（借り物でも空虚ではない）と第1章の「目の前の一人」を、はじめの体験で言える。H1-9 は、知らない誰かに作ってもらった一台から始まり、知らない誰かに作る今夜へ回る形で、第4章の 4-H（知らない誰かの指の跡）と対になる。
- **第2章**: H2-3 は、あげはを羨んだ日から自分の手（手順）を見なくなった、という一行で、章末のあげはの気づき（はじめは手順で直せる）へそのまま返る。H2-7 は一行で、勝つほど顔が見えなくなる＝スミさんが競技を離れた道と同じだと、第4章で読み返せる。H2-3 → H2-7 の2場面にもできる。
- 2本を2場面に組み合わせてもよい（例: 第2章 = H2-1 ‖ H2-7）。

## 10. 再考の候補（ブリーチらしさ×シーシャらしさ。2026-11-11）

**オーナー採用（2026-11-11）: R1-2・R2-7・R3-6・R4-6・R5-3**（§4・ゲーム内に反映した）。

オーナー「このポエムの内容を再度考え直して候補をたくさんください。またそれにあった画像生成も頼みます。ブリーチらしさやシーシャらしさの両立が必要で、今のやつも悪くはないけど少し満足いかない」（OSP17）。§4 の採用詩はそのまま残し、選び直す材料として35本を作った。

**今の詩の物足りなさ（Claudeの見立て）**

- 5篇とも語りの声がはじめ（「俺」）か語りで、§2 の本家で約4割を占める「**物・概念が主語の言い切り**」と、我々・お前の声がほとんど無い。
- シーシャならではの**事実**を使っていない。日常の言葉で書けてしまう詩が多い。

**作り直しの決まり**

- 主語をシーシャの物にする（炭・灰・煙・水・瓶・王冠）。本家の「死・誇り・運命」の位置に、シーシャの物を置く。
- 使ったシーシャの事実: 煙は**誰かが吸うまで立たない**／炭は**椰子の殻**から作る／炭は**燃え尽きる前に足す**（炭替え）／灰をかぶっても炭は**熱い**／煙は**瓶の水をくぐる**、水は毎回替える／煙の匂いは**服に朝まで残る**／ダブルアップルは**アニスとリコリスで描いた林檎**／回し吸いは**一本のホースを回す**。
- 型は §2 の配分に寄せる（反復→ひねり・列挙→ひねり・対句・一行の言い切り・定義「〜を〇〇と呼ぶ」）。声は、なし（物が主語）・我々・お前・人物の独白を混ぜる。
- 硬い字はときどき（熾《おこ》す・晒す）。ふりがなは「熾」だけ（本家もふりがなは1篇だけ）。英語は使わない。
- **第1章 R1-1 と第5章 R5-1、第2章 R2-1 と第5章 R5-5 は対**にした（本家の1巻と最終巻の詩が対になっているのにならう）。
- 字数・行数・1列の幅（16字）・2場面は、ゲーム内の検査（`remake/test/chapter_poems.mjs`）と同じ基準で全部確かめた。
- ◎は Claude の推し（各章2本）。ネタバレのあるものは印を付けた。

### 再考・第5章「機械仕掛けの神」

**R5-1 ◎「誰も座っていない椅子」**（51字・型: 列挙→ひねり・声: なし（博士の考え））
```
才能 運 気分 体調 舌
煙を 狂わせる ものを
一つずつ 数えて 外していった

最後に 残ったのは
誰も 座っていない 椅子だった
```
- シーシャ: 煙を狂わせるもの（作中の博士の言葉: 才能・運・気分・体調・舌）
- 接点: 狂わせるものを一つずつ外した先に残る、誰も座っていない椅子。「誰でも座れる椅子」とも「誰もいない椅子」とも読める。第1章 R1-1 と対
- コマ絵: 下の「再考のコマ絵」

**R5-2 ◎「神は機械の中に」**（34字・型: 言い切り→反転・声: なし（博士））
```
神は 機械の 中に いると 信じた

開けて みれば
炭の 熱と
他人の 夜が 詰まっていた
```
- シーシャ: 炭の熱
- 接点: 章題 Deus Ex Machina。機械の中にいるはずの神を開けると、炭の熱と他人の夜（多くの作り手の仕事）が詰まっていた。9000を空っぽ扱いしない
- コマ絵: 下の「再考のコマ絵」

**R5-3「砂の味」**（30字・型: 独白・声: 博士）
```
何を 吸っても 砂の 味が した

だから 私は
舌の いらない 神を
組み立てた
```
- シーシャ: 吸う・舌
- 接点: 何を吸っても砂の味がした博士が、舌のいらない神（9000）を組み立てた
- **ネタバレ: 博士の過去（試合後に明かす）**
- コマ絵の案: 博士がひとり煙を吐く。煙が砂のように崩れて落ちる象徴の絵

**R5-4「二度手を挙げる」**（37字・型: 反復→ひねり・声: なし）
```
同じ 葉で 二本
同じ 客が 二度 手を 挙げる

一度目と 二度目の 間に
その人の 今日が あった
```
- シーシャ: 同じ葉で二本・挙手
- 接点: 同じ客が二度手を挙げる二本勝負。一度目と二度目の間に、その人の今日があった
- コマ絵の案: 客席で同じ客が二度手を挙げる姿を左右に並べる（一度目と二度目で表情が違う）

**R5-5「正解の味」**（32字・型: 独白→帰結・声: 博士）
```
正解の 味を 一つだけ 探していた

同じ 一台は
席の 数だけ
違う 答えを 返した
```
- シーシャ: 同じ一台・席ごとに割れる票
- 接点: 正解の味を一つ探していた博士。同じ一台は席の数だけ違う答えを返した（FPC03）。第2章 R2-1 と対
- コマ絵の案: 十の席から立つ十本の違う形の煙を、博士が見上げる

**R5-6「手は覚えていた」**（27字・型: 逆接・声: 博士）
```
舌は まだ 遠い

けれど 炭を 置く 手は
十数年 前の 夜を
覚えていた
```
- シーシャ: 炭を置く手
- 接点: 舌はまだ遠いが、炭を置く手は昔の夜を覚えていた（#2534）
- **ネタバレ: 第5章の結末**
- コマ絵の案: 夜の研究室で、博士が十数年ぶりに炭を置く手元

**R5-7「完璧な煙の名前」**（33字・型: 逆説・声: なし）
```
完璧な 煙に 名前は いらない

名前を 欲しがるのは
いつも
失敗した 夜の ほうだ
```
- シーシャ: 煙
- 接点: 完璧な煙に名前はいらない。名前を欲しがるのは、いつも失敗した夜のほう
- コマ絵の案: 研究室の壁一面の記録の棚と、名前の札のない一台
