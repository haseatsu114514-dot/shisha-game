## 1. 集めた「型」（原作の6種類）

| 型 | 中身 | 本作での写し先 |
|---|---|---|
| ① 鬼道の詠唱＋術名 | 破道・縛道の2系統、番号は1〜99（大きいほど高位）。詠唱のあとに術名を言って発動する。詠唱を省く「詠唱破棄」もある | 採用せず（技型。オーナー指示で削除） |
| ② 解号＋刀の名 | 短い命令句と刀の名で力を解く | 採用せず（同上） |
| ③ 卍解の名乗り | 最終段階の名乗りと能力名 | 採用せず（同上） |
| ④ 戦闘中の独白・決め台詞 | 1〜3行の断定。言い切って間を置く | **一行ナレーション集**（§5） |
| ⑤ 章頭・節目の語り | 比喩を重ねて世界の真理のように語る | **巻頭ポエム**（序詩＋第1〜5章。§4） |
| ⑥ 英語まじりの章題・ルビ | 漢字に外来語のルビを振る | 章題のルビ（スモーク・アンド・ミラーズ等は既存の章題をそのまま使う） |

## 2. オサレ詩の特徴（12）

1. **呼びかけで始める**。「〜よ」と人ではなく概念や物に語りかけ、主語を大きくする。
2. **短い句を空白で刻む**。句点を打たず、1行を息の一拍にする。
3. **漢字熟語を多用し、音で読ませる**。難読は《》のルビで補う。
4. **大仰な名詞を連ねる**。スケールを一気に広げる語（宇宙・神・世界級の語）を置く。
5. **対の語を向かい合わせる**（光と闇、始と終、生と死）。
6. **否定→反転**。「〜ではない」と外してから「〜だ」で言い直す。
7. **命令形・使役で閉じる**。呪文として声に出せる終わり方にする。
8. **最後に技名で落とす**。番号つきの術名に漢字＋外来語ルビ。
9. **数字へのこだわり**。段の番号、「千」「万」「九十九」などの大きな数。
10. **観念を物のように扱う**。孤独・沈黙・静寂に重さや形を与える。
11. **断定のあとの間**。言い切って余白を残す。説明はしない。
12. **意味が分かりそうで分からない飛躍**。余韻が残る。省略（詠唱破棄）が逆に決め技になる。

技型は **呼びかけ → 性質の描写 → 命令 → 技名** の四拍子。巻頭ポエムはこの型ではなく、⑤の型（景色から入る→一段抽象へ上がる→言い切らずに終える）で書いた。

## 3. 本作へ移すときの決まり

- **強さの置き場所を変える**。原作の詠唱は「己の霊圧で理を従える」。本作は「理（葉・熱・炭・水・待つ時間・相手）に寄り添い、関わりを通す」。主語は己でなく**煙・熱・葉・炭・水・待つ時間**、否定→反転の反転先は**核ではなく関わり**に置く（`brand/story_and_structure.md`「全ルートを通る主題」）。
- **詩は結果を変える魔法にしない**。章の空気を整えるだけで、勝敗は手と葉と熱で決まる。
- **数字は実データに合わせる**（第5章の「十二グラム」は、同じ条件のダブルアップル単体12g。`docs/gameplay_agent_reference.md`・`docs/shisha_reference.md`）。
- **水は煙を冷ますだけ**。濾過・浄化と言わない。**炭は炎を出さず灰をまとう**。
- **「結論を言い換えた独白」は各章一度まで**。「混ざったままで、俺だった」は第5章専用なので、ここでは使っていない。「-EN:CODE-」の意味も説明していない（第5章まで作中で説明しない）。
- **原作語を使わない**。万象・灰燼・君臨者・卍解など原作の固有語・詠唱の語句は入れていない。
- ゲーム内の台詞にするときは `text-style`（台詞は1つ48字以内・手動改行をしない）と `dialogue-edit` に従う。詩は地の文なので末尾の「。」は付けない。

## 4. 巻頭ポエム（⑤の型。章タイトルの前に読ませる詩）

2026-11-08 オーナー追指示「巻頭ポエムみたいなのがいい。技というより」「結構長いかも」「ストーリーやキャラと照らし合わせて内容をより良く」。技型は削除し、この節の詩に一本化した。初版（10〜14行）は長く説明的だったため、**5〜8行へ詰め、物語の細部と響く像に置き換えた**（改稿の理由は §7）。

巻頭ポエムの書き方:
- **5〜8行**。景色や比喩から入り、言い切らずに終える。結論を言い換えない。
- 各章の主題・章題・人物の手がかりに沿い、その章の山場や結末は先に言わない（接点は各詩の下に書いた）。
- 漢字にルビ（《》）を振ってよい。専用の読ませる演出（§6）がふりがなを描く。章題の英題と響くルビを一部に置く。
- 置き場所と見せ方は §6（序詩はタイトルの後、各章の詩は章タイトルの直前）。

### 序詩「煙前口上」
タイトル・全体の巻頭。主題（空・縁起）を、結論にせず像で置く。「縁」を一度だけ使い、「-EN:CODE-」の意味は説明しない。
```
煙《スモーク》に 核は ない
ゆえに 誰の 肺にも 入れる

葉と 炭と 水と 手と
今日の 縁《えん》が 交わる 一点に
一筋の 煙が 立つ

その名を 人は
水煙《すいえん》と 呼ぶ
```

### 第1章「煙がつなぐ街」
接点: 「目の前の一人」（スミさん）、店を持ちたい憧れと目の前の仕事、街の人をつなぐ煙。糸は、紬（つむぎ）への小さな目配せ。
```
煙は 糸に 似ている
見えぬ 者同士を 音もなく 結ぶ

憧れは 遠くを 見る
仕事は 足元を 見る
糸は その間を 通って
今夜 最初の 一人へ 届く
```

### 第2章「才能の壁」（Hollow Crown）
接点: あげはの直感を「ずるい」と思うはじめ、感覚派のあげはも崩れた日に直せない（壁は両側にある）。章題の Hollow（空洞）。
```
壁の 向こうで 誰かが
こちらを 天才と 呼んでいる

王冠は いつも 向こう側に 見える
かぶった者に 見えるのは
空洞《ホロウ》だけだ
```

### 第3章「嘘つきたちの夜」（SMOKE AND MIRRORS）
接点: 綾取の盛った噂、はじめが「ダブルアップル」と知ったふりをした嘘、平気な顔で心配を隠すましろ、大会前夜の路地。章題の煙と鏡。嘘を免罪せず、逃げ場なく終える。章頭の幼少期の場面の前に置く。
```
煙《スモーク》は 嘘が 上手い
見たいものだけを 見せる

鏡《ミラー》は 嘘が 下手だ
見たくないものまで 映す

その二つを 同じ部屋に 置いた夜
嘘つきたちは 己の 顔を 見る
```

### 第4章「継承の煙」（Legacy Smoke）
接点: 15年前の路地裏の一台（スミさん→シェイク。当時は名を知らない）、王煙楼からシェイクへ渡った観察、第3章の「借りた手つき」。誰の一台かは明かさない。
```
煙は 手渡しできない
渡せるのは 器と 火と 手順だけ

それでも 煙は 渡ってきた
名も知らぬ 誰かの 手つきで
今 己の 手が 動いている
```

### 第5章「機械仕掛けの神」（Deus Ex Machina）
接点: 同じ条件のダブルアップル単体12gの二本勝負、博士の「再現できる最高の一台」、記録に残らない客の事情（「今日は時間、あるから」）。9000を貶めず、結論も言わない。「混ざったままで、俺だった」は使っていない。
```
同じ葉 同じ器具 同じ十二グラム
全ての 条件が 揃ってなお
残るものが あるとしたら

数字に ならなかった もの
あるいは
数字《データ》に した 誰かの 手
```

## 5. 一行ナレーション集（④の型・未接続）

章頭の独白、工程の合間などに1つずつ。「／」は行の区切り。

1. 熱は 嘘をつかない／嘘をつくのは いつも／吸う前の 期待だ
2. 水は 煙を 冷ますだけだ／浄めは しない／それでも 人は 水を通す／通して はじめて 優しくなるものが 在るから
3. 一台に 関わる者を 数えたことが あるか／葉 炭 水 風 雨／疲れ 客 そして 昨日の己／数え終わる前に 煙は 立つ
4. 待つ時間を 無駄と呼ぶ者は／まだ 煙の重さを 知らない
5. 勝ち負けは 煙の後に 来る／煙は 勝ち負けの前に 在る
6. 同じ葉 同じ手 同じ炭／それでも 今日の一台は 今日だけのもの
7. 雨の日の 煙は 重い／重さを 嫌う者は 雨を 知らない
8. 炭は 灰を着て はじめて 熱くなる／赤は 内に 在れ
9. 「上手く作れ」と言う者は 多い／「誰に」と問う者は 少ない
10. いい煙の席は 静かだ／言葉の要らない時間が 回っている証拠だ

## 6. ゲーム内の接続と見せ方（2026-11-08 実装）

ミューズの仮判断（オーナーが後から変更できる）に、オーナー追指示「章のタイトルコールの前後に入れたい。ウインドウで出すというより、読ませる工夫を」を重ねて、**会話ウインドウではなく専用の読ませる画面**で出す。

| 詩 | 出る場所 | 台詞ID |
|---|---|---|
| 序詩「煙前口上」 | タイトルから「はじめから」を選んだ直後、第1章のコールドオープンの前 | `poem_prologue` |
| 第1章 | コールドオープンの後、第1章の章タイトルの**直前** | `poem_ch1` |
| 第2〜5章 | 各章の章タイトルの**直前**（第3章は章頭の調べものの後、章タイトルの前。3経路とも） | `poem_ch2`〜`poem_ch5` |

- **なぜ章タイトルの前か**: 詩を前奏にして、章タイトル（第3章なら「嘘つきたちの夜」、第5章なら「機械仕掛けの神」）が詩の結びの答えとして落ちるようにするため。後に置く案に切り替えるときは、各章の `playChapterPoem` の行を章タイトルの後ろへ動かすだけでよい。
- **見せ方（何回かに分けて読ませる）**: 詩を**連ごとの場面**に分け、1場面ずつ読ませる（序詩=3場面、第3章=3場面、ほかの章=2場面）。暗い面に**縦書きの明朝**（会話の明朝 `Suien Blue Mincho`）で、場面の行を中央に置き、右の行から1行ずつ、ぼかしが晴れて浮かぶ。読み終えた場面は消え、次の連が浮かぶ。最後の場面のあとは全体が暗く閉じ、続けて章タイトルが出る。漢字には「漢字《よみ》」のふりがな（差し色）。最後の場面の最後の行だけ少し明るく、差し色の光をまとう。詩ごとに差し色が違う（序詩=薄紫、第1章=琥珀、第2章=金、第3章=鏡の水色、第4章=砂、第5章=機械の水色）。背景は画像なしのゆるいもや。
- **操作**: 読んでいる途中のタップ／Enter／Space は、その場面の残りの行を出す。読み終えた場面でもう一度で次の場面へ、最後の場面なら閉じる（直後の誤タップは無視）。Ctrl（SKIP）は全場面を飛ばしてすぐ閉じる。放っておいても、場面ごとに字数に応じた時間（途中の場面は約2秒、最後の場面は約3〜4秒）で進む。読み終えた場面には小さな▼が脈打つ。動き軽減では場面の行を最初から全部出し、フェードだけ（場面の分け方は同じ）。テストの自動送り（`vnTest.turbo`）では演出を飛ばす。
- **時間**: 放っておくと、第1章で約12秒、序詩で約14秒（実測）。タップで短くできる。章タイトルの絵は、詩を読んでいる間に先読みする。
- **再開**: 章ごとの `titleSeen`（第1章は `introDone`）を、詩と章タイトルを両方見終えてから立てる。詩の途中で中断した再開では、詩と章タイトルをもう一度出す。読了後の再開では出さない。
- 台本は `data/dialogue/chapter_poems.json`（話者なしの地の文、**1要素 = 詩の1行**、`gap: true` が連の切れ目）。再生は `remake/js/scenes/chapter-poem.js`、見た目は `remake/css/motions/chapter-poem.css`。
- 一行ナレーションは接続していない（置き場所が決まっていない）。置くなら章頭の独白、工程の合間、共通ロード画面の待ち時間。ロード画面は現状2コマ漫画の基盤（`docs/spec/loading_screen_and_comics.md`）なので、漫画と競合しない位置をオーナーが決める。
- 検証は `node remake/test/chapter_poems.mjs`（データの形・場面は2〜3つ・縦書き1列に収まる字数・文書との一致・章タイトルの直前に置かれていること）、`node remake/test/browser/chapter_poems.mjs`（実際の表示順・場面の切り替え・縦書き・ふりがな・タップ／Enter／Ctrl／中断／動き軽減・再開）、`python3 tools/lint_dialogue.py chapter_poems`、`node remake/test/text_wrap.mjs`。

## 7. 改稿の理由（原作との比べ方）

初版（各10〜14行）に対するオーナーの「結構長いかも」「原作と比べて」「ストーリーやキャラと照らし合わせて」を受けた改稿。原作の本文は引用せず、傾向（§2）との比較だけを書く。

- **長さ**: 原作の巻頭・章頭の詩は、数行で、意味の全部を言わないものが多い。初版は10〜14行で、主題を文章のように説明していた（「継承とは〜こと」など）。→ **5〜8行**へ詰め、結論の一行は削って像で終えた。
- **語彙**: 原作は漢字熟語と、読みを当てるルビで「ことばの手触り」を作る。初版は日常語が中心でルビもなかった。→ 章題の英題と響くルビ（煙《スモーク》／鏡《ミラー》／空洞《ホロウ》）と、縁《えん》・水煙《すいえん》・数字《データ》を置いた。
- **像**: 原作は「AはBに似ている」「AはBではない」のような、短い比喩と反転で意味を一瞬わからなくして余韻を残す。→ 糸（第1章）、向こう側の王冠（第2章）、煙は嘘が上手く鏡は嘘が下手（第3章）、渡る手つき（第4章）、数字にした誰かの手（第5章）のように、**1つの像に絞った**。
- **物語・人物との接点**（各詩の下にも書いた）: 第1章=「目の前の一人」と、糸は紬（つむぎ）への目配せ／第2章=あげはを「ずるい」と思うはじめ・壁は両側／第3章=綾取の噂・はじめの「知ったふり」・ましろの平気な顔・煙と鏡／第4章=15年前の路地裏の一台（誰のかは明かさない）・第3章の「借りた手つき」／第5章=同じ条件の12gの二本勝負・博士の「再現できる最高の一台」・記録に残らない客の事情。
- **残した弱み**: 原作の「意味が分からないまま格好いい」ほどの飛躍は、本作の主題（関わりを丁寧に描く）と相性が悪いので、そこまでは寄せていない。像は1つ、読めば分かる範囲にとどめた。
- **読ませ方**: 原作の詩は、紙面の余白と行の切れ目で効く。→ 本作は画面の余白（暗い面）・縦書き・行ごとの浮かび方、そして連ごとに場面を分けて「何回かに分けて」読ませることで、同じ効き方を作った（§6）。
