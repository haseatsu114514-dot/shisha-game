# Assets

**Art direction:** 16-bit pixel art style, Japanese urban shisha lounge atmosphere. Dark backgrounds with warm golden spotlights and purple/blue neon accent lighting. Visual novel layout with dialogue box at bottom. Grid-based pixel art with clean outlines, vibrant color palette on dark base.
