## 自由行動の成長

初期所持金は30,000円。能力は自分で選び実際に体力を消費した行動だけで育つ。
`core/stats.js` の `paidAction()` が台本・訪問の `earnStat()` / `applyStats()` を預かり、行動終了時に1能力につき実増加1P、最大2能力で確定する。
会話後に体力を使う約束も対象。強制イベント・チュートリアル・LIME・回復には加算しない。
バイト後の無料会話は同じ成長枠、追加体力を使う自主練は成功時2能力各1P・失敗時技術1Pの別枠。確定済みの能力加算だけを `gainStat()` が担当し、通常のゲーム内報酬から直接呼ばない。
初回・繰り返し・質問回も同じ1Pルール。同じ能力の報酬候補は重複加算せず、元の数値は候補の優先度に使う。章上限は48／66／82／90／100、★帯の減衰は廃止。既存セーブの現在値・所持金を保持し、旧経験値の端数は進捗率へ移行する（schema9）。
スロットの `onAction({ spent })` には実際の消耗を渡す。回復や強制案内では回さない。
スロットはハズレ／リプレイ1P、チェリー2P、ベル3P、REG16P、BIG／プレミア24P、フリーズ36P。確率・天井・再遊技・救済はそのまま。
成長通知は **STATUS UP** の下に能力名と実増加の **+NP** を置く。Pも数字と同じ19pxの大文字にし、21pxの能力名のすぐ右へ寄せる。漢字は黒い枠の中央へ揃える。煙なしの元の金属枠・漢字銘板・5色を維持し、通常272×68px。進化時だけ **LEVEL UP**・進化・短い恩恵を添え、スロットは **SLOT BONUS**。スロットの通知は同じ位置で枠が一度明るくなり、短い控えめな専用音を添える。ランク名はステータス画面で確認する。
全能力MAXは第5章で育成を重ねて狙う。第3章の必須ルートは帰郷まで接続済み。第4・5章の数値は成長モデルの検証値で、後続の心得の盤（`docs/stat-design/`）で見直す。[表示・バランスと検証記録](../docs/spec/compact_gains_and_growth_20261008.md)。

マップでは店名＋「へ行く」を顔の下に、施設名を大きな記号の下に置く。顔は52px、新しいイベントだけ字面を中央に揃えた丸い「！」を表示する。既読・凛の不在日・定休日・臨時休業は印の対象外。SHISHARKは第2章になるまで地図へ出さない。

## フォルダ構成

```
remake/
  index.html
  css/            base.css（トークン・共通UI）/ vn.css / daily.css / craft.css（大会＝黒×ネオン）/ reel.css（スロット）/ extras.css（恋人・くじ・ギャラリー）
  js/
    main.js       起動（データ読込→タイトル）
    core/         util / data（ローダ・アセット解決）/ state（状態・セーブ）/ stats / audio / ui / stage
    vn/           会話エンジン（dialogue JSON 互換・autoWrap・立ち絵）
    daily/        日常パート（マップ・スポット・バイト・ショップ・くじ・スロット・恋人・ステータス・LIME）
    craft/        シーシャ作り（工程ミニゲーム・調整2回・採点・結果発表）
    chapters/     章の台本（ch1.js〜ch5.js と章ごとの進行・地図・予告モジュール）
    scenes/       タイトル・ギャラリー（見たCGは端末単位で記録＝はじめからやり直しても消えない）
  data/
    manifest.json    立ち絵の余白計測・アセット一覧（tools/build_manifest.py で生成）
    lover.json       恋人のLIME・デート・ちょい会いの文面
  tools/build_manifest.py
  test/playthrough.mjs   第1章の通しテスト（優勝ルート／敗北ルート）
```

立ち絵・背景・作業台の素材（`assets/ui/making/`）を追加・差し替えたら `python3 remake/tools/build_manifest.py` を1回実行する
（Pillow・numpy・scipy が必要）。人物だけの追加は `--portraits-only kumicho rei volk` で他の採用済み画像を維持して更新できる。立ち絵の余白と足元位置、作業台素材の中身の範囲（bbox）を測って
`remake/data/manifest.json` に書き出す。コールドオープンの一台と制作画面の静止モックアップの素材は
この実測値から位置を計算して組む。制作画面には独立した一台のパネルを表示しない。それ以外の変更にビルドは要らない。
文字だけの仮置きCG（無地に説明文の画像）は一覧に載せない＝場面では飛ばし、ギャラリーにも出さない。本物の絵に差し替えて再実行すれば出る。
同じコマンドの最後に `tools/build_images.py` が走り、表示用の軽い WebP を `remake/img/` に作る（元の PNG 91MB → 約15MB。
