- 工程のS・A等のランク表示と大きな結果カードを廃止。結果の詳細は「詳しく見る」で開く。審査で選ぶアピールポイントも具体的な仕上がりの言葉で示し、最終結果の内訳は◎・○・△へ統一する
- 蒸らし時間は100均風の白いキッチンタイマーで自由に設定。分ボタンは1分、秒ボタンは10秒ずつ増え、60秒で分へ繰り上げる。上限は10分で、リセットは00:00。00:00では開始できない。スタート後は弾幕の「ストップ／スタート」で中断・再開できる
- 数字は画像に焼き込まず7セグで描画し、押した回数と実際の残り時間に追従。長い設定でも弾幕は最長32秒へ圧縮し、選んだ時間の温まり方や焦げやすさを反映する
- 弾幕中も吸い出しと同じ温度計・適温帯を表示。温度は時間で上昇し、ミスで下がらない。停止中は温度も弾も動かない。最後の温度を吸い出しへそのまま引き継ぎ、集中できた成績ほど吸い出しの成功帯を広げ、針をゆっくり動かす
- 弾幕の背景に薄い心拍線を表示。被弾するたびに波形が荒れ、緑から黄・赤へ変わり、はじめも驚き／不安の表情になる。時間が経つと落ち着く。初期リフレッシュは中くらいの範囲の弾消しだけで回復・無敵・出現停止を付けない。根性で範囲が広がり、★3からメンタル1段階回復、★5で画面全体を消す。ミス数・温度・成績は巻き戻さない。動きを減らす設定では揺れと心拍線の横移動を止める
- 温度計は適温（ミント）の中央に幅1/10の虹色の最適温を表示。弾幕は被弾数、吸い出しは提供時の最適温への近さで評価する。吸い出しはキープ中央で維持、少し左で微増、右で微減。針のジャスト自体で点数は増やさない。最低2回・3回までは無傷、4回目以降の吸いすぎは葉が痩せる

## 遊び方（ローカル）

```bash
# リポジトリのルートで
python3 remake/tools/serve_preview.py --port 8123
# → http://127.0.0.1:8123/remake/ を開く
```

`data/` と `assets/` を相対パス（`../data/`・`../assets/`）で直接読むので、
**ビルド不要**。file:// では fetch が通らないため、必ずローカルサーバー越しに開く。
開発ブランチの確認は raw.githack でも可:
`https://raw.githack.com/haseatsu114514-dot/shisha-game/<ブランチ名>/remake/index.html`

同梱サーバーは同時接続の待ち数を増やし、HTML・JS・CSS・JSONの古いキャッシュが
更新後のファイルに混ざらないようにする。データは4件ずつ読み、各通信は15秒で中断する。
起動に失敗した場合は読み込み画面に再試行ボタンを表示する。

## 作り直しの方針（旧版との違い）

| 観点 | 旧版 `web/` | リメイク版 `remake/` |
|---|---|---|
| コード構成 | `game.js` 1ファイル約9,000行（512KB） | 責務ごとのESモジュール（1ファイル数百行まで） |
| データ | `build_data.py` で `data.js` に束ねる（要ビルド） | `data/*.json` を**実行時に直接読む**（台詞の正本は共有＝二重管理なし） |
| 進行の書き方 | コールバックの入れ子 | `async/await` で章の台本を上から読める形に |
| セーブ | 継ぎ足しの互換コード多数 | スキーマ版数つき `state` ＋ `migrate()` 1か所 |
| 大会 | 既存工程に仕様を後付け | `docs/master_spec.md` 第2部（穴あけ/炭焼き/FLAVOR TRIAL/10カウント）を**最初から**設計の軸に |
| 画面 | 固定16:9 | 固定16:9（1280×720論理座標）＋煙ワイプ遷移を共通化 |
| 見た目 | 墨×金＋LINE風スマホ＋看板型マップピン | **日常パートは旧版のデザインを踏襲**（オーナー指摘で揃えた・下記）。大会だけ黒×ネオン |
| 書体 | 端末任せ（明朝・ゴシック・ドット等が混在） | **Zen Kaku Gothic New の1書体に統一**して同梱（`remake/fonts/`・SIL OFL）。外部フォントは読まない |

日常パートの見た目は旧版と同じ語彙に揃えている（「スマホとアイコンのセンスが悪くなった」の指摘を受けて）。
別の見た目を足すときもこの語彙から外さない:

- **HUD**: 左上に墨×金の DAY カード（角飾り）、右上に体力・★段階の五角形・アプリ風の LIME・MENU（`daily/hud.js`）
- **マップ**: 街マップ `bg_osu_map_day/night` ＋看板型ピン（テーマ色・白縁・しっぽ・面識のある相手は顔ドット絵）＋右下の墨×金パネル（`daily/map.js`）
- **LIME**: ノッチ付きの端末・緑のヘッダー・白と黄緑の吹き出し・明るい返信欄の丸ボタン（`daily/phone.js`）
- **報酬通知**: ステ色（`--stat-*`）の漢字バッジのカード／好感度は顔ドット絵＋ハート（`core/ui.js` の `gainCard`）
- 顔アイコンは `assets/ui/face_icons/`（48px ドット絵）。`assets/ui/ui_*.png` は仮の色板なので使わない
- 外側の窓はラウンジの金縁を使い、窓の中のタブ・操作ボタン・小さな札は `css/ui-inner.css` の墨色と細い真鍮色の線で揃える。短い操作の文字は中央、説明付きの行動は左端を揃える。ステータスの情報・説明はグラフと5項目の下にまとめ、ショップはDAYカードの下から表示する
- 外側の会話枠・選択肢・HUD・パネル、地図看板・ハート・ゲージ・好感度の通知は `assets/ui/lounge/` の生成画像を使う。実行時用の7枚は `python3 remake/tools/build_ui_skin.py` で `remake/img/ui/lounge/` に作る。プロンプトは `docs/ui_lounge_prompts.md`。通知ウィンドウは項目別、地図の看板は場所の役割別の色を使う
- 日付・所持金のHUDは300pxの固定幅。体力欄は最大体力に合わせてゲージと外枠が一緒に伸びる（残量が減っても器の幅は維持）。所持金は上限999,999円で、HUDはその桁数に合わせた20pxの文字。日常はDAY1〜13、大会はDAY14で、HUDと台詞の残り日数は同じ大会日を参照する。体力ゲージは最大値に対する残量が50%超=緑、25%超〜50%=黄、25%以下=赤。好感度・絆の通知は同じ相手への連続加算を700msで一枚にまとめ、実際の点数と端数は加算時にそのまま反映する
- 大会当日のカウントダウンも「次の大会まであと0日」。スロット横のエリア名・時間欄と筐体下の名前プレートは出さない
- 地図は墨色の共通面と銀の縁に、能力の色と被らない役割別の差し色（キャラの店=スチール／家・拠点=アイボリー／その他=石墨／ショップ=茶系／大会会場=銀白）。能力バッジは読みやすい角ゴシックの「技・感・根・魅・察」を項目色の控えめな四角い枠に重ね、正式名を併記する（アイコン案と比較してオーナーが選択）。洞察は青緑、体力回復は黄緑で区別し、能力アップ通知は実際の増加量を `+NP` で表示。能力アップの各色の面には煙マークを付けない。通知からHUDグラフの対応する頂点へ色の光を運ぶ（動きを減らす設定では光の移動を省略）
- **書体**: すべて `var(--font)`（Zen Kaku Gothic New・太さ 500/700/900）。別の書体を足さない。
  収録文字は JIS 第2水準まで＋データ中の全文字。見慣れない字が豆腐になったら `python3 remake/tools/build_font.py <元TTFのフォルダ>` で作り直す

正史・仕様の正本は変わらない（`CLAUDE.md` / `docs/master_spec.md` / `brand/story_and_structure.md` / `data/*.json`）。
リメイク版はそれを読むだけで、既存の台詞や設定を書き換えない。
リメイク版の進行だけで使う短い場面（チュートリアルの前後・リハーサル・通い訪問の小会話など）は
`data/dialogue/remake_ch1.json` に置いてある（他の台詞と同じスキーマ・同じリンタで検査される。旧版は読まない）。

## 自由行動の成長

初期所持金は30,000円。能力は自分で選び実際に体力を消費した行動だけで育つ。
`core/stats.js` の `paidAction()` が台本・訪問の `earnStat()` / `applyStats()` を預かり、行動終了時に1能力につき実増加1P、最大2能力で確定する。
会話後に体力を使う約束も対象。強制イベント・チュートリアル・LIME・回復には加算しない。
バイト後の無料会話は同じ成長枠、追加体力を使う自主練は成功時2能力各1P・失敗時技術1Pの別枠。確定済みの能力加算だけを `gainStat()` が担当し、通常のゲーム内報酬から直接呼ばない。
初回・繰り返し・質問回も同じ1Pルール。同じ能力の報酬候補は重複加算せず、元の数値は候補の優先度に使う。章上限は48／66／82／90／100、★帯の減衰は廃止。既存セーブの現在値・所持金を保持し、旧経験値の端数は進捗率へ移行する（schema9）。
スロットの `onAction({ spent })` には実際の消耗を渡す。回復や強制案内では回さない。
スロットはハズレ／リプレイ1P、チェリー2P、ベル3P、REG16P、BIG／プレミア24P、フリーズ36P。確率・天井・再遊技・救済はそのまま。
成長通知は **STATUS UP** の下に能力名と実増加の **+NP** を置く。Pも数字と同じ19pxの大文字にし、21pxの能力名のすぐ右へ寄せる。漢字は黒い枠の中央へ揃える。煙なしの元の金属枠・漢字銘板・5色を維持し、通常272×68px。進化時だけ **LEVEL UP**・進化・短い恩恵を添え、スロットは **SLOT BONUS**。スロットの通知は同じ位置で枠が一度明るくなり、短い控えめな専用音を添える。ランク名はステータス画面で確認する。
全能力MAXは第5章で育成を重ねて狙う。第2章以降はまだ未接続なので、5章の調整結果は成長モデルの検証。[表示・バランスと検証記録](../docs/compact_gains_and_growth_20261008.md)。

マップでは店名＋「へ行く」を顔の下に、施設名を大きな記号の下に置く。顔は52px、新しいイベントだけ字面を中央に揃えた丸い「！」を表示する。既読・凛の不在日・定休日・臨時休業は印の対象外。SHISHARKは第2章になるまで地図へ出さない。

## フォルダ構成

```
remake/
  index.html
  css/            base.css（トークン・共通UI）/ vn.css / daily.css / craft.css（大会＝黒×ネオン）/ reel.css（スロット）/ extras.css（恋人・くじ・ギャラリー）
  js/
    main.js       起動（データ読込→タイトル）
    core/         util / data（ローダ・アセット解決）/ state（状態・セーブ）/ stats / audio / ui / stage
    vn/           会話エンジン（dialogue JSON 互換・autoWrap・立ち絵）
    daily/        日常パート（マップ・スポット・バイト・ショップ・くじ・スロット・恋人・ステータス・LIME）
    craft/        シーシャ作り（工程ミニゲーム・採点・FLAVOR TRIAL・結果発表）
    chapters/     章の台本（ch1.js）
    scenes/       タイトル・ギャラリー（見たCGは端末単位で記録＝はじめからやり直しても消えない）
  data/
    manifest.json    立ち絵の余白計測・アセット一覧（tools/build_manifest.py で生成）
    lover.json       恋人のLIME・デート・ちょい会いの文面
  tools/build_manifest.py
  test/playthrough.mjs   第1章の通しテスト（優勝ルート／敗北ルート）
```

立ち絵・背景・作業台の素材（`assets/ui/making/`）を追加・差し替えたら `python3 remake/tools/build_manifest.py` を1回実行する
（Pillow・numpy・scipy が必要）。立ち絵の余白と足元位置、作業台素材の中身の範囲（bbox）を測って
`remake/data/manifest.json` に書き出す。コールドオープンの一台と制作画面の静止モックアップの素材は
この実測値から位置を計算して組む。制作画面には独立した一台のパネルを表示しない。それ以外の変更にビルドは要らない。
文字だけの仮置きCG（無地に説明文の画像）は一覧に載せない＝場面では飛ばし、ギャラリーにも出さない。本物の絵に差し替えて再実行すれば出る。
同じコマンドの最後に `tools/build_images.py` が走り、表示用の軽い WebP を `remake/img/` に作る（元の PNG 91MB → 約15MB。
1枚ずつ可逆と非可逆q90の小さいほう・作業台素材は長辺1280pxまで）。ゲームは一覧にある画像だけ WebP を読み、無ければ assets/ の PNG を読む。
変換済みで元より新しい画像は作り直さないので、2回目以降は数秒で終わる。

**トランジション・場面の演出**（2026-10-09〜10）: 就寝→翌朝は夜の紫が降りてDAYと残り日数がめくれる（`core/transitions.js`）。マップ→場所の移動は6つの型を `core/transition-moves.js` に持ち、既定は pin。`?move=door` や `__remake.dev.moveStyle("door")` で切り替える。チェキ・占い・贈り物・バイトの終わり・サメちゃんとの出会い・つむぎのスケッチは `core/scene-motions.js` が窓口で、中身は場面ごとの `js/motions/<場面>.js`・`css/motions/<場面>.css`（扉の型も `motions/door.js`）。各場面に a／b の2パターン（`?movar=b`・`__remake.dev.motionVariant("b")`）と、紫1色／場面ごとの色の2配色（`?mopal=free`・`__remake.dev.motionPalette("free")`）がある。`__remake.dev.motion("cheki")` などで再生、夜明けの天気は `dawn-sun`／`dawn-cloud`／`dawn-rain`／`dawn-sick`。DAYカードの天気（晴れ・くもり・雨）は `daily/weather.js` の `weatherOf()` で、くもりは見た目だけ。会話の中では `show_cg` の `"effect": "cheki"` と `{"type": "motion", "id": "tarot"}` で呼ぶ。SKIP中と動きを減らす設定では省く。録画は `asset_sources/transitions/`。

文言と表情の正本は `data/characters.json` の `intro_cutin`（サメちゃんは `data/dialogue/kafuka.json` の `profile`）。

背景は `assets/ui/character_intros/`、配色・現行人物PNGの配置は自動生成の `manifest.introArt`。背景・帯・人物・文字は独立して動かす。
