# DJ independent prototype — Issue1064

Entry: `remake/previews/dj/index.html` over the existing HTTP preview server. No build, package install, audio/image downloads or game SAVE required. From the repo root, an existing Python runtime can serve it with `python3 -m http.server 8123 --bind 127.0.0.1`; then use `http://127.0.0.1:8123/remake/previews/dj/`. A task-local candidate bundle can use the same server command with `--directory candidate`. A server/browser was not launched by this task around the recorded local Chrome refusal.

Press 音を開始. The initial level is 18%; mute and volume are available. With assistance ON, the fixed pair is tempo/phrase-aligned when a transfer is reserved. At the next 8-bar boundary, move the horizontal fader to the other deck over 8 bars. The next transfer is queued automatically. Missing the endpoint has no score, penalty or resource effect. Optional J/tap feedback is disabled during transfers.

For manual work, turn reservation assistance OFF. Change tempo separately from ±1/16-beat nudges. Bを半拍ずらして試す introduces an actual half-beat seek; A/B synchronization aligns both tempo and the full 32-beat phrase. Rate changes also change pitch; key lock is not implemented. B's bass is pretransposed to match A under assisted 128 BPM. Waveforms above the decks are actual generated PCM peaks on a common seven-second scale, A above B, with a shared playhead. The % readout is fader position, not linear gain; the audio uses equal-power gains with short ramps.

Both mono test tracks are original procedural sound (kick/hat/snare/bass), 32 beats each, nominal 128/126 BPM. Buffer duration rounding is included in the actual playback-rate calculation. No finished EDM, stock audio, sampled song, third-party sprites or product UI images are included. RED ROOM is a prototype label, not an adopted story venue. Pixel graphics are original code placeholders, not approved character art.

All transport/phase calculations use AudioContext time, not animation frame counts. A/B sources keep their own anchors. The louder side chooses the visual beat master with 40/60% hysteresis; the reserved outgoing deck times the 8-bar interval. VJ brightness uses the mixed-output analyser; the dancer's alternating steps use the visual master's actual beat. Reduced motion keeps a static pose and restrained VJ. No VJ scoring/input.

Pause, hidden tabs and audio interruption stop voices; return requires a user start. Seeking crossfades old/new voices for 8ms and releases the old nodes. Page exit disconnects/closes the graph; bfcache navigation pauses for manual resume. No localStorage/sessionStorage, game state import, economy, day/time or save-schema changes.

Validation: `node remake/test/dj_preview.mjs` checks the actual pure/audio modules through controlled WebAudio ports. It is not browser/listening acceptance. The registered normal CI browser suite is `dj-preview`, command `node remake/test/browser/dj_preview.mjs`; it checks real browser WebAudio/UI on PC, touch and reduced motion without media recording. It has not been run locally. Physical listening, output latency, artwork/animation quality, real device touch and audio/video recording remain acceptance work. Do not bypass recorded local browser restrictions to run it.
