## 遊び方（操作は ▶ と横フェーダーと選曲、ズレた時の皿・DJS17／案内と反応は DJS20〜／皿は DJG）

画面はいつも3つのことを見せる: **いま何をするか**（案内の1行と金色の矢印）、**お客さんがどう感じたか**（フロア）、**どこまで進んだか**（手順のランプ 1 かける → 2 入れる → 3 つなぐ → 4 えらぶ）。金色は「いま触るところ」だけに使う。

0. **始める前**: フロアの上に遊び方の板（4手順）が出ている。▶ を押すと消え、「？ 遊び方」でいつでも開閉できる。
   - タブを隠すなどで止まったときは「一時停止中。左の ▶ で続きから」。その ▶ 1回で、流れていた曲がすべて止まった位置から戻る（MIX 中でも2曲そろって戻る）。
1. **かける**: 左の ▶ が金色に光り、上に金色の矢印。押すと A が鳴り、B には最初の相方の曲が載っている。
2. **入れる**: 次の入りの線まで待つ（入りは**4小節ごと**で、2〜6小節先。DJF03）。案内は「次は右の ▶。カウントが出るまで待とう（あと n 小節）」で、**まだ矢印は出さない**（早押しさせないため）。最後の1小節でフロアに 4・3・2・1、次の ▶ が金色になって輪が縮み、矢印が出る。**0 で ▶**。押した瞬間に判定（PERFECT / GOOD / OK / EARLY / LATE と日本語のひとこと）とフロアの「DROP!」。
   - **QUANTIZE**（常時ON）: CDJ と同じく、押したタイミングを今の曲の一番近い拍に吸着して鳴らす。採点はずれた分で決まる。
   - **判定は一番近い入りの線に対して行う**（DJS23・DJF03）: 線を逃して次の線までの半分（2小節）を過ぎたら、次の線を狙っているものとして判定する（次の頭の少し手前は EARLY〜PERFECT。以前は大きな LATE になっていた）。逃したときの案内は「入りを逃した。次の頭を待とう」。
   - 「いま！」と出るのは、押しても OK 以上になるあいだ（頭から 120ms＋ヘッドホンぶん）だけ。
   - 入れる前に横フェーダーを動かして今の曲が消えかけると、案内が「音が消える！ 横フェーダーを左へ戻そう」に変わり、矢印が戻す向きを指す。
3. **つなぐ（8小節MIX）**: 横フェーダーの上を**光る枠**が動く（ゆっくり入り、5小節目で真ん中、ゆっくり抜ける）。つまみを枠の中に置き続ける。**拍ごとに1回**、枠（±0.14）の中にいるかを判定し、続くと「COMBO n」。
   - つまみが枠の中心から ±0.07 を超えて遅れると、つまみの先に**金色の矢印（1〜3個）**が枠へ向かって流れ、フェーダーの上に「もっと右へ →」。行きすぎると「← 行きすぎ、少し左へ」。乗れているあいだは枠がミント色になり「いい感じ、そのまま」。
   - **EQ は自動**（AUTO EQ）: フェーダーが中央を越えるまで入ってくる曲の低音を抑え、越えたら出ていく曲の低音を抑える。画面には AUTO EQ のランプだけを出す（HI / MID / LOW のつまみは、触れるものと間違えるので DJS30 で外した）。
   - 8小節が終わってもフェーダーが入ってくる側（0.9 以上）に届いていない場合、出ていく曲は最大8小節まで鳴り続ける（猶予。案内は「最後まで右へ動かしきろう」）。
4. **えらぶ（選曲）**: つなぎが終わると、次の曲の候補が2枚出る。吹き出しに**お客さんの声**（「もっと上げて！」「この感じ、続けて」「ちょっとひと息」）。カードには **ノリ**（炎5段階と「今より上がる ↑／同じくらい →／落ち着く ↓」）と、2つの印 **✓ 声に合う／✕ 声と違う**、**✓ なめらかにつながる／✕ 音がぶつかる**（キーが Camelot で同じ・隣・同じ番号の A/B なら ✓）。
   - ✓ が2つなら **◎**、1つなら **○**、0なら **△**。
   - 2枚のうち少なくとも1枚は、お客さんの声に合う（どちらも「✕ 声と違う」になる出方はしない。`model.mjs` の `requestFor`）。
   - 選んだ曲が空いたデッキに載り、次の入りを待つ（今度は逆向きにつなぐ）。曲数ぶん（SET 1 は3曲、SET 2・3 は4曲）つないで終了。候補はまだ回していない曲から出る。

### ズレと皿（2026-11-13・DJG）

オーナー「DJはもっとシンプルにしたく bpmフェーダーをなくして皿を大きくしたい。皿も触るとズレを治せるようにしたい。基本はクオンタイズついてるからそんなやる必要ないけどズレた時に。そういうゲーム性にして」。

- **テンポは機材が合わせる**。PITCH フェーダー・SYNC ボタン・LOCK ランプは無い。どの曲も、いま鳴っている曲の速さで届く（120 と 122 BPM の曲が混ざる SET 3 も同じ）。
- **SET 1** は一度もズレない（▶ と横フェーダーと選曲だけ）。**SET 2** は、つなぎの8小節の途中で入れた曲が**1回ズレる**（7〜21拍目のどこかで始まり、0.12〜0.2拍）。**SET 3** は**2回ズレる**（前半と後半に1回ずつ、0.16〜0.3拍）。先へ走るか遅れるかは毎回違う。`tracks.mjs` の `drift`。
- **ズレ方**: 入れた曲が3拍のあいだ少し速く（遅く）回り、BPM の数字と音がたわむ。3拍たつと速さは戻るが、拍はズレたまま。0.06拍（120 BPM で 30ms）を超えると「ズレた」扱いで、客が「ん、ズレてきた？」、案内が「ズレた！ 右の皿を右回りに回そう」、**その皿の縁が脈打ち、上に回す向きの金色の矢印**が流れ、ミキサーの**ビートメーター**の金の点が枠から出る（右 = 入れた曲が先へ走っている）。
- **直し方**: ズレている曲の**皿を回す**。時計回りで曲を先へ送り、反時計回りで戻す（1回転 = 1拍。皿のどこを触ってもよい。キーボードは皿を選んで ← →）。金の点が枠（±0.035拍）に入るか、**通り過ぎた瞬間に QUANTIZE がつかまえて**ぴったり合う（行きすぎは無い）。逆へ回すと余計にズレる。合っている時・鳴っている側の皿は、絵が回るだけで曲は動かない（自分でズラすことはできない）。
- **損得**: ズレている拍は1拍ごとにフロアの熱 −0.8（横フェーダーが枠を外れた1拍と同じ）。直した瞬間に +3（「ズレを直した」）と客の「お、戻った！」。採点の「ビート」は8小節のうち拍が合っていた割合なので、1〜2拍で直せば 100 のまま、放っておくと 30 まで落ちる。直している間も横フェーダーは枠を追い続ける（両手の仕事）。
- 調整・確認用: コンソールで `__dj.slip(-0.2)` と書くと、つなぎの最中にいますぐズレを起こせる。回す重さは `__dj.feel.jog.beatsPerTurn`。

### 採点

1回のつなぎごとに 3 項目（各 100 / 85 / 60 / 30）→ 平均 → S（90〜）/ A（75〜）/ B（55〜）/ C。

| 項目 | 100 | 85 | 60 | 30 |
|---|---|---|---|---|
| ビート（8小節のうち、2曲の拍が合っていた拍の割合。ズレない SET 1 は常に 100） | 9割以上 | 7.5割以上 | 5割以上 | それ未満 |
| 入り（▶のずれ） | ≤30 ms | ≤60 ms | ≤120 ms | それ以上 |
| フェーダー（枠に乗れた拍の割合） | 9割以上 | 7.5割以上 | 5割以上 | それ未満・最後まで届かない |

フェーダーは、8小節のうちに入ってくる側へ届かず猶予中に届いたときは 60 止まり。セットの点は全つなぎの平均に **フロアの熱のボーナス**（終了時 80 以上＝最高潮で +5、30 未満で −5、上限 100）。結果には各つなぎの選曲（◎○△）と最大コンボ、いちばん低かった項目への一言（次に意識すること）が出る。

### フロアの熱とお客さんの反応（DJS21・DJS22）

**フロアの熱**（0〜100、`model.mjs` の `floor`）がお客さんの気分。50（様子見）から始まり、**やったことごとに段で動く**ので、きれいに回すと最後に最高潮へ届く（以前は1回のつなぎで100に張り付いていた）。

| できごと | 熱の増減（`model.mjs`） |
|---|---|
| 入り（▶） | PERFECT +6 / GOOD +3 / OK 0 / EARLY・LATE −6（`GRADE_FLOOR`） |
| 8小節の1拍ごと | 枠に乗れた +0.3 / 外れた −0.8（`FOLLOW_FLOOR`。32拍すべて乗って +9.6、損益分岐は約73%） |
| ズレ（SET 2・3） | 拍がズレている1拍ごとに −0.8（`SLIP_FLOOR`）、皿で直した瞬間に +3（`SYNC_FLOOR`） |
| つなぎのランク | S +6 / A +3 / B 0 / C −6（`RANK_FLOOR`） |
| 選曲 | ◎ +10 / ○ +3 / △ −5（`PICK_FLOOR`） |
| 音の状態 | 2曲がきれいに混ざっているあいだは毎秒 +0.4（`FLOOR_WARM`）。無音・片側だけ薄い・拍がぶつかると毎秒最大 −3.3 |

目安: 完璧なつなぎ1回で約 +28、A のつなぎで約 +14、荒れると −20 前後。

| 熱 | 気分（`MOODS`） | フロアの見え方 |
|---|---|---|
| 0〜19 | 帰りそう | 暗く色が抜ける。手は上がらない |
| 20〜39 | しらけ気味 | 同上（熱のバーも色が抜ける） |
| 40〜59 | 様子見 | 少し暗い。手が数本 |
| 60〜79 | ノってきた | 明るい。手が増え、拍で揺れる |
| 80〜100 | 最高潮 | いちばん明るい。ほぼ全員の手、光が拍で強まる（ボーナス +5 の線。ゲージに印） |

- **声の吹き出し**: 入りの判定、コンボ 8・16・24・32、4拍続けて外した、音が消えかけた、拍がぶつかっている、つなぎのランク、選曲、気分が最高潮に上がった／しらけ気味に落ちた、で客が一言言う（良い反応は生成りの吹き出し、冷めた反応は灰色）。文言は `app.mjs` の `VOICES`。
- **熱の増減の札**: ゲージの下に「+6　ぴったり入った」「−6　つなぎが荒れた」のように、動いた量と理由が出る。
- **光と音符**: `#crowd` のキャンバスが、絵の上に頭より上を流れる光・熱が上がるとレーザーと拍ごとの閃光・枠に乗れているあいだの音符を描く。動きを減らす設定では止まる。コードで描いていた手前の手のシルエットは、絵の客がシルエットになったので DJS32 でやめた。
- **フロアは主人公（DJ）がブースから見た客席**（DJS28・DJS32）。Codex の5枚（Issue #3224・`asset_sources/ui/dj-renewal-20261111/raw/`）を2層で重ねる:
  - 奥 `floor-room.webp`: 誰もいない店内（`raw/floor-room.png`）。
  - 手前 `floor-pov-1`〜`4.webp`: **シルエットの客**の4段階（`raw/floor-sil-1`〜`4.png`。冷えている＝腕組みとスマホの光／様子見＝グラス／踊っている＝片手／最高潮＝両手）から切り出した観客の帯。熱で `style.css` の `--band` が差し替わる。客はみんなこっち（DJ）を向いている。

## 手応え（2026-11-13・DJF01〜11）

オーナー「DJ、ラクダレースに桜井政博スキルを使って改善と実装をしたい」。斧投げ（AXF）・サンドボード（DSR49〜63）と同じ観点（止め・押した瞬間の反応・音の役割・待ち時間・余韻・次の目標・数値の一元化）でコードを点検し、入れた。

- **待ち時間（DJF03）**: 入りの線を8小節ごと→**4小節ごと**にした。それまでは ▶ を押すまで 4〜12小節（120 BPM で 8〜24秒）、何もすることが無かった。いまは 2〜6小節（4〜12秒）。最初の入りは 16秒後→8秒後。きれいに回した SET 1 は 64秒→48秒（選曲に3秒）。線を逃した時も、次の機会は 16秒後→8秒後。つなぎの長さ（8小節）は同じ。波形の小節番号は入りの線を 1 として数える。`model.mjs` の `quickEntry`（`createSet` の既定は8小節のまま）。
- **▶ を押した瞬間（DJF01・02・10）**: 押した ▶ から判定の色の輪が広がり（PERFECT 金・GOOD ミント・OK 白・外れは赤く震える）、皿が一度弾み、音が鳴る（それまで、入ってくる曲は横フェーダーが反対側なので、押しても何も聞こえなかった）。PERFECT は 0.09秒・GOOD は 0.06秒、**フロアの絵だけ止めて暗く落とし**（客はしゃがむ。曲は止めない）、明けた瞬間に DROP!・白い光・縦の揺れ・客がいつもより高く跳ねる（冷えた客席でも跳ねる）。EARLY・LATE は止めずに、横へがくっと揺れて一瞬暗くなる。
- **効果音（DJF02）**: `sfx.mjs`。カウント 4・3・2・1 に小さなクリック（音声の時計で拍に置く。最後の1つだけ高い）／入りは低い衝撃＋歓声（PERFECT は大きく）／外した入りは下がる鈍い音／コンボ 8・16・24・32 は手拍子1〜3つ（16から歓声が足される）／8拍以上続いたコンボが切れると低い音／ズレた時はたわむ音、直した瞬間ははまる音／つなぎは S・A で衝撃と歓声、C は下がる2音／選曲は ◎ で上がる2音と歓声、△ で下がる2音／セット終了は拍手と歓声。歓声と拍手は本編の録音（`assets/audio/se/minigame/axe_cheer.wav`・`crowd_applause_01.mp3`）、ほかは合成。曲とは別の出口から鳴らし（メーターは曲だけ）、本編のミュートと音量に従う。
- **フェーダー（DJF04）**: COMBO の字は1拍乗るたびに弾み、8・16・24 で大きく明るくなる。4拍以上続いて切れたら、消えずに赤くなって落ちる。8拍ごとの節目は段々大きく（横の小さな揺れ → 縦の揺れ → 縦横の大きな揺れ）。
- **つなぎ完了（DJF05）**: ランクの印は「押して」付く（大きく出て収まる）。S は 0.11秒・A は 0.07秒の止めのあと、S は縦横の大きな揺れ、A は縦の揺れ、C は横へがくっ。
- **セット終了（DJF06）**: すぐ結果の板を重ねず、1.5秒、フロアに「SET COMPLETE!」・拍手と歓声・音符・大きな揺れ。タップ・クリック・Enter・Space・Esc で飛ばせる（最初の0.3秒は効かない）。**記録は回しきった瞬間に確定**する（余韻の途中で戻っても残る）。結果の板は点を 0 から数え上げ（0.9秒）、数え終わるとランクの印を押す。ボタンは最初から押せる。
- **次の目標（DJF07）**: 結果の板に「次のランク A まで あと 4点」（S は「最高ランク S に届いた！」）と、自己ベストとの差。自己ベストは本編が `?best=` で渡す（`minigames/dj.js` の `djUrl`。表示だけで、記録の正本は `state.dj`）。
- **再挑戦（DJF08）**: 遊び方の板は最初の1回だけ。「もう一度」は1曲目がすぐかかる。
- **揺れと光の型（DJF09）**: 揺れは4種（`style.css` の `shake-drop`／`sway`／`big`／`stumble`）。良い結果は暗→白、悪い結果は暗いだけ。
- **押せない ▶ も返事をする（DJG08）**: もう鳴っている・曲が載っていない ▶ を押すと、首を振って鈍い音がする。
- **数値（DJF11）**: 止めの長さ・揺れの型・光・音量・余韻の長さ・皿の重さは `feel.mjs` の `FEEL`（日本語の説明つき・凍結しない）。コンソールで `__dj.feel.hold.PERFECT = 140` と書くと止めずに変わる（今の状態は `__dj.fx`）。URL でも `?feel=hold.PERFECT:140,afterglow.ms:0`。
- 動きを減らす設定では、止め・揺れ・光・数え上げを省く（輪・判定の字・音は出る。余韻は 0.3秒）。
- **音量は計算で決めた値**（耳では確かめていない）。大きい・小さい時は `__dj.feel.sfx.master`（全体）か各項目を動かして決める。

## 軽さ（DJS33「処理重そう」）

毎フレーム動く画面なので、次を守っている（`app.mjs`）。

- **配置は 0.5 秒に1回だけ測る**（`measure`）。画面の幅・フェーダーの位置・波形の大きさを、フレームの最初に（配置が確定しているうちに）読む。毎フレームの書き込みのあとに `offsetWidth` を読むと、毎フレーム配置の計算をやり直すことになる。
- **毎フレームの書き込みは値が変わったときだけ**（`setVar`・`setAttr`・`setStyle`・`put`）。
- **毎フレーム変わるものは配置に響かない描き方にする**: レベルメーターと熱のゲージは高さ・幅ではなく `clip-path` で切り、光る枠と矢印は `left` ではなく `transform` で動かす。
- **フロアの光の層（`#crowd`）は半分の解像度**で描き、止まっているあいだは描き直さない。音符の光は `shadowBlur`（重い）ではなく、大きく薄い音符を重ねて出す。

手元の計測（ヘッドレス Chromium・CPU 4倍遅い設定・つなぎの最中の5秒）: 処理の合計 848 → 643ms／秒、配置の計算 62 → 7回／秒、スタイルの再計算 224 → 125回／秒。フレームは 60fps のまま。
