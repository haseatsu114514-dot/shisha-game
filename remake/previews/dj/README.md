## 遊び方（操作は ▶ と横フェーダーと選曲だけ・DJS17）

1. **A の ▶** でセットが始まる。A が鳴り、B には最初の相方の曲が載っている。上の波形に「IN ▶」の線が来るまで待つ（最低4小節先のフレーズ頭）。
2. **入りが見える**: 4小節前から次の ▶ に輪が縮んでくる。最後の1小節は波形の「IN ▶」が脈打ち、フロアに 4・3・2・1 が出る。**0 で ▶**。押した瞬間に判定（PERFECT / GOOD / OK / EARLY / LATE）とフロアの「DROP!」（PERFECT/GOOD は光が弾け、EARLY/LATE は揺れる）。
   - **QUANTIZE**（常時ON）: CDJ と同じく、押したタイミングを今の曲の一番近い拍に吸着して鳴らす。拍はずれないので、ジョグで位相を直す操作は無い。採点はずれた分で決まる。
3. **8小節MIX（光の帯に乗る）**: 横フェーダーの上を光の帯が動く（ゆっくり入り、5小節目で真ん中、ゆっくり抜ける）。帯の中にフェーダーを置き続ける。**拍ごとに1回**、帯（±0.14）の中にいるかを判定し、続くと「COMBO n」。8コンボ以上はフロアが光る。乗れた拍はフロアが少し上がり、外れると少し下がる。
   - **EQ は自動**（AUTO EQ）: フェーダーが中央を越えるまで入ってくる曲の低音を抑え、越えたら出ていく曲の低音を抑える（低音の入れ替え）。つまみとランプは動きに合わせて回るが操作はできない。
   - 8小節が終わってもフェーダーが入ってくる側（0.9 以上）に届いていない場合、出ていく曲は最大8小節まで鳴り続ける（猶予。届いた時点で終了）。
4. **選曲**: つなぎが終わると出ていった曲のデッキが空き、その上に次の曲の候補が2枚出る。フロアの声（「もっと上げて！」「この感じ、続けて」「ちょっとひと息」）と、各曲の **キーの相性**（Camelot で同じ・隣・同じ番号の A/B なら「相性◯」）と **盛り上がり**（5段階・今の曲より ↑→↓）を見てタップ。
   - 声と相性の両方が合えば **◎**（FLOOR が大きく上がる）、片方なら **○**、どちらも外すと **△**（FLOOR が下がる）。
   - 選んだ曲が空いたデッキに載り、次の入りを待つ（今度は逆向きにつなぐ）。曲数ぶん（SET 1 は3曲、SET 2・3 は4曲）つないで終了。候補はまだ回していない曲から出る。

### BPM 合わせ（任意）

- **SET 1** は選んだ曲も今の曲と同じ BPM で届くので何もしなくてよい（LOCK が点いている。選曲カードには「122 BPM → 120（自動）」）。
- **SET 2** は次の曲が ±1.2〜2.8 % ずれて届く。**PITCH フェーダー（±8 %）**かジョグ外周（1目盛り 0.01 BPM）で合わせる。0.15 % 以内で **LOCK** が点き、QUANTIZE が位相も合わせる。
- **SYNC** ボタンを押せば次の曲の BPM が今の曲に揃う（実機の SYNC と同じ）。使った回のBPM点は 85 止まり。
- **SET 3** は 120 / 122 BPM の曲が混ざる。違う BPM の曲を選ぶと +1.67 % / −1.64 % の合わせが要る。

### 採点

1回のつなぎごとに 3 項目（各 100 / 85 / 60 / 30）→ 平均 → S（90〜）/ A（75〜）/ B（55〜）/ C。

| 項目 | 100 | 85 | 60 | 30 |
|---|---|---|---|---|
| BPM（終了時のずれ） | ≤0.15 % | ≤0.3 %（SYNC使用もここ） | ≤0.6 % | それ以上 |
| 入り（▶のずれ） | ≤30 ms | ≤60 ms | ≤120 ms | それ以上 |
| フェーダー（帯に乗れた拍の割合） | 9割以上 | 7.5割以上 | 5割以上 | それ未満・最後まで届かない |

フェーダーは、8小節のうちに入ってくる側へ届かず猶予中に届いたときは 60 止まり。セットの点は全つなぎの平均に **FLOOR ボーナス**（終了時 80 % 以上で +5、30 % 未満で −5、上限 100）。結果表には各つなぎの選曲（◎○△）と最大コンボも出る。

**FLOOR**（盛り上がり 0〜100）: きれいに混ざっていると上がり、無音・片側だけ薄い・拍が噛み合っていない・EARLY/LATE で下がる。PERFECT と S/A のつなぎ、帯に乗れた拍、◎の選曲で上がる。観客の明るさ・彩度が FLOOR に連動する。

## 画面

- 上: **フロア**（観客の絵・FLOOR ゲージ・セット名と曲数・判定・カウント・DROP・やり直す）。
- 中: **上下 A/B の横波形**（共通の秒スケール・小節番号・8小節の頭は明るい線・次の入りの「IN ▶」・MIX 中は窓を薄く塗る）と案内文1行。
- 下: **コントローラー**。皿（アートワーク・BPM・LOCK）を外側、PITCH と ▶ をミキサー側に。中央は自動 EQ のつまみ・レベルメーター・QUANTIZE / AUTO EQ ランプ・SYNC・銀色の横フェーダー（MIX 中は光の帯とコンボ）。A は紫、B は水色。選曲中は空いたデッキの上に候補カード2枚。

素材は `remake/img/ui/dj/`（#2071/#2073/#2095/#2107/#2114 の生成物をそのまま使用）。フロアの背景は `bg-purple.webp`（空のクラブ）の上に群衆をコードで描いている。

### フロアの観客（DJS09・DJS16）

フロアの帯は Codex が描いた観客 `remake/img/ui/dj/floor-crowd.webp`（3案から b を採用、記録は `asset_sources/ui/dj-floor-crowd-20261102/README.md`）。`style.css` の `.floor:before` に群衆の頭が帯に入る高さで敷き、FLOOR の値で明るさ・彩度を上げる。ドット絵の群衆は描かず、`app.mjs` の drawCrowd は拍に合わせて流れる光だけを描く。
