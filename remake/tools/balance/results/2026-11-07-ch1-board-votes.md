# #2817 第1章の盤・大会の小規模再測定

## 対象と結論の範囲

- 計測対象: `main` の `8984d3e069dd72d54384ebe903d8eaf3848149d0`。このSHAを固定し、道具の現行投票対応だけを加えた。
- 設定: `remake/tools/balance/plan.json`、`version: ch1-normal-v1`、SHA-256 `b632265547803269116a475b2e583c73116bc2a7a10c39050051b37cc3e60c2b`。道具: `remake/tools/balance/measure.mjs`（本PR、SHA-256 `6a99eb8c5c985895fac84fdfae52ef179df961b3b4db4685dd00dc32afccef35`）。順位式: `remake/js/craft/ch1-votes.js` の `CH1_VOTE_VERSION = 2`、元SHAの同ファイル SHA-256 `4695a278883ae769e8d3f4b37088bd899566a7cda78355fe87a42882abc5ee85`。
- 第1章・1周目・14日目、Lv9・白火16個を**入力仮定**とする。各経路は `growth-board.js` の `pathTo`、`nodeStatus`、`commitPending` で実際に支払い、残額を検査した。Lv9・16個に自然プレイで到達する頻度は未測定。
- 操作モデル: `plan.json` の poor / mid / perfect。炭のタイミング、温度誤差、蒸らしの近接を正規分布で近似し、実プレイヤーの入力やフレーム進行を再現しない。レモン10g・ミント2g、シリコンボウル・lotos_hagal・平炭、熟練レモンLv2・ミントLv1、体調green、リハーサルなし、前夜早寝、雨なし、23℃、湿度50%、蒸らし360秒、穴あけスキップを共通条件とした。
- seed は各セル `1..200`。5経路 × 3操作モデル × 200 = **3,000試行**を各2回実行し、全15セルで行SHA-256一致。対応比較では同じseedの操作乱数を使用する。以下はゲーム本体の実機勝率ではなく、この入力モデルの観測値。

## 限界と次の測定

- 本測定は第1章の小さな接続確認。Lv9・16火種、装備・配合・熟練度、3種の操作誤差は仮定であり、実プレイでの分布は測っていない。リフレッシュ、炭交換、疲労、スキル入力判断、盤の授業・会心、自然進行での到達率を含まない。
- 第一印象 +0.3 のマスは第1章経路にない。現行加点式への静的な接続は確認したが、そのマスを灯す後章の効果は未測定。第1章の5経路で見えた差は主に感覚・理論の制作工程と、工程別票に由来する。
- 全章・NG+の同予算・実経路比較は #1801 の残件へ接続する。#2455 のコンプ設計や報酬変更は本件に含めない。旧 `tune3.mjs` の差替え条件は別実験として隔離する。
- ゲーム本体（`remake/js/`、`data/`）の数値・挙動は変更していない。調整値を自動変更していない。
